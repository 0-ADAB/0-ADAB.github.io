# 方法与分析

> 分析不是"把数据算出来"，而是**在明确前提假设下，把物理信号转换成可被推断的量**。每一步转换都会引入假设，假设不成立时，结果仍然会产生，但不再有意义。

## 定位

| 坐标 | 取值 |
| --- | --- |
| 输入 | 各类模态的原始数据 |
| 输出 | 可统计、可解释的指标 |
| 相关模态 | 全部 |
| 决定因素 | 数据类型、研究问题、尺度 |
| 证据类型 | 决定能产出哪类证据 |

## 分析链条

```text
原始数据 → 预处理 → 描述与提取 → 关系与结构 → 推断 → 整合
```

| 阶段 | 页面 | 这一步的假设 |
| --- | --- | --- |
| 预处理 | [[预处理与伪迹控制]] | 伪迹可被建模或剔除 |
| 描述与提取 | [[事件相关分析]] | 反应与刺激时间锁定的试次平均 |
| 描述与提取 | [[时频分析]] | 信号在短时窗内近似平稳 |
| 描述与提取 | [[源定位]] | 头皮场可由有限个源解释 |
| 描述与提取 | [[表征相似性分析]] | 表征差异体现为模式距离 |
| 关系与结构 | [[功能连接]] | 时间统计相关反映协同 |
| 关系与结构 | [[有效连接与因果建模]] | 模型能捕捉方向性影响 |
| 推断 | [[统计推断与多重比较]] | 检验族与错误率控制方式一致 |
| 推断 | [[解码与机器学习]] | 泛化到新样本意味着信息存在 |
| 整合 | [[多模态融合]] | 不同物理量的共同成分有意义 |
| 全程 | [[质控与可重复性]] | 贯穿整条链条，不属某一阶段 |

## 每条方法的固定信息

| 段落 | 作用 |
| --- | --- |
| 输入数据要求 | 决定能不能用 |
| 原理 | 说明它为什么能提取出该指标 |
| 输出结果 | 说明得到的是什么量，不是"什么结论" |
| 关键参数 | 影响结果的自由度 |
| 前提假设 | 最容易被忽略、也最致命 |
| 不适用 | 明确排除的场景 |
| 常见误用 | 高频错误 |
| 实现工具 | 索引到 [[07-资源/分析平台\|分析平台]] |

## 分析选择的三个约束

1. **数据约束**：采样率、空间覆盖、噪声结构决定了哪些方法在物理上可行。
2. **设计约束**：试次数、条件数、被试数决定了统计功效与可用的模型复杂度。
3. **推断约束**：方法输出的量能支持哪类证据。关联分析不能产出因果结论。

## 常见的方法论风险

- **分析自由度**：预处理与参数选择空间过大，导致结果不可复现。见 [[质控与可重复性]]。
- **多重比较**：未校正的检验会产生大量假阳性。见 [[统计推断与多重比较]]。
- **循环分析**：用同一份数据既选特征又做检验，会高估效应。见 [[解码与机器学习]]。
- **过度解释**：把指标变化直接翻译成心理或机制描述。见 [[06-证据/解释边界与常见错误|解释边界与常见错误]]。
