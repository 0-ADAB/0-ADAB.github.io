# 多模态融合

> 多模态融合是把来自不同物理测量手段的数据放入同一个分析框架；它不产生新的物理信息，只改变**能在何种约束下交叉检验**已有的信息。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 从通道/体素到网络与全脑 |
| 时间尺度 | 跨越毫秒（电生理）与秒（血流代谢），融合的核心难点在此 |
| 相关模态 | 电生理、血流代谢、结构扩散、调控、行为眼动、生理化学 |
| 相关现象 | 感知、注意、学习与记忆、意识与睡眠、临床与病理 |
| 相关结构 | [[皮层分区]]、[[大尺度网络]]、[[皮层下结构]] |
| 主要方法 | 对称融合（联合分解）、不对称融合（以一模态约束另一模态）、空间配准、时间耦合分析 |
| 证据类型 | 跨模态一致性证据；一致性提高信心，不一致揭示边界 |

## 输入数据要求

- **共同的时间或空间参照**：同一被试、同一 session 或可对齐的 session；事件标记在两套系统上必须可对应。
- **可靠的配准**：电极/传感器坐标到解剖空间的映射，或功能像到结构像的映射。配准误差是融合结果误差的主要来源之一。
- **可比的实验设计**：两种模态测的是同一任务或同一状态；把不同任务的模态数据合并需要额外论证。
- **各自充分的单模态质量**：融合不会修复单模态的质量问题，一个模态的伪迹会通过共同成分进入另一个模态的结论。

## 原理

融合按"谁约束谁"分为几种层次：

1. **非对称融合（asymmetric fusion）**：用一模态的空间信息约束另一模态的分析。例如用功能像的定位定义电生理分析的感兴趣区域，或用结构连接约束功能连接的候选路径。优点是显著降低自由度；代价是第二模态的结论继承第一模态的假设与误差——若定位错了，后续分析测的是错误位置。
2. **对称融合（symmetric fusion）**：把多个模态的数据放入同一个联合分解或联合模型，让数据自身决定共同成分，例如联合独立成分分解、多模态因子分析。它不预设主导模态，但成分的生理归属需要额外验证，且对模态间信噪比差异敏感。
3. **结果层面并列（conjunction / 并列比较）**：各自独立分析后再比较结果的空间或统计一致性。它回避了模型层面的融合，但"一致"的判断标准常是主观阈值。
4. **跨模态预测（cross-modal prediction）**：用一个模态的数据预测另一个模态的指标。它检验的是模态间可预测性，不直接建立机制联系。

无论哪种层次，融合的信息上限由**两个模态各自的物理分辨率**决定：融合不会把毫秒精度带给影像，也不会把体素精度带给头皮电极。

## 输出结果

- **联合成分或联合模型参数**：需要在生理上被命名，且命名必须独立于分解算法。
- **空间约束下的时间指标**：例如特定区域的时间过程或频率特征，其可靠性取决于定位精度（见 [[源定位]]）。
- **不一致结果**：同样重要的产出。不一致往往指向方法的边界而非"其中一方有错"。

输出是**在融合假设下的联合量**。把它读作"两种测量反映同一神经过程"需要额外前提：测量的物理量之间的关系已知、配准误差小于效应尺度、两模态覆盖的是同一时间过程。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 融合层次（对称/非对称/并列） | 决定结论依赖谁 | 非对称融合的误差传播常被忽略 |
| 空间配准方案 | 决定单元对应关系 | 误差大于效应尺度时结果不可解释 |
| 时间对齐与滞后处理 | 决定耦合估计 | 未考虑两个模态的固有延迟 |
| 成分数或模型阶数 | 决定分解粒度 | 成分数由数据挑选＝事后选择 |
| 感兴趣区或搜索空间 | 决定检验范围 | 由单模态结果反推区域，构成循环 |
| 统计与校正方案 | 决定显著性 | 联合分析的检验族常被低估 |

## 前提假设

1. **同一过程假设**：两个模态在目标条件下测量的是相关或同一神经过程。若被测的是不同过程（例如影像反映长期代谢状态、电生理反映瞬时同步），融合得到的"共同成分"没有单一机制含义。
2. **空间对应假设**：配准后的单元在两个模态中指同一组织或同一功能单元。不成立时，跨模态相关是配准误差的空间自相关。
3. **时间尺度可比假设**：跨模态时间关系的推断要求两个信号的时间尺度不构成瓶颈。以慢信号推断快过程的时序在此不成立。
4. **共同成分归因假设**：联合分解出的成分可被归因于神经活动。共有方差也可能来自生理噪声、头动、血管结构、任务相关的唤醒或预处理步骤。
5. **模态互补假设**：每个模态提供的信息不是另一个模态的确定函数。若一模态可由另一模态完全预测，融合不增加信息。

假设不成立时结果为何失去意义：联合成分仍然会被分解出来、跨模态相关仍然可以显著，但"共同成分"可能只是配准误差、共享噪声或被试间差异的空间模式。此时结论既不属于任一模态的机制陈述，也不能作为跨模态一致性的证据；它只能被描述为"两个数据集之间存在某种统计关联"。

## 适用场景

- 用一模态的高时间分辨率解释另一模态的高空间分辨率结果，形成互补描述（提示性）。
- 用结构连接约束功能连接的候选路径，检验结构—功能对应（见 [[结构与扩散成像]]、[[结构证据]]）。
- 检验跨模态一致性：独立测量在相同条件下是否指向同一区域或同一过程，属 [[跨模态一致性]] 的核心用法。

## 不适用场景

- **两个模态测的任务或状态不同**：融合的前提不存在。
- **配准精度不足**：此时应放弃单元级融合，只在系统或网络层面并列描述。
- **需要毫秒级时序结论而其中一个模态是慢信号**：物理上不可分辨，任何估计都是模型产物。
- **把融合当作因果证据**：多模态一致性提高信心，但不提供干预信息。
- **假设融合能"生成"新信息**：它只能在新约束下重新组织已有信息。

## 常见误用

- **把共同成分命名为机制**：命名来源于成分的空间形态与任务条件，而非独立验证。
- **忽略配准误差**：报告单元级的跨模态相关而不报告配准精度。
- **用单模态结果定义另一模态的感兴趣区后仍报告为独立发现**：构成选择偏差与循环分析。
- **把不一致解释为一方错误**：不一致常常反映两种测量的时间尺度或生理含义不同。
- **未处理模态间固有的响应延迟**：耦合估计的时间滞后被解释为方向性（见 [[有效连接与因果建模]]）。
- **信噪比差异主导分解**：结果主要由质量较好的模态决定，却被读作两模态共同结构。
