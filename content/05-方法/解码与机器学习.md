# 解码与机器学习

> 解码用分类或回归模型检验"某个变量能否从神经模式中被读出"；它回答的是信息存在性与泛化能力，不是"某个区域在做某个心理操作"。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 体素集合、电极阵列、网络或全脑；也可用于单神经元群体 |
| 时间尺度 | 秒（试次级影像响应）；电生理上可做时间分辨解码 |
| 相关模态 | 血流代谢、电生理、行为眼动 |
| 相关现象 | 感知、注意、语言、学习与记忆、决策与奖赏、社会认知 |
| 相关结构 | [[皮层分区]]、[[大尺度网络]] |
| 主要方法 | 分类与回归、交叉验证、正则化、特征重要性分析、多体素模式分析 |
| 证据类型 | 功能关联证据；其强度取决于验证方案是否干净 |

## 输入数据要求

- **试次级样本**：解码的样本单位通常是试次。以平均后的条件作为样本会人为提高可分性。
- **明确的标签或连续目标变量**：标签必须由独立于神经数据的信息定义（刺激类别、行为反应、被试状态），不能用神经数据自身定义的标签。
- **足够的样本量**：样本量需与特征维度、类别数与正则化强度匹配。特征数远大于样本数时，分类器可以在纯噪声上达到高准确率。
- **可交换的独立单元**：交叉验证的分折必须尊重数据的依赖结构（同一被试的试次、同一run的扫描、同一时间窗的重叠样本）。

## 原理

1. **线性与非线性模型**：线性分类器给出权重向量，其方向可被解释为判别轴；核方法与神经网络能拟合非线性边界，但代价是解释性与过拟合风险上升。
2. **泛化即信息**：若模型在**未见过的、独立采样的数据**上优于机会水平，就提示训练数据中的模式含有关于标签的信息。这里的关键词是"独立"——任何泄漏都会使这一提示失效。
3. **交叉验证**：把数据拆为训练与测试折，在训练折上拟合全部步骤（包括特征选择与超参数选择），在测试折上评估。任意一步在测试折上完成，都会使评估偏乐观。
4. **留一被试交叉验证（跨被试解码）**：检验信息是否在个体间共享。它比被试内解码更严格，其失败不否定被试内存在信息。
5. **与 RSA 的区别**：解码检验信息可用性，RSA 检验表征几何。高准确率不保证表征结构与模型一致，反之亦然。

## 输出结果

- **准确率、曲线下面积或相关系数**：模型在独立数据上的表现，通常与机会水平或基线模型比较。
- **显著性**：通过置换检验构造零分布（打乱标签重跑完整流程），而不是用理论假设分布。
- **权重与重要性图**：可给出空间或时间分布，用于生成假说；其解释受特征相关性与模型选择影响。
- **跨条件泛化矩阵**：在条件 A 上训练、条件 B 上测试，用于说明模式的共享与分离。

输出是**模型在特定数据划分下的表现**。"可解码"提示信息存在；它不说明编码形式、不说明区域功能、不说明该信息被试主观使用或意识到。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 模型类型 | 决定边界形状与解释性 | 复杂模型在小样本上过拟合 |
| 正则化强度 | 控制有效复杂度 | 在测试折上调参造成泄漏 |
| 特征选择方式 | 决定进入模型的特征 | 全数据选特征＝double dipping |
| 交叉验证方案 | 决定评估的无偏性 | 忽略数据依赖结构会高估性能 |
| 分折数量与重复次数 | 决定评估稳定性 | 分折过少使准确率方差极大 |
| 平衡与评价指标 | 决定结论方向 | 类别不平衡下准确率虚高 |

## 前提假设

1. **样本独立性假设**：训练与测试样本独立同分布。同一被试的相邻试次、同一 run 的扫描之间存在依赖，随机分折会高估泛化能力。
2. **无信息泄漏假设**：所有依赖数据的步骤都在训练折内完成。特征选择、标准化、伪迹剔除、试次剔除中的任何一步用到了全数据，就会让准确率不再是无偏估计。这是解码分析最致命、也最常见的失败点。
3. **样本代表性假设**：训练数据覆盖了测试分布。若测试是不同被试、不同 session 或不同扫描条件，分布偏移会压低性能，而这不等于"信息不存在"。
4. **标签有效性假设**：标签确实标记了目标变量，且被试在试次上真的处于该状态。标签噪声会同时压低性能与解释力。
5. **解释非对称假设**：权重图不是因果图。由权重推断"该体素编码了该变量"需要额外的、独立的证据。

假设不成立时结果为何失去意义：模型仍会输出一个准确率，甚至很高，但该数字不度量泛化能力。当泄漏或依赖结构存在时，性能估计可以远超真实泛化能力，阴性结果与阳性结果都失去参照。此时唯一诚实的表述是"在当前（有偏）评估方案下的性能"，而这一表述无法支持任何关于信息存在性的结论。

## 适用场景

- 检验某变量在神经模式中是否可读出，作为"信息存在"的证据（提示性）。
- 与行为表现比较：解码准确率与被试行为表现的关系，用于讨论信息与行为指标的对应。
- 时间分辨解码：电生理上判断信息在何时可被读出，属 [[时间动态证据]] 的常见形式。
- 跨条件泛化：说明两个条件是否共享同一模式，与 [[表征相似性分析]] 互补。

## 不适用场景

- **样本量远小于样本维度且无有效正则化**：任何结果都可能是过拟合。
- **标签来自神经数据本身**：例如用神经模式定义的条件作为标签，属循环论证。
- **需要因果或机制结论**：解码不提供操控信息。
- **用同一批数据既做特征选择又做检验并报告显著**：无偏性已破坏。

## 常见误用

- **double dipping（循环分析）**：在全部数据上选特征（或选时间窗、选体素、选通道），再用同一数据交叉验证并报告。
- **在全数据上标准化或做去伪迹再分折**：看似技术细节，实质是泄漏。
- **忽略数据依赖结构随机分折**：同被试相邻试次被分到训练与测试两侧，性能被系统性抬高。
- **用准确率与 50% 比较**：类别不平衡、分折不平衡时基线不是 50%。
- **把权重图当作功能定位图**：权重受特征相关性与正则化影响，不是激活图。
- **把解码成功解释为被试"使用"了该信息**：信息存在与行为使用是两件事。
