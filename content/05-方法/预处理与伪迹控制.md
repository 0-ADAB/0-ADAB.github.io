# 预处理与伪迹控制

> 预处理是把"混合了神经信号、生理噪声、环境噪声与受试者行为"的原始观测，转换成"尽量只保留目标信号"的观测序列；每一步都是带取舍的滤波，压掉噪声的同时也会压掉同尺度、同频段、同成分的信号。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 传感器/通道层级到全脑体素层级 |
| 时间尺度 | 毫秒（滤波瞬态、分段）到分钟（漂移校正） |
| 相关模态 | 电生理、血流代谢、结构扩散 |
| 相关现象 | 全部（伪迹与现象无关，只与记录条件有关） |
| 相关结构 | 全部 |
| 主要方法 | 滤波、重参考、分段与基线校正、伪迹校正、配准与标准化、平滑、坏道处理 |
| 证据类型 | 不直接产出证据，而决定后续证据是否有效（边界） |

## 输入数据要求

- **连续记录**：电生理需要连续原始信号而非已平均的波形；影像需要完整的四维时间序列。
- **采样与通道完整**：采样率足够高（避免混叠）、通道数与被试信息完整、坏段可被标记。
- **事件与同步信息**：刺激标记、反应标记、被试行为日志，且与记录系统的时间基准对齐。
- **解剖与空间信息**：电极坐标、头部形状点或结构像（用于源定位与配准，见 [[源定位]]）。

## 原理

预处理的每一步都可以写成一句话：**在一个可以区分信号与干扰的维度上做投影或滤波**。

- **时间维度**：滤波假设目标信号与干扰在频带上可分（如慢漂移与高频神经活动）。
- **空间维度**：重参考与空间滤波假设干扰在不同通道间具有特定几何结构（共模噪声、容积传导）。
- **成分维度**：盲源分离类方法假设干扰与信号在统计上是可分的、混合是线性的（眼动、心电、肌电常被当作独立成分）。
- **模板维度**：配准类方法假设干扰有可复制的时空模板，可从数据中估计并回归掉。

伪迹控制不是"清除"，而是**重新分配方差**：被去掉的方差不只包含噪声，也包含与噪声相关的信号。因此预处理后的数据不能被视为"更干净的真值"，而是"在特定假设下的一个版本"。

## 输出结果

- 一个结构化、可进入统计的处理后数据集（分段数据、时间序列、体素序列）。
- 一份隐含的**处理历史**：所选的滤波、参考、分段与剔除规则，构成结果可解释性的一部分。

## 关键参数

| 环节 | 关键参数 | 影响 |
| --- | --- | --- |
| 滤波 | 截止频率、滤波器类型、阶数、相位特性 | 高通过低会保留漂移，过高会削去慢成分；非线性相位会引入波形畸变 |
| 重参考 | 参考位置或方案（耳后/乳突、平均参考、以模型估计的参考） | 改变地形图与跨被试可比性 |
| 分段 | 时间窗起点与长度、基线窗位置 | 窗太短丢信息，太长引入漂移与伪迹 |
| 基线校正 | 基线区间选择 | 与刺激或反应重叠时，基线被污染 |
| 去伪迹 | 回归、成分分解、模板减法、剔除 | 强度越大，越可能移除信号 |
| 配准 | 刚体/仿射/非线性变换、代价函数、参数初值 | 误差直接进入后续所有空间分析 |
| 平滑 | 核大小与形状 | 核大于效应范围会抹平；核过小则噪声未降 |

这些参数合起来构成数量可观的组合空间，通常称为**预处理自由度（preprocessing degrees of freedom）**：同一份数据在不同合理流程下可以得到方向不同的结论。

## 前提假设

1. **可分性假设**：信号与干扰在所选维度上可分。若不成立，去伪迹会连带移除目标信号，结果是"处理后的差异"而非"神经差异"。
2. **正交性假设**：伪迹模板或成分与神经源不相关。若伪迹与任务条件系统相关（例如困难条件伴随更多眨眼），回归掉伪迹同时回归掉了任务效应的一部分。
3. **配准有效假设**：空间变换的误差小于被研究的结构或功能差异。不成立时，体素级比较反映的是解剖对齐误差。
4. **流程与模型一致假设**：预处理与后续统计模型匹配（例如时间自相关是否已处理、方差是否被伪迹校正扭曲）。不匹配会让统计的误差假设失效，见 [[统计推断与多重比较]]。

假设不成立时结果为何失去意义：因为此后所有分析都把这些处理后数值当作"该被试在该条件下的观测"。若观测本身是被假设塑造出来的，那么统计只验证了假设内部的算术一致性。

## 适用场景

- 所有需要跨试次、跨被试汇总的分析。
- 组间比较：必须确认两组伪迹水平与剔除比例可比，否则组间差异可能是伪迹差异。
- 需要与结构像或图谱对齐的分析：源定位、连接分析、多模态融合。

## 不适用场景

- **目标现象本身就是伪迹**：眼动、眨眼、肌电、心电研究中的这些信号是数据而非噪声，通用去伪迹流程会移除研究对象。
- **事件极短且与滤波瞬态同尺度**：强滤波会把短事件抹掉。
- **需要保留极低频或极高频信息**：常规带通会破坏它，例如缓慢漂移类过程与高频振荡的精细结构。
- **单试次、低信噪比场景**：以"平均后好看"为目标的流程，可能破坏单试次的时间结构（见 [[时频分析]] 的单试次部分）。

## 常见误用

- **相位失真未被考虑**：使用非线性相位滤波后仍按时间对齐解释波形。
- **基线窗与事件重叠**：基线本身含事件相关活动，使"基线校正"变成部分信号抵消。
- **在整段数据上做成分分解再挑成分**：用数据自身挑选噪声成分，等同于循环分析（见 [[解码与机器学习]] 的 double dipping）。
- **坏道阈值事后调整**：直到结果符合预期为止，等同于未校正的搜索。
- **组间流程不一致**：两组用不同的参考、滤波或剔除规则，组间差异被流程差异污染。
- **把配准误差当作结构差异**：尤其是萎缩、病变或术后被试。
- **平滑后报告"局部激活"**：平滑把相邻体素的信息混合，空间精度低于报告时的暗示。
