# 表征相似性分析

> 表征相似性分析（representational similarity analysis, RSA）把每个条件的多通道或多体素模式压缩成一个条件间的距离矩阵，再通过比较矩阵来检验"表征结构"是否一致。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 体素集合、电极阵列、区域或成分；单元集合的选择决定结论 |
| 时间尺度 | 秒（血流代谢的试次级响应）；电生理上可达毫秒级时间窗 |
| 相关模态 | 血流代谢、电生理；也可用于行为与模型表征 |
| 相关现象 | 感知、语言、学习与记忆、社会认知、决策与奖赏 |
| 相关结构 | [[皮层分区]]、[[大尺度网络]] |
| 主要方法 | 表征差异矩阵（RDM）构建、距离度量、矩阵比较、跨被试与跨模态对齐 |
| 证据类型 | 功能关联证据与跨模态一致性证据；结构化比较，而非定位断言 |

## 输入数据要求

- **条件明确的设计**：RSA 比较的是条件之间的关系结构，因此条件的定义与数量决定了矩阵的维度与可检验性。
- **试次级或条件级的模式估计**：每个条件需要一个稳定的多单元模式；试次数不足时模式估计被噪声主导。
- **单元集合（ROI、搜索空间或全脑）**：集合应当有先验依据，或明确说明为探索性。用结果反推区域再计算 RSA 构成循环分析。
- **噪声结构的估计**：要区分"真实相似"与"噪声造成的相似"，需要多次独立测量或分半、分折估计。

## 原理

1. **从模式到距离**：对每个条件估计一个模式向量（体素响应、电极幅值、时间窗特征）。任意两条件之间的距离构成 RDM 的一个元素：对角为零、对称的方阵。
2. **距离度量的选择**：常用欧氏距离、相关距离、马氏距离等。不同度量对模式的整体幅度、噪声与相关结构敏感度不同，选择会影响结论。
3. **矩阵层面的比较**：把神经 RDM 与另一个 RDM（不同区域、不同模态、行为、模型）做相关或偏相关，衡量两者的结构一致性。跨条件集合的信号相似性比较的是"关系的形状"，而不是绝对响应。
4. **噪声归一化**：当比较两个信噪比不同的 RDM 时，原始相关会被噪声差异压缩。常用做法是用独立分折估计噪声并做信噪比归一化，否则"哪个表征更接近模型"的比较没有意义。
5. **与解码的关系**：解码回答"信息是否可被读出"，RSA 回答"多个条件之间的几何结构如何"。两者可以互补但不能互相替代：良好的解码不意味着 RDM 与模型一致，RDM 相似也不意味着信息在单试次层面可用。

## 输出结果

- **RDM 及其可视化**：条件间的距离结构，是分析的中间产物，也是解释对象本身。
- **矩阵间的一致性量**：神经 RDM 与行为/模型/其他区域 RDM 的关联强度，通常带置换检验得到的显著性。
- **模式可分性结构**：哪些条件对彼此更相似，形成聚类或梯度结构。

输出是**模式空间中的距离结构**。它不提供"某区域负责某功能"的定位结论，也不说明表征使用的具体维度——RDM 是几何描述，不是内容描述。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 条件集合 | 决定 RDM 的维度 | 条件过少使相关估计不稳定 |
| 单元集合 | 决定模式的构成 | 用结果选区域造成循环 |
| 距离度量 | 决定相似性的含义 | 与噪声结构不匹配时结果被噪声主导 |
| 模式估计方式（单试次/平均、分折） | 决定信噪比与噪声校正可行性 | 单次估计无法分离噪声相关 |
| 噪声归一化方式 | 决定跨条件可比性 | 不归一化时信噪比差异伪装成表征差异 |

## 前提假设

1. **模式忠实假设**：估计出的模式反映该条件的神经表征，而非噪声或全局信号。信噪比低时，模式由噪声决定。
2. **距离有意义假设**：所选度量确实对应表征空间中的某种几何关系。欧氏距离与相关距离隐含不同的几何，且距离的可解释性依赖测量尺度。
3. **跨被试可比假设**：不同被试的单元集合对应同一解剖或功能位置。配准误差与功能边界个体差异会把"个体差异"写成"表征差异"。
4. **噪声独立假设**：比较两个 RDM 时，噪声不在两者间共享。若比较对象是同一批数据（例如同一被试的同一扫描），噪声相关会人为制造相似性。
5. **条件编码假设**：条件之间的相似性结构可以解释为刺激特征或任务变量的结构。不成立时，RDM 的几何无法被命名，结论只能停留在"存在某种结构"。

假设不成立时结果为何失去意义：RDM 仍然可以画出、仍然可以与他人的 RDM 显著相关，但这种相关可能是噪声结构、试次数差异或配准误差造成的。此时结论应降级为"在所选度量与噪声条件下，两个矩阵存在关联"，不能表述为"某区域以某种方式表征某类刺激"。

## 适用场景

- 比较多个条件之间的关系结构，而不仅是两两差异。
- 跨模态对齐：把影像、电生理与行为侧的相似性结构放在同一条件集合上比较（见 [[多模态融合]]、[[跨模态一致性]]）。
- 与计算模型对话：检验模型派生的表征几何是否与神经数据一致，属 [[计算模型证据]] 的常见形式。

## 不适用场景

- **条件数很少**：两三个条件的距离结构无法支撑矩阵层面的推断。
- **需要单试次层面的信息可用性**：RSA 默认是条件级几何，不直接回答单试次可读性，那属于 [[解码与机器学习]]。
- **功能区边界不明的集合**：跨被试对齐误差会主导结果。
- **需要方向或因果结论**：RSA 是描述性几何比较。
- **把 RDM 直接读成"表征内容"**：几何相似不等于共享内容或共享编码方式。

## 常见误用

- **忽略噪声相关**：两个 RDM 因共享噪声而相似，被解释为表征一致。这在使用分半数据或同一批试次时尤其危险。
- **用同一分折既估模式又估噪声**：循环分析，会系统高估相似性。
- **不做信噪比归一化就比较 RDM**：信噪比高的区域看似"更接近模型"，实为噪声更少。
- **事后选时间窗或区域**：构成未校正搜索。
- **把 RDM 相关当作机制证据**：相关性陈述不支持机制断言。
- **条件对不独立仍用常规相关检验**：RDM 元素之间高度依赖，需要置换或分层方案。
