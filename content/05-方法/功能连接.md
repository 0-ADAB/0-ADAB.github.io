# 功能连接

> 功能连接用时间序列之间的统计依赖描述区域间的协同程度；它是**相关性陈述**，不包含方向、不包含传递，也不包含解剖通路信息。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 脑区到网络、全脑 |
| 时间尺度 | 秒（血流代谢的波动）；毫秒级动态连接需电生理数据 |
| 相关模态 | 血流代谢、电生理 |
| 相关现象 | 注意、学习与记忆、意识与睡眠、发展、临床与病理 |
| 相关结构 | [[大尺度网络]]、[[皮层分区]]、[[皮层下结构]] |
| 主要方法 | 相关与偏相关、相干与相位同步、种子点分析、独立成分分析、图论指标 |
| 证据类型 | 功能关联证据；方向性需另行建模，见 [[有效连接与因果建模]] |

## 输入数据要求

- **时间序列与其长度**：连接指标的稳定性强烈依赖序列长度；序列越短，相关系数的抽样波动越大。
- **足够的时间分辨率与采样率**：相干与相位同步类指标要求采样率远高于目标频率。
- **统一的预处理**：滤波、重参考、配准与头动校正方案在个体间、组间一致（见 [[预处理与伪迹控制]]）。
- **节点定义**：图谱分区、种子点坐标、独立成分为三种常见做法，节点定义直接改变结果。

## 原理

1. **相关层面**：功能连接度量的是"两个时间序列的统计依赖强度"。皮尔逊相关度量线性同步；相干（coherence）在频域做同样的度量；相位同步类指标度量相位关系在时间上的稳定程度。
2. **偏相关与共同来源**：偏相关在控制其余节点后计算两节点的依赖，部分缓解共同驱动问题，但依赖节点集合的完整性——未被纳入的第三个源仍会制造伪连接。
3. **种子点方法**：选一个区域的时间序列，计算它与全脑其余体素的相关图。结果完全取决于种子点的时间序列本身，而种子点时间序列又包含了该区域内所有信号（包括噪声与部分容积效应）。
4. **独立成分分析（independent component analysis, ICA）**：把全脑信号分解为统计上相互独立的时空成分，再把成分的时间过程相互关联。它不预设节点，但成分数量、稳定性与生理归属都需要验证。
5. **图论刻画**：把连接矩阵当作网络，计算度、聚类、模块化、效率等指标，用于描述网络的整体结构。这些指标本身依赖阈值选择与节点定义，可比性有限。

## 输出结果

- **连接矩阵**：节点 × 节点的关联强度，是后续几乎所有分析的原料。
- **连接图**：以种子点或成分为中心的统计图，常与 [[大尺度网络]] 的名称对应。
- **网络指标**：度分布、模块结构、中心性、全局效率等网络层面的量。

输出的量是**统计依赖强度**。"连接增强"只能读作"两个时间序列的共同变化程度更高"，其背后至少有以下几种可能：真实相互作用、共同输入、同一生理噪声来源、预处理造成的共享变异、节点定义重叠造成的容积传导。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 节点定义 | 决定连接矩阵的维度与含义 | 图谱粒度改变结果；重叠区域人为制造高连接 |
| 时间序列长度 | 决定估计精度 | 过短导致矩阵噪声大，跨被试比较不成立 |
| 滤波与带通 | 决定保留哪些共变成分 | 带通过窄会人为提高相关 |
| 重参考/回归策略 | 决定共享成分 | 去除全局信号会改变所有连接值 |
| 窗长与步长（动态连接） | 决定时间分辨率与估计噪声 | 短窗结果高度依赖窗长选择 |
| 头动校正方式 | 影响伪连接方向 | 校正过度会移除真实连接 |

## 前提假设

1. **协同即关联假设**：区域间统计相关反映功能协同。这是**定义层面**的假设，把相关读成相互作用就超出了定义。
2. **平稳假设**：在整个分析窗内，两个序列的关系不变。若关系本身随时间变化（动态连接、状态切换），单一相关系数是混合值，且混合可能产生虚假的"中等连接"。
3. **共同驱动可忽略假设**：第三个源的系统性影响可以忽略或已被建模。不成立时，两个区域可能因共同输入而显示高连接，彼此并无直接关系。
4. **噪声不系统共变假设**：生理噪声（心跳、呼吸、运动、血管）不会在目标节点对上系统性共变。这对 fMRI 尤其重要：血管解剖与生理节律会造成与神经活动无关的高相关。
5. **预处理不制造连接假设**：滤波、全局信号回归、平滑等步骤没有在节点间引入共享方差。
6. **信度假设**：个体连接矩阵在重复测量中稳定。信度低的连接值在两个组之间比较不具备可解释性。

假设不成立时结果为何失去意义：连接矩阵仍然存在、仍然可以做出漂亮的网络图与显著组间差异，但"连接"一词所指的协同关系可能完全由共同驱动、生理噪声或预处理造成。此时结论不是"两个脑区交互更强"，而只是"两个信号更像"。

## 适用场景

- 描述性刻画：同一条件下哪些区域的时间过程彼此关联，用于生成假说。
- 组间比较：在严格控制伪连接来源与信度的前提下比较连接强度差异（属提示性证据）。
- 与结构连接对照：比较结构连接与功能连接的一致性，属跨模态一致性检验（见 [[结构与扩散成像]]、[[跨模态一致性]]）。
- 网络层面的整体描述：模块结构、中心性等，用于组织多区域结果。

## 不适用场景

- **推断方向性**：功能连接不含方向。所有"从 A 到 B"的表述都需要 [[有效连接与因果建模]] 的模型，且仍然需要额外假设。
- **替代解剖通路**：功能相关不要求存在直接轴突连接；强连接可以是多突触或共同输入的结果。
- **短序列的个体水平结论**：个体连接估计的抽样误差可能大于组间差异本身。
- **因果与机制断言**：相关性陈述不支持"某区域导致某功能"。

## 常见误用

- **把连接读作沟通或信息传递**：相位同步与相关只是统计依赖，不能证明信息流动。
- **忽略共同驱动**：把两个共同受第三区域驱动的区域报告为直接相互作用。
- **在短窗上做动态连接并直接解释状态切换**：窗长与步长选择本身可以生成"状态"。
- **不做信度检验就做组间比较**：低信度的指标上比较组间差异，效应难以复现。
- **忽略头动与生理噪声的组间差异**：临床组与对照组的头动、呼吸模式常不同，组间连接差异可能完全由此产生。
- **把全局信号回归的影响当作发现**：该步骤显著改变连接结构，选择本身需要预注册或敏感性分析。
