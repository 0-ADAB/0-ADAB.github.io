# 有效连接与因果建模

> 有效连接指的是"一个神经系统的活动对另一个系统活动的影响"，它通过显式模型估计，而不是通过相关性读出；在此语境中"因果"始终是**相对于模型与数据的因果**，而非干预意义上的因果。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 脑区到网络；节点定义决定结论粒度 |
| 时间尺度 | 毫秒（电生理类方法）到秒（血流代谢类方法） |
| 相关模态 | 血流代谢、电生理 |
| 相关现象 | 注意、学习与记忆、感知、临床与病理 |
| 相关结构 | [[大尺度网络]]、[[局部回路]]、[[皮层分区]] |
| 主要方法 | Granger 因果、动态因果模型、结构方程模型、转移熵、模型比较 |
| 证据类型 | 因果证据中的**模型内因果**；与 [[因果干预证据]] 有本质区别 |

## 输入数据要求

- **时间序列与其采样结构**：血流代谢数据的时间分辨率远低于神经事件的时间尺度，此处的时间顺序与神经层面的先后不是同一件事。
- **明确且先验指定的节点集合**：节点由假说指定（模型驱动）还是由数据选出（数据驱动），会决定结论的可信度。数据驱动选节点后再建模，容易把噪声结构写成连接。
- **模型空间的完整定义**：候选模型集合必须事先写清，包含合理的备择模型；模型比较只在给定的集合内有效。

## 原理

四条常见路径的出发点和代价不同：

1. **Granger 因果（Granger causality）**：如果序列 A 的过去能改进对序列 B 未来的预测（超出 B 自身过去所提供的预测力），就说 A "Granger 导致" B。它依赖可预测性、平稳性与观测完整；未观测的共同输入会同时制造两个方向的"因果"。
2. **动态因果模型（dynamic causal model, DCM）**：写出一组由状态方程描述的神经动力学模型，把神经活动与观测（血流动力学响应或电磁场）通过观测模型联系起来，再比较不同连接结构的模型。它的核心是**模型比较**而非单点估计。
3. **结构方程模型（structural equation model, SEM）**：在协方差结构上设定路径关系，用数据估计路径系数。它本质上是同期关联的分解，方向性来自模型的设定而非数据中的时序。
4. **转移熵（transfer entropy）**：基于信息论的定向依赖度量，度量一个序列的过去对另一个序列未来不确定性的减少，可捕捉非线性依赖，但同样需要长序列且对参数（嵌入维度、延迟、分箱）敏感。

共同点：方向不是"从数据里读出来"的，而是**在模型假设下被估计出来的**。不同方法在同一个数据集上给出不同方向，是很正常的结果，而不是其中之一出了错。

## 输出结果

- **连接参数及其不确定性**：每个方向上的影响强度与置信区间；只报告点估计无法支持方向断言。
- **模型比较量**：相比备择模型，某连接结构是否更受数据支持。没有模型比较，"有连接"这一陈述没有参照。
- **方向性诊断**：不同方法、不同预处理、不同节点定义下方向是否一致的敏感性分析。

输出的量是**模型参数**。把它读作"区域 A 驱动区域 B"需要额外前提：模型结构正确、节点同质、观测与神经活动的映射已知、未观测源可以忽略。缺少任何一条，方向结论就只是模型内部的结论。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 模型空间 | 决定哪些结构可被比较 | 备择模型不含真实结构，比较结果失去意义 |
| 节点定义与数量 | 决定模型维度 | 节点过多使参数估计不可靠 |
| 模型阶数/滞后阶 | 决定可捕捉的时间尺度 | 与数据采样率不匹配时方向估计失真 |
| 观测模型（DCM 中） | 连接神经活动与测量 | 观测模型的误差被归入连接参数 |
| 先验与正则化 | 约束参数估计 | 先验过强会决定结论 |
| 预处理（去噪、滤波、重参考） | 改变时间与空间结构 | 不同流程给出不同方向 |

## 前提假设

1. **因果充分性假设**：所有相关因果源都被纳入模型。Granger 类与转移熵类方法对此最敏感：未观测的共同输入会导致双向虚假"因果"。
2. **时间顺序即因果顺序假设**：观测到的时间先后对应神经层面的因果先后。血流代谢信号的时间尺度远慢于神经事件，其"先后"不能直接映射到神经因果链。
3. **模型正确性假设**：模型结构（连接的有无与形式）包含真实机制。若真实结构不在模型空间内，模型比较只会选出"最不差"的近似。
4. **平稳性假设**：序列的统计特性在分析窗内不变。非平稳会产生虚假的方向性，而任务数据本身往往是非平稳的。
5. **节点同质与观测同一性假设**：同一节点在不同条件下对应同一功能单元；不同被试的同一节点对应同一解剖位置（配准误差在此进入连接参数）。
6. **可识别性假设**：模型参数能从数据中被唯一确定。存在等价模型或参数不可识别时，估计值没有意义——这一点在 SEM 与 DCM 中必须显式检查。

假设不成立时结果为何失去意义：模型仍然会收敛、参数仍然有数值、模型比较仍然会选出一个赢家，但"方向"与"强度"只是模型与数据的联合产物。此时可以报告"在模型 X 下参数 Y 的估计值"，但不能报告"区域 A 驱动 B"，更不能把它与操控实验的因果证据并列。

## 适用场景

- 已有明确解剖或功能假说，需要比较几种候选连接结构时。
- 任务条件或个体差异如何改变已知耦合强度：把连接参数作为因变量做组间或条件比较（提示性证据）。
- 与功能连接联合报告：相关结构给出"谁与谁共变"，模型给出"在假设下谁影响谁"。
- 与干预数据结合：把调控或损伤结果作为模型假设的独立检验，这是提升因果强度的关键路径（见 [[神经调控技术]]）。

## 不适用场景

- **替代干预实验**：任何建模方法都不能替代操控。此处得到的"因果"不含干预含义。
- **节点集合未知的探索性研究**：在大量候选节点上搜索方向会产生大量不可复现的结果。
- **非平稳过程且未建模**：学习、漂移、状态切换中的方向估计需要显式处理非平稳性。
- **把慢信号的时间先后当作神经先后**：时间分辨率不足时，方向问题在物理上不可分辨。

## 常见误用

- **把 Granger 因果简称为因果**：方法名称中的"因果"不带来干预语义，报告时须明示这是预测性方向。
- **不做模型比较就报告连接**：没有备择模型，参数的正负无从解释。
- **数据驱动选节点后再建模并统计**：节点由数据选出，方向估计与检验共用数据。
- **忽略共同输入**：把双向"因果"当作相互影响，而实际来源是第三个未观测系统。
- **不报告参数不确定性与等价模型**：把点估计当作确定结构。
