# 时频分析

> 时频分析把一维时间序列展开成时间、频率与功率（或相位）联合表示的二维量，用来描述在时间上不持续、在相位上不锁定的振荡性活动。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 传感器/电极层面；源层级依赖 [[源定位]] 且分辨率更受限 |
| 时间尺度 | 毫秒到秒（单个振荡事件）；秒到分钟（功率的慢变） |
| 相关模态 | 电生理（头皮与颅内），亦可用于血流代谢信号的慢波动 |
| 相关现象 | 感知、注意、运动控制、学习与记忆、意识与睡眠 |
| 相关结构 | 全脑，常见于 [[局部回路]] 与 [[大尺度网络]] 的解释框架 |
| 主要方法 | 短时傅里叶变换、小波变换、希尔伯特变换、多锥度谱估计、单试次分解 |
| 证据类型 | 时间动态证据；相位类指标的推断边界尤其严格 |

## 输入数据要求

- **连续记录与足够采样率**：采样率决定可分析的频率上限，抗混叠滤波必须已经生效。
- **事件标记与分段**：既可按事件分段，也可在连续数据上滑动计算；两种做法的基线定义不同。
- **足够的试次数（对相位类指标尤其重要）**：相位估计在低信噪比下偏差很大，相位同步类指标对此尤其敏感。
- **频带定义**：频带界限必须先验指定或明确说明为探索性，事后选定频带属于未校正搜索。

## 原理

三种常见路径对"振荡"的假设不同：

1. **短时傅里叶变换（short-time Fourier transform, STFT）**：用固定长度的窗在时间上滑动做傅里叶变换。频率分辨率由窗长决定，时间分辨率随之被固定；加窗本身假定窗内信号近似平稳。
2. **小波变换（wavelet transform）**：用可伸缩的母小波与信号卷积，低频用长窗、高频用短窗，时间-频率分辨率随频率自适应变化。仍受不确定性关系约束。
3. **希尔伯特变换（Hilbert transform）**：先带通到窄频带，再构造解析信号，得到瞬时幅值与瞬时相位。它对带通宽度极敏感：带通过窄则瞬时幅值出现虚假慢调制，过宽则瞬时相位失去意义。

无论哪条路径，核心守恒量是**不确定性关系**：时间分辨率与频率分辨率不能同时任意提高，二者之积有下界。因此"某个频率在某个瞬间的功率"始终是一个时频单元的估计，而不是一个点值。

## 输出结果

- **功率（幅值）指标**：事件相关谱扰动（event-related spectral perturbation, ERSP）一类量，表示相对基线的功率变化；以及试次间相位一致性（inter-trial coherence, ITC）一类量，表示相位在试次间的集中程度。
- **相位指标**：瞬时相位、相位差、相位同步程度、相位-幅值耦合（跨频率耦合的一种形式）。
- **单试次指标**：单个振荡事件的持续时间、频率、幅值（常称 burst 或振荡事件分析）。

输出是**功率与相位随时间和频率的变化**。把它直接读作"某个脑区在做某件事"跨越了两步推断：从信号到神经活动，从神经活动到功能。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 窗长/小波周期数 | 决定时频分辨率的分配 | 在窄带与瞬变之间无法两全 |
| 频率范围与步长 | 决定覆盖与平滑程度 | 步长过密造成虚假的统计自由度 |
| 频带划分 | 定义报告单元 | 频带边界事后调整等于未校正搜索 |
| 基线区间 | 定义功率变化的参照 | 基线与事件重叠会吸收任务效应 |
| 基线归一化方式 | 决定跨条件可比性 | 减法、比值、对数变换对结果形状影响明显 |

## 前提假设

1. **局部平稳假设**：在分析窗内，信号的统计特性近似不变。若振荡是短暂且快速变频的，窗内平均会得到不存在的中间频率成分。
2. **窄带假设（希尔伯特路径）**：带通后的信号近似单频。不成立时瞬时相位与瞬时幅值不可靠。
3. **基线可比假设**：基线区间能在条件之间提供同一参照。若条件本身改变了基线活动（预期、唤醒、注意水平），归一化后的"事件相关"变化里包含基线差异。
4. **相位-功率可分假设**：报告相位同步时不隐含功率差异的影响。实际上两者常同时变化：功率升高会使相位估计更稳定，从而人为提高同步指标。

假设不成立时结果为何失去意义：时频图仍然色彩分明、统计仍可显著，但"某频带在某时段功率升高"可能只是窗长与基线的产物，而非振荡性神经活动。此时结论降级为"在所选参数下的分解结果"，不能作为生理量报告。

## 适用场景

- 非相位锁定的活动：自发振荡、振荡的幅度调制、事件引起的功率变化。
- 跨频率交互：相位-幅值耦合等，用于描述不同时间尺度的相互作用。
- 单试次与逐试次关联：把单试次功率与行为表现关联，检验"波动是否与行为共变"。

## 不适用场景

- **只有极少试次**：功率与相位估计的信噪比不足，尤其相位类指标。
- **目标是精确时序**：时频分解的时间精度受不确定性关系限制，不如直接的事件相关波形（见 [[事件相关分析]]）。
- **目标事件持续时间短于一个周期**：分解无法区分"短事件"与"低幅持续活动"。
- **非振荡性过程**：把任何慢变或阶梯状信号用小波展开都会得到看似有结构的时频图。
- **需要方向性连接结论**：功率与相位本身不含方向信息，方向性推断需要额外的模型（见 [[有效连接与因果建模]]）。

## 常见误用

- **把时频图的每个像素当作独立检验**：未做校正或未做聚类，直接报告"显著区域"，等同于大规模多重比较。
- **基线归一化掩盖基线差异**：只报告相对变化，不报告绝对功率与基线本身。
- **相位同步当作沟通**：两个信号的相位关系稳定，可以由共同输入或共同参考造成，不能读作信息传递。
- **功率与相位的混淆**：信噪比升高会同时提高功率与相位一致性，源于同一物理原因的两类指标被当作两条独立证据。
- **事后选择频带与时间窗**：在图上寻找最显著的区域再定义频带，形成循环分析。
- **把单试次"振荡事件"当作神经元放电**：头皮信号是大量单元活动的叠加，单个 event 不对应单个神经元事件。
