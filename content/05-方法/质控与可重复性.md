# 质控与可重复性

> 质控是判断"这份数据在多大程度上可以被当作该条件的有效观测"，可重复性是判断"这个结论在多大程度上可以被别人重新得到"；两者都是分析流程的一部分，而不是事后检查。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 从单通道到全脑，再到跨中心汇总 |
| 时间尺度 | 从单次记录到跨 session、跨年份的数据集 |
| 相关模态 | 全部 |
| 相关现象 | 全部 |
| 相关结构 | 不限定 |
| 主要方法 | 质量指标与阈值、剔除与敏感性分析、流程固定与共享、预注册、报告规范、版本与容器化 |
| 证据类型 | 一致性证据的前提；缺失时其他证据的强度不可评估 |

## 输入数据要求

- **原始数据与元数据**：原始记录、采集参数、被试信息、异常事件记录。只保留处理后数据会使一切质控无法回溯。
- **可自动计算的质量指标**：信噪比、坏道数量、头动幅度、剔除试次比例、伪迹成分解释的方差比例、缺失数据比例。
- **剔除与插值规则**：必须在看到结果之前或至少独立于结果定义，否则规则本身成为分析自由度。
- **流程的完整描述**：包括所有参数、工具配置与人工判断点，以及判断依据。

## 原理

1. **质量不等于数据好坏，而等于"偏差的可控程度"**：低信噪比未必不可用，但若质量与实验条件系统相关，条件比较就被质量差异污染。质控的目标是识别并打破这种关联。
2. **剔除既是清理也是选择**：剔除坏试次减少噪声，同时改变样本构成。剔除规则若与条件相关，会直接制造或抹除效应。
3. **多重分析路径（garden of forking paths）**：即使没有主观作弊，合理流程的分支数量也极大——滤波参数、参考、分段、剔除阈值、模型、检验族。不同分支给出不同结论时，选择哪条分支成为未声明的推断。
4. **可重复性的分层**：同一数据同一代码能否复现数值（计算可重复）；同一数据不同实现能否得到同一结论（分析稳健性）；新数据能否得到同一结论（结果可重复）。三者是不同的问题，混淆它们会导致错误的信心。
5. **预注册的作用是界定探索与确证**：它不保证结论正确，只是让"事先规定的检验"与"事后找到的检验"可被区分。
6. **工具实践的可复现性**：脚本化、版本控制、环境记录、数据组织规范，使流程能被外部重建而不是被口头描述。

## 输出结果

- **质控报告**：每位被试、每个 session 的质量指标与其分布，以及被剔除的单元与理由。
- **样本纳入流程图**：从采集到最终纳入的被试数变化，每一步的排除理由与人数。
- **敏感性分析结果**：不同预处理、剔除阈值与模型下结论是否稳定。这是判断结论稳健性的核心产出。
- **偏离预注册的清单**：所有事后改动及理由。

输出的量是**关于分析本身的可信度评估**。它不产生新的神经科学结论，但决定已有结论能被写到什么强度。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 质量指标与阈值 | 决定哪些数据进入分析 | 阈值事后调整 |
| 剔除策略（整段/试次/通道/被试） | 决定样本构成 | 与条件相关的剔除制造效应 |
| 敏感性分析的维度 | 检验稳健性 | 只做单向敏感性分析 |
| 预注册内容粒度 | 约束分析自由度 | 只写假说不写流程 |
| 报告规范遵循程度 | 决定可评估性 | 省略预处理细节与效应量 |

## 前提假设

1. **质量可测量假设**：所选指标确实反映数据质量而非任务效应。以信号幅度作为质量指标时，强的任务效应容易被误判为"好数据"或"坏数据"。
2. **剔除与结果独立假设**：剔除规则不依赖分析结果，也不与实验条件系统相关。不成立时，质控步骤本身在制造结论。
3. **缺失随机假设**：被剔除的数据是随机的，而不是系统性偏向某一条件或某一类被试。临床与儿童样本中这一假设尤其容易失效，因为头动与配合度本身与组别相关。
4. **结论稳健假设**：在合理的分析分支中，结论方向保持一致。若结论只在某一条分支上成立，它应被报告为分支特异的结果。
5. **报告完整假设**：报告包含了所有已做过的分析，或至少说明哪些是探索性的。选择性报告会使读者高估证据强度。

假设不成立时结果为何失去意义：统计仍然可以显著、图仍然可以漂亮，但结论既不能被他人在新数据上重复，也不能被评审者评估。此时它不是一个"较弱"的结论，而是一个**无法判断强度的结论**——这是质控段落存在的全部理由。

## 适用场景

- 所有数据分析项目，从单被试预实验到大样本多中心研究。
- 多中心或跨设备汇总：设备与流程差异必须被量化并纳入模型。
- 公开数据再分析：需要重建原流程并检验其对结论的影响。
- 团队协作项目：流程固定与共享是协作的前提（见 [[分析一致性原则]]）。

## 不适用场景

- **极端小样本的探索性预实验**：此时追求完备的质控报告不现实，但结论也不应被当作证据使用。
- **以现象本身为目标的个案研究**：质控仍然需要，但群体层面的纳入标准不适用。
- **用敏感性分析替代设计**：设计缺陷无法通过多种分析方案的尝试来弥补。

## 常见误用

- **阈值事后调整**：直到结果显著为止，等同于隐藏的多重比较。
- **剔除与条件相关的被试**：临床组因头动被大量剔除后，剩余样本已不代表目标群体。
- **只报告最终样本，不报告剔除过程**：读者无法评估选择偏差。
- **只做一种预处理并声称稳健**：未做敏感性分析。
- **预注册形式化**：事后改动不报告，或把探索性分析写成确证性分析。
- **把计算可重复当作结果可重复**：同一数据跑出同样数值，不代表结论在新数据上成立。
