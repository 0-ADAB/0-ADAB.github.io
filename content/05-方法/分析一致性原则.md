# 分析一致性原则

> 一致性原则指的是：在同一个项目内，**分析方法、控制变量与可视化规范在全部被试、全部条件、全部分析阶段上保持同一套定义**；因为只有在定义不变的前提下，量之间才可比，差异才可解释。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 项目级，覆盖从单通道到全脑的全部输出 |
| 时间尺度 | 项目级，覆盖从预实验到多轮分析的全过程 |
| 相关模态 | 全部 |
| 相关现象 | 全部 |
| 相关结构 | 不限定 |
| 主要方法 | 流程固定与参数冻结、控制变量的统一处理、可视化与绘图规范 |
| 证据类型 | 一致性证据的基础：不一致的流程使任何组间或条件间比较失去参照 |

## 输入数据要求

- **一份写下来的流程定义**：预处理与统计的全部参数、顺序与判断依据，先于结果固定下来。
- **跨单元一致的元数据**：被试、条件、session、设备与操作者的信息结构统一，否则无法检查一致性是否被违反。
- **版本与环境记录**：工具与依赖的变化会被误读为数据变化。
- **变更日志**：任何偏离既定流程的改动、时间与理由。这是唯一能让人区分"流程"与"临时决定"的东西。

## 原理

一致性原则要解决的是一类特定错误：**把流程差异读成现象差异**。

1. **可比性来自同一把尺子**。两个数值只有在用同一定义、同一参数、同一单位产生时才能相减。若被试 A 用了某种滤波、被试 B 用了另一种，两者的"幅值差异"里必然包含流程差异，而流程差异的量级常常与目标效应同阶。
2. **分析自由度是项目级问题**。单个被试内部的参数选择看起来无害，但当它随数据或结果变化时（"这个被试数据差，换个参数"），它就在条件之间引入了系统差异，见 [[质控与可重复性]] 中的多重分析路径。
3. **控制变量必须从头贯穿到尾**。年龄、性别、头动、用药、配合度、采集时间等变量若只在某一环节被处理，其影响会从其它环节进入结论。控制变量的处理方式（匹配、协变量、分层、排除）必须在设计、分析、报告三个阶段使用同一套定义。
4. **可视化是分析的一部分，不是包装**。图上的坐标范围、色标范围、平滑与插值、条件顺序、个体数据的呈现方式，都会改变读者对效应的感知。不同图使用不同尺度，等于隐性地改变了结论的强度。

## 输出结果

- **一套可被复用的流程资产**：脚本、参数文件、可视化模板。它们是项目可重复性的载体而非附属品。
- **一份逐单元一致的分析记录**：任何被试、条件、时间点的数值都能追溯到同一套定义。
- **一组可并置的图**：坐标、色标、单位、条件顺序一致，可以直接比较而不需要读者自行换算。

输出的不是新的神经科学结论，而是**结论的可比性条件**。一致性本身不提高效应量，它只是让效应量有意义。

## 关键参数

| 参数 | 一致性要求 | 违反的后果 |
| --- | --- | --- |
| 预处理参数（滤波、参考、分段） | 全部被试、全部条件同一套 | 组间差异含流程差异 |
| 分析单元定义（ROI、图谱、节点） | 全项目统一，跨被试使用同一映射 | 结果不可跨被试合并 |
| 控制变量处理 | 设计、分析、报告三阶段同一套 | 差异无法归因 |
| 图形尺寸与坐标范围 | 同轴类图表统一 | 视觉对比失真 |
| 色标与配色 | 同一指标同一色标范围 | 颜色暗示的强弱与数值脱节 |
| 个体数据呈现 | 统一展示点位或分布 | 均值掩盖异质性 |

## 前提假设

1. **目标量在同一维度上可比假设**：保持一致的量确实是同一物理或统计量。若两个条件测的量名义相同、定义不同（例如两种参考下的幅值），一致性并不产生可比性。
2. **一致性不等于正确性假设**：一致地使用错误流程，只会一致地错。因此一致性必须与 [[质控与可重复性]] 的敏感性分析配合，而不是替代它。
3. **控制变量可识别假设**：被控制的变量确实与结果相关且可被测量。未被测量的混淆变量不会因"已控制若干变量"而消失。
4. **可视化不改变数据假设**：绘图参数只影响呈现。一旦作图涉及平滑、插值、阈值化或标准化，它就已经是分析步骤，必须与统计口径一致。
5. **偏离可被发现假设**：变更日志与版本记录足以识别流程偏离。缺少记录时，"一致"只是一个声称。

假设不成立时结果为何失去意义：若一致性只是名义上的（定义不同、尺度不同、控制变量只处理了一部分），那么"条件差异"可能完全由流程或尺度差异构成，而读者无从分辨。此时统计仍然显著、图仍然整洁，但差异的解释权已经交给了未声明的自由度。

## 适用场景

- 项目内所有需要跨被试、跨条件、跨 session 比较的分析。
- 组间比较研究：流程一致性是组间差异可归因的必要条件。
- 纵向与追踪研究：跨时间点的一致性直接决定"变化"是否真实。
- 论文、预注册与补充材料的撰写：一套定义贯穿正文与补充材料。

## 不适用场景

- **探索性方法比较**：此时有意使用不同流程来比较其影响，但必须明确标注为方法比较而非结果分析。
- **个体化处理的必要场景**：某些个体需要不同的伪迹处理。此时一致性让位于有效性，但必须记录并做敏感性分析。
- **不同模态之间**：跨模态的流程不可能相同，一致性要求的是同一层级内一致，而不是跨模态统一（见 [[多模态融合]]）。
- **把一致性当作拒绝改进的理由**：发现流程缺陷后仍坚持一致，是把原则误用为惰性。

## 常见误用

- **对被试"单独调参"**：为让每个被试的结果看起来合理而逐个调整参数，等价于在每个被试上做一次搜索。
- **控制变量只在统计阶段出现**：设计与采集阶段未记录，事后无法真正控制。
- **同一指标多套色标**：不同图使用不同色标范围，视觉上放大或压缩效应。
- **坐标轴范围随结果调整**：使不同条件看起来效应量相近。
