# 事件相关分析

> 事件相关分析把连续电生理记录按事件切段、对齐并跨试次平均，得到与事件有稳定时间关系的电压或磁场波形；它的全部解释力来自"时间锁定"这一假设。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 传感器/电极阵列，源层级需借助 [[源定位]] |
| 时间尺度 | 毫秒 |
| 相关模态 | 电生理 |
| 相关现象 | 感知、注意、语言、决策与奖赏、运动控制 |
| 相关结构 | 全脑（头皮/传感器分布），解释到结构需额外证据 |
| 主要方法 | 分段、基线校正、试次平均、成分幅值与潜伏期测量、差异波 |
| 证据类型 | 时间动态证据，主要支持"何时"，弱支持"何处" |

## 输入数据要求

- **连续记录与精确事件标记**：刺激与反应的标记必须与采样时钟同一基准，抖动与延迟需被估计。
- **足够的试次数**：平均降噪的收益随试次数增加而递减；试次过少时成分估计不稳定，试次过多则单次记录过长。
- **稳定的被试状态**：随时间漂移的注意、疲劳或电极阻抗变化会使"早试次"与"晚试次"不属于同一分布。
- **行为数据**：正确率与反应时，用于判断条件差异是否伴随任务表现差异。

## 原理

1. **分解假设**：每个试次的记录被视为"事件相关成分 + 背景活动 + 噪声"的叠加。
2. **时间锁定假设**：事件相关成分在每次呈现后出现在相同的时间位置，其相位跨试次一致。
3. **非锁定成分抵消假设**：背景活动与事件无固定相位关系，跨试次平均后趋近于零，其残差幅度随试次数的平方根下降。
4. **线性叠加假设**：成分之间以及成分与背景之间可加，重叠成分不互相改变形状。

差异波（条件 A 减条件 B）进一步依赖"除目标操控外，两条件的时间锁定成分结构相同"这一假设。若两条件在刺激物理属性、难度或反应要求上不同，差异波同时含目标效应与非目标效应。

## 输出结果

- **波形与地形图**：时间 × 通道的幅值，以及在各时间点上的空间分布。
- **成分指标**：以峰幅值、峰潜伏期、或预先定义时间窗内的平均幅值量化。
- **差异波与其统计量**：说明条件间在哪些时间-通道单元上有差异（统计部分见 [[统计推断与多重比较]]）。

输出的量是**电压或磁场随时间的幅值**，不是认知过程本身。把幅值翻译成"注意资源""冲突量""语义整合难度"等构念，依赖额外的效度论证与操控检验。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 分段窗 | 决定包含哪些成分 | 窗太短截断慢成分，太长引入漂移 |
| 基线窗 | 定义零点 | 与事件重叠时基线被污染 |
| 滤波 | 决定波形形态 | 强滤波改变峰幅值与潜伏期 |
| 成分时间窗 | 量化哪个成分 | 窗由数据决定则等于事后选择 |
| 峰测量 vs 窗平均 | 幅值估计方式 | 峰测量对噪声更敏感，窗平均对重叠成分更敏感 |
| 试次纳入规则 | 决定哪些试次进入平均 | 按反应正确性筛选会改变条件构成 |

## 前提假设

1. **时间锁定假设**：目标成分与事件有固定相位关系。若成分是诱发式的、时间可变（如振荡的部分相位重置），平均会使其相互抵消，得到"没有效应"的假象。这是事件相关分析最核心的限制。
2. **线性叠加假设**：成分可加。若相邻成分在时间上重叠，峰幅值与潜伏期的变化无法分离——一个成分的幅值变化可以伪装成另一个成分的潜伏期变化。
3. **试次可交换假设**：构成同一平均的所有试次来自同一分布。若条件内试次存在时间趋势（学习、疲劳），平均波形是混合体。
4. **测量指向假设**：所选时间窗与通道确实测量了目标成分。不成立时，统计显著只是某个时空单元上存在差异，与构念无关。

假设不成立时结果为何失去意义：波形仍然存在、统计仍然可以显著，但"显著的时间-通道单元"不再对应任何可命名的成分，条件差异也无法归因于目标操控。此时结果只能描述为"在某时段某区域存在条件差异"，不能命名为心理过程。

## 适用场景

- 事件在时间上离散、可精确标记的任务（刺激呈现、反应、反馈）。
- 需要毫秒级时间信息、且对空间精度要求不高的研究。
- 时间锁定成分本身是研究对象的场景：信号感知与传递、注意的早期调制、冲突加工、错误监测。
- 与行为做逐试次或跨被试关联，用于建立时间与行为指标的对应。

## 不适用场景

- **非相位锁定的活动**：自发振荡、跨区域同步的幅度调制，它们在试次间相位随机，平均后会消失（见 [[时频分析]]）。
- **事件时间不可控**：自然观看、自由对话、连续运动，事件边界由分析者主观界定。
- **需要精确定位**：头皮分布受容积传导影响，源层级结论需 [[源定位]] 支持，且源定位本身的误差大于头皮效应范围。
- **单次或极少试次场景**：无法通过平均降噪，成分估计的信噪比不足以支持推断。

## 常见误用

- **把平均后的波形当作单试次活动**：平均波形可能不代表任何单个试次，尤其在成分发源于相位重置时。
- **用数据决定成分时间窗后再统计**：时间窗与通道由同一数据选出，构成循环分析，必须用独立数据或校正后报告。
- **以波形成分命名代替机制解释**：给某个峰起一个功能名字，然后把这个名字当作已确立的机制。
- **忽略基线差异**：条件间基线本身不同时，幅值差异可能是基线差异的延续。
- **用显著的时间窗覆盖全时段搜索**：未经校正的多点比较会把噪声选成效应（见 [[统计推断与多重比较]]）。
- **把差异波的显著解释为"两个成分"的差异**：差异波可能来自多个成分的重叠变化，也可能是信噪比差异。
