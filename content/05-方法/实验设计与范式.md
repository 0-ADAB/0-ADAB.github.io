# 实验设计与范式

> 实验设计是**在数据产生之前**决定"最终能得出什么结论"的一组选择；分析只能在设计允许的范围内补救，无法创造设计没有产生的信息。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 不限定，由所选测量手段决定 |
| 时间尺度 | 秒（单试次）到天（跨 session） |
| 相关模态 | 全部 |
| 相关现象 | 全部 |
| 相关结构 | 不限定 |
| 主要方法 | 条件操控与对照、被试内/间分配、随机化与平衡、功效分析、预注册 |
| 证据类型 | 决定可支持的推断范围；主要影响一致性证据与因果证据 |

## 输入数据要求

设计不消耗数据，它规定数据必须长什么样才能回答目标问题。

- 明确的变量清单：自变量（被试内操控或被试间分组）、因变量（可量化的测量指标）、控制变量（必须匹配或纳入模型的量）。
- 可操作化定义：目标构念通过什么刺激、任务或指令被操控；这一步的效度无法由统计补救。
- 样本预算：被试数、条件数、每条件试次数。三者共同决定统计功效与可用的模型复杂度。
- 时序精度：刺激呈现系统与记录系统之间的同步方式（触发标记、光电校验等），决定了事件锁定是否成立。

## 原理

设计的核心动作是**比较**，而比较要成立，必须让条件之间"除了操控以外尽量相同"。

1. **对照**：效应被定义为差异。没有合适的对照，观测值本身没有参照点。
2. **被试内与被试间**：被试内设计把稳定的个体差异从误差项中消去，但引入顺序、疲劳与习惯化等时间相关混淆；被试间设计避免这些混淆，但把个体差异全部留在误差项里。
3. **随机化与平衡**：随机分配使已知与未知的混淆变量在条件之间近似均等分布；拉丁方等平衡方案使顺序效应在各条件间可抵消。
4. **混淆控制**：混淆是"与自变量共同变化、且自身影响因变量"的第三个量。它无法通过增加样本量消除。
5. **预注册**：在见数据之前固定假说、主要指标、分析流程与停试规则，使"探索"与"确证"可被区分。

## 输出结果

设计产出的是一个**结构化的数据表**：维度为被试 × 条件 × 试次，附带事件时间、行为反应与被试信息。它同时产出一组"被允许的比较"。

这组允许的比较是后续一切的边界：[[统计推断与多重比较]] 只能在这组比较上定义检验族，[[解码与机器学习]] 只能在这组结构上定义交叉验证单元，[[因果干预证据]] 的强度完全取决于操控与随机化是否成立。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 被试数 | 决定组间比较的精度 | 事后按显著性决定是否加被试 |
| 每条件试次数 | 决定单条件估计的稳定性 | 试次过少导致效应被噪声掩盖 |
| 被试内/间 | 决定误差项结构 | 与被试内混淆（学习、顺序）未平衡 |
| 随机化方式 | 切断混淆与条件的关联 | 伪随机导致条件分布不均 |
| 对照类型 | 定义效应的参照 | 缺少主动对照，差异含任务难度 |

## 前提假设

这一节是整页的核心：设计的所有优点都建立在假设之上，假设不成立时，即便统计显著，结果也失去意义。

1. **可操作化假设**：构念能被所选的刺激或任务有效操控。不成立时，条件差异与该构念无关，无论 p 值多小。
2. **随机化有效假设**：随机分配确实切断了混淆变量与条件的关联。伪随机、按顺序分配或有偏剔除都会破坏它，此时观测到的差异可能是混淆造成的差异。
3. **测量稳定性假设**：重复测量不会系统性改变被测量的过程本身。习惯化、策略切换、疲劳会使"同一条件"在不同时间点不是同一个量。
4. **单位独立假设**：独立抽样单位是被试，而不是试次。把试次当独立样本会低估误差项，使显著性被系统性高估；这是本节最常被违反的假设。
5. **时间锁定假设**：事件标记与生理事件在时间上对齐。标记延迟或呈现抖动不成立时，[[事件相关分析]] 与 [[时频分析]] 的锁定前提同时失效。

## 适用场景

- 需要对条件差异做方向性解释的操控实验。
- 需要在个体内控制稳定特质的比较（被试内设计）。
- 需要跨被试、跨中心汇总的群体研究，此时统一范式与统一流程是前提（见 [[分析一致性原则]]）。

## 不适用场景

- **自变量不可操控**：性别、年龄、病程、人格特质等只能做观察或相关设计，不能产出因果结论。
- **样本极少的群体**：罕见临床群体或深部记录场景下功效常常不足，此时阴性结果不构成"无效应"的证据。
- **需要长时间自然行为**：高度约束的实验室范式会削去目标现象本身的生态特征，生态效度与内部效度在此直接冲突。

## 常见误用

- **以试次为样本单位**：把上千个试次当作上千个独立观测，人为放大自由度。
- **条件缺少主动对照**：把"任务 vs 静息"的差异解释为某认知成分，而差异主要来自唤醒、眼动或难度。
- **事后选择条件或指标**：在多个因变量中挑显著的报告，等同于未校正的多重比较。
- **以显著性代替功效论证**：先做实验再论功效，或把不显著当作等价性证据。
- **预注册形式化**：只写假说不写主要指标、预处理与排除规则，分析自由度仍然敞开（见 [[质控与可重复性]]）。
- **顺序效应当作效应**：被试内设计未做平衡，条件差异与时间趋势混在一起。

## 实现工具

实现工具按功能类别区分，具体条目见 [[分析平台]]。

| 类别 | 常见代表 | 用途 |
| --- | --- | --- |
| 刺激呈现与实验控制 | PsychoPy、Psychtoolbox、OpenSesame、E-Prime | 生成条件序列、随机化与平衡、记录反应 |
| 时序与同步校验 | 光电二极管、并行/串口触发、专用同步盒 | 保证事件标记与生理记录对齐 |
| 行为数据整理 | 通用脚本与表格工具 | 试次级数据、正确率与反应时计算 |
| 功效分析 | R 生态与 Python 生态中的功效分析包 | 事前估计被试数与试次数 |
| 预注册与版本管理 | 通用预注册模板、Git | 固定假说与分析流程，保留变更记录 |
| 数据组织 | BIDS 及其衍生规范 | 使范式描述可被他人复用 |
