# 源定位

> 源定位是从头皮电位或头外磁场反推脑内电流源的位置与强度；这是一个**欠定逆问题**，解不唯一，任何结果都是"在所选约束下的一个解"，而不是唯一真值。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 脑区到网络；实际可达精度远低于体素级影像 |
| 时间尺度 | 毫秒（这是该方法相对影像的核心优势） |
| 相关模态 | 电生理 |
| 相关现象 | 感知、注意、语言、运动控制、临床与病理 |
| 相关结构 | [[皮层分区]]、[[皮层下结构]]、[[大尺度网络]] |
| 主要方法 | 正演头模型、源模型（偶极子/分布式）、beamformer、最小范数类、稀疏与贝叶斯方法 |
| 证据类型 | 功能关联证据与时间动态证据；单独使用时空间结论的因果与结构含义很弱 |

## 输入数据要求

- **高质量的头皮记录**：通道数与覆盖、参考方案、信噪比共同决定定位下限。
- **传感器几何信息**：电极坐标或 MEG 传感器位置，误差直接进入正演模型。
- **解剖信息**：结构像用于构建头模型与皮层表面；缺少个体解剖时需用模板，个体差异无法被吸收。
- **协方差估计**：多数分布式与 beamformer 方法需要从数据估计噪声或数据协方差，估计质量取决于数据长度与伪迹控制。
- **事件相关或时频分解后的数据**：源定位通常在分段平均或单试次分解之后进行，因此继承上游的全部假设。

## 原理

1. **正演模型（forward model）**：给定源的候选位置与朝向，计算它在各传感器上产生的场。这一步由头模型（球模型、边界元、有限元）、导电率假设与源几何决定。
2. **逆问题（inverse problem）**：正演算子是"源 → 传感器"的映射，其反演不唯一——大量不同的源配置可产生几乎相同的头皮场。这一点是数学性质，不因算法改进而消失。
3. **约束的选择**：不同方法用不同约束挑出一个解。偶极子拟合约束源数量少；最小范数类方法约束总能量最小；beamformer 约束对目标位置以外活动的抑制；稀疏与贝叶斯方法约束源的先验分布。约束不同，解不同。
4. **深度偏倚（depth bias）**：深部源在头皮上的场更弥散，最小能量类方法倾向于把解推到浅层；beamformer 类方法对深部源的输出功率也往往被压低。深度加权是常用补偿手段，但会改变解的性质。

## 输出结果

- **偶极子解**：位置、朝向与时间序列。它给出紧凑的定位，但"少数几个源"本身是强假设。
- **分布式解**：皮层或体素网格上的电流强度分布图，可带时间过程。
- **时间序列**：源层级的波形或功率，可用于源层级连接分析（见 [[功能连接]]）。
- **定位精度指标（应当报告但常被省略）**：空间扩展、解的稳定性、对参数变化的敏感性、不同方法的解是否一致。

输出是**在特定正演与源模型下的电流分布估计**。它不等于"激活的脑区"，也不等于解剖实体；跨研究比较源位置时需要先比较头模型与方法。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 头模型类型 | 决定正演精度 | 用球模型替代个体解剖会带来系统偏移 |
| 导电率与组织分层 | 影响场分布 | 参数不确定直接传播到位置误差 |
| 源空间（皮层/体素/全脑） | 决定解的范围 | 源空间不含的结构当然无法被定位 |
| 深度加权 | 补偿深度偏倚 | 过度加权造成浅层伪源 |
| 噪声/数据协方差 | beamformer 与自适应方法的核心输入 | 估计窗口含事件相关活动会造成自抵消 |
| 正则化强度 | 控制解的空间平滑度 | 太大则弥散，太小则噪声被当作多个源 |

## 前提假设

1. **准静态假设**：在所关心频率范围内，头部组织中的电磁传播可视为瞬时。这在常规频段成立，但超出范围后需另行处理。
2. **正演模型正确性假设**：头模型反映了真实头部几何与导电性质。不成立时，位置系统偏移，且偏移方向与个体解剖有关，跨被试汇总会把系统偏移平均成弥散的"分布"。
3. **源模型充分性假设**：真实源能被所选源模型表达（例如分布式解确实能表示实际的空间扩展）。
4. **协方差代表噪声假设**：用数据估计的协方差反映噪声而非信号。若估计窗口含目标活动，自适应方法会部分抑制目标源，导致"该区域无活动"的假阴性，也称自抵消。
5. **线性叠加假设**：不同源的场线性相加，且源的朝向在分析窗内稳定。
6. **配准与头位稳定假设**：传感器到解剖的映射准确，且记录期间没有显著头动。

假设不成立时结果为何失去意义：源定位图仍然产生、仍然可以有显著"激活"，但该图是头模型误差、深度加权与协方差估计的共同产物。此时它可以作为时间信息的载体使用，却不能作为空间结论的证据——尤其不能用于支持"某脑区参与某功能"这类断言。

## 适用场景

- 需要毫秒级时间与脑内空间信息的组合：事件相关波形或时频指标的源层级解释。
- 与影像结果交叉检验：把电生理的时间信息与影像的空间信息对照，用于跨模态一致性判断（见 [[跨模态一致性]]）。
- 源层级的时间序列分析：连接、耦合与格兰杰类分析（须继承源定位的不确定性，见 [[有效连接与因果建模]]）。
- 临床电生理中的定位需求，此时通常结合多种独立信息而非单一算法输出。

## 不适用场景

- **需要精确解剖定位**：源定位的空间分辨率不足以支持核团或皮层分层级别的断言。
- **深部源**：深部结构与多个浅层源的场高度相似，深度偏倚与低信噪比同时存在。
- **缺少个体解剖或头位信息**：此时误差很可能大于效应尺度。
- **仅凭头皮数据推断方向性**：源层级的方向性结论叠加在源定位不确定性之上，误差被放大。
- **结果用于因果断言**：源定位是关联性推断，不提供操控信息。

## 常见误用

- **把源定位图等同于 fMRI 激活图**：两者物理量、分辨率与推断逻辑完全不同，直接叠加比较容易产生假一致或假矛盾。
- **未报告深度加权与正则化选择**：读者无法判断弥散结果是生理现象还是参数结果。
- **用同一段数据既估协方差又做检验**：自适应方法的噪声估计与统计检验共用数据，构成循环分析。
- **把"没有定位出源"读作"该区域未参与"**：多为灵敏度不足或自抵消，而非否定性证据。
- **忽略协方差窗口中的事件活动**：把自抵消造成的低功率当作"抑制"。
