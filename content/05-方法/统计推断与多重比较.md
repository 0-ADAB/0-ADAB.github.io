# 统计推断与多重比较

> 统计推断是在明确的零假设下判断观测模式是否超出抽样波动的范围；脑数据的检验数量常常是成千上万，**校正不是可选步骤，而是结论成立的前提**。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 体素/通道到被试群体 |
| 时间尺度 | 不限定；跨被试比较通常以秒到天的数据为单位 |
| 相关模态 | 全部 |
| 相关现象 | 全部 |
| 相关结构 | 全部 |
| 主要方法 | 参数与非参数检验、置换检验、聚类与 TFCE、FWE/FDR 校正、效应量与区间估计、贝叶斯因子 |
| 证据类型 | 决定证据的强度等级；本身不产生证据类型，只决定证据是否可被采信 |

## 输入数据要求

- **预先定义的检验族**：要校正，先要说明"这一族检验包含哪些"。事后扩大或缩小检验族是常见问题。
- **符合检验假设的数据结构**：独立性、分布形态、方差齐性、样本量的组间平衡。
- **设计对应的交换性**：置换检验要求数据在零假设下可交换。被试间设计与被试内设计的交换方案不同，配对结构必须体现在置换方案中。
- **效应量信息**：均值差、标准化效应量、置信区间；仅有 p 值无法说明效应大小。

## 原理

1. **零假设显著性检验（null hypothesis significance testing）**：假设无效应，计算观测到当前或更极端数据的概率。它不给出"效应存在的概率"，也不度量效应大小。
2. **参数检验**：依赖分布假设（如 t 检验的正态性与独立性）。样本量足够时对轻度偏离稳健，但被试间方差不等、极端值或层级结构未被建模时失效。
3. **置换检验（permutation test）**：通过重新分配条件标签生成零分布。它对分布形态的要求更弱，但要求数据在零假设下可交换；被试内与被试间设计的交换方案不同，方案错误会给出错误 p 值。
4. **聚类与 TFCE（threshold-free cluster enhancement）**：利用空间或时间上的相关结构，把"离散的单点检验"变成"区域级检验"。它们显著提高灵敏度，代价是结论的空间精度降低为区域级，且结果依赖初始阈值或邻域定义。
5. **错误率控制**：FWE（family-wise error rate）控制"家族中至少一个假阳性"的概率，适合少量、结论性的比较；FDR（false discovery rate）控制被声明为阳性的结果中假阳性的期望比例，适合大规模筛查，允许更多假阳性但给出比例预期。
6. **贝叶斯因子（Bayes factor）**：比较两个假设下数据的相对概率，可对"支持零假设"给出量化陈述，其结果依赖先验设定，且与 p 值回答的是不同问题。
7. **效应量与区间估计**：报告效应量与置信区间使结果具备可比较性；显著性只说明"能否与零区分"，不说明"有多大、是否重要"。

## 输出结果

- **p 值、校正后 p 值或 FWE/FDR 阈值下的显著结果**。
- **效应量与置信区间**：用于判断结果的实用意义与精度。
- **聚类或区域级结果**：峰值位置、团块范围、统计量极值。团块范围受平滑与阈值影响，不应被读作"激活的解剖范围"。
- **检验族与校正方式的明确说明**：没有这一说明，显著结果无法被评估。

输出是**在特定零假设与检验族下的概率陈述**。它不直接说明效应是否真实存在，也不说明结果的机制含义。

## 关键参数

| 参数 | 作用 | 常见风险 |
| --- | --- | --- |
| 检验族定义 | 决定校正的分母 | 事后调整族范围 |
| 单尾/双尾 | 决定零假设方向 | 看数据后改为单尾 |
| 置换方案 | 决定零分布正确性 | 未反映配对或被试内结构 |
| 置换次数 | 决定 p 值分辨率 | 次数过少使最小 p 值受限 |
| 聚类定义阈值 | 决定团块形成 | 阈值改变结果范围与显著性 |
| 邻域定义 | 决定空间或时间连通 | 邻域过大合并无关区域 |

## 前提假设

1. **零假设正确设定假设**：零假设对应"无效应"或"无差异"，且与设计匹配。零假设设定错误（例如忽略基线差异）使检验失去意义。
2. **可交换性假设（置换类方法）**：在零假设下，各单元的数据可以互换。被试内设计与被试间设计的交换限制不同；违反时会系统性低估或高估 p 值。
3. **独立性假设**：检验单元之间相互独立，或依赖结构已被建模。脑数据在空间与时间上高度相关，忽略这一点会大幅高估有效自由度。
4. **校正与探索范围一致假设**：校正覆盖了实际做过的全部比较，包括未报告的比较。只校正已报告的比较等于隐藏多重性。
5. **停试独立假设**：样本量不依赖中间结果。若边收集边检验、达到显著即停止，实际错误率远高于名义水平。

假设不成立时结果为何失去意义：p 值仍然可以小于阈值，但该数值不再具有它声称的含义。最常见的情形是"在大量未校正的比较中挑出显著者"，此时显著结果更可能是抽样波动的极值，而不是效应。这类结果即使重复实验也往往不复现。

## 适用场景

- 组间、条件间与个体差异比较，需要控制错误率时。
- 空间或时间上高度相关的数据，需要利用相关结构提升灵敏度（聚类与 TFCE）。
- 需要在多个被试、多个中心汇总时的层级模型。

## 不适用场景

- **检验族无法定义**：探索性全脑搜索在没有明确族定义时，无法给出有意义的校正结论。
- **数据依赖结构未知或未建模**：此时任何校正都建立在错误的自由度上。
- **把统计显著当作机制或因果结论**：统计从不提供机制。

## 常见误用

- **未校正的多重比较**：报告数十个显著单元中的若干，是最常见也最严重的问题。
- **事后定义检验族或时间窗**：在图上找到显著区域再定义分析范围。
- **平滑与聚类阈值联合调参至显著**：参数选择本身成为未校正搜索的一部分。
- **把 FDR 当作 FWE**：FDR 允许一定比例的假阳性，其结论强度低于 FWE 校正。
- **把不显著读作无效应**：缺少功效分析与等价性检验的支持。
- **把 p 值当作效应大小或证据概率**：p 值不回答"效应有多大"或"结论为真的概率"。
- **报告团块范围作为解剖范围**：团块范围由阈值与平滑决定，不是解剖边界。
