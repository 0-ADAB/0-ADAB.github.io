# 神经递质系统

> 神经递质系统指以特定递质为标志、由少数来源核团向全脑弥散投射的功能系统；这类系统在解剖上高度重叠、在时间上缓慢调节，因此它的"位置"与"时刻"都比脑区水平的观测更难界定。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 从分子（受体）到全脑（弥散投射） |
| 时间尺度 | 神经调质作用在百毫秒—分钟级；受体密度变化可跨天与发育 |
| 相关模态 | [[生理与神经化学]]、[[分子与遗传]]、[[血流与代谢成像]] |
| 相关现象 | [[决策与奖赏]]、[[情绪与应激]]、[[学习与记忆]]、[[注意]]、[[意识与睡眠]]、[[临床与病理]] |
| 相关结构 | [[皮层下结构]]（来源核团）、[[大尺度网络]]（共同靶区） |
| 主要方法 | PET/SPECT 受体成像、磁共振波谱、药理挑战、电化学检测、遗传编码探针 |
| 证据类型 | [[因果干预证据]]（药理操作）、[[结构证据]]（通路）、[[生理与神经化学]] 的测量证据 |

## 解剖边界与划分标准

递质系统的划分依据不是解剖边界，而是**递质的化学身份与来源核团**。这带来与皮层分区完全不同的划分问题：

| 系统 | 主要来源核团 | 主要投射去向 | 受体家族（举例） |
| --- | --- | --- | --- |
| 多巴胺（dopamine, DA） | 中脑黑质致密部、腹侧被盖区 | 纹状体、额叶皮层、边缘系统 | D1 样、D2 样受体家族 |
| 乙酰胆碱（acetylcholine, ACh） | 基底前脑核群、脑干被盖核团 | 全皮层、海马、丘脑 | 烟碱型、毒蕈碱型受体 |
| 去甲肾上腺素（noradrenaline/norepinephrine, NE） | 脑干蓝斑 | 全脑弥散投射 | α 与 β 肾上腺素受体 |
| 5-羟色胺（serotonin, 5-HT） | 脑干中缝核群 | 全脑弥散投射 | 多类 5-HT 受体亚型 |
| γ-氨基丁酸（gamma-aminobutyric acid, GABA） | 局部中间神经元为主，部分长投射通路 | 局部环路、部分输出通路 | GABAA、GABAB |
| 谷氨酸（glutamate） | 皮层与皮层下兴奋性投射神经元 | 全脑 | 离子型与代谢型受体 |

需要明确的三点：

1. **递质身份不能唯一确定细胞类型**：同一递质由多群细胞释放，作用取决于受体亚型、靶细胞与位置（突触、突触旁、突触外）。
2. **容积传递（volume transmission）打破点对点模型**：调质可扩散到突触外作用于邻近细胞，"一个突触一个信号"的框架在这里不适用。
3. **来源核团与靶区分属不同尺度**：观测来源核团（毫米）与观测受体密度（体素级平均）不是同一件事。

## 主要连接

- **多巴胺通路**：黑质纹状体通路（运动与习惯相关环路）、中脑皮层通路与中脑边缘通路（前额叶与边缘结构）。
- **胆碱能通路**：基底前脑向皮层与海马的投射，与皮层兴奋性和注意相关状态有关；脑干被盖核团参与丘脑与皮层的调节。
- **去甲肾上腺素与 5-羟色胺通路**：从脑干核团向全脑的上行投射，纤维密度高且分叉广，因此单个核团能同时影响多个系统。
- **GABA 与谷氨酸**：以局部环路为主，构成兴奋—抑制平衡；因此它们不适合用"某条投射通路"来描述，而更适合用局部回路或全脑梯度描述。
- 递质系统与 [[大尺度网络]] 的关系是调节关系：递质变化可以改变区域间耦合强度，而不只是改变单区活动水平。

## 参与的认知过程

- **多巴胺**：奖赏相关的学习信号、动机与努力分配、运动启动。常被简化成"快乐物质"，这类表述混淆了奖赏学习、动机与主观愉悦。
- **乙酰胆碱**：注意与知觉加工的调节、皮层状态与学习相关的可塑性。
- **去甲肾上腺素**：觉醒、警觉、应激反应与自主神经调节。
- **5-羟色胺**：情绪与行为状态的调节、昼夜与节律相关过程；受体亚型众多使"升高/降低 5-羟色胺"这类说法过于粗糙。
- **GABA / 谷氨酸**：兴奋—抑制平衡、振荡的产生与终止、信息的选择性传递。它们参与几乎所有认知过程，因此不适合做现象层面的对应。

## 可用观测手段

| 手段 | 测什么 | 分辨率限制 |
| --- | --- | --- |
| PET / SPECT 受体与转运体成像 | 受体密度、转运体可用性 | 空间分辨率低（体素级平均）、扫描时间长、需要放射性配体、个体内平均 |
| 药理挑战 + 成像 | 递质释放的间接变化（配体置换范式） | 只能给出间接推断；药物特异性与剂量效应是额外假设 |
| 磁共振波谱（magnetic resonance spectroscopy, MRS） | 代谢物浓度（如 GABA、谷氨酸复合物） | 组织水平平均，不能区分细胞来源与突触内外，时间分辨为分钟级 |
| 微透析 | 细胞外递质浓度 | 有创，仅动物或临床极少数情形，空间取样有限 |
| 电化学记录 | 快速递质浓度变化 | 有创、主要限于动物，需处理电极漂移与物种特异性 |
| 遗传编码探针 + 光学记录 | 特定递质的动态变化 | 需基因操作，主要限于动物；探针本身有时间常数与亲和力限制 |
| 药理与遗传操作 | 系统的因果作用 | 全身给药非特异；局部操作可能激活多条通路 |

## 分析方法

- **受体密度与释放量必须区分**：PET 结合电位主要反映受体可用性，不直接等于内源递质释放；需要挑战范式或动力学建模才能靠近释放量的推断。
- **MRS 的前提**：体素内组织成分（灰质、白质、脑脊液）比例会影响浓度估计，需要组织校正；谱线拟合模型与基线处理影响结果。
- **药理研究的设计**：剂量、给药途径、时间窗、个体差异（基线水平、遗传多态性）都会改变效应，报告应给出这些参数。
- **递质与行为之间通常是间接链**：药物 → 受体占据 → 环路活动 → 行为。链条越长，可支持的推断越弱。
- **多模态对接**：把受体分布图与功能连接或激活图叠加时，需注意空间配准与尺度不匹配，见 [[多模态融合]] 与 [[跨模态一致性]]。

## 物种差异与命名争议

- **解剖命名的历史差异**：同一核团在不同文献中有多个名称与缩写；部分结构（如基底前脑核群）的划分口径在各图谱中不统一。
- **物种差异显著**：啮齿类与灵长类在皮层胆碱能投射密度、多巴胺靶区比例上差异明显，投射拓扑相似不等于功能等价。
- **受体命名体系多样**：同一受体的药理学命名、基因命名与亚型编号可能并行使用，检索与对照需要显式说明采用哪一套。
- **"系统"一词的双重用法**：既可以指解剖上的一群核团与投射，也可以指一个功能概念（如"奖赏系统"）。两者混用会让研究命题变得不可检验。

## 常见误解

- **把受体密度当递质释放**：成像得到的结合信号反映受体可用性，与瞬时释放量不是同一个量。
- **把血液或脑脊液浓度当脑内突触浓度**：外周指标与中枢突触水平的递质变化之间隔着多层生理过程。
- **把药理效应当成特定递质的功能证明**：药物选择性有限、作用位点广泛，且常通过多条通路起效。
- **用"某递质升高/降低"解释复杂行为**：递质系统是调节性的，方向性表述忽略了受体、靶区与状态的依赖。
- **忽略时间尺度错配**：把分钟级的受体或代谢物测量与毫秒级的电生理主张拼接在一起，需要显式的尺度桥接假设。
- **GABA/谷氨酸的过度功能化**：把兴奋—抑制平衡的指标直接读成"抑制不足导致某症状"，是典型的相关当机制。
