# EEG-64

> 64 导 EEG 指在头皮上放置约 64 个记录电极的常规配置，其位置通常由国际 10-20 系统按等比例间距扩展而来；电极坐标决定了下游的参考选择、插值与源定位能做什么、不能做什么。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 头皮覆盖全脑，通道间距通常为厘米级 |
| 时间尺度 | 毫秒级采样，适合事件相关与时频分析 |
| 相关模态 | [[电生理记录]]；常与 [[行为与眼动]] 同步采集 |
| 相关现象 | [[注意]]、[[语言]]、[[运动控制]]、[[感知]]、[[意识与睡眠]] |
| 相关结构 | [[皮层分区]]（需经源定位才与皮层区建立联系） |
| 主要方法 | [[预处理与伪迹控制]]、[[事件相关分析]]、[[时频分析]]、[[源定位]] |
| 证据类型 | [[时间动态证据]]；通道本身不构成区域证据 |

## 解剖边界与划分标准

电极位置**不是解剖边界**，而是由颅骨标志按比例测量确定的标准点位。这套规则的意义在于让不同实验室的记录位置可比：

| 体系 | 定位间距 | 常用场合 |
| --- | --- | --- |
| 国际 10-20 系统 | 相邻点占颅骨标志间距离的 10% 或 20% | 基础临床与低通道数记录 |
| 10-10 系统 | 在 10-20 点位之间继续按 10% 插值 | 中等通道数（含 64 导）的常规扩展 |
| 10-5 系统 | 进一步加密到 5% 间距 | 高密度记录（百导以上）与精确配准 |

命名规则（方法学约定，与功能无关）：

- 字母表示所在区域：`Fp` 额极、`F` 额、`C` 中央、`P` 顶、`O` 枕、`T` 颞、`A` 耳垂、`M` 乳突。
- 数字表示同区内的序号：**奇数在右半球，偶数在左半球**，数字越大离中线越远。
- `z` 表示中线电极（如 `Fz`、`Cz`、`Pz`、`Oz`）；参考与辅助通道另有命名：耳垂/乳突参考、眼电（electrooculography, EOG）、心电（ECG）、肌电（EMG）。

划分标准带来的三条限制：

1. **位置按比例而非按解剖确定**：头形与颅骨标志的个体差异会导致同一通道名在不同被试下覆盖不同皮层。
2. **覆盖不均**：64 导配置在额、中央、顶、枕、颞的分布并不均匀，颞底、额底与内侧面的覆盖通常最弱。
3. **头皮位置与下方皮层是近似关系**：大脑皮层在头皮上的投影受脑脊液、颅骨与皮层褶皱影响，通道正下方的皮层并非唯一来源。

## 主要连接

这里的"连接"指通道之间的导联与电学关系，它决定了信号如何被定义：

- **单极（参考）导联**：每个电极相对一个共同参考记录电位差。参考点的选择（如中线电极、乳突、耳垂、平均参考）会改变所有通道的波形与地形图；地电极用于降低共模干扰，不参与电位差的定义。
- **双极导联**：相邻电极之间作差，可抑制共模成分、突出局部梯度，但得到的是导联组合而非单点电位。
- **重参考**：离线更换参考是常规操作，但它会改变振幅分布、连接估计与源定位结果，因此必须报告参考方案。
- **容积传导（volume conduction）**：相邻通道看到的皮层源高度重叠，通道之间的相关性天然偏高。任何"通道间连接"结论都要处理这一点。
- **与辅助通道的同步**：EOG、EMG、心电与刺激事件的同步通道，是伪迹识别与事件对齐的依据。

## 参与的认知过程

电极布局决定了能对哪些现象提出时间进程层面的问题，但**位置不等于功能**：

- 额区通道常用于与注意、执行控制、准备相关的慢波成分研究；这些成分的空间分布宽，不能据此定位到具体皮层区。
- 中央区通道常用于运动准备与运动执行相关电位（信号混合了感觉与运动成分）；枕区通道主要用于视觉相关反应，地形图上的极性反转常提示源的方向而非多个源。
- 颞区通道涉及听觉与语言相关加工，但该区域伪迹（肌电、眼动）较多，需谨慎。
- 中线通道（`Fz`/`Cz`/`Pz`）在成分研究中高频使用，原因之一是它们在场分布中振幅较大，而不等于该处皮层是唯一来源。

## 可用观测手段

- **记录配置**：电极材质（湿电极/干电极）、通道数、采样率、放大器带宽与在线滤波设置。
- **阻抗与接触质量**：单个桥接或高阻通道会在插值后留下看似真实的局部效应，需要在采集时记录并报告剔除情况。
- **被试准备**：头围与电极帽尺寸、导电膏用量、颅骨标志测量误差都会引入位置不确定性。
- **同步信号与数字化**：刺激触发、反应按键、眼动与生理通道的同步精度决定事件对齐质量；若要做源定位或跨被试比较，还需记录电极三维坐标（数字化仪或影像配准），仅凭标准点位会引入较大误差。

## 分析方法

- **预处理与重参考**：滤波、去漂移、坏道检测与插值、伪迹校正（眼动、肌电、心电）。插值通道的空间假设是"邻近电极可代表该点"，通道越稀疏该假设越弱；平均参考会让每个通道都包含其余通道的成分，从而人为引入相关性。见 [[预处理与伪迹控制]]。
- **事件相关与时频分析**：前者按刺激或反应分段平均得到时间锁定成分，前提是反应在试次间时间锁定；后者刻画功率与相位的时间演化，适合非相位锁定的活动。见 [[事件相关分析]]、[[时频分析]]。
- **空间分析**：独立成分分析用于分离伪迹或找出稳定的头皮分布模式；微状态分析把地形图按时间聚类，用于刻画快速变化的状态。
- **源定位**：把头皮场反推为皮层源，需要头模型、电极坐标与源空间约束。64 导的一般结论是：**空间分辨率受通道数与容积传导限制**，深部源与相邻源难以分离，源定位结果对头模型与正则化参数敏感。见 [[源定位]]。
- **可重复性前提**：报告通道命名体系、坏道列表、参考方案、滤波与插值参数，否则跨研究无法比较。

## 物种差异与命名争议

- **物种层面不适用**：头皮电极布局是人类专用的记录约定；动物电生理使用植入电极或皮层栅格，通道位置按解剖坐标而非颅骨比例定义，两者不能直接对照。
- **新旧命名并存**：部分颞区与后部点位存在新旧两套编号（旧编号与 10-10 编号指向近似但不完全相同的点位），不同软件与文献可能各用一套。
- **厂商布局与文件格式差异**：不同设备商的 64 导配置在点位集合、辅助通道数量与排序上并不完全一致；通道标签、单位与事件编码在格式转换时容易丢失，跨平台分析前应逐通道核对，同名文件不保证同一点位顺序。
- **"64 导"是通道数而非标准点位集**：同样是 64 导的两套帽子，覆盖范围可以不同。

## 常见误解

- **把通道位置当作该处皮层的活动**：头皮电位是所有源经容积传导叠加的结果，单个通道不代表其正下方的皮层。
- **把通道数当作空间分辨率**：增加电极只提高头皮场的采样密度，源定位的空间精度受容积传导、头模型与源模型的共同限制；插值会平滑局部差异，插值比例偏高时区域效应会被削弱或转移到邻近通道。
- **把地形图的极值当作源的位置**：极值位置与源的方向、深度和几何关系有关，不唯一对应源点。
- **忽略参考方案与个体坐标**：不同参考下的振幅与连接结果不可直接比较；未做电极数字化时，标准点位也不等于个体真实坐标。
