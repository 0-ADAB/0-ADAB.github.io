# 📐 当前认识

> 这一层回答你真正想问的问题：**脑科学到底做到什么程度了。** 但只收录经得起时间和同行检验的部分。

🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 所属层 | L3 证据层 |
| 回答什么 | 目前可以较有把握地说什么、把握到什么程度 |
| 不回答什么 | 不报道最新热点、不代替综述、不给临床建议 |
| 面向读者 | 想判断"某说法是否可信"的读者 |
| 与相邻页的关系 | [[06-证据/index\|证据与推断]] 讲**方法**能支持什么推断；本层讲**具体结论**处于什么状态 |

## 为什么单独立一层

其余各层讲的是"怎么观测"和"能推断到哪一步"，都是**能力**问题。但读者最常问的是另一件事：

> 那么，关于大脑，我们现在究竟知道什么？

如果不回答这个问题，站点会变成一个精致的工具箱，却始终不告诉你工具造出了什么。所以本层收录**结论**——但门槛极高。

## 收录门槛：三重检验

一条结论要进入本层，必须同时通过：

| 检验 | 要求 | 不通过的后果 |
| --- | --- | --- |
| **时间检验** | 结论提出后经过足够长时间，未被后续研究推翻 | 退回「研究线索」或直接不收录 |
| **同行检验** | 经过同行评议发表，且被独立团队重复或元分析支持 | 停留在「开放问题」 |
| **方法检验** | 由**多种独立模态或多种实验设计**得到一致结果 | 标注为单方法结论，明确其局限 |

> 只有单一模态、单一实验室、单篇论文支持的说法，**不属于本层**。它可以作为线索记在对应现象页里，但不能成为一条结论。

## 四级证据状态

每条结论页必须在正文顶部标明状态。状态描述的是**这条结论被检验到什么程度**，与页面写得多完整无关。

| 状态 | 含义 | 判据 |
| --- | --- | --- |
| 🟢 **稳固共识** | 结论方向已高度确定，可作为后续推理的前提 | 长期存在、跨方法一致、被教科书级综述采纳，质疑仅限于细节与边界 |
| 🔵 **较强证据** | 多数证据支持，但存在明确的适用条件或少数反例 | 多个独立团队、多种方法支持，仍未形成完全一致 |
| 🟡 **开放问题** | 有代表性证据，但结果不一致或解释存在竞争假说 | 证据互相冲突，或严重依赖特定范式 |
| ⚪ **研究线索** | 前沿发现，尚未充分复现，仅作观察对象 | 单项研究或单一团队，缺乏独立重复 |

**状态只能逐级上升，且每次上升都需要人工确认**。降级同理：当出现更强的反证时，标注必须下调。

## 一条结论页必须写清四件事

1. **观测到了什么** —— 直接测量层面的描述，不含解释；
2. **推断出了什么** —— 从观测到结论之间补了哪些假设；
3. **哪些证据支持、哪些证据反对** —— 包括反例与失败复现；
4. **不能据此推出什么** —— 边界，以及常见的越界说法。

> 第 4 条是本站最有价值的部分。一条没有边界的结论，等于一句口号。

## 缺口

- 尚无结论页模板之外的任何页面；
