# 神经元

> 神经元层级把观测单位收缩到一个整合单元：它把输入汇总为输出，因此这是少数能同时谈论"输入—输出关系"的层级。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 10⁻⁵—10⁻⁴ m（胞体与树突） |
| 时间尺度 | 亚毫秒（动作电位）—秒（放电率调制） |
| 相关模态 | 电生理、分子遗传（细胞类型标记）、调控 |
| 相关现象 | 感知、运动控制、学习与记忆、注意 |
| 相关结构 | [[皮层分区]]（细胞构筑）、[[皮层下结构]] |
| 主要方法 | [[解码与机器学习]]、[[表征相似性分析]]、[[统计推断与多重比较]] |
| 证据类型 | [[功能关联证据]]、[[时间动态证据]]；因果需要[[因果干预证据]] |

## 定义与边界

**操作性定义**：一个具有整合输入、产生输出的电学单元。判定标准是电学与形态学的，不是概念上的：胞体—树突区整合突触输入，轴突起始段或轴突丘决定是否发放。

需要区分三类常被并置的"单元"：

| 名称 | 含义 | 常见误读 |
| --- | --- | --- |
| 解剖细胞 | 具有明确形态的单个细胞 | 被默认为一个功能单元 |
| 单元（unit） | 从电极信号中分离出的放电源 | 被默认为一个或多个神经元 |
| 细胞类型 | 由形态、电生理或转录组定义的类别 | 被默认为功能类别 |

**边界**：单元聚类（spike sorting）的产物是算法输出，其"一个单元等于一个神经元"的假设在密集电极与高放电率条件下可能失败。这是软件输出与生物实体的典型混淆点。

## 在这个尺度上能观测什么

- **输出的时序**：动作电位的发生时刻、间隔分布、 burst 结构、与刺激或行为的对齐关系。时间精度可达亚毫秒。
- **编码关系**：放电率或放电时序与外部变量（刺激特征、运动参数、任务事件）之间的统计关系。这是[[解码与机器学习]]和[[表征相似性分析]]的层次。
- **输入整合的片段**：膜片钳在离体或麻醉条件下可测突触后电位总和、阈值与增益。
- **细胞类型的电生理指纹**：波形宽度、适应特性、发放模式。
- **细胞群的降维结构**：多个神经元同时记录时，群体活动可被表示为低维轨迹；这类结构是以细胞为单位的，但描述对象已是群体。

**证据陈述**：单细胞记录提示许多神经元的活动与特定刺激或动作参数存在稳定关系；这类关系是相关性的，且通常在特定任务与特定取样条件下成立。

## 不可观测什么

- **看不到全脑**：细胞级记录的空间覆盖极小，无法说明未采样区域发生了什么。
- **看不到慢过程**：单次记录通常持续分钟至小时，无法支持关于发育、学习或老化的推断。
- **钙信号不是放电**：钙成像测量的是钙浓度代理，被钙指示剂动力学与神经突活动平滑；用其推断精确放电时刻需要额外的反卷积假设。
- **一个神经元不等于一个功能**：同一细胞在不同条件下参与不同关系，"一个神经元对应一个概念"这类表述是解释性框架，不是测量结果。
- **结构不可见**：电生理看不到突触来源、受体类型与投射目标，这需要形态学或分子方法补充。
- **人类单细胞数据几乎全部来自临床机会**：电极位置由临床需要决定，抽样不代表一般人群。
- **不能由放电推心理内容**：放电模式本身不携带可读的心理意义；把单元活动等同于某种主观状态是越界解释。

## 典型测量手段

| 手段 | 测什么 | 主要局限 |
| --- | --- | --- |
| 单细胞胞外记录 | 动作电位时序 | 细胞归属依赖聚类，数量少 |
| 高密度探针 | 数十—数千细胞同时 | 深度受限，慢性记录稳定性差 |
| 膜片钳 | 膜电流、突触电流 | 离体为主，细胞数极少 |
| 钙成像（双光子） | 细胞群活动代理 | 时间被动力学平滑，深度受限 |
| 高密度微电极阵列（人类） | 人类单细胞活动 | 临床机会，样本极偏 |
| 单元聚类算法 | 从原始信号分离单元 | 输出不是生物实体 |

## 与相邻尺度的衔接

- **突触 → 神经元**：需要电生理或干预证据把位点变化与细胞输出连起来，见[[分子与突触]]。
- **神经元 → 回路**：需要同一时间窗内的多细胞同步记录。把不同实验中的单细胞结果并置，不构成回路级衔接。
- **神经元 → 脑区**：需要在同一次观测中同时获得区域级信号，或使用能覆盖区域的成像手段。
- **向人类认知的衔接**：人类单细胞证据稀少，多数认知结论由群体级手段（如成像、头皮电生理）给出，两者的衔接需要[[跨尺度整合]]讨论的桥接论证。

## 跨尺度推断的陷阱

- **把单元当神经元**：聚类输出的单元数受算法参数影响；报告"记录到 N 个神经元"时，N 的性质需要界定。
- **放电率窗口自由度过大**：窗口长度与基准期的选择可以改变结论方向，见[[分析一致性原则]]。
- **选择性（selectivity）的循环论证**：先用某刺激筛选出"对该刺激有反应的细胞"，再用同一数据说明该细胞群编码该刺激。
- **小样本下的过度解读**：单个或少数细胞的显著效应在细胞间异质性较大时不能推广到群体。
- **跨物种推广**：啮齿类的细胞类型比例、皮层几何与任务结构均与人类不同。
- **把相关写成编码**：观察到放电与刺激相关，与"神经系统用该放电表示该刺激"是两个不同强度的陈述；后者需要解码、扰动或跨条件泛化证据。
