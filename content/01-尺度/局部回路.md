# 局部回路

> 局部回路指同一小块组织内、以毫秒级相互作用耦合的细胞群；它上接脑区、下接单细胞，是"机制"一词在神经科学中最常被兑现的层级。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 10⁻⁴—10⁻³ m（数百微米至毫米级组织块） |
| 时间尺度 | 毫秒—秒（突触整合与群体振荡周期） |
| 相关模态 | 电生理、调控、分子遗传（细胞类型定向） |
| 相关现象 | 感知、运动控制、注意、学习与记忆 |
| 相关结构 | [[皮层分区]]（层状结构）、[[皮层下结构]]（核团内回路） |
| 主要方法 | [[功能连接]]（局部）、[[有效连接与因果建模]]、[[时频分析]] |
| 证据类型 | [[因果干预证据]]、[[时间动态证据]] |

## 定义与边界

**操作性定义**：一组细胞，其成员之间存在可测的、时间尺度在毫秒级的相互影响。"局部"不是严格的解剖边界，而是一个尺度约定——通常取电极阵列或成像视野能同时覆盖的范围。

回路的描述包含四个要素：

1. **组成**：参与细胞的类型与数量比例（兴奋性、抑制性、调质来源）。
2. **拓扑**：谁连谁、方向、汇聚与发散程度。
3. **动力学**：相互作用的时间常数、延迟、增益。
4. **状态依赖**：同一个回路在不同调质水平或觉醒状态下可能表现出不同功能。

**边界**：回路不等于"脑区的一部分"。脑区是解剖与图谱概念，回路是功能耦合概念；两者的边界不一定重合。同一块组织按不同标准可划出不同回路。

## 在这个尺度上能观测什么

- **群体电活动的结构**：局部场电位（local field potential, LFP）反映突触电流的空间和，可呈现振荡、瞬态与跨频耦合。
- **多细胞间的时序关系**：同时记录的细胞之间的相关、同步放电、序列复现。
- **兴奋—抑制的平衡**：由放电率分布、LFP 频谱形状、以及定向记录推断，属间接测量。
- **干预的反应**：激活或抑制指定细胞类型后，其余细胞与下游的变化。
- **振荡与行为事件的对应**：某些振荡的相位与行为时刻、刺激到达存在统计关系。

**能力陈述**：回路层是少数可以同时取得时间精度、空间归属与因果干预的尺度。

## 不可观测什么

- **看不到投射的整体**：局部记录看不到该回路的上游来源与下游目标，需要追踪方法补充。
- **LFP 的来源不可唯一分解**：LFP 是许多细胞与突触电流的加权和，权重取决于几何与导电性；不能反推出具体是哪一类细胞的电流。把某个频段等同于某类抑制性中间神经元的活动是常见越界。
- **不能覆盖全脑**：结论在空间上限于取样体积，"回路如此"通常意味着"这个取样体积内如此"。
- **麻醉与离体的状态偏移**：多数精细回路研究在麻醉或离体条件下完成，自发活动、调质水平与耦合强度可能改变。
- **不能推出认知内容**：回路的动态本身不给出知觉、记忆或决策的内容，只能作为这些过程在某一层级的实现描述。
- **人类数据的可获得性受限**：人类回路级测量几乎只来自临床电极（癫痫监测、术中），位置由临床决定。

## 典型测量手段

| 手段 | 测什么 | 主要局限 |
| --- | --- | --- |
| 高密度硅探针 | 多细胞放电与 LFP | 覆盖有限，慢性稳定性差 |
| 双光子钙成像 | 细胞群活动与树突事件 | 时间被钙动力学平滑 |
| 电压敏感染料/蛋白 | 亚阈值群体活动 | 信噪比与毒性权衡 |
| iEEG / ECoG | 人类局部场电位 | 临床机会性取样，位置不可选 |
| 光遗传与化学遗传 | 细胞类型定向的因果干预 | 需要遗传操作，多为动物 |
| 双电极/多电极配对记录 | 细胞间连接的单次验证 | 成功率低，样本量极小 |
| 离体切片电生理 | 精确的突触与回路参数 | 离体，网络状态缺失 |

## 与相邻尺度的衔接

- **单细胞 → 回路**：需要同一时间窗内的多细胞同步数据。分别得到的单细胞结论无法自动组成回路。
- **回路 → 脑区**：需要投射追踪或层状记录，说明局部动态与区域级输入输出一致。
- **回路 → 网络**：需要至少两个不同区域同时记录的耦合证据，或者由解剖投射加功能耦合共同支持；仅凭两个区域各自有回路不足以建立网络。
- **回路 → 行为**：需要对回路活动的读出与扰动同时进行，并证明扰动改变了行为。

## 跨尺度推断的陷阱

- **把频段当细胞类型**：LFP 频段与抑制性中间神经元之间不是一一对应关系，见[[时频分析]]。
- **把同步当沟通**：两个细胞或两个区域的时间同步只说明存在统计依赖；"沟通"是解释性说法，需要方向性与干预证据。见[[有效连接与因果建模]]。
- **刺激伪迹被读成效应**：电刺激与光刺激会引入伪迹，若不做控制条件，伪迹可能被解释为回路反应。见[[预处理与伪迹控制]]。
- **干预不特异**：任何调控手段都有非目标效应（热效应、纤维激活、脱靶表达）。把干预结果直接读作"该细胞类型负责该功能"需要特异性控制。
- **回路功能被绝对化**：同一回路镶嵌在不同网络状态中时功能可能变化；把它当作固定计算模块是过度简化。
- **跨物种回路差异**：细胞类型与层状组织在物种间不完全同源，特别是灵长类与啮齿类之间。
