# 全脑

> 全脑层级以"不遗漏"为目标：用一次观测或一个模型覆盖全部灰质或全皮层，代价是每个单位内的分辨能力显著下降。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | ~10⁻¹ m（整个脑或全皮层） |
| 时间尺度 | 毫秒（电生理）—秒（成像），取决于手段 |
| 相关模态 | 血流代谢、电生理、结构扩散、调控 |
| 相关现象 | 意识与睡眠、注意、语言、临床与病理 |
| 相关结构 | [[大尺度网络]]、[[皮层分区]]、[[神经递质系统]] |
| 主要方法 | [[多模态融合]]、[[源定位]]、[[功能连接]] |
| 证据类型 | [[跨模态一致性]]、[[计算模型证据]] |

## 定义与边界

**操作性定义**：观测或模型的空间覆盖包含全部（或声明范围内全部）灰质结构，因此任何区域都不会因采样设计而被系统性地遗漏。

需要区分三种"全脑"：

| 说法 | 实际含义 | 常见误读 |
| --- | --- | --- |
| 全脑成像 | 覆盖全脑，但体素为毫米级 | 读作"看到了全部细节" |
| 全脑记录 | 多区域同时记录，取样点有限 | 读作"全部区域都记录了" |
| 全脑模型 | 以全脑为对象的计算模型 | 读作"模型即脑" |

**边界**：全脑是覆盖范围的概念，不是分辨率的概念。全脑覆盖与细胞级分辨在当前手段下不可兼得，这属于视场—分辨率权衡的直接后果，见[[空间尺度]]。

## 在这个尺度上能观测什么

- **整体拓扑**：全部节点的连接结构与整体分布，用于检验某区域是否为孤立异常。
- **全局状态**：觉醒水平、意识状态、整体同步水平等只能在全脑范围定义的量。
- **跨区域的共同变化**：全局信号、整体梯度、大范围同步事件。
- **区域间的相对关系**：在全脑背景下比较区域，可减少选择性报告。
- **全脑尺度的一致性检验**：某局部发现是否在全脑范围内仍然成立。

**能力陈述**：全脑覆盖是检验"某结论是否只是局部取样产物"的必要条件；但它不能替代高分辨手段提供的机制信息。

## 不可观测什么

- **看不到细胞与回路**：全脑手段的分辨率不足以指认细胞类型、层或突触事件。
- **覆盖不等于无偏**：成像受磁敏感伪影、头动、信号缺失影响，某些区域（如眶额、颞极、小脑下部）系统性信噪比较低；"全脑"实际是"覆盖良好区域的全脑"。
- **看不到时间细节（成像）**：秒级采样无法分辨毫秒序列。
- **看不到因果（记录）**：全脑记录给出相关结构，方向需模型或干预。
- **看不到个体特异的边界**：全脑分析仍依赖配准到共同空间，个体边界差异被平均。
- **模型不是脑**：全脑计算模型是对数据的拟合，其参数与机制之间不是一一对应，见[[计算模型证据]]。

## 典型测量手段

| 手段 | 覆盖 | 主要局限 |
| --- | --- | --- |
| fMRI（全脑） | 全脑 | 秒级、间接、区域信噪不均 |
| PET（全脑） | 全脑 | 分钟级、注入、代价高 |
| 高密度 EEG / MEG | 全脑（源定位受限） | 逆问题不唯一，深部源差 |
| ECoG 网格（临床） | 单侧或双侧大面积 | 临床机会性，覆盖由临床决定 |
| 全脑连接组（动物） | 全脑 | 电镜代价极高，通常单个体 |
| 清醒动物多区域记录 | 多区域 | 电极数有限，慢性稳定性 |
| 全脑计算模型 | 全脑 | 假设驱动的简化 |

## 与相邻尺度的衔接

- **网络 → 全脑**：网络分析通常已使用全脑节点，两者的差别在于覆盖完整性与节点粒度；节点粒度改变会显著改变拓扑指标。
- **全脑 → 群体**：需要跨个体的共同坐标、配准程序与群体统计；个体间对齐本身是假设。
- **全脑 → 局部**：需要把全脑结论落到具体区域或回路时，必须引入额外证据；仅凭全脑统计不能指认局部机制。

## 跨尺度推断的陷阱

- **把覆盖当分辨**：这是全脑层最常见的错误，见[[模态比较]]。
- **全局信号的处理决定结论**：是否回归全局信号会系统改变连接结果与组间差异。
- **共同驱动混淆**：全脑范围内大量区域相关可能来自共同输入（如觉醒系统）而非区域间耦合。
- **多重比较规模巨大**：全脑体素或全脑连接的分析次数极大，未校正或校正不当会产出大量假阳性，见[[统计推断与多重比较]]。
- **把全脑统计差异读作机制**：全脑层面的差异只说明分布不同，不指认原因。
- **"全脑一致"的证据价值被高估**：一致性可能来自共同的生理噪声或头动，需要阴性对照与质控支撑。
- **跨模态拼接的隐含假设**：把全脑成像与局部电生理拼接时，假设了两者的时间与空间对应关系，这一假设需要显式论证，见[[跨尺度整合]]。
