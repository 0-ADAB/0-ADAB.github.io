# 慢变状态

> 慢变状态指在分钟到天的时间尺度上起伏的、影响全局的变量：觉醒水平、注意漂移、神经调质状态、昼夜节律；它们不直接对应事件，而改变事件发生的背景。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 全脑—网络（慢变量通常以全局或系统水平起作用） |
| 时间尺度 | ~1 min—24 h 及以上 |
| 相关模态 | 生理化学、血流代谢、电生理（长期监测） |
| 相关现象 | 注意、意识与睡眠、情绪与应激、学习与记忆 |
| 相关结构 | [[神经递质系统]]、[[大尺度网络]]、[[皮层下结构]] |
| 主要方法 | [[功能连接]]、[[有效连接与因果建模]]、[[质控与可重复性]] |
| 证据类型 | [[时间动态证据]]；因果需要独立的操纵实验 |

## 定义与边界

**操作性定义**：一类取值随时间缓慢变化、且对大量下游过程同时产生影响的变量。它满足两个条件：

1. **时间常数远大于被观察的事件**（状态在多个试次之间保持不变）；
2. **影响是全局的或系统级的**（不是某个条件下的局部效应）。

常见候选状态变量及其常用代理指标：

| 候选状态 | 常用代理 | 代理的性质 |
| --- | --- | --- |
| 觉醒/警觉水平 | 瞳孔、皮电、心率变异性、EEG 频谱比例 | 生理代理，与主观状态不完全对应 |
| 注意漂移 | 行为波动、眼动、脑信号低频波动 | 事后推断 |
| 睡眠—觉醒周期 | 行为、电生理、活动记录 | 观察性 |
| 昼夜节律 | 体温、激素（如皮质醇、褪黑素） | 生化取样 |
| 神经调质状态 | 瞳孔（去甲肾上腺素代理）、PET 受体 | 间接，空间与时间精度有限 |
| 疲劳与练习效应 | 时间趋势、纵向行为 | 混杂于设计 |

**边界**：状态的定义通常是**事后的**。研究者先从连续记录中划分出"状态段"，再比较段间差异；划分标准参与结论。

## 在这个尺度上能观测什么

- **慢变量的时间过程**：瞳孔、心率、激素、活动量的连续变化。
- **长记录中的状态分段**：分段后的信号与连接模式差异。
- **状态与表现的关联**：状态指标与行为表现之间的统计关系。
- **状态的神经相关**：不同状态下脑信号的系统性差异（频谱、连接、整体水平）。
- **节律性**：以小时或天为周期的周期成分。
- **纵向稳定性与信度**：同一测量在不同时间点的一致性，这是判断个体差异研究是否可行的前提。

**证据陈述**：多项研究提示觉醒水平等慢变量与脑信号的整体指标存在关联；这类关联多为系统水平的统计关系，且状态推断依赖代理指标的效度。

## 不可观测什么

- **不能直接测量状态本身**：瞳孔、心率、激素都是代理，代理与状态的关系受药物、光照、情绪、运动影响。
- **不能由慢变量推断具体过程**：慢状态改变的是背景，"某状态更高"不指认任何具体计算。
- **不能观测快速事件**：长记录手段通常时间分辨较低，或通过间断取样，毫秒事件不可及。
- **不能区分状态与特质**：单次记录无法说明某个体的慢变量水平是否是稳定属性。
- **不能观测状态切换的触发原因**：观察到切换不等于知道原因，需要操纵或高时间分辨的因果设计。
- **不能把睡眠分期的边界当脑状态的真实边界**：分期由规则定义，跨期过渡是连续的。
- **不能忽略测量漂移**：长时程设备漂移与配准变化会被读成状态变化。

## 典型测量手段

| 手段 | 采样 | 该尺度上的角色 |
| --- | --- | --- |
| 静息态 fMRI（长扫描） | 秒级、数分钟至数十分钟 | 状态相关的连接变化 |
| 长时间 EEG / 可穿戴脑电 | 数百 Hz、小时至天 | 睡眠与觉醒监测 |
| 瞳孔与眼动 | 数十—数百 Hz | 觉醒与注意代理 |
| 皮电、心率变异性 | 数十—数百 Hz | 自主神经代理 |
| 激素与代谢取样（唾液、血、微透析） | 分钟级取样 | 慢生化变量 |
| 活动记录（actigraphy） | 分钟级、数天至数周 | 节律与睡眠 |
| 经验取样与日记法 | 事件级、数周 | 主观状态与情绪 |

## 与相邻尺度的衔接

- **秒 → 分钟**：需要显式定义状态边界，并检验结论对分段方式不敏感。
- **分钟 → 小时/天**：需要连续或密集重复取样，并控制昼夜相位。
- **小时/天 → 发育/老化**：跨越的量级很大，通常靠纵向重复而非连续记录连接。见[[发育与老化]]。

## 跨尺度推断的陷阱

- **状态拼接导致连接估计混合**：把不同状态的时段合并估计功能连接，得到的是混合模式，不能代表任一状态。
- **把慢波动当任务效应**：未建模的慢漂移会在条件比较中产生看起来显著的低频差异。
- **用瞳孔代表去甲肾上腺素**：这是常用的间接推理，受光照、认知负荷与情绪多重影响，见[[生理与神经化学]]。
- **在状态未受控时比较组间**：临床组、老年人、儿童的状态分布不同，组间连接差异可能是状态差异。见[[个体间与群体]]。
- **事后分段的研究者自由度**：分段阈值可调时，显著结果容易来自阈值选择，见[[分析一致性原则]]。
- **相关与因果混淆**：状态与表现共生变化，可能是第三变量（时间、疲劳）共同驱动。
- **节律混入**：未记录昼夜相位的纵向研究可能把节律效应归因于干预。
