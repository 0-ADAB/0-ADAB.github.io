# 跨尺度整合

> 跨尺度整合不是"多测几种手段"，而是构造一条从观测到推断的**桥接论证（bridging argument）**：说明两个层级之间的映射关系是什么、凭什么成立、在什么条件下失效。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 跨越至少两级（分子 ↔ 回路 ↔ 脑区 ↔ 全脑 ↔ 群体） |
| 时间尺度 | 跨越至少两级（毫秒 ↔ 秒 ↔ 分钟及以上） |
| 相关模态 | 全部模态（本页讨论模态之间如何拼接） |
| 相关现象 | 全部现象 |
| 相关结构 | [[大尺度网络]]、[[皮层分区]]、[[神经递质系统]] |
| 主要方法 | [[多模态融合]]、[[有效连接与因果建模]]、[[计算模型证据]] |
| 证据类型 | [[跨模态一致性]]、[[计算模型证据]]；结论强度受解释边界约束 |

## 定义与边界

**定义**：在至少两个不同的空间或时间层级上取得的观测，被组合成一个关于机制或功能的连贯陈述。它不等于以下三件事——同一批被试做两种测量（那只是多模态采集）、两个层级的结果方向一致（那只是一致性，是一致性线索而非整合本身）、把局部机制写进全脑框架的语言（那只是修辞，缺少映射关系）。

**边界**：整合的产物是**有条件的推断**，不是机制的事实。任何跨尺度陈述都应能回答："如果这一层级的关系不成立，结论会怎样变化？"

## 桥接论证的四个必要条件

一条可检验的桥接论证需要同时具备以下四项。缺任一项，跨尺度陈述即降级为并列叙述。按桥接策略，强度由弱到强分为三级：共同参照（两次测量共享同一刺激、任务或坐标，仅时空重叠）＜同时记录（同一时间、同一被试上并行采集，可估计量纲与时延关系）＜干预桥接（扰动一个层级并观测另一层级是否按预测改变，可区分共同驱动与直接关系）。

1. **尺度映射（scale mapping）**：说明高层级单位由哪些低层级单位组成，以及权重或聚集规则。例如"该体素覆盖的区域包含哪些细胞类型与层"。
2. **量纲关系（measurement relation）**：说明两个测量量之间的物理或统计关系。例如"该电生理指标与血流代谢信号之间是线性还是非线性关系，延迟多少"。
3. **时空对齐（alignment）**：说明两次观测在空间与时间上如何对应，包括配准误差与延迟的估计。
4. **独立可检验的预测（falsifiable prediction）**：桥接本身应给出一个在尚未观测的条件下可被证伪的预测，而不是只解释已观测到的数据。

## 向上推断：微观 → 宏观

**成立所需条件**（例如由细胞活动推断成像信号）：

- 聚集规则已知：哪些细胞、以什么权重、以什么非线性方式参与高层级信号。
- 覆盖已知：高层级单位内的细胞类型比例与几何。
- 状态已匹配：低层级数据所在的状态与高层级数据相同。

**不成立的情况**：

- 权重未知时的"平均"假设。血流代谢信号依赖血管分布、细胞类型与神经血管耦合，没有通用权重。
- 非线性叠加：多个细胞的活动在信号层面可能相互抵消，因此"高层级无变化"不等于"低层级无变化"。
- 取样偏倚：低层级测量集中在特定细胞类型（如易记录的大锥体细胞），其行为不代表群体。

**能力陈述**：向上推断原理上可行，但需要显式的聚集模型；实践中往往只能给出方向性预测，而非定量预测。

## 向下推断：宏观 → 微观

**成立所需条件**（例如由区域激活推断细胞或突触变化）：

- **逆问题唯一性**：高层级观测能唯一确定一个低层级解释。这在大多数神经测量中不成立——多个不同的细胞级配置可产生同一宏观信号。
- **选择性证据**：该高层级指标对目标低层级过程有选择性，而非对多种过程都敏感。
- **排除替代解释**：非神经来源（血管、运动、注意力、唤醒）不能解释同一观察。

**典型失败模式**：

- "该区域活动升高"被读作"该区域的某类神经元放电增加"——缺少同时电生理证据时不成立。
- "某频段增强"被读作"某类中间神经元活动增强"——LFP 是加权和，不能反推出细胞类型。
- "连接增强"被读作"突触权重增加"——功能连接是统计依赖，与突触效能之间缺少映射。

## "同一脑区被两种手段激活"不等于同一过程

这是跨尺度文献中最常见的推断跳跃，其失效来自至少五重不匹配：

| 不匹配来源 | 具体表现 |
| --- | --- |
| 物理量不同 | 一个测血流代谢代理或电流源，另一个测电位或磁场；量纲不同 |
| 空间单位不同 | 体素、电极、图谱分区、聚类单元不是同一类实体，边界不重合 |
| 时间尺度不同 | 秒级平均与毫秒级事件无法对齐；"同时"通常是分析上的重合 |
| 条件与基线不同 | 两次测量的任务、对照、状态、被试群体可以完全不同 |
| 分析选择不同 | 平滑、阈值、校正、感兴趣区定义都参与结论，选择空间巨大 |

**因此**：空间或时间上的**重叠**只提供"值得进一步检验"的线索。要把它升级为"同一过程"，需要在同一被试、同一时间窗上同时测量，并给出量纲关系与可证伪的预测——即上文第 2、4 项条件。

## 常见的跨尺度推断陷阱

- **尺度置换**：把某一层级成立的关系无条件提升到所有层级。
- **中转量被当作中性**：把行为指标、外周生理或血流信号当作"神经活动的直接读数"，忽略每一个中转环节引入的假设。
- **一致性被当作验证**：两个手段给出相似模式，可能来自共同的生理噪声、共同的运动伪迹或共同的分析选择，见[[跨模态一致性]]。
- **模型拟合被当作机制**：能拟合多层数据的模型未必对应真实实现，见[[计算模型证据]]。
- **选择性报告**：只在两层级一致时报告整合、不一致时分别报告，使整合的证据价值被系统性高估。
- **物种与准备条件的跳跃**：把离体或动物的低层级机制与人类高层级观测拼接，需要额外的同源论证。

## 可操作的检查清单

1. 两个层级的**观测单位**分别是什么？包含关系是否明确？
2. 两个测量量之间的**关系**是测量得到的，还是被假定的？
3. 空间与时间的**对齐**误差有多大？结论是否对对齐方式敏感？
4. 是否存在**单一层级内**或非神经的替代解释？桥接是否给出可被证伪的预测？两层级不一致时结论如何改写？
