# 脑区

> 脑区是解剖与图谱约定的空间单位，也是不同研究之间最通用的比较单位；但它的边界来自人为划分，不是自然给定的功能模块。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 10⁻³—10⁻² m（毫米至厘米级） |
| 时间尺度 | 秒—分钟（成像尺度）；区域级动态可到毫秒 |
| 相关模态 | 血流代谢、结构扩散、电生理（源定位） |
| 相关现象 | 感知、运动控制、语言、情绪与应激、临床与病理 |
| 相关结构 | [[皮层分区]]、[[皮层下结构]]、[[大尺度网络]] |
| 主要方法 | [[源定位]]、[[统计推断与多重比较]]、[[功能连接]] |
| 证据类型 | [[功能关联证据]]、[[结构证据]]；因果需[[因果干预证据]] |

## 定义与边界

**脑区的四种来源**，它们的性质不同，比较时必须知道用的是哪一种：

| 来源 | 依据 | 典型局限 |
| --- | --- | --- |
| 细胞构筑 | 层状与细胞形态差异 | 划分标准主观，个体差异大 |
| 拓扑图谱 | 坐标空间内的固定划分 | 不保证功能同质 |
| 连接图谱 | 区域间连接的相似性聚类 | 依赖连接测量与聚类参数 |
| 功能图谱 | 任务或静息数据的共激活模式 | 依赖数据与阈值，可复现性受限 |

**边界的三重含义**：

- **解剖边界**：组织学上可辨识的划分。
- **图谱边界**：某个坐标空间里的分割，任意两个坐标可能落在不同图谱的不同分区。
- **功能边界**：由反应模式或连接模式定义，随任务与状态改变。

三者不重合。因此"某脑区是 X 功能的区域"这类陈述通常只在指定图谱与任务条件下成立。

## 在这个尺度上能观测什么

- **区域水平的活动强度差异**：任务条件之间的信号差异，通常以血流代谢或代谢标记为代理。
- **区域水平的形态与完整性**：灰质体积、皮层厚度、白质弥散属性。
- **区域间的统计依赖**：区域时间序列之间的相关或偏相关，构成[[功能连接]]。
- **区域水平的电活动**：源定位估计的电流源、或临床电极直接记录的区域信号。
- **病损与干预的区域效应**：区域被破坏或被调控后行为与其余活动的变化。

**证据陈述**：多项研究提示许多任务与特定区域的血流代谢变化存在稳定的统计关联；这类关联是区域级的、条件性的，并受分析与阈值选择影响。

## 不可观测什么

- **不能观测区域内的机制**：区域级信号是数百万细胞的加权和，"该区域活动升高"不指认细胞类型、层、通路或突触事件。
- **不能观测方向**：区域 A 与 B 相关不说明 A 影响 B，见[[有效连接与因果建模]]。
- **不能观测个体特异的边界**：把群体平均图谱套到单个被试上会引入配准误差，特别是边界区域。
- **不能由解剖连接推出功能**：存在投射不等于该投射在任务中被使用。
- **"激活"不是开关**：血流代谢变化是连续量，用"激活/未激活"二分是语言简化，阈值化后才出现二元结论。
- **不能把区域当计算模块**：区域是多条通路、多种细胞类型、多种动态的叠合体，把它当作单一功能单元是过度简化。
- **静息态的功能连接不等于解剖连接**：两者相关但不等同，个体与状态差异可造成偏离，见[[结构与扩散成像]]。

## 典型测量手段

| 手段 | 测什么 | 主要局限 |
| --- | --- | --- |
| fMRI | 血流动力学代理 | 秒级、空间模糊、间接 |
| PET | 代谢或受体分布 | 分钟级、需注入、代价高 |
| 结构 MRI | 体积与厚度 | 静态，不反映活动 |
| 扩散 MRI | 白质几何与弥散属性 | 纤维追踪分辨率与交叉纤维问题 |
| EEG/MEG 源定位 | 头皮信号的源估计 | 逆问题不唯一，深部源差 |
| iEEG / ECoG | 局部场电位 | 临床机会性，覆盖不全 |
| 病损分析 | 区域被破坏的后果 | 病损不选择细胞类型，常有重组 |
| 图谱配准 | 把个体数据映射到共同空间 | 配准误差与图谱选择影响结论 |

## 与相邻尺度的衔接

- **回路 → 脑区**：需要投射证据或覆盖区域的记录，说明局部回路与区域级信号一致。
- **脑区 → 网络**：需要连接矩阵，并显式声明阈值与节点定义；不同阈值给出不同网络。
- **脑区 → 全脑**：需要覆盖性检查与多重比较校正，见[[统计推断与多重比较]]。
- **脑区 → 行为**：需要行为时序与区域信号的联合建模，且需区分相关与因果。

## 跨尺度推断的陷阱

- **体素/电极 ≠ 脑区**：体素是采样单位，电极是物理接触点，两者与图谱分区都没有一一对应。把体素坐标直接说成"某脑区"是最常见的层级混淆，见[[跨尺度整合]]。
- **"同一脑区被两种手段激活"≠同一过程**：两种模态测的是不同物理量，条件、时间窗与空间尺度都不同，见[[模态比较]]。
- **反向推断（reverse inference）**：从区域激活回推心理过程，只在有充分选择性证据时才成立，而多数区域参与多种任务。
- **双中心与网络混杂**：区域效应可能来自共同输入或整体状态变化，而非区域自身计算。
- **病损的不特异性**：病损破坏所有经过该区域的纤维与细胞，后果不能归因于某类神经元。
- **图谱选择即结论**：更换图谱可能改变显著区域；报告时应说明图谱与版本。
- **圆形分析（circular analysis）**：用全体数据选区域再在全体数据上检验，会系统性放大效应。
