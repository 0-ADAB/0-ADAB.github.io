# 分子与突触

> 分子与突触是空间轴最细的两个层级：它们描述构成神经系统的物质与连接位点，回答"由什么组成、连到哪里"，而不回答"此刻在做什么"。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 10⁻¹⁰—10⁻⁶ m（分子、突触） |
| 时间尺度 | 分子事件微秒—毫秒；受体与表达调节可达分钟—天 |
| 相关模态 | 分子遗传、电生理、结构扩散 |
| 相关现象 | 学习与记忆、情绪与应激、临床与病理（作为机制的底层） |
| 相关结构 | [[神经递质系统]]、[[皮层下结构]]、[[皮层分区]]（细胞构筑层面） |
| 主要方法 | [[预处理与伪迹控制]]、[[多模态融合]]（与电生理、成像拼接时） |
| 证据类型 | [[结构证据]]为主；功能与因果需要额外的电生理或干预证据 |

## 定义与边界

**分子层级**关注三类对象：递质与调质（如谷氨酸、γ-氨基丁酸即 gamma-aminobutyric acid, GABA、多巴胺、乙酰胆碱）、受体与离子通道、以及基因表达与蛋白产物。这一层级的观测单位是"种类与丰度"，不是"活动"。

**突触层级**关注连接位点本身：突触前末梢、突触后受体群、间隙连接、树突棘形态，以及连接的统计权重。需要区分两个常被混用的概念：

- **解剖连接（anatomical connectivity）**：结构上存在一个连接位点。
- **功能权重（functional weight）**：在给定条件下，该位点对下游输出的实际影响。

前者是结构事实，后者依赖状态与历史。从前者到后者需要功能证据。

**层级边界**：突触是"一个位点"，神经元是"一个整合单元"。区分标准是信号是否在空间上被汇总——突触后电位在胞体—轴突丘被整合，这个整合点把突触层与神经元层分开。

## 在这个尺度上能观测什么

- **分子种类与分布**：什么分子、在哪些细胞、大致多少。转录组与蛋白组提供种类清单，组织化学提供空间分布。
- **突触的存在与形态**：连接位点的位置、类型（兴奋性/抑制性）、棘的形态变化。
- **受体与通道的电学后果**：膜片钳可直接测量单通道电导、突触电流的幅值与时间常数。
- **递质释放的时空特征**：释放的量子性质、清除时间常数。
- **连接组的局部片段**：连续切片电镜可在小体积内重建全部突触连接。

**能力陈述**：这一层级能给出机制层面最具体的量（单个通道电导、单个位点的位置），但这些量是关于"硬件"的描述。

## 不可观测什么

- **不能观测"意义"**：任何分子或突触测量都不直接给出行为、认知或心理内容。分子变化与心理过程的对应必须由更高层级的证据建立。
- **动物与离体偏差**：多数突触级测量在离体切片或麻醉动物中完成；离体条件改变自发活动、神经调质水平与网络状态。
- **单次测量的代表性有限**：一种细胞类型的分子图谱来自若干取样细胞，个体差异与区域差异可能大于类型差异。
- **形态不等于功能权重**：看到一个突触不等于知道它是否驱动下游放电；"存在连接"与"有效连接"是两个陈述。
- **在体人类数据几乎不可得**：人类活体的突触级测量基本限于临床机会（如术中组织），抽样偏倚无法忽略。
- **时间分辨率的两难**：电镜给出极好的空间信息但没有时间；电生理有时间但无法指认分子身份。

## 典型测量手段

| 手段 | 测什么 | 主要局限 |
| --- | --- | --- |
| 单细胞/单核测序 | 细胞类型与表达谱 | 破坏组织，无空间与动态信息 |
| 空间转录组 | 表达的空间分布 | 分辨率与灵敏度权衡 |
| 免疫组化与原位杂交 | 分子在组织中的位置 | 抗体特异性是常见混淆源 |
| 质谱与微透析 | 递质或代谢物丰度 | 时间分辨率低，取样体积较大 |
| 连续切片电镜 | 突触级连接组 | 视野极小，代价高 |
| 膜片钳 | 单通道与突触电流 | 离体、细胞数极少 |
| 双光子成像 | 在体树突与棘动态 | 深度受限，需颅窗 |
| 突触追踪病毒 | 跨突触的连接关系 | 方向与多级传递的解释受限 |

## 与相邻尺度的衔接

- **分子 → 突触**：需要共定位证据，证明该分子位于该连接位点。仅凭同区域存在不构成衔接。
- **突触 → 神经元**：需要电生理或干预证据，说明该位点的变化改变细胞输出。
- **突触 → 回路**：需要同时测量多个细胞的相互作用；单细胞水平的突触测量无法给出回路结构。
- **向更高层级的跳跃**：从分子变化直接推到一个脑区或一个网络的表现，中间缺少神经元与回路两级，属于典型的跨尺度越界。见[[跨尺度整合]]。

## 跨尺度推断的陷阱

- **把分子相关当机制解释**：某个分子在任务中变化，只说明它与任务条件相关；因果方向需要干预。
- **把"存在"读作"激活"**：表达或分布是静态属性，活动是动态量。两者不同，见[[分子与遗传]]。
- **把离体结果直接推广到在体**：离体制备缺少完整的输入与调质环境，突触性质可能改变。
- **把细胞类型当功能类型**：转录组定义的细胞类型与功能类型并不一一对应。
- **以丰度推断权重**：某个受体的数量多，不等于它在功能上主导；受体分布位置（突触内/突触外）常比总量更关键。
- **命名陷阱**：递质系统按分子命名，但一个分子在多个系统中起作用（如多巴胺既参与运动也参与奖赏相关过程），不能由分子名称推出功能归属。见[[神经递质系统]]。
