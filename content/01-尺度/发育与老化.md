# 发育与老化

> 发育与老化是时间轴两端最长的层级，以月到数十年为单位；它们描述的不是事件而是轨迹，因此对测量的稳定性与设计的纵向性要求最高。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 群体（需跨个体比较）→ 全脑（形态与网络层面） |
| 时间尺度 | 月—数十年 |
| 相关模态 | 结构扩散、血流代谢、行为眼动、分子遗传 |
| 相关现象 | 发展、学习与记忆、语言、临床与病理 |
| 相关结构 | [[皮层分区]]、[[大尺度网络]]、[[皮层下结构]] |
| 主要方法 | [[统计推断与多重比较]]、[[质控与可重复性]]、[[功能连接]] |
| 证据类型 | [[结构证据]]与[[功能关联证据]]为主；因果极难建立 |

## 定义与边界

**发育**与**老化**在这套坐标系中是对称的两端，共享同一套方法学困难：

| 维度 | 发育 | 老化 |
| --- | --- | --- |
| 主要过程 | 髓鞘化、突触生成与修剪、网络分化 | 灰质体积下降、白质完整性变化、代偿 |
| 观测窗口 | 出生前至约 25 岁 | 成年中期至生命终点 |
| 采样困难 | 配合度低、运动多、任务难标准化 | 共病、用药、感觉功能下降 |
| 常见设计 | 纵向队列、加速纵向设计 | 队列、横断比较 |

**设计类型与其支持的推断强度**：

- **横断设计（cross-sectional）**：不同年龄组各测一次。得到的是**年龄组差异**，混杂世代效应（cohort effect）与选择效应。
- **纵向设计（longitudinal）**：同一批个体重复测量。得到的是**个体内变化**，但受练习效应、脱落偏倚与测量漂移影响。
- **加速纵向设计（accelerated longitudinal）**：多个年龄段各做短程纵向，拼接成轨迹。以设计假设换取时间成本。

**边界**：只有纵向设计能直接证明"变化"；横断差异在语言上必须写成差异而非变化。

## 在这个尺度上能观测什么

- **形态轨迹**：灰质体积、皮层厚度的年龄相关曲线（群体层面）。
- **白质属性**：弥散指标随年龄的群体趋势。
- **网络的成熟与重组**：连接模式随年龄的群体趋势。
- **行为与认知轨迹**：能力随年龄的纵向变化。
- **个体差异的稳定性**：同一指标在同一样本内跨时间点的秩序保持程度。
- **敏感期候选窗口**：某指标在特定年龄段的快速变化区间（提示性）。

**证据陈述**：多项研究提示若干脑形态与连接指标在群体水平呈单调或有转折的年龄趋势；这些趋势描述的是群体统计，不描述任何个体的轨迹。

## 不可观测什么

- **不能观测机制**：年龄相关差异不指认原因（经验、激素、血管、遗传、退化都可贡献）。
- **不能从横断推出个体变化**：这是本层级最常见、后果最严重的越界。
- **不能确定转折点的存在与位置**：轨迹的"峰值年龄"高度依赖样本、测量与模型形式，不同分析可能给出不同转折。
- **不能观测早期状态**：多数研究在某个年龄起点开始，此前的轨迹是外推。
- **不能忽略测量等价性**：同一任务在不同年龄可能被不同策略完成，"同样的测量"未必测同样的东西。
- **不能把结构差异读作功能差异**：体积或弥散指标与功能的关系是间接的，见[[结构与扩散成像]]。
- **不能把群体趋势个体化**：群体平均曲线不描述个体轨迹的形状，个体间异质性常大于年龄效应。

## 典型测量手段

| 手段 | 测什么 | 该尺度上的限制 |
| --- | --- | --- |
| 结构 MRI | 体积、厚度 | 配准与分割算法在极端年龄的偏差 |
| 扩散 MRI | 白质弥散属性 | 运动敏感，儿童与老人更难 |
| 静息态 fMRI | 连接模式 | 头动与状态差异与年龄相关 |
| 认知任务与标准化测验 | 行为轨迹 | 测量等价性与天花板/地板效应 |
| 纵向队列 | 个体内变化 | 脱落、练习效应、测量漂移 |
| 遗传与生化取样 | 个体差异的候选来源 | 效应量小、需大样本 |

## 与相邻尺度的衔接

- **慢变状态 → 发育/老化**：需要重复测量把状态波动与长期趋势分开；单次测量的慢变量不等于发展水平。
- **群体 → 轨迹**：需要纵向或加速设计，并要求测量信度足以检出个体内变化，见[[个体间与群体]]。
- **形态 → 功能**：需要独立的功能证据；两者不能互相推出。

## 跨尺度推断的陷阱

- **横断差异被写成发展变化**：语言替换（"差异"→"变化"）是这一领域最普遍的推断越界。
- **世代效应（cohort effect）**：不同年龄组成长环境不同，组间差异不来自年龄。
- **选择效应与存活偏倚**：老年样本常由更健康者构成，会低估老化效应。
- **练习效应与测量漂移**：纵向重复同一任务会提高成绩；扫描仪或序列更新会造成阶跃式变化。
- **头动与年龄共变**：儿童与老年人头动更多，而头动影响连接与形态指标，未严格控制的年龄效应可能是运动效应。见[[预处理与伪迹控制]]。
- **非线性模型的选择**：多项式阶数、断点与平滑参数的选择可决定"转折点"是否出现，见[[分析一致性原则]]。
- **把相关读作经验塑造**：脑指标与经验的相关不能确定方向，环境选择与个体倾向都是竞争解释。
- **因果语言**：除非有随机干预或自然实验设计，本层级只能给出关联，见[[因果干预证据]]。
