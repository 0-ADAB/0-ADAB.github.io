# 毫秒动态

> 毫秒动态指以千分之一秒为单位演变的神经事件：动作电位、突触后电位、以及由此生成的振荡与序列；这是神经系统中唯一能被直接读出"顺序"的尺度。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 单细胞—全脑（取决于手段） |
| 时间尺度 | ~1—100 ms |
| 相关模态 | 电生理、调控（刺激时序）、行为眼动（反应时） |
| 相关现象 | 感知、运动控制、注意、语言、意识与睡眠 |
| 相关结构 | [[皮层分区]]（层状与时序）、[[大尺度网络]]（传播） |
| 主要方法 | [[时频分析]]、[[事件相关分析]]、[[有效连接与因果建模]] |
| 证据类型 | [[时间动态证据]]；因果需刺激时序与干预配合 |

## 定义与边界

**为什么毫秒重要**：神经元的信号传递以毫秒为基本单位——动作电位持续约 1 ms，突触后电位的整合常数为数毫秒至数十毫秒。因此任何"哪一步先发生"的问题，都只能在毫秒尺度上提出。

**边界**：

- **下方边界**：更快的离子通道门控过程需要膜片钳等直接电学方法，群体手段无法触及。
- **上方边界**：超过约 1 s 的过程属于[[秒级过程]]，其组织原则（累积、状态切换）不同于毫秒级事件。
- **观测边界**：EEG/MEG 可覆盖全脑的毫秒级场电位，但其空间归属依赖[[源定位]]；单细胞记录时间精确但空间极小。

**关键约定**：毫秒尺度上讨论的"时间"通常是**相对时间**（相对于刺激或反应），而不是绝对时钟时间。对齐点选择本身参与结论。

## 在这个尺度上能观测什么

- **事件时刻与潜伏期**：刺激到响应的延迟，以及不同通道、不同区域之间的相对延迟。
- **振荡的相位与周期**：群体节律的瞬时相位、相位重置、跨频耦合。
- **放电序列**：细胞的时序放电模式、重复序列、与行为时刻的锁定。
- **传播方向候选**：若时间精度与空间覆盖同时足够，可观察到跨区域的时序梯度。
- **刺激时序的因果检验**：在特定相位施加扰动并观察后果，是把时间关系转化为因果关系的核心手段。

**能力陈述**：电生理手段原理上可以记录毫秒级事件；能否观测到，取决于采样率、信噪比与实验设计。

## 不可观测什么

- **fMRI 看不到毫秒**：血流动力学响应的时间常数在秒级，一个采样点内的事件序列不可恢复；不做反卷积时，时间信息只剩相对顺序。
- **不能从头皮信号直接读出脑内时刻**：容积传导使所有电极几乎同时接收到同一源，测得的零延迟不等于脑内零延迟。
- **不能仅凭时序确定方向**：先后出现是因果的必要条件而非充分条件；共同输入、滤波延迟与重采样都能制造时序假象。
- **不能观测未采样区域**：某区域的时间信息若未被覆盖，其参与顺序无法推断。
- **不能由放电序列读出"内容"**：序列本身不携带可读的心理内容，见[[神经元]]。
- **离体数据的时序不可直接外推**：离体与麻醉条件下网络状态改变，振荡与延迟可能不同。

## 典型测量手段

| 手段 | 采样 | 该尺度上的角色 |
| --- | --- | --- |
| 单细胞/多细胞电生理 | 20—40 kHz | 精确时刻，覆盖小 |
| 高密度探针 | 20—30 kHz | 局部群体的时序 |
| EEG | 250—2000 Hz | 全脑毫秒动态，空间模糊 |
| MEG | 1000—2000 Hz | 同上，受磁屏蔽限制 |
| iEEG / ECoG | 500—2000 Hz | 时空兼顾，临床机会性 |
| 钙成像 | 10—30 Hz | 时间被钙动力学平滑，难以测单次放电 |
| 眼动/行为 | 60—1000 Hz | 毫秒级输出，需推断到神经层面 |

## 与相邻尺度的衔接

- **毫秒 → 秒**：需要把瞬时事件与慢信号联系起来的模型（如血流动力学响应函数）。该模型是假设，不是测量。
- **毫秒 → 分钟以上**：跨度极大，通常通过状态变量（觉醒、注意）而不是通过逐事件追踪来连接。
- **细胞 → 全脑**：需要同时具备时间精度与空间覆盖的数据，一般通过跨模态拼接逼近，见[[跨尺度整合]]。

## 跨尺度推断的陷阱

- **采样率不足造成混叠**：高频活动被折叠为低频假象，看起来像慢振荡。
- **滤波决定可见内容**：报告"某频段差异"前，须说明滤波与基线处理，见[[分析一致性原则]]。
- **相位—振幅耦合的假阳性**：跨频耦合指标对滤波、波形形状与信噪比高度敏感，非正弦波形可伪造耦合。
- **事件对齐偏差**：对齐点（刺激标记、反应检测算法）的系统性偏差会伪造潜伏期差异。
- **潜伏期差异被读作"处理阶段"**：潜伏期不同可能来自传导距离、纤维粗细或信噪比，而非认知阶段。
- **把振荡读作机制**：振荡是描述性结构，把它等同于某种计算（如"通信窗口"）需要独立证据。
- **单试次（single-trial）分析的陷阱**：试次数少时的单试次估计噪声很大，需明确信噪比与正则化。
