# 时间尺度

> 时间尺度指一个过程完成一轮变化所需的时长，以及观测手段在时间上可以分辨到多细；它决定了"哪类过程在这套数据里是可见的"。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 与时间层级部分耦合；慢过程通常需要更广的空间取样 |
| 时间尺度 | 毫秒 → 秒 → 分钟 → 小时 → 天 → 发育 → 老化 |
| 相关模态 | 电生理、血流代谢、行为眼动、生理化学、结构扩散 |
| 相关现象 | 感知、运动控制、注意、学习与记忆、发展、临床 |
| 相关结构 | [[大尺度网络]]、[[神经递质系统]]、[[皮层下结构]] |
| 主要方法 | [[时频分析]]、[[事件相关分析]]、[[有效连接与因果建模]] |
| 证据类型 | [[时间动态证据]]为主，慢变过程依赖[[结构证据]]与纵向设计 |

## 定义与边界

时间尺度有两个含义，必须分开：

- **过程的固有时间常数（time constant）**：现象本身持续多久。膜电位约在毫秒级，血流动力学响应在秒级，突触与受体的调节可达分钟至小时，发育与老化以年计。
- **观测的采样能力（sampling）**：手段能以多快的速率、多长的时间窗记录。采样率不足会把快过程平均掉；记录时长不足则看不到慢过程。

**层级的操作性定义**：

| 层级 | 典型范围 | 该层级常见的过程 | 主要观测手段 |
| --- | --- | --- | --- |
| 毫秒 | 1—100 ms | 动作电位、突触后电位、局部场电位振荡周期 | 电生理、MEG |
| 秒 | 0.1—10 s | 血流动力学响应、诱发电位成分、行为反应时 | fMRI、EEG/MEG、眼动 |
| 分钟 | 1—60 min | 觉醒水平波动、注意状态漂移、药物起效 | 静息态分段、生理监测 |
| 小时 | 1—24 h | 昼夜节律、突触稳态调节、疲劳 | 长时间监测、生化取样 |
| 天 | 数日—数月 | 学习巩固、习惯化、情绪波动 | 日记法、纵向取样 |
| 发育 | 月至数十年 | 髓鞘化、网络成熟、突触修剪 | 纵向结构像、队列 |
| 老化 | 数十年 | 灰质体积变化、白质完整性下降 | 队列、横断设计 |

## 在这个尺度上能观测什么

- **毫秒**：单个细胞的放电时刻、群体振荡的相位、刺激到响应之间的潜伏期。这是[[毫秒动态]]的主场，也是少数可以直接观察"顺序"的尺度。
- **秒**：一个刺激或一个反应所对应的整体状态变化。成像的血流动力学响应在这个尺度上成形；行为反应也在这个尺度上给出可测的输出。
- **分钟与小时**：状态变量。同一被试在扫描前后半段的数据可以分属不同状态，这不是噪声而是信号。
- **天与更长**：变化的方向性。只有跨时间点重复测量，才能把"差异"读成"变化"。

**能力陈述**：时间分辨率与空间分辨率在非侵入手段上通常互相牺牲；同时覆盖宽频段与长时段的手段目前不存在。

## 不可观测什么

- **慢过程无法用快手段的短记录推断**：一次 10 分钟的扫描记录不到发育或昼夜节律；把单次采样当作个体的稳定属性，需要额外的信度证据。
- **快过程在慢手段中被平均**：fMRI 的一个采样点（通常秒级）内的神经事件序列不可恢复；不做反卷积时，时间信息只有相对顺序而非绝对时序。
- **时间窗即分析假设**：任何"某窗口内活动升高"的结论都依赖窗口的选择。同一数据换一个窗口，结论可能变化。这是[[分析一致性原则]]关注的核心问题之一。
- **不能从相关推断方向**：两个信号在时间上先后出现，不足以确定因果方向；先后关系受血流延迟、滤波、重采样影响。见[[有效连接与因果建模]]。
- **无绝对时钟**：多数人类数据以刺激或反应为对齐点，跨被试对齐依赖事件标记的准确性；标记错误会系统性地伪造时序差异。
- **老化与发育的个体差异不能由横断数据推出**：横断设计的组间差异混杂着世代效应与选择效应，不等于个体内部的时间变化。

## 典型测量手段

| 手段 | 采样率/时间窗量级 | 在该尺度上的角色 |
| --- | --- | --- |
| 单细胞/多细胞电生理 | 数十 kHz | 毫秒以下事件的直接测量 |
| EEG / MEG | 数百—数千 Hz | 全脑毫秒级电位或磁场 |
| iEEG / ECoG | 数百—数千 Hz | 临床机会性、时空兼顾 |
| 钙成像 | 数—数十 Hz | 细胞级但时间被钙动力学平滑 |
| fMRI | 0.5—3 s | 秒级、间接、依赖血流耦合 |
| PET | 数十秒—分钟 | 分钟级代谢或受体 |
| 眼动 / 行为 | 数十—数千 Hz | 毫秒级输出，但需推断到神经层面 |
| 生化取样 | 分钟—小时 | 激素、递质代谢物 |
| 纵向队列 | 月—年 | 发育与老化 |

## 与相邻尺度的衔接

- **毫秒 → 秒**：需要动力学模型或反卷积把瞬时神经事件映射到慢信号；这一步引入的血流耦合假设是主要不确定性来源。
- **秒 → 分钟**：需要状态划分。把长记录切分成"状态"通常是数据驱动的，切分方式会改变结果。
- **分钟 → 小时**：需要连续监测或重复取样，跨天的推论要求采样密度足以覆盖周期。
- **小时 → 天**：需要节律模型；缺少昼夜标记的长时间记录容易被节律混入。
- **天 → 发育/老化**：需要纵向设计。同一批被试的重复测量与不同批被试的横断比较，支持的结论强度不同。

## 跨尺度推断的陷阱

- **用快手段的结论解释慢现象**：把毫秒级机制直接推广为"某认知功能的机制"，缺一个把时间尺度对应起来的论证。
- **用慢手段的结论指认快过程**：秒级成像差异不能指认某个振荡或某个放电模式。
- **采样率混叠（aliasing）**：低于奈奎斯特频率的采样会把快过程折叠成低频假象，看起来像慢振荡。
- **滤波即结论**：对数据施加的带通滤波决定了能看到哪个频段；滤波后报告的"频段差异"部分是滤波器的性质。
- **窗口选择自由度过大**：在多个候选时间窗中挑选最显著的，等价于增加比较次数。见[[统计推断与多重比较]]。
- **把时间上的共变当作序列因果**：需要保留刺激时序、控制延迟，并用独立数据检验。
