# 秒级过程

> 秒级过程指以数百毫秒到数秒为单位展开的神经与行为事件；它既是血流动力学响应的固有时间常数，也是绝大多数实验任务的时间单位。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 脑区—全脑（该尺度的主导手段决定了这一点） |
| 时间尺度 | ~0.1—10 s |
| 相关模态 | 血流代谢、行为眼动、电生理（作为对齐参考） |
| 相关现象 | 感知、注意、决策与奖赏、语言、情绪与应激 |
| 相关结构 | [[皮层分区]]、[[大尺度网络]]、[[皮层下结构]] |
| 主要方法 | [[事件相关分析]]、[[有效连接与因果建模]]、[[实验设计与范式]] |
| 证据类型 | [[功能关联证据]]、[[时间动态证据]] |

## 定义与边界

**为什么秒级成为默认单位**：任务设计与观测手段在这里交汇。

- **生理侧**：血流动力学响应（hemodynamic response）从刺激到峰值约需数秒，全形持续十余秒。这是成像手段的时间下限。
- **行为侧**：简单刺激—反应任务的反应时集中在数百毫秒；一个试次（trial）通常持续一至数秒。
- **设计侧**：试次是可控的最小实验单位，条件分配、随机化与对照都在这一层实现。

**边界**：秒级是成像与行为共同可及的尺度，因此绝大多数"任务激活"结论生活在这一层。低于此层的事件被平均，高于此层的过程（如疲劳、学习）在单个试次中表现为漂移而非效应。

## 在这个尺度上能观测什么

- **条件间的信号差异**：某条件相对对照的平均信号变化，通常以区域或体素为单位报告。
- **诱发电位的晚期成分**：电生理中与认知过程相关的成分多落在数百毫秒量级。
- **行为指标**：反应时、正确率、眼动指标、决策选择。
- **试次级波动**：单试次信号与单试次行为的关系（试次级分析）。
- **试次序列效应**：前一试次对当前试次的影响（适应、启动、切换代价）。
- **状态的短时波动**：注意漂移、困倦在数秒至数十秒尺度上的影响。

**证据陈述**：多项研究提示条件相关的秒级信号差异在群体水平可稳定检出；其解释依赖设计对照是否排除了低层感觉、运动与预期混淆。

## 不可观测什么

- **看不到毫秒事件**：一个采样点内的神经时序不可恢复；报告"在 X 时刻活动升高"实际指"在该秒级窗口内平均升高"。
- **不能观测"心理过程本身"**：条件差异是信号差异，把它等同于某个认知操作（如"冲突解决"）属解释性命名。
- **不能由单试次信号推断单次心理事件**：单试次的信噪比通常很低，个体试次层面的推断需要明确信噪比证据。
- **不能观测未设计进任务的过程**：任务未操纵的过程若与条件相关，会与目标过程混在一起，无法事后分离。
- **不能由延迟差异推断处理阶段**：峰值延迟受血管、信噪比、基线影响。
- **不能忽略漂移**：扫描中的慢漂移与状态变化会在秒级信号上叠加低频成分，未建模时被读成任务效应。
- **不能把反应时差异读作"难度"**：反应时受策略、速度—准确率权衡与运动准备影响。

## 典型测量手段

| 手段 | 时间单位 | 该尺度上的角色 |
| --- | --- | --- |
| fMRI | 0.5—3 s | 主力手段，间接测量 |
| 事件相关电位（ERP） | 毫秒采样、秒级成分 | 时间精确，空间模糊 |
| 眼动与行为记录 | 毫秒级采样 | 可精确对齐行为事件 |
| 皮电、瞳孔、心率 | 数十—数百 Hz | 外周生理指标 |
| 试次级建模 | 依赖设计 | 把单试次行为作为回归量 |

## 与相邻尺度的衔接

- **毫秒 → 秒**：需要反卷积或前瞻模型；这一步把瞬时神经事件映射到慢信号，所引入的血流耦合假设是主要不确定性来源。见[[毫秒动态]]。
- **秒 → 分钟**：需要显式建模漂移与状态变量；把整段扫描当作恒定状态是常见简化。
- **秒 → 天以上**：需要纵向设计，见[[发育与老化]]。
- **行为 → 神经**：需要把行为指标作为回归量或分层变量纳入模型，而不是事后解释。

## 跨尺度推断的陷阱

- **反卷积的有色噪声问题**：不做反卷积时，快速事件序列会与慢响应混淆，估计出的时序不可靠。
- **时间窗与基线的自由度**：窗口与基线期选择可改变结论；应预先声明并做敏感性分析，见[[分析一致性原则]]。
- **模型假设即结论**：一般线性模型（general linear model, GLM）的回归量形式决定了"发现"的形式；设计矩阵中的假设常被忽略。
- **把试次当独立**：时间自相关与试次顺序效应使独立性假设失效，需在统计模型中处理，见[[统计推断与多重比较]]。
- **心率与呼吸的混入**：秒级生理波动与任务时序相关时会产生假效应。
- **条件比较的低层混淆**：条件间若在感觉输入、运动输出或注视位置上不同，差异不能归因于目标认知过程。
- **圆形设计**：用同一数据既定义感兴趣区又检验条件差异，会系统性高估效应。
