# 个体间与群体

> 群体层级把观测单位从单个脑扩展到多个个体；它的核心问题不是"记录更多脑"，而是"凭什么认为不同脑的数据可以放在一起比较"。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | >1 m（跨个体），以单脑为单位求和或对齐 |
| 时间尺度 | 天—年（个体差异与纵向），被试内可达毫秒 |
| 相关模态 | 多人、血流代谢、结构扩散、行为眼动 |
| 相关现象 | 社会认知、发展、临床与病理、语言 |
| 相关结构 | [[大尺度网络]]、[[皮层分区]]、[[皮层下结构]] |
| 主要方法 | [[统计推断与多重比较]]、[[质控与可重复性]]、[[功能连接]] |
| 证据类型 | 一致性类证据；因果需[[因果干预证据]] |

## 定义与边界

这个层级包含三类本质上不同的问题：

| 问题类型 | 比较对象 | 推断目标 |
| --- | --- | --- |
| 群体共性 | 个体之间求平均 | 人类（或某群体）的一般规律 |
| 个体差异 | 个体之间求相关 | 脑指标与行为或特质的关联 |
| 个体内变化 | 同一个体不同时间点 | 发展、学习、状态的纵向变化 |

**边界条件**：

- **共同坐标**：跨个体比较要求把不同形状的脑映射到共同空间，配准误差会成为组间差异的一部分。
- **抽样代表性**：群体结论的适用范围由抽样框决定，而不是由样本量决定。
- **被试内与组间不可互换**：组间差异不等于个体内部变化；横断设计的组间差异混杂世代效应与选择效应。

**多人同时测量**是这一层级的特殊情形：它同时要求个体内配准（同一被试内）与跨个体配准（被试之间），假设更多，见[[多人同步记录]]。

## 在这个尺度上能观测什么

- **群体平均效应**：在足够样本下估计某条件相对某基线的平均差异。
- **效应量的分布**：不仅是均值，还有个体间离散程度；后者常比均值更有信息量。
- **个体差异的关联**：脑指标与行为、特质、临床评分之间的统计关系。
- **组间比较**：不同群体（年龄组、临床组、文化组）之间的指标差异。
- **跨个体一致性**：多个体的反应模式是否在时间、空间或表征上对齐。
- **群体水平的可重复性**：同一效应在不同样本或不同站点上是否复现。

**证据陈述**：多项研究提示多数群体水平的脑—行为关联效应量偏小，报告效应量、置信区间与预注册对解读是必要的。

## 不可观测什么

- **不能由组间差异推断个体**：群体统计量不描述任何特定个体，个体预测需要个体水平的信度证据。
- **不能由相关推断因果**：脑指标与行为的相关可由第三变量、反向因果或选择效应产生。
- **不能由群体平均推断普遍性**：平均效应可能由少数个体驱动；需检查分布而非只看均值。
- **不能观测"社会互动"本身**：多人同步记录得到的是每个个体各自的信号及其统计关系，社会过程是解释，不是测量。
- **不能把同步等同于沟通**：跨个体信号同步可来自共同刺激、共同任务节奏或共同环境，见[[实时的神经同步]]。
- **低信度指标不支持个体差异研究**：测量信度不足时，个体差异关联会被系统性衰减，见[[质控与可重复性]]。
- **不能忽略文化、语言与任务理解差异**：同一范式的意义在不同群体中可能不同。

## 典型测量手段

| 手段 | 测什么 | 主要局限 |
| --- | --- | --- |
| 群体成像研究 | 群体平均效应与组间差异 | 配准误差、头动、多重比较 |
| 纵向队列 | 个体内变化的轨迹 | 脱落偏倚、测量漂移 |
| 大样本队列 | 个体差异的稳定关联 | 效应量小，任务简化 |
| 多人同步记录 | 跨个体信号关系 | 运动与生理伪迹、假设多 |
| 行为与眼动分组 | 群体层面的输出指标 | 到神经层面的推断是间接的 |
| 元分析与多站点 | 跨样本可重复性 | 发表偏倚、异质性 |

## 与相邻尺度的衔接

- **全脑 → 群体**：需要共同空间、配准与群体统计模型；对齐程序本身是假设，见[[全脑]]。
- **群体 → 个体**：从群体关联回到个体预测，需要个体水平的信度与独立样本验证。
- **群体 → 社会互动**：从跨个体统计关系推到互动机制，需要额外的因果或行为操纵证据。

## 跨尺度推断的陷阱

- **生态学谬误（ecological fallacy）**：群体层面的关联不能套用到个体层面。
- **选择偏倚**：便利样本（学生、志愿者、临床就诊者）使结论的适用范围远小于叙述所暗示的范围。
- **头动与生理噪声的组间差异**：临床组、儿童、老年人常运动更多，头动与连接差异相关，需严格控制才能比较。见[[预处理与伪迹控制]]。
- **双重 dipping（double dipping）**：用同一数据选择特征又检验关联，会放大效应，见[[解码与机器学习]]。
- **多重比较与研究者自由度**：分析选择空间大时，显著结果容易来自选择而非效应。见[[统计推断与多重比较]]。
- **把同步读作共情或理解**：跨个体同步的强弱与互动质量的关系是提示性的，方向与机制未定。
- **个体差异的可塑性解释**：横断差异被写成"训练导致"或"经验塑造"，需要纵向或干预证据。
