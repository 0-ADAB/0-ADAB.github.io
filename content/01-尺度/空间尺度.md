# 空间尺度

> 空间尺度指一次观测所覆盖的空间单位，以及在这个单位内所能分辨的最小结构；它决定了"什么问题在这个手段上是可问的"。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 分子（10⁻¹⁰ m）→ 群体（跨个体，>1 m） |
| 时间尺度 | 与空间层级强耦合：越小的层级通常对应越快的动态，但并非严格对应 |
| 相关模态 | 电生理、血流代谢、结构扩散、分子遗传、调控 |
| 相关现象 | 全部现象（同一现象可在多个层级上被追问） |
| 相关结构 | [[皮层分区]]、[[皮层下结构]]、[[大尺度网络]]、[[神经递质系统]] |
| 主要方法 | [[多模态融合]]、[[功能连接]]、[[源定位]] |
| 证据类型 | 各层级产出不同证据；跨层级推断属于边界问题 |

## 定义与边界

空间尺度由两个彼此独立、又经常被混淆的量共同决定：

- **采样单位（sampling unit）**：一个数据点代表多大的一块组织。体素（voxel）代表毫米级组织块，电极代表电极—组织界面的电流加权和，单个细胞则代表一个膜电位系统。
- **分辨精度（resolution）**：在采样单位之内，多小的结构差异还能被区分。同一采样单位可以有不同的分辨精度（例如体素 2 mm 的功能像对亚毫米层状结构无分辨力）。

**层级的操作性定义**（数量级为公认的结构尺度，不是某次测量结果）：

| 层级 | 典型空间范围 | 层级成立的条件 |
| --- | --- | --- |
| 分子 | 10⁻¹⁰—10⁻⁸ m | 分子种类与浓度可被区分 |
| 突触 | 10⁻⁷—10⁻⁶ m | 能定位到单个连接位点 |
| 神经元 | 10⁻⁵—10⁻⁴ m | 信号可归属到单个细胞的输出 |
| 回路 | 10⁻⁴—10⁻³ m | 能在同一时间窗内比较多个细胞的相互关系 |
| 脑区 | 10⁻³—10⁻² m | 有可复现的解剖或功能边界 |
| 网络 | 10⁻²—10⁻¹ m | 多个脑区间存在可测的统计依赖 |
| 全脑 | 10⁻¹ m | 覆盖全部灰质或全皮层 |
| 群体 | >1 m（跨个体） | 多个个体的数据可被对齐到共同坐标 |

## 在这个尺度上能观测什么

- **分子 / 突触**：分子种类、表达水平、连接位点的形态与位置。属于[[结构证据]]的强项。
- **神经元**：单个细胞的放电时刻与序列、胞体—树突的信号整合、细胞类型归属。
- **回路**：局部群体内的兴奋—抑制平衡、细胞间的时序关系、投射方向。这是[[因果干预证据]]最常被构造的层级。
- **脑区**：区域水平的活动强度、区域水平的灰质形态、区域间的投射。区域是成像研究与临床语言中最通用的公共货币。
- **网络**：区域之间的统计依赖结构、图论指标、网络在不同状态下的重组。
- **全脑 / 群体**：整体拓扑、跨个体一致性与个体差异分布。

**能力陈述**：每一个层级都至少存在一种原理上可用的测量方式；层级越高，覆盖越完整而分辨越粗，层级越低则相反。

## 不可观测什么

- **视场—分辨率的权衡**：任何单一手段都无法同时在细胞级分辨下覆盖全脑。想两者兼得，只能靠多次取样、跨模态拼接或插值，而拼接本身引入假设。
- **低层级的动态覆盖不到全域**：单细胞记录可以精确到毫秒，但只能覆盖极小体积；由此得到的"普遍规律"未必在未采样区域成立。
- **高层级分辨率不足以指认机制**：毫米级体素的信号差异不能被解释为"某类神经元的活动变化"，因为体素是数万至数百万细胞的加权和，权重未知。
- **无活动的结构层级**：结构像与扩散像测的是形态与弥散属性，不测活动；在下述页面中它们属于结构而非功能证据，见[[结构与扩散成像]]。
- **图谱边界不是功能边界**：任何分区图谱都是人为约定的划分，见[[皮层分区]]。跨图谱比较时，同一坐标可能落在不同分区，这种差异是测量约定的差异，不是发现。
- **覆盖不等于尺度**：全脑覆盖只说明观测范围，不说明观测精度；不要把"全脑"读作"高分辨率地看到了全部"。

## 典型测量手段

| 层级 | 常用手段 | 该手段实际测的物理量 |
| --- | --- | --- |
| 分子 | 单细胞测序、质谱、免疫组化 | 分子丰度，非活动 |
| 突触 | 电镜、双光子、膜片钳、突触追踪 | 形态、电流、连接关系 |
| 神经元 | 单细胞/多细胞电生理、钙成像、单元聚类 | 电活动或钙信号代理 |
| 回路 | 高密度电极、iEEG/ECoG、光遗传与化学遗传 | 群体电活动、干预效果 |
| 脑区 | fMRI、PET、源定位、病损、图谱配准 | 血流代谢代理、电流源、结构 |
| 网络 | 功能连接、扩散成像纤维追踪、图论 | 统计依赖、白质几何 |
| 全脑 | 全脑成像、连接组、全脑建模 | 覆盖性结构或功能描述 |
| 群体 | 多人同步、队列、元分析 | 个体间一致性与差异 |

## 与相邻尺度的衔接

衔接不是自动的，每一处跨越都需要一条独立论证：

- **分子 → 突触**：需要形态学对应，说明分子位于该连接位点上（免疫电镜一类）。
- **突触 → 神经元**：需要电生理或因果干预，说明该突触的权重变化改变了细胞输出。
- **神经元 → 回路**：需要同一时间窗内的多细胞同步记录，否则只是把若干单细胞结果并置。
- **回路 → 脑区**：需要投射追踪或层状记录，说明局部回路与区域整体输入输出一致。
- **脑区 → 网络**：需要连接矩阵及其阈值假设；不同阈值会给出不同的网络。
- **网络 → 全脑**：需要覆盖性检查，说明未包含的区域不会改变结论。
- **全脑 → 群体**：需要共同坐标与对齐程序，跨个体的对应本身是假设。

## 跨尺度推断的陷阱

- **向上推断（微观 → 宏观）**：微观机制不能直接推广。成像信号是群体加权和，权重取决于细胞类型、几何与血管耦合，通常未知。
- **向下推断（宏观 → 微观）**：区域激活差异不能等同于某类神经元放电改变，也不能等同于突触可塑性。
- **尺度置换**：把"某手段在某个尺度上有效"读成"该手段在所有尺度上都有效"，是最常见的越界。见[[解释边界与常见错误]]。
- **跨物种尺度差异**：动物模型可做到细胞级，但其皮层几何、细胞类型比例与认知任务均与人类不可直接对应。
- **单位混合**：把空间单位（体素、电极、聚类单元、图谱分区）当作同一类实体比较，是大量"同一区域被两种手段激活"误读的来源。系统讨论见[[跨尺度整合]]。
