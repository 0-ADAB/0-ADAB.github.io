# 网络

> 网络不是解剖实体，而是把若干区域及其相互关系表示为一个图之后的描述层级；节点与边的定义方式本身参与结论。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 10⁻²—10⁻¹ m（跨区域、单侧或全脑范围） |
| 时间尺度 | 秒—分钟（连接估计所需的时间窗） |
| 相关模态 | 血流代谢、电生理、结构扩散 |
| 相关现象 | 注意、学习与记忆、语言、意识与睡眠、临床与病理 |
| 相关结构 | [[大尺度网络]]、[[皮层分区]]、[[皮层下结构]] |
| 主要方法 | [[功能连接]]、[[有效连接与因果建模]]、[[统计推断与多重比较]] |
| 证据类型 | [[功能关联证据]]为主；[[结构证据]]为骨架 |

## 定义与边界

**网络的三个构成要素**，缺一不可，且都可被不同选择改变：

| 要素 | 可选定义 | 影响 |
| --- | --- | --- |
| 节点（node） | 体素、图谱分区、独立成分、电极 | 改变网络规模与拓扑指标 |
| 边（edge） | 相关、偏相关、相干、因果模型、纤维数 | 改变"连接"的含义 |
| 阈值 | 绝对阈值、比例阈值、加权不阈值 | 稀疏化后拓扑指标大幅变化 |

**三类"连接"必须区分**：

- **结构连接（structural connectivity）**：白质通路或突触关系，物理存在。
- **功能连接（functional connectivity）**：时间序列之间的统计依赖，无方向。
- **有效连接（effective connectivity）**：有方向的、通常依赖模型的影响关系。

三者相关但不互相替代。功能连接可以反映共同输入、共同调质或瞬时耦合，而不必有直接解剖连接。

**边界**：网络层级依赖一个整体时间窗。窗内状态若发生变化，估计出的"连接"是两种状态的混合，这类混合无法通过后续分析还原。

## 在这个尺度上能观测什么

- **统计依赖结构**：哪些区域的时间序列彼此相关，相关强度随条件或状态如何变化。
- **候选的拓扑性质**：模块化、枢纽节点、路径长度、聚类系数。这些量在定义了节点、边与阈值之后才存在。
- **状态相关的重组**：同一批节点在不同任务、不同觉醒水平下的连接模式差异。
- **有方向的候选影响**：在模型假设成立时，估计区域间的定向影响。
- **结构骨架**：由扩散成像得到的白质通路，作为功能连接的可能基底。

**证据陈述**：多项研究提示网络的连接模式与觉醒水平、任务状态、以及若干临床分组存在统计关联；这类关联是群体与条件层面的，个体层面推断需要额外的信度证据。

## 不可观测什么

- **不能由功能连接推出解剖通路**：相关不蕴含直接的解剖连接，中间节点与共同输入都能产生相关。
- **不能由结构连接推出功能耦合**：存在通路不等于在任务中被使用；多突触间接通路使直接与间接影响难以分离。
- **不能观测"信息流动"**：图论指标描述的是拓扑性质，"信息"与"沟通"是解释性用语，见[[有效连接与因果建模]]。
- **不能观测网络内部的细胞机制**：网络层不指认细胞类型、层或突触事件。
- **不能由单次扫描确定个体的稳定网络**：短时间窗连接的估计稳定性有限，个体差异推断需要信度证据，见[[质控与可重复性]]。
- **不能区分状态与特质**：静息态连接差异可能来自瞬时状态（困倦、注意力漂移），扫描中不做状态监测时无法分开。

## 典型测量手段

| 手段 | 连接含义 | 主要局限 |
| --- | --- | --- |
| 静息态 fMRI | 低频波动的统计依赖 | 时间分辨率低，生理噪声混入 |
| 任务态 fMRI | 条件相关耦合 | 任务设计限制时间窗 |
| EEG / MEG 相干与相位 | 频段特异的依赖 | 容积传导导致虚假相干 |
| iEEG | 区域间直接电耦合 | 临床机会性，覆盖偏 |
| 扩散 MRI 纤维追踪 | 白质通路 | 交叉纤维与分辨率限制 |
| 图论分析 | 拓扑描述子 | 结果依赖节点/边/阈值选择 |

## 与相邻尺度的衔接

- **脑区 → 网络**：需要明确节点定义与阈值，并做敏感性分析说明结论不依赖于某个特定选择。
- **网络 → 全脑**：网络通常已经是全脑范围的，改换的是覆盖完整性与节点粒度；把节点粒度当尺度混淆是常见问题。
- **网络 → 行为**：需要把连接指标与行为或状态联合建模，并控制时间窗与状态混杂。
- **网络 → 回路**：需要区域间同时的细胞级记录，目前只在少数物种与少数区域对之间可行。

## 跨尺度推断的陷阱

- **阈值即结论**：拓扑指标对阈值高度敏感，报告时应给出多阈值结果。见[[分析一致性原则]]。
- **节点数决定比较**：不同研究的节点数不同，直接比较"网络效率"等指标没有意义。
- **容积传导与场扩散**：头皮与颅内信号的空间扩散会制造零延迟的高相关，"强连接"可能是同一源的泄漏。
- **全局信号（global signal）争议**：是否回归全局信号会系统性改变功能连接结果，两种做法都影响解释。
- **状态拼接**：把不同警觉状态的时段合并估计连接，会得到两类模式的混合，见[[慢变状态]]。
- **把网络标签实体化**：默认模式网络一类的命名来自统计聚类，把它当作固定的解剖对象会掩盖其组成随分析而变化的事实。
- **临床分组的过度解释**：组间连接差异可能来自头动、生理噪声、药物或扫描时长差异，需先行控制。
