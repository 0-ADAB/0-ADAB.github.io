# 尺度

> 尺度不是分类标签，而是**观测能力的边界**。同一个现象在不同尺度上是不同的问题，需要不同的测量手段，产出不同类型的证据。

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 分子 → 群体（全部层级） |
| 时间尺度 | 毫秒 → 老化（全部层级） |
| 相关模态 | 全部模态 |
| 相关现象 | 全部现象 |
| 主要方法 | 跨尺度整合、多模态融合 |

## 空间与时间的耦合

这两个维度不是独立的。每一种测量手段都占据"空间 × 时间"平面上的一个区域：

| 手段 | 空间 | 时间 | 位置特征 |
| --- | --- | --- | --- |
| 单细胞记录 | 单细胞 | 亚毫秒 | 空间最精、时间最精，覆盖最小 |
| 钙成像 | 细胞群 | 百毫秒—秒 | 兼顾细胞与群体 |
| EEG / MEG | 全脑（源定位受限） | 毫秒 | 时间最精，空间模糊 |
| iEEG / ECoG | 局部到全脑 | 毫秒 | 临床机会性取样 |
| fMRI | 毫米—厘米 | 秒 | 空间较好，时间慢 |
| 结构 / 扩散 MRI | 毫米 | 静态 | 不直接反映活动 |
| 行为 / 眼动 | 外周指标 | 毫秒—秒 | 需要推断到神经层面 |

**关键限制**：空间精度与时间精度在非侵入手段上往往互相牺牲。因此"某脑区在某个毫秒发生了什么"这类问题，通常只能通过跨模态互补来逼近，而不能由单一手段直接回答。

## 跨尺度推断的陷阱

- **向上推断（微观→宏观）**：单细胞层面的机制不能直接推广到全脑成像信号；成像信号是大量神经元群体的加权和。
- **向下推断（宏观→微观）**：fMRI 激活差异不能等同于某类神经元的放电变化。
- **跨物种推断**：动物模型的空间尺度往往更细，但认知任务与人类不可比。
- **跨模态推断**：不同模态测量的是不同物理量，"同一脑区同时被两种手段激活"不等于"两种信号反映同一过程"。
