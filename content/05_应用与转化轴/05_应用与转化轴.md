# 应用与转化

> **脑科学知识如何进入临床、技术与社会？**

## 转化地图

| 方向 | 典型主题 |
| --- | --- |
| 临床转化 | 诊断、生物标志物、疾病分层、药物、神经调控、康复 |
| 神经技术 | 脑机接口、神经信号解码、闭环反馈 |
| 伦理与社会 | 神经隐私、认知增强、责任归属、认知自由 |
| 法律与政策 | 数据治理、神经权利、监管与公平性 |

## 评价应用的三道问题

**能不能做？** 明确技术可行性、适用条件和失效场景。

**有没有效？** 核对对照、终点指标、效应大小、长期随访、独立验证和人群差异。

**应不应该做？** 评价副作用、隐私、知情同意、伦理、法律与公平性。

## 证据等级与成熟度

概念验证、初步研究、临床验证和常规实践必须明确区分。临床推荐不得直接由动物模型或单项机制研究推出。
