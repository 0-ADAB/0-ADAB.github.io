# 帕金森病的深部脑刺激

> **一句话介绍：** 深部脑刺激（DBS）通过植入电极对丘脑底核（STN）或苍白球内侧部（GPi）持续施加高频电刺激，用于最佳药物治疗仍出现显著运动并发症的帕金森病患者；它能改善运动症状与生活质量，但不阻断疾病本身的进展。

## 快速理解

- **适用对象：** 最佳药物治疗下仍有严重运动波动、异动症或难治性震颤的中晚期帕金森病患者。国际专家共识提出的候选条件是：无显著活动性认知障碍或精神疾病、存在药物难以控制的运动波动或震颤、对药物副作用不耐受 (Bronstein et al., 2011, Arch Neurol)。
- **年龄不是绝对限制：** 在含 25% 七十岁以上患者的随机试验中，老年患者同样获益，但风险与获益需单独权衡 (Weaver et al., 2009, JAMA)。
- **早期干预的讨论：** 在运动并发症刚出现（平均病程 7.5 年）的阶段进行刺激也显示生活质量获益 (Schuepbach et al., 2013, N Engl J Med)，但这是特定临床试验条件下的结论，不等于所有早期患者都应手术。
- **务必克制地理解效果：** DBS 是症状控制手段，不是治愈；所有获益都发生在"刺激开启"状态下，疾病本身的进展（尤其轴向症状与认知）会继续。

## 科学依据与关键前提

**基础研究支持的机制链条。** 帕金森病模型的核心发现是 STN 神经元活动过度：在 MPTP 帕金森样猴中，Bergman 等（1990，Science）证明损毁 STN 可逆转对侧肢体的运动减少、僵直与震颤，支持"STN 过度活动导致帕金森样运动障碍"的假说。既然不可逆的损毁有效，可逆、可调节的高频刺激便成为替代思路——Benabid 等（1991，Lancet）先在丘脑腹中间核（Vim）证明 43 个刺激侧中 88% 的震颤获得完全或显著缓解且副作用轻微，为慢性植入刺激奠定了临床可行性与安全性基础。

**高频刺激做了什么，仍有争议。** 大鼠记录显示，130 Hz 刺激 STN 使电极附近局部神经元活动净下降，并抑制下游黑质网质部多数神经元、激活丘脑腹外侧核，即"降低 STN 兴奋性谷氨酸输出"（Benazzouz 等（2000，Neuroscience））。但机制解释并未统一：Garcia 等（2005，Trends Neurosci）综合实验证据提出"双重机制"——既关断病理性节律（less），又注入自身具有功能意义的高频规则放电（more）；Perlmutter 与 Mink（2006，Annu Rev Neurosci）在综述中明确指出 DBS 的确切作用机制仍然不确定。计算建模方面，McIntyre 等（2004，Clin Neurophysiol）的有限元模型显示临床常用参数主要激活大直径有髓轴突，且激活体积受脑组织电导率各向异性影响——刺激的效应范围并不局限于核团本身。

**不能外推的部分。** "模型上有效"不等于"临床上改变病程"。机制层面的获益属于症状层面的功能替代；长期队列一致显示，即使运动获益维持，轴向症状（言语、姿势、冻结）与认知仍随时间恶化 (Krack et al., 2003, N Engl J Med; Castrioto et al., 2011, Arch Neurol)。把 DBS 描述为"修复大脑回路从而治愈帕金森病"没有证据支持。

## 实际实施方式

- **流程与资源条件：** 标准路径为多学科评估（运动障碍专科、立体定向神经外科、神经心理）→ 影像与电生理引导下立体定向植入电极 → 术后程控（电压/电流、脉宽、频率、触点选择）→ 逐步下调抗帕金森药物。早期开放试验中，刺激开启 1 年后"关药"状态日常生活与运动评分改善 60%，多巴胺能药物剂量平均减半 (Limousin et al., 1998, N Engl J Med)。
- **监管因素：** 该疗法在美国经历了从震颤到帕金森病的分步批准（1997 年批准 Vim 靶点治疗震颤，2002 年批准用于帕金森病），属处方级植入器械治疗，具体表述以监管文件与综述为准 (Okun, 2012, N Engl J Med)。
- **靶点选择的现状：** STN 与 GPi 是两大主流靶点。多项随机对照试验显示两者运动获益相当：24 个月时运动改善无显著差异 (Follett et al., 2010, N Engl J Med)，36 个月时改善幅度稳定且靶点间相当 (Weaver et al., 2012, Neurology)，荷兰 NSTAPS 试验在功能健康与认知-情绪-行为复合副作用两个主要终点上也未见差异 (Odekerken et al., 2013, Lancet Neurol)。但靶点间的非运动差异存在：STN 刺激所需多巴胺能药物剂量更低，而抑郁在 STN 组恶化、GPi 组改善，视觉运动处理速度在 STN 组下降更多 (Follett et al., 2010, N Engl J Med)。靶点选择应纳入这些非运动因素，而非只看运动症状。
- **共识建议：** 由有立体定向经验的外科医生在多学科团队框架内实施，患者选择、靶点、程控与随访都应有制度保障 (Bronstein et al., 2011, Arch Neurol)。

## 有效性与安全性证据

**随机对照试验（症状与生活质量终点）。** 德国的随机配对试验入组 156 例晚期患者，6 个月时刺激组生活质量（PDQ-39）平均改善 9.5 分、关药状态 UPDRS-III 改善 19.6 分，均优于单纯药物治疗（Deuschl 等（2006，N Engl J Med））。美国退伍军人事务部与大学医院的多中心试验（255 例，含老年层）报告，刺激组"无致残性异动的开期"每日平均多 4.6 小时（组间差 4.5 小时，95% CI 3.7–5.4），71% 的刺激患者取得临床有意义的运动改善（对照组 32%）（Weaver 等（2009，JAMA））。英国 PD SURG 试验（366 例，以患者自报生活质量为主要终点）1 年时手术组 PDQ-39 改善 5.0 分、药物组 0.3 分（组间差 4.7 分，95% CI −7.6 至 −1.8），但 19% 患者发生手术相关严重不良事件，并有 1 例操作相关死亡（Williams 等（2010，Lancet Neurol））。EARLYSTIM 试验（251 例早期运动并发症患者）2 年时 PDQ-39 刺激组改善 7.8 分、药物组恶化 0.2 分（组间差 8.0 分，P=0.002），但刺激组严重不良事件更多（54.8% 对 44.1%），其中 17.7% 与植入手术或器械相关（Schuepbach 等（2013，N Engl J Med））。

**长期随访（获益的边界）。** 格勒诺布尔的 49 例连续病例 5 年随访显示，关药运动功能改善 54%、日常生活改善 49%，异动与药物剂量持续下降；但"开药"状态的运动不能、言语、姿势稳定性与冻结步态在第 1 至第 5 年间恶化，3 例在 3 年后出现痴呆（Krack 等（2003，N Engl J Med））。另一队列 1 年时关药状态 UPDRS 总分较基线降 42%，末次评估仍维持 41% 的改善，但轴向分量仅剩改善趋势 (Kleiner-Fisman et al., 2003, J Neurosurg)。18 例 10 年盲评显示总运动、震颤与运动减慢仍有显著改善，轴向体征则呈进行性下降（Castrioto 等（2011，Arch Neurol））。8 年随访中，基线"关药"疼痛全部改善或消失，但 75% 的患者出现新疼痛（Jung 等（2015，JAMA Neurol））。总体模式一致：**刺激可长期替代多巴胺能药物控制多巴胺反应性症状，但 轴向症状、言语与认知随疾病进展恶化，刺激不改变这一轨迹**。

**认知与精神影响（负结果与风险）。** 与生活质量改善并存的，是可测量的执行功能代价：随机试验 6 个月时，刺激组语义与音位言语流畅、Stroop 任务表现较药物组显著变差（Witt 等（2008，Lancet Neurol））。行为方面，63 例前瞻队列采用术后立即停用多巴胺激动剂、减量左旋多巴的方案，1 年时多巴胺失调综合征（4/4）、行为成瘾（17/17）与强迫性服药（9/9）全部消失，非运动波动减轻，仅 1 例手术失败者新发左旋多巴滥用（Lhommée 等（2012，Brain））——提示刺激配合药物重构可以"恢复动机行为的平衡"，但也可引起去抑制或淡漠，需要参数与药物协同微调（Castrioto 等（2014，Lancet Neurol））。自杀风险需要正视：534 例单中心队列中完成自杀 0.75%、自杀未遂 4.11%，术后首年自杀死亡率经年龄性别校正后的标化死亡比为 8.1，危险因素包括自杀史、精神病性症状与术前抑郁评分更高（Giannini 等（2019，Neurology））。

**自适应刺激（aDBS）：有前景但尚未成熟。** 以局部场电位驱动的闭环刺激在 8 例患者中优于常规持续刺激与随机间歇刺激 (Little et al., 2013, Ann Neurol)；盲法随机交叉可行性试验（4 例）用刺激卷入的 gamma 振荡作为生物标志物驱动 aDBS，运动症状与生活质量优于临床优化的常规刺激（Oehrn 等（2024，Nat Med））。这些试验样本量极小（4–8 例），属可行性阶段，不能据此宣称 aDBS 已优于常规 DBS。

**独立重复性。** 上述确证性试验分别由德国、美国、英国、荷兰团队独立完成，主要效应方向一致；这与证据评估中强调的独立重复原则一致，参见 [[04_证据与推理轴/证据质量/可重复性|可重复性]]。

## 当前成熟度

**成熟实践（限定适应证内）。** 依据：多项随机对照试验 (Deuschl et al., 2006, N Engl J Med; Weaver et al., 2009, JAMA; Williams et al., 2010, Lancet Neurol; Schuepbach et al., 2013, N Engl J Med)与最长 10 年的盲法长期随访 (Castrioto et al., 2011, Arch Neurol)一致支持其在严格适应证内的获益-风险平衡；有国际专家共识与监管批准 (Bronstein et al., 2011, Arch Neurol; Okun, 2012, N Engl J Med)。**临床验证阶段（早期）**：自适应 DBS 仅有 4–8 例可行性试验 (Little et al., 2013, Ann Neurol; Oehrn et al., 2024, Nat Med)。**假说阶段**：机制解释（抑制对规则的放电注入等）仍无定论 (Garcia et al., 2005, Trends Neurosci; Perlmutter & Mink, 2006, Annu Rev Neurosci)。

领域层面，Lozano 等（2019，Nat Rev Neurol）把「选哪些脑区、适用于哪些患者」列为 DBS 领域尚未解决的核心问题，这也是本节点把成熟度限定在特定适应证内的原因。

## 限制、伦理与社会影响

- **不改变疾病进程：** 长期随访一致显示轴向症状、言语与认知继续恶化 (Krack et al., 2003, N Engl J Med; Weaver et al., 2012, Neurology)。向患者交代预期时应明确"症状控制"定位。
- **手术与器械风险：** 颅内出血在早期开放试验与 5 年队列中各有 1 例报告（1 例术中出血致偏瘫失语，1 例大量出血） (Limousin et al., 1998, N Engl J Med; Krack et al., 2003, N Engl J Med)；手术相关严重不良事件在 PD SURG 试验 1 年内为 19%，含 1 例操作相关死亡 (Williams et al., 2010, Lancet Neurol)。
- **精神与认知风险：** 自杀 (Giannini et al., 2019, Neurology)与抑郁恶化 (Follett et al., 2010, N Engl J Med)要求术前精神评估与术后长期随访；执行功能下降应纳入知情同意 (Witt et al., 2008, Lancet Neurol)。
- **公平与可及性：** 器械、手术与终身程控随访费用高；优质中心分布不均，资源有限地区可及性受限。
- **神经数据与设备治理：** 植入设备持续采集脑内电活动并支持远程程控，带来设备数据归属、安全与精神隐私议题。相关框架讨论见：神经数据隐私、认知自由与精神完整性、脑机接口中的知情同意（均为本库 05 轴已有节点，此处不建双链）。
