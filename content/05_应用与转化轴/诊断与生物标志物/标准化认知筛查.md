# 标准化认知筛查

> **一句话介绍：** 标准化认知筛查（standardized cognitive screening）是在明确适用人群与场景的前提下，以经验证、可重复的简短认知测评识别**可能存在的认知损害**，据此决定是否需要详细病史、功能评估、神经心理测验和病因检查；它本身不是轻度认知障碍（MCI）、痴呆或阿尔茨海默病的确诊工具。(Atri et al., 2025a, Alzheimers Dement; NICE, 2018, NG97)

## 快速理解

**筛查不是给人贴疾病标签，而是把“值得进一步检查的线索”尽量可靠地找出来。** 临床上，患者可能自述记忆变差、家人观察到管理财务或服药困难，也可能在问诊时出现定向、语言或执行功能方面的变化。简短测验可帮助记录当前认知表现，但是否真正发生较既往的下降、是否影响日常独立性、是否由抑郁、谵妄、药物或其他疾病引起，需要另外判断。(Atri et al., 2025b, Alzheimers Dement; NICE, 2018, NG97)

尤其要区分两个经常混用的场景：

1. **症状／线索触发的认知评估（case-finding / diagnostic assessment）：** 患者、家属或医生已经发现认知行为问题。此时规范化认知工具是临床评估链的一环，不应因单次正常分数而停止必要检查；2025 年阿尔茨海默病协会的临床流程指南明确强调将测验与病史、功能和查体结合。(Atri et al., 2025b, Alzheimers Dement; NICE, 2018, NG97)
2. **无症状普通人群筛查（population screening）：** 面向没有被识别出认知症状的社区老人开展常规测试。美国 USPSTF 2020 年对**无明显症状、社区居住且 65 岁及以上**人群给出证据不足的 **I statement**：现有证据不足以判断常规筛查的整体利弊。这并不是说不应评估主动就诊的记忆主诉。(USPSTF, 2020, JAMA; Patnode et al., 2020, JAMA)

标准化认知筛查多用于识别早期认知下降与可能的痴呆综合征：经典工具包括 **MMSE、MoCA、Mini-Cog、AD8**；不同环境下也可考虑 **GPCOG、RUDAS、SLUMS、ACE-III**。它们在耗时、认知领域、是否需要熟悉患者的知情者、低文化程度可用性，以及适合检出 MCI 还是痴呆方面都不同。**没有单一量表在所有疾病、语言和医疗场景中都最好。**(Tsoi et al., 2015, JAMA Intern Med; Atri et al., 2025a, Alzheimers Dement)

**三个最重要的判断边界：**

- **筛查阳性 ≠ 确诊：** 低分可能来自语言不匹配、教育经历、听视力障碍、急性病、情绪、注意和镇静类药物等多种因素；需评估起病、变化轨迹、日常功能和其他证据。(Rossetti et al., 2011, Neurology; NICE, 2018, NG97)
- **筛查阴性 ≠ 排除：** 极早期、特定认知领域受损、受教育程度较高或症状波动者，可能在总分正常时仍有真实问题。(Atri et al., 2025b, Alzheimers Dement; NICE, 2018, NG97)
- **认知表现 ≠ 病因性生物标志物：** 低分不能直接判断是否具有淀粉样蛋白或 tau 病理，也不能鉴别所有阿尔茨海默病、血管性认知障碍、路易体病和额颞叶变性。(Jack et al., 2024, Alzheimers Dement)

## 科学依据与关键前提

### 1. 筛查识别的是“认知表现”，而不是一种特定脑部病理

简短认知评估通常覆盖部分**定向力、注意、学习与延迟记忆、语言、视空间／结构能力、执行功能**。这些能力依赖广泛脑网络；总分偏低说明某些任务表现异常，却不具有疾病病理特异性。例如轻度认知损害（MCI）一般仍保留相对独立的日常活动，痴呆综合征则涉及足以影响独立性的认知功能下降；这一区分离不开病史和实际生活功能信息。(Albert et al., 2011, Alzheimers Dement; Pfeffer et al., 1982, J Gerontol)

从 1975 年的 MMSE，到较强调执行和视空间任务的 MoCA，再到用知情者报告补充任务表现的 AD8，量表发展并不是“新表取代所有旧表”，而是针对**测量对象、临床负担与特定误检类型**的不同取舍。(Folstein et al., 1975, J Psychiatr Res; Nasreddine et al., 2005, J Am Geriatr Soc; Galvin et al., 2005, Neurology)

应当严格分开以下层级：

| 层级 | 实际回答的问题 | 典型依据 | 不能直接推出 |
| --- | --- | --- | --- |
| **认知筛查** | 是否存在需要继续评估的异常线索？ | 简短量表、知情者问卷、测评过程观察 | 痴呆确诊、疾病病因 |
| **综合征诊断** | 是否存在 MCI、痴呆或谵妄等临床综合征？ | 起病与病程、日常功能、体格和神经检查、详细认知评估 | 必然由 AD 或其他单一病理引起 |
| **病因学评估** | 何种疾病或可逆因素解释这些表现？ | 临床表型、药物及躯体病排查、实验室／影像，必要时特定生物标志物 | 生物标志物阳性即可代表全部症状原因 |
| **风险／变化监测** | 个体认知能力是否真实变化？ | 纵向测量、替代版、基线与常模、可靠变化区间 | 单次两分差异必定是疾病进展 |

2024 年阿尔茨海默病协会修订的诊断与分期标准强调**AD 可用核心生物标志物从生物学层面定义**；这套标准本身又明确不是逐步的临床工作流程指南。故不能把 MoCA、MMSE 等“表现型筛查”包装成阿尔茨海默病病理生物标志物，也不能仅凭“有症状 + 一次量表异常”直接作病因学断言。(Jack et al., 2024, Alzheimers Dement)

### 2. 工具构成、适用问题与限制

以下时间为**常见临床实施量级**，具体版本、语言、知情者参与程度与评估者训练会改变耗时；不是统一操作承诺。

| 工具 | 核心方式／典型耗时 | 相对优势及常用情境 | 不可忽略的边界 |
| --- | --- | --- | --- |
| **MMSE**（Mini-Mental State Examination） | 面对面认知测试；约 7–10 分钟；满分 30 | 历史资料最丰富，适用于部分痴呆患者总体认知表现与追踪 `(Folstein et al., 1975, J Psychiatr Res; Atri et al., 2025a, Alzheimers Dement)` | 对轻微损害及部分执行功能异常不够敏感；教育、语言及版权限制 `(Creavin et al., 2016, Cochrane Database Syst Rev)` |
| **MoCA**（Montreal Cognitive Assessment） | 多认知领域；常约 10–15 分钟；满分 30 | 在若干验证样本中比 MMSE 更容易发现 MCI 线索 `(Nasreddine et al., 2005, J Am Geriatr Soc; Roalf et al., 2013, Alzheimers Dement)` | 经典 26 分界值并非通用诊断阈值；文化／教育、版本与授权训练需核对 `(Rossetti et al., 2011, Neurology; Carson et al., 2018, Int J Geriatr Psychiatry)` |
| **Mini-Cog** | 简短回忆 + 画钟；常约 3 分钟 | 简便、适合时间受限的初步风险识别 `(Borson et al., 2000, Int J Geriatr Psychiatry)` | 基层研究少、敏感度和特异度变化大；画钟受视力及动作能力影响 `(Seitz et al., 2021, Cochrane Database Syst Rev)` |
| **AD8** | 熟悉被评估者的**知情者**回答认知与功能变化问题；约 2–3 分钟 | 关注“与既往相比是否发生变化”，可与患者测试互补 `(Galvin et al., 2005, Neurology)` | 依赖知情者质量；单用时特异度可能偏低；不是痴呆诊断标准 `(Hendry et al., 2019, Cochrane Database Syst Rev)` |
| **GPCOG** | 患者简筛 + 适宜时知情者条目；数分钟级 | 面向全科问诊与风险辨识的组合设计 `(Brodaty et al., 2002, J Am Geriatr Soc)` | 涉及知情者可得性，需符合本地验证及版本流程 |
| **RUDAS** | 文化适配取向的简短多领域评估；约 10 分钟 | 在多文化／教育背景差异较大时可作为备选 `(Storey et al., 2004, Int Psychogeriatr; Rowland et al., 2006, Int Psychogeriatr)` | **“文化适配”不等于“完全无语言和教育偏倚”**；需本地化验证 |
| **SLUMS** | 多领域简短测试；约 7–10 分钟 | 在部分研究中用于轻度神经认知问题初筛 `(Tariq et al., 2006, Am J Geriatr Psychiatry)` | 常模及阈值明显受教育背景与研究人群影响；先导研究不足以确立所有地区表现 |
| **ACE-III** | 较多领域的结构化认知检查；通常更耗时 | 有助于对语言、额叶相关表现和其他认知领域做更细致的初步刻画 `(Hsieh et al., 2013, Dement Geriatr Cogn Disord)` | 接近扩展测评而非超短简筛；不能独立鉴别额颞叶变性和 AD |

**附：并非所有简短量表都属于同一种工具。** 日常功能 FAQ 是功能证据，IQCODE 是知情者回顾性变化报告；它们可补充认知测验，但不是将两个分数机械相加就能获得“病因概率”。(Pfeffer et al., 1982, J Gerontol; Jorm & Jacomb, 1989, Psychol Med; Roalf et al., 2013, Alzheimers Dement)

### 3. “标准化”至少包含六个条件

1. **固定施测与评分规程：** 有明确版本、指导语、允许提示范围、计时方法与计分规范，不随评估者临场修改。将 MMSE 实施流程标准化可以改善评分者之间的一致性，但并不解决不同人群阈值的外推问题。(Molloy et al., 1991, Am J Psychiatry)
2. **可识别目标状态：** 明确工具是为了发现“任何认知损害”“MCI”“痴呆”还是“变化趋势”，不能把 MCI 的检出性能直接引用为阿尔茨海默病病理检测性能。(Albert et al., 2011, Alzheimers Dement; Davis et al., 2021, Cochrane Database Syst Rev)
3. **可信的参照标准：** 诊断准确性研究应采用相对独立、事先规定的临床诊断／神经心理参考标准，避免研究者依据正在被验证的量表本身作诊断而形成循环论证。(Whiting et al., 2011, Ann Intern Med)
4. **可靠性与练习效应控制：** 重测可能受疲劳、情绪、学习记忆及熟悉测试的影响，平行版本也不一定真正等价。(Costa et al., 2012, Dement Geriatr Cogn Disord; Goldberg et al., 2015, Alzheimers Dement Diagn Assess Dis Monit)
5. **适宜常模与语言：** 同一个分数在不同年龄、教育、读写能力、母语、文化背景中含义可能不同；可采用经过验证的语言与低识字版本，而非直接口译原版题目。(Rossetti et al., 2011, Neurology; Julayanont et al., 2015, J Am Geriatr Soc)
6. **预定后续行动：** 任何筛查工具都要与结果解释、诊断转介、支持和随访制度联动。只有诊疗流程形成闭环，才有机会把测验表现转化为患者实际获益。(Atri et al., 2025b, Alzheimers Dement; Verghese et al., 2024, Nat Med)

### 4. 阈值与患病率：为什么“正确率很高”仍可能误导？

**敏感度**代表有目标疾病／综合征的人中被筛查判阳性的比例；**特异度**代表没有该目标状态的人中被判阴性的比例。它们不直接回答“某位筛查阳性者究竟有多大概率患病”。后一个问题取决于**阳性预测值（PPV）**，而 PPV 还受测试人群中目标状态的基线比例影响。

**教学算例，绝非某一量表的实测参数：** 假设筛查 1,000 人，目标状态患病率 5%，工具的敏感度 90%、特异度 80%。会得到 45 位真阳性、5 位假阴性、190 位假阳性、760 位真阴性。阳性预测值约为 **19.1%**，阴性预测值约为 **99.3%**。即使测试看似不错，在低患病率场景中，**筛查阳性者仍可能有大量需要进一步排除的假阳性**。这也是筛查前选择合适人群和安排转介的重要理由；算例只是贝叶斯统计演示，不代表 MMSE、MoCA、Mini-Cog 或 AD8 的真实表现。(Patnode et al., 2020, JAMA; Whiting et al., 2011, Ann Intern Med)

## 实际实施方式

### 1. 明确要解决的临床问题，而不是先选量表

建议在正式施测之前先确认：**为何此时需要认知筛查、要识别哪种认知问题、结果将改变什么后续行动**。

- **有长期渐进主诉或亲友观察到变化：** 先询问起病、持续时间、变化轨迹、功能影响、既往水平与药物情况；结合患者测试和知情者信息。(Atri et al., 2025b, Alzheimers Dement)
- **急性意识／注意变化，尤其住院或感染、术后：** 优先考虑谵妄筛查及急性诱因诊治，不能把一次低 MMSE／MoCA 分数直接当作慢性痴呆。CAM、4AT 服务于谵妄识别，测量对象与慢性认知筛查不同。(Inouye et al., 1990, Ann Intern Med; Bellelli et al., 2014, Age Ageing)
- **没有任何认知线索的社区老人：** 是否开展普筛是人群政策与知情选择问题，需要考量获益证据、资源与后续服务，不能把“容易实施”当成“必然有利”。(USPSTF, 2020, JAMA)
- **专科或已有疑似病因的患者：** 简筛只是测验组合的一部分；若存在特定语言、执行、视空间或行为症状，应选择更针对性的神经心理与综合评估，而不是只用一个总分定性。(Hsieh et al., 2013, Dement Geriatr Cogn Disord; Atri et al., 2025a, Alzheimers Dement)

### 2. 一个可复核的诊疗链

**第 1 步：评估前信息。** 记录患者主诉、知情者观察、教育年限、主要语言与方言、视觉／听觉／运动条件、抑郁焦虑与睡眠状态、谵妄线索、疼痛疲劳、药物（尤其抗胆碱负担较重及镇静药物）、基线功能及既往测试。(NICE, 2018, NG97; Atri et al., 2025b, Alzheimers Dement)

**第 2 步：预先选择目的与量表。** 若重点是较轻症状，考虑合适语言版本的 MoCA 或相当工具；若基层时间有限，可依据场景用 Mini-Cog 或 GPCOG；无法充分交流但有可靠亲友时，使用 AD8／IQCODE 等补充既往变化。选择要基于实际验证人群，而不是依靠量表名气或固定“最佳排行榜”。(Tsoi et al., 2015, JAMA Intern Med; Atri et al., 2025a, Alzheimers Dement)

**第 3 步：规范施测。** 使用对应版本官方指导语、评分原则，记录是否有中断、提示、非标准翻译、助听／视力辅助、运动受限或缺失项目；能开展培训时尽量保持评分一致。避免在公开平台、教学资料或商业应用中未经许可复制受版权保护的整份题库。(Molloy et al., 1991, Am J Psychiatry; MoCA Cognition, 2026, Terms)

**第 4 步：情境化解释。** 总分、受损任务类型与临床主诉是否一致？是否具备合适年龄／教育／语言常模？既往分数是否采用同版与同样条件？高分且持续有疑虑时进一步详细评估；低分也应先排查测试障碍及可治疗因素。(Rossetti et al., 2011, Neurology; Atri et al., 2025b, Alzheimers Dement)

**第 5 步：按结果安排分流。** 结合身体检查、药物审查、必要的实验室检查、功能评价、情绪／睡眠与感觉问题处理；如仍怀疑认知障碍，按本地条件转神经科、老年科、记忆门诊或神经心理团队。若有急剧进展或急性意识波动应进入更紧急的医疗评估流程。(NICE, 2018, NG97; Atri et al., 2025b, Alzheimers Dement)

**第 6 步：反馈、跟踪与记录。** 向患者和照护者解释“检测到何种异常及下一步怎么办”，避免直接告知“量表得分 = 阿尔茨海默病”。如需重测，应尽量使用同语言、可比测量条件和经验证的替代版本，注明可能的练习效应，不以一次微小波动代表病情改变。(Costa et al., 2012, Dement Geriatr Cogn Disord; Goldberg et al., 2015, Alzheimers Dement Diagn Assess Dis Monit)

### 3. 结构化记录建议

推荐在病历或研究数据字典中保留：

| 字段 | 最低限度需要记录的内容 |
| --- | --- |
| **评估目的与人群** | 主动认知主诉、知情者疑虑、症状触发评估、住院急性评估或无症状筛查 |
| **工具与版本** | MMSE／MoCA／Mini-Cog 等全称、语言、版次、是否使用官方翻译与评分规则 |
| **实施条件** | 日期、场所、施测人员训练背景、教育与语言、视听与动作适配 |
| **结果与过程** | 总分、适宜时的领域表现、评分口径、缺失项、非标准指导、疲劳或中断 |
| **临床背景** | 主诉、日常功能变化、相关药物与躯体情况、谵妄风险及知情者资料 |
| **判断与行动** | 仅筛查提示／未提示异常、疑似综合征、需要复核什么、转诊／复评时间及告知情况 |

这一记录框架属于**从指南、方法学与伦理要求推导出的编辑性建议**，不是某篇原始论文已验证过的独立量表。(Whiting et al., 2011, Ann Intern Med; Atri et al., 2025a, Alzheimers Dement)

### 4. 施测培训、量表授权与数字化

规范化不等于可以随意复制题库。MMSE 存在版权／授权问题；MoCA 官方现行使用条款对纸本筛查、领域解释、研究、商业化、数字产品与复制另设不同规定。Mini-Cog 官方也分别列出临床、教学、研究与商业应用的许可条件。使用前应以**当时的官方文件、所在地区法规和实际用途**核实，不能将“患者免费使用”理解成开放许可。(MoCA Cognition, 2026, Terms; Mini-Cog, 2026, Permissions)

远程或数字认知评估可能改善覆盖范围、自动记录和重复测试便利性，但设备熟悉度、听视适配、身份核验、家庭环境、等值性和数据安全都可能改变分数；未经充分验证，不应把一个纸本量表的表现直接迁移到新应用程序或由 AI 自动判断病因。(Atri et al., 2025a, Alzheimers Dement; Whiting et al., 2011, Ann Intern Med)

## 有效性与安全性证据

### 1. 经典工具研究与独立证据汇合

| 证据 | 直接观察或归纳 | 能支持什么 | 主要限制 |
| --- | --- | --- | --- |
| MoCA 原始研究 `(Nasreddine et al., 2005, J Am Geriatr Soc)` | 在研究所选 MCI 与健康对照中，经典 26 分界值的 **MCI 敏感度约 90%**、对照特异度 **约 87%** | 说明某些特定临床样本中 MoCA 有较好的轻度损害识别能力 | 原始病例选择、教育和语言背景特定；不是各地普适的阳性诊断概率 |
| MMSE／MoCA 临床对照 `(Roalf et al., 2013, Alzheimers Dement)` | 临床样本中 MoCA 对 MCI 与健康老化的区分更敏感；加入知情者功能信息有所改善 | 总分与功能信息互补，工具需按目标状态选用 | 不是随机的社区普查队列；“比另一工具好”依赖设计与样本 |
| MoCA 社区常模 `(Rossetti et al., 2011, Neurology)` | **2,653** 人跨较宽年龄范围样本中，**66%** 低于经典 26 分界值 | 直观提示“固定分数线”可能产生过多阳性 | 是跨年龄社区常模，不能把 66% 当作经临床核实的“假阳性率” |
| 跨工具系统评价 `(Tsoi et al., 2015, JAMA Intern Med)` | 多种简短工具对痴呆和 MCI 的分类能力各有优势 | 不应默认最广为人知的工具必然最合适 | 异质性、不同诊断目标与切点妨碍简单总体排名 |
| MMSE Cochrane `(Creavin et al., 2016, Cochrane Database Syst Rev)` | 社区研究在**24 分截点**的汇总敏感度约 **0.85**、特异度约 **0.90** | 在相关人群中有诊断流程内的辅助价值 | 基层样本不足以支持完全一样的汇总参数；不能独立确诊／排除 |
| MoCA Cochrane `(Davis et al., 2021, Cochrane Database Syst Rev)` | 不同环境研究质量和阈值适用性存在问题 | 需要研究场景匹配的阈值与验证 | 主要研究“痴呆识别”，不能直接代入 MCI 原始研究的敏感度 |
| Mini-Cog Cochrane `(Seitz et al., 2021, Cochrane Database Syst Rev)` | 纳入 **4 项基层研究，共 1,517 人**；敏感度约 **0.76–1.00**，特异度 **0.27–0.85** | 说明可行性不等于性能在基层稳定 | 选择偏倚、队列差异大，研究者无法开展可靠的合并估计 |
| AD8 原始研究 `(Galvin et al., 2005, Neurology)` | 知情者回答能帮助区分认知变化和极轻度痴呆 | 为变化报告与患者当场表现互补提供依据 | 原始筛选与对照人群、知情者质量影响性能 |
| AD8 Cochrane `(Hendry et al., 2019, Cochrane Database Syst Rev)` | **阈值≥2** 的汇总敏感度 **约 0.92**、特异度 **约 0.64** | 更适合提示下一步评估，不宜仅凭阳性下诊断 | 不同卫生机构与语言存在异质性，特异度有明显不确定性 |
| RUDAS 原始与后续比较 `(Storey et al., 2004, Int Psychogeriatr; Rowland et al., 2006, Int Psychogeriatr)` | 开发时重视文化与教育差异，并作多文化对照 | 提供传统识字／语言负担较高量表的备选 | 尚需特定国家、语言和教育环境验证 |
| 低教育版 MoCA `(Julayanont et al., 2015, J Am Geriatr Soc)` | 在低识字／较低教育的研究人群中评估 MoCA-B | 减少部分原版任务的教育依赖的研发方向 | 某地版本验证结果不能无条件转用到中国所有人群 |

**独立重复的正确表述：** 多篇综述和 Cochrane 评价汇合了不同研究，但同一开发样本在多项文章中出现、阈值针对研究样本优化、以及临床转诊中心富集重症患者，都可能使表面证据数量和真实外部有效性不一致。应区分**工具原始开发、外部验证、系统评价和临床实施干预**；诊断准确性研究可依据 QUADAS-2 的患者选择、指标测试、参照标准、时序等方面评价偏倚。(Whiting et al., 2011, Ann Intern Med)

### 2. “能够检出异常”与“改善诊疗后果”是两个层级

2024 年一项针对**已有认知担忧**的初级保健就诊者随机对照试验，比较了 **5-Cog 简短评估结合电子病历临床决策支持**与对照流程。在 **1,201** 名参与者中，干预组 **90 天内发生预先定义的痴呆相关诊疗行动**的比例为 **18.5%**，对照组为 **6.8%**；调整后的比值比约 **3.43（95% CI 2.32–5.07）**。这说明**工具＋可执行后续流程**能改变部分临床行为。(Verghese et al., 2024, Nat Med)

但这里的主要终点是：出现新的 MCI／痴呆诊断、开立检查、药物或转诊等**综合行动指标**，不能说它已证明患者长期认知下降变慢、住院率降低、死亡率下降、照护者负担减轻或生活质量提高。试验本身属于**有认知担忧者的病例识别**，不应被引用为“无症状老人普筛已被随机试验证明有益”的证据。(Verghese et al., 2024, Nat Med; USPSTF, 2020, JAMA)

对应地，USPSTF 的证据汇总确认一些工具可较好识别认知问题，但筛查本身在无症状老年人中是否改善患者及照护者重要结局仍未得到足够实证回答。**诊断准确率很高**和**普遍实施带来净临床获益**是不同问题，不能相互替代。(Patnode et al., 2020, JAMA)

### 3. 负结果、方法学限制与可重复性

- **阈值依赖：** 原始 MoCA 研究的 26 分界值偏重敏感度；后续常模及阈值再评估提醒，低分比例受人群背景显著影响。合理阈值应结合临床目的（避免漏检还是避免误检）、本地常模和风险分布选取，不能写成普适诊断规则。(Nasreddine et al., 2005, J Am Geriatr Soc; Rossetti et al., 2011, Neurology; Carson et al., 2018, Int J Geriatr Psychiatry)
- **观察者与训练：** 同一患者不同施测者、翻译习惯与评分可能产生差异；培训可提高实施一致性，但不能保证降低所有系统性偏倚。(Molloy et al., 1991, Am J Psychiatry)
- **重复练习和测量误差：** 反复做同类任务可能因熟悉题型而分数提高；替代版本也应验证是否等值。不能用单次“升 1–2 分”断言干预有效。(Costa et al., 2012, Dement Geriatr Cogn Disord; Goldberg et al., 2015, Alzheimers Dement Diagn Assess Dis Monit)
- **选择及验证偏倚：** 痴呆病例与完全健康对照的病例—对照设计，通常比真实门诊中各种轻度、混合或可逆问题的区分更容易；若只有筛查阳性者接受详细临床验证，会进一步扭曲敏感度与特异度。(Whiting et al., 2011, Ann Intern Med)
- **目标与场景不匹配：** Cochrane 对 MoCA、Mini-Cog、AD8 的评价不是针对完全相同的疾病、阈值和就诊环境；任何“横向性能冠军”都必须先解释这种差异。(Davis et al., 2021, Cochrane Database Syst Rev; Seitz et al., 2021, Cochrane Database Syst Rev; Hendry et al., 2019, Cochrane Database Syst Rev)

### 4. 安全性及临床解释风险

认知量表通常没有侵入性器械风险，但仍可能产生**心理压力、污名、错误诊断、延误其他疾病诊治、无谓转诊、经济与照护负担**。错误地宣布“已患阿尔茨海默病”可能影响社会角色、家庭决策、驾驶、就业或保险；错误地宣布“一切正常”则可能延误危险症状的评估。(USPSTF, 2020, JAMA; NICE, 2018, NG97)

老年急性病人的低分尤其要优先考虑谵妄与身体状况因素。4AT／CAM 可帮助处理急性谵妄识别问题，但**谵妄与痴呆可共存**，识别其中之一不能自动否定另一种。(Inouye et al., 1990, Ann Intern Med; Bellelli et al., 2014, Age Ageing)

| 应用环节 | 成熟度 | 支持依据 | 尚欠证据／实施约束 |

| 症状触发的标准化简短认知评估 | **成熟的临床诊断辅助实践** | 多项原始验证、系统评价与 NICE／DETeCD-ADRD 指南 `(Atri et al., 2025b, Alzheimers Dement; NICE, 2018, NG97)` | 必须整合病史、功能和可逆因素；不能孤立确诊 |

| 简筛＋临床决策支持的流程创新 | **在特定症状人群中已有随机试验支持短期流程结局** | 2024 年 5-Cog 随机试验 `(Verghese et al., 2024, Nat Med)` | 跨机构推广及长期患者中心获益尚未充分证实 |
| 无症状社区人群普遍筛查 | **存在重要证据缺口／利弊未定** | USPSTF I statement 与系统评价 `(USPSTF, 2020, JAMA; Patnode et al., 2020, JAMA)` | 不应把症状触发的试验结果误用于普筛 |
| 自动化／远程数字评估 | **研究到部分场景应用，产品与任务差异明显** | 临床评估工具指南涉及不同施测形式 `(Atri et al., 2025a, Alzheimers Dement)` | 等值性、数据安全、用户可访问性与规范审批需逐产品确认 |

对于“诊断与生物标志物”这一分类，应明确：**认知筛查属于临床表型／功能测量工具，不是独立的分子或影像生物标志物。** 其主要解释位置依然属于应用与转化轴，因为本节点重心是“如何规范筛查并接入诊疗流程”，而不是描述某种疾病病理或测量仪器的纯技术原理。(Jack et al., 2024, Alzheimers Dement)

## 限制、伦理与社会影响

### 1. 认知多样性与公平性

教育年限、识字状况、熟悉文字和图形的经验、语言与方言、职业训练、神经发育特征及既往认知储备都会影响量表任务表现。**测量公平性的检验对象不是“是否提供中文版”，而是中文版在目标人群中是否有合适常模、明确评分规程、已验证的疾病判别能力，以及是否对不同亚群体产生系统性误差。**(Rossetti et al., 2011, Neurology; Rowland et al., 2006, Int Psychogeriatr)

MoCA-B 和 RUDAS 的初衷包括缓解部分文化／识字偏差，但它们既不保证所有残障人士均可参与，也不能自动消除翻译差异；有严重听力、视力、上肢运动障碍的人应根据专门验证证据选用适配工具，而不是把无法完成题目按零分解释为认知障碍。(Storey et al., 2004, Int Psychogeriatr; Julayanont et al., 2015, J Am Geriatr Soc)

### 2. 同意、结果反馈和不伤害原则

测试前应说明为何测试、结果可能意味着什么、谁可接收结果，以及下一步如何处理；适度避免让受试者误认为一次筛查就是不可逆的疾病判决。沟通中宜使用“需要进一步评估的线索”“在该测验条件下表现偏低／正常”等表述。向家属提供结果时应尊重患者的沟通与决定权，并遵循适用的保密与法律规定。(Atri et al., 2025b, Alzheimers Dement)

对无症状人群普遍开展筛查还可能挤占诊断转介资源。若当地缺乏足够后续评估、复核与照护服务，广泛检出异常未必转化为良好结局；这是实施层面的公平性问题，不能只以量表简单、便宜作为全面推广理由。(Patnode et al., 2020, JAMA)

### 3. 版权、数字数据与商业风险

- **受保护测试材料：** 授权使用与转载不是同一回事；不应将整份 MoCA／MMSE／Mini-Cog 测试题目、答案与评分模板直接发布到公开知识库。官方规则可能随时间修订，应以具体用途、版本与授权方当前条款为准。(MoCA Cognition, 2026, Terms; Mini-Cog, 2026, Permissions)
- **个人数据：** 认知分数、年龄、教育、临床病史、知情者回答和语音／书写记录可能构成高度敏感信息。远程系统应限制访问范围，区分临床照护与商业训练用途，明确保存期限、撤回权限与审计机制。
- **数字工具“自动确诊”主张：** 不能仅凭与纸本分数高度相关、或算法 AUC 较高，就宣称可诊断阿尔茨海默病；需要验证参考诊断、独立人群、疾病谱、差异性误差及患者临床结局。(Whiting et al., 2011, Ann Intern Med; Jack et al., 2024, Alzheimers Dement)

### 4. 仍有争议、待研究和不得外推的部分

1. **统一阈值：** 能否建立涵盖不同语言、教育与文化背景的稳定多维判断规则？目前不能认为一个 MoCA 或 MMSE 数字适合所有人。(Carson et al., 2018, Int J Geriatr Psychiatry)
2. **筛查带来的真实获益：** 除了更多转诊与检查，怎样证明患者自主生活、生活质量、照护者负担和长期安全的改善？现有试验与指南并未完成全部链条。(Verghese et al., 2024, Nat Med; Patnode et al., 2020, JAMA)
3. **重复测试与个体化轨迹：** 如何区分疾病变化与练习效应、短暂疲劳、情绪波动、不同题本及施测者差异？(Costa et al., 2012, Dement Geriatr Cogn Disord; Goldberg et al., 2015, Alzheimers Dement Diagn Assess Dis Monit)
4. **筛查与生物标志物联用：** 应如何决定谁需要进一步血液、脑脊液或影像标志物检测？认知总分不能被直接转写成病理分期。(Jack et al., 2024, Alzheimers Dement)
5. **结论强度：** “某工具能提高检出率”属于诊断测试证据；“某流程使诊疗行动增加”属于实施试验结局；“改善患者长期生活”需要更直接的临床结果。三者不应混写为单一“已证实有效”。(Whiting et al., 2011, Ann Intern Med; Verghese et al., 2024, Nat Med)

## 相关节点

- **应用与转化：** 阿尔茨海默病生物标志物、神经心理评估、数字认知评估、早期痴呆诊断、精神与神经疾病鉴别诊断。
- **研究对象与尺度：** 认知控制、记忆系统、注意网络、执行功能、语言功能。
- **科学问题：** 轻度认知障碍、痴呆、阿尔茨海默病、谵妄、认知老化、认知储备。
- **方法与模型：** 心理测量学、敏感度与特异度、ROC 曲线、阳性预测值、临床决策阈值、纵向变化模型。
- **证据与推理：** 诊断准确性、外部验证、QUADAS-2、谱偏倚、可重复性、测量不变性、公平性与临床获益。
