# 意识障碍评估

> **一句话介绍：** 意识障碍评估（assessment of disorders of consciousness, DoC）是针对昏迷、无反应觉醒综合征和最低意识状态等严重脑损伤患者，采用**反复标准化床旁行为检查**并在合适条件下整合 EEG、fMRI、PET 等证据，尽量区分“没有可见反应”和“没有意识证据”、改善诊断分层并辅助预后与照护决策的方法体系；它**不是某个能一次性证明或排除主观体验的单项检测**(Giacino et al., 2018, Neurology; Kondziella et al., 2020, Eur J Neurol; Bodien et al., 2024, N Engl J Med; Laigaard et al., 2026, Eur J Neurol)。

## 快速理解

一个人可以睁眼、出现睡眠—觉醒周期，却没有被观察到遵从指令或其他可靠的意识行为；另一人可能理解指令，却因完全或近乎完全的运动输出障碍、语言障碍、感觉障碍或觉醒波动而无法在床旁作出可见反应。意识障碍评估最容易犯的错误，就是把**外显运动反应、脑内信息加工、可证实的主动指令遵从和个体主观体验**混作一个指标(Giacino et al., 2002, Neurology; Laureys et al., 2010, BMC Med; Kondziella et al., 2020, Eur J Neurol; Bodien et al., 2024, N Engl J Med)。

本节点主要讨论严重获得性脑损伤后急性期及持续性 DoC，尤其是 ICU、神经内科/神经外科、康复病区和长期照护人群；同时必须考虑药物、癫痫、低体温、代谢紊乱、镇静、感觉与运动缺损等混杂因素。2018 年 AAN 指南的主要适用对象是**持续至少 28 天的意识障碍**，不应原样套用到所有急性 ICU 病例(Giacino et al., 2018, Neurology; Kondziella et al., 2020, Eur J Neurol)。

### 常见临床状态：评估时应明确记录

| 状态 | 操作性区分 | 容易误判之处 |
| --- | --- | --- |
| 昏迷（coma） | 无清醒表现，持续闭眼，不能可靠唤醒 | 镇静、低体温和重症病理因素可模拟或掩盖临床表现 |
| 无反应觉醒综合征（UWS；既往 VS） | 有可辨认的觉醒/睁眼周期，但未检测到可靠的意识相关行为 | “没有观察到”并非“已证明没有任何意识” |
| 最低意识状态（MCS） | 可出现少量但可重复或足以区分反射的意识相关行为 | 表现可高度波动，单次检查容易漏检 |
| MCS− 与 MCS+ | 常用操作性亚类：MCS− 可见视觉追踪/定位等意识相关行为但无明确语言相关指令遵从；MCS+ 出现遵从指令、可理解语言或有意交流等较高层次迹象 | “+ / −”不能简单解释为两个固定的生物学断点 |
| 脱离 MCS（eMCS） | 恢复功能性交流或功能性物体使用的行为学证据 | 单次或非功能性反应不等于已经可靠交流 |
| 闭锁综合征（locked-in syndrome） | 意识可完整保留，严重瘫痪；典型病例可借垂直眼动或眨眼交流 | 不能因肢体不能动而误归为 DoC |
| 隐匿指令遵从／认知—运动分离（CMD） | 床旁未见指令遵从，但经经验证的**主动任务** EEG/fMRI 检出与指令相符的自主脑活动 | 阳性证据强于纯被动刺激响应；阴性不排除意识 |

上述分类基于不同历史时期的诊断共识及多模态研究，不同研究的具体判据可能略有差异(Giacino et al., 2002, Neurology; Laureys et al., 2010, BMC Med; Claassen et al., 2019, N Engl J Med; Kondziella et al., 2020, Eur J Neurol; Bodien et al., 2024, N Engl J Med)。

**一句话记忆：** 行为反应是重要观察窗口，不是意识的全部；神经电生理或影像指标是必要时的补充证据，也不能脱离行为评估单独定性(Giacino et al., 2018, Neurology; Kondziella et al., 2020, Eur J Neurol; Edlow et al., 2021, Nat Rev Neurol)。

## 科学依据与关键前提

### 1. 意识评估究竟在测什么

临床上常将\*\*觉醒（arousal）**与**意识内容/觉知（awareness）\*\*区别描述。脑干—丘脑—皮层与大尺度皮层连接的完整程度影响可观察的唤醒、反应以及复杂认知加工。但某项脑网络活动的存在仅能证明对应功能在特定条件下可能保留，不直接证明患者能体验、理解或随意表达所有信息(Casali et al., 2013, Sci Transl Med; Sitt et al., 2014, Brain; Edlow et al., 2021, Nat Rev Neurol)。

- **外显行为学证据：** 例如可靠遵从指令、目光追踪、目标定位、可理解语言、功能性交流或物体使用。行为标准使诊断可操作，但前提是患者在测试时能接收指令并有足够运动/注意/觉醒能力作出反应(Giacino et al., 2002, Neurology; Giacino et al., 2004, Arch Phys Med Rehabil; Giacino et al., 2018, Neurology)。
- **主动脑反应证据：** fMRI 中按指令想象打网球、空间导航，或 EEG 中按要求完成运动想象/尝试等任务。重复、任务特异的调节比单纯听到声音后的诱发电位更支持保留有意指令遵从，称为 CMD 的主要操作性依据(Owen et al., 2006, Science; Monti et al., 2010, N Engl J Med; Curley et al., 2018, Brain; Bodien et al., 2024, N Engl J Med)。
- **被动/静息神经证据：** 标准 EEG 背景、睡眠纺锤波、诱发电位、EEG 复杂性、功能连接、脑代谢 PET 与 TMS–EEG 扰动复杂性。它们提供网络完整性、信息处理或潜在预后的线索，但单独检出不等于主动理解并执行指令(Casali et al., 2013, Sci Transl Med; Sitt et al., 2014, Brain; Stender et al., 2014, Lancet; Chennu et al., 2017, Brain; Carroll et al., 2025, Nat Med)。
- **预后指标：** 检测时的 DoC 类型、脑损伤病因、损伤后时间、结构损害、合并症、神经任务结果及功能量表随访。预后是概率性、时间相关的估计，不是“能否存活”或“未来是否一定醒来”的确定断言(Giacino et al., 2018, Neurology; Claassen et al., 2019, N Engl J Med; Edlow et al., 2021, Nat Rev Neurol; Egbebike et al., 2022, Lancet Neurol)。

### 2. 标准化行为检查为何是首要层

GCS 最早提出眼、言语和运动反应评分，便于急性意识损伤沟通；FOUR 分析眼、运动、脑干反射和呼吸，在插管及脑干评估场景具有实用优势。它们**不能简单替代 CRS-R 对持续意识障碍细微行为的分层**(Teasdale & Jennett, 1974, Lancet; Wijdicks et al., 2005, Ann Neurol; Kondziella et al., 2020, Eur J Neurol)。

修订版昏迷恢复量表 **CRS-R（Coma Recovery Scale–Revised）** 由听觉、视觉、运动、口运动/言语、交流、觉醒等六个分量表组成。其价值不是把总分机械对应为“意识百分比”，而是系统地探测可复制的反应模式和诊断性行为；训练、环境和实施细节会影响可比性(Giacino et al., 2002, Neurology; Giacino et al., 2004, Arch Phys Med Rehabil; Giacino et al., 2018, Neurology)。

**重复检查不是可选装饰：** 2009 年 103 人研究中，原常规临床判断为 VS 的 44 人，18 人经 CRS-R 重新分为 MCS（18/44，约 41%）；分母是**原本被判为 VS 的受试者**，不能写成“所有昏迷患者的误诊率”。2017 年 123 人研究在 10 天内进行至少六次检查，以六次中最高行为诊断作为参照，首次评估相对参照出现较多漏判，支持序贯评估(Schnakers et al., 2009, BMC Neurol; Wannez et al., 2017, Ann Neurol)。

### 3. 多模态证据的互补与不可互换

| 检测手段 | 更直接测得什么 | 对“有意识”的推断边界 |
| --- | --- | --- |
| CRS-R／床旁行为 | 外显的眼、肢体、言语、指令遵从与功能性交互 | 阳性可形成行为证据；阴性依赖能否唤醒、感知、移动 |
| 标准 EEG | 背景活动、反应性、癫痫活动、睡眠结构 | 用于排查影响因素与网络功能；反应性≠可主动遵从 |
| EEG／fMRI 主动任务 | 按指令改变的任务特异神经活动 | 阳性可支持 CMD；阴性受疲劳、听觉和任务能力影响 |
| 静息态 EEG／fMRI、复杂性 | 连接、频谱、熵或扰动后的皮层整合等代理指标 | 主要为状态分类、风险分层或研究生物标志物 |
| FDG-PET | 局部脑葡萄糖代谢及网络保留程度 | **不是淀粉样蛋白PET**，代谢保留≠主动执行命令 |
| 结构 MRI/CT | 病损类型、脑干/丘脑/皮层损伤范围 | 有助病因和风险判断，但无法单独充分判定主观意识 |

临床综合评估需采用**能解释各项检查为何一致或不一致的证据框架**，而不是看到某个机器评分阳性就覆盖所有床旁和病史信息(Stender et al., 2014, Lancet; Engemann et al., 2018, Brain; Kondziella et al., 2020, Eur J Neurol; Edlow et al., 2021, Nat Rev Neurol)。

### 4. 关键理论限制：意识不是一个完美二分类金标准

CRS-R 与脑电/影像的验证常以现有行为诊断作参照，而真正的“当下主观体验”无法直接由患者独立报告。某些 EEG 分类器在两中心间迁移性能良好，但判别目标仍是行为分组而非可完全验证的主观意识。TMS–EEG 复杂性等指标即使在群体上区分觉醒/麻醉/意识状态，也须谨慎评价具体脑损伤个体中的阈值、混杂和可重复性(Casali et al., 2013, Sci Transl Med; Sitt et al., 2014, Brain; Engemann et al., 2018, Brain)。

## 实际实施方式

> 下述为专业医疗团队适用的评估工作框架，不是家庭自测或决定撤除生命支持的操作指引。

### 第一步：确认病因、状态与检查时机

- 核对损伤时间与原因：创伤性脑损伤、缺氧缺血、脑血管事件、感染、代谢或药物相关等；分清**急性昏迷、持续 DoC、恢复过程以及非 DoC 的运动输出障碍**(Giacino et al., 2018, Neurology; Kondziella et al., 2020, Eur J Neurol; Edlow et al., 2021, Nat Rev Neurol)。
- 核对可逆混杂：镇静/麻醉药的剩余作用、癫痫或非惊厥性癫痫持续状态、低氧/低血糖/电解质紊乱、感染、低体温、严重疼痛、睡眠不足或疲劳、听觉/视觉缺陷、气管插管及严重瘫痪(Giacino et al., 2018, Neurology; Kondziella et al., 2020, Eur J Neurol)。
- 明确床旁数据的采集环境、语言沟通渠道与生理稳定性；ICU 搬运至 MRI/PET 可能带来监护、通气及设备相容性风险，检查并非对每人都可实施(Kondziella et al., 2020, Eur J Neurol; Monti & Schnakers, 2022, Neurology)。

### 第二步：由受训练的团队反复实施标准化行为检查

1. 急性 ICU 可记录 GCS、FOUR 及全面神经系统评估；若条件允许用 CRS-R 系统检测 DoC 相关行为。在气管插管患者中，不能把“无法发声”简单当作缺少语言理解(Teasdale & Jennett, 1974, Lancet; Wijdicks et al., 2005, Ann Neurol; Kondziella et al., 2020, Eur J Neurol)。
2. 按照听觉、视觉、运动、口运动/言语、交流和觉醒六个领域实施 CRS-R，并记录最佳反应及当次状态。检查时关注镜中人脸引发的视觉追踪、正确时序的指令反应与功能性交流，防止反射性动作被误记为自主反应(Giacino et al., 2004, Arch Phys Med Rehabil; Kondziella et al., 2020, Eur J Neurol)。
3. 在患者病情许可时分时段重复，联合护士、康复治疗师、医师以及家属观察；重复次数由病情与实际资源决定。Wannez 研究建议在短时间内增加检查次数，但不应把实验设置中的“五次”机械视为全部病例法规要求(Wannez et al., 2017, Ann Neurol; Giacino et al., 2018, Neurology)。
4. 如 ICU 环境必须缩短流程，可考虑验证阶段的 **CRSR-FAST** 辅助筛查；其在 45 名严重 TBI 患者中的平均用时约为 6.5 分钟，完整 CRS-R 约为 20.1 分钟。它是经初步验证的短版工具，不等于完整版的无损替代(Bodien et al., 2023, Ann Neurol)。

### 第三步：选择互补的 EEG、影像及认知任务

- **标准 EEG：** 检测癫痫、背景、反应性、睡眠周期/纺锤波等，在条件许可时结合重复采集；其生理与预后信息与主动任务有所不同(Kondziella et al., 2020, Eur J Neurol; Carroll et al., 2025, Nat Med)。
- **高级 EEG：** 频谱、复杂性、动态连接、跨协议模型，以及需要主动指令执行的运动想象/计数任务。尽量预定义任务、质控标准和多重比较校正；被动音频诱发不能当作 CMD 阳性(Sitt et al., 2014, Brain; Engemann et al., 2018, Brain; Curley et al., 2018, Brain; Laigaard et al., 2026, Eur J Neurol)。
- **fMRI 主动任务：** 可能适合能够安全转运、能接受听觉/视觉指令且满足设备限制的部分患者；任务特异信号对 CMD 有解释力，但高度依赖注意、感官输入与分析方案。阴性时不能单独否认意识(Owen et al., 2006, Science; Monti et al., 2010, N Engl J Med; Bodien et al., 2024, N Engl J Med)。
- **FDG-PET／静息 fMRI／TMS–EEG：** 在专科及研究中心按临床问题评估使用；前者反映代谢保留，后者刻画静息网络或扰动后的复杂性，与主动遵从命令不是同一个测量目标(Casali et al., 2013, Sci Transl Med; Stender et al., 2014, Lancet; Chennu et al., 2017, Brain; Kondziella et al., 2020, Eur J Neurol)。

### 第四步：多学科综合判读与动态再评估

建议至少分别形成**床旁行为诊断、附加神经功能证据、影响可信度的混杂因素、当前预后不确定性**四个独立记录域。发现主动任务阳性时，宜重新审视床旁检查和可能的残余交流通道；未检出时，应检查是否有任务理解障碍、过度镇静、听力问题、低信噪比、瞬时觉醒下降等，谨慎进行重复或替代评估(Claassen et al., 2019, N Engl J Med; Kondziella et al., 2020, Eur J Neurol; Bodien et al., 2024, N Engl J Med)。

在需要讨论预后、康复安置和维持生命治疗时，应由有经验的团队、患者代理人或家属共同审阅**多时点证据和可逆因素**，并区分预测自然病程与因照护决策导致的结局变化。任何单项 CMD、睡眠纺锤波或 AI 分数都不应直接用作停治标准(Giacino et al., 2018, Neurology; Edlow & Fins, 2018, J Head Trauma Rehabil; Egbebike et al., 2022, Lancet Neurol; Carroll et al., 2025, Nat Med)。

## 有效性与安全性证据

### 1. 行为学：可重复标准化评估有实质临床诊断价值

CRS-R 原始验证研究确认其分量表在行为诊断上有良好的临床效用；后续研究进一步说明**非标准化日常临床印象可能漏判 MCS**：2009 年 103 人研究中“18/44”的差异是传统评估对特定 VS 亚组的漏识别现象，而不代表所有 DoC 状态的普适误诊率(Giacino et al., 2004, Arch Phys Med Rehabil; Schnakers et al., 2009, BMC Neurol)。

2015 年一项长期照护机构观察研究也提示，机构条件、连续评估资源和康复可及性会影响最终诊断质量(van Erp et al., 2015, J Am Med Dir Assoc)。

2017 年 Wannez 等在 123 名慢性 DoC 患者中用六次 CRS-R 的最高状态作为比较参照，首次评估相对参照有约 36% 的诊断不一致。因为“最佳六次结果”本身也是研究定义的参考标准，所以**不能把 36% 当成严格病理金标准下的错误率**；但它有力支持行为波动会影响临床分层(Wannez et al., 2017, Ann Neurol)。

2023 年 45 人的 CRSR-FAST 测试显示，用时减少但灵敏度约 81%、特异度约 89%；比较对象为完整版 CRS-R，故这些指标不能解释为对主观意识的真实敏感度和特异度，也不能直接扩展到非创伤性病因或儿童(Bodien et al., 2023, Ann Neurol)。

### 2. 主动任务：真正改变“看上去没有反应”的认识

2017 年对急性严重创伤性脑损伤患者的研究提示，多模态神经影像有时可以比常规床旁观察更早发现保留的意识相关功能，但这类转运和影像结果仍受样本规模、病情稳定性及测试条件限制(Edlow et al., 2017, Brain)。

2006 年个案证明在符合当时 VS 诊断的患者身上可能检测到有指令特异性的 fMRI 活动；2010 年 54 人队列进一步发现少数患者能够主动调节脑信号，部分能使用任务范式作简单回答。这类研究的强项是证明**神经层面的自主指令遵从可以与运动输出脱钩**，而不是证明所有“无反应”人群均保留意识或沟通能力(Owen et al., 2006, Science; Monti et al., 2010, N Engl J Med)。

2018 年 EEG 研究提示这类主动脑活动在空间和时间上具有个体差异，觉醒状态变化会影响阳性检测；2019 年连续 ICU 队列中，104 名缺乏可见指令反应的急性脑损伤者，16 人被检测到任务相关 EEG 活动（约 15%）。此处“15%”受病因、急性时点和具体任务影响，并非所有 DoC 的恒定比例(Curley et al., 2018, Brain; Claassen et al., 2019, N Engl J Med)。

**2024 年核心多中心研究：** 六个国际中心共分析 353 人；其中 **241 人没有观察到指令遵从，60 人通过 fMRI 或 EEG 被检出 CMD（60/241，约 25%）**。重要的反面信息同样必须保留：**112 名床旁有可见指令反应者中仅 43 人在所用任务态测试上呈阳性**，即大多数“临床已能遵从指令”的患者在该研究设置下反而未通过主动脑任务。因此**检测阴性不能当作缺乏意识的反证**，也不能简单从检出率反推出总体患病率(Bodien et al., 2024, N Engl J Med)。

### 3. 静息指标与影像：提示能力，但指标含义不一样

FDG-PET 在 2014 年临床验证中为 DoC 患者提供保留脑代谢活动的信息；静息 EEG 频谱与动态复杂性、跨脑区网络连接，以及 TMS–EEG 的 PCI 均能在研究中区分部分行为分组。它们的真实优势是对无法参加复杂指令任务的人提供补充指标；**保留脑代谢、皮层信息整合或某类诱发电位，并不等同于完成主动意识任务**(Casali et al., 2013, Sci Transl Med; Sitt et al., 2014, Brain; Stender et al., 2014, Lancet; Chennu et al., 2017, Brain)。

2018 年两中心研究采用 327 份 DoC EEG 记录进行跨采集条件验证，证明某些多特征机器学习模型具有跨中心迁移能力，但外部 AUC 仍远非 1，且参照标签受行为评估质量影响。因此，EEG 算法目前应定位为**概率性分层工具**，而非独立裁定意识存在与否的法医式判据(Engemann et al., 2018, Brain)。

2025 年 226 人急性脑损伤队列发现清晰的 **N2 睡眠纺锤波**与 CMD 及意识恢复时间有关，并可能先于主动 EEG 中的 CMD 检出；它是相对便于观察的候选**预后线索**，并不是“出现纺锤波就证明能理解指令”(Carroll et al., 2025, Nat Med)。

### 4. 预后证据：应强调统计关联而不是绝对命运

在 2019 年 104 人队列中，接受 12 个月结局评估者里，最初 CMD 阳性者中 **7/16** 达到指定 GOS-E 功能水平，而非 CMD 者中为 **12/84**；两组结局存在差异，但脑损伤病因、撤除支持治疗与随访状况可能影响估计(Claassen et al., 2019, N Engl J Med)。

2022 年 193 人观察队列进一步在模型派生和验证样本中考察 CMD 与恢复的关系，其中 27 人被诊断 CMD。CMD 与较短的达到较好功能结局时间相关（HR 5.6，95% CI 2.5–12.5）；这是经协变量调整的**关联估计**，并不证明通过提高 EEG CMD 检出就可以改变疾病轨迹，也不代表 CMD 阴性者没有恢复机会(Egbebike et al., 2022, Lancet Neurol)。

2026 年个体参与者数据荟萃分析汇总 **56 项研究与 1,248 名参与者**，发现相比创伤性脑损伤，缺氧性和脑血管性损伤的 CMD 检出机会相对较低，而 MCS− 相比 UWS 更容易检出；患者招募、记录技术、时间及检测范式都具有异质性，汇总的技术检出率不能解读为某一地区的无选择偏差人群发生率(Laigaard et al., 2026, Eur J Neurol)。

### 5. 安全性、方法学反例与诊断偏差

| 风险/偏差 | 为什么重要 | 建议解读 |
| --- | --- | --- |
| **假阴性** | 即使床旁已可遵从指令，fMRI/EEG 主动任务也可能无反应 | 阴性不是无意识证明，需检查任务适配与觉醒状态 |
| **假阳性／多重比较** | 噪声、分析方案选择和刺激相关伪迹可影响阈值 | 预先定义任务、质控、统计校正并优先重复 |
| **选择偏差** | 高度专业中心、可承受转运者、特定病因比例 | 特定研究检出率不直接适用于全部医院或患者 |
| **参照标准局限** | 行为学可漏判，机器学习往往按行为标签训练 | 组间判别指标不是主观意识的独立金标准 |
| **预后自我实现偏差** | 撤除生命支持等决策会改变观察到的结局 | 避免把决策后果循环用作早期预测准确性的证明 |
| **资源及检查风险** | 长时 EEG、MRI/PET 转运、环境干扰、罕见不良反应 | 权衡临床价值、稳定性、设备限制和家属期望 |

这些问题均可导致“好看的检出率”与实际患者决策质量分离，应结合指南和方法学研究审查(Giacino et al., 2018, Neurology; Edlow & Fins, 2018, J Head Trauma Rehabil; Claassen et al., 2019, N Engl J Med; Kondziella et al., 2020, Eur J Neurol; Bodien et al., 2024, N Engl J Med; Laigaard et al., 2026, Eur J Neurol)。

## 当前成熟度

**截至 2026 年 10 月：标准化多次床旁评估与标准 EEG 属于可进入常规临床流程的成熟基础方法；高级主动 EEG/fMRI 和 FDG-PET 属于指南支持在具备条件时考虑的专科补充；若干静息态/自动化/睡眠指标仍是转化验证中的候选生物标志物。**

| 子方向 | 成熟度 | 主要依据与适用边界 |
| --- | --- | --- |
| GCS / FOUR / 临床神经检查 | 成熟临床基础 | 特别适合急性生命体征与神经功能评估；不能单独诊断持续 UWS/MCS (Teasdale & Jennett, 1974, Lancet; Wijdicks et al., 2005, Ann Neurol; Kondziella et al., 2020, Eur J Neurol) |
| 重复 CRS-R | **持续 DoC 分层的重要临床基础** | 量表信效度和行为重复性研究支持；依赖正确实施和排除混杂 (Giacino et al., 2004, Arch Phys Med Rehabil; Wannez et al., 2017, Ann Neurol; Giacino et al., 2018, Neurology) |
| ICU 短版 CRSR-FAST | **初步验证、尚需拓展** | 重症 TBI 小样本验证；不应取代全部完整检查 (Bodien et al., 2023, Ann Neurol) |
| 标准 EEG 与睡眠结构评估 | 临床基础＋风险辅助 | 可用于排查癫痫、评估背景与睡眠结构；特定纺锤波预后模型仍需要跨中心验证 (Kondziella et al., 2020, Eur J Neurol; Carroll et al., 2025, Nat Med) |
| 主动 EEG / fMRI 检出 CMD | 多中心人体研究支持的专科/研究工具 | 发现重要临床盲点，但阴性高假阴性且可及性不均 (Claassen et al., 2019, N Engl J Med; Bodien et al., 2024, N Engl J Med; Laigaard et al., 2026, Eur J Neurol) |
| 静息态高级 EEG、PCI、FDG-PET、算法分类 | 专科研究与补充验证 | 定量分析、代谢及网络关联意义明确；诊断阈值、外部验证、临床收益不完全解决 (Casali et al., 2013, Sci Transl Med; Stender et al., 2014, Lancet; Engemann et al., 2018, Brain) |
| 多模态预后／个体决策模型 | **发展中** | 已有观察关联与部分验证队列，但仍需分离病因、撤除治疗等混杂及验证真实决策收益 (Egbebike et al., 2022, Lancet Neurol; Carroll et al., 2025, Nat Med; Laigaard et al., 2026, Eur J Neurol) |

**不得声称：** “PET/EEG/fMRI 一项检测就能证明绝对无意识”“25% 表明四分之一昏迷者都完全清醒”“CRS-R 总分就是意识百分比”“TMS–EEG 或睡眠纺锤波可以代替脑死亡判定”“阴性 CMD 就表示不会恢复”。

## 限制、伦理与社会影响

1. **诊断语言的道德后果。** VS/UWS、MCS、CMD 是不同层面的临床与研究定义；向家庭解释结果时应明确什么行为被观察到、什么神经证据被检出、什么仍不确定。术语的变化不意味着意识机制已完全解决(Laureys et al., 2010, BMC Med; Edlow & Fins, 2018, J Head Trauma Rehabil; Edlow et al., 2021, Nat Rev Neurol)。
2. **“检出隐匿意识”与“能有效交流”不同。** 某一任务中出现可靠命令相关脑活动，不代表已有稳定、可推广的双向沟通通道，更不意味着患者已能充分表达复杂医疗意愿；需要独立验证跨次、跨问题和错误率(Monti et al., 2010, N Engl J Med; Curley et al., 2018, Brain; Bodien et al., 2024, N Engl J Med)。
3. **生命支持与预后预测中的伦理风险。** 错误的悲观评估可能影响转诊、康复机会及撤除支持治疗决策；而过度乐观的单项结果也可能造成不必要负担。应由多学科团队沟通可逆因素、时间窗口、质量/不确定性及患者既往意愿，避免“自我实现预言”(Giacino et al., 2018, Neurology; Edlow & Fins, 2018, J Head Trauma Rehabil; Egbebike et al., 2022, Lancet Neurol)。
4. **脑死亡判定是另外一套程序。** 脑死亡／依神经学标准判定死亡（BD/DNC）与昏迷、UWS/MCS 和 CMD 不是互相替代的诊断；2023 年 AAN 等多学会 BD/DNC 指南规定不同的前提、神经学检查和必要时辅助检查，不能用本节点任意 EEG/PET 指标替代法定流程(Greer et al., 2023, Neurology)。
5. **照护不公平。** 稳定 MRI 转运、神经心理测验、长时间 EEG、专科评估及高级分析在地区和医疗系统之间极不平衡。资源不足导致“未检测”不能被翻译成“检测过且阴性”；跨中心模式还可能因语言、设备和病因结构失去通用性(Engemann et al., 2018, Brain; Kondziella et al., 2020, Eur J Neurol; Monti & Schnakers, 2022, Neurology; Laigaard et al., 2026, Eur J Neurol)。
6. **隐私、代理同意与数据治理。** 神经记录涉及高度敏感的临床与行为相关数据；对无法直接同意的患者须遵循伦理审核、代理授权、最小必要采集及安全的数据共享与算法评估。使用 AI 自动分层时必须记录可解释的输入与错误边界(Edlow & Fins, 2018, J Head Trauma Rehabil; Kondziella et al., 2020, Eur J Neurol)。

### 证据边界与人工验收清单

**较稳定的认识：** 行为评估必须标准化且在可行条件下重复；单次阴性行为检查不能排除隐匿意识；在部分行为无指令反应者中，任务态 EEG/fMRI 能揭示自主指令相关脑活动；病因和觉醒状态影响检出；多模态结果应被联合解释(Giacino et al., 2004, Arch Phys Med Rehabil; Wannez et al., 2017, Ann Neurol; Giacino et al., 2018, Neurology; Kondziella et al., 2020, Eur J Neurol; Bodien et al., 2024, N Engl J Med; Laigaard et al., 2026, Eur J Neurol)。

**仍有争议或仅是研究性候选：** 最合理的检查顺序与复查频率、任务阴性的阴性预测值、TMS–EEG/AI 模型的跨病因阈值、何种脑网络/睡眠指标能独立预测个人恢复、检测 CMD 是否直接改善长期生活质量或改变资源配置公平性(Casali et al., 2013, Sci Transl Med; Engemann et al., 2018, Brain; Egbebike et al., 2022, Lancet Neurol; Carroll et al., 2025, Nat Med; Laigaard et al., 2026, Eur J Neurol)。

**人工审核重点：** 核对已有 Vault 中 CRS-R、CMD、UWS 等节点与同义别名；核对当地有效的诊疗及脑死亡判定规范；复核医院可用的检查和转运条件；对 2018 指南适用人群与 2023 BD/DNC 指南及更正明确区分；对任何预测概率保留人群、时点、病因和撤除生命支持混杂提示；根据新研究更新元数据但不自行发布(Giacino et al., 2018, Neurology; Kondziella et al., 2020, Eur J Neurol; Greer et al., 2023, Neurology)。
