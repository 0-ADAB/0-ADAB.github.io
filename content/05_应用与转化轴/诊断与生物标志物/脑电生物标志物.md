# 脑电生物标志物

> **一句话介绍：** 脑电生物标志物（electroencephalographic biomarkers, EEG biomarkers）是指**有明确定义、测量流程和使用情境**的脑电生理特征，可用于识别特定脑功能状态、辅助疾病评估、监测生理变化或研究预后；其中癫痫相关电生理发现和部分重症 EEG 模式具有确立的临床价值，而利用功率谱、连接性或 AI 模型单独诊断痴呆、抑郁和 ADHD 仍有明显证据边界。(FDA-NIH, 2025, BEST; Hirsch et al., 2021, J Clin Neurophysiol; Gloss et al., 2016, Neurology; De Keulenaer et al., 2025, Neurol Sci)

## 快速理解

EEG 通过头皮电极记录神经群体活动在体积传导之后形成的电位差，时间分辨率较高，可连续、反复、床旁采集。研究者从波形中观察突发放电、整体背景、睡眠相关模式，或计算频谱、事件相关电位（ERP）、连接与复杂度指标。**同一个“脑电异常”可能只是非特异的脑功能变化，也可能是具有明确临床意义的特定电生理事件，不能一概称为疾病特异性标志物。**(Peltola et al., 2023, Epilepsia; Donoghue et al., 2020, Nat Neurosci)

将技术按照临床**决策问题**划分，比按某个波段名称建立“疾病—脑波对照表”更有意义：

| 临床／科研问题 | 常见 EEG 指标 | 当前合理用途 | 关键不能外推之处 |
| --- | --- | --- | --- |
| 疑似癫痫或首次非诱发发作 | 间期癫痫样放电（IED）、电图发作，结合视频 | 作为临床诊断与复发风险判断的重要**辅助证据** `(Krumholz et al., 2015, Neurology; Kural et al., 2020, Neurology)` | 一次阴性短程 EEG 不能排除癫痫；IED 阳性也需结合病史 |
| 重症意识异常、疑似非惊厥性发作 | 连续 EEG 发作、电图持续状态、周期／节律模式 | 检出难以从床旁行为观察到的发作，协助抗发作治疗 `(Herman et al., 2015a, J Clin Neurophysiol; Hirsch et al., 2021, J Clin Neurophysiol)` | 更多发作检出不自动等于更低死亡率或更好功能结局 |
| 心脏骤停后昏迷的预后评估 | 在规定时点的背景抑制、爆发抑制等 | **多模态预后评估中的一个组成部分** `(Rajajee et al., 2023, Neurocrit Care)` | 不能单凭 EEG 决定生命支持或认定个体无法恢复 |
| 意识障碍中隐匿的指令反应 | 任务态 EEG 的运动想象／命令反应 | 研究和部分专科评估中的附加线索 `(Bodien et al., 2024, N Engl J Med)` | EEG 或 fMRI 有反应，不等于普通静息 EEG 可以“读出意识”；阴性不能排除意识 |
| MCI／阿尔茨海默病／DLB 等 | 频谱减慢、后部主导节律、连接性、复杂度 | 候选表型指标与疾病机制研究，选定病例中协助鉴别其他脑病 `(De Keulenaer et al., 2025, Neurol Sci; Van Langenhove et al., 2026, Eur J Neurol)` | 不是 Aβ、tau 病理的替代检测，也未成为一般人群可靠的单项确诊法 |
| 抑郁、ADHD、精神病性障碍 | 额叶 α 不对称、θ/β 比、MMN、P300 | 部分指标有群体关联，个别有纵向研究价值 `(Luo et al., 2025, npj Ment Health Res; Fuentes-Claramonte et al., 2024, Schizophr Bull Open)` | 群体平均差异不能自动实现患者层面的高准确性诊断 |

**最重要的区别：** “具有神经生理意义”“能区分研究样本”“能预测某种结局”“能够在日常临床改变决策并改善患者获益”是不同层级的证据。EEG 一般情况下是**测量手段**；只有某项明确定义的特征在指定用途下得到相应验证时，才宜讨论它是否为特定类型的生物标志物。(FDA-NIH, 2025, BEST; Bossuyt et al., 2015, BMJ)

## 科学依据与关键前提

### 1. 什么才算“生物标志物”，与普通 EEG 描述有什么不同？

FDA/NIH BEST 术语将生物标志物定义为反映正常生物过程、致病过程或暴露／干预反应的**可测量特征**，并区分易感／风险、诊断、监测、预后、预测、药效／反应和安全性用途。**“某波段功率升高”是可量化的观察描述，不自动等于“诊断某疾病的已验证标志物”。**(FDA-NIH, 2025, BEST)

从概念上可以分为五个层次：

1. **原始生理信号：** 头皮 EEG 的电位差与相位关系；主要来自同步突触后活动等群体电场作用，受体积传导、头部结构、电极和参考选择影响。
2. **可复核 EEG 特征：** 如经标准条件判读的 IED、特定电图发作、背景连续性与反应性，或预定义的频谱／ERP 特征。
3. **分析有效性（analytical validity）：** 相同条件是否测得到、评分者是否一致、设备间能否复现、伪迹是否可控制。
4. **临床有效性（clinical validity）：** 能否在目标患者群体中准确回答**预先定义的诊断或预后问题**，而非仅在病例—健康对照中区分两组。
5. **临床实用性（clinical utility）：** 把该指标加入实际诊疗后，是否改变合理决策、减少风险、改善患者重要结局，同时成本与不良后果是否可接受。

这套层次是结合生物标志物定义及诊断模型报告规范给出的**本节点分析框架**，不是说所有指标均已经完成五级验证。(FDA-NIH, 2025, BEST; Bossuyt et al., 2015, BMJ; Collins et al., 2024, BMJ)

### 2. 常见特征与研究机制

| 特征类别 | 常见计算／观察对象 | 可解释内容与局限 |
| --- | --- | --- |
| **波形与事件** | IED、尖波／棘波、棘慢复合波、电图发作、周期性放电 | 需遵循明确形态、时程、场分布和演变准则；肌电、眼动、良性变异和伪迹可造成误判 `(Kural et al., 2020, Neurology; Hirsch et al., 2021, J Clin Neurophysiol)` |
| **背景活动** | 后部主导节律（PDR）、连续性、对称性、反应性、弥漫性慢波、爆发抑制 | 可揭示脑状态、觉醒水平或广泛功能障碍；受镇静、低温、代谢、年龄和睡眠影响 `(Westhall et al., 2016, Neurology; Rajajee et al., 2023, Neurocrit Care)` |
| **频谱特征（qEEG）** | δ／θ／α／β 等频带的绝对或相对功率、峰值频率、频带比值 | 能概括振荡谱；固定频段边界与非周期背景混淆会改变结论，频谱减慢通常缺乏疾病特异性 `(Donoghue et al., 2020, Nat Neurosci; De Keulenaer et al., 2025, Neurol Sci)` |
| **事件相关电位（ERP）** | MMN、P300 等刺激锁定的平均反应及延迟 | 指向感觉预测、注意及认知处理的某些环节；组间差异不等于个体病因确定 `(Donaldson et al., 2023, Psychol Med; Fuentes-Claramonte et al., 2024, Schizophr Bull Open)` |
| **连接性与网络** | 相干、相位关系、图指标、源空间功能连接 | 可表达脑网络协同，但参考方案、共同源、体积传导、滤波与源定位假设会引入伪连接 `(Chetty et al., 2024, Alzheimers Res Ther; Kucikova et al., 2024, Ageing Res Rev)` |
| **复杂度与 AI 嵌入** | 信号复杂性、熵、非线性动态、深度学习表示 | 可提高统计分类能力，但易学习年龄、设备、机构差异、伪迹和患者身份而非疾病机制 `(Sitt et al., 2014, Brain; Roy et al., 2019, J Neural Eng; Tveit et al., 2023, JAMA Neurol)` |

**频谱方法学陷阱：** 功率谱同时包含相对周期性的振荡峰和近似 1/f 的非周期背景。不同年龄／疾病／觉醒状态可能改变非周期背景斜率，使固定 α 或 θ 频带功率的变化被错误解释成特定神经振荡增强；参数分离能减少这类混淆，但也需报告拟合范围、假设与质量控制。(Donoghue et al., 2020, Nat Neurosci)

### 3. 癫痫：临床价值明确，但“放电—疾病”并非一一对应

\*\*间期癫痫样放电（IED）\*\*能增加对癫痫的怀疑程度，并在首次非诱发发作后的复发风险估计中提供信息；其具体价值仍需结合事件特征、既往脑损伤、影像与其他诊断信息。人群研究表明一次常规 EEG 对间歇性异常的检出率有限，因此单次阴性记录不能排除癫痫。(Baldin et al., 2014, Epilepsia; Krumholz et al., 2015, Neurology)

错误解读正常变异为 IED 可能导致长期错误诊断。临床验证研究使用 IFCN 描述的多个形态和场分布准则对可疑放电进行盲法评估，提高判读的可操作性，但同样不能将这些条件机械地替代患者整体病史。**“具有癫痫样放电”是电生理证据，不等于“存在某类特定遗传癫痫综合征”**。(Kural et al., 2020, Neurology)

### 4. 重症：电图发作检出、治疗调整和预后是不同终点

对于昏迷、原因不明的意识改变、急性脑损伤和疑似非惊厥性癫痫发作患者，持续 EEG（cEEG）可能发现常规床旁观察难以识别的电图发作。ACNS 将电图发作、周期性放电、节律性模式及其演变用标准化术语描述，避免不同医院对相同图形给出含糊名称。(Herman et al., 2015a, J Clin Neurophysiol; Hirsch et al., 2021, J Clin Neurophysiol)

重症周期／节律性图形的一部分属于**发作—间期连续谱（ictal–interictal continuum）**：不能把每次周期性放电都当成必须治疗的确定电图持续状态。初始 EEG 所见可与临床特点联合，用 2HELPS2B 等模型分层评估后续监测需要，但评分工具没有覆盖全部成人、儿童、病因和治疗条件。(Struck et al., 2020, JAMA Neurol)

关键反例：CERTA 多中心随机试验比较 cEEG 和重复常规 EEG。持续记录**发现更多电图发作、促成更多抗发作治疗调整**，却未证实患者死亡率相应下降；这并不说明重症 EEG 无价值，而是提醒**发现一个事件、改变一个治疗动作、改善远期结局需要逐级验证**。(Rossetti et al., 2020, JAMA Neurol)

### 5. 心脏骤停后预后：时点、镇静和自我实现偏倚不可省略

心脏骤停后长期昏迷者的 EEG 背景抑制或爆发抑制等模式与不良神经结局相关。标准化判读研究和 2023 年神经重症预后指南支持其在**特定复苏／复温时间窗、没有镇静及低温等重大混杂因素**时的预后评估价值。(Westhall et al., 2016, Neurology; Rajajee et al., 2023, Neurocrit Care)

但这项证据特别易受**自我实现预言（self-fulfilling prophecy）**影响：若临床医生根据早期脑电异常决定撤除生命支持，随后出现的不良结果并不是完全独立于评估结果。2023 年指南把特定 EEG 抑制／爆发抑制模式评为**中等可靠**的不良预后预测因子，且为弱建议、低质量证据，并要求多模态评估；因此不能将单次 EEG 或 AI 预后分数作为终止治疗的唯一依据。(Rajajee et al., 2023, Neurocrit Care)

### 6. 意识障碍：静息态、任务态和意识本身是三个不同层级

静息 EEG 的低频功率、复杂度与跨电极信息交换等统计指标，能在某些研究中区分不同意识障碍临床状态；但这类指标大多仍是辅助表型，不能单独等同于“证明患者有或没有主观意识”。(Sitt et al., 2014, Brain)

任务态 EEG 则通过要求患者尝试完成运动想象等命令，探测是否存在与指令一致的脑活动。早期急性脑损伤研究和 2024 年多中心队列都发现，部分**床旁行为无法遵循指令**的患者仍具有可检测的命令相关脑反应。2024 年研究中，**241 名没有可观察指令反应者有 60 人（约四分之一）**呈现认知运动分离；这是**任务态 EEG 或 fMRI 或二者合用的总体结果**，绝不能误写为“仅凭常规 EEG 发现四分之一患者清醒”。(Claassen et al., 2019, N Engl J Med; Bodien et al., 2024, N Engl J Med)

任务反应阴性也可能出现在听觉理解受损、疲劳、注意资源不足或测试实施困难的人身上。阴性 EEG／fMRI 不足以证实“没有意识”，阳性也不等于具有稳定的日常交流能力。(Bodien et al., 2024, N Engl J Med)

### 7. 痴呆与神经退行性疾病：常见减慢，不代表 AD 病理特异性

AD、路易体痴呆（DLB）及部分其他神经退行性疾病的 EEG 可出现节律频率变慢、相对低频功率变化及连接异常；跨疾病系统评价发现这些表型有研究价值，但多个病种间频谱表现重叠，额外受到药物、警觉性和病程的影响。(Chetty et al., 2024, Alzheimers Res Ther; Kucikova et al., 2024, Ageing Res Rev; De Keulenaer et al., 2025, Neurol Sci)

特别要区分“以认知测验诊断病例／对照”的机器学习研究与“有 Aβ、tau 等核心病理证据”的疾病生物学验证。2024 年 AD 修订标准重视特定分子与影像标志物；2025 年 EEG/MEG 多模态系统回顾强调与病理生物标志物衔接仍需更多纵向研究。2026 年比利时专家路径共识明确指出，**常规 EEG 不在其 AD 生物标志物诊断路径内**，但在癫痫、代谢／中毒性脑病、快速进展性痴呆和特殊鉴别诊断时仍有选择性用途。(Jack et al., 2024, Alzheimers Dement; Sohrabpour et al., 2025, Alzheimers Dement; Van Langenhove et al., 2026, Eur J Neurol)

### 8. 精神疾病：强群体差异仍可能无法辅助个体确诊

**抑郁：** 2025 年静息额叶 α 不对称（FAA）元分析纳入多组病例与对照，发现总体效应虽有统计学信号，却很小，因此不宜把某种“左右脑 α 不平衡”当作抑郁症的独立生物诊断指标。(Luo et al., 2025, npj Ment Health Res)

**ADHD：** EEG θ/β 比及额叶 β 指标曾被用于研发辅助工具；美国神经病学学会指出其假阳性及泛化问题，明确不支持其替代标准临床诊断，且不建议在研究条件外用 θ/β 比确认诊断或支持后续测试；相关实践建议于 2025 年获再次确认。**某特定年龄段辅助设备曾获监管许可，不等于 EEG 指标足以自行确诊 ADHD，也不等于专业指南认可为常规替代方案。**(Gloss et al., 2016, Neurology; AAN, 2025, Practice Advisory)

**精神病性障碍：** MMN／P300 的某些指标存在跨研究群体关联；纵向研究还提示 MMN 某些成分与长期症状和功能轨迹有关。但伞状综述指出研究间异质性明显；2025 年针对 EEG 区分原发与继发精神病病因的荟萃分析显示总体判别力有限。因此不能将“MMN 较低”写成个体精神分裂症确诊，也不能凭单次异常 EEG 判定精神症状来自器质性病因。(Donaldson et al., 2023, Psychol Med; Fuentes-Claramonte et al., 2024, Schizophr Bull Open; Fanshawe et al., 2025, Schizophr Res)

## 实际实施方式

### 1. 在开立 EEG 前写下明确的“预期用途”

要求首先把临床问题定义为以下之一：

- **辅助诊断：** 例如怀疑癫痫、非惊厥性发作、特定脑病的异常放电；明确为何 EEG 比单纯临床观察有额外信息价值。
- **监测：** 例如重症持续电图发作负荷，或治疗前后的 EEG 变化；明确需多久的记录与观察窗口。
- **预后：** 例如规定复苏阶段的 EEG 背景特征；明确结局、时间窗、镇静等混杂因素及联合证据。
- **探索性候选标志物：** 例如 MCI/AD 的 θ 功率、连接性、抑郁 FAA 或脑电 AI 分数；使用前规定目标样本、临床参照标准和外部验证计划。
- **治疗反应与算法评估：** 若要宣称“预测何种药物更有效”，必须有对应治疗、预测—交互效应及外部验证，不能凭治疗前后相关性臆断。(FDA-NIH, 2025, BEST; Collins et al., 2024, BMJ)

### 2. 规范采集与记录

**临床采集：** 按目标人群遵循国际与本地 EEG 最低记录标准；说明是清醒／闭眼／睁眼、睡眠、睡眠剥夺、诱发试验、视频 EEG 还是 ICU 持续 EEG。记录电极布局、参考、采样率、阻抗／接触、滤波、时间窗、药物、警觉状态、是否中断等信息。IFCN 电极标准强调下颞电极覆盖的意义，而 2023 IFCN/ILAE 指南为常规和睡眠 EEG 提供最低要求，其部分推荐依赖较低或中等质量证据和专家共识。(Seeck et al., 2017, Clin Neurophysiol; Peltola et al., 2023, Epilepsia)

**采集目的与实现能力应匹配：** 常规 EEG 对于罕见事件可能采样不足；长时间视频 EEG 和 cEEG 则可能带来较高人员、硬件、隐私和判读负担。不能仅因为设备能连续记录就推断长时监测对所有患者都具有增量临床收益。(Baldin et al., 2014, Epilepsia; Herman et al., 2015b, J Clin Neurophysiol; Rossetti et al., 2020, JAMA Neurol)

| 阶段 | 最低限度记录项 | 常见偏倚与控制方式 |
| --- | --- | --- |
| **A. 确定问题** | 目标综合征／结局、目标人群、用途、决策阈值、计划改变的临床行动 | 防止“先看波形再指定疾病”导致事后解释 `(Bossuyt et al., 2015, BMJ)` |
| **B. 收集数据** | 诊断基线与用药、年龄、睡眠／觉醒、设备、电极、参考、采样、任务设计、记录长度 | 不同状态、硬件和受试者选择可改变特征 `(Seeck et al., 2017, Clin Neurophysiol; Peltola et al., 2023, Epilepsia)` |
| **C. 品质控制** | 坏道、眼电／肌电／心电／运动伪迹、丢包、重参考、滤波和剔除比例 | 肌电被误解为高频活动，低频漂移被误解为脑波；需报告被剔除记录的分布 |
| **D. 特征提取** | 预注册的频带、窗长、平均方式、PSD 周期／非周期分量、IED 判据、ERP 测量窗口 | 特征选择、多重比较与频谱背景混淆 `(Donoghue et al., 2020, Nat Neurosci; Kural et al., 2020, Neurology)` |
| **E. 人工／模型判读** | 判读资质、是否盲法、评分者一致性、分歧处理、自动化异常提示与最终报告 | 误读良性变异、AI 黑箱和阈值漂移；结构化 SCORE 能改进规范性 `(Beniczky et al., 2017, Clin Neurophysiol; Tveit et al., 2023, JAMA Neurol)` |
| **F. 独立验证** | 以**受试者**及医院为单位隔离训练／测试，报告敏感度、特异度、PPV／NPV、AUC、校准及置信区间 | 不能把同一患者切成多个时间窗后随机打散形成虚假“独立测试” `(Roy et al., 2019, J Neural Eng; Collins et al., 2024, BMJ)` |
| **G. 临床落地** | 异常触发后具体谁复核、谁通知、是否转诊／治疗、未检出时的替代方案与随访结果 | “识别更多信号”不等于“改善患者结局”；需比较新增成本与误报 `(Rossetti et al., 2020, JAMA Neurol)` |

用于研究共享的原始 EEG 与衍生数据可按 EEG-BIDS 规范组织，保留采集元数据、事件和处理记录。此举改善再分析与研究复现条件，但 EEG-BIDS 文件合规并不能证明某模型具有临床诊断性能。(Pernet et al., 2019, Sci Data)

### 4. 报告中应怎样写诊断结论？

应分开三句话：

1. **“测到什么”：** 如记录中存在符合判据的特定放电／背景模式，给出通道、时间、状态、数量或置信范围，以及局限。
2. **“支持何种临床判断”：** 例如提高癫痫可能性，提示需要继续评估非惊厥性发作，或纳入昏迷多模态预后评估。
3. **“尚不能证明什么”：** 例如不能凭短程阴性排除癫痫、凭 EEG 慢波确诊 AD、凭抑郁 FAA 或 ADHD θ/β 比独立完成精神疾病诊断。(Krumholz et al., 2015, Neurology; Jack et al., 2024, Alzheimers Dement; Gloss et al., 2016, Neurology)

临床 EEG 报告宜采用标准化术语和由有资质人员作最终综合解读；自动标注和辅助量化结果应可追溯到原始 EEG，不能只留一个没有复核通道的“患病概率”。(Beniczky et al., 2017, Clin Neurophysiol; Hirsch et al., 2021, J Clin Neurophysiol)

## 有效性与安全性证据

### 1. 按证据强度横向比较，不以算法指标高低直接排名

| 临床方向／研究 | 证据类型与直接观察 | 能成立的结论 | 必须保留的局限 |
| --- | --- | --- | --- |
| **IED 形态学** `(Kural et al., 2020, Neurology)` | 病例与对照经过视频 EEG 确认后，多位阅片者对可疑放电盲评 | 标准化判据可减少不合理的“见尖就诊断” | 特定异常片段的判读表现不能直接代表所有患者的诊断准确率 |
| **首次发作／复发风险** `(Baldin et al., 2014, Epilepsia; Krumholz et al., 2015, Neurology)` | 人群 EEG 检出研究与神经科治疗指南 | IED 是重要风险线索之一，且一次常规 EEG 有漏检 | 无 IED 不能排除，阳性也需考虑临床事件与风险基线 |
| **住院发作风险** `(Struck et al., 2020, JAMA Neurol)` | 对 2HELPS2B 模型进行住院病人验证 | 风险评分可辅助决定监测时长 | 不是个人发作的必然预测或所有 ICU 患者的通用算法 |
| **重症 cEEG 随机试验** `(Rossetti et al., 2020, JAMA Neurol)` | 多中心随机比较 cEEG 与重复常规 EEG | 更多检出、更多治疗调整 | **未证明降低死亡率**；不同患者及研究场景不能盲目外推 |
| **复苏后昏迷** `(Westhall et al., 2016, Neurology; Rajajee et al., 2023, Neurocrit Care)` | 队列分析和方法学指南 | 特定时点背景异常可支持不良预后评估 | 低温、药物、技术条件及撤除治疗相关的自我实现偏倚 |
| **认知运动分离** `(Bodien et al., 2024, N Engl J Med)` | 六中心前瞻性 EEG 或 fMRI 任务态评估 | 60/241 名无可观察指令反应者有检测到的任务反应 | **联合模态结果，不是 EEG 单项敏感度**；样本为专科便利队列 |
| **临床 EEG 自动判读** `(Tveit et al., 2023, JAMA Neurol)` | 多数据集测试，异常类型 AUC 约 0.89–0.96 | AI 有望辅助分类与减轻阅读工作量 | AUC 不是 PPV，不等于外部前瞻性流程改善，也不等于能鉴别疾病病因 |
| **AD／DLB／FTD 标志物** `(De Keulenaer et al., 2025, Neurol Sci; Sohrabpour et al., 2025, Alzheimers Dement)` | 频谱、连接和跨模态系统回顾 | 部分特征在特定样本中有关联和鉴别潜力 | 病种重叠、参考病理异质、跨设备/中心标准不足 |
| **AD EEG 候选频谱** `(Chetty et al., 2024, Alzheimers Res Ther)` | AD、前驱期相关临床组别与对照的频谱及连接观察 | 提供某些候选特征与模型研究方向 | 非全部个体经病理独立确认，指标尚未取得通用独立诊断地位 |
| **抑郁 FAA** `(Luo et al., 2025, npj Ment Health Res)` | Meta：23 个数据组、1,928 名 MDD 与 2,604 名对照 | 发现较小的总体群体效应 | 临床个体准确性不足，不能作为独立确诊工具 |
| **ADHD θ/β** `(Gloss et al., 2016, Neurology; AAN, 2025, Practice Advisory)` | 神经病学学会审查与后续维持建议 | 不能替代标准临床评价，普通诊疗有误诊风险 | 监管层某特定设备的辅助许可不改变这一证据边界 |
| **精神病性障碍 EEG 病因鉴别** `(Fanshawe et al., 2025, Schizophr Res)` | 38 篇研究荟萃；总体 AUC 约 0.67 | EEG 单独区分继发与原发精神病的能力有限 | 未排除定向使用 EEG 检查特殊脑病的潜在价值 |
| **MMN 的纵向相关性** `(Donaldson et al., 2023, Psychol Med)` | 五年纵向患者及对照研究 | 某些 MMN 特征相对稳定并与病程有关 | 不是独立、可直接改变治疗的预测标志物 |

**研究数量不等于独立样本数量。** 同一个 EEG 数据集经不同滤波、分段、特征工程和模型架构发表为多项论文，并不能视为多项独立临床重复。文末系统评价可能包含前述原始研究；不能再把被纳入研究与综述重复计为各自的外部证据。(Roy et al., 2019, J Neural Eng; De Keulenaer et al., 2025, Neurol Sci)

### 2. 对定量和 AI EEG 的最低验收框架

**诊断准确性**至少评估：目标人群代表性、真实世界疾病患病率、明确独立的诊断参照标准、观察者盲法、测试样本是否未参与任何阈值选择，以及敏感度、特异度、预测值和可信区间。使用同一病人的多个窗口做普通随机分折，极可能高估性能；需要**严格受试者级划分**，更理想的是跨医院／跨设备、预先冻结模型后的外部验证。(Bossuyt et al., 2015, BMJ; Collins et al., 2024, BMJ)

**预后与治疗指导**还须评估：预测时间窗、是否纳入病情严重程度／镇静药量、模型校准、关键亚群和医疗流程依赖，以及使用该预测后是否改善患者安全与重要结局；对昏迷预后尤其要防止 AI 结论导致撤除生命支持的自我实现偏倚。(Rajajee et al., 2023, Neurocrit Care; Collins et al., 2024, BMJ)

**算法比较**建议始终报告简单可解释基线（如单个临床 EEG 项目或 Logistic 回归模型）及临床信息的增量价值；不能用“相对于健康对照的 AUC 很高”替代与真正可能混淆的疾病比较。SCORE-AI 的多数据集验证说明自动化有潜力，但不是证明所有 EEG 深度学习产品都可直接临床部署。(Tveit et al., 2023, JAMA Neurol; Roy et al., 2019, J Neural Eng)

### 3. 伪迹、误判和安全性

头皮 EEG 通常是非侵入性的；更常见的危害来自**解释错误及其引发的决策**：

- 眼动、眨眼、咬肌与颞肌收缩、电极松动、环境电噪声以及参考电极变化，可产生貌似异常的波形或改变频谱特征。尤其应谨慎解释头皮“高频 γ 增强”和非标准佩戴设备中的低频波动。
- 正常 EEG 变异或伪迹被错误标记为 IED，可能导致癫痫误诊、长期服药、驾驶与职业限制；反过来，短程阴性也可能造成漏诊。(Kural et al., 2020, Neurology; Baldin et al., 2014, Epilepsia)
- “EEG 检出异常＝某种严重脑病”可能造成不必要的心理负担、医疗费用与延误其他检查。针对 AD、抑郁与 ADHD 的商业检测必须明确其测试条件、目标疾病、许可状态和独立验证情况。(Van Langenhove et al., 2026, Eur J Neurol; Luo et al., 2025, npj Ment Health Res; Gloss et al., 2016, Neurology)
- 在 ICU 等高风险场景，不恰当的异常警报可能导致过度镇静／抗发作治疗，或不适当的撤除生命支持；需由合格临床团队复核并采用多模态判断。(Rossetti et al., 2020, JAMA Neurol; Rajajee et al., 2023, Neurocrit Care)

## 当前成熟度

以下为**截至 2026 年 10 月 17 日的编辑性分级**，依据指定用途的证据，而不是按“传统 EEG / AI EEG”粗分。不同国家的设备注册、医保、临床使用权和指南更新应分别核查。

| 用途／指标 | 当前成熟度 | 主要依据 | 尚不允许的结论 |
| --- | --- | --- | --- |
| **临床 EEG 对癫痫样放电／电图发作的辅助判读** | **成熟临床应用** | IFCN 标准、IED 验证、首发癫痫指南 `(Kural et al., 2020, Neurology; Krumholz et al., 2015, Neurology; Peltola et al., 2023, Epilepsia)` | 一次记录完成全部诊断；负 EEG 可排除癫痫 |
| **ICU EEG／cEEG 的非惊厥性发作监测** | **有明确适应证的临床实践** | ACNS 共识、2HELPS2B 和 CERTA 随机试验 `(Herman et al., 2015a, J Clin Neurophysiol; Struck et al., 2020, JAMA Neurol; Rossetti et al., 2020, JAMA Neurol)` | 所有患者延长记录都能减少死亡率 |
| **心脏骤停后 EEG 多模态预后** | **特定条件下有指南支持，但须审慎使用** | 神经重症预后指南 `(Rajajee et al., 2023, Neurocrit Care)` | 单凭 EEG 决定个体不可恢复／终止治疗 |
| **重度意识障碍静息／任务态 EEG** | **专科评估与研究性增强检测** | 意识复杂度和任务态多中心研究 `(Sitt et al., 2014, Brain; Bodien et al., 2024, N Engl J Med)` | 阴性等于无意识；联合 EEG/fMRI 结果等于常规 EEG 检出率 |
| **AD／DLB／MCI 的 qEEG 与连接特征** | **候选研究标志物，尚非病理确诊主路径** | 临床研究、多项系统评价和 2026 年诊疗路径共识 `(Chetty et al., 2024, Alzheimers Res Ther; De Keulenaer et al., 2025, Neurol Sci; Van Langenhove et al., 2026, Eur J Neurol)` | 可取代 Aβ 或 tau 分子生物标志物 |
| **抑郁 FAA、ADHD θ/β** | **研究关联与受限辅助应用；常规独立诊断不成立** | 元分析、AAN 实践建议 `(Luo et al., 2025, npj Ment Health Res; Gloss et al., 2016, Neurology)` | 某种“脑波比例”能直接诊断精神疾病 |
| **精神病性障碍 MMN／P300** | **较多群体证据，个体诊断与治疗决策证据有限** | 纵向研究和伞状综述 `(Donaldson et al., 2023, Psychol Med; Fuentes-Claramonte et al., 2024, Schizophr Bull Open)` | 可以不结合临床诊断精神分裂症 |
| **AI EEG 的异常自动分类** | **已有多数据集验证的辅助技术，具体产品需逐一评估** | SCORE-AI 的多数据集测试 `(Tveit et al., 2023, JAMA Neurol)` | 任何 AI 分类分数等于临床病因诊断；可无人工复核地部署 |

## 限制、伦理与社会影响

### 1. 技术可达性并不等于人群公平性

年龄、颅骨和头皮特征、发量、皮肤接触、电极帽适配、不同地区可用的硬件、是否能安静配合、是否可以完成特定语言指令，都会改变 EEG 数据品质。儿童、老年人、重症患者和存在运动异常的人需要与研究场景匹配的判读与参照标准；不能把训练于年轻、无病、清醒受试者的 qEEG 常模直接套用于所有患者。(Seeck et al., 2017, Clin Neurophysiol; Peltola et al., 2023, Epilepsia)

### 2. 数据隐私和二次用途

EEG 与视频、睡眠、医疗记录、任务指令和身份信息合并后，可能暴露敏感的疾病、功能或行为线索。数据收集应明确临床目的、研究再利用授权、存储期限和访问权限；向 AI 企业分享原始记录前，需审查去标识化和跨机构再识别风险。**数据结构规范有助于科研共享，并不自动完成伦理同意或隐私保护。**(Pernet et al., 2019, Sci Data)

### 3. 解释权、AI 自动化偏倚和商业宣传

当脑电热图或“神经年龄”“抑郁风险”“阿尔茨海默病概率”出现在报告中，用户容易将可视化数字误解为具有高度疾病特异性的诊断。应说明**参考人群、模型训练数据、验证地点、疾病基线率、假阳性、亚组偏倚和未获验证的用途**，并允许临床医生查看原始 EEG 和标注证据。(Collins et al., 2024, BMJ; Tveit et al., 2023, JAMA Neurol)

对于昏迷、意识障碍等高度敏感的医疗决策，更需向家属解释 EEG 的不确定性，尤其不能将一项算法的“低恢复概率”当作个体命运的确定结论。支持多次复核、多模态测量与知情沟通；专业人员应识别可能由早期医疗决定引发的自我实现偏倚。(Rajajee et al., 2023, Neurocrit Care; Bodien et al., 2024, N Engl J Med)

### 4. 尚需验证的问题

1. 预注册的数据处理方案、多个 EEG 设备与真实医院之间，能否稳定保持候选 qEEG 标志物的阈值、校准和净临床价值？(Donoghue et al., 2020, Nat Neurosci; Pernet et al., 2019, Sci Data)
2. 怎样在**真正相似的临床竞争诊断**之间验证 AD／DLB 等 EEG 特征，而不是只进行病例—年轻健康对照分类？如何与分子生物标志物联合？(Sohrabpour et al., 2025, Alzheimers Dement; Van Langenhove et al., 2026, Eur J Neurol)
3. 何种认知运动分离任务在不同机构与损伤阶段可重复？对于测试阴性的患者，临床团队应怎样降低误判风险？(Bodien et al., 2024, N Engl J Med)
4. 自动脑电异常提示能否在前瞻性研究中减少误诊、漏诊、人工负担或不良事件，而不仅在既有标注库上提高 AUC？(Tveit et al., 2023, JAMA Neurol; Collins et al., 2024, BMJ)
5. 能否将**诊断、预后、疗效反应**分别验证的 EEG 指标规范为真正可用于医疗决策的工具，并避免同一指标在多个未验证用途之间被商业性外推？(FDA-NIH, 2025, BEST; Bossuyt et al., 2015, BMJ)

**证据边界总结：** 具有生理意义的波形不等于疾病特异性的分子病理，模型测试集准确率不等于真实临床收益，群体相关不等于个体确诊，风险分数不等于因果机制。(FDA-NIH, 2025, BEST; Collins et al., 2024, BMJ)

## 相关节点

- **诊断与生物标志物：** 标准化认知筛查、阿尔茨海默病生物标志物、神经退行性疾病鉴别诊断、床旁监测、临床预后评估。
- **方法与模型：** 脑电图（EEG）、定量脑电（qEEG）、事件相关电位（ERP）、功率谱密度（PSD）、相位与功能连接、EEG-BIDS、自动化 EEG 判读、外部验证。
- **疾病与问题：** 癫痫、非惊厥性癫痫持续状态、意识障碍、缺氧性脑损伤、阿尔茨海默病、路易体痴呆、轻度认知障碍、ADHD、抑郁症和精神病性障碍。
- **证据与伦理：** 敏感度与特异度、阳性预测值、谱偏倚、设备间漂移、可重复性、临床实用性、神经数据隐私、医疗 AI 可信度。

- **主题定位：** 应用与转化 / 诊断与生物标志物；重点是特定 EEG 指标的临床用途、诊断准确性、监测和预后证据，而不是把所有 EEG 研究特征都视为已验证生物标志物。
- **证据分类：** 已区分指南／标准、病例队列、系统评价、临床随机试验、AI 验证与候选指标研究；书目含 35 条资料，未把同一标准的不同发表版本重复计数。
