# 岛叶

> **一句话定义：** 岛叶（insula / insular cortex，又称岛皮质、脑岛）位于大脑外侧沟（Sylvian fissure）深部，是一个具有显著细胞构筑、连接与功能异质性的皮质区；它在身体内部状态、味觉、体温与伤害性输入、情绪和行为相关信息的表示及调节中发挥重要作用，但不能被概括为单一的“情绪中枢”或“意识中心”。(Morel et al., 2013, Neuroscience; Kurth et al., 2010, Brain Struct Funct; Namkung et al., 2017, Trends Neurosci; Charbonneau et al., 2026, Nat Neurosci)

## 快速理解

岛叶常被描述为把“**身体正在发生什么**”与“**这些信号对当前行为有什么意义**”联系起来的皮质枢纽。饥饿时看到食物、感觉心跳、品尝味道、体验疼痛、注意突发重要事件，都有可能募集不同的岛叶亚区。这里的“枢纽”是连接与信息整合的概括性描述，**不意味着所有体验都由岛叶产生或必须经过岛叶才能发生**。(Craig, 2002, Nat Rev Neurosci; Craig, 2009, Nat Rev Neurosci; Gogolla, 2017, Curr Biol; Livneh et al., 2017, Nature)

- **结构上**，岛叶不是外侧脑表面可直接完整看到的一块皮质：需将额、顶、颞盖部打开，才可见其回、沟与前后组织；细胞构筑总体沿后背侧至前腹侧呈颗粒、弱颗粒和无颗粒的梯度。(Morel et al., 2013, Neuroscience; Quabs et al., 2022, NeuroImage)
- **感觉上**，中后岛叶更多与躯体感受、温度、内脏和疼痛相关输入联系；它也是人类味觉与岛盖—额盖网络的组成部分。说“更多与……相关”是统计概括，不能当作互不重叠的模块分隔。(Craig et al., 2000, Nat Neurosci; Mazzola et al., 2009, Pain; Kurth et al., 2010, Brain Struct Funct)
- **动机与情绪上**，前岛叶常参与主观身体感受、厌恶、渴求、风险及任务显著性等过程；其活动往往与前扣带、额叶及皮质下结构共同出现。(Wicker et al., 2003, Neuron; Singer et al., 2004, Science; Seeley et al., 2007, J Neurosci; Naqvi et al., 2007, Science)
- **认知网络上**，背侧前岛叶被视为显著性／控制相关网络的重要节点，与其他脑网络随任务变化的耦合有关；这主要来自功能连接与时序建模，不能直接描述为“岛叶开关命令所有脑网络”。(Sridharan et al., 2008, PNAS; Menon & Uddin, 2010, Brain Struct Funct; Uddin, 2015, Nat Rev Neurosci)
- **在更细尺度上**，小鼠投射组／活动记录以及猕猴单细胞数据说明，“前岛叶”“后岛叶”本身仍包含多种不同的神经元与微回路。(Gehrlach et al., 2020, eLife; Fodoulian et al., 2025, Nat Commun; Liu et al., 2026, Nat Cell Biol; Jongbloets et al., 2026, Nat Neurosci)

**读图与读论文时的核心提醒：** 岛叶在多种任务中激活，并不等于它对每项任务都有特异编码，也不等于它对正常完成这些任务都是必要的。(Kurth et al., 2010, Brain Struct Funct; Khalsa et al., 2009, Nat Neurosci; Davis et al., 2015, F1000Res; Kwon et al., 2026, Nat Commun)

## 概念界定与边界

### 1. 解剖边界

岛叶属于**端脑皮质（cerebral cortex）**，位于外侧沟深部，被额盖、顶盖和颞盖所覆盖；它以周围岛沟与邻近盖部皮质分隔，在前下端经岛阈（limen insulae）与周围前额—颞叶区域过渡。典型大体解剖可区分前部短岛回、后部长岛回，以及近似将两部隔开的中央岛沟（central insular sulcus）。个体与图谱的界线并不完全相同。(Morel et al., 2013, Neuroscience; Quabs et al., 2022, NeuroImage; Charbonneau et al., 2026, Nat Neurosci)

**岛叶 ≠ 岛盖（operculum）**。味觉、疼痛、声音及其他刺激的fMRI激活经常横跨岛叶—岛盖边界；对于空间分辨率不够的研究，将二者混称“岛叶活动”可能造成归因过度。**岛叶 ≠ 屏状核（claustrum）**：后者虽与岛叶相邻，但属于不同灰质结构；在小鼠“屏状核—岛叶区域”的空间转录组研究中，部分重要基因改变主要来自屏状核，而不能全部归因岛叶。(Morel et al., 2013, Neuroscience; Fodoulian et al., 2025, Nat Commun; Kwon et al., 2026, Nat Commun)

### 2. 大体分区、微结构分区与功能分区不是同一套标签

| 分区视角 | 常见表述 | 主要用途与局限 |
| --- | --- | --- |
| **肉眼解剖** | 前岛叶、后岛叶、短岛回、长岛回、中央岛沟 | 便于手术、影像定位；回沟边界不等于细胞构筑边界 |
| **细胞构筑** | 颗粒型（granular）、弱颗粒型（dysgranular）、无颗粒型（agranular）与多种过渡区 | 依据皮质层和细胞密度；整体存在梯度，地图因方法不同而有细节差异 |
| **常用功能分区** | 后岛叶（pIns）、背侧前岛叶（dAIns）、腹侧前岛叶（vAIns）等 | 基于多任务激活或连接聚类；不是各自只负责一种心理功能 |
| **网络归属** | 感觉运动、显著性／控制、情感相关网络等 | 与观测时的任务、参考图谱及模型有关；一片区域可参与多网络 |

尸检构筑研究显示，后背侧颗粒性较强、前腹侧趋向无颗粒的整体梯度；2013年研究描述了七个细分区，2022年概率图谱又进一步更新部分微结构边界。2011年静息态研究则提出后部、背侧前中部与腹侧前部三个连接群。**“3个功能簇”不是“全岛叶只有3种细胞区”，也不能与任一解剖地图逐区机械对齐。**(Morel et al., 2013, Neuroscience; Quabs et al., 2022, NeuroImage; Deen et al., 2011, Cereb Cortex)

### 3. 相关术语不要替换使用

- **内感受（interoception）**：感知或表征身体内部生理状态，如心血管、胃肠或呼吸相关信号；在现代研究中，其范围和任务操作定义仍存在差异。(Craig, 2002, Nat Rev Neurosci; Garfinkel et al., 2015, Biol Psychol)
- **躯体感觉（somatosensation）**：来自皮肤、肌肉等体部的触觉和感觉输入，与内感受存在重叠及相互辅助，不应全部视为岛叶专属。(Khalsa et al., 2009, Nat Neurosci; Craig et al., 2000, Nat Neurosci)
- **显著性（salience）**：事件对行为与资源分配的重要性，可以源自痛、奖赏、惊奇、威胁及任务需求；并不等同于“负性情绪”。(Seeley et al., 2007, J Neurosci; Uddin, 2015, Nat Rev Neurosci)
- **内感受准确性、自评敏感性、元认知觉察**：是可部分分离的测量维度。一个人“觉得自己对心跳特别敏感”，不必然意味着其心跳辨认客观成绩很高。(Garfinkel et al., 2015, Biol Psychol)
- **功能连接／有效连接／因果干预**：静息态信号共变、时序模型推断方向、病灶或刺激引发的行为变化，分别对应不同的证据强度。(Seeley et al., 2007, J Neurosci; Sridharan et al., 2008, PNAS; Khalsa et al., 2009, Nat Neurosci)

### 4. 物种与临床定义的边界

“人类前岛叶—前扣带网络”“猕猴前岛叶von Economo神经元（VEN）”“小鼠无颗粒岛叶（agranular insula）”不应当作一模一样的细胞类型或皮质亚区。跨物种有可比较的连接与组织梯度，但不同物种的岛叶范围、皮质分区细节与细胞组成存在差异。(Charbonneau et al., 2026, Nat Neurosci; Liu et al., 2026, Nat Cell Biol; Jongbloets et al., 2026, Nat Neurosci)

在临床记录中，“岛叶梗死”“岛叶癫痫”“额岛叶病理”也不意味着病灶只局限在岛叶本体；邻近岛盖、壳核、白质通路和血管供区的同时受累必须明确记录。(Calder et al., 2000, Nat Neurosci; Klepzig et al., 2023, Brain Commun; Lotze, 2024, NeuroImage)

## 结构与机制（适用时）

### 1. 细胞层次：颗粒性梯度和特殊投射神经元

按典型皮质层结构，后背侧岛叶偏向具有相对明显的第四层颗粒细胞特征；向前、向腹侧，第四层颗粒化逐渐减弱，部分区域呈无颗粒皮质。该梯度提示不同区域的输入整合与远程输出模式可能存在系统差异，但**层次分类本身并不足以推演出行为功能**。(Morel et al., 2013, Neuroscience; Quabs et al., 2022, NeuroImage; Kittleson et al., 2024, Neurosci Biobehav Rev)

前岛叶及相邻额岛区可见**von Economo神经元（VEN）**，常具有较大的梭形胞体与特殊树突排列。2006年额颞叶变性脑组织分析提出其选择性脆弱性；2026年猕猴前岛叶单细胞＋膜片钳研究识别出分子／电生理性质不同的VEN亚型，并提出其轴突起始部位与胞体信号整合有关。这是**细胞类型与机制层次的新证据，不是证明VEN是共情、意识或高级智能唯一载体**。(Seeley et al., 2006, Ann Neurol; Liu et al., 2026, Nat Cell Biol)

2026年小鼠大规模形态、局部输入与电生理测量进一步揭示岛叶锥体神经元并非均匀群体，而是具有不同树突、电特性与投射组合；不同物种的细胞类群不宜只凭形态相似就视为同源类型。(Jongbloets et al., 2026, Nat Neurosci; Charbonneau et al., 2026, Nat Neurosci)

### 2. 网络连接：后部偏感觉输入，前部偏跨系统整合——但并非一条单向传送带

来自躯体和内脏的感觉可经脑干—丘脑与其他中继进入岛叶相关网络；岛叶又与躯体感觉区、岛盖、前扣带、眶额皮质、杏仁核、纹状体、丘脑与下丘脑等多区域有不同程度联系。不同投射的解剖证明主要来自动物示踪，人的扩散MRI与功能连接通常不能以同样的精度确定突触级输入方向。(Craig, 2002, Nat Rev Neurosci; Morel et al., 2013, Neuroscience; Gehrlach et al., 2020, eLife; Charbonneau et al., 2026, Nat Neurosci)

小鼠全脑病毒示踪显示，前段与较后部岛叶连接模式存在差异，一些皮质连接相对双向，部分皮质下连接表现方向性；这些数据支持按回路分区，而不是给整块岛叶指定一种无差别的输出功能。(Gehrlach et al., 2020, eLife)

人类静息态研究显示，后岛叶较常连接感觉运动相关网络，背侧前中岛叶更常连接前扣带与控制网络，腹侧前岛叶则与情感相关扣带区域关系较强。不同研究的簇数、边界并不必然一致，且BOLD功能连接本身不是解剖性的轴突追踪。(Deen et al., 2011, Cereb Cortex; Seeley et al., 2007, J Neurosci; Kurth et al., 2010, Brain Struct Funct)

### 3. 内感受：从外周身体信号到状态判断

一种有影响力的模型认为，较后部岛叶更多接收内感受的感觉表征，沿岛叶向前逐级与动机、情绪、自我相关判断融合，前岛叶于是更常在主观感受任务中被激活。PET热感研究和心跳感知fMRI提供了重要的相关性支持；但该模型是**对异质证据的理论整合，而非确定的“每一条感觉必须按后→前顺序流动”的单一路径定律**。(Craig et al., 2000, Nat Neurosci; Craig, 2002, Nat Rev Neurosci; Critchley et al., 2004, Nat Neurosci; Craig, 2009, Nat Rev Neurosci)

2004年的心跳感知实验中，右前岛叶／岛盖信号与任务表现相关；2009年的病灶和药理研究却显示，在岛叶与前扣带受损的个体，心跳感觉仍可经皮肤等躯体感觉路径保留。二者并非简单互相否定：前者讨论**在完整脑系统中谁随表现共同活动**，后者更接近**某条通道丧失后是否还可能完成同类任务**。(Critchley et al., 2004, Nat Neurosci; Khalsa et al., 2009, Nat Neurosci)

测量上还要区分“准确辨认身体变化”“自我报告对身体信号的敏感程度”和“对自己是否判断正确有多清楚”三维，不能把一项自评问卷当作岛叶内感受功能的独立客观测量。(Garfinkel et al., 2015, Biol Psychol)

### 4. 温度、疼痛和体部表征：参与不等于疼痛专属

2000年PET实验发现冷刺激与中后岛叶背侧区域的血流改变有系统联系；2009年在癫痫患者岛叶的直接电刺激中，有部分刺激点能诱发主观疼痛，且在部分案例中呈现体部定位。然而直接电刺激也可能激活临近纤维与网络，且同一区域的多数刺激未诱发疼痛。(Craig et al., 2000, Nat Neurosci; Mazzola et al., 2009, Pain)

疼痛成像元分析确认岛叶与前扣带等网络频繁参与伤害性刺激加工。2015年持续痛灌注成像研究强调背侧后岛叶的重要性，但同年发表的学术评论指出其对“疼痛特异性”的论证缺少充分非痛条件比较。应把“伤害性刺激加工中的稳定参与”和“对疼痛独有或充分必要”拆开讨论。(Duerden & Albanese, 2013, Hum Brain Mapp; Segerdahl et al., 2015, Nat Neurosci; Davis et al., 2015, F1000Res)

2018年的疼痛生物标记综述进一步强调，“疼痛矩阵”类多区域激活可受显著性、注意与唤醒影响，不能仅凭某个岛叶簇的fMRI活动断定个体正在体验疼痛。2026年跨任务汇总研究同时找到与疼痛相对偏好的岛叶区域，以及在疼痛、趋近／厌恶和认知控制任务间共同激活的区域，凸显功能异质与共性并存。(Mouraux & Iannetti, 2018, Brain; Kwon et al., 2026, Nat Commun)

### 5. 味觉、进食与奖赏：把感受质量与状态价值分开

味觉刺激通常募集\*\*岛叶—额盖（insulo-opercular）\*\*网络，并在眶额皮质等区域进一步涉及主观价值；2001年味觉fMRI可比较愉快与厌恶味道的激活，另一项巧克力摄食PET则显示相近感官输入在饱腹、愉悦度变化下会伴随不同脑活动。两者不能证明岛叶单独编码每种味道，也不能把眶额奖励信号全算进岛叶。(O'Doherty et al., 2001, J Neurophysiol; Small et al., 2001, Brain)

小鼠在体记录与干预研究发现，下丘脑AgRP相关饥饿状态能够改变岛叶神经元对食物线索的反应；2020年研究进一步展示，与生理需求相关的岛叶神经群活动既表征当前状态，也与未来状态估计有关。这些结果将“体内生理需求”与“外部线索价值”的关系从纯fMRI相关性推进到可操控的环路层次，但不能直接当作人类主观食欲意识的全因果解释。(Livneh et al., 2017, Nature; Livneh et al., 2020, Neuron)

### 6. 厌恶、共情、渴求和价值赋予

2000年有合并岛叶与壳核损伤的患者表现出厌恶情绪识别障碍；2003年fMRI研究显示，闻到恶心气味与看到他人厌恶表情都可能激活前岛叶相关位置；2004年研究显示亲近他人受痛相关线索与自身疼痛情境在前岛叶／扣带的部分响应重叠。它们共同支持岛叶在**自身状态与社会情境信息加工**中的参与，但“激活重叠”无法单独说明神经元是否相同或某种共情能力是否以岛叶为唯一必要条件。(Calder et al., 2000, Nat Neurosci; Wicker et al., 2003, Neuron; Singer et al., 2004, Science)

吸烟病灶研究具有更直接的临床对照：2007年观察到，岛叶损伤患者更可能出现容易戒烟、渴求中断等情况；2015年独立卒中队列也报告类似戒烟关联。此类自然病灶研究比单纯激活研究更接近因果，但仍无法排除病变范围、康复经历、住院环境与戒烟支持等因素，也不能由此推出“人为损伤岛叶可安全治疗成瘾”。(Naqvi et al., 2007, Science; Abdolahi et al., 2015, Addict Behav)

### 7. 显著性网络与动态协同

静息态fMRI将前岛叶与前扣带识别为显著性相关网络的组成部分；2008年任务fMRI与时间序列建模发现，右额岛叶活动在某些事件边界检测任务中先于其他网络的变化，于是提出其可能帮助默认模式网络（DMN）与中央执行相关网络（CEN）的切换。其核心限制是：**Granger因果性属于统计上的时间预测，不等于通过随机干预证实右岛叶能够独立“启动”整个网络切换**。(Seeley et al., 2007, J Neurosci; Sridharan et al., 2008, PNAS)

2010年和2015年的模型综述把该证据发展为“显著性识别—资源调配—行为控制”框架；2010年坐标型元分析、2011年连接聚类及2026年跨任务参与者级汇总又显示：岛叶既存在相对专门化的区域，也有跨域共同活动的背侧前部区域。因此“全岛叶只处理显著性”与“前岛叶只处理情绪”都不充分。(Kurth et al., 2010, Brain Struct Funct; Menon & Uddin, 2010, Brain Struct Funct; Deen et al., 2011, Cereb Cortex; Uddin, 2015, Nat Rev Neurosci; Kwon et al., 2026, Nat Commun)

### 8. 自主神经、免疫及跨系统调节

1992年少量接受癫痫术中电刺激的患者，岛叶不同侧刺激与心率、血压改变有不同关联，提示该皮质可参与自主神经心血管调节；但该样本很小，不能确立“左岛叶永远副交感、右岛叶永远交感”的硬性定位。(Oppenheimer et al., 1992, Neurology)

2021年小鼠研究标记炎症状态期间活跃的岛叶神经元群，并在之后重新激活这些细胞时观察到部分对应的外周炎症变化；实验提供了脑—免疫交互的因果线索，却**不等于人体所有炎症均由岛叶直接存储与控制**。该论文随后对药物剂量说明及部分图示样本数有正式勘误，复现实验须阅读订正版本。(Koren et al., 2021, Cell)

### 9. 近年微结构与“枢纽”假说的细化

2022年人类概率细胞构筑图谱、2024年细胞—系统层综述、2025年小鼠屏状核—岛叶转录组图谱，以及2026年猕猴VEN与小鼠锥体神经元研究，把早期“前岛叶／后岛叶”二分法拓展为细胞类型、局部连接和跨物种可比性的研究问题。(Quabs et al., 2022, NeuroImage; Kittleson et al., 2024, Neurosci Biobehav Rev; Fodoulian et al., 2025, Nat Commun; Liu et al., 2026, Nat Cell Biol; Jongbloets et al., 2026, Nat Neurosci)

2026年一项以多个既有fMRI研究的参与者级数据汇总、并使用独立数据集验证的研究，发现**背侧前岛叶跨疼痛、非躯体性趋近／厌恶、认知控制任务的共同响应区域**，同时辨识周围较具任务选择性的区域。这强化了“选择性加工与跨域汇合并存”的结构化观点；**体素激活并不等于同一个细胞同时编码四种功能，且该研究不包含所有可能的内感受／味觉任务**。(Kwon et al., 2026, Nat Commun)

## 关键研究与可重复性

### 研究证据的时间链

**1. 刺激与组织学定位：从解剖／生理进入功能。** 1992年人类岛叶刺激与心血管反应研究、2000年热感觉PET、2009年深部电刺激引发痛感，提供了不同层面的定位证据；尸检组织学与概率图谱则为影像定位提供与任务无关的结构参照。它们研究不同的变量，不能相互替代。(Oppenheimer et al., 1992, Neurology; Craig et al., 2000, Nat Neurosci; Mazzola et al., 2009, Pain; Morel et al., 2013, Neuroscience; Quabs et al., 2022, NeuroImage)

**2. 内感受：相关性与必要性必须并置。** 2004年心跳判断fMRI提示右前岛叶与任务成绩相关，2009年病灶＋药理研究却支持多通路心跳感知。这并非“一篇推翻另一篇”，而是提示完整网络中的参与和替代通路下的保留可以同时成立。(Critchley et al., 2004, Nat Neurosci; Khalsa et al., 2009, Nat Neurosci; Garfinkel et al., 2015, Biol Psychol)

**3. 情绪与社会认知：合并病灶、共享激活和病灶群体检验。** 厌恶病灶个案、厌恶观察／体验fMRI与共情痛研究构成关联链；2023年卒中病灶定位与2024年病灶文献汇总则要求区分面部情绪类型、病灶侧别、邻近壳核及白质通路的作用。这些群体证据支持“岛叶重要但非独有”。(Calder et al., 2000, Nat Neurosci; Wicker et al., 2003, Neuron; Singer et al., 2004, Science; Klepzig et al., 2023, Brain Commun; Lotze, 2024, NeuroImage)

**4. 显著性网络：跨方法的汇合与因果性不足。** 静息态连接、任务时序建模、坐标型元分析和连接聚类均支持前岛叶与显著性／控制活动的关系；2026年参与者级跨研究汇总及独立数据验证进一步检查跨域活动。但目前不能把这些相关性直接提升为单细胞级的、面向所有任务的唯一切换控制器。(Seeley et al., 2007, J Neurosci; Sridharan et al., 2008, PNAS; Kurth et al., 2010, Brain Struct Funct; Deen et al., 2011, Cereb Cortex; Kwon et al., 2026, Nat Commun)

**5. 疼痛：支持证据与直接方法争议。** 热／伤害性刺激成像、疼痛深电刺激和持续痛灌注成像支持中后岛叶重要性；2015年正式批评及2018年神经标记综述提醒注意非痛显著性对照不足。**Davis等2015年的论文是方法学评论，不应被标为一项独立的大样本负结果。**(Craig et al., 2000, Nat Neurosci; Mazzola et al., 2009, Pain; Duerden & Albanese, 2013, Hum Brain Mapp; Segerdahl et al., 2015, Nat Neurosci; Davis et al., 2015, F1000Res; Mouraux & Iannetti, 2018, Brain)

**6. 成瘾和身体状态：从临床自然病灶到动物可控回路。** 两组卒中患者戒烟研究提供相关的自然病灶证据；2017、2020年小鼠进食线索与状态预测研究，以及2021年免疫反应再激活研究，提供可操控的动物实验。但这些研究并未直接重复同一种功能，不能合并为“岛叶负责所有渴求和身体调控”的单一结论。(Naqvi et al., 2007, Science; Abdolahi et al., 2015, Addict Behav; Livneh et al., 2017, Nature; Livneh et al., 2020, Neuron; Koren et al., 2021, Cell)

**7. 新的细胞与跨物种地图。** 小鼠全脑病毒示踪、2025年区域空间转录组、2026年小鼠锥体细胞系统测量与猕猴前岛叶VEN单细胞数据，分别改善连接、分子分类与机制精度；2026年比较综述把这些结果放回物种差异背景。它们更接近可复用的基础数据资源，但不构成“人脑意识神经元”的功能因果证明。(Gehrlach et al., 2020, eLife; Fodoulian et al., 2025, Nat Commun; Jongbloets et al., 2026, Nat Neurosci; Liu et al., 2026, Nat Cell Biol; Charbonneau et al., 2026, Nat Neurosci)

### 可重复性核查需要记录的变量

| 维度 | 必须检查的内容 | 常见失真方式 |
| --- | --- | --- |
| **空间定义** | 是否只测岛叶？前/中/后，背侧/腹侧，岛盖及壳核是否纳入ROI | 把混合的岛叶—岛盖簇写成纯岛叶 |
| **物种与层次** | 人类影像/卒中/SEEG；猕猴Patch-seq；小鼠示踪、光遗传与行为 | 直接把小鼠某一亚区当成人类前岛叶同源区域 |
| **任务与目标量** | 心跳准确性、自评；温度还是主观疼痛；味觉品质还是愉悦价值；自然戒烟还是在院短期行为 | 把不同指标合并为同一种心理功能 |
| **因果性强弱** | PET/fMRI相关、统计时序、组织学、自然病灶、直接刺激、条件操控 | 把“时间先后”误写为“直接命令” |
| **分区算法** | 空间平滑、阈值、功能连接聚类、图谱版本、注册误差 | 以单研究分区为所有个体的真实解剖分区 |
| **患者偏倚** | 侧别、血管供区、邻近灰白质病变、药物、癫痫网络扩散、样本量 | 把广泛卒中引起的缺陷归因单一脑回 |
| **跨研究验证** | 是否独立样本／不同实验组／不同测量，是否仅对原始数据重分析 | 把再分析说成真正独立重复 |

尤其对2026年多任务fMRI汇总，应区分其内部跨研究验证与独立外部数据验证；这增强**群体BOLD模式**的稳定性，却不自动验证细胞连接与病灶因果。(Kwon et al., 2026, Nat Commun)

## 当前较稳定的认识

1. **岛叶是解剖学上可界定、内部微结构高度异质的皮质区域。** 前后及背腹轴上存在颗粒化梯度和多种细胞/连接亚区，不同分区地图需要保持其方法学定义。(Morel et al., 2013, Neuroscience; Quabs et al., 2022, NeuroImage; Jongbloets et al., 2026, Nat Neurosci)
2. **岛叶是内感受、感觉与情绪/动机相关的网络组成部分，而非唯一“身体感觉器官”。** 完整脑fMRI、刺激和部分病灶研究提供互补支持，保留替代路径尤其重要。(Craig et al., 2000, Nat Neurosci; Critchley et al., 2004, Nat Neurosci; Khalsa et al., 2009, Nat Neurosci; Gogolla, 2017, Curr Biol)
3. **中后岛叶与温度、伤害性刺激和某些痛感形成过程有稳定关联。** 但“疼痛特异性中心”的更强主张尚不能据这些证据直接确立。(Mazzola et al., 2009, Pain; Duerden & Albanese, 2013, Hum Brain Mapp; Davis et al., 2015, F1000Res; Mouraux & Iannetti, 2018, Brain)
4. **前岛叶及其网络与多类高显著性事件、情绪和认知控制任务共同活动。** 功能选择区与跨域汇合区并存，比“岛叶只处理一种情绪”更贴近现有证据。(Seeley et al., 2007, J Neurosci; Deen et al., 2011, Cereb Cortex; Uddin, 2015, Nat Rev Neurosci; Kwon et al., 2026, Nat Commun)
5. **岛叶功能具有投射和生理状态依赖性，部分动物研究已有较明确回路干预证据。** 小鼠食物线索调制、免疫相关神经群和小鼠/猕猴细胞图谱提供机制线索，但不能直接当作人类临床干预的既定效果。(Livneh et al., 2017, Nature; Koren et al., 2021, Cell; Liu et al., 2026, Nat Cell Biol; Charbonneau et al., 2026, Nat Neurosci)

## 争议与推断边界

### 1. 岛叶是不是“内感受的唯一皮质中心”？

**不能这样断言。** 右前岛叶心跳辨认相关性与病灶保留心跳感知的研究并存，说明并行的皮肤体感和其他网络可参与。需要先说清所测的是心跳、胃肠、呼吸还是主观情绪性身体感觉。(Critchley et al., 2004, Nat Neurosci; Khalsa et al., 2009, Nat Neurosci; Garfinkel et al., 2015, Biol Psychol)

### 2. “岛叶激活”能不能说明个体正在疼痛？

**不能仅凭激活判断。** 中后岛叶较强参与伤害性输入，但需要比较非痛的显著刺激、注意、唤醒与身体状态效应；2015年背侧后岛叶疼痛特异性争论不应被隐去。2026年研究的痛相关选择性区域是**跨研究fMRI定义的偏好区**，不等同于对疼痛绝对排他反应的细胞群。(Segerdahl et al., 2015, Nat Neurosci; Davis et al., 2015, F1000Res; Mouraux & Iannetti, 2018, Brain; Kwon et al., 2026, Nat Commun)

### 3. “右前岛叶负责切换默认网络和执行网络”是否已证明？

目前更准确的说法是“右额岛叶信号与切换过程的时序及功能联系支持一种有影响力的控制模型”。时序预测和静息态共变均不等于被直接干预证实的唯一主导机制；显著性网络边界也依研究方法而改变。(Sridharan et al., 2008, PNAS; Menon & Uddin, 2010, Brain Struct Funct; Deen et al., 2011, Cereb Cortex; Uddin, 2015, Nat Rev Neurosci)

### 4. 前/后岛叶是否只是情绪/感觉二分？

不能。颗粒性和连接模式形成连续梯度，并有多个中间或交叉功能区；味觉价值、疼痛、情绪与工作任务可在不同区域部分重叠。细胞分型结果进一步提醒一个宏观ROI内可能同时包含许多不同投射类型。(Morel et al., 2013, Neuroscience; Quabs et al., 2022, NeuroImage; Kwon et al., 2026, Nat Commun; Jongbloets et al., 2026, Nat Neurosci)

### 5. 左右半球的功能分工能否被一张表固定下来？

不宜。1992年自主神经刺激研究的样本很少；2024年情绪病灶综述还发现文献中右侧患者的纳入偏倚及微亚区统计不足。应报告效应来自哪侧、哪种任务和何种病灶，而不是宣称“左岛叶负责积极、右岛叶负责消极”等普遍规则。(Oppenheimer et al., 1992, Neurology; Lotze, 2024, NeuroImage)

### 6. 共情、厌恶与成瘾的“共享区域”是否意味着共享唯一神经机制？

不成立。厌恶病灶个案含壳核，厌恶观察与嗅觉体验的fMRI重叠可能来自混合群体；共情痛任务的情感网络重叠不能说明具有与自身痛相同的感觉体验。戒烟病灶观察比成像关联更有干预意义，但仍不能排除邻近组织损伤及临床背景。(Calder et al., 2000, Nat Neurosci; Wicker et al., 2003, Neuron; Singer et al., 2004, Science; Naqvi et al., 2007, Science; Abdolahi et al., 2015, Addict Behav)

### 7. 精神疾病、前额颞变性和岛叶异常间的因果关系如何界定？

病理与神经影像提示岛叶、前岛叶VEN及相关网络在若干疾病中可异常，但许多改变并非该病特异，既可能是疾病机制的一部分，也可能是全脑网络和临床症状变化的伴随表现。没有纵向特异性证据和干预试验时，不可将“岛叶异常”直接当成临床确诊标志或统一治疗靶点。(Seeley et al., 2006, Ann Neurol; Namkung et al., 2017, Trends Neurosci; Kittleson et al., 2024, Neurosci Biobehav Rev)

### 8. 动物研究是否已经证明人类可以“用岛叶控制免疫”？

还没有。小鼠炎症状态相关群体的化学遗传重激活可诱发外周炎症变化，构成有价值的机制证据，但缺乏同等精度的人类自然状态与干预验证；原研究还须结合其正式勘误解释。(Koren et al., 2021, Cell; Charbonneau et al., 2026, Nat Neurosci)

### 9. 最新图谱研究为何不能马上变成心理学定位表？

2025年小鼠屏状核—岛叶单细胞图谱中某些基因效应主要出现在屏状核；2026年猕猴VEN、小鼠锥体类型研究则各自描述不同物种的细胞构成。它们可以提出投射与局部生理的机制假说，却不能由转录组或树突形态直接推断某个神经元“负责自我意识”“负责社交”或“负责疼痛”。(Fodoulian et al., 2025, Nat Commun; Liu et al., 2026, Nat Cell Biol; Jongbloets et al., 2026, Nat Neurosci)

### 10. 几项容易被遗漏的文献修订

- **Koren等2021年《Cell》研究有正式勘误**，修订了细胞标记方法中的Tamoxifen与4-OHT剂量、部分图注样本数及补充图轴标注。重复该实验应优先查看[原文](https://doi.org/10.1016/j.cell.2021.10.013)及[勘误](https://doi.org/10.1016/j.cell.2021.11.021)，不能沿用更正前的数字。(Koren et al., 2021, Cell)
- **Segerdahl等2015年论文有官方勘误且其“疼痛特异性”受到公开反驳。** 这两者不是一回事：需要区分原始结果、期刊勘误和独立学术评论。检索入口：[原文](https://doi.org/10.1038/nn.3969)；[方法学评论](https://doi.org/10.12688/f1000research.6833.1)。(Segerdahl et al., 2015, Nat Neurosci; Davis et al., 2015, F1000Res)
- **VEN的“人类/猿类独有”表述不应未经比较解剖核实就原样沿袭早年论文标题。** 正文只保留可验证的前岛叶分布、细胞形态和具体病理及电生理发现。(Seeley et al., 2006, Ann Neurol; Liu et al., 2026, Nat Cell Biol; Charbonneau et al., 2026, Nat Neurosci)
