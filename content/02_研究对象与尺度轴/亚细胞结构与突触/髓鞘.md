# 髓鞘

> **一句话定义：** 髓鞘（myelin sheath）是由中枢神经系统的少突胶质细胞（oligodendrocyte）或外周神经系统的施旺细胞（Schwann cell）将富含脂质的细胞膜多层包绕于部分轴突表面形成的分段结构；它通过重塑膜电学性质、组织郎飞结及支持轴突代谢，使神经信号在适当的纤维上快速而可靠地传递(Nave & Werner, 2014, Annu Rev Cell Dev Biol; Salzer, 2015, Cold Spring Harb Perspect Biol)。

## 快速理解

可以把轴突想象成传递电信号的长线路，髓鞘则是**由活细胞制造并维护的、分段设置的绝缘性膜结构**，但它并非普通电缆外皮。髓鞘节段（internode）之间保留短的无髓鞘区——**郎飞结**（node of Ranvier）。动作电位主要在这些富集电压门控 Na⁺ 通道的节点主动再生，节点之间以快速的局部电流传递为主，这就&#x662F;_&#x8DF3;跃式传导_（saltatory conduction）。经典实验与电缆理论为这一解释奠定基础，现代工作又揭示节点长度、节段几何及轴突直径都可影响传导时序(Huxley & Stämpfli, 1949, J Physiol; Rushton, 1951, J Physiol; Arancibia-Cárcamo et al., 2017, eLife)。

- **谁制造？** 脑和脊髓主要由少突胶质细胞成髓；周围神经主要由施旺细胞成髓。典型情况下，一个少突胶质细胞可支持多个轴突节段，一个成髓施旺细胞在单条轴突上形成一个节段；这两套系统具有不同的分化与信号需求(Nave & Werner, 2014, Annu Rev Cell Dev Biol; Salzer, 2015, Cold Spring Harb Perspect Biol)。
- **不仅是提速。** 髓鞘化的轴突与胶质细胞之间还存在营养和代谢耦合；即使显微镜下形成了髓鞘，轴突长期存活所需的胶质支持也可能独立受损(Lappe-Siefke et al., 2003, Nat Genet; Lee et al., 2012, Nature)。
- **也不是一成不变。** 发育期持续产生新髓鞘，成年脑的部分区域仍可产生新少突胶质细胞、新节段或有限的既有节段改变；“新增髓鞘”“旧髓鞘伸缩”和“髓鞘修复”是不同现象(Hill et al., 2018, Nat Neurosci; Hughes et al., 2018, Nat Neurosci)。
- **与学习可能相关，但并非一切学习都依赖它。** 小鼠实验已通过遗传干预把少突胶质细胞形成与特定运动学习、记忆巩固联系起来；这不能直接推广为人类任意学习导致髓鞘变厚(McKenzie et al., 2014, Science; Steadman et al., 2020, Neuron)。

**最重要的理解界限：髓鞘是一个“轴突—胶质—离子通道”功能单元，而不只是可由白质 MRI 信号直接读出的单一绝缘材料。**

## 概念界定与边界

| 术语 | 本节点采用的界定与易混淆点 |
| --- | --- |
| 髓鞘（myelin sheath） | 包绕轴突的多层特化胶质细胞膜；是细胞形成的结构，不是独立细胞或一种单独蛋白。 |
| 髓鞘化／成髓（myelination） | 胶质细胞识别轴突、启动包裹、扩展并压实膜、成熟维持的过程。 |
| 髓鞘节段（internode） | 相邻郎飞结间被髓鞘覆盖的轴突区段；其长度不是全部轴突通用的固定数值。 |
| 郎飞结／旁节点／旁旁节点 | 节点为动作电位再生的离子通道富集区；旁节点（paranode）为轴突—胶质连接带；旁旁节点（juxtaparanode）常富集特定 K⁺ 通道，功能并不相同。 |
| 紧密髓鞘与非紧密髓鞘 | 多层膜高度压实区与保留胶质细胞质的通道、内外舌及旁节点环；“紧密”不意味着髓鞘完全无物质交换。 |
| 少突胶质前体细胞（OPC） | CNS 中能产生新的少突胶质细胞的细胞群；“出现 OPC”“新少突胶质细胞”“新髓鞘”不可互作同义词。 |
| 脱髓鞘（demyelination） | 已形成髓鞘的损失或严重损坏；不等于发育阶段尚未成髓&#x7684;_&#x9AD3;鞘形成不足_（hypomyelination）。 |
| 再髓鞘化（remyelination） | 脱髓鞘后沿原有存活轴突重新形成髓鞘；不等于轴突自身再生，也不等于临床功能必然恢复。 |
| _g-ratio_ | 组织切面中轴突直径与含髓鞘纤维外径之比，反映相对包裹厚度；测量须说明取样、切面方向与纤维直径分布。 |
| 白质信号与髓鞘含量 | 白质通常富含有髓轴突，但弥散 MRI 的 FA、T1/T2 或其他单一成像参数并非髓鞘的无歧义直接计数(Jones et al., 2013, Neuroimage; Stüber et al., 2014, Neuroimage)。 |

**研究对象边界。** 髓鞘广泛存在于脊椎动物部分轴突，但不是每条神经纤维、每段轴突都成髓：外周存在无髓的 Remak 束，成年大脑皮层也可见同一轴突上的间断成髓分布。髓鞘研究常以小鼠、斑马鱼、细胞培养、人体尸检和影像为对象；其结论应附随物种、组织区域、发育阶段与方法学条件(Salzer, 2015, Cold Spring Harb Perspect Biol; Hill et al., 2018, Nat Neurosci)。

**不等同于突触。** 化学突触主要传递神经元之间的信息；髓鞘主要包裹轴突并影响传播和维持。二者都能影响网络功能，但属于不同的解剖结构及可塑性机制(Nave & Werner, 2014, Annu Rev Cell Dev Biol; Fields, 2015, Nat Rev Neurosci)。

## 结构与机制（适用时）

### 1. 微观层次：节段、结区与多层膜

纵向看，一条典型有髓轴突依次由节段、旁节点和郎飞结构成。节段下的轴突膜（axolemma）与内层髓鞘之间保留轴周空间（periaxonal space），旁节点处胶质细胞膜末端形成连接环；节点处的钠通道、黏附蛋白、锚蛋白及谱蛋白骨架共同维持高密度兴奋性区(Rasband & Peles, 2021, Nat Rev Neurosci)。

横向看，髓鞘由螺旋式叠层细胞膜构成，富含胆固醇、鞘脂等脂类，也包含髓鞘碱性蛋白 MBP、蛋白脂质蛋白 PLP/PLP1、CNP、MAG 等。**CNS 与 PNS 的主要蛋白组成不完全相同**：外周紧密髓鞘的重要组成还包括 P0/MPZ 和 PMP22；不能将 CNS 的 PLP 主导结构图原样视为外周标准结构(Jahn et al., 2009, Mol Neurobiol; Aggarwal et al., 2011, Trends Cell Biol; Salzer, 2015, Cold Spring Harb Perspect Biol)。

髓鞘生长高度依赖膜脂供应。通过少突胶质细胞条件性干预胆固醇合成，研究者发现 CNS 髓鞘膜的正常扩展受到限制；这属于**细胞内胆固醇生物合成的机制证据**，不能推出通过增加饮食胆固醇可改善髓鞘化(Saher et al., 2005, Nat Neurosci)。MBP 促进膜层紧密结合，而 CNP 有助于保留部分细胞质通道；两者的平衡可影响膜结构与轴突—胶质物质运输(Snaidero et al., 2017, Cell Rep; Simons & Nave, 2016, Cold Spring Harb Perspect Biol)。

### 2. 形成过程：选择轴突、包裹、扩展、压实与维持

CNS 少突胶质细胞通常经历 OPC、分化中的少突胶质细胞、前髓鞘化细胞和成熟成髓状态。其突起先与轴突接触并尝试包裹，稳定后延长、增加环绕层数，并压实膜。三维电镜和活体成像支持一种机制：新膜在靠近轴突的\*\*内舌（inner tongue）\*\*处持续增加，同时髓鞘沿轴突长度方向扩展，并通过细胞质通道运输物质；这不应误写成所有膜都只从最外层“往上叠加”(Snaidero et al., 2014, Cell)。

细胞骨架既负责伸出前沿，也要适时解聚以促成大片膜的铺展。两组机制实验分别强调了 F-actin 解聚、ADF/cofilin 与肌动蛋白高周转率在 CNS 髓鞘包裹中的作用，支持“动态组装—解聚”而不是“越多肌动蛋白越能成髓”的简单模型(Zuchero et al., 2015, Dev Cell; Nawaz et al., 2015, Dev Cell)。膜极性与运输过程可参考更早的细胞生物学整合(Simons & Trotter, 2007, Curr Opin Neurobiol)。

早期包裹还含有明显的试探与淘汰。斑马鱼单细胞纵向观察显示，新少突胶质细胞初始建立多数节段的时间窗口相对集中；更高频的观察发现多个包裹尝试可能回缩，少部分保留为稳定节段。**这些是特定发育模型中的统计结果，不能直接规定成年人的统一髓鞘生成时间**(Czopka et al., 2013, Dev Cell; Almeida & Macklin, 2023, eLife)。

### 3. CNS 与 PNS 的信号调控有实质差异

PNS 中，轴突膜上的 NRG1 type III 通过施旺细胞 ErbB 相关信号，参与决定轴突被包绕、是否成髓及相对厚度。遗传操纵和表达救援实验支持这种轴突—施旺细胞调控关系(Michailov et al., 2004, Science; Taveggia et al., 2005, Neuron)。

但**不能因此断言 NRG1 是 CNS 正常成髓的普遍必需信号**。条件性缺失 NRG1 以及少突胶质 ErbB3/ErbB4 的实验显示，某些中枢发育阶段仍能形成大量髓鞘，而过表达 NRG1 可促进中枢髓鞘增加；说明“增强能力”与“生理必要性”是两回事(Brinkmann et al., 2008, Neuron)。少突胶质细胞本身也有区域来源相关的成鞘程序：在合成纳米纤维上、缺少正常神经元信号时仍可包裹出长度不同的髓鞘(Bechler et al., 2015, Curr Biol)。

### 4. 电生理机制：绝缘、节点动作电位与时序

髓鞘化降低节段膜的有效电容并增加跨膜阻抗，使局部去极化较有效地在节点间传播；下一节点的电压门控离子通道再生动作电位。Huxley 与 Stämpfli 对外周有髓纤维的电生理研究给出经典实验证据，Rushton 的电缆理论把轴突直径与髓鞘尺寸纳入传导分析(Huxley & Stämpfli, 1949, J Physiol; Rushton, 1951, J Physiol)。

传导速度与延迟还受节段长度、髓鞘厚度、轴突直径、节点几何、通道密度、温度和病理状态共同影响。郎飞结的组装依赖胶质—轴突黏附及离子通道定位系统；鼠视神经和皮层轴突的形态学结合模拟研究提示节点长度差异本身具有调节传导的潜力，**模拟出速度变化不是对在体学习时序变化的直接证明**(Rasband & Peles, 2021, Nat Rev Neurosci; Arancibia-Cárcamo et al., 2017, eLife)。

### 5. 活动依赖性髓鞘化与成人可塑性

**神经活动能影响髓鞘形成，但不是唯一指令，也不是所有阶段都有效。** 小鼠神经活动刺激实验显示少突胶质发生与髓鞘改变；斑马鱼干预囊泡释放及轴突活动，则显示其能够影响形成节段的数量、稳定性及轴突选择(Gibson et al., 2014, Science; Mensch et al., 2015, Nat Neurosci; Hines et al., 2015, Nat Neurosci)。成年小鼠药理遗传刺激支持某些回路中的轴突特异性效应(Mitew et al., 2018, Nat Commun)。

活动效应应与少突胶质的自主程序结合理解。无神经元纳米纤维实验表明鞘长具有一定细胞内在倾向；成年小鼠皮层的在体成像显示新少突胶质整合和新鞘增加，但不同研究对**既有髓鞘是否频繁改变长度**的观察并不完全一致。部位、年龄、定义及追踪窗口都可能影响结果(Bechler et al., 2015, Curr Biol; Hill et al., 2018, Nat Neurosci; Hughes et al., 2018, Nat Neurosci)。

行为学证据更接近因果推断：通过干预成年少突胶质发生，部分小鼠实验发现新髓鞘化对复杂跑轮运动技能、特定空间记忆巩固及远期恐惧记忆有重要作用；然而，这不是“所有学习都必须增加髓鞘厚度”的证据，也不能仅凭行为效应确定具体哪一段轴突改变了多少毫秒的传导(McKenzie et al., 2014, Science; Xiao et al., 2016, Nat Neurosci; Steadman et al., 2020, Neuron; Pan et al., 2020, Nat Neurosci)。

人类与动物的证据不能直接等量齐观。人脑少突胶质细胞碳-14 定年和成人皮层成像研究支持长时间尺度的细胞及髓鞘动态，但仍不能像斑马鱼活体成像那样追踪同一人的单个髓鞘节段；较早的啮齿类训练结合 MRI 与组织学研究也只是为结构关联提供交叉方法线索(Yeung et al., 2014, Cell; Sampaio-Baptista et al., 2013, J Neurosci)。

**新近进展：** 2025 年的斑马鱼多方法研究通过药理、遗传、Ca²⁺ 成像和光遗传干预，支持少突胶质相关 mGluR5 参与活动驱动的髓鞘伸长；2025 年在线发表于《Nature Neuroscience》、编入 2026 年卷期的 Enpp6-CreER 小鼠研究，则将活动影响定位到前髓鞘化少突胶质细胞存活和整合的较窄成熟窗口。两项研究分别针&#x5BF9;_&#x9798;生长的分子环&#x8282;_&#x548C;_细胞发育阶段_，不能直接拼接为人脑中的单一通路(Braaker et al., 2025, Nat Neurosci; Bhambri et al., 2026, Nat Neurosci)。

### 6. 代谢耦合：轴突长期存活不等于仅靠膜绝缘

在成熟 CNS 中，少突胶质细胞及其髓鞘保留了与轴突相连的代谢通道。CNP 缺失模型可在初期髓鞘外观相对保留的情况下出现轴突变性，说明“已成髓”和“支持轴突长期完整”可被实验区分(Lappe-Siefke et al., 2003, Nat Genet; Snaidero et al., 2017, Cell Rep)。

MCT1 相关干预和少突胶质线粒体功能研究支持髓鞘胶质参与局部代谢底物供给、糖酵解与轴突维持；但**髓鞘的电绝缘功能与少突胶质细胞的营养支持功能相关而不相同**，也不宜认定乳酸是所有情境唯一的运输底物(Lee et al., 2012, Nature; Fünfschilling et al., 2012, Nature)。

### 7. 脱髓鞘、再髓鞘化与疾病

多发性硬化症（MS）是研究 CNS 炎症性脱髓鞘和轴突损伤的典型场景；此外还存在以髓鞘形成障碍为主的遗传性白质病、外周脱髓鞘性神经病等，但它们的病因和受损细胞不能混写。MS 人体病灶研究观察到轴突横断，提示疾病负担不能简化为“只丢失绝缘层”(Trapp et al., 1998, N Engl J Med; Franklin & ffrench-Constant, 2008, Nat Rev Neurosci)。

CNS 的再髓鞘化通常涉及局部 OPC 激活、迁移或募集、分化、重新包绕存活轴突及节段成熟。病理研究显示**部分 MS 个体与病灶可以有广泛再髓鞘化**，而另一些慢性病灶中修复明显不足；两组结果并非逻辑矛盾，而是反映患者、病灶区域、炎症背景、病程与修复阶段的异质性(Patrikios et al., 2006, Brain; Goldschmidt et al., 2009, Neurology; Franklin & ffrench-Constant, 2017, Nat Rev Neurosci)。

BCAS1 等标记有助于识别人体病理材料中较新的成髓细胞状态，不过某一标记阳性不能单独证明轴突形成了功能完整的新髓鞘。开发能标记前髓鞘化阶段的新小鼠工具也有助于将“细胞存活”“成髓成功”从组织整体反应中拆分出来(Fard et al., 2017, Sci Transl Med; Bhambri et al., 2026, Nat Neurosci)。

临床转化还需谨慎：ReBUILD 试验中 clemastine fumarate 在特定 MS 慢性视神经病变受试者中出现视觉诱发电位（VEP）潜伏期改善信号，属&#x4E8E;_&#x4E0E;传导改善一致的有限临床线索_；它不直接测量所有病灶的新髓鞘形成，也不等于已证明长期、广泛或确定的临床功能恢复(Green et al., 2017, Lancet)。

### 8. 测量手段及其能证明什么

| 方法 | 直接或间接读出 | 强项 | 主要边界 |
| --- | --- | --- | --- |
| 透射电镜／体积电镜 | 层板、轴突直径、包裹层数、g-ratio、节段与结区细节 | 微观结构证据强 | 固定、切片角度、采样偏倚；静态形态不能直接测得活体传导 |
| 蛋白免疫染色／蛋白质组 | MBP、PLP1、CNP、MPZ、BCAS1 等分布或丰度 | 区分分子组成、部分细胞状态 | 表达变化不自动等同新形成的成熟功能性髓鞘 |
| 活体双光子／斑马鱼时序成像 | 髓鞘节段建立、缩回、成髓细胞整合 | 同一结构纵向追踪 | 成像深度、物种、染色与空间采样限制 |
| 电生理／神经传导／VEP | 传导速度、潜伏期、兴奋性 | 直接反映电功能结果 | 受轴突、节点、温度与回路状态共同影响；无法单独测定髓鞘厚度 |
| 扩散 MRI（含 FA） | 水分子扩散方向性及复杂组织微结构 | 活体人体纵向追踪可行 | FA 非髓鞘特异指标，不可直接写为“髓鞘增加了 x%” |
| 髓鞘水成像、定量磁化相关指标 | 与髓鞘相关的 MRI 模型参数 | 某些方法有离体组织学相关验证 | 信号仍受序列、铁、水含量、病理与模型条件影响 |

关于成像，离体 MS 组织研究证明髓鞘水成像与定量病理指标具有一定相关性；另一项定量研究表明髓鞘和铁都可改变 MRI 对比度。因而“影像学表征与髓鞘相关”**不等于**“任意 MRI 对比度变化就是髓鞘的新生或丢失”(Laule et al., 2006, Mult Scler; Laule et al., 2008, Neuroimage; Stüber et al., 2014, Neuroimage; Jones et al., 2013, Neuroimage)。

## 关键研究与可重复性

这里的“重复”至少区分三种含义：**相似现象在不同模型出现**、**以不同方法检验同一推断**、**独立团队重复相近的干预与结局**。综述不应作为额外独立数据集计算。

| 研究线索 | 关键证据链 | 可重复性与限制 |
| --- | --- | --- |
| 跳跃式传导 | 经典外周有髓纤维电生理、传导模型、现代节点超微结构／分子装配(Huxley & Stämpfli, 1949, J Physiol; Rushton, 1951, J Physiol; Rasband & Peles, 2021, Nat Rev Neurosci) | **高稳定度的基本原理**；纤维种类及具体传导速度依参数变化 |
| 髓鞘扩展和膜压实 | 三维电镜与活体成像、两组肌动蛋白机制研究、细胞质通道模型(Snaidero et al., 2014, Cell; Zuchero et al., 2015, Dev Cell; Nawaz et al., 2015, Dev Cell; Snaidero et al., 2017, Cell Rep) | **多方法相互支持**；不同成髓阶段可采用不同局部机制 |
| CNS/PNS 调控区别 | PNS NRG1 量与成髓实验、CNS NRG1/ErbB 条件敲除比较(Taveggia et al., 2005, Neuron; Brinkmann et al., 2008, Neuron) | **具有直接遗传学证据**；不可仅凭外周结果规定中枢 |

| 既有鞘变化还是新生鞘增加 | 2018 年两组成年小鼠皮层纵向成像(Hill et al., 2018, Nat Neurosci; Hughes et al., 2018, Nat Neurosci) | **同年独立方法线索**；新节段增加较一致，旧鞘动态幅度与经验效应需分开 |

**证据分类判断。** 传导电学、CNS/PNS 成髓细胞来源以及髓鞘膜层结构，有多种方法相互印证，属于稳定基础知识。活动相关细胞机制与特定小鼠行为学因果效应证据不断加强，但不能直接提升为所有脑区、所有物种的普适定律。人体修复疗效尤其需要功能终点、适当对照与长期追踪。

## 当前较稳定的认识

1. **髓鞘由胶质细胞的多层特化膜构成，CNS 与 PNS 的成髓细胞及关键分子调控不同。**(Nave & Werner, 2014, Annu Rev Cell Dev Biol; Salzer, 2015, Cold Spring Harb Perspect Biol; Brinkmann et al., 2008, Neuron)
2. **有髓轴突的快传导依赖髓鞘节段与郎飞结共同工作，而不是信号真正“跳过”轴突。** 其速度受轴突和结区几何共同调节(Huxley & Stämpfli, 1949, J Physiol; Rushton, 1951, J Physiol; Rasband & Peles, 2021, Nat Rev Neurosci)。
3. **髓鞘形成涉及主动膜运输、细胞骨架重塑和分子压实，而非一次性静态包裹。**(Snaidero et al., 2014, Cell; Zuchero et al., 2015, Dev Cell; Nawaz et al., 2015, Dev Cell)
4. **少突胶质细胞对轴突的长期保护不限于绝缘；代谢支持是可以实验区分的贡献。**(Lappe-Siefke et al., 2003, Nat Genet; Lee et al., 2012, Nature; Fünfschilling et al., 2012, Nature)
5. **髓鞘在成熟生命阶段仍可发生某些形式的更新，并在特定动物学习范式中具有功能重要性；病后再髓鞘化也真实存在，但程度与疗效高度异质。**(Hughes et al., 2018, Nat Neurosci; McKenzie et al., 2014, Science; Patrikios et al., 2006, Brain; Goldschmidt et al., 2009, Neurology)

## 争议与推断边界

1. **“神经活动决定所有髓鞘”——过度概括。** 活动可偏向特定轴突的髓鞘稳定或延伸，但早期包裹存在不依赖神经活动的步骤，少突胶质细胞也有内源的长度／区域程序；细胞来源与发育阶段同样重要(Hines et al., 2015, Nat Neurosci; Bechler et al., 2015, Curr Biol; Braaker et al., 2025, Nat Neurosci)。
2. **“成年髓鞘重塑＝既有鞘快速增厚”——证据不支持直接等同。** 新少突胶质形成、新节段增加、既有节段伸长／缩短和膜层改变应分别测量；2018 年成年皮层成像结果对既有节段动力学与刺激效应给出不同侧重点(Hill et al., 2018, Nat Neurosci; Hughes et al., 2018, Nat Neurosci)。
3. **“观察到白质 FA 上升＝发生了髓鞘增生”——不成立。** MRI 的扩散指标受纤维排列、体素组成、炎症、水和其他微结构变化影响；髓鞘水成像等方法虽有病理相关验证，仍存在信号模型与样本条件限制(Jones et al., 2013, Neuroimage; Laule et al., 2006, Mult Scler; Stüber et al., 2014, Neuroimage)。
4. **“更厚的髓鞘必然传导更快”——缺少条件。** g-ratio、节点长度、轴突直径、间节长度和通道分布共同决定传导。理论最优条件不是所有区域普适不变的结构目标(Rushton, 1951, J Physiol; Arancibia-Cárcamo et al., 2017, eLife)。
5. **“NRG1 是所有髓鞘形成的必需信号”——跨系统外推错误。** NRG1 type III 在 PNS 施旺成髓中的重要性有直接因果证据，但 CNS 少突胶质细胞的 NRG1 依赖性不同(Michailov et al., 2004, Science; Taveggia et al., 2005, Neuron; Brinkmann et al., 2008, Neuron)。
6. **“再髓鞘化成功＝临床修复已完成”——过度推断。** 新髓鞘可能较薄且节段较短；轴突已经丢失、炎症持续或节点结构未恢复时，结构修复未必能转换成长期功能获益。MS 病理材料的修复程度差异很大，早期药物试验的 VEP 改善也不能替代长期失能终点(Franklin & ffrench-Constant, 2017, Nat Rev Neurosci; Patrikios et al., 2006, Brain; Goldschmidt et al., 2009, Neurology; Green et al., 2017, Lancet)。
7. **“少突胶质细胞的任何神经保护作用都由髓鞘膜承担”——因果对象混淆。** 胶质细胞可通过代谢耦合支持轴突，某些基因干预能分离髓鞘形成与长期轴突完整性(Lappe-Siefke et al., 2003, Nat Genet; Lee et al., 2012, Nature)。
8. **“2025—2026 单篇新研究证明统一机制”——证据尚不足。** mGluR5 相关斑马鱼鞘伸长与小鼠前髓鞘化细胞的生存整合窗口是不同层次的发现；目前不应宣称在健康成人、所有疾病模型均已复制(Braaker et al., 2025, Nat Neurosci; Bhambri et al., 2026, Nat Neurosci)。
9. **“一种动物脱髓鞘模型等于完整 MS 病理”——不成立。** 毒素诱导脱髓鞘、自身免疫性炎症、遗传性髓鞘形成不足以及外周神经病的病因、细胞环境和再生障碍不同；研究须报告模型与适用范围(Franklin & ffrench-Constant, 2008, Nat Rev Neurosci; Franklin & ffrench-Constant, 2017, Nat Rev Neurosci)。
10. **“病例系列出现较广泛再髓鞘化与慢性病灶修复失败互相否定”——并非如此。** 两类研究的对象、取样及疾病阶段不同，提示需要患者级与病灶级分层，而不是选择一个结论抹去另一个(Patrikios et al., 2006, Brain; Goldschmidt et al., 2009, Neurology)。

**尚待补强的证据：** 健康人成人学习中，单条轴突髓鞘结构变化与传导时序改变之间的直接可逆因果链；跨脑区统一的活动—髓鞘分子规则；能够同时证明结构再髓鞘化、功能传导恢复和长期患者获益的临床标志物与治疗证据。
