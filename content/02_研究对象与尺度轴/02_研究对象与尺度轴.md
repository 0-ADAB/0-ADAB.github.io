# 研究对象与尺度

> **研究的是谁、什么实体，处于哪个空间或时间层级？**

本轴为知识提供稳定的实体和尺度锚点。一个研究问题可以同时连接多个尺度，但实体本身只保留一个规范节点。

## 研究对象地图

| 维度 | 常用分类 |
| --- | --- |
| 组织尺度 | 分子、亚细胞、突触、细胞、神经元群体、局部环路、脑区、跨脑区网络、全脑 |
| 时间尺度 | 快速神经动力学、行为事件、学习与可塑性、昼夜节律、生命周期 |
| 解剖实体 | 脑区、神经核团、神经通路、细胞类型 |
| 分子实体 | 神经递质、受体、离子通道、信号通路 |
| 研究系统 | 模型生物、研究人群、生理与疾病状态 |

## 理解多尺度研究

微观分子变化可能影响突触和细胞功能，并进一步影响环路与行为；但**跨尺度的因果联系需要独立证据**，不能由相关性自动推出。

## 创建实体节点时

清楚定义命名与边界、组成结构、物种差异、已证实功能、适用实验条件。像“海马”和“位置细胞”可分为不同节点，但它们的功能关系由双链描述，不通过深层文件夹强制表达。
