# BDNF

> **一句话定义：** \*\*BDNF（brain-derived neurotrophic factor，脑源性神经营养因子）\*\*是神经营养因子家族的一种可分泌蛋白，在不同发育阶段和细胞背景下，通过受体信号调节神经元存活、树突和突触发育、突触可塑性及部分学习记忆过程；**但“BDNF 越高越好”“血 BDNF 等于脑 BDNF”都不是可靠的通用结论**。(Barde et al., 1982, EMBO J; Klein et al., 1991, Cell; Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron; Harward et al., 2016, Nature; Naegelin et al., 2018, eNeuro; Tikhonova et al., 2022, Int J Mol Sci; Park & Poo, 2013, Nat Rev Neurosci; Lu et al., 2014, Handb Exp Pharmacol)

## 快速理解

可以把 BDNF 想成神经网络中一种**随活动而变化的局部调节信号**，而不是一枚负责产生快乐或聪明的“化学按钮”。

- **从哪里来？** 神经元及某些非神经细胞可以产生 BDNF。神经活动会影响其基因转录、mRNA 在细胞内的分布、蛋白加工以及分泌时机；实验发现 BDNF 可在受刺激突触附近发挥局部作用。(Aid et al., 2007, J Neurosci Res; An et al., 2008, Cell; Hartmann et al., 2001, EMBO J; Harward et al., 2016, Nature; Park & Poo, 2013, Nat Rev Neurosci)
- **它作用于什么？** 成熟 BDNF（mature BDNF，mBDNF）主要通过具有酪氨酸激酶活性的 **TrkB** 受体影响细胞；其前体 **proBDNF** 在某些条件下可经 **p75NTR/sortilin** 复合物介导不同乃至相反的细胞效应。(Klein et al., 1991, Cell; Lee et al., 2001, Science; Teng et al., 2005, J Neurosci; Pang et al., 2004, Science; Woo et al., 2005, Nat Neurosci; Patapoutian & Reichardt, 2001, Curr Opin Neurobiol)
- **为什么与记忆有关？** 小鼠 Bdnf 缺失、TrkB 条件敲除、单棘突功能成像，以及部分大鼠记忆巩固干预，支持 BDNF 信号参与若干突触可塑性与记忆过程；这些研究**不能**单独证明一种在人类中通用的“记忆强度 = BDNF 浓度”公式。(Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron; Harward et al., 2016, Nature; Bekinschtein et al., 2007, Neuron; Bekinschtein et al., 2008, PNAS; Park & Poo, 2013, Nat Rev Neurosci; Lu et al., 2014, Handb Exp Pharmacol)
- **为什么临床文章常提 BDNF？** 血清 BDNF 在某些抑郁病例组中平均偏低，治疗及运动干预后有时上升；但是采样方法、血小板释放、个体差异、分析偏倚以及血液和脑组织并不必然同步，都限制了它作为个人脑状态或疗效读数的可靠性。(Molendijk et al., 2014, Mol Psychiatry; Polyakova et al., 2015, J Affect Disord; Naegelin et al., 2018, eNeuro; Tsuchimine et al., 2014, Neuropsychobiology; Gejl et al., 2019, Sci Rep; Klein et al., 2011, Int J Neuropsychopharmacol; Tikhonova et al., 2022, Int J Mol Sci; Wang et al., 2022, Brain Behav; Gholami et al., 2025, Exp Gerontol; Bevilacqua et al., 2026, Clin Chem Lab Med; Castrén & Monteggia, 2021, Biol Psychiatry)

**核心记忆点：** **基因/转录本 → proBDNF 加工 → 释放位置与时机 → 受体组合 → 细胞与网络效应**，每一环都有独立的实验问题。不要把所有文献中的“BDNF”当成同一种检测指标、同一种信号来源或同一个终点。(Aid et al., 2007, J Neurosci Res; An et al., 2008, Cell; Hartmann et al., 2001, EMBO J; Matsumoto et al., 2008, Nat Neurosci; Yang et al., 2009, Nat Neurosci; Lee et al., 2001, Science; Teng et al., 2005, J Neurosci; Pang et al., 2004, Science; Woo et al., 2005, Nat Neurosci; Naegelin et al., 2018, eNeuro; Tsuchimine et al., 2014, Neuropsychobiology; Gejl et al., 2019, Sci Rep; Klein et al., 2011, Int J Neuropsychopharmacol; Tikhonova et al., 2022, Int J Mol Sci; Lim et al., 2015, J Neurochem)

## 概念界定与边界

| 术语 | 准确定义 / 本文用法 | 常见误解与边界 |
| --- | --- | --- |
| **BDNF** | 一种神经营养因子蛋白；对应人类 _BDNF_ 基因、啮齿类 _Bdnf_ 基因 | 不是经典小分子神经递质；本节点放在“分子与递质”类是知识分类，不表示其属于递质 |
| **pre-proBDNF / proBDNF / mBDNF** | 蛋白质合成及加工的不同形式；proBDNF 可经蛋白酶剪切产生成熟 BDNF | “检测到总 BDNF”不必然说明是成熟型，亦不能直接说明 proBDNF/mBDNF 比例(Matsumoto et al., 2008, Nat Neurosci; Yang et al., 2009, Nat Neurosci; Lee et al., 2001, Science; Lim et al., 2015, J Neurochem) |
| **TrkB（NTRK2）** | 结合 BDNF 的受体酪氨酸激酶；需区分有催化结构域的全长型和截短型 | BDNF 不是 TrkB 本身；TrkB 不只响应 BDNF，NT-4 等也是相关配体(Klein et al., 1991, Cell; Patapoutian & Reichardt, 2001, Curr Opin Neurobiol) |
| **p75NTR（NGFR）与 sortilin** | 多种神经营养信号涉及的受体/共受体组合，可能介导 proBDNF 的特定效应 | p75NTR 的功能不恒等于“死亡受体”，取决于共受体、细胞类型与生理背景(Lee et al., 2001, Science; Teng et al., 2005, J Neurosci; Lu et al., 2014, Handb Exp Pharmacol) |
| **活动依赖性分泌** | 神经活动按特定时空模式改变 BDNF 释放 | 不等于脑内所有 BDNF 都由活动瞬时释放；还涉及转录、转运和构成性分泌(Aid et al., 2007, J Neurosci Res; An et al., 2008, Cell; Hartmann et al., 2001, EMBO J; Matsumoto et al., 2008, Nat Neurosci; Yang et al., 2009, Nat Neurosci) |
| **LTP / LTD / 记忆** | 分别是指定条件下的突触增强、减弱与行为或认知过程 | 三者相关但不是同义词；细胞局部成像不能替代人类记忆研究(Woo et al., 2005, Nat Neurosci; Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron; Harward et al., 2016, Nature; Bekinschtein et al., 2007, Neuron; Bekinschtein et al., 2008, PNAS) |
| **Val66Met（rs6265）** | 人类 BDNF 前体区常见错义变异，可能影响细胞内转运及诱发性分泌 | 不是“聪明/抑郁基因”；细胞功能效应与人群行为效应要分开检验(Egan et al., 2003, Cell; Mandelman & Grigorenko, 2012, Genes Brain Behav; Kambeitz et al., 2012, Neurosci Biobehav Rev; Harrisberger et al., 2014, Neurosci Biobehav Rev) |
| **血清 / 血浆 BDNF** | 由不同采血及凝血处理产生的外周标本中的免疫学检测读数 | 不可互换，更不能不加验证地当成脑脊液/脑组织 BDNF 水平(Naegelin et al., 2018, eNeuro; Tsuchimine et al., 2014, Neuropsychobiology; Gejl et al., 2019, Sci Rep; Klein et al., 2011, Int J Neuropsychopharmacol; Tikhonova et al., 2022, Int J Mol Sci) |

**范围约定：** 本节点主要讨论哺乳动物神经系统的机制与人群研究。来自体外重组蛋白、培养神经元、急性脑片、发育性基因敲除、动物记忆行为和人群观察的证据**分别标注**，不自动在层级之间推导因果。疾病部分以研究机制和生物标志物争论为主，**不构成诊疗建议**。

## 结构与机制（适用时）

### 1. 基因表达、转录本和局部来源

BDNF 并不是一份“恒定表达量”的单一转录产物。啮齿类 _Bdnf_ 具有多种不同的 5′ 非翻译区外显子和启动子，它们与编码区组合，形成对刺激和组织背景响应不同的转录本；人类与啮齿类基因结构不应机械对应。(Aid et al., 2007, J Neurosci Res)

同样编码 BDNF 蛋白的 mRNA 可以具有较短或较长的 **3′ 非翻译区（3′UTR）**。An 等以啮齿类神经元及遗传模型显示，长 3′UTR 与树突定位、局部 BDNF 供应及部分树突棘形态和可塑性现象有关；即使**总 BDNF 蛋白近乎不变**，改变其细胞内分布仍可能出现突触表型。因此“总量正常”不等于“局部信号正常”。(An et al., 2008, Cell)

### 2. 前体加工：细胞内成熟与胞外剪切

BDNF 以具有前体区的多肽形式合成。前体加工可在细胞内发生，也有实验显示分泌到胞外的 proBDNF 可受纤溶酶（plasmin）及某些基质金属蛋白酶等加工。(Matsumoto et al., 2008, Nat Neurosci; Lee et al., 2001, Science; Pang et al., 2004, Science)

但要特别区分**加工机制存在**与**某种形式在天然神经元里通常释放多少**：

- Matsumoto 等（2008，Nat Neurosci）分析内源性小鼠神经元 BDNF，报告 proBDNF 被较快加工、储存和受兴奋性刺激释放的主要是成熟 BDNF。
- Yang 等（2009，Nat Neurosci）在另一研究体系中报告神经元可释放 proBDNF。
- 两种观察不应被粗暴合并成“神经元总是分泌 proBDNF”或“神经元绝不会释放 proBDNF”；应比较年龄、细胞类别、内源/外源标记、诱导协议、蛋白酶、抗体灵敏度及污染控制。(Matsumoto et al., 2008, Nat Neurosci; Yang et al., 2009, Nat Neurosci; Lim et al., 2015, J Neurochem)

### 3. 两条受体信号路径：不是永远的“一好一坏”

**成熟 BDNF—全长 TrkB：** BDNF 结合 TrkB 后，受体二聚化和酪氨酸磷酸化促使细胞内多个信号级联活化，包括 **Ras/MAPK–ERK、PI3K–Akt、PLCγ** 等，参与蛋白合成、存活、突触蛋白运输、树突形态和细胞内 Ca²⁺ 调节。具体输出取决于细胞类型、受体剪接变体与配体可用性。(Klein et al., 1991, Cell; Park & Poo, 2013, Nat Rev Neurosci; Lu et al., 2014, Handb Exp Pharmacol; Patapoutian & Reichardt, 2001, Curr Opin Neurobiol)

**proBDNF—p75NTR/sortilin：** 在特定交感神经元培养模型中，proBDNF 能借助 p75NTR 与 sortilin 共表达促进凋亡；在某些海马 CA1 模型中，proBDNF—p75NTR 信号参与 NMDA 受体依赖的 LTD。(Teng et al., 2005, J Neurosci; Woo et al., 2005, Nat Neurosci) 这不证明所有 proBDNF 作用都有害，或所有 mBDNF 作用都能改善学习；受体、发育阶段、剂量和刺激条件均不可省略。(Lee et al., 2001, Science; Teng et al., 2005, J Neurosci; Pang et al., 2004, Science; Woo et al., 2005, Nat Neurosci; Lu et al., 2014, Handb Exp Pharmacol)

**蛋白酶剪切和时序是关键调节节点。** Pang 等在特定海马晚期 LTP（L-LTP）实验中发现 tPA/plasmin 相关的 proBDNF 加工有重要作用；其结果不能直接扩写成“所有 LTP 都须经过胞外 plasmin 剪切”。(Pang et al., 2004, Science)

### 4. 突触可塑性：分泌位置和受体活化时间

在若干海马模型中，BDNF 缺失或 TrkB 缺失使特定 CA1-LTP 方案受损。(Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron) Hartmann 等在培养的谷氨酸能突触系统中观察到高频刺激后的 BDNF 分泌。(Hartmann et al., 2001, EMBO J) Harward 等利用双光子成像、TrkB 活性传感器和局部刺激，在**培养的海马脑片单个树突棘**上记录到 NMDA 受体、CaMKII 相关的突触后 BDNF 释放与 TrkB 活化，支持局部自分泌信号参与特定结构性与功能性可塑性。(Harward et al., 2016, Nature)

这些结果相互补充，说明 BDNF 不只是“脑组织中有多少蛋白”，其**信号来源（突触前/后）、微区定位、刺激时间和受体所在区室**也可能决定功能。(An et al., 2008, Cell; Hartmann et al., 2001, EMBO J; Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron; Harward et al., 2016, Nature)

### 5. LTP 与记忆行为之间仍隔着多个推断层次

Korte 等（1995，PNAS）的基因敲除研究与 Minichiello 等（1999，Neuron）的前脑条件 TrkB 敲除研究，分别报告部分 CA1-LTP 异常；后者发现复杂学习任务受损，却不等于所有任务均受损，而且部分 LTP 改变未必转化为可检测的行为缺陷。

Bekinschtein 等（2007、2008）在**特定大鼠学习任务**中通过时间窗干预提出：学习后的较晚阶段仍可能有 BDNF/新蛋白合成依赖过程，对记忆持续性有影响。但这两篇由**同一核心研究团队**完成，是扩展/交叉方法证据，不应写作“多组独立实验室已证明所有长期记忆都持续依赖同一分子机制”。(Bekinschtein et al., 2007, Neuron; Bekinschtein et al., 2008, PNAS)

### 6. 抑郁、抗抑郁药与运动：机制不等于临床指标

- **抗抑郁研究：** Autry 等在小鼠研究中把 NMDA 受体阻断后的快速抗抑郁样行为与 BDNF 翻译联系起来；Lepack 等在另一个动物/细胞体系中得到 BDNF 释放相关的证据。Casarotto 等进一步提出部分抗抑郁药可直接结合 TrkB 跨膜区并促进 BDNF 信号。(Autry et al., 2011, Nature; Lepack et al., 2014, Int J Neuropsychopharmacol; Casarotto et al., 2021, Cell) 这些是重要的**机制研究**，不能证明所有药物在所有患者中的抗抑郁效应都以 BDNF 为唯一必要途径，也不能把小鼠强迫游泳结果当作临床疗效直接证据。(Castrén & Monteggia, 2021, Biol Psychiatry)
- **临床相关性：** 抑郁与血清 BDNF 平均水平的关联在汇总研究中存在，但效应量受发表偏倚、样本量和研究年份等影响；与症状严重程度的关系并不稳定。(Molendijk et al., 2014, Mol Psychiatry; Polyakova et al., 2015, J Affect Disord; Bocchio-Chiavetto et al., 2010, World J Biol Psychiatry)
- **运动研究：** 2022 年健康人群运动随机试验荟萃分析和 2025 年老年人试验汇总报告外周 BDNF 平均上升，但结果依赖人群、运动方式和血液标本。**外周 BDNF 上升**并不独立证明海马 BDNF 同样上升，更不证明认知/抑郁症状必然随之改善。(Wang et al., 2022, Brain Behav; Gholami et al., 2025, Exp Gerontol)

## 关键研究与可重复性

### 研究脉络：从发现到多尺度操作

| 阶段 / 证据层级 | 关键研究 | 直接观察 | 不能直接推出 |
| --- | --- | --- | --- |
| **分子发现与受体** | Barde 等（1982，EMBO J）；Klein 等（1991，Cell） | 蛋白纯化的营养活性、TrkB 可响应 BDNF | BDNF 是特异的“记忆荷尔蒙” |
| **啮齿类遗传与 LTP** | Korte 等（1995，PNAS）；Minichiello 等（1999，Neuron） | 特定突变体海马 CA1-LTP 下降及部分行为差异 | 所有学习任务、所有脑区都需要相同强度的 BDNF 信号 |
| **活动依赖与局部信号** | Hartmann 等（2001，EMBO J）；An 等（2008，Cell）；Harward 等（2016，Nature） | 分泌、树突 mRNA 定位、单树突棘 TrkB 活化 | 已在完整人脑直接观测同一微区过程 |
| **前体与成熟形式** | Pang 等（2004，Science）；Woo 等（2005，Nat Neurosci）；Matsumoto 等（2008，Nat Neurosci）；Yang 等（2009，Nat Neurosci） | 前体剪切、特定 LTD、不同条件下检测到不同分泌形式 | proBDNF 恒为“坏”、mBDNF 恒为“好”，或二者分泌比例固定 |
| **动物记忆持续性** | Bekinschtein 等（2007、2008）(Bekinschtein et al., 2007, Neuron; Bekinschtein et al., 2008, PNAS) | 特定任务存在延迟的 BDNF 依赖阶段 | 两篇来自同团队就等于独立复现全部行为记忆机制 |
| **人类遗传关联** | Egan 等（2003，Cell）；Mandelman 等（2012，Genes Brain Behav）；Kambeitz 等（2012，Neurosci Biobehav Rev）；Harrisberger 等（2014，Neurosci Biobehav Rev） | 细胞功能效应较有依据，人群记忆/结构效应跨分析并不一致 | rs6265 可可靠预测个人记忆力或抑郁风险 |
| **血液标志物** | Klein 等（2011，Int J Neuropsychopharmacol）；Tikhonova 等（2022，Int J Mol Sci）；Molendijk 等（2014，Mol Psychiatry）；Naegelin 等（2018，eNeuro） | 某些动物血脑相关、有限人类研究未见相同相关、外周检测受样本体系影响 | 任意实验室的一次血 BDNF 检测就是脑内突触可塑性强弱 |
| **干预与转化** | Autry 等（2011，Nature）；Casarotto 等（2021，Cell）；Wang 等（2022，Brain Behav）；Gholami 等（2025，Exp Gerontol） | 动物分子机制、部分药物结合机制及外周干预关联 | 人类 BDNF 定量已成为独立认可的疗效/认知指标 |

### 三组尤其需要并列呈现的冲突

**冲突 A｜神经元究竟释放 proBDNF 还是成熟 BDNF？**

- **Matsumoto 等（2008，Nat Neurosci）：** 在其内源性小鼠神经元实验中，以成熟 BDNF 储存和分泌为主要结果。
- **Yang 等（2009，Nat Neurosci）：** 在其不同制备与检测体系中发现可检测的 proBDNF 释放。
- **编辑判断：** 前体的存在与“所有神经元在生理条件下都有足量前体释放”是不同命题。务必核查被检测的是天然内源、外源过表达、胞内储存还是胞外分泌；注明抗体交叉反应与蛋白酶处理。(Matsumoto et al., 2008, Nat Neurosci; Yang et al., 2009, Nat Neurosci; Lim et al., 2015, J Neurochem)

**冲突 B｜Val66Met 是否导致可预测的人类记忆差异？**

- **Egan 等（2003，Cell）：** 提供细胞内分泌机制和较早的人类记忆/成像关联。
- **Mandelman 与 Grigorenko（2012，Genes Brain Behav）：** 在多个认知表型的荟萃分析中未确立显著的总体关联。
- **Kambeitz 等（2012，Neurosci Biobehav Rev）：** 聚焦陈述性记忆等表型的荟萃分析观察到一些关联。
- **Harrisberger 等（2014，Neurosci Biobehav Rev）：** 海马体积关联非常小、受手工/自动分割方法及发表偏倚影响；其较大新样本未见显著关联。
- **编辑判断：** 细胞内运输机制和人群中稳定可重复的行为预测不是一回事；不要从任意一个荟萃分析抽出一句话当作无条件共识。

**冲突 C｜血 BDNF 能否代表脑 BDNF？**

- **Klein 等（2011，Int J Neuropsychopharmacol）：** 在大鼠和猪的若干血液—脑组织比较中见到正相关；物种和检测体系范围有限。
- **Tikhonova 等（2022，Int J Mol Sci）：** 纳入的人类同体中枢—外周研究很少，所审查的 BDNF 研究未见显著血脑相关。
- **Naegelin（2018，eNeuro）、Gejl（2019，Sci Rep） 与 Bevilacqua（2026，Clin Chem Lab Med）：** 强调血小板来源、不同血液组分、凝血/离心及前分析操作是关键变异来源。
- **编辑判断：** 动物组织相关性**不能**直接转化为人类单次外周检测的临床替代效度；也不能说在所有物种和场景中“绝对没有相关性”。

### 方法上的重复性检查

1. **分子身份：** 优先明确检测 mBDNF、proBDNF 还是两者合计；检验抗体对前体的交叉反应，必要时与免疫印迹或正交方法互证。(Lim et al., 2015, J Neurochem)
2. **模型与干预：** 记录物种、脑区、发育阶段、单/双等位基因操作、TrkB 全长/截短状态；发展期敲除表型不能自动等同于成人急性抑制效应。(Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron; Harward et al., 2016, Nature; Park & Poo, 2013, Nat Rev Neurosci)
3. **可塑性指标：** 区分基线传递、LTP 诱导、早/晚阶段及行为记忆；报告刺激方案和观察时间。(Pang et al., 2004, Science; Woo et al., 2005, Nat Neurosci; Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron; Harward et al., 2016, Nature; Bekinschtein et al., 2007, Neuron; Bekinschtein et al., 2008, PNAS)
4. **人群遗传学：** 比较不同种群的等位基因频率、任务、认知表型、共变量、样本量、预注册与多重检验；别把 rs6265 当作单基因决定论。(Egan et al., 2003, Cell; Mandelman & Grigorenko, 2012, Genes Brain Behav; Kambeitz et al., 2012, Neurosci Biobehav Rev; Harrisberger et al., 2014, Neurosci Biobehav Rev)
5. **血液检测：** 最少报告血清/血浆、采血时间、抗凝剂、凝血时间、离心方案、残留血小板、保存温度、冻融、检测试剂盒、批次和样本是否随机化。(Naegelin et al., 2018, eNeuro; Tsuchimine et al., 2014, Neuropsychobiology; Gejl et al., 2019, Sci Rep; Bevilacqua et al., 2026, Clin Chem Lab Med; Lim et al., 2015, J Neurochem)
6. **研究综述边界：** 荟萃分析并非自动等于因果或临床可用性；读者仍须检查纳入试验重叠、发表偏倚、异质性与实际结果的临床相关性。(Mandelman & Grigorenko, 2012, Genes Brain Behav; Kambeitz et al., 2012, Neurosci Biobehav Rev; Harrisberger et al., 2014, Neurosci Biobehav Rev; Molendijk et al., 2014, Mol Psychiatry; Polyakova et al., 2015, J Affect Disord; Wang et al., 2022, Brain Behav; Gholami et al., 2025, Exp Gerontol; Bevilacqua et al., 2026, Clin Chem Lab Med; Bocchio-Chiavetto et al., 2010, World J Biol Psychiatry)

## 当前较稳定的认识

1. **BDNF 属于神经营养因子，而非经典小分子神经递质；成熟 BDNF 能通过 TrkB 等受体调节发育和突触功能。** 这一框架有蛋白纯化、受体鉴定及多种细胞和动物实验支撑。(Barde et al., 1982, EMBO J; Klein et al., 1991, Cell; Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron; Harward et al., 2016, Nature; Park & Poo, 2013, Nat Rev Neurosci; Lu et al., 2014, Handb Exp Pharmacol; Lim et al., 2015, J Neurochem; Patapoutian & Reichardt, 2001, Curr Opin Neurobiol)
2. **BDNF 的功能具有明确的加工、定位和活动依赖性。** 不同转录本位置、前体剪切、受体共表达和分泌时机都能改变实验输出；“只看总量”经常不够。(Aid et al., 2007, J Neurosci Res; An et al., 2008, Cell; Hartmann et al., 2001, EMBO J; Matsumoto et al., 2008, Nat Neurosci; Yang et al., 2009, Nat Neurosci; Lee et al., 2001, Science; Teng et al., 2005, J Neurosci; Pang et al., 2004, Science; Woo et al., 2005, Nat Neurosci; Harward et al., 2016, Nature; Lim et al., 2015, J Neurochem)
3. **在若干哺乳动物海马模型中，BDNF/TrkB 对特定形式的可塑性和学习具有因果作用。** 基因、药理和局部成像方法提供互补证据，但不能概括为一切物种、环路、任务和时间窗的统一必要条件。(Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron; Harward et al., 2016, Nature; Bekinschtein et al., 2007, Neuron; Bekinschtein et al., 2008, PNAS)
4. **BDNF Val66Met 可影响某些细胞模型的分泌与运输，但它对人类一般认知表现或海马体积的稳定预测力远未确立。** 群体分析中的支持、零结果与方法依赖性并存。(Egan et al., 2003, Cell; Mandelman & Grigorenko, 2012, Genes Brain Behav; Kambeitz et al., 2012, Neurosci Biobehav Rev; Harrisberger et al., 2014, Neurosci Biobehav Rev)
5. **血清/血浆 BDNF 测定有明确的前分析和生物学混杂；目前不能将单次外周读数当作脑内 BDNF 的可靠替代值。** 与抑郁或运动的关联属于群体统计与干预指标，需要与临床终点分开解释。(Molendijk et al., 2014, Mol Psychiatry; Polyakova et al., 2015, J Affect Disord; Naegelin et al., 2018, eNeuro; Tsuchimine et al., 2014, Neuropsychobiology; Gejl et al., 2019, Sci Rep; Klein et al., 2011, Int J Neuropsychopharmacol; Tikhonova et al., 2022, Int J Mol Sci; Wang et al., 2022, Brain Behav; Gholami et al., 2025, Exp Gerontol; Bevilacqua et al., 2026, Clin Chem Lab Med; Bocchio-Chiavetto et al., 2010, World J Biol Psychiatry)

## 争议与推断边界

### 尚有实质争议 / 不足以作通用结论

- **前体是否在天然成年脑中具有何种浓度与时空尺度的信号效应？** 不同分泌检测结果、加工模型与抗体特异性意味着不能直接比较所有论文的 proBDNF/mBDNF 比值。(Matsumoto et al., 2008, Nat Neurosci; Yang et al., 2009, Nat Neurosci; Lee et al., 2001, Science; Teng et al., 2005, J Neurosci; Pang et al., 2004, Science; Woo et al., 2005, Nat Neurosci; Lim et al., 2015, J Neurochem)
- **BDNF 是所有形式 LTP 的必要条件吗？** 不是这样表述证据最稳妥。应明确脑区、突触、刺激强度、发育期与受体亚型。结构性 LTP、切片电生理和行为记忆都不是彼此可替换的终点。(Pang et al., 2004, Science; Woo et al., 2005, Nat Neurosci; Korte et al., 1995, PNAS; Minichiello et al., 1999, Neuron; Harward et al., 2016, Nature; Bekinschtein et al., 2007, Neuron; Bekinschtein et al., 2008, PNAS)
- **Val66Met 是否足以决定某人记忆力、脑结构或精神障碍风险？** 不足。领域汇总之间存在总体零结果、表型特异关联与影像测量依赖，且共同环境与其他基因变异并未被单一 SNP 控制。(Egan et al., 2003, Cell; Mandelman & Grigorenko, 2012, Genes Brain Behav; Kambeitz et al., 2012, Neurosci Biobehav Rev; Harrisberger et al., 2014, Neurosci Biobehav Rev)
- **抑郁是否就是“BDNF 缺乏”？** 不是已证实的单因果模型。血清组间差异不能定位脑内病变来源，效应可能受用药、炎症、年龄、血小板和其他因素影响；不同个体的诊断和用药选择不能仅由其血 BDNF 指导。(Molendijk et al., 2014, Mol Psychiatry; Polyakova et al., 2015, J Affect Disord; Naegelin et al., 2018, eNeuro; Tsuchimine et al., 2014, Neuropsychobiology; Gejl et al., 2019, Sci Rep; Klein et al., 2011, Int J Neuropsychopharmacol; Tikhonova et al., 2022, Int J Mol Sci; Castrén & Monteggia, 2021, Biol Psychiatry; Bocchio-Chiavetto et al., 2010, World J Biol Psychiatry)
- **所有抗抑郁药都会直接结合 TrkB 吗？** 2021 年存在支持某类直接结合机制的实验；是否为不同药物在临床患者中共同、充分、必需的路径仍须更广泛的正交验证。(Autry et al., 2011, Nature; Lepack et al., 2014, Int J Neuropsychopharmacol; Casarotto et al., 2021, Cell; Castrén & Monteggia, 2021, Biol Psychiatry)
- **运动让血 BDNF 上升是否就证明能“增智”？** 不足。运动汇总研究观察的是不同方法下的**外周指标**，而非直接的海马浓度、突触信号或所有人群的认知临床获益。(Naegelin et al., 2018, eNeuro; Tsuchimine et al., 2014, Neuropsychobiology; Gejl et al., 2019, Sci Rep; Klein et al., 2011, Int J Neuropsychopharmacol; Tikhonova et al., 2022, Int J Mol Sci; Wang et al., 2022, Brain Behav; Gholami et al., 2025, Exp Gerontol; Bevilacqua et al., 2026, Clin Chem Lab Med)
- **外周 BDNF 是否可作脑内水平的无创替代？** 动物相关证据与人类系统证据并不一致，且标本体系差异很大；临床验证所需的阈值、敏感度、特异度和跨实验室校准并未因某篇相关性论文而确立。(Naegelin et al., 2018, eNeuro; Tsuchimine et al., 2014, Neuropsychobiology; Gejl et al., 2019, Sci Rep; Klein et al., 2011, Int J Neuropsychopharmacol; Tikhonova et al., 2022, Int J Mol Sci; Bevilacqua et al., 2026, Clin Chem Lab Med)

### 典型过度推断（应避免）

> “BDNF 数值越高，人的学习、情绪和脑健康就越好。”

> “一份血清 BDNF 报告就能看出一个人的海马可塑性。”

> “Val66Met 可以用来预测个人的记忆力或抑郁命运。”

> “既然抗抑郁药可能作用于 TrkB，BDNF 就是抑郁症唯一病因。”

这些说法混淆了**分子功能、动物因果证据、人群组间相关、临床个体预测**，不应写入正式公开稿。(Egan et al., 2003, Cell; Mandelman & Grigorenko, 2012, Genes Brain Behav; Kambeitz et al., 2012, Neurosci Biobehav Rev; Harrisberger et al., 2014, Neurosci Biobehav Rev; Molendijk et al., 2014, Mol Psychiatry; Polyakova et al., 2015, J Affect Disord; Naegelin et al., 2018, eNeuro; Tsuchimine et al., 2014, Neuropsychobiology; Gejl et al., 2019, Sci Rep; Klein et al., 2011, Int J Neuropsychopharmacol; Tikhonova et al., 2022, Int J Mol Sci; Wang et al., 2022, Brain Behav; Gholami et al., 2025, Exp Gerontol; Bevilacqua et al., 2026, Clin Chem Lab Med; Autry et al., 2011, Nature; Lepack et al., 2014, Int J Neuropsychopharmacol; Casarotto et al., 2021, Cell; Castrén & Monteggia, 2021, Biol Psychiatry)
