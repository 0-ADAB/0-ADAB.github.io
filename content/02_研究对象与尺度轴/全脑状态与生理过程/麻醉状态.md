# 麻醉状态

> **一句话定义：** 麻醉状态是麻醉药诱导的、可逆的意识体验丧失与行为无反应状态；它不是单一"深度"的一个点，而是**无意识、遗忘、镇痛、制动与自主神经抑制**这几项可分离成分的组合，在网络层面对应脑区之间有效连接与信息整合的崩溃，而这些成分的相对组合随药物、剂量与个体而变。(Brown et al., 2010, N Engl J Med; Brown et al., 2011, Annu Rev Neurosci; Franks, 2008, Nat Rev Neurosci)

## 快速理解

把麻醉想成"**被药拨下来的一组开关**"，而不是一个统一的开关：有的药主要抑制觉醒环路让人睡过去，有的阻断 NMDA 受体产生分离样状态，有的还要额外处理疼痛反射、肌肉松弛和自主神经反射。临床上一次"麻醉成功"的判断，实际是这几个方面同时达标。

| 成分 | 通俗含义 | 为什么必须分开看 |
| --- | --- | --- |
| **无意识／催眠**（hypnosis, unconsciousness） | 失去主观体验、不能被唤醒 | 不等于遗忘或镇痛；清醒者在缺少后两项时仍会记住并疼痛 |
| **遗忘**（amnesia） | 对术中事件不能形成可提取的记忆 | 遗忘可在较浅的镇静深度下出现，与"是否清醒"不同步 |
| **镇痛**（analgesia） | 伤害性输入的传导与感受被压制 | 与无意识的药物靶点和剂量—反应关系都不相同 |
| **制动**（immobility）与反射抑制 | 不体动、自主反射减弱 | 是 MAC 这类指标的操作终点，不是"意识消失"的终点 |
| **自主神经调控** | 血压、心率、体温等被改变或维持 | 属生理管理目标，不是意识成分本身 |

(Brown et al., 2010, N Engl J Med; Eger et al., 1965, Anesthesiology; Brown et al., 2011, Annu Rev Neurosci)

**为什么它在脑科学里重要。** 麻醉是人类唯一可以**有控制、可逆地反复开关意识**的情形：同一个人在几十分钟内经历清醒—无反应—清醒的全过程，并能同步记录脑电、影像，罕见情况下还能记录颅内信号。这使麻醉成为检验"意识需要哪些神经过程"的主要实验平台之一 (Alkire et al., 2008, Science; Brown et al., 2011, Annu Rev Neurosci)。

**仍未确定的部分。** 分子靶点如何一步步导致意识消失（"分子—系统解释鸿沟"）尚未被填满；不同药物的分子起点不同，却都能导致行为上的无反应，这一现象本身说明"一个机制解释所有麻醉药"的假说仍待检验 (Franks, 2008, Nat Rev Neurosci; Hemmings et al., 2005, Trends Pharmacol Sci)。

## 概念界定与边界

1. **麻醉 ≠ 睡眠。** 两者都有行为静止和慢波脑电，但麻醉状态不能被伤害性刺激或呼唤唤醒，其慢波在空间上更弥散、**不能有效募集纺锤波**，且伴随额部 alpha 振荡与特定的低频—alpha 相位耦合 (Murphy et al., 2011, Sleep; Akeju & Brown, 2017, Curr Opin Neurobiol; Purdon et al., 2013, PNAS)。但在环路层面二者确实共享部分结构：吸入麻醉药可直接激活促睡的 VLPO 神经元，GABA 能麻醉药的镇静部分经由结节乳头核（TMN）发挥作用 (Moore et al., 2012, Curr Biol; Nelson et al., 2002, Nat Neurosci)。因此准确的说法是"**借用部分睡眠环路，状态本身不等同**"。
2. **麻醉 ≠ 昏迷。** 昏迷由脑损伤或代谢障碍引起，恢复取决于病因；麻醉是药理学可逆状态，停药后按药代动力学恢复 (Brown et al., 2010, N Engl J Med)。
3. **MAC 是终点，不是"意识阈值"。** 最低肺泡有效浓度（MAC）定义为使 50% 受试者在标准化伤害性刺激下**不发生体动**的肺泡浓度，是群体中位数的行为终点；在此基础上还有 MAC-awake 等派生指标 (Eger et al., 1965, Anesthesiology)。把 MAC 当作"无意识所需浓度"或把呼气末浓度当作意识读数都是常见误解。
4. **"无反应"是操作定义，不等于"没有体验"。** 麻醉研究大多以对指令的反应性定义意识消失；但反应性依赖于唤醒性注意通路、任务显著性与运动输出。证据是：诱导过程中受试者先失去对**低显著性声音**的反应、随后才失去对**言语**的反应，恢复时顺序相反 (Purdon et al., 2013, PNAS)；且极少数患者出现**术中知晓（awareness with recall）**，多中心前瞻研究在 19,575 例手术中确认 25 例（0.13%），ASA III–V 的比值比为 2.41（95% CI 1.04–5.60）(Sebel et al., 2004, Anesth Analg)。这说明"无反应"与"无主观体验"之间的缺口是真实存在的。
5. **不同药物的状态不通用。** 丙泊酚、七氟醚与氯胺酮都可导致无反应，但它们改变的功能连接模式、脑电签名与主观报告质量并不相同；氯胺酮相关的网络解离模式与 GABA 能药物差异明显 (Lee et al., 2013, Anesthesiology; Bonhomme et al., 2016, Anesthesiology; Nelson et al., 2002, Nat Neurosci)。把某一药物的发现称为"麻醉的机制"是不严谨的。
6. **不属于本页范围。** 具体给药方案与剂量计算、气道与循环管理、术后谵妄的防治，以及小儿神经毒性的完整证据链，分属临床应用类节点；本页只在概念边界处引用可界定或限制该概念的证据。

**三层尺度不要互换：**

| 层次 | 研究对象 | 不能混淆的推论 |
| --- | --- | --- |
| 分子 | GABA\_A 受体、NMDA 受体、双孔域钾通道、α2 受体、HCN 通道 | 测得某药作用于某受体，不等于解释了为何失去意识 |
| 环路／网络 | 丘脑—皮层、额顶网络、显著性网络、VLPO／TMN | 网络指标改变是状态的相关标记，需与行为终点并列看 |
| 行为／临床 | 反应性、回忆、镇痛评分、体动、MAC | 任一项达标都不代表其他成分同时达标 |

(Franks, 2008, Nat Rev Neurosci; Brown et al., 2011, Annu Rev Neurosci; Eger et al., 1965, Anesthesiology)

## 结构与机制（适用时）

### 1. 分子入口：并不止一条

| 主要机制 | 代表药物 | 代表性证据 | 边界 |
| --- | --- | --- | --- |
| 增强 GABA\_A 受体介导的抑制 | 丙泊酚、依托咪酯、巴比妥类、部分吸入麻醉药 | 分子与受体层面的综述证据；麻醉药的镇静成分可在 TMN 这一结节乳头核节点上被 GABA\_A 拮抗剂削弱 (Hemmings et al., 2005, Trends Pharmacol Sci; Nelson et al., 2002, Nat Neurosci) | 受体占据经过 ⇏ 意识消失的解释完成 |
| 抑制 NMDA 受体 | 氯胺酮、氧化亚氮、氙 | 药理学综述；氯胺酮引起不同于 GABA 能药物的功能连接改变 (Franks, 2008, Nat Rev Neurosci; Bonhomme et al., 2016, Anesthesiology) | 阻断 NMDA 并非氯胺酮全部作用的上限 |
| 激活双孔域背景钾通道（K2P） | 吸入麻醉药（醚类、氟烷等） | 氯通道激活的直接电生理证据 (Patel et al., 1999, Nat Neurosci) | 多为离体表达系统；与整体行为终点的定量关系未闭合 |
| 其他／共同作用位点 | 挥发性麻醉药、α2 受体激动剂等 | 多靶点综述指出麻醉药常作用于多个位点，单靶点解释通常不足 (Hemmings et al., 2005, Trends Pharmacol Sci; Franks, 2008, Nat Rev Neurosci) | 多靶点并存使"一个靶点解释一种药"的写法不成立 |

关键点：**"不同分子起点，相似的行为终点"**——这提示在系统层面可能存在少数共同的失效模式，但该推断仍缺直接证明 (Alkire et al., 2008, Science; Franks, 2008, Nat Rev Neurosci)。

### 2. 网络层面：两种互补的解释路线

- **"自下而上"（bottom-up）：丘脑作为开关。** 早期 PET 证据显示麻醉期间丘脑代谢/活动下降，并提出**丘脑—皮层信息传递中断（thalamocortical switch）**的假说 (Fiset et al., 1999, J Neurosci; Alkire et al., 2000, Conscious Cogn)。随后的人类 PET 功能连接分析显示，丙泊酚所致无意识时期，丘脑与皮层之间的连接下降 (White & Alkire, 2003, NeuroImage)；颅内记录进一步支持无意识期丘脑—皮层连接减弱 (Malekmohammadi et al., 2019, Brain)。这些结果与药理唤醒的可逆实验相容：毒扁豆碱（physostigmine）在丙泊酚麻醉下恢复意识时，PET 显示**丘脑与楔前叶**参与其中 (Xie et al., 2011, Br J Anaesth)。
- **"自上而下"（top-down）：皮层整合失效。** 另一条证据链认为关键不在"输入被切断"，而在皮层内部无法整合信息：丙泊酚所致无意识期出现网络内与网络间 resting-state 功能连接的同时崩溃 (Boveroux et al., 2010, Anesthesiology)；EEG 的动态因果建模显示额—顶的有效连接被削弱 (Boly et al., 2012, J Neurosci)；多种药物都能破坏额—顶通讯，但模式不同 (Lee et al., 2013, Anesthesiology)。**"自上而下"路线的综述与整合可作为框架参照** (Mashour, 2014, Front Syst Neurosci)。

两者不是互斥的：可能的情形是不同药物经不同入口，最终落到"整合—反馈能力下降"这一共同终点 (Alkire et al., 2008, Science; Brown et al., 2011, Annu Rev Neurosci)。

### 3. 借用睡眠环路：部分解释，不是全部

- GABA 能麻醉药的镇静成分需要\*\*结节乳头核（TMN）\*\*参与，且氯胺酮的镇静不受 GABA\_A 拮抗剂影响——这一反例直接说明"借用睡眠环路"的适用范围有限 (Nelson et al., 2002, Nat Neurosci)。
- 挥发性麻醉药可直接使促睡的 **VLPO** 神经元去极化（关闭背景钾电导），损毁 VLPO 可产生对异氟烷催眠作用的急性耐受 (Moore et al., 2012, Curr Biol)。
- 更系统的综述把"内源性睡眠—觉醒与镇痛系统"作为麻醉作用的共同基质加以整理 (Lu et al., 2008, J Comp Neurol; Lydic & Baghdoyan, 2005, Anesthesiology)。

### 4. 皮层动力学：可读的脑电签名与中间态

- **失去意识瞬间出现了什么。** 在癫痫患者植入电极期间记录的多尺度活动显示，丙泊酚致意识消失发生在 **<1 Hz 慢振荡**骤然出现的数秒之内；此时局部（<4 mm）网络的毫秒级连接模式仍保留，但活动在时间与空间上被**碎片化** (Lewis et al., 2012, PNAS)。
- **可复核的无意识脑电签名。** 高密度 EEG 显示，意识消失同时表现为 <1 Hz 功率升高、枕部空间相干 alpha 振荡消失，以及额部空间相干 alpha 振荡出现；这些变化在恢复时逆序恢复 (Purdon et al., 2013, PNAS)。轻麻醉期的间歇性反应性与"清醒 alpha 振荡功率"的下降相关 (Pavone et al., 2017, Front Syst Neurosci)。
- **深度麻醉与爆发抑制。** 更深的抑制表现为爆发与等电位交替出现（burst suppression），已有神经—代谢模型把它解释为脑代谢供给与神经需求失配的结果 (Ching et al., 2012, PNAS)。这类模型的解释力仍在检验中。
- **麻醉中的慢波虽像睡眠，却不是睡眠。** 丙泊酚慢波与 NREM 慢波的皮层起源相似、都沿默认网络中线结构传播，但**空间更弥散、不能有效带动纺锤波**，并伴有源自前/后扣带回的 gamma 功率升高 (Murphy et al., 2011, Sleep)。
- **苏醒不是简单的逆过程。** 人类从丙泊酚麻醉苏醒前存在一个短暂状态：出现类似 II 期睡眠 K 复合波的大幅、广泛分布的慢感觉诱发电位，而自发活动与此不同 (Lewis et al., 2018, eLife)。这提示"恢复"有中间态，不是一条可逆曲线上的同一路径。

### 5. 读数与监测：代理指标，不是意识测量

- 临床用脑电（及其派生的处理指数）提供了可操作的深度监测，但**不同药物的脑电签名不能互换，同一指数在不同药物、年龄与脑状态下的含义不同** (Purdon et al., 2015, Anesthesiology; Akeju & Brown, 2017, Curr Opin Neurobiol)。
- 随机对照证据**并不一致**：在高风险人群中，BIS 指导的麻醉减少了知晓报告（1225 例 vs 1238 例，2 例 vs 11 例，p = 0.022）(Myles et al., 2004, Lancet)；而在另一项 2000 例的随机试验中，BIS 指导组与呼气末麻醉气体（ETAG）指导组各有 2 例明确知晓（绝对差异 0%，95% CI −0.56% ~ 0.57%），未显示 BIS 优效 (Avidan et al., 2008, N Engl J Med)。**既不能据此断言"监测无用"，也不能断言"监测保证无意识"。**

## 关键研究与可重复性

| 研究链条 | 原始数据／实验设计 | 补充证据或重要不一致 | 审慎结论 |
| --- | --- | --- | --- |
| **分子靶点** | K2P 背景钾通道被吸入麻醉药激活 (Patel et al., 1999, Nat Neurosci) | 多靶点机制综述 (Hemmings et al., 2005, Trends Pharmacol Sci; Franks, 2008, Nat Rev Neurosci) | 靶点层面的证据扎实；与行为终点之间仍有解释鸿沟 |
| **丘脑—皮层开关** | 人类 PET 显示丙泊酚致无意识期皮层代谢改变 (Fiset et al., 1999, J Neurosci)；丘脑—皮层连接下降 (White & Alkire, 2003, NeuroImage) | 颅内电生理支持丘脑—皮层连接减弱 (Malekmohammadi et al., 2019, Brain)；毒扁豆碱唤醒的 PET 显示丘脑与楔前叶参与 (Xie et al., 2011, Br J Anaesth) | 丘脑参与证据充分；"单开关"表述过强，且样本量普遍偏小 |
| **网络／有效连接崩溃** | fMRI 网络内与网络间连接同时崩溃 (Boveroux et al., 2010, Anesthesiology) | EEG 动态因果建模显示额—顶有效连接减弱 (Boly et al., 2012, J Neurosci)；跨药物的额—顶通讯破坏 (Lee et al., 2013, Anesthesiology) | 整合失败是可复现的现象；多数为相关设计，因果操纵有限 |
| **是否借用睡眠环路** | TMN 内注射 GABA\_A 拮抗剂削弱 GABA 能麻醉药的镇静 (Nelson et al., 2002, Nat Neurosci)；挥发性麻醉药直接去极化 VLPO 神经元 (Moore et al., 2012, Curr Biol) | 氯胺酮镇静不受 GABA\_A 拮抗剂影响；系统性综述 (Lu et al., 2008, J Comp Neurol; Lydic & Baghdoyan, 2005, Anesthesiology) | 部分药物确实借用睡眠环路；不能推广到全部麻醉药 |
| **高密度 EEG 签名** | 渐变诱导/苏醒过程的行为—EEG 对应关系 (Purdon et al., 2013, PNAS) | 轻麻醉期的反应性与 alpha 功率变化 (Pavone et al., 2017, Front Syst Neurosci)；2024 年有向连接分析 (Troyas et al., 2024, Anesthesiology) | 签名在丙泊酚/七氟醚中较稳定；跨药物外推需单独验证 |
| **细胞尺度的过渡证据** | 人类多尺度颅内记录显示 <1 Hz 慢振荡与网络碎片化同步出现 (Lewis et al., 2012, PNAS) | 苏醒前出现类 K 复合波的短暂状态 (Lewis et al., 2018, eLife) | 罕见人群（植入电极患者）的小样本证据，不宜直接推广为普遍机制 |
| **麻醉 vs 睡眠的 EEG 比较** | 256 导 EEG 比较丙泊酚麻醉与自然睡眠慢波 (Murphy et al., 2011, Sleep) | 振荡层面的系统综述 (Akeju & Brown, 2017, Curr Opin Neurobiol) | 8 例样本；结论为"相似但可辨别"，不是"等同" |
| **麻醉 vs 昏迷的关系** | 状态比较的系统综述视角 (Brown et al., 2010, N Engl J Med) | 系统神经科学综述 (Brown et al., 2011, Annu Rev Neurosci) | 可逆性、病因与恢复动力学三者区别明确 |
| **知晓流行病学与预防** | 多中心前瞻队列，19,575 例中 25 例确认知晓（0.13%）(Sebel et al., 2004, Anesth Analg) | BIS 指导减少知晓的 RCT（阳性）(Myles et al., 2004, Lancet) 与 BIS 未显示优效的 RCT（经剂量对照）(Avidan et al., 2008, N Engl J Med) | 知晓罕见但真实存在；监测策略的相对价值依赖对照条件，不可一概而论 |
| **发育期暴露的边界证据** | 婴儿期随机对照试验（GAS）报告 2 岁时两组神经发育结局未见显著差异 (Davidson et al., 2016, Lancet) | 监管机构的动物证据综述与风险提示（US FDA, 2016, FDA Drug Safety Communication） | 单次短时暴露的 RCT 证据较安抚；长时间/多次暴露仍不确定 |
| **新近高分辨率证据** | 小鼠宽视野钙成像显示不同麻醉药均增强压后皮层 1.5–2.5 Hz 振荡 (Xia et al., 2026, Anesth Analg) | 尚无同期独立复制 | 提示可能存在跨药物的区域共同节点；动物、单实验室、待复制 |

**可重复性表述标准：** 分子靶点证据、动物环路操纵与人类影像／电生理属于不同层级；互为补充不等于互相替代。样本量小的机制研究（如 8 例的 hd-EEG、颅内电极患者研究）应作为"机制线索"而非"群体定量结论"。临床问卷与访谈类终点（知晓）依赖术后询问时机与判读标准，不同研究的计数口径不同，不能直接合并。

## 当前较稳定的认识

1. **麻醉状态是多个可分离成分的组合，单看"是否体动"或"是否能回忆"都不能定义麻醉是否足够。** (Brown et al., 2010, N Engl J Med; Eger et al., 1965, Anesthesiology)
2. **存在不止一条分子入口。** GABA\_A 增强、NMDA 拮抗与双孔域钾通道激活等都有直接证据，且不同麻醉药的主导机制不同 (Patel et al., 1999, Nat Neurosci; Hemmings et al., 2005, Trends Pharmacol Sci; Nelson et al., 2002, Nat Neurosci)。
3. **意识消失在网络层面表现为整合能力的崩溃**，具体形式包括丘脑—皮层连接下降与额—顶有效连接减弱；"自下而上"与"自上而下"两条路线各有支持，可能共同成立 (Fiset et al., 1999, J Neurosci; White & Alkire, 2003, NeuroImage; Boveroux et al., 2010, Anesthesiology; Boly et al., 2012, J Neurosci; Mashour, 2014, Front Syst Neurosci)。
4. **麻醉可借用内源性睡眠环路，但麻醉状态本身不是睡眠。** 直接的 EEG 比较与环路操纵证据同时支持这两句话 (Murphy et al., 2011, Sleep; Moore et al., 2012, Curr Biol; Akeju & Brown, 2017, Curr Opin Neurobiol)。
5. **存在可复核但仍非决定性的脑电标记**（低频功率升高、枕部 alpha 消失、额部 alpha 出现、慢振荡碎片化），不过它们随药物与年龄而变 (Purdon et al., 2013, PNAS; Lewis et al., 2012, PNAS; Purdon et al., 2015, Anesthesiology)。
6. **"无反应"不等于"无体验"。** 术中知晓虽罕见（约 0.13%）但真实存在，且反应性的丧失与恢复存在明确的顺序效应：先失去对低显著性刺激的反应，恢复时顺序相反 (Sebel et al., 2004, Anesth Analg; Purdon et al., 2013, PNAS)。

## 争议与推断边界

- **"统一机制"尚未成立。** thalamocortical switch 是有 PET 数据支持的**假说框架**，不是已被证明的唯一解释；不同药物的分子起点差异表明，最后的网络终局可能比单一开关更复杂 (Alkire et al., 2000, Conscious Cogn; Alkire et al., 2008, Science; Franks, 2008, Nat Rev Neurosci)。
- **分子—系统解释鸿沟。** 从受体占据到意识消失之间缺少可量化的中间链条；用分子机制解释行为终点，或用网络现象反推单一分子机制，都是过度推论 (Franks, 2008, Nat Rev Neurosci; Brown et al., 2011, Annu Rev Neurosci)。
- **"麻醉＝睡眠"与"麻醉与睡眠毫无关系"都不成立。** 前者忽略可唤醒性、纺锤波与振荡特征的差异；后者忽略 VLPO／TMN 的直接证据 (Murphy et al., 2011, Sleep; Moore et al., 2012, Curr Biol; Nelson et al., 2002, Nat Neurosci)。
- **氯胺酮等 NMDA 拮抗剂构成重要反例。** 其镇静不受 GABA\_A 拮抗剂影响，功能连接改变模式也与 GABA 能药物不同；因此"所有麻醉药共享同一条环路"应改写为"不同药物经不同入口，可能收敛于整合失败" (Nelson et al., 2002, Nat Neurosci; Bonhomme et al., 2016, Anesthesiology; Lee et al., 2013, Anesthesiology)。
- **监测指数不是意识的代理测量。** 两项大型 RCT 结论不一致（一项阳性、一项未显示优效），说明指数有效性与对照条件、目标人群、终点定义都有关；不得用指数值断言"患者一定无意识" (Myles et al., 2004, Lancet; Avidan et al., 2008, N Engl J Med; Purdon et al., 2015, Anesthesiology)。
- **MAC 外推的边界。** MAC 以制动为终点、是群体中位数；把它当成"无意识阈值"或跨个体精确预测指标都不合适 (Eger et al., 1965, Anesthesiology)。
- **物种与人群外推。** 小鼠 c-Fos／损毁实验、健康志愿者影像、手术患者 EEG、植入电极患者的颅内记录，是四个不同的证据层级；特别是颅内与 widefield 研究的样本结构特殊（癫痫患者、转基因小鼠），不能直接推广到普通人群 (Moore et al., 2012, Curr Biol; Lewis et al., 2012, PNAS; Xia et al., 2026, Anesth Analg)。
- **burst suppression 与结局的关系多为观察性。** 尽管有模型解释其产生机制，关于它与术后认知改变或谵妄关系的证据仍以队列研究为主，因果未定 (Ching et al., 2012, PNAS; Purdon et al., 2015, Anesthesiology)。
- **发育期暴露的推断要克制。** 单次短时暴露的 RCT 未见 2 岁时的显著神经发育差异，这与动物研究中长时间暴露的神经毒性证据并不矛盾，只是适用条件不同；本页不据此提供任何就医或用药建议 (Davidson et al., 2016, Lancet; US FDA, 2016, FDA Drug Safety Communication)。
- **最新证据的时间风险。** (Troyas et al., 2024, Anesthesiology) 与 (Xia et al., 2026, Anesth Analg) 发表较近且缺乏独立复制，本页仅作为"方向性线索"收录。
- **人工审核待查：** ①是否需要另建"术中知晓""脑电意识监测（BIS 等）""MAC 与麻醉深度""爆发抑制"等子节点；②本 Vault 是否已有同义节点（如"全身麻醉""麻醉共病"）需要合并；③(Eger et al., 1965, Anesthesiology) 仅用于 MAC 的历史定义，若需现代数据应另补来源。
