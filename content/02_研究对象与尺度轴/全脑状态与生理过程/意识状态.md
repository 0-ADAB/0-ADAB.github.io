# 意识状态

> **一句话定义：** 意识状态（consciousness / conscious state）不是单一可读数，而是描述全脑整体工作模式的概念，通常被拆成两个可以彼此分离的维度——**觉醒水平**（waking / arousal，是否处于可被唤起的清醒状态）与**觉知内容**（awareness / experience，是否存在可被报告或推断的主观体验）；支撑它的是丘脑—皮层系统同时具备的**整合**与**分化**能力，而我们能测量的永远只是它的代理指标，不是意识本身。(Laureys, 2005, Trends Cogn Sci; Laureys et al., 2010, BMC Med; Koch et al., 2016, Nat Rev Neurosci; Bayne et al., 2016, Trends Cogn Sci)

## 快速理解

把意识状态理解成"这台机器是否开机、以及屏幕上是否有内容"两件不同的事，比理解成"一个从 0 到 100 的刻度"更接近现有证据。

- **开机但不显示内容**，对应临床上的无反应觉醒综合征（UWS，旧称植物状态）：患者有睁闭眼与睡眠—觉醒周期，却没有可重复的觉知内容证据 (Laureys, 2005, Trends Cogn Sci; Laureys et al., 2010, BMC Med)。
- **有内容但无法输出**，对应认知运动分离（CMD）：患者行为上无命令跟随，任务态影像或脑电却显示出按指令调制的大脑反应 (Schiff, 2015, JAMA Neurol; Claassen et al., 2019, N Engl J Med; Bodien et al., 2024, N Engl J Med)。
- **脑电呈激活态但对外部世界休眠**，对应快速眼动睡眠中的梦境：睡眠者对外界刺激几乎无反应，却报告丰富的主观体验 (Siclari et al., 2017, Nat Neurosci)。
- **药物可逆地抹掉内容**，对应全身麻醉：丙泊酚等药物使皮层网络进入高度同步、整合能力下降的可逆状态 (Alkire et al., 2008, Science; Purdon et al., 2013, PNAS; Mhuircheartaigh et al., 2010, J Neurosci)。

**为什么它对研究者重要。** 几乎所有脑测量都受整体状态调制：同一刺激在不同意识水平下得到的反应幅值、相关结构、解码精度与行为成绩都不同。把"整体状态"当作噪声丢掉，或反过来把任何一次测量差异都归因于"意识水平变了"，都是这一领域最常见的两类错误。

**还没有定论的部分。** 意识本身无法被直接测量：实验上只能依赖报告（受损患者恰恰不能报告）或"代理指标"，而不同代理指标可以相互分离、给出矛盾结论。这使"某测量是否在测意识"本身成为未决问题 (Bayne et al., 2024, Trends Cogn Sci)。此外，主流理论（全局神经元工作空间理论 GNWT 与整合信息理论 IIT）虽已进入对抗性合作检验，其核心预测仍未同时被满足 (Ferrante et al., 2025, Nature)。

## 概念界定与边界

1. **两维度框架是分析工具，不是已证实的模块划分。** 把意识拆成"觉醒水平"与"觉知内容"有明确的临床理由（二者在 UWS 中分离），但这一拆分本身是概念与临床层面的操作，不证明存在两个彼此独立的神经模块 (Laureys, 2005, Trends Cogn Sci; Bayne et al., 2016, Trends Cogn Sci)。
2. **"水平"隐喻正在被质疑。** 用"意识水平高低"描述状态隐含了单一有序刻度，而临床与实验证据更支持**多维、非单序**的结构：不同维度可以各自独立变动，某些病理状态难以在单一刻度上排序 (Bayne et al., 2016, Trends Cogn Sci)。因此本页使用"意识状态"而非"意识水平"作为标题。
3. **意识状态 ≠ 觉醒 ≠ 注意。** 觉醒是意识状态的两个维度之一（另一维度是觉知内容）；注意是在特定内容上的选择性加工，与整体状态可被部分分离。三者常被混用，混用会直接导致错误推论。
4. **意识状态 ≠ 意识的内容是什么。** 本页关注"整体状态"这一尺度；具体意识内容（看到红色、想起某段记忆）的神经表征属于"意识相关神经活动"的范畴，二者不能互换 (Koch et al., 2016, Nat Rev Neurosci)。
5. **清醒 ≠ 有意识内容，无反应 ≠ 无意识。** 前者见 UWS，后者见 CMD、闭锁综合征与麻醉中的"无反应但有体验"报告 (Sanders et al., 2012, Anesthesiology; Schiff, 2015, JAMA Neurol)。
6. **适用对象。** 本页机制描述以人类证据为主、辅以动物模型。非人动物的意识状态判定需依赖"无报告"范式与理论中性指标，且其结论受理论假设约束 (Tsuchiya et al., 2015, Trends Cogn Sci; Bayne et al., 2024, Trends Cogn Sci)。
7. **不属于本页范围。** 具体 DoC 亚类的诊断标准与评估量表流程、脑死亡判定、麻醉深度监测、精神科意义上的"意识障碍"，均有专门节点；本页只处理"意识状态"这一概念本身及其边界。

**三层尺度不要互换：**

| 层次 | 研究对象 | 不能混淆的推论 |
| --- | --- | --- |
| 环路／网络 | 丘脑—皮层系统、默认网络、皮层下—皮层回路 | 某网络连接强度变化不等于意识状态本身改变 |
| 状态／指标 | 脑电频谱与复杂度、任务态激活、静息态连接、行为量表 | 指标间可分离，任一项都不是意识状态的定义 |
| 内容／报告 | 主观报告、命令跟随、做梦报告 | 报告缺失可由无意识造成，也可由输出通路损坏造成 |

(Laureys, 2005, Trends Cogn Sci; Alkire et al., 2008, Science; Casali et al., 2013, Sci Transl Med; Sanders et al., 2012, Anesthesiology)

## 结构与机制（适用时）

### 1. 两个维度及其临床对应

| 维度 | 含义 | 常用判据 | 可分离的反例 |
| --- | --- | --- | --- |
| 觉醒水平 | 是否处于可被唤起的清醒状态 | 睁眼、睡眠—觉醒周期、脑电去同步化 | UWS：觉醒保留而觉知内容无证据 (Laureys et al., 2010, BMC Med) |
| 觉知内容 | 是否存在可报告或可推断的主观体验 | 命令跟随、任务态激活、报告 | CMD：觉知保留而行为输出缺失 (Claassen et al., 2019, N Engl J Med) |

这一框架的临床价值在于：它把"看起来没反应"与"实际没有体验"区分成两个可独立检验的问题，从而直接改变了误诊率与预后判断 (Giacino et al., 2018, Neurology; Edlow et al., 2021, Nat Rev Neurol)。

### 2. 支撑意识状态的网络机制：整合与分化

目前被较多证据支持的工作假设是：意识状态依赖于丘脑—皮层系统**同时**具备两件事——大范围区域之间的**整合**（信息能被统一起来）与**分化**（系统能进入大量不同状态）。二者任一被破坏，意识内容都会受损 (Alkire et al., 2008, Science; Casali et al., 2013, Sci Transl Med; Koch et al., 2016, Nat Rev Neurosci)。

- **整合受破坏：** 麻醉与睡眠中，皮层对经颅磁刺激的响应从"复杂、时空扩散"退化为"局部、短促"，提示有效连接断裂 (Massimini et al., 2005, Science; Alkire et al., 2008, Science)；丙泊酚下皮层—丘脑有效连接随意识水平下降而减弱 (Mhuircheartaigh et al., 2010, J Neurosci; Hudetz, 2012, Brain Connect)。
- **分化受破坏：** 深度麻醉与 UWS 的脑电出现高频成分减少、爆发抑制或高度同步模式，可用状态空间被压缩 (Purdon et al., 2013, PNAS; Casali et al., 2013, Sci Transl Med)。
- **丘脑的门控角色：** 丘脑—皮层环路是状态切换的关键节点，但既不是唯一来源，也不能把"丘脑被激活"直接读作"有意识内容"。
- **分子起点与环路终点的距离：** 麻醉药作用于 GABA\_A、NMDA 等分子靶点，但意识消失发生在网络层面；从分子到状态的链路长、非线性，不能由靶点直接推状态 (Franks, 2008, Nat Rev Neurosci; Alkire et al., 2008, Science; Brown et al., 2010, N Engl J Med)。

### 3. 可以读什么：代理指标及其限制

| 指标 | 主要读出 | 能被什么混淆 |
| --- | --- | --- |
| 行为量表（如 CRS-R） | 可重复的行为反应水平 | 运动输出障碍、疲劳、评估者经验、单次施测不稳定 (Giacino et al., 2004, Arch Phys Med Rehabil) |
| 任务态 fMRI | 命令跟随的脑激活 | 语言理解、听觉能力、扫描可行性；阴性结果无法区分"无意识"与"未能完成" (Owen et al., 2006, Science; Monti et al., 2010, N Engl J Med) |
| 任务态 EEG | 床旁命令跟随的电生理指标 | 统计判定阈值、伪迹、小样本不稳健 (Cruse et al., 2011, Lancet; Goldfine et al., 2013, Lancet) |
| 静息态 FDG-PET／fMRI | 全脑代谢与网络连接水平 | 麻醉、镇静、代谢状态；只有相关没有因果 (Stender et al., 2014, Lancet) |
| 脑电复杂度／扰动响应（PCI） | 皮层响应的整合程度 | 需经颅磁刺激设备；个体判定阈值仍需统一 (Casali et al., 2013, Sci Transl Med; Casarotto et al., 2016, Ann Neurol) |

**一个重要的方法论修正：** 意识无法直接测量，"无反应"又常被当作"无意识"的同义词使用。直接证据是多中心的 CMD 研究——454 例中约 25% 的无命令跟随行为者存在隐匿意识，而这一比例在不同研究范式与判定标准下差异很大 (Bodien et al., 2024, N Engl J Med; Schnakers et al., 2020, Brain Sci)。**所有"测到了／没测到意识"的说法都应写成"在该指标、该阈值、该样本下检出／未检出"。**

### 4. 特殊状态：睡眠、麻醉、脑损伤

- **睡眠**：NREM 深睡中皮层有效连接断裂、报告缺失；REM 中脑电激活、报告丰富。二者说明"脑电激活程度"与"是否有体验"不能互相换算 (Massimini et al., 2005, Science; Siclari et al., 2017, Nat Neurosci)。
- **麻醉**：可逆、可控，是研究意识消失的最佳实验窗口；但"麻醉=睡眠的深度版"是错误前提，二者分子机制、脑电模式与网络靶点不同 (Franks, 2008, Nat Rev Neurosci; Brown et al., 2010, N Engl J Med; Purdon et al., 2013, PNAS)。
- **脑损伤**：昏迷（无觉醒也无觉知）→ UWS（有觉醒无觉知证据）→ MCS（出现波动但可重复的觉知证据）构成纵向轨迹，且存在 CMD 这一横切类别；具体亚类标准与量表流程另有专门节点 (Giacino et al., 2018, Neurology; Edlow et al., 2021, Nat Rev Neurol)。

### 5. 有竞争性的理论框架

| 理论 | 核心主张 | 主要检验结果 | 边界 |
| --- | --- | --- | --- |
| 全局神经元工作空间（GNWT） | 信息进入全局工作空间并被广泛广播即成为意识内容 | 对抗性合作中其"点火与持续性"预测未获明确支持 | "广播"操作化困难，预测范围宽泛 |
| 整合信息理论（IIT） | 意识对应于系统能整合的最大不可分解信息量 | 对抗性合作中其后部皮层区域特异性预测未获支持 | 核心量 Φ 在人体无法直接测量，只能以代理指标近似 |
| 高阶／预测加工类框架 | 意识内容依赖对自身表征或预测的层级加工 | 证据分散、检验方式尚不统一 | 与上述理论的判据尚未形成共同实验平台 |

(Ferrante et al., 2025, Nature; Koch et al., 2016, Nat Rev Neurosci; Bayne et al., 2024, Trends Cogn Sci)

**该对抗性合作的关键结论是"部分预测被满足、部分被明确否定"，而不是某一方获胜**；把它写成"某项理论已被证实／证伪"都属于过度解读。

## 关键研究与可重复性

| 研究链条 | 原始数据／实验设计 | 补充证据或重要不一致 | 审慎结论 |
| --- | --- | --- | --- |
| **两维度框架** | 临床综述提出"觉醒水平／觉知内容"拆分 (Laureys, 2005, Trends Cogn Sci) | 命名与框架被 UWS 共识文件更新 (Laureys et al., 2010, BMC Med)；哲学层面被质疑"水平"隐喻 (Bayne et al., 2016, Trends Cogn Sci) | 分析框架有用；不等于已证实的模块划分，也不等于单一有序刻度 |
| **睡眠中有效连接断裂** | TMS＋高密度 EEG 在 NREM 中显示皮层响应局部化 (Massimini et al., 2005, Science) | 麻醉下皮层—丘脑有效连接随意识水平下降 (Mhuircheartaigh et al., 2010, J Neurosci; Hudetz, 2012, Brain Connect) | 支持"整合受损"；均为小样本、指标间尚未统一 |
| **隐匿意识与 CMD** | 单例 fMRI 命令跟随 (Owen et al., 2006, Science) | 54 例 fMRI 队列 5 例阳性 (Monti et al., 2010, N Engl J Med)；16 例 EEG 队列 3 例阳性并遭独立重分析质疑 (Cruse et al., 2011, Lancet; Goldfine et al., 2013, Lancet)；104 例急性期 15% 阳性 (Claassen et al., 2019, N Engl J Med)；454 例多中心约 25% (Bodien et al., 2024, N Engl J Med) | 现象稳健；**检出率随范式与标准大幅变动**，不可当作固定流行病学常数 |
| **诊断工具敏感性差异** | PET 与 fMRI 在同一批患者中直接比较 (Stender et al., 2014, Lancet) | 指南据此强调重复标准化评估与工具互补 (Giacino et al., 2018, Neurology) | 单中心结果；PET 敏感性高但可及性受限，"阴性不等于无意识"成立 |
| **脑复杂度指标（PCI）** | 以 TMS-EEG 响应复杂度区分清醒、睡眠与麻醉 (Casali et al., 2013, Sci Transl Med) | 独立队列中该指标可分层无反应患者 (Casarotto et al., 2016, Ann Neurol) | 方法学有前景；个体判定阈值与设备依赖仍未统一 |
| **梦境的神经相关** | 睡眠中唤醒并采集报告，定位高频脑电变化 (Siclari et al., 2017, Nat Neurosci) | 报告依赖记忆与唤醒过程本身，存在系统性混淆 | 支持"REM 脑电激活≠清醒"；报告法固有局限 |
| **理论对抗性检验** | 预注册的对抗性合作，同时检验 GNWT 与 IIT 预测 (Ferrante et al., 2025, Nature) | 对两项理论均有预测被判不成立 | 结论是"部分预测未被支持"，不是某一理论胜出 |

**可重复性表述标准：** 跨方法、跨队列方向一致属于证据汇合，不等同于同一实验室的独立重复；综述与理论文章属于整合性观点，不能当作新一轮实证；单中心小样本的比例数字（9%、19%、15%）应明确标注样本量与判定标准，不得改写成"普遍比例"。

## 当前较稳定的认识

1. **意识状态不能被直接测量，只能通过行为、脑电与影像等代理指标间接推断；而代理指标之间可以分离。** (Laureys, 2005, Trends Cogn Sci; Sanders et al., 2012, Anesthesiology; Bayne et al., 2024, Trends Cogn Sci)
2. **"觉醒水平"与"觉知内容"可分离，这一拆分有明确临床价值。** (Laureys, 2005, Trends Cogn Sci; Laureys et al., 2010, BMC Med; Giacino et al., 2018, Neurology)
3. **无反应不等于无意识：CMD 已在多中心队列中被重复检出。** (Schiff, 2015, JAMA Neurol; Claassen et al., 2019, N Engl J Med; Bodien et al., 2024, N Engl J Med)
4. **意识内容依赖丘脑—皮层系统同时具备整合与分化能力；麻醉、睡眠与脑损伤都使这一能力下降。** (Massimini et al., 2005, Science; Alkire et al., 2008, Science; Casali et al., 2013, Sci Transl Med; Koch et al., 2016, Nat Rev Neurosci)
5. **麻醉、睡眠与昏迷都降低意识水平，但机制、脑电模式与可逆性不同，不能互相替代。** (Franks, 2008, Nat Rev Neurosci; Brown et al., 2010, N Engl J Med; Purdon et al., 2013, PNAS)
6. **现有主流理论（GNWT、IIT）的核心预测均未在对抗性合作中被完整支持，意识状态尚无被普遍接受的定量指标。** (Ferrante et al., 2025, Nature)

## 争议与推断边界

- **"意识水平"是单一有序刻度吗？** 临床与实验都倾向于使用它，但 Bayne 等（2016，Trends Cogn Sci）指出状态之间未必可单序排列，某些病理状态无法在单一刻度上定位。本页因此以"两维度＋多维"表述为主，避免"高低"式简化。
- **"阴性结果"的解释边界。** 任务态 fMRI 的阴性可来自无意识，也可来自听觉／语言通路损伤、未理解指令、扫描失败或统计阈值。**把任何阴性结果写成"证明无意识"都是越界** (Monti et al., 2010, N Engl J Med; Stender et al., 2014, Lancet)。
- **检出率不能当常数。** 9%、19%、15%、约 25% 分别来自不同人群（慢性／急性／多中心）、不同工具与不同判定标准，横向比较没有意义；单中心 EEG 结果还曾遭独立重分析质疑 (Cruse et al., 2011, Lancet; Goldfine et al., 2013, Lancet; Schnakers et al., 2020, Brain Sci)。
- **复杂度指标的理论载荷。** PCI 等指标以 IIT 类假设为出发点，用它支持 IIT 存在循环论证风险；其可用性应表述为"方法学前景"而非"理论被证实" (Casali et al., 2013, Sci Transl Med; Bayne et al., 2024, Trends Cogn Sci)。
- **对抗性合作的解读边界。** 该合作对两项理论的若干预测均给出不支持的结果，但实验设计本身受限于当时的工具与操作化方式，**不能读作"两项理论均被证伪"** (Ferrante et al., 2025, Nature)。
- **相关不等于因果。** 人类证据几乎全部是观测性配准（影像、脑电、PET），因果操纵证据主要来自动物；从动物到人的外推需要明确假设。
- **跨物种与跨状态的硬边界。** 以人类报告与临床量表建立的概念，不能不加限定地推广到动物或类器官；反之，动物模型中的"意识样"指标也不能直接定义人类意识状态 (Tsuchiya et al., 2015, Trends Cogn Sci; Bayne et al., 2024, Trends Cogn Sci)。
- **人工审核待查：** ①本节点与同目录「觉醒」「昏迷与植物状态」「麻醉状态」「快速眼动睡眠」「慢波睡眠」「静息态」「脑电微状态」存在概念邻接，需确认边界分工（本页负责"整体状态概念与测量逻辑"，具体亚类与量表流程留给专门节点）；②05 轴的「意识障碍评估」与 04 轴的「意识相关神经活动不等于意识本身」目前仍为空模板，需确认其与本节的分工；③所有双链目标须在发布前确认为 `publish: true`。
