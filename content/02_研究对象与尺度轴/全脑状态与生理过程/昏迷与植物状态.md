# 昏迷与植物状态

> **一句话定义：** 昏迷、植物状态与最小意识状态是严重脑损伤后**觉醒（arousal／wakefulness，能否醒来）与觉知（awareness，是否有体验）两个维度分离或同时丧失**的临床状态；它们之所以重要，是因为既是意识神经科学最关键的自然实验材料，也是误诊后果最严重的一类临床诊断。

## 快速理解

可以把人的清醒拆成两件事。**第一件是"醒着"**——由脑干上行网状激活系统、丘脑和皮层维持的睁眼能力与睡眠—觉醒周期。**第二件是"知道"**——对自身和世界有体验、能理解语言、能按意愿行动。

- **昏迷**：两件事都丧失。患者双眼闭合，任何刺激都不能唤醒，没有睡眠—觉醒周期，通常持续不超过数天至数周，之后要么死亡、要么转入下面几种状态之一。
- **植物状态（vegetative state, VS；现多称无反应觉醒综合征, unresponsive wakefulness syndrome, UWS）**：第一件恢复了、第二件似乎没有。患者可自发睁眼、有睡眠—觉醒周期，甚至有打哈欠、咀嚼、流泪等反射性动作，但**没有任何可被重复观察到的、有目的的行为**。
- **最小意识状态（minimally conscious state, MCS）**：出现了**不一致但可辨别**的意识行为证据，例如视物追踪、用手势或言语间断地回应命令。它说明觉知"有一点"，但极不稳定。

最容易被误解的一点是：**这些诊断至今仍以行为为金标准**。而行为输出受运动功能、注意力波动、镇静药物、疼痛、感觉缺损和疲劳的强烈影响。自 2006 年起，功能磁共振与脑电研究发现，一部分**完全无行为反应**的患者仍能按指令主动调控自己的脑活动——这一现象现在被称为**认知运动分离（cognitive motor dissociation, CMD）**，也常被通俗地称作"隐匿意识" (Schiff, 2015, JAMA Neurol)。它同时改写了预后判断、临床伦理和沟通的可能性。

本节点描述的是科学上如何界定与测量这些状态，**不是临床诊断或预后工具**。任何具体患者必须由专业团队结合标准化量表、影像与电生理综合判断。

## 概念界定与边界

**术语的历史。** "持续性植物状态"（persistent vegetative state）由 Jennett 与 Plum 于 1972 年提出，用来描述严重脑损伤后**自主功能与觉醒恢复、但高级功能永久缺失**的一类患者；两位作者在文中明确表示，创造这个名称是为了描述一种"尚待命名"的综合征，而非做出价值判断 (Jennett & Plum, 1972, Lancet)。1994 年，美国多个学会组成的专门工作组给出了当时通用的诊断标准与预后框架 (Multi-Society Task Force on PVS, 1994, N Engl J Med)。

2002 年，最小意识状态被正式定义并给出诊断标准，用来涵盖那些有明确但不稳定意识迹象的患者 (Giacino et al., 2002, Neurology)。2010 年，Laureys 等提出以"无反应觉醒综合征"取代"植物状态"，理由是后者在公众语境中已带有贬义并常被误解为"植物人"，且新名称更准确地描述了行为特征 (Laureys et al., 2010, BMC Med)。**本节点保留"植物状态"作为历史与检索用词，正文优先使用 UWS。**

**必须区分的相邻状态。**

- **脑死亡（brain death）**：全脑（含脑干）功能不可逆丧失，是**死亡的判定**，不是意识障碍的一个等级；其判定遵循独立的操作规程 (Wijdicks et al., 2010, Neurology; Greer et al., 2024, Neurology)。把脑死亡与昏迷、UWS 混为一谈是最严重的临床混淆之一。
- **闭锁综合征（locked-in syndrome）**：患者**觉知完整**，但因脑干腹侧损害而几乎完全失去随意运动，仅保留垂直眼动或眼睑运动。它是 UWS 最重要的鉴别诊断，因为两者的外部表现可高度相似，而内在体验截然相反。
- **认知运动分离（CMD）**：不是与 UWS 并列的第四个等级，而是**在行为学诊断为 UWS 或 MCS 的患者中，用影像或脑电检出命令跟随反应**的一个附加描述层。
- **谵妄、镇静、癫痫后状态、失语与严重执行功能障碍**：都可在床旁造成"看起来没有反应"的假象，是误诊的主要来源。

**适用对象。** 本节点主要讨论**获得性脑损伤后**（创伤性脑损伤、缺氧缺血性脑损伤、脑卒中）的成人意识障碍。先天性或神经发育性因素导致的意识改变、以及神经退行性疾病晚期的意识改变，机制与判定标准不完全相同，不在此处展开。

## 结构与机制（适用时）

**觉醒侧的解剖基础。** 维持觉醒依赖脑干被盖的上行网状激活系统、下丘脑与基底前脑，以及丘脑板内核与中央中核—束旁核复合体向皮层的广泛投射。这一通路的完整性决定了患者能否睁眼、能否有睡眠—觉醒周期。

**觉知侧的环路假设。** 目前影响力最大的两类假设是：以**丘脑—皮层与额顶网络的有效连接**为核心的"中枢丘脑假说"，以及强调**全局信息广播**（全局神经工作空间）与**信息整合**的理论取向 (Giacino et al., 2014, Nat Rev Neurol)。它们的共同预测是：仅有局部皮层活动不足以产生觉知，还需要跨脑区的长程整合。

**支持性证据。** Laureys 等用 PET 观察到，植物状态患者全脑代谢降至正常的 40%–50%，且与正常对照相比，广泛皮层区域之间的**有效连接显著受损** (Laureys et al., 1999, NeuroImage)。Vanhaudenhuyse 等进一步显示，默认网络内部（尤其是后扣带／楔前叶）的连接强度随意识水平下降而递减，从健康对照到闭锁综合征、MCS、UWS 呈单调梯度 (Vanhaudenhuyse et al., 2010, Brain)。Edlow 等结合超高场 ex vivo MRI 与尸检，刻画了缺氧缺血性脑损伤后皮层、丘脑与脑干的损伤模式，并强调现有的活体影像对**脑干微小病灶**的检出能力仍有限 (Edlow et al., 2021, Nat Rev Neurol)。

**干预性证据。** Schiff 等报告，对一名处于 MCS 长达 6 年的创伤性脑损伤患者实施双侧**中央丘脑深部脑刺激**后，其行为反应性与功能沟通得到改善；这是一例**开放性、单病例**研究，证据强度有限，但它是"调控特定环路可改善意识行为"这一假设的关键原理验证 (Schiff et al., 2007, Nature)，后续的权威综述把它作为"中枢丘脑假说"的直接检验来讨论 (Giacino et al., 2014, Nat Rev Neurol; Edlow et al., 2021, Nat Rev Neurol)。

**需要强调的因果边界。** 上述代谢与连接异常绝大多数是**相关性**描述。除少数开放标签或单病例的刺激研究外，人类研究基本无法把"某条通路受损"确立为"意识丧失的原因"。动物实验可提供机制细节，但从啮齿类到人类的外推在意识这一议题上尤其脆弱，本节点不把动物结论作为对人的既定结论。

## 关键研究与可重复性

**一、行为学诊断工具与其可靠性。** 目前国际通用的床旁工具是**昏迷恢复量表修订版（Coma Recovery Scale-Revised, CRS-R）**，包含听觉、视觉、运动、言语—视觉、交流与唤醒六个分量表 (Giacino et al., 2004, Arch Phys Med Rehabil)。它之所以关键，是因为后续所有研究的分期都依赖它。

Schnakers 等对 44 名临床诊断为植物状态的患者重新使用 CRS-R 评估，发现其中 \*\*18 名（41%）\*\*实际上具备符合 MCS 的行为能力——这是"临床印象"与"标准化评估"之间差距最常被引用的定量证据 (Schnakers et al., 2009, BMC Neurol)。这类研究支持一个稳健结论：**单次床旁印象不足以分期，必须重复、标准化评估**。

疼痛评估方面，Schnakers 等开发了**伤害感受昏迷量表（Nociception Coma Scale, NCS）**，并报告其在区分不同意识水平患者对伤害性刺激的反应上具备可接受的心理测量学特性 (Schnakers et al., 2010, Pain)。

**二、影像与脑电检出的"隐匿意识"。** Owen 等报告，一名被诊断为植物状态的患者在 fMRI 中被要求想象打网球或在家中走动时，产生了与 **5 名健康对照高度相似**的、具有任务特异性的脑激活 (Owen et al., 2006, Science)。这是"行为无反应但存在意志性脑活动"的第一个标志性证据，但**只有 1 名患者**。

Monti 等把同一范式用于 54 名患者，其中 **5 名（9%）**能通过想象特定动作来回答问题；他们同时报告了方法学上的困难：患者**无法完成任务**（而非没有反应）的情况无法与真正的无意识区分 (Monti et al., 2010, N Engl J Med)。Cruse 等把范式搬到床旁脑电，在 16 名植物状态患者中检出 **3 名（19%）**具备可靠的命令跟随反应——这一结果的重要性在于它**不依赖 fMRI 设备**，使隐匿意识检测具备了可扩展性 (Cruse et al., 2011, Lancet)。

**三、限定性与负结果。** 这是本节点最需要读者注意的部分。

Goldfine 等对上述床旁脑电研究（Cruse 等）的原始数据做了**独立重分析**，结论认为在更严格的统计标准下，部分患者的反应证据**并不稳健**，并据此提出需要预先登记的分析流程与更保守的统计阈值 (Goldfine et al., 2013, Lancet)。

Stender 等做了一项**前瞻性临床验证研究**，直接比较 FDG-PET、任务态 fMRI 与 EEG：FDG-PET 识别 MCS 的敏感性约为 **93%**，而任务态 fMRI 的敏感性仅约 **45%** (Stender et al., 2014, Lancet)。这是一个决定性的限定性结果——**fMRI 命令跟随阴性绝不等于无意识**，因为敏感性本身就很低。

**四、认知运动分离的流行病学。** Claassen 等用脑电在 104 名无行为反应的患者中检出 **16 名（15%）**存在命令跟随的脑反应，并证明这种检出与 12 个月后的功能恢复相关 (Claassen et al., 2019, N Engl J Med)。Bodien 等在 **6 个中心、353 名**患者中报告，在无命令跟随行为的 241 名患者中约 **25%** 存在 CMD，且 CMD 的检出率随损伤时间与病因变化 (Bodien et al., 2024, N Engl J Med)。后者是目前样本量最大、多中心的一次估计，但作者明确指出了**转诊与入组偏倚**的限制。Schnakers 等的一项元分析汇总了多项隐匿认知研究，指出检出率随任务范式与判定标准差异很大 (Schnakers et al., 2020, Brain Sci)。

**五、临床指南与药物证据。** 美国神经病学会 2018 年的指南更新基于系统综述给出诊断与预后建议：建议使用 CRS-R 等经过验证的量表、要求重复评估、并明确告知家属**现有证据不足以支持对多数个体做出确定性预后判断** (Giacino et al., 2018, Neurology)。在药物方面，一项多中心**安慰剂对照随机试验**报告，金刚烷胺在创伤后 4–16 周加速了功能恢复，但在 6 个月时两组差异**不再显著** (Giacino et al., 2012, N Engl J Med)。这一"加速而非提高最终恢复水平"的模式，是理解 DoC 药物证据的典型范例。

**六、可重复性状况。** 本领域的证据结构与多数神经科学领域不同：**不存在可做大样本随机化的"实验"，患者异质性极高，许多关键结论来自小样本队列**。因此"重复"在这里主要指跨中心、跨方法（PET／fMRI／EEG）的一致趋势，而非同一协议的直接复制。上述 CMD 比例从 15% 到 25% 的差异，正反映了入组标准与方法的依赖性，而非互相矛盾。

## 当前较稳定的认识

1. **觉醒与觉知是可分离的两个维度**，UWS 的本质是"有觉醒、无觉知（的证据）"，这不是语义游戏，而是诊断与预后判断的支点 (Jennett & Plum, 1972, Lancet; Giacino et al., 2002, Neurology)。
2. **单次床旁印象的误诊率高**，重复、标准化的 CRS-R 评估能显著改变分期结论 (Schnakers et al., 2009, BMC Neurol; Giacino et al., 2018, Neurology)。
3. **一部分行为无反应的患者存在意志性脑活动（CMD）**，这一现象已被 EEG 与 fMRI 在多中心研究中反复检出 (Cruse et al., 2011, Lancet; Claassen et al., 2019, N Engl J Med; Bodien et al., 2024, N Engl J Med)。
4. **检测手段的敏感性差异极大**：FDG-PET 远高于任务态 fMRI，因此**阴性结果不能被当作"无意识"的证据** (Stender et al., 2014, Lancet)。
5. **UWS 患者全脑代谢显著下降，且皮层间有效连接与默认网络连接随意识水平递减**，这是跨方法一致的观察 (Laureys et al., 1999, NeuroImage; Vanhaudenhuyse et al., 2010, Brain)。
6. **尚无任何药物或刺激手段被证明能提高最终恢复水平**；现有阳性结果多为加速恢复或单病例观察 (Giacino et al., 2012, N Engl J Med; Schiff et al., 2007, Nature)。

## 争议与推断边界

**隐匿意识究竟意味着什么。** 最核心的争议在于**推断跨度**：从"患者能按指令想象打网球"到"患者有丰富的主观体验、能理解语言、有意愿"，中间有相当大的解释距离。批评者指出，任务态激活可能来自被保留的语义或运动程序加工，而未必伴随现象意识；而且**检出 CMD 的患者比例随方法、阈值、入组标准变动很大**。本节点采取的表述是：CMD 证明了**意志性脑活动**的存在，但**不能直接等同于"正常的内在体验"**。

**统计与方法学脆弱性。** Goldfine 等的重分析表明，早期标志性结果对统计校正方式敏感 (Goldfine et al., 2013, Lancet)。这提示：**在个体水平上用 fMRI 或 EEG 判断意识状态，目前的假阳性与假阴性率都不足以支撑确定性结论**。Stender 等的低敏感性数据则从另一端限制了解释 (Stender et al., 2014, Lancet)。

**样本量与外推限制。** Owen 等的研究只有 1 名患者 (Owen et al., 2006, Science)；Schiff 等的中枢丘脑刺激研究同样是单病例开放干预 (Schiff et al., 2007, Nature)。从这些研究得出"意识可以被电刺激恢复"的结论属于**明显超出证据的推断**。此外，不同病因（创伤性 vs 缺氧缺血性）的恢复轨迹差异显著，**把创伤性脑损伤的预后数据外推到缺氧后损伤是常见错误**。

**术语与伦理争议。** "植物状态"一词的去污名化尚未结束；不同国家、不同临床团队对 UWS 与 MCS 的操作性定义仍存在细节分歧 (Laureys et al., 2010, BMC Med)。更重要的是，CMD 的检出对**预后沟通、治疗决策与生命维持决策**构成直接冲击，而这些决策还依赖患者事前意愿、家属理解与法律框架，科学证据只是其中一维。

**尚未解决的问题。**

- CMD 的长期轨迹如何？能否转化为稳定的行为沟通？
- 是否存在**可靠的床旁、低成本、高敏感性**的隐匿意识筛查方案？
- 意识障碍的异质性应当如何细分（病因 × 损伤模式 × 时间），而不是停留在 UWS／MCS 二分？
- 中枢丘脑刺激等侵入性干预的**疗效**是否能在随机对照设计中被证实？
- 脑机接口辅助沟通在无行为反应患者中的成功率与适用边界？
