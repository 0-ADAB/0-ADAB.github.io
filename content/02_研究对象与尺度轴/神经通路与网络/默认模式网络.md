# 默认模式网络

> **一句话定义：** 默认模式网络（default mode network, DMN）是由后扣带皮层/楔前叶、内侧前额叶、角回及部分颞叶等分布式脑区组成、具有协调活动特征的大尺度**功能网络**；它最初因多种外部注意任务相对静息基线的活动下降而受到关注，后来被证明还参与记忆、情境模拟、社会认知以及部分主动任务中的信息整合。(Shulman et al., 1997, J Cogn Neurosci; Raichle et al., 2001, PNAS; Buckner et al., 2008, Ann N Y Acad Sci; Sormaz et al., 2018, PNAS)

## 快速理解

初学者可以从两个现象理解 DMN：

**第一，在不执行实验者指定的外部任务时，大脑并非“停止运转”。** 某些内侧前额叶与后内侧皮层区域在安静基线下保持显著的代谢与功能活动，在很多需要持续感知、注意和操作的任务中反而相对下降。这是 DMN 名称的历史由来，不表示这些区域只在休息时才工作。(Shulman et al., 1997, J Cogn Neurosci; Raichle et al., 2001, PNAS; Raichle, 2015, Annu Rev Neurosci)

**第二，它并非一个“空闲开关”，而是一组能够参与不同计算的网络。** 当人回顾往事、设想未来、思考他人意图，或在观看电影时整合跨越较长时间的信息，DMN 的不同部分都可能参与；部分目标导向任务还会招募 DMN 与额顶控制网络协同活动。(Schacter et al., 2007, Nat Rev Neurosci; Spreng et al., 2010, NeuroImage; Simony et al., 2016, Nat Commun; Chen et al., 2017, Nat Neurosci)

**一个直观比喻：** 如果外部注意网络偏重“眼前发生了什么、下一步该做什么”，DMN 的某些子系统更常参与“这些信息与过去经历、个人情境和对他人的理解有什么关系”。这只是帮助记忆的**功能倾向**，不是大脑的硬性分工，更不意味着 DMN 总与注意或执行控制网络竞争。(Andrews-Hanna et al., 2014, Ann N Y Acad Sci; Dixon et al., 2018, PNAS)

需要同时避免三个误区：

- **静息 ≠ 无思维。** 静息态扫描通常只说明没有强制执行某种实验任务，不代表受试者意识内容为空；困倦、内在思维、头动也可能影响测得的连接。(Raichle, 2015, Annu Rev Neurosci; Power et al., 2017, NeuroImage)
- **DMN 活跃 ≠ 一定在走神。** 自我相关、情景记忆、心理理论和叙事理解可以具有不同的行为目标及神经配置。(Christoff et al., 2016, Nat Rev Neurosci; DiNicola et al., 2020, J Neurophysiol)
- **两个脑区的 fMRI 信号同步 ≠ 存在直接轴突连接。** 功能连接是统计关联，可以受共同驱动、血流动力学及预处理影响。(Greicius et al., 2003, PNAS; Murphy et al., 2009, NeuroImage)

## 概念界定与边界

### 1. 研究对象是什么

**DMN 首先是网络层次的概念，不是单一脑区、递质、细胞类型或某条定向神经束。** 常见操作性界定来自以下几类证据：

| 证据或术语 | 实际定义 | 能支持的结论和边界 |
| --- | --- | --- |
| 任务诱发相对活动下降（task-induced deactivation） | PET 或 fMRI 中，某区域在某任务条件下的信号低于选定基线 | 支持任务—基线相对差异；不能推断该区域绝对不工作。 |
| 静息态功能连接（resting-state functional connectivity） | 未执行指定任务或维持注视时，区域间 BOLD 时间序列的统计相关性 | 支持共同波动与网络归属；不能替代神经纤维示踪。 |
| 网络分区（parcellation） | 基于连接相似度或空间边界，给皮层顶点、体素或区域赋予网络标签 | 便于重复研究；结果依赖算法、分辨率、数据量与个体。 |
| 有效连接 / 方向性建模（effective connectivity） | 依模型假设估计区域间的定向影响 | 可形成信息流假设；不等于证明特定单突触线路。 |
| 任务态功能参与 | 在记忆、心理理论、叙事或计划任务中观察到 DMN 节点/子网络活动 | 支持特定任务中参与；相关激活本身通常不足以证明行为必要性。 |

前三类的经典依据分别来自相对基线 PET、静息相关分析和群体分区；近期多模态工作还显示，细胞构筑和估计的信号流在 DMN 内部显著不均一。(Raichle et al., 2001, PNAS; Greicius et al., 2003, PNAS; Yeo et al., 2011, J Neurophysiol; Schaefer et al., 2018, Cereb Cortex; Paquola et al., 2025, Nat Neurosci)

### 2. 与相邻网络或名称的区别

- **静息态网络（resting-state networks, RSNs）** 是总体类别；DMN 是其中一个常见大尺度网络，不是所有静息相关网络的总称。显著性网络、背侧注意网络和额顶控制网络可以在相同数据中被区分。(Seeley et al., 2007, J Neurosci; Yeo et al., 2011, J Neurophysiol)
- **“任务负网络”（task-negative network）** 强调相对于特定外部任务基线的活动下降，不能当作 DMN 在所有任务中固定负激活的同义词。自传体计划、真实叙事和主动体验中仍可看到 DMN 参与。(Spreng et al., 2010, NeuroImage; Sormaz et al., 2018, PNAS; Simony et al., 2016, Nat Commun)
- **“自传体记忆网络”“心理理论网络”** 与 DMN 的部分区域或子网相互重叠，但不能视作完全同一空间集合；高精度个体研究支持部分共享、部分分化。(DiNicola et al., 2020, J Neurophysiol; Hughes et al., 2024, J Neurophysiol)
- **“默认”不意味着神经活动弱、能量消耗低或只有内心独白。** 此词源自有组织的基线功能和相对任务下降的发现史，而非一个全能心理机制标签。(Gusnard et al., 2001, PNAS; Raichle, 2015, Annu Rev Neurosci)

### 3. 物种与空间边界

最系统的皮层网络分区和个体精密映射证据来自人类影像；麻醉猴研究能检验部分内在网络跨物种的相似性，但**相似的静息耦合不代表细胞同源、同一认知功能或完全相同的解剖边界**。(Vincent et al., 2007, Nature; Buckner et al., 2008, Ann N Y Acad Sci)

群体平均 DMN 图谱中某些被涂成同色的区域，在个体高密度扫描里可能分属毗邻、交错的两个网络；海马形成的关联尤其可能在默认网络子网之间有差异。(Laumann et al., 2015, Neuron; Braga & Buckner, 2017, Neuron; Gordon et al., 2017, Neuron)

## 结构与机制（适用时）

### 1. 典型组成与枢纽

| 常见区域（非穷尽） | 在 DMN 文献中的作用或位置 | 必须保留的限定 |
| --- | --- | --- |
| 后扣带皮层（PCC）及邻近楔前叶 | 后中线网络枢纽，常被用作 DMN 种子或核心区 | PCC 背腹侧功能与连接不同；不能把 PCC 活动代表全 DMN。 |
| 前内侧前额叶（aMPFC）/腹内侧前额叶（vmPFC） | 中线核心或自我相关/价值与情境评估的一部分 | 不同任务与图谱对边界有不同界定。 |
| 背内侧前额叶（dmPFC） | 常与社会认知、心理理论相关的子系统重叠 | dmPFC 并非全部 DMN 子网共有节点。 |
| 外侧顶叶/角回（angular gyrus） | 与语义、情景和情境整合相关的分布式节点 | 角回及邻近顶叶区域的网络归属具有细分与个体差异。 |
| 外侧颞叶及颞顶交界（TPJ）附近区域 | 在部分 DMN/社会认知子系统中出现 | 不能将所有 TPJ 或外侧颞叶均归入同一 DMN。 |
| 内侧颞叶系统（海马形成、海马旁皮层）与压后皮层（RSC） | 对部分以记忆为核心的 DMN 子系统提供关联 | 不是每种群体分区都把整个海马无差别划为 DMN 核心。 |

这些区域名称和分工是**常见影像网络框架下的操作性归纳**，而不是一张已确定的跨物种连接线路图。(Buckner et al., 2008, Ann N Y Acad Sci; Andrews-Hanna et al., 2010, Neuron; Leech et al., 2011, J Neurosci; Leech & Sharp, 2014, Brain; DiNicola et al., 2020, J Neurophysiol)

### 2. 子系统：经典核心模型与精细个体网络

经典功能—解剖模型提出：围绕前内侧前额叶与后扣带/楔前叶的**核心区域**，有两个具有相对不同任务偏好的子系统：

1. **内侧颞叶子系统（MTL subsystem）**：与情景记忆、过去经验的重组、未来事件想象等任务有关，涉及海马形成、海马旁和压后等区域；
2. **背内侧前额叶子系统（dmPFC subsystem）**：与关于他人、社会情境及心智状态的推断等过程更相关，涉及 dmPFC、颞顶交界/外侧颞叶附近区域。

两者有相互作用，也存在任务交叉；该划分是重要**研究框架**，并非“每个区域只属于一个子系统”的解剖定理。(Buckner et al., 2008, Ann N Y Acad Sci; Andrews-Hanna et al., 2010, Neuron; Andrews-Hanna et al., 2014, Ann N Y Acad Sci)

更高精度的个体化功能连接分析发现，群体 DMN 范围可能包含彼此紧邻、空间交错的平行网络；部分网络与海马形成有较强耦合，另一部分则不明显。后续个体任务研究支持情景投射和心理理论偏好在不同子网间分化，但仍可以在同一研究中呈现共享活动。(Braga & Buckner, 2017, Neuron; DiNicola et al., 2020, J Neurophysiol; Hughes et al., 2024, J Neurophysiol)

2025 年的一项多模态研究将死后细胞构筑学、活体结构扩散 MRI 与有效连接模型结合，发现 DMN 各节点所处的感觉—跨模态层级位置不同：一些区域更可接收感官输入，某些核心区域相对远离直接环境输入。这为“为什么 DMN 能兼容外部信息与内部建模”提供**组织学与模型层面的线索**，但模型估计的信号方向不等于已观察到细胞级突触因果。(Paquola et al., 2025, Nat Neurosci)

### 3. 与其他网络的动态关系

最早一批研究将 DMN 与部分外部注意网络描述为在静息态功能连接上呈反相关的系统。后来研究发现，全局信号回归（global signal regression, GSR）本身可以引入或强化负相关，故**反相关既不能被无条件视为生理对抗，也不能简单断言所有负相关都是伪影**。报告结果时必须说明去噪、基线与分析选择。(Fox et al., 2005, PNAS; Murphy et al., 2009, NeuroImage; Power et al., 2017, NeuroImage)

DMN、额顶控制网络（FPN）和显著性网络（SN）常被放在一起研究。三网络模型是组织脑功能与精神病理的常用框架，但不是一个经过解剖示踪证实、由一个开关统一调度所有认知任务的硬件线路。(Seeley et al., 2007, J Neurosci; Menon, 2011, Trends Cogn Sci)

在自传体计划等任务中，DMN 与额顶控制网络可以共同参与目标导向加工；额顶控制网络自身也存在可能更偏向 DMN 或背侧注意网络的分部。因此“执行网络与默认网络必然彼此排斥”是不准确的。(Spreng et al., 2010, NeuroImage; Dixon et al., 2018, PNAS)

连接梯度分析还将 DMN 定位于远离初级感觉—运动系统的皮层联络端，提示它可能参与跨较长时间、较高抽象层级的整合；这是一种**组织原则的统计表征**，不能简单赋予各梯度端点唯一心理标签。(Margulies et al., 2016, PNAS)

### 4. 不只“内部思维”：记忆、社会认知和真实世界信息

**情景记忆与未来模拟。** 过去经历的重组和未来情境想象共享一部分神经系统；部分 DMN 子网与海马形成的联系，为跨事件的情境模型提供可能机制。但“共享脑区”本身不足以证明 DMN 中每个节点对情景记忆都是必要的。(Schacter et al., 2007, Nat Rev Neurosci; Buckner et al., 2008, Ann N Y Acad Sci; DiNicola et al., 2020, J Neurophysiol)

**自我相关加工与自发思维。** 内侧前额叶的自我相关活动提供了早期机制线索；后续综述认为，走神、自我反省、情节想象和自主规划并不是一种单一“内部思维”事件，不宜用单一 DMN 活跃度衡量“自我感”或创造力。(Gusnard et al., 2001, PNAS; Andrews-Hanna et al., 2014, Ann N Y Acad Sci; Christoff et al., 2016, Nat Rev Neurosci)

**心理理论与社会认知。** 一些默认网络子系统参与推测他人的信念、意图或体验。高精度功能图谱在自传体记忆和心理理论范式之间观察到共享与偏好分化，提示“以自己的经验理解他人”并非唯一或足以解释全部社会认知的神经机制。(DiNicola et al., 2020, J Neurophysiol; Hughes et al., 2024, J Neurophysiol)

**持续叙事与现实事件。** 观看或聆听长篇叙事时，DMN 内的刺激相关协调模式可随故事推进重组；观影后的自由回忆还能在 DMN 与内侧颞叶等区域再现事件相关活动模式。证据对象是高阶、自然情境下的表征，并不是 DMN 独占感知或所有听觉加工。(Simony et al., 2016, Nat Commun; Chen et al., 2017, Nat Neurosci)

**主动任务状态。** 研究观察到 DMN 某些部分的活动随任务执行期间主观体验的细节而变化；静息影像的个体特征也可预测部分任务激活差异。2025 年发表的精密映射工作进一步证明，在合适的任务回归与分析条件下，任务数据也能重建与静息相近的个体网络结构。不能再把“在静息中识别到网络”误解为“网络只存在于静息状态”。(Sormaz et al., 2018, PNAS; Tavor et al., 2016, Science; Du et al., 2025, Neuron)

### 5. 发育、睡眠与跨物种状态

儿童—成人比较显示 DMN 的区域间网络结构随发育呈现更明显的整合变化，但这首先是年龄相关差异而不是对所有个体发展轨迹的直接跟踪。(Fair et al., 2008, PNAS)

2026 年儿童与青少年精细功能映射进一步报告，DMN 子网分隔和边界清晰程度随年龄变化，某些记忆相关子网的空间特征与情景记忆表现相关。该证据具有发育研究价值，但目前不足以定义统一的儿童个体预后阈值。(He et al., 2026, Dev Cogn Neurosci)

睡眠中仍可研究默认网络相关活动，但深睡眠时部分跨区功能连接会减弱；麻醉猴仍能检测内在网络的部分组织。这表明静息网络与清醒、睡眠、麻醉不构成“一开一关”的关系，且功能耦合存在状态依赖。(Horovitz et al., 2009, PNAS; Vincent et al., 2007, Nature)

### 6. 疾病研究中的位置

阿尔茨海默病、重性抑郁障碍和创伤性脑损伤研究都报告过 DMN 或相关跨网络连接的群体差异。抑郁障碍的元分析提示，在部分区域和网络之间的异常连接呈现可汇合模式，但方向、分布与个体差异复杂，不能总结成“抑郁就是默认模式网络过强”。(Greicius et al., 2004, PNAS; Sheline et al., 2010, PNAS; Kaiser et al., 2015, JAMA Psychiatry; Bonnelle et al., 2011, J Neurosci)

精神病理的 DMN 文献具有跨疾病关联的启发性，但许多论文仍是病例对照、横断连接或与症状评分的统计关系；它们不能单独说明 DMN 改变是疾病原因、结果、代偿或药物效应。(Whitfield-Gabrieli & Ford, 2012, Annu Rev Clin Psychol; Menon, 2011, Trends Cogn Sci)

## 关键研究与可重复性

### 从发现到结构分化的证据链

1. **活动下降的跨任务观察**：1997 年多项 PET 任务再分析报告一组重复出现的相对下降区；2001 年的代谢与任务比较研究把这种现象解释为大脑具有有组织的基线活动，而不是“基线比任务更激活”这一简单说法。(Shulman et al., 1997, J Cogn Neurosci; Raichle et al., 2001, PNAS; Gusnard et al., 2001, PNAS)
2. **静息网络识别的测量扩展**：2003 年使用静息态时间序列的连接分析，支持此前基于任务下降定义的网络可以通过内在活动识别。该跨方法一致性支持“存在功能组织”，却没有给出单突触接线图。(Greicius et al., 2003, PNAS; Raichle, 2015, Annu Rev Neurosci)
3. **子系统结构的独立补充**：2010 年的功能—解剖划分与之后的 PCC 内部细分、群体网络分区、个体高密度连接研究共同指向**网络内异质性**。这些研究研究对象与算法不同，是收敛证据而不是同一个边界图的完全一致复制。(Andrews-Hanna et al., 2010, Neuron; Leech et al., 2011, J Neurosci; Yeo et al., 2011, J Neurophysiol; Gordon et al., 2017, Neuron)
4. **跨任务与自然情境收敛**：自传体计划、叙事理解、事件回忆和体验采样研究证明，DMN 参与外部输入和内部情境整合的多种条件；所用行为范式不相同，不能据此设立“万能内省效应量”。(Spreng et al., 2010, NeuroImage; Simony et al., 2016, Nat Commun; Chen et al., 2017, Nat Neurosci; Sormaz et al., 2018, PNAS)
5. **个体网络地图的精化与交叉验证**：密集扫描揭示群体平均遗漏的网络间交错；功能任务检查对应不同子网的情景与社会认知偏好；2024 年大型个体化概率图谱进一步量化人际空间变异。这构成跨队列/方法的相互补充，不意味着人人具有完全同位置的 DMN 亚区。(Laumann et al., 2015, Neuron; Braga & Buckner, 2017, Neuron; DiNicola et al., 2020, J Neurophysiol; Hermosillo et al., 2024, Nat Neurosci)
6. **结构与动态的较新证据**：2025 年细胞构筑/连接建模研究和任务数据精密映射推进了“网络组织不依赖单一静息条件”的认识；2026 年的发育研究显示 DMN 子网络边界不是从儿童期起就固定不变。它们是**近年重要增量**，但不能冒充已多次独立因果复制。(Paquola et al., 2025, Nat Neurosci; Du et al., 2025, Neuron; He et al., 2026, Dev Cogn Neurosci)

**建议的重复性报告项目**包括：扫描仪与场强、静息指令（睁眼/闭眼/注视）、记录的清醒与困倦状态、头动指标、呼吸与心动处理、GSR 选择及有/无 GSR 的敏感性结果、预处理和剔除标准、脑区空间分区、扫描长度、网络/子网定义、独立数据集复核，以及是否报告外部样本的预测表现。(Power et al., 2012, NeuroImage; Birn et al., 2013, NeuroImage; Noble et al., 2019, NeuroImage; Marek et al., 2022, Nature)

**可重复性的关键区分：**

- 多中心识别“中线额顶网络拓扑”相对稳健，**不代表每一条体素间连接都达到临床个体预测所需的重测可靠性**。(Yeo et al., 2011, J Neurophysiol; Noble et al., 2019, NeuroImage)
- 在相同预处理下得到负相关可以被再现，**不等于其生理含义独立于预处理选择**。(Fox et al., 2005, PNAS; Murphy et al., 2009, NeuroImage)
- 抑郁、认知损伤等组间差异需要区分**原始观察、跨研究元分析与临床效能验证**；前两种不自动导出第三种。(Greicius et al., 2004, PNAS; Kaiser et al., 2015, JAMA Psychiatry; Whitfield-Gabrieli & Ford, 2012, Annu Rev Clin Psychol)

本文整理代表性研究，没有依照系统综述检索流程对全部 DMN 文献进行穷尽汇总，因而**不计算统一的“DMN 重复成功率”、所有任务的平均效应量或个人诊断准确率**。

## 当前较稳定的认识

1. **DMN 是可跨任务基线、静息连接与多种网络分区观察到的大尺度功能组织。** 其常见枢纽位于内侧前额叶、后扣带/楔前叶和外侧顶叶，但不等于一条直接纤维束。(Raichle et al., 2001, PNAS; Greicius et al., 2003, PNAS; Yeo et al., 2011, J Neurophysiol)
2. **DMN 有可分化的子系统和显著个体差异。** 不同子网可能与情景记忆、社会认知及海马形成有不同关系，不能只用整网平均值表征全部功能。(Andrews-Hanna et al., 2010, Neuron; Braga & Buckner, 2017, Neuron; Hughes et al., 2024, J Neurophysiol)
3. **DMN 不是被动“休息网络”。** 自传体计划、社会推断、叙事理解和事件回忆等任务可以使用网络中不同部分；它还能与控制系统协作。(Spreng et al., 2010, NeuroImage; Simony et al., 2016, Nat Commun; Chen et al., 2017, Nat Neurosci)
4. **网络估计依赖采集条件与计算方法。** 静息态相关不能直接证明结构连接、信息流方向或行为因果；头动、GSR、扫描时间与个体映射决定结果的可比较程度。(Murphy et al., 2009, NeuroImage; Power et al., 2012, NeuroImage; Gordon et al., 2017, Neuron)
5. **发展阶段和脑状态改变功能组织。** 成年、儿童、深睡眠和麻醉条件下的内在耦合具有部分共同点，也存在显著差别。(Fair et al., 2008, PNAS; Horovitz et al., 2009, PNAS; He et al., 2026, Dev Cogn Neurosci)
6. **若干疾病群体观察到 DMN 连接差异，但临床解释仍有限。** 当前此类证据更适于机制研究和群体层面的假说检验，而非仅靠 DMN 指标作个人诊断。(Greicius et al., 2004, PNAS; Kaiser et al., 2015, JAMA Psychiatry; Marek et al., 2022, Nature)

## 争议与推断边界

### 1. DMN 究竟有没有“唯一主要功能”？

不同模型强调基线活动、自我相关加工、情景记忆、心理模拟、社会认知、情境整合和长期尺度的信息整合。它们部分兼容，但**不能仅凭同一网络在多个任务中活跃，就证明其执行同一种独一无二的心理运算**。子网络差异和任务范式选择会进一步改变结论。(Buckner et al., 2008, Ann N Y Acad Sci; Andrews-Hanna et al., 2014, Ann N Y Acad Sci; DiNicola et al., 2020, J Neurophysiol; Paquola et al., 2025, Nat Neurosci)

### 2. DMN 是否必然在注意与复杂任务中被压制？

不是。许多高度外部注意任务确实观察到相对下降，然而主动的自传体计划、自然叙事理解及包含丰富细节的任务态体验均可牵涉 DMN。必须明示**所比较的任务和基线**，否则“激活/去激活”没有统一含义。(Shulman et al., 1997, J Cogn Neurosci; Spreng et al., 2010, NeuroImage; Sormaz et al., 2018, PNAS)

### 3. “DMN—注意网络反相关”是否等于强制竞争？

不能。反相关的强弱与是否出现可受 GSR、去噪、状态及网络内部异质性影响，而且额顶控制网络的某些子部分可以与 DMN 合作。不能把静息态负相关系数直接写成“互相抑制的突触回路”。(Fox et al., 2005, PNAS; Murphy et al., 2009, NeuroImage; Dixon et al., 2018, PNAS)

### 4. 采用哪种图谱才能定义“真正的 DMN”？

没有跨所有尺度、物种和个体的单一金标准。七网络、十七网络、细粒度皮层分区、个体精密映射、细胞构筑和连续梯度分别回答不同问题。某些高精度地图发现两个邻接网络在群体分析中融合；是否称为 DMN 的一个或两个子网，部分取决于分区和命名规则。(Yeo et al., 2011, J Neurophysiol; Schaefer et al., 2018, Cereb Cortex; Margulies et al., 2016, PNAS; Hermosillo et al., 2024, Nat Neurosci)

### 5. 可以把 DMN 活动读成“自我意识/走神指数”吗？

不能。静息态 BOLD 波动混合神经、血流及生理相关过程；单一网络统计量无法无歧义地推断正在回忆、规划、担忧、做梦或思考他人。心理内容最好结合任务、经验采样或更具体的行为证据。(Gusnard et al., 2001, PNAS; Christoff et al., 2016, Nat Rev Neurosci; Power et al., 2017, NeuroImage)

### 6. DMN 异常是否可以直接诊断抑郁症、阿尔茨海默病或其他精神障碍？

目前不能把一般性的组间连接异常当作已确立的通用诊断标准。不同疾病、亚型、年龄、药物状态和扫描方法可能导致不同方向的改变。即使在群体间稳定，也仍需独立验证个人敏感度、特异度、增量价值和临床成本。(Greicius et al., 2004, PNAS; Sheline et al., 2010, PNAS; Kaiser et al., 2015, JAMA Psychiatry; Marek et al., 2022, Nature)

### 7. 发育与近期研究能否直接确立机制？

2025 年多模态研究显示 DMN 的细胞构筑多样性和模型信息流特征，2026 年精密映射显示发展阶段与网络拓扑相关；但**多模态一致性、年龄关联与突触级因果必要性并不相同**。尤其新的发育结果宜等待独立纵向样本及不同采集方案验证。(Paquola et al., 2025, Nat Neurosci; He et al., 2026, Dev Cogn Neurosci)

**明确不应采用的断言：** “DMN 只在发呆时工作”“DMN 是大脑自我意识的专属中心”“反相关证明两个网络互相抑制”“fMRI 功能连接等于轴突连接”“DMN 越活跃创造力越强”“DMN 指标已能单独诊断精神障碍”。
