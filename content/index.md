# 🧠 脑研究导航

> 一个按**离结论有多远**分层的脑科学研究导航。
> 它不急着告诉你"大脑是什么"，而是让你看清三件事：**在研究什么 · 用什么看见 · 看见了能说明什么。**

🌿 扩充中

## 这个站回答三个问题

| 问题 | 去哪一层 |
| --- | --- |
| 脑科学在研究**什么**？ | **L1 世界层** —— 尺度、现象、结构 |
| 用**什么**看见它？ | **L2 观测层** —— 模态、方法、资源 |
| 看见了能**说明什么**、做到了什么程度？ | **L3 证据层** —— 证据、设计、结论 |

## 四层结构

| 层 | 做什么 | 目录 |
| --- | --- | --- |
| **L0 导航层** | 入口、视图、更新机制与规则 | [[00-导航/index\|导航层]]、[[09-关于/index\|关于本站]] |
| **L1 世界层** | 描述研究对象：多大的尺度、什么现象、哪些结构 | [[01-尺度/index\|尺度]]、[[03-现象/index\|现象]]、[[04-结构/index\|结构]] |
| **L2 观测层** | 描述观测手段：测什么物理量、怎么算、用什么工具 | [[02-模态/index\|模态]]、[[05-方法/index\|方法]]、[[07-资源/index\|资源]] |
| **L3 证据层** | 约束推断：能推到哪一步、目前把握有多大 | [[06-证据/index\|证据]]、[[08-设计/index\|设计]]、[[10-结论/index\|当前认识]] |

层与层之间是**单向依赖**：世界层不依赖观测层，观测层不依赖证据层；反过来，任何一条结论都必须回溯到具体的观测手段。

```text
L1 世界层   研究对象：尺度 · 现象 · 结构
                  │  被观测
                  ▼
L2 观测层   观测手段：模态 · 方法 · 资源
                  │  产出数据，经推断
                  ▼
L3 证据层   推断与结论：证据 · 设计 · 结论
                  │
                  ▼
L0 导航层   入口与视图：五个入口，任意一页都能横向跳
```

## 本站的四条取舍

这四条决定了什么内容会被收录、什么会被拒绝：

| 取舍 | 含义 |
| --- | --- |
| **为 30 年写作** | 收录长期稳定的概念、原理与边界，而非当前热点、某代设备或某个流行模型 |
| **只有经过检验的结论才升级** | 时间、同行、方法三重检验；单篇论文永远不足以进入结论层 |
| **模态全覆盖** | 从"人脑能被观测到哪些信号"出发穷举，每种信号都写清它能回答什么、不能回答什么 |
| **导航优先，不做教程** | 只讲"能测什么、推论到哪里失效"，具体方法一律外链到论文、数据库与官方文档 |
| **允许被更新** | 骨架稳定、证据每周可动；AI 负责发现与核查，等级变更必须人工确认 |

## 阅读任意一页时，先看两段

1. **定位表** —— 六个坐标的取值，判断这页是否与你的问题相关；
2. **边界段落** —— 「不适用」「局限」「常见误用」「不可支持的推断」。

方法的**能力**决定它能做什么，方法的**边界**决定结论能走多远。后者更重要。

## 本站不做什么

- 不做方法学教程，不复制官方文档；
- 不给临床诊断或健康建议；
- 不把软件输出直接等同于心理过程或脑机制；
- 不因为"最新"就收录，也不因为"经典"就免于核查。
