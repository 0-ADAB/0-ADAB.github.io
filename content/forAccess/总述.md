# 数据类型

| 数据类型            | 空间尺度 | 时间分辨率  | 测量内容  | 主要用途      |            |
| --------------- | ---- | ------ | ----- | --------- | ---------- |
|  **sMRI**       | 宏观   | 静态     | 脑结构   | 解剖形态、疾病诊断 | [[FMRI数据]] |
|  **fMRI**       | 宏观   | 低（秒级）  | 血氧信号  | 脑区功能、网络连接 |            |
|  **EEG/MEG**    | 宏观   | 高（毫秒级） | 电/磁场  | 认知时序、脑节律  | [[EEG数据]]  |
|  **LFP/ECoG**   | 介观   | 高（毫秒级） | 局部场电位 | 局部神经集群活动  |            |
|  **单单位记录**      | 微观   | 极高     | 动作电位  | 单个神经元编码   |            |
|  **钙成像**        | 微观   | 中（Hz级） | 钙离子信号 | 在体神经元集群活动 |            |
|  **scRNA-seq**  | 分子   | 静态     | RNA表达 | 细胞分类、分子机制 |            |
