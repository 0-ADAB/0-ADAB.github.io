# 因果干预证据

> 因果干预证据指通过调控、病损、药理或遗传操作改变神经系统状态后观察结果的证据；它是目前把"参与"升级为"必要或充分"的主要途径，但仍然不等于对机制的完整说明。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 来源层级 | 分子—回路—脑区—网络（干预的作用范围常跨越多个层级） |
| 时间尺度 | 从毫秒级刺激到长期病损与慢性药物作用 |
| 相关模态 | [[神经调控技术]]、[[分子与遗传]]、[[生理与神经化学]] |
| 相关现象 | 全部现象；与 [[临床与病理]] 关系最紧密 |
| 相关结构 | [[皮层下结构]]（深部刺激靶点）、[[神经递质系统]]（药理靶点） |
| 主要方法 | [[实验设计与范式]]、[[有效连接与因果建模]]、[[统计推断与多重比较]] |
| 证据类型 | 本页即为证据类型之一；它是关联证据升级的唯一稳定路径 |

## 来源数据

| 来源 | 干预方式 | 关键特异性问题 |
| --- | --- | --- |
| 电磁与超声调控 | 经颅磁刺激（TMS）、经颅电刺激（tDCS/tACS）、聚焦超声 | 作用区域弥散、电场受个体解剖影响、远隔效应 |
| 深部脑刺激 | 植入电极的持续或程序化刺激 | 靶点与参数由临床决定、同时激活纤维束与胞体 |
| 病损 | 自然病损、外科切除、动物损毁 | 代偿与可塑性、损毁不区分过路纤维与胞体 |
| 药理 | 激动剂/拮抗剂、递质挑战、全身或局部给药 | 全身给药的非特异性、剂量与时间窗 |
| 遗传操作 | 基因敲除/敲入、光遗传学、化学遗传学 | 主要限于动物；发育补偿、表达范围与时间控制 |
| 行为或感觉扰动 | 刺激参数操作、反馈操纵、闭环保留 | 操作影响的是任务而非单一神经过程 |
| 因果建模 | 格兰杰因果、动态因果模型等 | 属于模型推断，不是真实干预；结论依赖模型假设 |

需要注意：前三类改变的是**系统的状态**，最后两类分别是**生物学操作**与**统计建模**。把模型输出的方向性当作干预证据，是常见混淆。

## 可支持的推断

- **必要性**：抑制或损毁某结构/通路后，某功能或行为指标发生变化（提示性），支持该成分在该条件下是必要的。
- **充分性**：激活某结构/通路可以引出或改善某功能指标（提示性），支持在该条件下是充分的。
- **时间特异性**：在特定时刻施加短暂干预会改变后续加工（提示性），这类时序化干预对区分"参与"与"驱动"最有价值。
- **剂量或参数依赖**：效应随干预强度单调或呈特定形态变化（提示性），比单一强度的结果更能排除偶然。
- **可逆性**：短期干预后效应消失，提示作用不是永久结构改变造成的。
- **状态依赖的因果作用**：同一干预在不同状态或不同基线水平下效应不同，支持"作用依赖情境"的表述。
- **环路层级的交互**：对 A 的干预改变 A 与 B 的耦合，支持二者存在功能性相互作用（提示性）。

## 不可支持的推断

- **完整机制**：干预只说明"扰动这一点会改变结果"，不说明系统如何实现该功能。机制主张需要多层面的、可同时解释的模型。
- **定位结论**：干预范围通常弥散，且存在远隔效应与网络级补偿；"刺激 A 改变了行为"不等于"A 负责该功能"。
- **干预即抑制/激活的二分**：神经调控对神经元与纤维的作用不同，参数（频率、极性、强度）可以反转效应方向，把 TMS 或 tDCS 简单称为"激活/抑制某区"是过度简化。
- **全身药理等于特定受体作用**：药物选择性有限，且作用位点、代谢产物与个体差异都会影响结果。
- **动物结论可直接外推到人类**：环路与行为表型差异明显，尤其涉及高级认知与语言。
- **临床改善等于机制正确**：深部刺激的临床效果可以出现在机制假说被否定的情形下。
- **从干预结果反推心理过程**：这仍是反向推断的一种形式，只说明该扰动影响该任务表现。
- **单次显著即可下因果结论**：干预研究同样受样本量、盲法、安慰剂效应与多重比较影响。

## 强度分级

| 强度 | 条件 | 可支持的表述 |
| --- | --- | --- |
| 弱 | 无对照或无假干预条件、非随机、开放标签 | 观察性报告 |
| 中 | 随机分组、假干预对照、盲法、预注册分析、报告效应量与不确定度 | 提示性因果作用 |
| 中强 | 参数或剂量依赖、时间特异性、可逆性、独立复现 | 较稳健的必要性或充分性主张 |
| 强（干预层面） | 多物种或多手段收敛、作用机制有独立生物学证据支持、预测新条件成立 | 较稳固的因果陈述，仍限于"必要/充分"层级 |
| 不等于机制 | 任何强度的干预证据都不自动给出"如何实现"的说明 | 机制需要 [[计算模型证据]] 与多层面观测共同支持 |

## 常见的越界解释

- **把干预当作"关闭某脑区"**：实际改变的是该处及其网络下游的状态，报告需说明作用范围与假干预对照。
- **用干预结果作定位论证**：把行为改变归因于靶区，忽略弥散作用、远隔效应与个体电场差异。
- **忽略安慰剂与期望**：人类调控研究在不设假干预条件时，效应难以与期望效应分离。
- **事后选择靶点或时间窗**：先用数据找最强效应，再据此论证特异性，属于双 dipping。见 [[解码与机器学习]]。
- **把模型因果当干预证据**：有效连接建模依赖于模型结构与噪声假设，不能在缺少干预的情况下支持强因果表述。
- **忽略代偿与发育可塑性**：慢性病损会触发重组，损毁后的功能保留不代表原结构无关，功能缺失也不代表它是唯一承担者。
- **过度概括适用人群**：临床样本的干预结论向健康人群推广时，基线状态差异会改变效应方向。

## 与其他证据类型的关系

- **与功能关联证据**：关联提供"哪里可能相关"的假设，干预检验其中的因果成分；没有关联证据，干预设计往往缺少合理靶点。
- **与结构证据**：结构证据提供靶点可行性与解剖参照；干预也可反过来检验结构指标的功能含义。
- **与时间动态证据**：时序化干预是最接近"时间优先是否等于因果优先"这一问题的检验方式。
- **与计算模型证据**：干预结果常被用于在竞争模型中作判别；反过来，模型可预测干预的后果，二者形成闭环检验。
- **与跨模态一致性**：干预效应在多模态上一致时结论更稳，但仍需注意一致不等于同一过程。
- **与解释边界**：干预证据最容易产生的错觉是"找到了机制"，见 [[解释边界与常见错误]]。
