# 时间动态证据

> 时间动态证据指来自电生理、时频分析与试次间变异的数据所支持的一类主张；它的核心能力是给出**时间结构**——先后、持续、相位与瞬时状态——而不是给出因果优先。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 来源层级 | 神经元—回路—脑区—网络 |
| 时间尺度 | 毫秒—秒为主，可延伸至分钟级状态变化 |
| 相关模态 | [[电生理记录]]、[[血流与代谢成像]]（时间信息受限）、[[行为与眼动]] |
| 相关现象 | [[感知]]、[[注意]]、[[学习与记忆]]、[[语言]]、[[意识与睡眠]] |
| 相关结构 | [[皮层分区]]、[[大尺度网络]] |
| 主要方法 | [[事件相关分析]]、[[时频分析]]、[[源定位]]、单试次分析 |
| 证据类型 | 本页即为证据类型之一；时间优先与因果优先必须分开 |

## 来源数据

| 来源 | 典型指标 | 时间特性 |
| --- | --- | --- |
| 单元记录 | 放电时刻、放电率、尖峰序列 | 毫秒级，可归属到单个细胞 |
| 局部场电位与颅内记录 | 振荡功率、相位、跨频耦合 | 毫秒级，空间覆盖局限 |
| EEG / MEG | 事件相关电位/场、功率与相位、微状态 | 毫秒级，头皮场为多源混合 |
| 时频分解 | 功率谱随时间的演化、相位—振幅耦合 | 受窗长与基线选择影响 |
| 试次间变异 | 反应时波动、单试次解码、变异性指标 | 试次级，可把行为与神经波动配对 |
| 功能像时间信息 | 事件相关血氧反应的时间进程、时变连接 | 秒级，被血流动力学响应函数模糊 |
| 状态与节律 | 睡眠分期、觉醒水平、慢变波动 | 秒—分钟级，与行为状态关联 |

## 可支持的推断

- **时序**：信号 A 在时间上先于信号 B（提示性）。这是时间动态证据最强的一类主张，但仍受采样与定义影响。
- **瞬时状态**：某网络或某模式在短时间内占主导，并可与其他状态区分（提示性）。
- **振荡与相位关系**：特定频段的功率或相位随条件变化，区域间存在相位关系（提示性）。
- **证据累积**：某信号随时间单调累积，并与反应时或判断共同变化（提示性），支持"证据随时间构建"类假设。
- **试次水平的对应**：神经指标在单试次上的波动与行为波动共同变化（提示性），比条件平均更贴近"瞬时状态"这一概念。
- **时间尺度约束**：某过程的时间常数在毫秒级还是秒级，从而排除部分计算假设。

## 不可支持的推断

- **时间优先等于因果优先**：A 先于 B 也可能因为二者共享上游驱动、因为 A 是准备而非驱动、或因为测量延迟不同。方向性主张需要干预或专门的因果建模。
- **相位耦合等于通讯机制**：相位关系可以是共同输入、容积传导或分析假象的结果；"跨区通讯"是需要额外论证的解释。
- **振荡等于计算**：某频段功率升高可以对应多种环路状态；把频段直接命名为功能（如"某频段负责绑定"）缺少依据。
- **单试次解码等于因果通路**：可解码只说明信息存在于该信号中。
- **血氧时间进程的毫秒级解读**：血流动力学响应函数本身持续数秒，用它比较几十到几百毫秒级的差异，超出其时间分辨能力，除非做了显式的去卷积与假设检验。
- **早期成分=感觉、晚期成分=认知**：这一二分是历史惯例而非测量结果；成分的功能归属需要独立证据。
- **头皮时间进程等于皮层时序**：容积传导使多个源同时贡献到每个通道，[[源定位]] 的时间精度受信噪比与模型误差限制。
- **"X 在 Y 之前"就能排除反馈**：需要考虑传导延迟、突触数量与信号定义；同样的先后关系可与多个环路假说相容。

## 强度分级

| 强度 | 条件 | 可支持的表述 |
| --- | --- | --- |
| 弱 | 单通道或单频段、时间窗事后选择、未校正 | 描述性时间进程 |
| 中 | 时间窗与分析参数预注册、控制基线、报告效应量与不确定度 | 提示性时序或状态变化 |
| 中强 | 多指标（功率、相位、单试次）方向一致，跨被试可复现，参数稳健 | 较稳健的时间结构主张 |
| 强（动态层面） | 时序关系在扰动实验（如刺激时序操作）下可被改变，且改变方向符合预测 | 时序关系的因果性主张 |
| 升级路径 | 仅有时间优先永远不能单独升级为因果；需要 [[因果干预证据]] 介入 | 见 [[因果干预证据]] |

## 常见的越界解释

- **把先后叙述为"驱动"**：语言上的"先激活、后激活"会被读成因果链，需要显式声明这只是时序。
- **把试次平均的振幅差解释为心理强度**：振幅受方向、源深度与重叠成分影响，不是心理量的线性刻度。
- **用宽时间窗掩盖方向问题**：把时序差压缩到与测量不确定度相当的范围内，再据此论证方向。
- **循环的时间窗选择**：先在数据上找到差异最大的时间窗，再检验该窗的显著性，属于双 dipping 的一种。
- **忽略多重比较**：通道 × 时间点 × 频段的检验空间极大，未校正会大量产生"显著片段"。见 [[统计推断与多重比较]]。
- **把振荡指标当作机制名词**：用频段名称解释加工过程，等于用现象命名替代机制说明。
- **忽略状态依赖**：觉醒水平、注意波动与药物状态会改变时间动态指标，跨条件比较需控制。

## 与其他证据类型的关系

- **与功能关联证据**：两者共享相关性限制，但时间动态证据额外提供时序与瞬时状态信息，适合约束计算模型的动力学。
- **与结构证据**：结构给出通路与几何约束，时间动态给出时序；二者结合可缩小可行环路假说的范围。
- **与因果干预证据**：干预是检验时序关系是否具有因果地位的主要途径，尤其是时序化的干预设计。
- **与计算模型证据**：模型的时间常数与状态变量需要与观测的时间结构对照，这是模型可检验性的重要来源。
- **与跨模态一致性**：把毫秒级动态与秒级血流信号对齐需要显式的尺度桥接假设，见 [[跨模态一致性]] 与 [[跨尺度整合]]。
- **与解释边界**：本页最核心的红线是"时间优先不等于因果优先"，见 [[解释边界与常见错误]]。
