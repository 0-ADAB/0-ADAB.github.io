# 功能关联证据

> 功能关联证据指来自任务激活、功能连接与脑—行为相关的数据所支持的一类主张；它能说明某个区域或某组区域"在此时参与"，而不能说明它"导致"或"负责"该过程。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 来源层级 | 回路—脑区—网络—全脑 |
| 时间尺度 | 秒级为主（血氧信号），电生理版本可达毫秒级 |
| 相关模态 | [[血流与代谢成像]]、[[电生理记录]]、[[行为与眼动]] |
| 相关现象 | 全部现象；关联证据是现象与脑区之间的主要桥梁 |
| 相关结构 | [[皮层分区]]、[[大尺度网络]] |
| 主要方法 | [[功能连接]]、[[解码与机器学习]]、[[表征相似性分析]] |
| 证据类型 | 本页即为证据类型之一；需与 [[因果干预证据]] 配合才能升级 |

## 来源数据

| 来源 | 典型指标 | 隐含的测量链条 |
| --- | --- | --- |
| 任务激活 | 条件间信号差、参数调制 | 神经活动 → 代谢/血流变化 → 血氧信号 → 统计对比 |
| 功能连接 | 时间序列相关、偏相关、相干 | 神经耦合 → 血管与噪声共同贡献 → 统计相关 |
| 共激活汇总 | 跨研究激活坐标的空间聚类 | 文献收录 → 坐标标准化 → 聚类 |
| 脑—行为相关 | 激活或连接指标与行为成绩的相关 | 两个独立测量之间的统计关联 |
| 多体素模式 | 分类准确率、表征距离矩阵 | 信息存在性 → 可解码性（受样本量与噪声限制） |
| 生理耦合 | 瞳孔、心率、皮肤电与脑信号的相关 | 外周生理与中枢活动共同受多因素调节 |

统一的前提：**指标是代理量**。血氧信号与神经活动之间的关系由神经血管耦合中介，且在不同区域、不同个体与不同状态下强度不同。

## 可支持的推断

- **参与关系**：某区域或网络的活动随任务条件变化（提示性）；这是"参与"的证据，不是"必要"或"充分"的证据。
- **共同变化**：两个指标在同一批被试上共同变化，或在同一被试内随时间共同波动（提示性）。
- **功能连接的结构**：区域之间存在随时间变化的统计依赖（提示性），可用于提出关于交互的假设。
- **信息的存在性**：多体素模式或时间序列中携带与刺激、反应或行为状态相关的信息（提示性），可解码性支持"信息可被读出"。
- **表征差异**：条件之间的模式距离结构提示表征的相似性关系（提示性）。
- **预测**：基于脑指标的模型能泛化预测行为或状态（预测力独立于机制解释）。
- **假设生成**：关联结果为干预实验提供靶区与时间窗假设，这是关联证据最有价值的用途之一。

## 不可支持的推断

- **因果**：无论统计多么强、样本多么大，相关设计不能确定方向，也不能排除第三变量。
- **必要性与充分性**：参与不等于不可或缺，也不等于足以产生该过程。
- **反向推断（reverse inference）**：从"某区域被激活"推回"被试正在经历某心理过程"缺少选择性前提；同一区域参与多个任务，且任务会同时牵动多个区域。
- **定位即功能分派**：激活位置不说明该处执行了什么计算；知道"哪里"不等于知道"做法"。
- **功能连接等于有效连接**：时间相关不给方向、不给符号、也不给中介结构。
- **共同激活等于同一机制**：两次任务在同一区域产生激活，不能推出两者共享机制或共享心理成分。
- **代理量等于神经活动**：血氧、头皮电位、外周生理都不是神经元放电本身，把指标变化直接读成"某脑区活动增强/减弱"时，需要说明测量模型的假设。
- **预测模型的特征权重等于脑机制**：可解码性说明信息存在，权重分配到哪个特征受共线性、噪声与正则化影响。

## 强度分级

| 强度 | 条件 | 可支持的表述 |
| --- | --- | --- |
| 弱 | 单条件、单区域、未校正多重比较、事后选择 ROI | 描述性观察 |
| 中 | 预注册假设、ROI 独立定义、控制混淆、报告效应量与不确定度 | 提示性参与关系 |
| 中强 | 独立样本复现、多指标或多模态方向一致、参数稳健性检验通过 | 较稳健的参与关系 |
| 强（关联层面） | 跨被试、跨任务与跨数据集泛化预测成立 | 稳健的功能关联或预测关系 |
| 升级路径 | 只有加入干预或纵向设计，才能把上述任一级别升级为因果主张 | 见 [[因果干预证据]] |

## 常见的越界解释

- **反向推断**：用"某区激活 → 某心理功能"完成闭环，忽略区域的多功能性与任务的多成分性。
- **相关当因果**：把连接强度差异叙述为"某区域影响了另一区域"。
- **假设碰撞（double dipping）**：用同一份数据先选出显著体素或成分，再在同一数据上检验其与行为的关联，会导致效应量虚高。补救是数据分割或独立样本。见 [[解码与机器学习]]。
- **循环分析**：用功能连接定义网络、再用该网络解释同一批功能连接结果。
- **未校正多重比较**：全脑体素、多通道、多频段同时检验时不校正，会得到大量假阳性。见 [[统计推断与多重比较]]。
- **缺失效应量**：只报告显著性阈值而不报告效应量与置信区间，读者无法判断实际大小。
- **头动与生理噪声的伪装**：头动、呼吸与血管因素会在组间制造差异，尤其在被试组间活动水平不同时。
- **把组平均图当个体结论**：组平均反映的是共享成分，个体可能有不同甚至相反的分布。

## 与其他证据类型的关系

- **与结构证据**：结构说明"通路是否可能存在"，功能说明"是否参与"；两者互为约束但不能互相替代。
- **与时间动态证据**：功能关联常缺少精确时序；时序主张需要电生理或更快的测量。
- **与因果干预证据**：干预把关联假设转为可检验的因果主张；没有干预时，关联结论应保持在提示性措辞。
- **与计算模型证据**：模型可以解释关联模式，但同一模式往往可被多个模型拟合；模型需要关联之外的约束。
- **与跨模态一致性**：多模态一致的关联结果比单模态更稳健，但一致不等于同一过程，见 [[跨模态一致性]]。
- **与解释边界**：本页的越界清单是 [[解释边界与常见错误]] 的主要组成部分之一。
