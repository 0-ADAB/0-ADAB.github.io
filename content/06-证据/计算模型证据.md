# 计算模型证据

> 计算模型证据指由建模、参数拟合与模型比较所支持的一类主张；它回答的是"哪一组形式化约束足以复现观测"，而不回答"大脑是否真的这样实现"。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 来源层级 | 计算层面（可对应到回路、神经元与行为） |
| 时间尺度 | 取决于数据：从毫秒级动力学到试次级学习过程 |
| 相关模态 | 行为数据、[[电生理记录]]、[[血流与代谢成像]]（作为模型约束） |
| 相关现象 | [[决策与奖赏]]、[[学习与记忆]]、[[感知]]、[[注意]]、[[运动控制]] |
| 相关结构 | [[局部回路]]、[[皮层下结构]]（实现层面的对应需单独论证） |
| 主要方法 | [[解码与机器学习]]、[[表征相似性分析]]、[[有效连接与因果建模]] |
| 证据类型 | 本页即为证据类型之一；其解释力必须与替代模型比较才有意义 |

## 来源数据

| 来源 | 典型产出 | 与神经数据的接口 |
| --- | --- | --- |
| 行为模型拟合 | 参数估计、拟合优度、交叉验证预测 | 参数需与神经量建立映射才能成为机制主张 |
| 模型比较 | 相对证据、交叉验证误差、模型恢复能力 | 比较只在所设定的模型集合内有效 |
| 参数估计质量 | 参数恢复（parameter recovery）、可识别性分析 | 参数不可识别时，参数值不可解释 |
| 神经网络建模 | 表征相似性、单元响应、任务训练后的内部结构 | 与生物数据的对应是类比，不是同一性 |
| 生物物理模型 | 膜电位、突触动力学、群体活动的预测 | 参数多、约束少时容易欠定 |
| 生成模型与推断框架 | 对刺激或状态的隐含推断 | 隐含变量是建模选择，不必然对应神经实现 |
| 强化学习类模型 | 价值、预测误差等中间量 | 中间量的神经对应需要独立证据 |

## 可支持的推断

- **形式化充分性**：某组假设足以在给定数据上复现观测模式（提示性）。注意"足以"是逻辑上的充分，不是唯一。
- **竞争假设的判别**：在所比较的模型集合内，某一模型对数据的相对解释更好（提示性）。
- **参数的可解释性**：当参数可恢复且模型可识别时，参数差异可反映数据中存在的系统差异（提示性）。
- **泛化预测**：模型在新的被试、新的条件或新的刺激上仍能预测（提示性），比拟合优度更有说服力。
- **跨层面约束**：同一模型同时解释行为与神经观测时，其可信度提高（提示性，且需报告拟合过程是否对各层面独立）。
- **否定性结论**：某个模型在数据上系统性失败，提示其核心假设需要修正（这类结论通常比"胜出"更稳健）。
- **假设生成**：模型给出可被干预检验的预测，是计算证据最有价值的下游用途。

## 不可支持的推断

- **模型即实现**：模型拟合好不说明大脑以同样方式计算；反问题通常不唯一，多组不同机制可产生相同行为。
- **获胜模型即真模型**：模型比较的结果只在候选集合内成立；集合不完备时，最佳模型可能仍然偏离实际。
- **参数等于神经量**：模型参数（如学习率、温度、耦合强度）是形式化描述，除非有独立映射证据，否则不能读成某种递质或放电特性。
- **网络层与脑区对应**：人工网络中的"层"或"单元"与解剖结构之间是类比关系。
- **拟合优度高即机制清楚**：参数越多、自由度越大，拟合越好；缺少泛化与模型恢复时，拟合优度不构成证据。
- **可解释性叙事等于机制**：用模型的叙述性语言（"系统在预测"）解释数据属于把模型语言实在化。
- **行为可复现即神经可复现**：行为层面的拟合不约束实现层面的细节。

## 强度分级

| 强度 | 条件 | 可支持的表述 |
| --- | --- | --- |
| 弱 | 仅报告最优拟合，无交叉验证、无替代模型、参数未做恢复检查 | 描述性拟合 |
| 中 | 交叉验证预测成立，与替代模型作形式化比较，报告不确定度 | 提示性形式化解释 |
| 中强 | 参数恢复与模型恢复通过，结论跨被试与跨数据集泛化，参数稳健 | 较稳健的计算层主张 |
| 强（计算层面） | 在同一框架下同时约束行为与神经数据，且能预测未参与拟合的条件 | 较强的机制候选说明 |
| 升级路径 | 计算层的强主张仍需实现层的干预证据支撑，才能称为机制 | 见 [[因果干预证据]] |

## 常见的越界解释

- **过拟合**：自由度高的模型在小样本上总能拟合，需要通过交叉验证与惩罚项控制。见 [[解码与机器学习]]。
- **不可识别**：不同参数组合产生相同预测时，参数估计值本身不可解释，需给出可识别性分析。
- **循环论证**：用同一份数据选择模型的隐含变量，再在相同数据上验证其神经对应。
- **模型动物园式选择**：只报告最好的一个模型，而不报告候选集合与选择过程，读者无法判断比较的可信度。
- **把心理学术语植入模型后当结论**：模型中的"信心""愿望"是形式化变量，不自动等于心理过程。
- **忽略负面结果**：只报告模型成功的情形，会让文献层面的证据偏乐观，与发表偏倚叠加。见 [[解释边界与常见错误]]。
- **跨尺度直接拼接**：把毫秒级动力学模型与分钟级测量结果直接对齐，需要显式的尺度桥接假设。

## 与其他证据类型的关系

- **与功能关联证据**：模型可以组织关联结果，但关联模式通常不足以在多个模型中作出判别。
- **与时间动态证据**：时间常数、振荡与状态转移是模型可检验性的主要来源；缺少时间信息时模型约束很弱。
- **与因果干预证据**：干预用于检验模型的预测，是提升计算证据等级最直接的方式。
- **与结构证据**：解剖约束（连接的存在与方向）可以缩小模型空间，提高可识别性。
- **与跨模态一致性**：多层面同时被同一模型解释时结论更稳，但需要检查各层面的独立性。
- **与解释边界**：计算证据最常被越界使用的方向是"模型即机制"，见 [[解释边界与常见错误]]。
