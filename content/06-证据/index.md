# 证据与推断

> 数据本身不是结论。**同一份数据在不同设计下，能支持的推断强度差别很大。** 这个目录负责把"能说到哪一步"标出来。

## 定位

| 坐标 | 取值 |
| --- | --- |
| 输入 | 各模态经分析得到的指标 |
| 输出 | 推断类型与强度分级 |
| 相关模态 | 全部 |
| 相关方法 | 全部 |
| 作用 | 约束解释，防止越界 |

## 推断强度阶梯

从弱到强，越往下需要的设计条件越严格：

```text
1. 描述       某指标在某条件下存在差异
2. 关联       两个指标共同变化（不代表因果）
3. 预测       某指标能泛化预测另一指标
4. 时间优先   某信号在时间上先于另一信号
5. 干预       操作 X 改变 Y（最强的实验性因果证据）
6. 机制       模型同时解释多个层面的观测
```

> 注意：第 5 级也不等于"完整机制"。干预结果说明"必要或充分"，不说明"如何实现"。

## 三条不能越过的线

1. **相关 ≠ 因果** — 相关设计无论统计多强，都不能推出因果。
2. **定位 ≠ 功能** — 知道"哪里参与"，不等于知道"那里做了什么计算"。
3. **代理量 ≠ 神经活动** — 血氧、电位、钙信号与"脑活动"之间隔着测量模型。

## 报告结果时建议同时写出的四项

- 效应与不确定度（不只写显著性）
- 分析自由度中做过选择的地方
- 数据与代码是否可获取
- 结论的适用边界（人群、任务、尺度）
