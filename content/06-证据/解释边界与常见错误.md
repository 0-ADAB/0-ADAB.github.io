# 解释边界与常见错误

> 本页不产出一类新证据，而是汇总所有证据类型共享的解释红线：这些错误与数据质量无关，即使测量完美、样本很大，只要推断跨过了边界，结论依然不成立。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 适用对象 | 全部模态、全部尺度、全部分析路径 |
| 时间尺度 | 不适用（本页是检查清单，不是测量对象） |
| 相关模态 | [[模态比较]]；本页对所有模态同等适用 |
| 相关现象 | 全部现象；在 [[临床与病理]] 中后果最重 |
| 相关结构 | 不适用 |
| 主要方法 | [[统计推断与多重比较]]、[[分析一致性原则]]、[[质控与可重复性]] |
| 证据类型 | `证据/边界` 这一标签维度本身；与其余六类证据页逐一对应 |

## 来源数据

本页的"来源"是各类研究中的**推断语句**，而不是某种数据：

| 检查对象 | 出现位置 | 典型句式 |
| --- | --- | --- |
| 结论句 | 摘要、讨论、图注 | "结果表明某区域负责某功能" |
| 因果措辞 | 相关或横断设计的结果段 | "X 影响了 Y""X 驱动了 Y" |
| 代理量映射 | 指标解释处 | "活动增强""连接变差""功能下降" |
| 分析自由度 | 方法与补充材料 | 未报告的时间窗、ROI、阈值、通道或体素选择 |
| 统计报告 | 结果表 | 只有 p 值、缺少效应量与不确定度 |
| 文献层 | 综述与元分析 | 只汇总显著结果，"基线"被系统性高估 |

使用方式：把研究中的每一句结论，按下面的两问逐条过一遍——

1. 这句话需要什么**设计条件**才能成立（相关？干预？纵向？），测量到的量是目标量本身还是**代理量**？
2. 分析中哪些选择是**事后**做的、是否可能直接产生结论，以及该结论的**适用边界**（人群、任务、尺度、状态）是否被写出？

## 可支持的推断

本页自身可以支持的推断只有一类，但它很实用：

- **对结论强度与缺失信息的判定**（提示性）：可以判定某个结论目前处于哪一强度级别、缺少哪一类证据才能升级，并指出一项研究缺少的关键报告项（效应量、分析自由度、可获取性），这是评估可重复性的前置条件。
- **对表述与升级路径的建议**：把越界句式改写为与其证据等级匹配的表述（例如把"X 导致"改为"X 与该指标共同变化"），并明确从相关升级到因果需要哪类设计，见 [[从问题到证据]]。

## 不可支持的推断

- **不能支持"某结论是错的"**：本页红线说明的是"证据不足"，不是"结论为假"；数据可能与结论相容，只是当前设计不足以确立它。
- **不能支持"越界表述说明结果无效"或"所有相关研究都无价值"**：结果本身可能可靠，问题出在解释层级上，应分别评价数据质量与推断强度；关联证据是假设生成的主要来源，问题在于把关联结论当作因果结论使用。
- **不能支持"报告规范即可保证可重复"**：报告完整提高可评估性，但分析自由度、样本量与测量信噪比仍是独立因素。
- **不能支持"统计显著即效应重要"或"未显著即无效应"**：前者需要效应量与不确定度，后者缺少功效，不能支持"没有效应"。

## 强度分级

红线不是同一类问题，按严重程度可分为三层：

| 层级 | 问题 | 为何严重 | 补救方式 |
| --- | --- | --- | --- |
| 推断层（最重） | 反向推断、相关当因果、定位当机制、代理量当神经活动 | 结论的方向性错误，无法靠增加样本量修正 | 更换设计（干预、纵向、预注册假设），或改写结论措辞 |
| 分析层 | 双 dipping、循环分析、多重比较未校正、过拟合、忽略混淆与批次效应 | 会系统性虚高效应量或制造假阳性 | 数据分割、独立验证、正确校正、零模型、预注册分析 |
| 报告层 | 效应量与不确定度缺失、分析自由度未报告、数据不可获取、只报告成功结果 | 使他人无法判断与复现，文献层面偏差累积 | 按报告规范补齐信息，先行注册，共享数据与代码 |

一个实用的判断规则：**能靠更多数据解决的，多半是分析层或报告层问题；不能靠更多数据解决的，是推断层问题。**

需要单独点名的两个偏差：

- **发表偏倚与选择性报告**：显著结果更容易被发表，导致综述与元分析的效应估计偏高；在同一研究内部只报告显著的条件、通道或时间窗，效果相同但更难从外部察觉。补救包括先行注册、结果盲检、漏斗图类检验与对未发表结果的检索。

## 常见的越界解释

按出现频率排列的典型越界句式及其改写方向：

| 越界句式 | 越界点 | 改写方向 |
| --- | --- | --- |
| "某区激活说明被试在经历某心理过程" | 反向推断：缺少选择性前提 | "该区域在本任务下活动变化，与某过程的参与关系一致" |
| "X 与 Y 相关，因此 X 导致 Y" | 相关当因果 | "X 与 Y 共同变化，方向性有待干预或纵向设计检验" |
| "该区域负责某功能" | 定位当机制 | "该区域参与该功能，其计算作用尚不清楚" |
| "血氧/电位/钙信号升高说明神经元活动增强" | 代理量当神经活动 | "该代理量升高，其与神经活动的映射依赖测量模型" |
| "灰质体积减少说明神经元丢失" | 代理量越界到细胞层面 | "体积差异存在，其组织学成因需要独立证据" |
| "先激活者驱动后激活者" | 时间优先当因果优先 | "两者存在时序关系，方向性需要干预检验" |
| "连接变差导致功能下降" | 相关当因果 + 代理量越界 | "连接指标与功能指标共同变化" |
| "刺激该区后被试某能力下降，故该区是某能力中枢" | 干预结果过度定位（弥散作用、远隔效应） | "该扰动改变了该任务表现，作用范围与网络效应需进一步界定" |
| "模型能复现该现象，说明大脑就是这样计算的" | 计算层当实现层 | "该模型在本数据上具有形式化解释力，实现层对应待检验" |
| "两种模态结果一致，机制已明确" | 一致当同一过程 | "多模态方向一致，收敛效度提高，机制仍需干预与模型共同支持" |
| "该指标只在患者组显著，可作诊断标记" | 群体效应当个体判别 | "组间差异存在，个体判别能力需交叉验证评估" |
| "校正后不显著，说明该条件无效应" | 缺少功效的零结果 | "本样本不足以检出该效应，需要功效分析" |

另有三类不写在句子里、只在分析流程中发生的越界：

- **双 dipping 与循环分析**：前者用同一份数据既选特征/区域又做统计检验，效应量被系统性高估；后者用结论定义自变量（如用功能连接定义网络，再解释该网络的功能连接），命题不可检验。
- **未校正的多重比较**：检验空间巨大时不校正，结果里的"显著"多数为噪声，尤其在全脑体素、多通道、多频段、多指标场景。

## 与其他证据类型的关系

- **与结构证据**：最常见的越界是把体积、FA 等代理量当作细胞或连接本身。
- **与功能关联证据**：反向推断与相关当因果在此类证据上最集中，见 [[功能关联证据]]。
- **与时间动态证据**：核心红线是时间优先不等于因果优先，见 [[时间动态证据]]。
- **与因果干预证据**：核心红线是必要/充分不等于完整机制，干预范围不等于定位，见 [[因果干预证据]]。
- **与计算模型证据**：核心红线是形式化解释力不等于实现机制，且需警惕过拟合与不可识别，见 [[计算模型证据]]。
- **与跨模态一致性**：核心红线是一致不等于同一过程，需警惕假一致与假不一致，见 [[跨模态一致性]]。
- **与设计路径**：这些红线在 [[从问题到证据]] 与 [[从结果到推断]] 中被用作逐步检查项；在项目层面则由 [[研究实践原则]] 与 [[分析一致性原则]] 约束。
