# 跨模态一致性

> 跨模态一致性指同一现象在测量原理不同的多种手段上得到方向一致的结果；它能提高结论的稳健性，但"一致"本身不是因果证据，也不保证两种手段测到的是同一个过程。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 来源层级 | 分子—回路—脑区—网络—全脑（跨层级对齐） |
| 时间尺度 | 一致性主张必须面对各模态时间常数的差异 |
| 相关模态 | [[电生理记录]]、[[血流与代谢成像]]、[[结构与扩散成像]]、[[行为与眼动]] |
| 相关现象 | 全部现象；一致性在临床与个体差异研究中尤其常用 |
| 相关结构 | [[皮层分区]]、[[大尺度网络]]、[[神经递质系统]] |
| 主要方法 | [[多模态融合]]、[[源定位]]、[[质控与可重复性]] |
| 证据类型 | 本页即为证据类型之一；它是整合层而非独立的因果来源 |

## 来源数据

| 联合方式 | 做法 | 一致性主张的来源 |
| --- | --- | --- |
| 同被试多模态采集 | 同一批被试完成多次不同模态的测量 | 个体内或个体间的对应关系 |
| 同任务跨模态 | 同一范式在不同模态下实施 | 条件效应的方向一致 |
| 空间叠加 | 把激活图、连接图、受体分布图配准后叠加 | 空间重叠程度 |
| 联合分解 | 把多模态数据分解到共同成分 | 共享成分的解释 |
| 经验映射 | 用同步记录建立模态之间的定量关系 | 映射函数的稳定性 |
| 跨数据集复现 | 在不同样本、不同设备上重复方向 | 方向一致的可复现性 |
| 跨物种比较 | 动物机制与人类观测的对照 | 拓扑或功能对应 |

需要注意：一致性检验必须在**同一分析口径**下进行。若各模态分别做了不同的预处理、平滑与阈值选择，那么"一致"可能反映的是分析选择而非神经现象。

## 可支持的推断

- **收敛效度**：测量原理相互独立的多种手段给出方向一致的结论时，单一模态特有的伪迹难以解释全部结果（提示性）。
- **空间定位的相互约束**：结构像、功能像与电生理在空间上的共同限定，可缩小可能源的范围（提示性）。
- **经验映射关系的存在**：在同步记录下，两种模态的指标之间存在可复现的对应关系（提示性）。
- **结论的稳健性**：一致结果在跨设备、跨样本重复时，受单次实验偶然性影响的可能性下降（提示性）。
- **不一致的诊断价值**：当方向不一致时，可据此定位到尺度差异、配准误差或指标定义差异，进而提出更精确的假设（提示性）。
- **多层次描述**：多模态联合可以给出同一现象在不同尺度上的描述，为模型提供多重约束。

## 不可支持的推断

- **一致等于同一过程**：不同模态测的是不同物理量、不同时间常数、不同空间权重的量，即使方向一致，也未必指向同一个神经事件。"同一"这一主张需要独立的桥接证据。
- **一致等于因果**：多种相关证据的一致仍然是相关证据的叠加，不产生方向性。
- **不一致等于某一方错误**：不一致常常来自尺度、敏感性、阈值或分析口径的差异，而不是数据有误。
- **联合分析自动更强**：融合模型的结果不会因为输入模态多而更可信；融合效果取决于模型假设是否被验证。
- **空间重叠等于共定位**：体素或通道分辨率的差异会让不同尺度的结构在低分辨率下看起来重叠。
- **跨物种一致等于同源**：拓扑相似的功能对应还需要同源性论证。
- **多模态一致可以替代干预**：一致的多模态相关证据仍不能支持必要性与充分性。

## 强度分级

| 强度 | 条件 | 可支持的表述 |
| --- | --- | --- |
| 弱 | 各模态分别在不同样本上得到结果后比较方向 | 提示性的一致性观察 |
| 中 | 同一批被试、同一任务、独立分析流程、方向与效应量一致 | 收敛效度初步成立 |
| 中强 | 定量映射关系在独立数据上复现，配准与尺度差异已被量化 | 较稳健的跨模态对应关系 |
| 强（一致性层面） | 多种原理不同的手段在多个样本、多个任务上收敛，且能预测新条件 | 稳健的多层面描述 |
| 升级路径 | 因果等级仍取决于是否包含干预设计，一致性本身不能升级为因果 | 见 [[因果干预证据]] |

**假一致（false convergence）的常见来源**

- **配准误差**：把不同空间的图对齐后，边界附近的信号被错误地叠加到一起。
- **共同上游**：两个指标都受同一第三因素（如觉醒水平、头动、血管反应）驱动。
- **空间平滑**：平滑核扩大了空间范围，使两个本来分离的信号看起来重叠。
- **共享分析管道**：同一套预处理与阈值选择同时作用于多模态数据，引入共同偏向。
- **自由度滥用**：在同一数据上反复选择区域或时间窗，直到出现一致（双 dipping）。

**假不一致（spurious divergence）的常见来源**

- **时间常数不同**：毫秒级的电生理事件与秒级的血流反应本身就不在同一时间尺度上。
- **敏感性与功效不同**：一种模态信噪比更高、样本更大，更容易检出效应。
- **指标定义不同**：功率、振幅、连接强度、受体密度不是同一类量，方向不可直接比较。
- **空间加权不同**：头皮场、灰质体素与受体分布对同一源的权重不同。
- **阈值与统计口径不同**：不同校正方式会产生方向不可比的显著图。

## 常见的越界解释

- **用一致性代替机制**：把"结构、功能、连接都对上了"叙述为机制已经清楚，这是最典型的一类越界。
- **把重叠区当作功能单元**：重叠是分辨率与阈值共同作用的结果，不等于存在一个承担单一功能的实体。
- **配准后直接做联合统计**：未量化配准误差与尺度差异就做联合分析，会把误差计入结论。
- **循环选择**：用模态 A 的结果定义 ROI，再在模态 B 中检验该 ROI，并把所得一致性当作独立验证。
- **只报告一致的部分**：不一致结果常被省略，导致一致性被系统性高估，与发表偏倚叠加。见 [[解释边界与常见错误]]。
- **未校正的多模态检验**：多个模态 × 多个区域 × 多个指标的检验空间很大，不校正会制造看似收敛的模式。
- **把跨物种对照当作验证**：动物与人类观测的对应关系若不预先设定，事后对齐容易过拟合。

## 与其他证据类型的关系

- **与结构证据**：结构—功能对应是跨模态一致性最常见的对象，但结构指标与功能指标的映射需要经验验证。
- **与功能关联证据**：一致性把多条相关证据并置，不改变其相关性质。
- **与时间动态证据**：时间尺度对齐是多模态一致的前提之一，尺度桥接假设必须显式说明。
- **与因果干预证据**：干预可作为检验一致性的判别手段——若一处扰动同时改变多个模态的指标，对应关系更可信。
- **与计算模型证据**：同一模型同时约束多模态数据时，一致性的解释力提高，但需检查模型自由度。
- **与解释边界**：本页的核心红线是"一致不等于同一过程，不一致不等于某一方错"，见 [[解释边界与常见错误]]。
