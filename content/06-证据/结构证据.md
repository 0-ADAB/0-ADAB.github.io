# 结构证据

> 结构证据指来自形态测量、扩散成像与组织学的数据所支持的一类主张；它能较稳健地支持"解剖上存在差异或通路"这类陈述，而功能层面的含义必须另外论证。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 来源层级 | 分子—脑区—网络 |
| 时间尺度 | 结构指标在小时—年级变化；扩散指标可在分钟级波动 |
| 相关模态 | [[结构与扩散成像]]、组织学与免疫组化、定量 MRI |
| 相关现象 | 全部现象的解剖基础，不绑定单一现象 |
| 相关结构 | [[皮层分区]]、[[皮层下结构]]、[[大尺度网络]] |
| 主要方法 | [[预处理与伪迹控制]]、[[统计推断与多重比较]]、追踪与分割 |
| 证据类型 | 本页即为证据类型之一；与 [[功能关联证据]] 互补 |

## 来源数据

| 数据来源 | 典型指标 | 它实际测量的是什么 |
| --- | --- | --- |
| 形态测量 | 灰质体积、皮层厚度、表面积、皮层下核团体积、形状 | 组织成分与几何形态的组合，受分割口径与配准影响 |
| 扩散成像 | 各向异性分数（fractional anisotropy, FA）、平均扩散率、纤维束追踪流线、结构连接矩阵 | 水分子扩散的方向性与受限程度，受束内构型、交叉纤维与水肿影响 |
| 定量 MRI | 弛豫时间、磁化转移、磁敏感相关对比（含铁含量） | 组织微结构属性的间接映射，需组织学验证才能赋义 |
| 组织学 | 细胞构筑、髓鞘染色、受体放射自显影、免疫组化 | 层面最直接的解剖与分子证据，但样本量小、多为尸检或动物 |
| 结构协变 | 区域形态指标之间的跨个体相关 | 统计关系，不是通路测量 |
| 纵向结构变化 | 同一被试多次测量的形态或扩散变化 | 变化的可测性受重测信度限制 |

需要注意：这些指标都是**代理量**。体积、厚度、FA 都不是"连接强度""神经元数量""髓鞘完整性"本身，而是与它们相关的可测量量。

## 可支持的推断

- **解剖差异的存在性**：在给定分割与统计流程下，两组被试或同一被试两个时点的结构指标存在差异（提示性）。
- **连接的存在性**：扩散成像的追踪结果提示两个区域之间存在可能的白质通路；组织学示踪可更直接地支持通路存在。
- **解剖与行为的协变**：结构指标与行为测量共同变化（相关，不具备因果地位）。
- **个体差异的刻画**：结构指标可用于描述被试间差异，并作为预测模型的输入（预测力不等于机制）。
- **结构约束的合理性**：为功能连接或有效连接的模型提供解剖可行性约束（存在通路是功能交互的必要条件之一，但不是充分条件）。
- **靶点定位**：为调控或记录提供解剖坐标，供 [[因果干预证据]] 使用。

## 不可支持的推断

- **结构差异解释功能差异**：结构指标的组间差异与功能差异可能来自不同原因（发育、经验、测量误差、分割口径），二者之间需要独立的桥接证据。
- **体积差异等于细胞差异**：体素或核团体积混合灰质、白质、脑脊液与血管成分；体积减小可以由含水量或髓鞘变化引起，而非细胞丢失。
- **FA 降低等于连接变差**：FA 是扩散各向异性的综合指标，受纤维密度、直径、髓鞘、交叉纤维与部分容积影响，方向性解释不成立。
- **追踪流线等于真实轴突束**：追踪是算法重建，存在假阳性与假阴性，尤其在交叉、分叉与终止区域。
- **连接存在即信息流动**：结构连接不给方向、不给有效性、不给符号（兴奋/抑制）。
- **组间结构差异可直接用于个体诊断**：群体效应量通常远小于个体差异，个体分类需要独立验证与交叉验证。
- **横断结构差异等于变化**：两组差异不等于随时间发生的改变，纵向主张需要纵向数据。

## 强度分级

| 强度 | 条件 | 可支持的表述 |
| --- | --- | --- |
| 弱 | 单一指标、单次测量、未校正多重比较、样本小 | 描述性观察，不能超出该样本 |
| 中 | 指标经过预注册或独立复现，控制了头动、年龄、颅内体积等混淆，报告效应量与不确定度 | 提示性解剖差异 |
| 中强 | 多种结构指标或多种成像方式给出方向一致的结果，重测信度已报告 | 较稳健的解剖差异或通路存在性 |
| 强（结构层面） | 组织学或动物示踪直接支持，且与活体指标的经验映射已被验证 | 解剖事实层面的陈述 |
| 不等同于功能强 | 即使结构层面很强，功能推论仍然需要功能或干预证据 | — |

## 常见的越界解释

- **把结构指标当作功能能力的度量**：如把某区体积与"某能力"直接挂钩，中间缺少功能与干预证据。
- **用结构结果解释功能结果**：在同一研究中，用结构组间差异去说明功能组间差异，是典型的越界；两者是平行的两组观测。
- **把相关性写成因果**：结构协变、结构—行为相关都不是因果证据。
- **把追踪结果画成解剖图**：把流线渲染成"纤维束照片"会诱导读者相信存在性已被证实。
- **选择性报告分割或参数**：分割图谱、平滑核、追踪算法与阈值都会影响结果，未报告即不可复现。
- **横向群体差异的临床化**：把研究人群的结构差异直接叙述为疾病的"结构基础"，忽略了诊断异质性与共病。

## 与其他证据类型的关系

- **与功能关联证据**：结构提供"在哪里、是否连通"，功能提供"是否参与"。二者经常被错误地互相解释，正确用法是并置，而不是互相推论。
- **与因果干预证据**：结构证据为干预提供靶点与可行性论证，干预结果反过来检验结构指标的功能意义。
- **与时间动态证据**：结构指标通常缺少毫秒级时间信息，无法支持时序主张。
- **与计算模型证据**：结构连接常被用作模型的解剖约束；约束成立不代表模型正确。
- **与跨模态一致性**：结构—功能对应关系本身需要经验映射支持，见 [[跨模态一致性]]。
- **与解释边界**：结构证据最常见的越界是把代理量当作被代理物，见 [[解释边界与常见错误]]。
