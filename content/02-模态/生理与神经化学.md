# 生理与神经化学

> 这一类手段要么读**外周自主神经与内分泌的读数**，要么直接测**脑内化学物质的浓度或结合状态**。前者的代理链很长且多义，后者时间分辨率低但化学信息不可替代。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 分子 → 全脑（激素与药理层面可达全身） |
| 时间尺度 | 秒（皮电、心率）→ 分钟至小时（激素、PET、MRS） |
| 相关模态 | [[血流与代谢成像]]、[[电生理记录]]、[[神经调控技术]] |
| 相关现象 | [[情绪与应激]]、[[意识与睡眠]]、[[临床与病理]] |
| 相关结构 | [[神经递质系统]]、[[皮层下结构]] |
| 主要方法 | [[预处理与伪迹控制]]、[[统计推断与多重比较]]、[[多模态融合]] |
| 证据类型 | [[功能关联证据]]、[[计算模型证据]]（化学约束模型）；极少单独支持因果 |

## 物理量与被测量之间的关系

这一族内部差别很大，需要分成两支来看。

**外周生理支：**

```text
中枢状态（唤醒、情绪、认知负荷） → 自主神经与内分泌输出 → 汗腺、心脏、呼吸、血管 → 电导、心搏间期、呼吸频率 → 记录设备
```

- **皮肤电活动（electrodermal activity, EDA）**：交感节后胆碱能纤维支配汗腺，分泌改变皮肤电导。皮肤电反应（skin conductance response, SCR）通常在被触发后数秒内出现峰值，潜伏期与波形受皮温、湿度与电极位置影响。
- **心率与心率变异性（heart rate variability, HRV）**：心搏间期同时受交感与副交感（迷走）影响，HRV 指标对两者的混合贡献敏感，不是单一神经通路读数。
- **呼吸与血压**：既是被测变量，也是污染其他模态的噪声源——在 [[血流与代谢成像]] 与 [[电生理记录]] 中必须回归或剔除。
- **激素（皮质醇、性激素等）**：通过唾液、血液或毛发取样，反映数分钟至数月的水平；分泌呈脉动与昼夜节律，单次采样难以代表状态。

**神经化学支：**

- **微透析（microdialysis）**：在特定脑区植入探针，按分子扩散收集细胞外液，再用化学方法定量。空间与化学特异性好，但侵入、取样体积有限、时间分辨率在分钟级，主要在动物或临床特殊情形下使用。
- **PET 受体成像**：用放射性配体估计受体或转运体的结合电位（binding potential）。它反映受体可用性与亲和力的组合，单次扫描无法区分「受体数量变化」与「内源递质竞争」。
- **磁共振波谱（magnetic resonance spectroscopy, MRS）**：在厘米级体素内定量代谢物浓度（如 GABA、谷氨酸、肌醇等）。它测的是**浓度**，不是释放量或活动强度，且体素内包含多种组织与细胞类型。

三种句式：

| 句式 | 例子 |
| --- | --- |
| 能力陈述 | EDA 能够以秒级时间分辨率连续记录交感汗腺活动；MRS 可非侵入定量体素内代谢物浓度 |
| 证据陈述 | 多项研究提示，某些应激或情绪任务中 SCR 幅度上升与唤醒状态相关（提示性；不特异于某种情绪） |
| 推断边界 | SCR 上升不能推断为某一种情绪或某个脑区活动；MRS 的 GABA 浓度不能读作「抑制功能强弱」 |

## 分辨率与采样

| 手段 | 空间尺度 | 时间尺度 | 侵入性 | 主要输出 |
| --- | --- | --- | --- | --- |
| EDA | 全身（外周） | 秒—数十秒 | 无 | 皮电电导、反应幅度 |
| 心电／HRV | 全身 | 毫秒采样，指标以秒—分钟计 | 无 | 心搏间期及其变异性 |
| 呼吸／血压 | 全身 | 秒级 | 无 | 频率、幅度、血压 |
| 激素 | 全身 | 分钟—小时（毛发为数月） | 低（取样） | 浓度 |
| 微透析 | 局部（毫米级探针） | 分钟 | 高 | 细胞外液递质浓度 |
| PET 受体成像 | 毫米—厘米 | 分钟（扫描时长） | 有（辐射） | 结合电位 |
| MRS | 厘米级体素 | 分钟 | 无 | 代谢物浓度 |

## 典型实验范式

- **情绪与应激诱发**：图片、声音、社会评价等操纵，配合 SCR、心率与激素取样。
- **认知负荷与唤醒操纵**：同时记录行为与生理，检验两者是否共同变化。
- **睡眠与昼夜节律记录**：长时程外周记录，配合多导睡眠图与 [[电生理记录]]。
- **药理挑战与受体占位**：给药前后测量生理或成像指标，估计药物对受体的作用。

## 常见分析

EDA 的事件相关反应分解（相位成分与紧张成分）、HRV 时域与频域指标、基线校正与个体化归一化、生理噪声回归（用于其他模态）、混合效应模型、与神经信号的时间滞后分析、PET 的参考区模型与占位估计、MRS 的谱拟合与组织校正。对应页面：[[预处理与伪迹控制]]、[[统计推断与多重比较]]、[[多模态融合]]。

## 优势

- 可穿戴、可长时程、生态效度高，适合自然情境与临床监测。
- 提供连续的状态与唤醒背景，任何其他模态都可借此控制混杂状态。
- 化学层面（MRS、PET、微透析）提供其他非侵入手段无法获得的信息。

## 局限

- **多义性**：SCR、HRV、瞳孔、心率都受多个系统共同决定，单一指标不能指认过程。
- **个体差异极大**：皮肤性质、体型、年龄、药物（咖啡因、β 受体阻滞剂）、运动与饮食都会改变读数，跨被试比较需要个体化归一化。
- **时间尺度错配**：激素与 PET/MRS 的时间尺度无法对应毫秒—秒级的神经过程。
- **外周—中枢耦合强度未知**：外周变化与中枢活动之间没有固定换算关系，耦合系数因情境而变。
- **微透析的侵入与取样偏差**：探针会造成局部组织反应，回收率需校正，取样体积小。
- **PET 的辐射与配体限制**：配体选择性、内源竞争、参考区假设都影响结果，且不宜重复测量。
- **MRS 的体素与浓度解释**：体素大、部分容积效应、组织成分差异需要校正；浓度不等于释放或功能。
- **激素采样的时点依赖**：单点采样难以代表状态，脉动与节律可掩盖真实差异。

## 与其他模态的互补

- 与 [[血流与代谢成像]]：PET 与 MRS 在同一解剖框架内补充化学信息；生理信号用于回归生理噪声。
- 与 [[电生理记录]]：心电、肌电、皮电是伪迹的主要来源，也是状态控制的依据。
- 与 [[神经调控技术]]：药理干预直接作用于递质系统，与电/磁刺激互为对照。
- 与 [[分子与遗传]]：受体分布、递质系统与遗传变异在同一化学层面上对话。

## 常见误用

1. 把 SCR 称为「情绪指标」，或在没有对照条件时把生理唤醒解释为特定情绪。
2. 把 HRV 的高或低直接读作迷走张力或「情绪调节能力」。
3. 把单次激素水平差异读作因果（如把皮质醇差异解释为压力导致的结果）。
4. 把 MRS 的代谢物浓度当作神经活动或抑制／兴奋功能的直接指标。
5. 把 PET 结合电位差异直接读作内源递质释放量的差异。
6. 在神经影像分析中忽略生理噪声回归，或在不报告回归策略的情况下解释结果。
7. 用外周指标对被试做个体层面的诊断或推断。
