# 行为与眼动

> 行为与眼动是最接近**功能输出**的一类指标：它们直接反映有机体做了什么。代价是指标高度多义——同一个反应时或瞳孔变化可以由完全不同的内部过程产生。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 个体（外周指标，不直接定位中枢） |
| 时间尺度 | 毫秒（反应、扫视）→ 秒（注视、瞳孔） |
| 相关模态 | [[电生理记录]]、[[血流与代谢成像]]、[[神经调控技术]]、[[生理与神经化学]] |
| 相关现象 | [[注意]]、[[决策与奖赏]]、[[语言]]、[[社会认知]] |
| 相关结构 | [[皮层分区]]、[[皮层下结构]]（通过推断关联，不是测量目标） |
| 主要方法 | [[实验设计与范式]]、[[统计推断与多重比较]]、[[解码与机器学习]] |
| 证据类型 | [[功能关联证据]]为主；与干预结合才可能触及[[因果干预证据]] |

## 物理量与被测量之间的关系

```text
感知与决策过程 → 反应选择与运动准备 → 运动执行 → 按键/眼球运动/腺体反应 → 设备记录
```

- **反应时（reaction time, RT）与正确率**：测的是从刺激呈现到反应完成的总时间。它包含感觉编码、决策累积、运动准备、执行与设备延迟，是一个**合成量**，本身不指向其中任何一段。
- **注视（fixation）与扫视（saccade）**：注视位置与时长常被用来推断注意与信息采样；扫视幅度、潜伏期与峰值速度反映眼球运动控制。需要注意的是，注视方向与注意焦点可以分离（外显与内隐注意）。
- **微扫视与漂移**：注视期间眼球并非静止，微小运动与视觉稳定性、精细定位有关，其解读依赖具体任务与记录精度。
- **瞳孔（pupil）**：直径同时受光照反射、唤醒水平、认知负荷、情绪与药物影响，因此是典型的多义指标。
- **其他外周输出**：按键力度、语音起始时间、手部轨迹、姿势与步态，都提供连续的行为读数。

三种句式：

| 句式 | 例子 |
| --- | --- |
| 能力陈述 | 眼动仪可以毫秒级记录注视与扫视，并给出亚度量级的空间读数 |
| 证据陈述 | 多项研究提示，某些任务中瞳孔扩大与认知负荷或唤醒上升相关（提示性；同一变化有多种来源） |
| 推断边界 | 反应时变慢不能定位到某一脑区或某一计算步骤；注视某处不等于注意该处 |

## 分辨率与采样

| 指标 | 时间精度 | 空间／幅度读数 | 关键限制 |
| --- | --- | --- | --- |
| 按键反应 | 毫秒级 | 不适用 | 显示器刷新率与输入设备延迟构成下限 |
| 正确率 | 试次级 | 不适用 | 需要足够试次与信号检测论框架 |
| 眼动 | 数百 Hz 记录 | 亚度—1 度量级 | 校准漂移、头动、眼镜与睫毛遮挡 |
| 瞳孔 | 数十—数百 Hz | 相对变化 | 光照、基线、眨眼与插值方法 |
| 手部轨迹／连续反应 | 数十—数百 Hz | 空间轨迹 | 采样与平滑参数影响指标 |

1. 行为实验的时间精度不是无限的：屏幕刷新、输入设备与操作系统调度都会引入毫秒级或更大的不确定度，报告时需说明。
2. 一段记录被切成「注视」或「扫视」依赖事件检测算法与阈值，不同算法给出不同事件集合。
3. 试次数决定估计精度；只报告均值会掩盖分布的形态与策略差异。

## 典型实验范式

- **线索—靶子与注意范式**：通过提示有效性操纵注意，观察反应时或眼动的代价与收益。
- **信号检测论范式**：区分敏感性与判定标准，避免把反应偏向读作能力差异。
- **反扫视与抑制控制范式**：要求抑制朝向反射性扫视，用于研究抑制控制与外周运动指标。
- **自由观看与视觉搜索**：观察自然信息采样策略，常与 [[表征相似性分析]] 或解码联合。
- **瞳孔范式**：oddball、听觉目标、认知负荷、情绪诱发等，必须严格控制光照与基线。
- **行为—神经同步采集**：与 [[电生理记录]]、[[血流与代谢成像]] 同时记录，构成时间锚点。

## 常见分析

反应时分布的建模（不只是均值）、正确率与信号检测指标、速度—正确率权衡的显式建模、混合效应模型与试次间变异分析、漂移扩散类决策模型、眼动事件检测与注视热图、扫描路径与熵指标、瞳孔预处理（眨眼插值、基线校正、光照回归）。对应页面：[[统计推断与多重比较]]、[[解码与机器学习]]、[[计算模型证据]]。

## 优势

- 直接测量功能输出，是所有模态中代理链最短的一环。
- 非侵入、成本低、可移动、可长时程，适合生态效度较高的场景。
- 时间精度好，可提供其他模态所需的事件时间戳。
- 可用于无法完成语言报告的群体（婴儿、动物、部分临床人群）。

## 局限

- **多义性**：同一指标可由多种内部过程产生；瞳孔、皮电、反应时都属此类。
- **合成量不可拆解**：反应时无法分离感觉、决策与运动成分，除非用专门的建模或额外测量。
- **策略与权衡**：被试可采用不同策略，速度与正确率之间存在权衡，均值掩盖异质性。
- **需求特征与期望效应**：被试对实验目的的判断会影响行为，尤其在有明显操纵的范式中。
- **注视不等于注意**：注意可内隐转移；眼动受限任务中两者分离。
- **设备下限**：刷新率与输入延迟限制可分辨的时间差。
- **个体差异与状态**：疲劳、动机、练习、药物、昼夜节律改变指标，需要显式控制或建模。
- **跨物种比较受限**：动物与人类的任务与反应通道差异大，行为指标不可直接对照。

## 与其他模态的互补

- 与 [[电生理记录]]：行为时间戳决定事件对齐，是 ERP/时频分析的锚点。
- 与 [[血流与代谢成像]]：行为指标用于确认条件有效性与核对结果的功能意义。
- 与 [[神经调控技术]]：干预是否改变行为，是因果推断中最常见的结果变量。
- 与 [[生理与神经化学]]：外周生理提供唤醒与状态背景，帮助解释行为差异。
- 与 [[多人同步记录]]：多人行为（注视、动作、言语）是社交互动同步性的直接读数。

## 常见误用

1. 把瞳孔扩大或皮电上升直接称为「情绪反应」或「认知负荷指标」。
2. 用反应时均值的组间差异推论某一加工阶段的速度差异。
3. 把注视热图当作注意分布的唯一证据，忽略内隐注意与任务需求。
4. 忽略速度—正确率权衡，把更快更差的表现读作「能力更强」。
5. 只用正确率而不用信号检测框架，把反应偏向读作敏感性差异。
6. 在神经影像条件比较中不做行为核对，或行为无差异时仍做强功能结论。
7. 把行为指标的变化直接映射到某个脑区或递质系统的变化。
