# 神经调控技术

> 干预手段的价值不在于「更精确地观测」，而在于它能把观测设计变成**操作设计**：主动改变神经活动，观察下游后果。但从「刺激产生了变化」到「该结构负责该功能」之间，仍然有若干必须交代的条件。🌿 扩充中

## 物理量与被测量之间的关系

干预手段的链条是反向的：先施加物理或化学作用，再观察被测量如何改变。

```text
外加电场/磁场/光/药物 → 膜电位或受体状态的改变 → 局部与网络的兴奋性变化 → 观测到的行为或信号变化
```

- **经颅磁刺激（transcranial magnetic stimulation, TMS）**：时变磁场在皮层诱导电流，改变神经元膜电位的瞬时状态。单脉冲或成对脉冲用于探测兴奋性，重复刺激（rTMS）用于产生持续数分钟以上的调节。
- **经颅电刺激（transcranial electrical stimulation, tES）**：微弱电流经头皮电极改变静息膜电位，包含直流（tDCS）、交流（tACS）与随机噪声（tRNS）等形式。电流分布弥散，极性相关效应的方向依赖神经元朝向与状态。
- **脑深部刺激（deep brain stimulation, DBS）**：植入电极对深部结构施加高频电脉冲。其作用机制仍在讨论中，可能同时包含局部抑制、轴突激活与网络层面的节律重塑。
- **光遗传学（optogenetics）**：以基因手段表达光敏离子通道或泵，用光在毫秒级、细胞类型特异地改变活动。目前主要在动物模型中使用。
- **药理干预**：口服或局部给药，从受体或递质水平改变系统状态；时间尺度由药代动力学决定，作用范围通常为全脑。
- **病损与离断**：自然的或人为的损伤，提供另一类「操作」证据，但不可逆且难以限定范围。

三种句式：

| 句式 | 例子 |
| --- | --- |
| 能力陈述 | TMS 可在毫秒级时间窗内干扰特定皮层的加工；光遗传可在特定细胞类型上做毫秒级操作 |
| 证据陈述 | 若刺激某区域后行为指标发生方向一致的变化，研究通常将其解读为该区域参与该任务的证据（提示性；方向与范围仍受个体差异约束） |
| 推断边界 | 刺激导致变化不等于该区域「负责」该功能；刺激也不等于抑制或兴奋——二者的判定需要独立指标 |

## 分辨率与采样

| 手段 | 作用范围 | 时间尺度 | 细胞特异性 | 侵入性 |
| --- | --- | --- | --- | --- |
| TMS | 厘米级（随线圈与深度迅速衰减） | 毫秒—分钟 | 无 | 无（但影响被试状态） |
| tES | 厘米级且弥散 | 秒—分钟（后效应更长） | 无 | 无 |
| DBS | 电极附近毫米级，作用遍及网络 | 毫秒脉冲，持续给药式 | 无 | 有（植入） |
| 光遗传 | 单细胞—小群 | 毫秒 | 高（需基因操作） | 有（动物为主） |
| 药理 | 全脑 | 分钟—小时 | 受体类型层面 | 系统性 |

要点：干预的「分辨率」不同于观测的分辨率。线圈位置不等于受影响区域，电极位置不等于作用范围。

## 典型实验范式

- **在线与离线设计**：刺激与任务同时进行（在线），或先调节再测量（离线）；两者回答的问题不同。
- **假刺激对照（sham）与盲法**：假刺激设计的可信度直接决定结论强度。
- **剂量—反应与参数扫描**：强度、频率、时长、极性等参数改变结果，报告参数是可比性的前提。
- **状态依赖设计**：同一刺激在不同脑状态或任务阶段效果不同，常与 [[电生理记录]] 联用。
- **与记录联用**：TMS-EEG、DBS-LFP、刺激—成像，用于观察干预的直接后果。

## 常见分析

刺激效应量（如运动诱发电位幅度）、阈值测定、反应时与正确率变化、刺激前后信号差异、网络层面的连接变化、与个体解剖或电场模型的关联。对应页面：[[实验设计与范式]]、[[有效连接与因果建模]]、[[统计推断与多重比较]]、[[质控与可重复性]]。

## 优势

- 是唯一能在人类身上获得干预性证据的非侵入路径，可支持必要性与充分性的初步判定。
- 时间精度高（TMS、光遗传可到毫秒），适合检验时序假设。
- 可与记录模态同期使用，使「操作—后果」落在同一时间轴上。
- 部分手段具有临床应用价值，研究与应用共享同一套参数空间。
- 光遗传在动物中提供细胞类型特异的操作，是机制研究的关键工具。

## 局限

- **方向不确定**：刺激改变的是网络状态，「抑制」或「兴奋」的标签需要独立指标支持，且随参数与状态反转。
- **范围不确定**：TMS 与 tES 的实际电场分布因人而异，依赖头颅与脑解剖建模，模型本身含假设。
- **个体差异大**：头皮—皮层距离、脑形态、年龄、药物、觉醒状态都会改变效应量。
- **假刺激不完美**：tES 与 TMS 的假刺激难以完全匹配感觉副作用，盲法有效性受限。
- **机制未定**：DBS 与 rTMS 的长期效应机制都没有定论，参数常由经验而非机制决定。
- **物种跨越困难**：光遗传与多数侵入性操作只在动物模型中进行，认知任务与网络组织与人不可比。
- **安全与伦理边界**：存在诱发癫痫等风险，需遵守强度与频率限制；侵入性手段的受试者选择本身引入偏差。
- **不等于完整机制**：干预结果说明「操之则变」，不说明「如何实现」。

## 与其他模态的互补

- 与 [[电生理记录]]：刺激的直接电生理后果，是判定方向与时间窗最直接的方式。
- 与 [[血流与代谢成像]]：观察干预对网络活动的空间影响。
- 与 [[行为与眼动]]：行为变化是干预是否影响功能的关键判据。
- 与 [[结构与扩散成像]]：个体化解剖与电场建模的输入。
- 与 [[生理与神经化学]]：药理干预把递质系统作为变量，与生理指标互为对照。

## 常见误用

1. 把「刺激某区域改变了行为」直接表述为「该区域是该功能的脑区」。
2. 把 rTMS 低频一律称为抑制、高频一律称为兴奋。
3. 用假刺激组之间的差异代替对效应机制的说明。
4. 把 tES 的结果按电极位置定位（电流并不局限在电极下）。
5. 把动物光遗传结果直接外推到人类认知与临床。
6. 只报告显著的行为指标，不报告刺激参数、盲法效果与被试状态。
7. 在小样本、多参数的组合搜索后只报告最优结果，忽略多重比较问题。
8. 把干预的统计显著当作因果机制的证明，忽略干预本身的非特异性效应。
