# 分子与遗传

> 这一类手段把观测单位下沉到**转录本、蛋白与基因型**，给细胞类型与分子机制提供定义基础。代价是绝大多数测量发生在离体组织或人群统计层面，与活体、实时的脑活动之间还隔着多级调控。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 分子 → 神经元 → 回路 |
| 时间尺度 | 静态；跨发育与老化比较可用 |
| 相关模态 | [[结构与扩散成像]]、[[生理与神经化学]]、[[神经调控技术]] |
| 相关现象 | [[发育与老化]]、[[学习与记忆]]、[[临床与病理]] |
| 相关结构 | [[皮层分区]]、[[神经递质系统]]、[[分子与突触]] |
| 主要方法 | [[表征相似性分析]]、[[统计推断与多重比较]]、[[多模态融合]] |
| 证据类型 | [[结构证据]]与[[计算模型证据]]；关联性遗传证据需谨慎分级 |

## 物理量与被测量之间的关系

```text
基因型 → 转录调控 → 转录本丰度 → 蛋白丰度与修饰 → 细胞与突触性质 → 回路与网络 → 行为/影像表型
```

链条上的每一级都有额外调控与噪声，因此相邻层级之间的对应关系从不严格。

- **单细胞测序（single-cell RNA sequencing, scRNA-seq）**：把组织解离为单细胞，测每个细胞的转录本计数。输出是**转录本丰度**，经归一化与聚类后得到细胞类型划分。聚类结果是数据分析的产物，与发育起源或解剖位置的分类不必一致。
- **单核测序与空间转录组（spatial transcriptomics）**：前者避免解离造成的状态改变；后者保留空间坐标，分辨率依技术不同，从数十微米到近亚细胞不等，但捕获效率与基因覆盖通常低于解离方法。
- **免疫组化（immunohistochemistry, IHC）与原位杂交**：用抗体或探针标记蛋白或 RNA 的分布。结果是切片上的相对强度，受抗体特异性、穿透、组织固定与观察者判定影响。
- **基因编辑与基因操作**：改变特定基因或表达特定构建体，与 [[神经调控技术]]（如光遗传）联用可形成特异的干预—观测组合。
- **遗传变异与影像遗传学**：在人群层面把常见变异、罕见变异或多基因分数与影像、生理或行为表型关联。单个常见变异对复杂表型的效应通常极小，需要大样本；关联不指示中介路径。

三种句式：

| 句式 | 例子 |
| --- | --- |
| 能力陈述 | scRNA-seq 可给出成千上万个单细胞的转录本谱并据此聚类；空间转录组能同时给出转录本与空间坐标 |
| 证据陈述 | 多项研究提示，某些遗传变异与影像或行为表型存在统计关联（提示性；效应量小、需独立样本重复） |
| 推断边界 | 遗传关联不能读作因果，也不能用于个体预测；细胞类型聚类不等于解剖学分类 |

## 分辨率与采样

| 手段 | 空间分辨率 | 时间维度 | 侵入性 | 主要输出 |
| --- | --- | --- | --- | --- |
| 单细胞测序 | 单细胞（解离后无空间信息） | 静态快照 | 高（需组织） | 转录本计数 |
| 单核测序 | 单核 | 静态快照 | 高（需组织） | 转录本计数 |
| 空间转录组 | 数十 µm 至近亚细胞 | 静态快照 | 高（需组织） | 转录本 + 坐标 |
| 免疫组化／原位杂交 | 微米级 | 静态快照 | 高（切片） | 蛋白／RNA 相对强度 |
| 基因编辑模型 | 单基因／细胞类型 | 基因修饰后跨发育 | 高（动物为主） | 表型变化 |
| 影像遗传学 | 人群层面（表型为毫米级体素） | 队列随访 | 低（取样） | 关联统计量 |

要点：

1. 表达量是**相对量**，跨样本比较依赖归一化与批次校正方法，不同流程可比性有限。
2. 人体脑组织的可得性受限：多为尸检、手术切除或临床样本，取样偏倚与死后间隔都会改变表达谱。
3. 遗传学与影像学的样本量量级不同，联合分析的表型噪声与统计功效必须一并报告。

## 典型实验范式

- **细胞类型图谱构建**：跨脑区与发育阶段的单细胞取样，建立参考分类。
- **病例—对照表达谱**：比较临床组与对照组的转录或蛋白模式，需严格控制批次与混杂。
- **空间—功能对照**：把转录组分区与影像梯度、连接模式对照。
- **基因操作结合行为与记录**：在动物中以编辑或表达构建体改变分子，再观察回路与行为后果。
- **影像遗传学队列**：大样本中同时采集基因型与影像／行为表型，做关联与重复。

## 常见分析

归一化与批次校正 → 降维与聚类 → 细胞类型注释 → 差异表达与富集分析 → 反卷积（把组织水平信号拆为细胞类型比例）→ 关联分析（多基因分数、混合模型）→ 中介与共定位分析。对应页面：[[表征相似性分析]]、[[统计推断与多重比较]]、[[质控与可重复性]]。

## 优势

- 提供分子与细胞类型层面的分辨率，是其他活体模态无法达到的层级。
- 为回路与网络研究提供细胞类型的定义基础；与 [[结构与扩散成像]] 的宏观分区互为补充。
- 基因操作可以在动物中实现细胞类型特异的因果干预。
- 大规模队列使小效应的稳健检测在统计上可行。

## 局限

- **不可在活体人脑获得**：绝大多数人类分子数据来自尸检或手术样本，时间与空间取样受限。
- **解离与固定改变状态**：转录本谱是组织处理后的快照，不能等同于活体状态。
- **聚类不是分类学**：细胞类型的边界依赖算法、分辨率参数与标记基因选择，存在主观成分。
- **表达不等于功能**：转录本丰度与蛋白丰度、蛋白活性之间不是线性对应。
- **遗传效应极小且多效**：复杂表型的遗传结构高度分散，单个变异难以解释机制，群体分层与连锁不平衡是主要混杂。
- **中介路径未知**：基因—脑—行为之间的链条通常只被两端测量，中间环节多为假设。
- **跨物种外推受限**：转录组相似不等于功能相似，任务与行为范式的可比性更差。
- **可重复性压力**：小样本分子研究、多重比较与流程选择带来的假阳性风险需要显式处理。

## 与其他模态的互补

- 与 [[结构与扩散成像]]：用分子分区校验或细化宏观解剖边界；影像遗传学以影像为表型。
- 与 [[生理与神经化学]]：MRS 与 PET 提供活体化学信息，与离体分子数据互相印证。
- 与 [[神经调控技术]]：基因操作是细胞类型特异干预的前提。
- 与 [[电生理记录]]：分子定义的细胞类型与电生理特征联合，用于校对分类。
- 与 [[多人同步记录]]：个体间遗传差异可能解释同步性或反应性的个体差异（属假设层面）。

## 常见误用

1. 把遗传关联表述为「某基因导致某脑特征或疾病」。
2. 把多基因分数当作个体风险预测工具。
3. 把细胞类型聚类结果当作解剖学或功能分类的定论。
4. 忽略批次效应与死后间隔，直接把表达差异读作病理差异。
5. 用动物模型的分子与行为结果直接外推到人类认知。
6. 把转录本丰度变化称为「蛋白功能变化」。
7. 在影像遗传学中忽略表型测量误差与多重比较，报告未重复的位点作为结论。
