# 结构与扩散成像

> 这一族手段测的是**组织物理性质**——弛豫时间、质子密度、水分子扩散的方向与速率，不是活动。它给出脑的解剖与连接底图，但「底图上的差异」与「功能上的差异」之间没有自动的桥。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 脑区 → 网络 → 全脑 |
| 时间尺度 | 静态；跨发育与老化的纵向比较可用 |
| 相关模态 | [[血流与代谢成像]]、[[电生理记录]]、[[分子与遗传]] |
| 相关现象 | [[发育与老化]]、[[临床与病理]]、[[学习与记忆]] |
| 相关结构 | [[皮层分区]]、[[皮层下结构]]、[[大尺度网络]] |
| 主要方法 | [[预处理与伪迹控制]]、[[功能连接]]、[[多模态融合]] |
| 证据类型 | [[结构证据]]为主；不单独支持功能或因果推断 |

## 物理量与被测量之间的关系

```text
组织的质子与微环境 → 弛豫时间、质子密度、磁化率 → MR 对比 → 分割/形态指标
水分子受组织屏障限制的扩散 → 扩散信号随方向变化 → 张量或方向分布模型 → 纤维走向与「连接」推断
```

- **结构 MRI（structural MRI, sMRI）**：T1/T2 加权像的组织对比来自不同组织的弛豫差异，受髓鞘、铁、含水量、细胞密度共同影响。分割后得到的体积、皮层厚度、表面积是**从图像推导的量**，不是直接测量的量。
- **扩散 MRI（diffusion MRI, dMRI）与扩散张量成像（diffusion tensor imaging, DTI）**：测量水分子在多个方向上受梯度磁场编码后的信号衰减。张量模型输出各向异性分数（fractional anisotropy, FA）、平均扩散率（mean diffusivity, MD）与主方向。信号反映轴突密度、直径、髓鞘、膜通透性、细胞外间隙与纤维离散度的**混合效应**。
- **纤维追踪（tractography）**：由体素级方向分布重建流线。它给出的是与扩散数据一致的几何假设，不是解剖上验证过的轴突走向。
- **定量 MRI（quantitative MRI, qMRI）**：T1/T2 mapping、磁化转移（magnetization transfer, MT）、髓鞘水分数、定量磁化率成像（quantitative susceptibility mapping, QSM）等，试图给出可跨扫描仪比较的物理参数，但仍需模型假设，且各参数与髓鞘、铁、水含量的对应不是一一映射。

三种句式：

| 句式 | 例子 |
| --- | --- |
| 能力陈述 | dMRI 可给出毫米级体素内的扩散方向分布；tractography 可重建跨脑区的流线 |
| 证据陈述 | 多项研究提示，训练或发育过程中某些白质区域的扩散指标发生变化（提示性；指标特异性有限） |
| 推断边界 | FA 差异不能读作「髓鞘增加」，也不能读作「连接增强」；流线的存在不代表信息沿其传递 |

## 分辨率与采样

| 手段 | 空间分辨率 | 时间维度 | 主要输出 | 侵入性 |
| --- | --- | --- | --- | --- |
| sMRI | 毫米级体素 | 静态，可纵向 | 体积、厚度、表面积、分割标签 | 无 |
| dMRI / DTI | 毫米级体素 | 静态 | FA、MD、方向分布、流线 | 无 |
| qMRI | 毫米级体素 | 静态 | T1/T2、MT、磁化率等定量参数 | 无 |
| 组织学 / 电镜 | 微米—纳米 | 静态（离体） | 细胞与轴突形态 | 有（离体或侵入） |

1. 一个毫米级体素包含大量轴突、多种细胞与血管，扩散信号是所有微环境贡献的平均。
2. 层流空间分辨率与角分辨率相互制约：方向数越多、每方向采样越少，或反之。
3. 扫描协议（b 值、方向数、体素大小）、场强与线圈都会改变数值，跨中心比较必须先做协议协调。

## 典型实验范式

- **组间形态比较**：病例—对照或不同能力组的体积、皮层厚度比较（常配合 [[统计推断与多重比较]]）。
- **纵向设计**：发育、训练、病程中的结构变化，需要配准与测量稳定性控制。
- **个体化配准与图谱映射**：把功能或电极位置映射到解剖空间，例如 [[EEG-64]] 的通道与皮层对应。
- **连接组构建**：以 tractography 为基础建立结构连接矩阵，用于图论与网络分析。
- **多模态整合**：结构像作为 fMRI、电生理、调控的空间参照系。

## 常见分析

分割与表面重建 → 形态指标提取 → 配准到公共空间 → 体素或固定束统计（如基于骨架的扩散统计）→ 纤维追踪与连接矩阵 → 与功能网络比较。对应页面：[[预处理与伪迹控制]]、[[功能连接]]、[[多模态融合]]、[[统计推断与多重比较]]。

## 优势

- 非侵入、可重复采集、临床设备普及，适合大样本与纵向研究。
- 空间分辨率在活体全脑观测中最高档位之一，个体解剖结构可直接获得。
- 为其他模态提供必要的空间参照与解剖约束。
- qMRI 与扩散指标有潜力成为可跨中心比较的定量指标（前提是协议与模型统一）。
- 与遗传、认知、临床变量的关联分析可在同一空间框架内进行，见 [[分子与遗传]]。

## 局限

- **指标不特异**：体积、厚度、FA、MD 的变化都可能由髓鞘、轴突、胶质、水分、血管等多因素引起，单一指标不能指认原因。
- **分割与算法依赖**：不同软件、参数与图谱会给出不同的边界与数值，跨研究比较需谨慎。
- **tractography 的假阳与假阴**：交叉纤维、亲吻纤维与低各向异性区域会产生错误流线；「连接存在」的判定阈值带有人为选择。
- **方向与极性未知**：扩散指标对轴突方向敏感，但不区分顺行与逆行，也不指示信息流向。
- **结构不等于功能**：结构连接是功能通信的必要条件之一，不是充分条件。
- **头动与场强效应**：头动会系统性地影响扩散指标；不同场强与协议难以直接对照。
- **离体组织学与活体成像不可直接等同**：尺度、固定方式、组织状态都不同。

## 与其他模态的互补

- 与 [[血流与代谢成像]]：功能定位挂到解剖与结构连接上，是结构—功能联合的基本用法。
- 与 [[电生理记录]]：电极位置、源定位与连接分析都需要结构像做参照与约束。
- 与 [[分子与遗传]]：影像遗传学把结构指标与遗传变异关联，但中介路径通常未知。
- 与 [[神经调控技术]]：个体化电场或靶点计算依赖解剖模型。
- 与 [[生理与神经化学]]：MRS 与 PET 提供同空间框架下的化学与受体信息。

## 常见误用

1. 把 FA 下降解释为「髓鞘脱失」或「连接受损」（指标是多因素混合）。
2. 把 tractography 流线图当作解剖切片，用箭头表示信息方向。
3. 用未做协议协调的公开数据做跨中心数值比较。
4. 把组间结构差异直接读作功能差异或疾病机制。
5. 在纵向研究中忽略测量误差与配准误差，把噪声当作变化。
6. 用结构连接矩阵替代功能连接做「通信」结论。
7. 忽略分析自由度（图谱、平滑、阈值）导致结果不可重复。
