# 实时的神经同步

> 这一页回答三个问题：**同步性意味着什么、实时的神经同步能否实现、能监测什么**。答案取决于把「同步」与「实时」定义在哪一层——本页给出判据与边界，不给结论。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 群体（个体间）；也可指被试内的回路间 |
| 时间尺度 | 毫秒（在线估计）→ 秒（血流动力学手段） |
| 相关模态 | [[多人同步记录]]、[[电生理记录]]、[[生理与神经化学]] |
| 相关现象 | [[社会认知]]、[[注意]]、[[语言]]、[[意识与睡眠]] |
| 相关结构 | [[大尺度网络]]、[[局部回路]] |
| 主要方法 | [[功能连接]]、[[有效连接与因果建模]]、[[解码与机器学习]] |
| 证据类型 | [[跨模态一致性]]、[[时间动态证据]]；实时性本身不提升证据等级 |

## 物理量与被测量之间的关系

每个被试身上测得的仍是各自模态的代理量（电位、血氧、外周信号）；「同步」不存在于任何一台设备上，而是分析阶段构造出来的派生量——被试 A 的代理量 + 被试 B 的代理量 → 跨序列统计关系 → 「同步」这一构念。

因此它的推断距离比单模态记录**多一层**：代理量到神经活动的距离不变，额外增加的是「统计关系 → 交互过程」这一步。这一步没有设备可以替代，只能靠设计支撑。

**推断边界**：同步指标不能反过来当作神经活动的直接测量；同一批数据换一种统计定义（相位、幅度、时间对齐、有向）会得到不同的「同步」。

## 问题一：同步性意味着什么

「同步」至少在三层含义上被使用，混用会造成系统性误读：

| 层次 | 具体所指 | 常见指标 |
| --- | --- | --- |
| 被试内单元间 | 神经元之间、区域之间的相位或幅度关系 | 相位锁定、相干、尖峰—场耦合 |
| 被试内跨时间 | 同一信号在不同时刻的稳定性 | 试次间相关、状态持续性 |
| 被试之间 | 两条独立记录序列的统计关系 | 跨被试相关、包络耦合、有向模型 |

使用该词时还必须说明统计关系属于哪一类：**相位关系**（相位对齐，与幅度无关）、**幅度关系**（包络共变，与相位无关）、**时间对齐**（同时或固定滞后发生）、**有向关系**（一方对另一方有预测力）。四类互不蕴含：幅度同步可以没有相位关系，时间对齐可以来自共同输入。

**推断边界**：同步是统计共变，不是信息传递；同步强度没有公认的绝对阈值，不同定义的同步值不可直接比较；同步缺失也不等于无交互。

## 问题二：实时的神经同步能否实现

「实时」有两种含义：**工程实时**（系统在可接受延迟内完成采集 → 估计 → 输出／反馈，属于延迟链问题）与**科学实时**（在线估计的量能否即时反映所关心的过程，属于代理量与时间尺度问题）。两者必须分开评估。

延迟链构成：采集缓冲 → 滤波与特征提取 → 耦合估计（常需滑动窗，窗长本身即延迟）→ 输出或刺激。窗越长估计越稳、延迟越大——稳定性与实时性此消彼长。各模态的天然约束：

| 模态 | 在线估计可行性 | 主要约束 |
| --- | --- | --- |
| EEG | 毫秒级指标输出 | 肌电与眼动伪迹、参考与容积传导、个体差异 |
| fNIRS | 秒级 | 血流动力学响应本身延迟数秒，毫秒级同步不可得 |
| fMRI | 慢 | TR 与血流响应限制，通常离线或准实时反馈 |

还需区分**观测到同步**（计算耦合强度）与**用同步做控制**（把耦合指标接回刺激系统形成闭环）：闭环在工程上可实现，但会引入自反馈——刺激改变信号，信号又触发刺激，分析必须显式处理这一回路。

**推断边界**：时间上「实时」不等于估计量在性质上更接近神经活动；实时性是工程属性，不改变证据等级。能否实现取决于延迟上限、指标定义与可接受伪迹水平的具体约定，而不是一个统一的是或否。

## 问题三：能监测什么

可监测对象按确定性从高到低：**信号质量与状态量**（电极阻抗、伪迹水平、觉醒与困倦、头动、呼吸与心跳节律）→ **己方指标的相对变化**（与个体基线相比的相位／幅度耦合趋势）→ **行为与外周指标**（注视、动作、皮电、心率，可作独立的第二通道）→ **跨被试耦合的在线估计**（技术上可算，解释依赖对照与设计）。

明确**不在**监测范围内的对象：个体的心理内容、意图与「理解深度」；社会关系的质量；临床诊断结论。评估任何「实时同步」系统的判据清单：延迟是多少、包含哪些环节；指标定义与窗长是什么、稳定性如何验证；对照条件与伪对基线是否具备；共同刺激与运动伪迹是否处理；个体化基线如何建立；输出用于控制还是用于生成结论。

## 分辨率与采样

- 时间分辨率受两端约束：记录手段的采样率与在线估计所需的时间窗，有效值由较长的一方决定。
- 多人同时记录时，设备间时钟同步精度是独立于采样率的关键参数；未校准的漂移会制造虚假滞后。
- 提高采样率不能弥补指标定义或对照设计上的缺陷。

## 典型实验范式

- **自然互动 + 在线指标**：对话、联合行动中在线计算耦合。
- **闭环互动**：一方接收另一方（或其信号派生量）的实时反馈并据此行动。
- **伪对与时间偏移对照**：拼接记录或平移其中一条序列，检查耦合是否消失。

## 常见分析

在线指标多依赖滑动窗相关、包络耦合、相位锁定与有向模型；离线验证则用置换检验、伪对基线与试次间变异。对应页面：[[功能连接]]、[[有效连接与因果建模]]、[[解码与机器学习]]、[[统计推断与多重比较]]。

报告时必须交代的一项：**在线算法与离线验证算法是否一致**——若不一致，在线系统的「实时性」与最终结论之间就缺少可追溯的链路。

## 优势

- 使互动范式可控：反馈可在被试不知情的时间窗内改变，提高设计的因果成分。
- 在线质量控制在采集阶段就暴露伪迹与漂移，减少事后补救。
- 闭环设计可放大或抑制特定状态，为状态依赖性研究提供工具。

## 局限

- **延迟与稳定性的矛盾**：窗越短越实时、估计越不稳；窗越长越稳、越不实时。
- **伪迹与真实耦合难分离**：说话、点头、呼吸、心跳在多人记录中天然共变。
- **共同刺激的混淆**：自然互动中共同输入与真实耦合难以在事中分离。
- **指标的生理含义未统一**：尤其 fNIRS 与 EEG 的跨被试耦合，缺少被广泛接受的机制对应。

## 与其他模态的互补

- 与 [[多人同步记录]]：本页是那套记录方法与解释边界的问题清单。
- 与 [[电生理记录]]：在线毫秒级指标的来源，同时继承容积传导与参考依赖问题。
- 与 [[血流与代谢成像]]：长时程互动的空间信息，但本质上不适合毫秒级实时。
- 与 [[生理与神经化学]]：心跳与呼吸是首要混淆源，也是最易在线监测的共同节律。

## 常见误用

1. 把在线相关性当作实时因果耦合。
2. 不声明「同步」的统计定义就使用该词，跨页面与跨研究比较因此失效。
3. 把工程延迟与神经时间尺度混为一谈（如认为 fNIRS 可做毫秒级实时同步）。
4. 忽略滑动窗长度造成的平滑，把窗口内平均效果读作瞬时事件。
5. 用闭环系统的输出证明闭环所依据的假设（自证循环）。
