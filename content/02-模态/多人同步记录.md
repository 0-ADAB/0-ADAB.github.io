# 多人同步记录

> 多人同步记录（hyperscanning）在**同一时间轴上记录两人或更多人的神经与行为信号**。它测量的不是「两个人之间的连接」，而是多条独立时间序列之间的统计关系——这种关系的来源需要在设计上逐一排除。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 群体（个体间）；单人信号的空间分辨率由所用手段决定 |
| 时间尺度 | 毫秒（EEG）→ 秒（fNIRS、fMRI） |
| 相关模态 | [[电生理记录]]、[[血流与代谢成像]]、[[行为与眼动]] |
| 相关现象 | [[社会认知]]、[[语言]]、[[情绪与应激]]、[[临床与病理]] |
| 相关结构 | [[大尺度网络]]（仅在被试内层面成立） |
| 主要方法 | [[功能连接]]、[[事件相关分析]]、[[统计推断与多重比较]] |
| 证据类型 | [[跨模态一致性]]与[[功能关联证据]]；单独难以支持因果，除非设计与干预结合 |

## 物理量与被测量之间的关系

每个被试身上测得的仍是各自模态的代理量（电位、血氧、磁场），「同步」是**在分析阶段构造**的量：

```text
被试 A 的时间序列 + 被试 B 的时间序列 → 跨被试统计关系（相关、锁相、包络耦合、有向模型） → 解释为「脑间同步」
```

- **共同刺激**：两人看同一屏幕、听同一段话，会自然产生相似的感觉与注意反应，无需任何相互耦合。
- **共同任务与环境**：同一节奏的动作、同一房间的温度与噪声，都会带来共变。
- **行为与生理伪迹**：说话、咀嚼、点头、呼吸、眨眼、心跳在 EEG 与 fNIRS 上都是强信号，且两人天然相关。
- **行为同步**：动作与言语的同步会机械地带来神经指标的同步。
- **可能的真实耦合**：在上述来源之外，仍可能存在通过感知对方行为而产生的相互影响——这通常是最难分离、也是最有理论价值的部分。

因此「观察到同步」本身不区分以上来源。区分的途径在设计，而不在统计量本身。

三种句式：

| 句式 | 例子 |
| --- | --- |
| 能力陈述 | 超扫描可在毫秒级时间轴上同时记录多人的电生理或血流信号，并计算跨被试的耦合指标 |
| 证据陈述 | 多项研究提示，合作或交流任务中跨被试耦合高于对照条件（提示性；共同输入与伪迹贡献需另行评估） |
| 推断边界 | 跨被试耦合不能读作「两人之间传递了信息」，也不能用作社会关系或临床判断的依据 |

## 分辨率与采样

| 手段 | 时间分辨率 | 空间分辨率 | 运动容忍度 | 备注 |
| --- | --- | --- | --- | --- |
| 多人 EEG | 毫秒 | 厘米级（源定位受限） | 低 | 需硬件级同步与时钟校准 |
| 多人 fNIRS | 秒 | 厘米级、皮层浅表 | 高 | 适合面对面与自然互动 |
| 多人 fMRI | 秒 | 毫米级 | 极低 | 同机或分机采集；分机需时间对齐 |
| 多人行为／眼动 | 毫秒 | 不适用 | 高 | 常作为同步性的独立读数 |

工程要点：

1. **共同时钟**：不同设备之间存在时钟漂移，未校准的漂移会产生虚假的滞后耦合。
2. **刺激呈现同步**：两台设备上的刺激呈现需要一致的时间基准，否则条件间差异可能来自时序误差。
3. **被试间距离与硬件串扰**：EEG 放大器的相互干扰、fNIRS 光路交叉需要显式检查。
4. **数据量与统计功效**：多人数增加设计难度，但样本单位仍是「对」或「组」，不是单个被试。

## 典型实验范式

- **合作与竞争任务**：同一任务中角色对称或不对称，比较不同社会关系下的耦合模式。
- **自然对话与教学**：轮流说话、讲解—学习，行为同步与神经耦合同时记录。
- **联合行动与音乐**：需要精确时间协调的任务。
- **替代与对照设计**：把真实配对与「伪对」（不相关的被试记录拼接）比较，或比较无互动条件。
- **闭环互动范式**：一方看到另一方的实时信号并据此行动，用于加强耦合的因果成分。

## 常见分析

跨被试相关与包络耦合、相位锁定类指标、有向模型（滞后与因果建模）、被试间相似性分析（inter-subject correlation, ISC）、跨被试解码、角色不对称性分析、时间滞后扫描。对应页面：[[功能连接]]、[[事件相关分析]]、[[有效连接与因果建模]]、[[统计推断与多重比较]]。

## 优势

- 社会互动本质上是双人乃至多人的现象，单人记录在设计上无法覆盖。
- 提供同时刻的行为与神经双通道信息，便于核对与解释。
- fNIRS 与 EEG 的可移动性使自然互动范式成为可能。
- 与 [[行为与眼动]] 联合时，行为同步可作为耦合的独立证据。
- 可用于发展与临床场景，观察难以在实验室内人为制造的真实互动。

## 局限

- **同步性的多解释**：共同输入、伪迹、行为同步与真实耦合都可产生同一统计结果，分离依赖设计而非算法。
- **控制条件难以匹配**：真正的「无互动」对照在生态效度上往往不可比。
- **方向性推断脆弱**：时间滞后受采样率、平滑与信噪比影响，方向性结论容易受参数驱动。
- **样本量与统计单位**：配对样本量小、被试内非独立，统计推断易被高估。
- **神经指标缺乏统一验证**：跨被试耦合的生理含义（尤其 fNIRS 与 EEG）尚未有公认的对应机制。
- **角色不对称与个体差异**：领导者—跟随者、亲子、师生之间的不对称会改变耦合强度，跨研究比较困难。
- **不能证明信息传输**：耦合是统计共变，不指示「脑对脑」的直接通路。

## 与其他模态的互补

- 与 [[电生理记录]]：毫秒级的耦合指标，但空间定位与容积传导问题同步放大。
- 与 [[血流与代谢成像]]：空间定位较好，时间慢，适合长时程互动。
- 与 [[行为与眼动]]：行为同步是耦合的独立读数，也是解释的关键。
- 与 [[生理与神经化学]]：心跳与呼吸的共同节律是重要的混淆源，需记录并回归。
- 与 [[神经调控技术]]：结合干预的设计才可能把耦合从相关推向因果。

## 常见误用

1. 把跨被试耦合直接表述为「脑间通信」或「心灵相通」。
2. 不做伪对或替代基线，直接把显著相关解释为互动效应。
3. 用同步强度比较不同任务，而不同任务的共同刺激与运动负荷并不可比。
4. 在言语互动中不处理说话、咀嚼与头动伪迹。
5. 把行为同步当作神经同步的证明（反之亦然）。
6. 在小样本配对设计中忽略多重比较与统计单位问题。
