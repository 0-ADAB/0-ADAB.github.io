# 电生理记录

> 电生理记录测量的是**电荷移动造成的电位差与磁场**，是时间分辨率最高的一类神经活动观测手段；但从电位到「神经活动」之间隔着电极几何、容积传导与源定位三层推断。🌿 扩充中

## 物理量与被测量之间的关系

电生理的因果链从离子流动开始，到记录电极结束：

```text
离子跨膜流动 → 跨膜电流 → 胞外电流密度 → 组织/脑脊液/颅骨/头皮的容积传导 → 电极间电位差（或颅外磁场）
```

- **单细胞/多细胞记录（single-unit / multi-unit recording）**：胞外微电极拾取邻近神经元动作电位引起的胞外电位变化，经阈值或聚类得到放电时刻。测到的是电极附近动作电位的叠加，受细胞类型、电极距离、组织阻抗影响。
- **局部场电位（local field potential, LFP）**：低频成分，主要反映电极附近群体神经元的突触后电流（postsynaptic current）总和，而非放电本身。因此 LFP 幅度更接近「局部输入的同步程度」，不是「放电多少」。
- **皮层脑电（electrocorticography, ECoG）与颅内脑电（intracranial EEG, iEEG）**：电极置于皮层表面或深部，绕过颅骨衰减，信噪比高、空间更局部，但只在临床需要时才可获得。
- **脑电（electroencephalography, EEG）**：头皮电极间的电位差。颅骨与脑脊液使电位衰减并向四周扩散（容积传导, volume conduction），一个电极记录的是大范围皮层源的混合。
- **脑磁（magnetoencephalography, MEG）**：测神经元胞内电流产生的微弱磁场。磁场不受颅骨与脑脊液显著畸变，但主要对切向（tangential）源敏感，且需要磁屏蔽。

三种句式在本页必须分清：

| 句式 | 电生理中的例子 |
| --- | --- |
| 能力陈述 | EEG 可记录毫秒级电位变化；单细胞记录可分辨单个神经元的放电时刻 |
| 证据陈述 | 若某任务后数百毫秒出现头皮电位差异，多项研究提示它与感觉或认知加工的时间进程有关（提示性结论，依赖范式与对照条件） |
| 推断边界 | 头皮电位差异不能推断为「某脑区放电增加」；LFP 幅度变化不等于放电频率变化 |

## 分辨率与采样

| 手段 | 空间范围 | 时间精度 | 采样率量级 | 侵入性 |
| --- | --- | --- | --- | --- |
| 膜片钳 | 单细胞／单通道 | 亚毫秒 | 数 kHz—数十 kHz | 高（离体或急性） |
| 单细胞记录 | 数十—数百 µm | 亚毫秒 | 数十 kHz | 高（动物为主） |
| LFP | 数百 µm—数 mm | 毫秒 | 数百 Hz—数 kHz | 高（动物、iEEG） |
| ECoG／iEEG | 毫米—厘米 | 毫秒 | 数百 Hz—数 kHz | 高（临床机会） |
| EEG | 厘米级（源定位受限） | 毫秒 | 数百—数千 Hz | 无 |
| MEG | 厘米级 | 毫秒 | 数百—数千 Hz | 无 |

1. 采样率必须远高于关心的频段（奈奎斯特限制）。若分析 gamma 频段，低采样与低通滤波会把结论直接限定在带宽之内。
2. 空间与时间是两笔独立的账。时间精度不弥补空间模糊，反之亦然。
3. 电极位置与参考（reference）选择会改变 EEG/iEEG 的波形与极性。参考不是中性的观测选择，换参考等于换了一组观测量。

## 典型实验范式

- **静息态**：闭眼/睁眼、睡眠分期，观察自发振荡的统计结构。
- **事件相关**：重复呈现刺激或要求反应，叠加平均得到事件相关电位/场（ERP/ERF），用锁时性把信号从背景中提出来。
- **振荡范式**：稳态视觉诱发电位（steady-state visual evoked potential, SSVEP）、节律性刺激或电刺激夹带（entrainment），研究相位与频率。

## 常见分析

预处理（滤波、重参考、坏道剔除、伪迹校正）→ 事件相关分析 → 时频分析 → 源定位 → 连接分析 → 解码。对应页面见 [[预处理与伪迹控制]]、[[事件相关分析]]、[[时频分析]]、[[源定位]]、[[功能连接]]、[[解码与机器学习]]。

分析链上每一步都引入假设：滤波改变波形与时序；平均假设响应跨试次稳定；源定位依赖头模型与源模型；连接分析必须处理容积传导造成的虚假零延迟耦合。因此报告结果时需要同时交代这些选择，见 [[分析一致性原则]]。

## 优势

- 时间分辨率在非侵入手段中最高，适合毫秒级时序、相位与振荡问题。
- 直接测量电／磁活动，代理链比血流代谢短。
- iEEG/ECoG 在人类可获得高信噪比、毫米级的直接记录。

## 局限

- **容积传导**：头皮 EEG、iEEG 相邻电极可能看到同一个源，「同步」容易被高估。
- **参考依赖**：结论依赖参考电极的选择，跨研究比较需谨慎。
- **逆问题不唯一**：头皮到皮层的源定位没有唯一解，只能给出与数据一致的解，而不是实测的解剖定位。
- **覆盖偏差**：iEEG 电极位置由临床决定，取样不随机，向一般人群外推受限。
- **单细胞覆盖极小**：同时记录的细胞数有限，且难以确认细胞类型与投射靶区。
- **对肌肉与运动敏感**：EEG/MEG 对肌电、眼球运动、心跳敏感，伪迹常与神经信号高度重叠。
- **幅度不是放电率**：群体同步程度、源方向、组织导电率都会改变幅度。

## 与其他模态的互补

- 与 [[血流与代谢成像]]：时间精度 × 空间精度，是最常见的组合；但两者测的不是同一个量，联合分析只能部分弥补。
- 与 [[行为与眼动]]：行为时间戳提供事件锚点，也提供独立的功能输出。
- 与 [[神经调控技术]]：刺激—记录联用（如 TMS-EEG、DBS-LFP）把观测与干预放在同一时间轴上。

组合的方法论代价见 [[多模态融合]]。

## 常见误用

1. 把 ERP 成分直接当作某个心理过程的指标（成分是多个源的叠加，功能含义依赖范式和对照条件）。
2. 把头皮记录到的同步当作脑区间真实通信（未控制容积传导与共同参考）。
3. 把源定位结果当作已验证的解剖位置（它是模型依赖的解，不是测量结果）。
4. 用幅度差异推断放电率差异（两者不是同一物理量）。
5. 把临床样本 iEEG 上的发现直接外推到健康人群。
6. 忽略分析自由度（滤波、参考、时间窗、电极选择）对结论的影响，导致不可重复。
7. 把单细胞或 LFP 层面的机制直接推广到全脑成像信号，或将 LFP 与 fMRI 的同一区域活动等同为同一过程。
