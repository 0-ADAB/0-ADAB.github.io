# 测量模态

> 没有任何手段能直接"看到脑活动"。每种模态测的都是代理量——电位差、血氧、钙浓度、眼动、行为反应。**理解模态，就是理解这层代理关系的距离。**

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 分子 → 全脑 |
| 时间尺度 | 亚毫秒 → 老化 |
| 相关模态 | 全部 |
| 主要方法 | 见各模态页的「常见分析」 |
| 证据类型 | 各类证据都源于模态 |

## 选择时必须确认的四件事

1. **物理量到神经活动的距离** — 电生理接近、血流代谢间接、行为更远。
2. **分辨率与尺度的匹配** — 用秒级手段研究毫秒过程，或反过来，都会失败。
3. **能得出什么类型的证据** — 记录类手段多产关联证据，干预类才可能产因果证据。
4. **不能回答什么** — 每页的「局限」段落。

## 模态之间的组合

单模态的边界只能靠另一模态部分弥补，但组合不会自动产生整合：

- 时间 + 空间：[[电生理记录]] × [[血流与代谢成像]]
- 活动 + 结构：[[血流与代谢成像]] × [[结构与扩散成像]]
- 神经 + 行为：[[电生理记录]] × [[行为与眼动]]
- 观测 + 干预：任意记录模态 × [[神经调控技术]]

组合的方法论问题见 [[05-方法/多模态融合|多模态融合]]。
