# 资源索引

> 这里不复制文档，只回答：**这个工具适合什么数据、什么任务、什么水平，以及从哪里开始。**

## 定位

| 坐标 | 取值 |
| --- | --- |
| 内容 | 外部工具、数据、教程、规范的索引 |
| 收录原则 | 只做适用性与入口说明，不转载内容 |
| 面向对象 | 需要落地实现的研究者 |
| 维护 | 定期核查可达性与维护状态 |

## 条目格式

每个条目至少包含：

| 字段 | 说明 |
| --- | --- |
| 名称 | 官方名称 |
| 类型 | 软件 / 数据集 / 教程 / 规范 |
| 适用数据 | 例如 EEG、MEG、fMRI、行为 |
| 适用任务 | 例如预处理、源定位、连接分析 |
| 难度 | 入门 / 中等 / 进阶 |
| 平台 | Python / MATLAB / R / 图形界面 |
| 官方地址 | 一手来源 |
| 维护状态 | 活跃 / 稳定 / 停滞 |

## 挑选工具的四条准则

1. **优先官方**：官方文档与官方教程优先于二手教程。
2. **看维护状态**：多年未更新的工具，其算法可能已被替代，或依赖已不可安装。
3. **看可复现性**：是否能固定版本、导出参数、生成可重跑流程。
4. **看社区**：问题能否被检索到，通常比功能清单更能决定能否走下去。
