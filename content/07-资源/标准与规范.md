# 标准与规范

> 规范不是形式主义。它的作用是把"我们做了什么"变成**别人可以核查、可以重跑、可以比较的陈述**。缺了这一步，方法部分写得再长也无法被检验。 🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 内容 | 报告标准、数据格式规范、注册与共享规范、术语约定 |
| 解决的问题 | 可核查性、可比较性、可重跑性、合规性 |
| 使用时机 | 设计阶段、分析阶段、投稿前后、数据共享时 |
| 收录原则 | 只说明规范解决什么问题与何时用，不复制清单正文 |
| 免责 | 条款与版本以各规范官方页面为准 |

## 一、五类规范，各自解决什么问题

```text
报告标准   →  让读者知道你到底做了什么（方法透明度）
数据格式   →  让数据和流程能被机器读懂与复用（互操作性）
预注册     →  让假设与分析的先后顺序能被验证（防事后解释）
共享与伦理 →  让数据能合法、安全地被再使用（合规与隐私）
术语与本体 →  让同一个词指向同一个东西（可比性）
```

## 二、报告标准

| 规范类型 | 解决的问题 | 什么时候用 | 入口 |
| --- | --- | --- | --- |
| 影像数据分析与共享最佳实践类清单（如 COBIDAS 类） | 采集、预处理、统计与共享信息的最小报告集合 | 设计阶段就先看，写方法部分时逐条核对 | 相关学会官方页面 |
| 观察性研究报告规范 | 人群与队列研究报告的完整性与一致性 | 撰写队列与观察性研究时 | 各规范官方页面（如 STROBE 类） |
| 临床试验报告规范 | 干预类研究的设计、流程与结果报告 | 涉及干预或调控的研究 | 各规范官方页面（如 CONSORT 类） |
| 系统综述与元分析报告规范 | 检索、筛选与合并流程的可复现 | 做综述或元分析时 | 各规范官方页面（如 PRISMA 类） |
| 动物研究报告规范 | 动物实验的报告完整性与可重复 | 动物研究 | 各规范官方页面（如 ARRIVE 类） |

共同点：**它们不判断你的结论对不对，只判断你披露的信息够不够**。方法部分缺参数、缺排除标准、缺校正方式，是最常见的被质疑点。

## 三、数据组织与格式

| 规范 | 解决的问题 | 什么时候用 |
| --- | --- | --- |
| BIDS（脑影像数据结构） | 统一目录命名、元数据字段与事件标注 | 采集完成后立刻整理，越早越好 |
| BIDS 扩展提案 | 新模态与新数据类型如何纳入 BIDS | 你的数据类型尚未被核心规范覆盖时 |
| 交换格式与原始格式（如 NIfTI、DICOM 类） | 影像的通用读写与元数据保留 | 数据导出、转换与归档 |
| 衍生数据处理约定 | 预处理输出如何命名与标注来源 | 使用流水线生成衍生数据后 |
| 数据字典与 README 约定 | 字段含义、单位、缺失值编码 | 任何交付给他人的数据集 |

BIDS 的现实收益很直接：**大量官方流水线只接受 BIDS 输入**。不整理格式，就等于放弃了这些工具；见 [[分析平台]] 与 [[质控与可重复性]]。

## 四、预注册与注册报告

| 类型 | 解决的问题 | 什么时候用 |
| --- | --- | --- |
| 研究预注册 | 事先固定假设、设计与分析计划 | 在看过数据之前；越早越有价值 |
| 注册报告 | 在数据收集前获得对设计与分析的计划评审 | 期刊支持时，可降低发表偏倚 |
| 临床试验注册 | 干预类研究的公开登记与结果报告义务 | 涉及人类干预时，常为强制要求 |
| 系统综述注册 | 综述方案的事先固定 | 开展综述之前 |
| 分析计划补充说明 | 偏离预注册时的透明说明 | 计划变更后必须写明改了什么、为什么 |

关键区分：预注册**不禁止探索性分析**，它要求你区分"事先假设的验证性分析"与"事后发现的探索性分析"，并分别报告。模糊这两者，是 [[解释边界与常见错误]] 的典型来源。

## 五、数据共享与隐私伦理

| 主题 | 关键问题 | 什么时候处理 |
| --- | --- | --- |
| 知情同意范围 | 同意书是否允许数据共享与再分发 | 采集之前，事后通常无法补救 |
| 去标识化与面部信息处理 | 结构像可能重建面部，需做去标识处理 | 共享前 |
| 数据使用协议与再分发规则 | 谁能用、用于什么、能否转给第三方 | 接收与转交数据时 |
| 隐私法规与伦理审查 | 适用法律、机构审查与豁免条件 | 立项与申请阶段 |
| 开放科学原则（如 FAIR 类） | 数据可发现、可访问、可互操作、可复用 | 数据发布与归档时 |
| 敏感数据的分级访问 | 完全开放、受控访问、仅限平台内分析 | 共享方案设计时 |

一句话原则：**伦理与隐私的决定必须早于采集**。等数据到手再考虑共享范围，通常只能选择"不共享"。

## 六、术语与本体一致性

| 主题 | 解决的问题 | 使用场景 |
| --- | --- | --- |
| 解剖命名与图谱体系 | 同一解剖结构在不同图谱中名称与边界不一致 | 报告脑区结果、跨研究比较时 |
| 脑图谱与分区约定 | 分区方案决定所有体素级结果的解读 | 定义感兴趣区与网络节点时 |
| 认知构念与任务本体 | 同一任务名称在不同研究中含义不同 | 检索、元分析与跨研究汇总时 |
| 术语表与缩写约定 | 缩写歧义（如多种同名指标）导致误读 | 写作与项目文档中 |
| 单位与量纲约定 | 功率、幅度、效应量的单位不一致 | 报告数值与作图时 |

本站同样受此约束：[[09-关于/内容模型]] 中的标签体系就是为了避免同义词分裂；命名争议可参见 [[皮层分区]] 与 [[大尺度网络]]。

## 七、什么时候用哪一条

| 你的处境 | 优先处理 |
| --- | --- |
| 准备采集数据 | 知情同意范围、BIDS 结构、预注册 |
| 数据刚到手 | BIDS 整理、数据字典、随机种子与参数记录 |
| 正在分析 | 分析计划对照、多重比较校正说明、质控记录 |
| 准备投稿 | 报告清单逐条核对、术语与图谱版本说明 |
| 被要求共享数据 | 去标识化、使用协议、分级访问方案 |
| 审阅他人工作 | 报告清单作为核查表，而非攻击工具 |
