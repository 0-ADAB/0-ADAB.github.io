# 证据与推理

> **我们为什么相信一个结论？在什么条件下能相信到什么程度？**

这一轴是整个森林的**研究质量控制层**，同时容纳证据质量概念、研究设计、科学主张及特定证据节点。

## 推理与证据地图

| 主题 | 关注点 |
| --- | --- |
| 研究设计 | 观察、干预、纵向和跨物种设计；这些可以交叉组合 |
| 推断类型 | 描述、关联、预测、因果效应、机制 |
| 证据质量 | 测量有效性、统计与不确定性、**可重复性**、证据汇合 |
| 推断边界 | 泛化与外推、定位不等于功能、代理指标不等于直接神经活动 |

- [[04_证据与推理轴/证据质量/可重复性|可重复性]]：区分计算可复现、独立研究重复及跨情境泛化。

## 从问题到结论

**科学问题 → 明确主张 → 研究设计 → 观察结果 → 独立验证 → 证据汇合 → 带范围限定的结论**

这是一条逻辑路径，而不是要求每个步骤都独立建立目录。

## 证据分层原则

- **观察结果**：仪器、行为或数据记录实际展示的结果。
- **研究解释**：作者据此提出的统计、因果或机制推断。
- **独立验证**：其他数据、样本、方法和研究团队检验结果。
- **当前结论**：综合一致证据、反例和适用边界后的审慎表述。

共识等级必须人工确认；不能按被引频次、显著性或链接数量自动提升。

## 两种核心节点

- **Claim（科学主张）**：表达一条明确、可检验、限定适用范围的判断。
- **Evidence（证据）**：说明一项研究/分析观察到了什么，对哪些主张构成何种支持或限制。

对跨领域证据质量概念（如“可重复性”）使用 **Concept 模板**，而不是强行归入研究对象轴。
