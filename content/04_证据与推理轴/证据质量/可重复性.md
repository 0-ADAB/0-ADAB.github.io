# 可重复性

> **一句话理解：** 可重复性不是“某篇研究得到了显著结果”，而是一个研究发现的计算过程能否被核查、以及其科学结论能否在新的研究中得到一致支持。

## 快速理解

在日常中文中，“可重复性”常被用来涵盖多个问题。为避免歧义，本页采用美国国家科学院等机构 2019 年报告中的三项区分：

| 要检查的事 | 英文术语 | 核心判据 |
| --- | --- | --- |
| 使用原始数据和分析流程，能否再次得到一致的计算结果？ | **Reproducibility**（计算可复现性） | 相同原始数据、代码、分析条件 |
| 使用**新数据**研究同一科学问题，能否获得统计上相容的结论？ | **Replicability**（独立重复验证） | 独立实验或新样本、考虑效应与不确定性 |
| 换物种、人群、任务或环境，结论是否仍适用？ | **Generalizability**（泛化性） | 新情境下的外推与边界 |

这些英文术语在不同领域并不总按同一方式使用，因此阅读文献时要检查作者的**操作性定义**。\[来源 1]

## 为什么对脑科学重要？

脑科学研究常跨越**神经元—环路—行为**等不同层级，还面临生物个体差异、间接测量、分析选择以及跨实验室操作差异。一个结果的可核查性、独立重复验证程度和跨尺度适用性，需要分别判断，不能以一种指标替代全部。

针对神经科学领域，Button 等人在方法学分析中指出：**统计功效不足**会妨碍真实效应被检测，同时也会削弱显著性发现的可信度。这是方法学风险分析，**不是**“某个脑科学领域普遍无法重复”的直接测量结果。\[来源 3]

## 三种检验分别意味着什么？

### 1. 计算可复现性

评价原始数据、预处理规则、软件版本、参数与分析代码是否足以重新生成文中的分析结果。数据或代码未公开时，通常只能说**尚无法独立验证**，不能仅据此断言结果为假。\[来源 1]

### 2. 独立重复验证

使用新的样本或实验，检验同一科学问题中的结果是否一致。应结合**效应方向、效应大小、置信区间、测量误差和研究设计差异**判断；不能只凭“第二次 p 值是否仍小于 0.05”得出成功或失败的结论。\[来源 1]

### 3. 跨情境泛化

例如，小鼠某神经环路中的结果能否推广到其他品系、行为任务、脑状态或人群。**重复验证成功并不自动证明可以跨物种或临床外推**。\[来源 1]

## 一个可操作的研究核查顺序

1. **明确主张**：需要检验的是效应、预测还是机制？其适用的物种、脑区、任务与条件是什么？
2. **查核原始研究**：是否交代实验单位、样本量、随机化、盲法、纳排标准及分析方法？
3. **核验分析**：数据、代码和预处理步骤是否足以复算，是否说明异常值、排除与多重比较？
4. **寻找独立研究**：有无新样本、新实验室、预注册验证或系统证据综合？
5. **比较证据一致性**：不能只数阳性研究，应综合效应大小、置信区间、异质性及负结果。
6. **给出带边界的结论**：明确哪些条件获得支持，哪些只是合理推测，哪些还缺少证据。

上述步骤是综合 \[来源 1、2、4] 的**实践性检查清单**，并非某一份指南逐项规定的统一评分系统。

## 针对脑科学研究的特殊检查

| 情形 | 特别需要确认 |
| --- | --- |
| 电生理或成像数据 | 预处理、剔除规则、伪迹控制、统计单位与可共享分析流程 |
| 动物实验与环路干预 | 实验单位、随机化、盲法、样本量说明、操作细节、目标参与验证 |
| 跨物种研究 | 细胞类型与解剖同源性、行为任务可比性、生态有效性 |
| 临床神经科学 | 诊断和纳入标准、样本异质性、预定义终点、外部验证 |

美国 NINDS 关于严谨研究设计的指导特别强调随机化、盲法、纳排标准、报告阴性结果、目标验证以及独立重复计划。\[来源 2]

对于动物研究，ARRIVE 2.0 提供了透明报告的项目清单，有助于评估和复现实验流程；**遵守报告清单本身不等于证明结论已经独立重复成功**。\[来源 4]

## 当前较稳定的认识

- 科学研究应清楚披露数据处理、分析方法和相关不确定性，便于他人检查结论。\[来源 1、2]
- 计算可复现、独立重复与泛化分别回答不同问题，评价一项研究时应区分。\[来源 1]
- 样本量、统计功效、偏倚控制与透明报告关系到研究结果的可解释性和后续验证价值。\[来源 2、3、4]

这些是**研究方法学层面的共识与建议**，不能替代对某项特定神经科学结论的独立重复文献检索。

## 争议与推断边界

- **术语分歧**：不同学科可能交换 _reproducibility_ 与 _replicability_ 的叫法，必须先确认定义。\[来源 1]
- **重复不一致不等于原研究一定错误**：可能涉及研究功效、测量误差、隐藏条件或真实异质性；需要对差异作系统分析。\[来源 1]
- **重复成功不自动构成机制证据**：发现稳定的相关性，仍不必然解释神经机制或因果方向。
- **报告完整不等于结果成立**：数据开放、注册或规范报告提高可核查性，但不直接保证效应真实。
