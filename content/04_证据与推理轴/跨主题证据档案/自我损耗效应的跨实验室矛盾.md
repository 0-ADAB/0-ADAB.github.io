# 自我损耗效应的跨实验室矛盾

> **观察到什么：** Baumeister 等（1998，J Pers Soc Psychol）提出并论证「自我控制依赖有限资源」的力量模型：先前的自控努力会暂时耗尽资源，使后续自控表现下降。该模型在二十余年文献中反复报告中等量级效应，但 Carter 与 McCullough（2014，Front Psychol）的元分析偏倚检验、Hagger 等（2016，Perspect Psychol Sci）23 实验室注册重复报告与 Vohs 等（2021，Psychol Sci）36 实验室范式化重复的确认性检验，都指向同一方向：按严格标准执行时效应接近零。

## 原始研究信息

本节点汇集从原始模型到两项独立大规模重复的关键文献，以及原始作者阵营的方法学回应。

- **原始模型**：Baumeister 等（1998，J Pers Soc Psychol）系统提出力量模型并报告支持性实验序列。
- **偏倚检验**：Carter 与 McCullough（2014，Front Psychol）对该文献做元分析偏倚检验。
- **注册重复报告（RRR）**：Hagger 等（2016，Perspect Psychol Sci）由 23 个实验室按标准化序列任务协议执行预注册重复，合计 2,141 人。
- **原始阵营回应**：Baumeister 与 Vohs（2016，Perspect Psychol Sci）对 RRR 的方法与推断提出批评。
- **范式化多实验室重复**：Vohs 等（2021，Psychol Sci）由 36 个实验室、合计 3,531 人，用事先固定的「范式化」方案执行确认性检验。

## 实验设计与对象

**原始范式。** 力量模型的典型检验采用序列任务设计：被试先完成一项耗费自控的任务（如抑制注意、抵抗诱惑），再完成第二项自控任务（如难题坚持、斯特鲁普干扰控制），比较两组表现差异 (Baumeister et al., 1998, J Pers Soc Psychol)。这类设计的关键脆弱点包括：任务间迁移难以界定、需求特征与主试期望可进入第二项任务、实验室间操作细节不统一。

**两项重复的设计。** Hagger 等（2016，Perspect Psychol Sci）采用标准化协议（基于 Sripada 等的序列任务程序）并在各实验室预注册分析计划；Vohs 等（2021，Psychol Sci）采用「范式复制」方法——在数据收集前由领域研究者共同确定被检验的范式与程序，各实验室只执行不作个案调整，从而把「程序差异」从「效应是否存在」中分离。两项设计的共同点是：确认性分析计划在结果已知前固定，且样本量按检测原始文献平均效应量设计。

## 核心结果

**偏倚检验。** Carter 与 McCullough（2014，Front Psychol）对该文献的元分析显示，观察到的效应分布与发表偏倚的模拟一致；在考虑偏倚后，损耗效应的估计接近零。这属于间接证据：它质疑的是文献整体的可信度，而非任何单项实验。

**注册重复报告。** Hagger 等（2016，Perspect Psychol Sci）的 23 个实验室、2,141 人的元分析得到很小的效应，95% 置信区间包含零（d ≈ 0.04），远低于该文献此前报告的平均效应量。这是该效应第一项大规模预注册直接重复。

**范式化重复。** Vohs 等（2021，Psychol Sci）的 36 个实验室、3,531 人确认性检验同样不显著（d = 0.06）；以知情先验（δ = 0.30）做贝叶斯元分析，数据在零假设下的可能性约为备择假设的 4 倍。仅当**忽略预设剔除标准**的全样本探索性分析中才出现小的显著效应（d = 0.08）；探索性调节分析提示报告更疲劳的被试效应更大，而特质自控、意志信念与行动导向均无调节作用。

**原始阵营的回应。** Baumeister 与 Vohs（2016，Perspect Psychol Sci）认为 RRR 的失败不应被解读为效应不存在，理由包括重复方案对原始程序的偏离、被试群体差异与单次重复的抽样波动；这一回应没有提供新的重复数据，属于对同一批证据的推断分歧。

## 与哪些科学主张有关？

本节点为跨主题证据档案，是「预注册多实验室重复如何裁决文献争议」的判例。相关 Claim 节点尚未创建，此处以文字列出：

- **「自我控制是有限资源，使用后暂时耗尽」**：原始文献的中等效应量未能在两项独立大规模重复中复现，属**被显著削弱**。
- **「该文献整体的阳性结果可由发表偏倚解释」**：Carter 与 McCullough（2014，Front Psychol）提供支持性间接证据，属**较可能但非直接证明**。
- **「效应存在于特定亚群或特定程序变体中」**：Vohs 等（2021，Psychol Sci）的探索性调节分析提示疲劳相关亚群，属**假说级**，需要预注册验证。
- **「重复失败源于方案偏离」**：Baumeister 与 Vohs（2016，Perspect Psychol Sci）的主张，属**有争议**；范式化方法正是为回应此类质疑而设计，其结果仍为零。

## 证据质量

- **两项独立大规模重复互相印证。** Hagger 等（2016，Perspect Psychol Sci）与 Vohs 等（2021，Psychol Sci）由不同团队、不同协议、不同样本量执行，确认性结果一致接近零；这不是单次重复的抽样波动可以解释的。
- **方法学设计针对既往弱点。** 预注册分析计划、标准化协议、范式化方法分别处理了选择性报告、程序偏离与实验室差异三类质疑，证据强度高于一般的「重复失败」叙事。
- **仍有解释空间。** 两项重复各自只检验了特定范式；原始文献的效应若高度依赖特定任务组合或人群，重复失败与被试群体、任务选择的关系仍无法完全排除 (Baumeister & Vohs, 2016, Perspect Psychol Sci)。
- **领域尚无新共识。** 重复结果发表后，学界对「损耗效应是否存在」仍有分歧，近年文献中既有引用重复结果的，也有继续报告阳性结果的；本节点不宣称争议已解决。

## 不能推出什么？

1. **不能推出「自控不存在」或「自我控制研究整体无效」。** 被重复否定的是一般意义上的损耗效应量级；自控的干预效果、个体差异与临床意义是不同问题。
2. **不能把探索性显著结果（d = 0.08）当作效应存在的证据。** Vohs 等（2021，Psychol Sci）明确将其标为探索性；确认性框架下的结论是零。
3. **不能把贝叶斯结果解读为「证明零假设为真」。** 「数据在零假设下可能性约 4 倍于备择」是在特定先验下的模型比较，不是效应绝对不存在的证明。
4. **不能据本案例推断其他心理学效应的可重复性。** 本档案只覆盖自我损耗这一效应线。
