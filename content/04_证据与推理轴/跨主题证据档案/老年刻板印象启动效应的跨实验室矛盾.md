# 老年刻板印象启动效应的跨实验室矛盾

> **观察到什么：** Bargh、Chen 与 Burrows（1996，J Pers Soc Psychol）的经典实验中，完成老年相关词汇乱词任务的被试离开走廊时行走变慢。此后更严格的重复得到方向不一的结果：Doyen 等（2012，PLoS ONE）的第一个实验用自动化计时与更大样本**未能复现**该效应，第二个实验中效应**只在主试预期效应出现时**才出现；Cesario 等（2006，J Pers Soc Psychol）的系列研究则显示该效应只在对老年人持积极态度的被试中出现。三条证据线合起来表明：原始研究报告的效应要么依赖未被控制的实验者因素，要么依赖被试的态度条件，而不是稳定的自动激活。

## 原始研究信息

本节点汇集原始研究与两项关键后续研究，构成「阳性—阴性—条件性阳性」的完整证据链。

- **原始研究**：Bargh、Chen 与 Burrows（1996，J Pers Soc Psychol）报告了感知觉特质与社会刻板印象激活对行为的直接影响；其中老年刻板印象启动后行走变慢的结果被引为社会启动研究的标志性发现。
- **直接重复**：Doyen、Klein、Pichon 与 Cleeremans（2012，PLoS ONE）发表了对该实验的重复，包含自动化计时与主试预期操纵两个关键改进。
- **条件性证据**：Cesario、Plaks 与 Higgins（2006，J Pers Soc Psychol）用系列实验论证社会类别启动效应取决于被试对该类别的态度，并据此提出「有动机的互动准备」解释。

## 实验设计与对象

**原始设计。** 被试完成句子乱词任务（材料含老年相关词或中性词），随后在一段走廊中的行走时间被隐蔽测量。单个实验的样本量在数十人量级；这是 1990 年代中期社会心理学研究的典型规模。该设计的潜在敏感点包括：样本小、行走时间依赖主试的起止信号、缺乏主试盲法 (Bargh et al., 1996, J Pers Soc Psychol)。

**Doyen 等的设计。** 实验一改用自动化计时并加大样本，重复原始流程；实验二操纵主试信念——半数主试被告知「启动会让被试走得更慢」，半数被告知相反。被试与计时对主试条件盲 (Doyen et al., 2012, PLoS ONE)。

**Cesario 等的设计。** 系列研究测量被试对目标类别的态度，检验启动效应是否只出现在态度与刻板印象方向一致的被试中 (Cesario et al., 2006, J Pers Soc Psychol)。

## 核心结果

**原始结果。** 老年启动组被试的行走时间显著长于中性启动组，作者将其解释为刻板印象的自动行为激活 (Bargh et al., 1996, J Pers Soc Psychol)。

**重复结果（实验一：失败）。** 尽管使用自动化计时与更大样本，Doyen 等的实验一未显示启动效应 (Doyen et al., 2012, PLoS ONE)。

**重复结果（实验二：效应随主试预期出现）。** 当主试预期启动会让被试走得更慢时，观察到了行走速度效应；当主试预期相反方向时则没有。作者据此认为，该效应至少部分由实验者预期而非（或不只是）被试的自动激活驱动；事后访谈还提示部分被试觉察到了启动材料的存在 (Doyen et al., 2012, PLoS ONE)。值得注意的是，Doyen 等自己的结论是「无意识行为启动是真实的，但其机制与通常假设不同」——他们否定的不是启动现象本身，而是对原始结果的机制解读。

**条件性结果。** Cesario 等（2006，J Pers Soc Psychol）发现社会类别启动（含老年启动）只在被试对该类别持积极态度时产生与刻板印象一致的行为改变，持消极态度者出现相反方向；作者据此主张启动的作用是为互动做准备，其方向由被试既有态度决定。

## 与哪些科学主张有关？

- **「老年刻板印象启动能自动改变行为（强版本）」**：原始研究支持，但严格重复失败或条件化，属**被削弱**。
- **「无意识社会启动现象完全不存在」**：Doyen 等（2012，PLoS ONE）与 Cesario 等（2006，J Pers Soc Psychol）的结果都不支持这一强否定；启动效应可能存在但依赖条件，属**争议未决**。
- **「概念重复成功可以代替直接重复」**：本案例中大量概念复制的存在与直接重复的失败并存，是区分两类「重复」的经典教材案例，属**已被领域讨论接受**。

## 证据质量

- **直接重复已经发表，且包含了方法学改进。** 自动化计时与更大样本本应提高而非降低检出率，因此实验一的阴性结果不是「功效不足」可以简单解释的 (Doyen et al., 2012, PLoS ONE)。
- **原始研究的效应量报告与样本规模不匹配。** 数十人样本下的行为时间差异，在多重比较与选择性报告盛行的发表环境中容易被夸大；这一点与整个社会启动文献的元分析争议一致。
- **存在未正式发表的重复尝试。** 学术圈流传过若干未经同行评议的失败复现稿件（如 Pashler 等 2011 年关于老年启动的未发表尝试），因无法核验其设计与数据，本节点不将其纳入证据评估，仅在此说明「文献表之外的未发表材料不能作为证据」这一处理原则。
- **发表偏倚的方向性问题。** 阳性结果（原始研究与概念复制）大量发表，失败尝试多不发表，这使「文献中多数研究支持该效应」的统计失去意义。

## 不能推出什么？

1. **不能从概念复制的数量推断直接重复成功。** 「许多研究显示了启动效应」与「原始实验能否被重复」是两个问题；本案例中前者成立而后者存疑。
2. **不能把 Doyen 等的实验二解读为「复现成功」。** 效应只在主试预期方向出现，这恰恰是实验者效应的证据，而不是启动效应稳健的证据 (Doyen et al., 2012, PLoS ONE)。
3. **不能从本案例否定全部社会启动研究。** 本档案只评估老年行走速度这一具体效应；其他启动效应的证据强度需要各自独立评估。
4. **不能据此评判原始研究者的意图。** 可重复性失败的方法学原因（样本量、盲法缺失、分析灵活性）与科研不端是两个问题，本节点只讨论前者。
