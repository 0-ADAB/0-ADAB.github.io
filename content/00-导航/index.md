# 🧭 导航层

> 这一层不介绍脑科学，只回答一个问题：**你现在想找什么，该从哪个门进去。**

🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 所属层 | L0 导航层 |
| 回答什么 | 从哪进入、怎么横向跳转 |
| 不回答什么 | 不承载研究内容，不解释概念 |
| 面向读者 | 第一次到站的人、以及需要快速定位的老读者 |
| 依赖 | 世界层、观测层、证据层的全部页面 |

## 五个入口

同一份内容可以从五个方向进入。选哪个都行，它们是同一张网的不同切法。

### ① 按层进入 —— 从"我想知道什么"开始

| 你的问题 | 入口 |
| --- | --- |
| 脑科学在研究哪些对象？ | [[01-尺度/index\|尺度]] · [[03-现象/index\|现象]] · [[04-结构/index\|结构]] |
| 人脑到底有哪几种可观测信号？ | [[00-导航/信号全景\|信号全景]] |
| 数据怎么变成结果？ | [[05-方法/index\|方法与分析]] |
| 这个结论可靠吗、做到什么程度了？ | [[06-证据/index\|证据与推断]] · [[10-结论/index\|当前认识]] |
| 我该怎么做完一整条链路？ | [[08-设计/index\|研究路径]] |

### ② 按坐标进入 —— 六个坐标轴

任何一页都能被六个坐标定位，沿任一轴横向跳转。

| 坐标轴 | 入口 |
| --- | --- |
| 空间尺度 | [[01-尺度/空间尺度\|分子 → 突触 → 神经元 → 回路 → 脑区 → 网络 → 全脑 → 群体]] |
| 时间尺度 | [[01-尺度/时间尺度\|毫秒 → 秒 → 分钟 → 发育 → 老化]] |
| 测量模态 | [[02-模态/index\|电生理 · 血流代谢 · 结构扩散 · 调控 · 行为眼动 · 生理化学 · 分子遗传 · 多人]] |
| 现象与功能 | [[03-现象/index\|感知 · 运动 · 注意 · 记忆 · 语言 · 决策 · 情绪 · 社会 · 意识 · 临床]] |

### ③ 按标签进入

每页 frontmatter 带跨维度标签，点标签即进入标签总览页，可跨类型检索。标签分六族：

```text
层/     L0 导航 · L1 世界 · L2 观测 · L3 证据
类型/   尺度 · 模态 · 现象 · 结构 · 方法 · 证据 · 结论 · 资源 · 设计 · 导航
尺度/   空间/… 时间/…
模态/   电生理 · 血流代谢 · 结构扩散 · 调控 · 行为眼动 · 生理化学 · 分子遗传 · 多人
证据/   结构 · 功能 · 动态 · 因果 · 计算 · 一致性 · 边界
```

标签是**交叉**用的：`模态/电生理` 会同时命中尺度页、方法页和证据页，而不只是模态页。

### ④ 按网络视图进入

Quartz 自带的关系图谱把全站页面画成一张网，适合发现"我没想到要看的相邻页面"。

- 进图谱后先找度数最高的节点，它们通常是坐标轴首页和模态页；
- 图谱反映的只是**站内链接**，不反映脑解剖连接——这两件事不要混淆。

### ⑤ 按检索进入 —— 搜索与词云

- **搜索框**：支持中英文关键词，可直接搜模态名、方法名、脑区名、术语缩写。
- **词云**：按标签权重生成，用来发现站内的高频主题，以及**应当有页面却还没写**的概念（词云与 [[00-导航/视图与检索|检索视图]] 联动）。
