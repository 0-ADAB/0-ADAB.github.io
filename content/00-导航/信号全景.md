# 信号全景

> 人脑没有任何一种信号是「神经活动」本身：能测到的只是电位、磁场、血氧、放射性计数、光子、声波、分子浓度与行为输出。这一页把它们排成一张矩阵，横向回答**每类信号离神经活动隔了几层、能测到什么、测不到什么**。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 分子 → 突触 → 神经元 → 回路 → 脑区 → 网络 → 全脑 → 群体 |
| 时间尺度 | 亚毫秒 → 毫秒 → 秒 → 分钟 → 发育 → 老化 |
| 相关模态 | 全部（本页是 [[02-模态/index\|测量模态]] 的横向总入口） |
| 相关现象 | 全部（现象决定需要哪类信号，而不是反过来） |
| 相关结构 | 全部（结构页给出观测对象与解剖约束） |
| 主要方法 | [[05-方法/多模态融合\|多模态融合]]、[[05-方法/源定位\|源定位]]、[[05-方法/预处理与伪迹控制\|预处理与伪迹控制]] |
| 证据类型 | 本页只分类信号；某信号能支持什么推断见 [[06-证据/index\|证据与推断]] |

## 三层代理距离

先分类，再比较。全部信号按「到神经活动的层数」分三层：

| 层 | 定义 | 信号家族 | 能支持的最强推断 |
| --- | --- | --- | --- |
| **直接测量** | 测的就是神经电活动的产物，中间只隔物理传导 | 电（单细胞 / LFP / ECoG / iEEG / EEG）、磁（MEG / OPM-MEG） | 时间动态、关联；配合扰动可到因果 |
| **一阶代理** | 测的是紧邻神经活动的生理量，需经过一个明确的生理耦合环节 | 血流血氧（fMRI / fNIRS）、代谢灌注（PET / ASL / MRS）、自主与外周生理、行为输出 | 功能关联、时间进程；因果推断依赖设计 |
| **多级推断** | 测的是组织、分子或状态的性质，需叠加多个模型假设 | 结构扩散（sMRI / dMRI / 定量 MRI）、化学分子（受体 PET / 微透析 / 遗传表达）、主观报告与量表 | 结构、化学与状态约束；不能单独支持动态 |

三层不可互推：直接测量层给不出化学信息，多级推断层给不出毫秒时序。换层必须重新论证。

## 测量空间的硬约束

1. **空间精度与时间精度互相牺牲**：非侵入手段无法同时取得毫米与毫秒；两者兼得目前只能靠侵入性记录或临床机会，见 [[02-模态/模态比较|模态比较]]。
2. **每种信号都有自己的时间常数**：血流动力学响应以秒计，瞳孔与自主信号以百毫秒—秒计，电与磁信号以毫秒计。低于该常数的差异不是噪声，而是该信号的**物理不可达区**。
3. **采样率不等于过程分辨率**：外周信号可以采到千赫兹，但背后的生理过程仍以秒计；把采样率当分辨率会系统性高估结论精度。
4. **信号强度不是神经量**：电位幅度、BOLD 幅度、计数率都不等于放电率；幅度同时受几何、方向、组织与增益影响。
5. **代理距离决定可支持的推断类型**：距离越远，需要的前提假设越多，能承载的推断越弱。这也是 [[06-证据/index|证据与推断]] 的分层依据。
6. **观测 ≠ 因果**：除扰动类手段外，任何信号都不能单独确立必要性；观测与扰动必须配对设计。
