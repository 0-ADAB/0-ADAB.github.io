# 🔍 视图与检索

> 同一份内容有五种看法。视图不是装饰，而是**不同的提问方式**：换一个视图，等于换一个问题。

🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 所属层 | L0 导航层 |
| 回答什么 | 用哪种视图回答哪类问题 |
| 不回答什么 | 不介绍 Quartz 的安装与配置 |
| 面向读者 | 想快速定位内容的读者、以及维护站点的编者 |
| 实现 | Quartz 5 内置能力 + 本库的标签约定 |

## 五种视图

| 视图 | 回答的问题 | 什么时候用 | 弱点 |
| --- | --- | --- | --- |
| **层级目录** | 这个主题归在哪一类？ | 已知大致领域，想逐层收窄 | 只能沿一条分类走，看不到横向关系 |
| **标签目录** | 有哪些东西和「电生理」有关？ | 想跨类型交叉检索 | 标签是扁平的，看不出层级 |
| **关系图谱** | 这一页旁边还有什么？ | 想发现没想到的相邻页面 | 只反映站内链接，不反映真实脑连接 |
| **全文搜索** | 那篇讲 XX 的在哪？ | 已知关键词或缩写 | 依赖页面里真的写了这个词 |
| **词云** | 这个站在讲什么？什么被讲得最多？ | 第一次到站，或想找覆盖缺口 | 高频不等于重要 |

## 一、层级目录

四层结构本身就是最大的目录：导航层 → 世界层 / 观测层 / 证据层。每一层的首页登记该层全部实体页，逐级收窄。

- 目录的**层数**只在导航层与实体层之间，实体页本身**不再分文件夹**；层级靠标签体现，不靠目录嵌套。
- 每页底部「相关」段落指向上级目录，因此任意一页都能回到目录。

## 二、标签目录

标签是**跨维度的第二套导航**。六个标签族见 [[00-导航/index|导航层]]。使用要点：

1. **一个类型标签**：`类型/模态`、`类型/结论` 等，每页只有一个，决定它属于哪一类实体；
2. **若干维度标签**：`模态/`、`尺度/`、`证据/` 等，可以多个，决定它能被哪些横向检索命中；
3. 类型标签回答"它是什么"，维度标签回答"它和什么有关"——**两者都要有，页面才算完整**。

> 新增标签值前先检查是否已有同类标签，避免同义标签分裂成两张网。

## 三、关系图谱

Quartz 把页面间的 wikilink 渲染成可交互网络。

- 图谱的**连线全部来自手写的 `[[链接]]`**，没有任何自动推断；因此"图上没有边"通常意味着"作者没写链接"，而不是"两者无关"。
- 判断一个页面是否被正确安置，最快的办法是看它周围的邻居是否符合直觉：结构页旁边应当有模态页与现象页，不应只有同类页面互相链接。

## 四、全文搜索

Quartz 内置客户端搜索，索引页面的正文与标题。

- 中文按字切分，因此**术语缩写（EEG、fMRI、BOLD、OPM）与中文名都要在页面里至少出现一次**，否则搜不到；
- `aliases` 里的名字不参与检索，所以常见别名要写进正文。

## 五、词云与覆盖缺口

词云按标签出现频次加权，用途有两个：

1. **正向**：一眼看出站点的重心在哪几个领域；
2. **反向**：一个反复被引用、却始终没有专属页面的概念，就是这个站该补的页——把它记进 [[00-导航/每周更新|每周更新]] 的待补清单。

> 词云的高频只是"被提到得多"。一个概念被频繁**引用**却不被**解释**，往往是导航结构里真实的缺口。

## 视图选择的经验法则

| 你的状态 | 先用哪个视图 |
| --- | --- |
| 完全不知道该站有什么 | 层级目录，从四层首页开始 |
| 知道领域，不知道具体页 | 标签目录，用维度标签交叉 |
| 已经在一页上，想往旁边看 | 关系图谱 |
| 记得一个词，找不到在哪 | 全文搜索 |
| 想知道站点是否覆盖完整 | 词云 + 缺口清单 |
