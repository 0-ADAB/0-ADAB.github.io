# 认知革命与认知科学

> 页名沿用旧笔记的说法。这一页不写历史叙事，只处理它引出的方法学问题：**当"认知"成为研究对象时，观测与推断难在哪里，以及为什么必须对这些困难保持自觉。** 🌿 扩充中

## 一、认知科学的问题域

认知科学处理的问题可以压缩成四个：

| 问题 | 典型提问方式 | 主要困难 |
| --- | --- | --- |
| 表征 | 系统里"存着"什么信息？ | 表征是理论构念，不能直接读出 |
| 计算 | 这些信息如何被转换？ | 同一行为可由多种计算方案产生 |
| 实现 | 转换发生在哪些神经结构上？ | 结构与功能不是一一对应 |
| 变化 | 它如何随发育、学习与病理改变？ | 变化的时间尺度跨越多个量级 |

这四类问题常用"计算层 / 算法层 / 实现层"的说法来分层（通称 Marr 三层次）。分层的用处很实际：**不同层次的问题需要不同的证据类型**，把实现层的测量直接当成计算层的答案，是认知研究中最常见的层级混淆。

## 二、困难一：心理过程不可直接观测

脑成像与电生理测量的都是物理量：血氧相关信号、电位差、钙浓度、磁场。认知构念（注意、意图、记忆强度）**不是物理量**，它们是从行为与神经指标中被推断出来的理论对象。

由此产生三条纪律：

1. **区分观测与构念**。数据里只有指标，没有"注意"。任何"注意增强了…"的表述都隐含了一次推断。
2. **同一指标有多种解释**。反应变慢可以是资源竞争、可以是策略改变、也可以是运动准备延迟。
3. **不同构念可能对应同一指标**。这意味着指标本身不能作为构念存在的证据，只能作为构念的操作化痕迹。

## 三、困难二：操作定义与构念效度

既然构念不能被直接测量，就必须**操作定义**：用一套可观测的刺激、任务与指标来代表它。问题在于，操作定义与构念之间永远存在距离，这段距离就是构念效度。

| 风险 | 表现 | 后果 |
| --- | --- | --- |
| 定义过窄 | 用单一任务的操作定义代表整个构念 | 结论只能推广到该任务，却被写成构念层面的结论 |
| 定义过宽 | 一个指标被用来代表多个构念 | 结果无法与其它研究比较 |
| 任务不纯 | 任务同时牵动多个过程 | 差异无法归因到目标过程 |
| 名称代替定义 | 用任务名称当构念名称 | 跨研究汇总时出现同词异义 |

可执行的应对方式：在设计阶段就**写出竞争假设**——如果结果成立，还有哪些别的解释能产生同样的模式？能预先排除的解释越多，结论越少依赖假设。

## 四、从行为到脑活动的推断链条

```text
刺激 / 任务
    ↓   （设计：条件之间只差目标变量？）
可观测行为（反应时、正确率、注视、报告）
    ↓   （操作定义：该行为代表哪个心理过程？）
心理构念（注意、记忆、决策…）
    ↓   （桥接假设：该构念对应哪种神经过程？）
神经测量（电位、血氧、放电率、连接强度）
    ↓   （分析：指标如何提取，假设是否成立？）
统计结果
    ↓   （推断：属于哪类证据，能支持到第几级？）
关于认知的结论
```

链条上每一段都是**一次推断，不是一个测量**。常见失效位置：

| 断点 | 失效方式 |
| --- | --- |
| 设计与行为之间 | 条件混杂或任务不纯，导致行为差异无法归因 |
| 行为与构念之间 | 操作定义过窄或过宽，构念效度不足 |
| 构念与神经之间 | 桥接假设未说明，直接跳到"某区负责某功能" |
| 神经与结果之间 | 预处理与统计假设不成立，指标本身不可信 |
| 结果与结论之间 | 证据等级与结论强度不匹配，见 [[从结果到推断]] |

## 五、困难三：尺度与模态的错位

认知过程在时间上跨越毫秒到数年，在空间上跨越突触到全脑，而**任何单一手段只能覆盖其中一小块**：

- 时间精度高的手段（电生理），空间定位弱；
- 空间精度较好的手段（fMRI），时间被血流响应平滑；
- 结构手段不反映当下活动，行为指标不反映神经实现。

因此"某认知过程发生在哪里、什么时候发生"这类问题，通常只能通过多模态互补与显式的桥接论证逼近。跨尺度、跨模态的结论若不写清桥接逻辑，就只是两段并置的描述，见 [[跨尺度整合]] 与 [[多模态融合]]。

## 六、方法论自觉：六条可执行要求

1. **先写下构念的操作定义，再选手段**。定义不清楚时，任何模态都救不了这个研究。
2. **为每个结论标注证据等级**（描述 / 关联 / 预测 / 时序 / 干预 / 机制），并检查表述是否越级。
3. **写明桥接假设**：从指标到构念、从构念到神经过程，各用了什么假设。
4. **写出竞争解释与排除方式**，而不是只报告支持性证据。
5. **区分验证性分析与探索性分析**，并分别报告，见 [[标准与规范]]。
6. **把限制写成适用范围**，而不是通用免责声明，见 [[解释边界与常见错误]]。
