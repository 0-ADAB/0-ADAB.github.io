# 收录标准

> 本站的取舍标准不是"全不全"，而是"三十年后还成不成立"。

🌿 扩充中

## 一、总门槛：三个问题

任何内容进入本站前先过这三问：

| 问题 | 不通过的表现 |
| --- | --- |
| 三十年后这个问题仍然成立吗？ | 依赖当前某代设备、某个流行模型或某个热点 |
| 它讲的是**能力与边界**，还是某个转瞬即逝的结果？ | 通篇在报道"某研究发现" |
| 读者能沿着它找到原始来源吗？ | 无法回溯到论文、数据库或官方文档 |

三问里有两个答不上来，就不该作为核心页面收录。

## 二、分层收录什么

| 层 | 收录 | 不收录 |
| --- | --- | --- |
| L1 世界层 | 层级定义、解剖与连接事实、现象的行为指标与争议 | 某篇论文对某脑区功能的单一解释 |
| L2 观测层 | 测什么物理量、与神经活动的距离、分辨率、前提假设、工具入口 | 完整方法学教程、软件操作步骤 |
| L3 证据层 | 推断类型与边界、常见越界解释、经三重检验的结论 | 未经验证的单一研究结论、临床诊断建议 |

## 三、结论层的额外门槛

只有同时通过三重检验的结论，才可进入 [[10-结论/index|当前认识]]：

| 检验 | 要求 |
| --- | --- |
| 时间检验 | 提出后经过足够长时间未被推翻 |
| 同行检验 | 经同行评议发表，并被独立团队重复或元分析支持 |
| 方法检验 | 由多种独立模态或多种实验设计得到一致结果 |

四级证据状态（🟢 稳固共识 / 🔵 较强证据 / 🟡 开放问题 / ⚪ 研究线索）的定义与判据见 [[10-结论/index|当前认识]]。

> 状态升级**只能由人工确认**。AI 与自动化流程可以提供候选，不负责拍板。

## 四、不收录什么

| 不收录 | 原因 |
| --- | --- |
| 未经验证的单篇论文结论 | 未经时间与同行检验，且很快过时 |
| 某疾病的具体诊断标准 | 属临床指南范畴，责任与时效都不匹配 |
| 原始实验数据与结果图表 | 属原始研究，附带大量上下文 |
| 未标明出处的断言 | 无法核查 |
| 个人健康建议 | 超出科普与工具索引的边界 |
| 教程全文转载 | 应链接到官方源头 |

**例外**：为说明原理而举的经典范式可以出现，但必须标注性质，且不作为"结论"呈现。

## 五、条目的完成标准

- 文件位于 `forAccess/` 内（**发布区外的页面不会被发布，即使写了 `publish: true`**）
- frontmatter 五字段齐全，`publish: true`
- 有且仅有一个 `类型/` 标签，以及一个 `层/` 标签
- 开头的**定位**表已填
- 正文包含该实体类型的全部专有段落
- 「不适用 / 局限 / 边界」段落非空且具体
- 至少与三个其他实体双向链接（尽量跨层）
- 已被上级目录的 index 页收录
- 链接一律相对 `forAccess/` 写，不带 `forAccess/` 前缀
- `node tools/检查链接.mjs` 报告「问题合计：0」

## 六、两种互相独立的状态标记

| 标记 | 标记的是什么 | 取值 |
| --- | --- | --- |
| 成熟度 🌱🌿🌳 | **这一页写完了多少** | 🌱 雏形 / 🌿 扩充中 / 🌳 稳定 |
| 证据状态 🟢🔵🟡⚪ | **这条结论被检验到什么程度** | 见 [[10-结论/index\|当前认识]] |

两者互不推导：一页可以写得很完整（🌳），但它记录的结论仍可能只是「🟡 开放问题」。

## 七、外部链接的收录底线

收录外部资源时至少要能说清：类型（软件 / 数据集 / 教程 / 规范）、适用数据与任务、面向水平、官方地址、是否官方来源。

半年以上未核查的外部链接应重新确认可达性；核查节奏见 [[00-导航/每周更新|每周更新]]。
