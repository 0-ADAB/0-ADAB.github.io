# 关于本站

> 一个按「世界 → 观测 → 证据」分层组织的脑研究导航。
> 它不是课程，也不是文献库：不教你怎么做，只告诉你**能看见什么、能说明什么、做到什么程度**。

## 站点的四条假设

1. **没有任何单一手段能"看见大脑"**。每种模态测的都是代理量，各有分辨率与推断限制。
2. **尺度之间不能自由换算**。跨尺度、跨模态的结论需要显式的桥接论证。
3. **导航的价值在于边界**。说清"这个方法不能做什么"，比罗列它能做什么更有用。
4. **只有经得起时间与同行检验的结论才值得长期收录**。单篇论文不构成结论。

## 四层结构

```text
L0 导航层   入口、视图、更新机制与规则     00-导航/  09-关于/
L1 世界层   研究对象：尺度 · 现象 · 结构   01-尺度/  03-现象/  04-结构/
L2 观测层   观测手段：模态 · 方法 · 资源   02-模态/  05-方法/  07-资源/
L3 证据层   推断与结论：证据 · 设计 · 结论  06-证据/  08-设计/  10-结论/
```

上层结论必须能回溯到下层观测；导航层不承载内容，只提供入口。

## 技术实现

| 环节 | 方式 |
| --- | --- |
| 写作 | Obsidian，本地笔记库 |
| 发布闸门 | 文件位于 `forAccess/` **且** 带 `publish: true` |
| 生成 | Quartz 5，静态站点 |
| 托管 | GitHub Pages |
| 导航能力 | 层级目录 + 标签目录 + 双向链接 + 关系图谱 + 全文搜索 + 词云 |
| 结构自检 | `node tools/检查链接.mjs`（frontmatter、链接、段落、目录登记四项） |

## 参与与纠错

发现错误、链接失效或表述不当时，可提 Issue 或直接提交修改。修改前请先读 [[09-关于/内容模型|内容模型]] 与 [[09-关于/收录标准|收录标准]]：

- 页面必须放进 `forAccess/` 内对应目录；
- frontmatter 补齐五个字段，且带一个 `类型/` 与一个 `层/` 标签；
- 链接相对 `forAccess/` 写；
- 在上级 index 页登记；
- 改完运行 `node tools/检查链接.mjs`，确认「问题合计：0」。
