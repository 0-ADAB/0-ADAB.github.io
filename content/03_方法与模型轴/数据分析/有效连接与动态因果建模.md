# 有效连接与动态因果建模

> **一句话介绍：** **有效连接**（effective connectivity）描述某一神经系统对另一神经系统活动的有向影响；**动态因果建模**（dynamic causal modelling, DCM）通过“神经状态如何相互影响、神经活动如何变成观测信号”的生成模型，结合贝叶斯模型比较与参数估计，检验候选神经回路的作用方向及其受任务或状态调制的可能机制——结论始终**以模型、测量、先验与候选假设为条件**。(Friston et al., 2003, NeuroImage; Friston, 2011, Brain Connect; Stephan et al., 2010, NeuroImage)

## 快速理解

**功能连接**可以发现两个脑区的时间序列经常一起变化，却无法直接回答谁影响了谁。DCM 的问题更具体：如果脑区 A 对 B 有作用，或任务刺激改变 A→B 的连接，所提出的神经动力学能否产生我们在 fMRI、EEG 或 MEG 中看到的信号？再与另一套候选网络比较，哪种解释在拟合表现与模型复杂性之间更有支持？(Friston et al., 2003, NeuroImage; Penny et al., 2004, NeuroImage)

可以把它想成研究一套城市供水系统：两地水压同时波动只是统计相关。若提出了泵站、阀门、管道与传感器的动力学模型，再用不同阀门开启条件的数据比较不同连接方案，就可以估计更具体的方向性作用。但如果漏掉重要泵站，或传感器测量方式假设错误，即便某个模型是候选中最好的，它也未必是真实系统。(Penny et al., 2004, NeuroImage; Daunizeau et al., 2011, NeuroImage)

**最重要的四个区分：**

1. **有效连接是推断目标，DCM 是一个模型框架。** 有效连接不等于 DCM 的专有名词；结构方程、某些因果发现算法和其他状态空间模型也可能研究方向性，不过假设与证据强度各不相同。(Friston, 2011, Brain Connect; Smith et al., 2011, NeuroImage)
2. **模型中的“因果” ≠ 随机干预直接证实的因果。** DCM 估计的是模型所定义、由数据支持的有向神经影响。若数据仅为观察性记录，隐藏共同输入、错误神经或血流动力学模型仍可影响识别；外部刺激或独立电生理能增加验证力度。(David et al., 2008, PLoS Biol; Daunizeau et al., 2011, NeuroImage)
3. **任务调制 ≠ 基线耦合。** 经典 fMRI DCM 分开估计基线连接、实验情境对连接的调制和外部刺激的驱动位置；“某连接为正/负”也不能直接翻译成具体的谷氨酸或 GABA 突触活动。(Friston et al., 2003, NeuroImage; Zeidman et al., 2019a, NeuroImage)
4. **DCM 不只有 fMRI 任务态一种。** 静息态谱 DCM、随机 DCM、EEG/MEG 神经质量模型、回归 DCM 与群体层 PEB 的观测目标、噪声假设、参数意义和适用网络规模不同，不能互换结果的解释。(Daunizeau et al., 2012, NeuroImage; Friston et al., 2014, NeuroImage; Frässle et al., 2017, NeuroImage; Moran et al., 2013, Front Comput Neurosci)

## 原理与操作流程

### 1. 明确有向问题，并构造合理的候选网络

从可检验的神经科学假设出发，指定区域／神经元群体、允许的连接方向、自连接、外部输入的进入位置及哪些任务条件可能调制连接。候选模型需要包括**科学上可信的竞争解释**，不是凭拟合结果事后随意添加边。结构影像或电生理先验可辅助模型构造，但结构连通不自动证明特定条件下的有效连接存在。(Penny et al., 2004, NeuroImage; Stephan et al., 2009b, NeuroImage; Stephan et al., 2010, NeuroImage)

经典任务态 fMRI DCM 通常针对规模受控的神经网络；大规模网络可考虑回归 DCM 等计算简化方法，但其线性化与频域假设不能照搬经典双线性 DCM 的全部参数解释。(Frässle et al., 2017, NeuroImage)

### 2. 神经动力学：A、B、C 三类参数

经典双线性 DCM 可以写成如下示意形式：

\[
\frac{d\mathbf z(t)}{dt}
\=\left(\mathbf A+\sum\_{k=1}^{K}u\_k(t)\mathbf B^{(k)}\right)\mathbf z(t)
+\mathbf C\mathbf u(t).
]

其中，(\mathbf z(t)) 是不可直接观察的神经状态，(\mathbf u(t)) 为预先编码的实验输入；(\mathbf A) 表示给定模型的基线内在／区域间作用，(\mathbf B^{(k)}) 表示第 (k) 个情境如何改变这种作用，(\mathbf C) 表示驱动输入进入网络的方式。完整 DCM 还有自连接、区域时间常数等相关参数及其先验；公式是经典双线性 fMRI 版本的概括，**不是所有 DCM 的统一方程**。(Friston et al., 2003, NeuroImage; Stephan et al., 2008, NeuroImage; Zeidman et al., 2019a, NeuroImage)

- (\mathbf A\_{ij}) 的大小和方向以节点及模型约定为前提；并非每个 (\mathbf A\_{ij}) 都等于真实解剖突触强度。
- (\mathbf B^{(k)}\_{ij}) 估计调制效应，应与所指定的基线连接、条件编码一起解释；“正调制”不一定意味着该连接在所有条件下为兴奋性。
- 一些 DCM 把自连接写为保证系统稳定的负性衰减或经特定变换参数化的自抑制；不能把它与脑区间连接的符号直接等同。
- 非线性 DCM 能表示一个区域的活动对另外两个区域间连接的门控，但参数更多、辨识度和收敛要求也相应提高。(Stephan et al., 2008, NeuroImage; Zeidman et al., 2019a, NeuroImage)

### 3. 测量模型：从隐变量到真实记录

在 fMRI 中，DCM 除神经动力学外，还要用血流动力学／神经血管耦合的前向模型把潜在神经状态映射为 BOLD 信号。**BOLD 不是突触传递方向的直接记录**；若不同脑区的血流反应延迟不同，单靠 BOLD 峰值先后或时序预测可能推错神经驱动关系。在有 EEG/颅内记录对照的动物模型中，显式建模血流动力学有助于找回与电生理更一致的驱动位置。(Friston et al., 2003, NeuroImage; David et al., 2008, PLoS Biol)

在 EEG/MEG 中，测量模型需要神经源的群体动力学及头部传导的空间前向模型；其反演受源定位不确定性、体积传导和神经质量模型假设限制。神经质量或皮层微回路 DCM 可能估计层特异或突触群体参数，但这些仍是模型映射后的结果，并非直接观测每条突触。(David et al., 2006, NeuroImage; Moran et al., 2013, Front Comput Neurosci; Friston et al., 2019, NeuroImage)

### 4. 选择与数据问题匹配的 DCM 变体

| 方法／变体 | 主要输入与目标 | 核心思想 | 主要边界 |
| --- | --- | --- | --- |
| 经典任务态双线性 DCM | 已明确任务条件及区域的 fMRI BOLD | 外部输入、基线连接与任务调制共同生成观测 | 候选网络、刺激编码和 BOLD 前向模型必须合理 |
| 非线性 DCM | 任务 fMRI | 增加神经状态对连接的门控项 | 更复杂、可辨识性要求更高 |
| 随机 DCM（stochastic DCM） | 连续 fMRI 时序，含自发波动 | 在隐含神经状态中显式加入随机扰动并估计动态 | 潜在噪声和参数识别依赖模型与数据 |
| 静息态谱 DCM（spectral DCM） | 静息 fMRI 的交叉谱/二阶统计量 | 用潜在神经波动及血流动力学预测观测谱 | 通常采用近似平稳等假设；不重建每次瞬时信息流 |
| DCM for ERP / induced / CSD | EEG、MEG、ECoG、LFP | 用神经质量、神经场或生物物理网络生成电磁响应及谱 | 源模型、群体假设与传感器前向模型决定解释 |
| 回归 DCM（rDCM） | 较大范围或全脑 fMRI | 在线性化及频域框架中以贝叶斯回归提高可计算性 | 与完整非线性/生物物理 DCM 不等价 |
| PEB + BMR | 多被试的 DCM 后验及协方差 | 在层级贝叶斯模型中估计群体效应、删减参数模型 | 属于群体推断程序，不是独立测量或“新连接类型” |

该分类来自方法原始论文与教程。(David et al., 2006, NeuroImage; Chen et al., 2008, NeuroImage; Stephan et al., 2008, NeuroImage; Li et al., 2011, NeuroImage; Daunizeau et al., 2012, NeuroImage; Friston et al., 2014, NeuroImage; Frässle et al., 2017, NeuroImage; Zeidman et al., 2019b, NeuroImage)

**谱 DCM 的特殊理解：** 它不是先通过普通 FC 算完相关系数，再给每条相关边添加箭头。它使用神经生成模型预测隐含状态的相关频谱，经测量模型得到 BOLD 交叉谱，反过来估计能解释这些统计量的有向参数；因此能在一些假设下从无方向的观测协方差推断有方向的潜在作用，但**方向性仍是生成模型支持的结论**。(Friston et al., 2014, NeuroImage; Razi et al., 2015, NeuroImage)

### 5. 贝叶斯反演、模型证据及群体比较

给定模型 (m)、数据 (y) 与连接参数 (\theta)，DCM 依据先验与似然估计后验 (p(\theta\mid y,m))。比较竞争模型时使用边际似然（模型证据）：

\[
p(y\mid m)=\int p(y\mid\theta,m)p(\theta\mid m),d\theta .
]

这一积分体现拟合精度与模型复杂性间的取舍；实际算法可用变分自由能近似对数模型证据。Bayes 因子是**候选模型相对证据**，即使某模型后验最高，也只意味着在设定的候选集合与先验下它相对更受支持，不意味着其参数、节点或生物机制已经得到排他性证明。(Penny et al., 2004, NeuroImage; Stephan et al., 2010, NeuroImage)

对于多被试研究，可用固定效应或随机效应的群体模型比较来讨论被试间模型异质性；也可在参数空间使用参数经验贝叶斯（parametric empirical Bayes, PEB）和贝叶斯模型约简（Bayesian model reduction, BMR），把个体参数的不确定性传递到群体层并检验组别、行为或条件差异。**群体模型比较、PEB 参数推断与独立被试预测不是同一种检验。**(Stephan et al., 2009a, NeuroImage; Friston et al., 2016, NeuroImage; Zeidman et al., 2019b, NeuroImage)

### 6. 解释、敏感性检查与独立验证

建议按照：**科学假设 → ROI/神经源与实验条件 → 候选模型及先验 → 预处理与模型拟合 → 反演诊断 → 模型／模型族比较 → 参数后验与不确定性 → 层级群体效应 → 候选模型和先验敏感性分析 → 跨会话、独立样本或干预验证** 的顺序报告。保留用于复算的模型空间定义、代码/工具箱版本和数据划分，不只发表一张标箭头的“胜出网络图”。(Stephan et al., 2010, NeuroImage; Frässle et al., 2015, NeuroImage; Zeidman et al., 2019a, NeuroImage; Zeidman et al., 2019b, NeuroImage)

## 能回答什么，不能回答什么？

**在模型可辨识、数据质量足够且替代解释受到检验时，能够回答：**

- 在指定神经区域和输入条件下，哪类方向性网络更能解释实际观测；某些基线连接是否与零/先验存在有意义的后验差异。(Friston et al., 2003, NeuroImage; Penny et al., 2004, NeuroImage)
- 实验情境或刺激操纵是否与某些网络连接的模型参数变化有关，包括某些区域间调制及局部群体增益。(Stephan et al., 2008, NeuroImage; Friston et al., 2019, NeuroImage)
- 在理论限定的前提下，静息态观测谱更符合哪种有向潜在网络，以及参数是否在组别/会话之间存在可重复差异。(Friston et al., 2014, NeuroImage; Razi et al., 2015, NeuroImage; Ma et al., 2024, NeuroImage)
- EEG/MEG 神经网络或层特异频域特征是否符合某个神经质量及前向/反馈网络假说。(Bastos et al., 2015, NeuroImage; Jafarian et al., 2024, Hum Brain Mapp)

**单靠 DCM 不能直接回答：**

1. **“这条解剖纤维真实存在吗？”** 一条 DCM 边是潜在神经群体之间的模型化作用，不等于一束被示踪确认的轴突，更不能直接推出具体神经递质。(Stephan et al., 2009b, NeuroImage)
2. **“A 是 B 的唯一真实原因吗？”** 隐藏区域、共同输入、未测试的备选拓扑和错误的神经/测量模型都可能带来方向误判；模型选择并不自动枚举所有可能的因果结构。(Smith et al., 2011, NeuroImage; Daunizeau et al., 2011, NeuroImage)
3. **“正、负连接就是兴奋/抑制性突触吗？”** 脑区级参数是对群体净动力学的抽象，数值与符号依赖参数化；只有在充分的微回路约束和独立实验支持下，才可能对受体或抑制性群体提出更具体解释。(Moran et al., 2013, Front Comput Neurosci; Friston et al., 2019, NeuroImage)
4. **“被试组参数差异必然有临床诊断意义吗？”** 样本内组效应与新患者独立预测、外部临床有效性是不同目标；高模型证据亦非高临床效度。(Frässle & Stephan, 2022, Netw Neurosci; Nara et al., 2025, J Neurosci)
5. **“BOLD 曲线先到达的区域一定在神经因果链的上游吗？”** 血流动力学迟滞与区域差异可能制造表面方向，必须在潜在神经层建模并接受独立验证。(David et al., 2008, PLoS Biol)
6. **“贝叶斯后验概率可以直接当作独立验证的真因果概率吗？”** 后验依赖先验、似然、模型族与数据；同一数据既定义模型又宣称独立确认，会夸大证据。(Penny et al., 2004, NeuroImage; Stephan et al., 2010, NeuroImage)

## 空间、时间尺度与适用对象

| 模态／数据 | 主要模型节点 | 时间性质 | 解释与外推限制 |
| --- | --- | --- | --- |
| 任务态 fMRI | ROI 或预定义区域的隐神经状态 | 观测由缓慢 BOLD 代理产生；神经动态不可直接毫秒读出 | 依赖任务输入、神经血管耦合及候选拓扑 |
| 静息态 fMRI / 谱 DCM | 预定义区域及其潜在神经波动 | 利用时间序列或交叉谱的统计结构 | 平稳性/噪声谱假设；长时序及稳定测量很重要 |
| EEG、MEG、ECoG、LFP | 神经源、神经群体乃至神经微回路 | 毫秒级电生理信息，但频谱可靠估计仍需时间/试次数 | 体积传导、源定位、多群体动力学参数和先验约束 |
| 神经群体/层级侵入性记录 | 层内及层间神经质量群体 | 可较直接测量微回路动态 | 物种、麻醉/任务状态和电极覆盖限制外推 |
| 多被试纵向/临床样本 | 各个体 DCM 后验再建群体模型 | 依赖会话、疾病状态及重测间隔 | 组别混杂、采样方案、模型参数信度与外部复核 |

这些是测量与模型层级的划分，而不是严格的“fMRI 只能做慢因果／电生理一定是真实因果”的二分。EEG/MEG 的逆源问题不会因采样快而消失；fMRI 虽然测量慢，若输入设计与模型充分，仍可对潜在方向性作用作出有条件推断。(David et al., 2006, NeuroImage; David et al., 2008, PLoS Biol; Moran et al., 2013, Front Comput Neurosci)

**受试者与研究场景：** 人类任务、静息、临床观察和刺激研究以及动物电生理均可采用合适 DCM 变体，不能把动物癫痫环路的验证直接外推为人类每个皮层网络的普适因果确认。(David et al., 2008, PLoS Biol; Czime Litwińczuk et al., 2025, NeuroImage Rep; Gjini et al., 2026, Epilepsy Behav)

## 质量控制与典型伪迹

| 风险/误区 | 为什么会改变结论 | 建议检查 |
| --- | --- | --- |
| ROI 和候选模型不完整 | 遗漏共同驱动或直接连接，导致错误方向分配 | 预定义 ROI，合理扩充竞争模型和结构先验，敏感性比较 |
| 模型空间过窄 | “最优”仅是所选候选中的相对最优 | 公开候选模型/家族，测试关键替代路径并报告模型不确定性 |
| 血流动力学差异 | 神经先后与 BOLD 先后不一致 | 检查信号质量、区域 HRF/血管混杂、模型参数与替代前向模型 |
| EEG/MEG 的体积传导与源泄漏 | 传感器相关和源参数可能由混合导致 | 报告源定位、传感器前向模型和源空间稳健性分析 |
| 先验与参数不可辨识 | 不同参数组合拟合同样数据；后验受先验主导 | 检查后验方差/相关、先验敏感性、参数恢复和模型诊断 |
| 优化局部极值和软件版本 | 相同数据的结果可随反演算法或默认先验变化 | 多初值/重新反演、软件版本、异常参数与拟合残差检查 |
| 头动、呼吸、觉醒、任务共同驱动 | 伪迹通过观测模型影响神经参数 | 完整预处理 QC、独立试次与合适混杂模型 |
| 群体层参数与组别协变量 | 年龄、运动、扫描仪、数据长度影响所谓疾病效应 | PEB 设计矩阵纳入适当协变量；查看组间不平衡、跨中心验证 |
| 重测信度与数据量不足 | 网络拓扑可能稳定，单个参数却不稳定 | 分半/跨会话重测、数据时长敏感性，优先关注可恢复参数 |
| 事后挑选连接与结果 | 双重使用数据使模型后验和预测表现乐观 | 预注册模型空间、独立确认、交叉验证和外部样本 |

**主要方法争议及证据：**

**① 模型辨识与先验依赖。** DCM 的输出不是由输入数据“自动读出”的因果方向。2004 年的模型比较研究已经明确，结构假设决定哪类结论可被检验；2015 年 fMRI 重测研究还观察到不同软件默认先验与反演设置明显影响参数信度。这不是说 DCM 无效，而是说报告工具版本及后验诊断是研究结果的一部分。(Penny et al., 2004, NeuroImage; Daunizeau et al., 2011, NeuroImage; Frässle et al., 2015, NeuroImage)

**② 重测结果取决于评估对象。** 2022 年全脑 rDCM 研究发现，群体层边权表现可稳定，但若平均所有边，单边个体内信度仍有限；较强连接的可靠性通常更高。2024 年静息 fMRI 研究显示延长扫描、扩大样本能改善与长扫描参考结果的一致性，但“够用的分钟数/人数”是该论文特定数据、连接与判据下的结果，不能变成普遍最低规范。(Frässle & Stephan, 2022, Netw Neurosci; Ma et al., 2024, NeuroImage)

**③ 不同测量模态的重测不能混为一谈。** 2024 年静息态 MEG 的电导式神经质量 DCM 研究报告，在相近条件的扫描段和会话比较中，多数参数缺乏改变的证据；这依赖其贝叶斯层级框架和假设，不能简单等同于“每一条 DCM 边的经典 ICC 都接近完美”。(Jafarian et al., 2024, Hum Brain Mapp)

**④ 有方向性的后验不等于经干预确认。** 2008 年动物癫痫模型使用电生理与 fMRI 的交叉对照，为明确考虑血流动力学的有向模型提供有价值的外部验证；而 2025 年小样本、假刺激对照的 tDCS 研究能把外源操纵与 DCM 变化联系起来，但没有发现所有预设调制边都随刺激改变，因此不能把其题名中的“重组”扩展成所有个体或所有连接的必然变化。(David et al., 2008, PLoS Biol; Czime Litwińczuk et al., 2025, NeuroImage Rep)

**⑤ 临床转化与模型选择中的不确定性。** 对异常痛觉、安慰剂反应及癫痫相关信号的近期 DCM 结果提供了具体可检验回路假设，但还需检查跨样本推广和独立干预证据；即使与症状相关，也未成为临床诊断的已验证单一生物标志物。(Nara et al., 2025, J Neurosci; Gjini et al., 2026, Epilepsy Behav)

## 代表性实验或应用

### 1. 动态因果模型的提出及经典任务连接比较（方法原始研究）

2003 年的 DCM 研究把神经状态模型与 BOLD 前向模型结合，在受控任务条件下讨论区域基线作用、驱动输入与调制；2004 年的模型比较论文以同一观测数据比较若干神经网络结构和输入调制假说，建立了使用边际似然处理拟合与复杂性之间权衡的基本范式。(Friston et al., 2003, NeuroImage; Penny et al., 2004, NeuroImage)

**支持范围：** 可对明确定义的连接假设做相对模型比较；不证明未被考虑的候选网络一定较差。

### 2. 癫痫网络驱动：fMRI 推断与电生理交叉验证

在大鼠失神癫痫模型中，研究人员同时或分别测量 fMRI、EEG 和颅内电生理，将 fMRI 的连接分析与直接电生理导出的驱动位置进行比较。直接使用 BOLD 时间先后的方法会受区域血流动力学差异误导；在建模潜在神经状态后，结果更接近电生理证据。随后也出现了结合 EEG–fMRI 研究癫痫传播路径的 DCM 应用。(David et al., 2008, PLoS Biol; Murta et al., 2012, NeuroImage)

**支持范围：** 这是对特定模型、病理生理系统的重要跨方法验证，不能保证对所有人类静息网络同样正确。

### 3. 静息态谱 DCM 的构造及检验

原始谱 DCM 以预测 BOLD 交叉谱的方式估计隐含网络参数；后续研究通过仿真和经验数据比较谱 DCM 与随机 DCM，给出了在所评估条件下的构念验证与模型效率/效能优势。(Friston et al., 2014, NeuroImage; Razi et al., 2015, NeuroImage)

**支持范围：** 支持这种模型在特定仿真和数据设置中的有效性；不能称其对全部静息态模型和真实因果结构均获得外部金标准验证。

### 4. EEG/MEG 的神经质量与皮层层级假说

早期 DCM 把事件相关电位/磁场与神经群体模型联系起来；猴视觉皮层 ECoG 的研究通过模型比较考察前馈、反馈作用的频谱非对称；层内记录结合光遗传操纵的研究则将神经质量模型进一步用于较细的皮层层级解释。(David et al., 2006, NeuroImage; Chen et al., 2008, NeuroImage; Bastos et al., 2015, NeuroImage; Pinotsis et al., 2017, NeuroImage)

**支持范围：** 频谱与层级作用之间的对应依赖模型及具体记录部位；不等于每个脑区的 γ 都是前馈、α/β 都是反馈。

### 5. 全脑 DCM、层级 PEB 和可重复性

回归 DCM 提供了更易扩展到全脑的算法路线；分层 PEB 与 BMR 让多被试数据的参数推断和模型约简更实用；其教程附有可重建分析流程的数据与操作说明。后续 rDCM 重测分析显示，群体网络、单条边和个体指纹的可靠性各不相同。(Frässle et al., 2017, NeuroImage; Friston et al., 2016, NeuroImage; Zeidman et al., 2019a, NeuroImage; Zeidman et al., 2019b, NeuroImage; Frässle & Stephan, 2022, Netw Neurosci)

**支持范围：** 更大的网络和更多被试并不会自动消除方向识别与先验依赖。

### 6. 2024—2026 年：时长、跨会话与转化研究

2024 年的 fMRI 研究系统考察了数据时长和样本量对静息 DCM 一致性的影响，另一项 MEG 研究直接讨论了神经质量 DCM 的跨时段与跨会话可靠性。2025 年的 tDCS 研究结合刺激操纵与工作记忆 DCM，为“外源干预—潜在连接变化”建立了可分析范式，但部分预期调制结果为负。2026 年青少年肌阵挛性癫痫 EEG 研究运用 DCM 与 PEB 比较听觉偏差加工网络，为特定临床群体提出新的方向性假设。(Ma et al., 2024, NeuroImage; Jafarian et al., 2024, Hum Brain Mapp; Czime Litwińczuk et al., 2025, NeuroImage Rep; Gjini et al., 2026, Epilepsy Behav)

**支持范围：** 新近研究各有不同模态、样本量与验证方法，不能合并为一个“DCM 已经普遍可以诊断疾病”的结论。

## 与其他方法的关系

| 方法 | 与 DCM 的交叉 | 关键区别及使用建议 |
| --- | --- | --- |
| 功能连接分析（FC） | 都可研究大尺度脑网络及状态差异 | FC 多估计统计依赖；DCM 检验生成模型内的有向作用；静息谱 DCM 并非将 FC 系数直接改为箭头 |
| 结构连接 / dMRI / 示踪 | 为候选有向网络提供生物解剖约束 | 解剖通路限制可能性，却不自动指定动态增益及任务调制 |
| Granger 因果 / VAR | 都可讨论时间关系与方向 | 基于可观测时序的预测先后，不与建模潜在神经状态及血流动力学的 DCM 等同 |
| 结构方程模型 / 其他因果图方法 | 都能表达候选依赖和方向假设 | 经典 DCM 特别强调神经动态与测量前向模型；各类方法依赖不同识别假设 |
| 心理生理交互（PPI） | 同样能问某实验条件是否调制跨区统计关系 | PPI 是交互/连接效应的统计模型，标准 PPI 不识别单向神经影响 |
| TMS、tDCS、光遗传、损毁 | 为方向机制提供外源操纵或更接近干预的约束 | 干预本身有刺激范围和网络传播限制，DCM 可作机制模型，但不能代替实验设计 |
| 脑网络图论 | 汇总有向或无向网络的模块和中心性 | 图的方向源于输入估计量，中心性不能证明边的生理正确性 |
| 贝叶斯模型比较／PEB | 是 DCM 参数、模型与群体不确定性推断的重要组成部分 | 贝叶斯方法本身不是神经因果实验 |
| 多重比较校正 | 对探索性组效应、多连接或非贝叶斯检验提供错误率控制 | 显著性校正不能解决模型空间遗漏、先验依赖及参数不可辨识 |
| 表征相似性分析（RSA） | 可对同一实验中的区域活动模式与计算模型作比较 | RSA 主要问条件间表征几何；DCM 问隐含网络动力学，不能以 RDM 相关推出连接方向 |

相关区别有经典比较与专题综述支持。(Friston, 2011, Brain Connect; Smith et al., 2011, NeuroImage; Daunizeau et al., 2011, NeuroImage; Stephan et al., 2009b, NeuroImage; Czime Litwińczuk et al., 2025, NeuroImage Rep)
