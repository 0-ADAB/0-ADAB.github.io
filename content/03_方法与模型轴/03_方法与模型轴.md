# 方法与模型

> **我们如何测量、干预、分析并解释神经系统？**

方法可以提高观察和推断能力，也有自身的物理、统计及解释边界。

## 方法地图

| 方法组 | 例子 |
| --- | --- |
| 神经活动测量 | 电生理、钙成像、EEG/MEG、fMRI、PET |
| 解剖与分子测量 | 神经示踪、显微成像、连接组学、单细胞组学、空间组学 |
| 行为与实验范式 | 行为任务、心理物理学、眼动 |
| 因果干预 | 光遗传学、化学遗传学、药理干预、TMS、DBS |
| 数据分析 | 信号处理、编码/解码、功能连接、有效连接、机器学习 |
| 理论与计算模型 | 生物物理模型、网络模型、动力系统、强化学习、贝叶斯模型 |
| 基础设施 | 数据库、脑图谱、软件工具、数据标准 |

## 方法节点的固定问题

1. 直接测量、操纵或建模的量是什么？
2. 空间和时间分辨率、适用对象与实验条件是什么？
3. 能回答什么问题，不能直接推出什么结论？
4. 已知的偏差、伪迹、混杂因素与验证方式有哪些？

## 方法和推断的关系

**解码成功不必然等于证实某种神经表征机制；观察到相关性也不必然说明因果。** 方法节点应指向证据与推理轴的相应限制。
