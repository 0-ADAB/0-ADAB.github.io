# 免疫组织化学

> **一句话介绍：** 免疫组织化学（immunohistochemistry，IHC）利用抗体识别组织内抗原表位，并以酶促显色或荧光读出位置，帮助回答“**特定分子在何种细胞、亚细胞结构或脑区可被检测到**”；但染色信号还依赖抗体特异性、组织制备与检测体系，不能天然视为蛋白绝对丰度或细胞功能。(Coons & Kaplan, 1950, J Exp Med; Ramos-Vara, 2005, Vet Pathol; Uhlen et al., 2016, Nat Methods)

## 快速理解

可以把免疫组织化学想成在保留街区结构的地图上寻找某种“带特征的目标”：**一抗**识别目标表位，酶或荧光检测体系把这一结合事件转成可见信号，显微镜则记录目标在组织中的位置。荧光标记抗体与酶标抗体的经典研究分别建立了这类技术的重要基础。(Coons & Kaplan, 1950, J Exp Med; Nakane & Pierce, 1966, J Histochem Cytochem)

需要先分清四个概念：

- \*\*IHC（广义）\*\*包括显色 IHC 与组织免疫荧光（IF）；部分临床语境把 IHC 专指明场显色，本节点使用广义定义。
- \*\*免疫细胞化学（ICC）\*\*通常用于培养细胞等离体细胞制备；与保留组织原位构筑的 IHC 不完全相同。
- **免疫荧光不是所有组织化学的同义词**：普通组织染料、部分酶组织化学、核酸原位杂交未必以抗原—抗体特异性识别为读数基础。
- **一个标记不等于整个细胞类别或功能状态**：NeuN 不覆盖全部神经元；GFAP、Iba1、c-Fos 的阳性也不能分别直接写成“所有星形胶质细胞”“所有小胶质细胞”或“实时放电神经元”。(Mullen et al., 1992, Development; Ito et al., 1998, Brain Res Mol Brain Res; Sagar et al., 1988, Science; Escartin et al., 2021, Nat Neurosci)

\*\*阅读顺序：\*\*先问抗体能否在当前样本中可靠识别目标，再问染色和成像是否受背景及批次影响，最后才讨论生物学解释。厂家说明书、已发表论文中的使用经验、单张漂亮图像，都不能独立替代当前应用条件下的验证。(Bordeaux et al., 2010, Biotechniques; Uhlen et al., 2016, Nat Methods)

## 原理与操作流程

### 1. 抗原、表位与报告信号

抗体通常识别特定**抗原表位（epitope）**，并不是“无条件识别一整条蛋白”。交联固定可能遮蔽表位，抗原修复又可能让其重新暴露，也可能损伤组织或增加非特异性信号；目标蛋白存在与某支抗体能够检出，不能简单画等号。(Shi et al., 1991, J Histochem Cytochem)

- **直接标记**：荧光／酶直接连接一抗，识别链较短，但信号及兼容性受标记设计影响。
- **间接标记**：未标记一抗先结合表位，再用带报告基团的二抗显影；方便组合与放大，但多了二抗交叉反应和背景的风险。
- **明场酶促显色**：如 HRP-DAB 在局部沉积可见产物，便于观察组织形态；反应程度受酶活性、底物和时间等影响，并非普遍线性。
- **免疫荧光**：利用荧光团的激发与发射光形成多通道图像；必须控制光谱串色、自发荧光、漂白、探测器饱和及显示映射。(Nakane & Pierce, 1966, J Histochem Cytochem; Waters, 2009, J Cell Biol)

### 2. 不同检测与信号放大策略

| 检测形式 | 主要读数 | 优势 | 局限 |
| --- | --- | --- | --- |
| 直接荧光一抗 | 一抗偶联荧光信号 | 可减少部分二抗串扰 | 灵敏度依标记设计，一抗仍需验证 |
| 间接荧光一抗＋二抗 | 二抗所带的荧光 | 便于多色、提高可见度 | 二抗交叉结合、通道泄漏、非特异吸附 |
| HRP-DAB 显色 | 酶催化不溶性产物 | 适于组织病理及明场 | 内源酶、反应非线性、过度显色 |
| ABC 复合物 | 生物素—亲和素—酶信号 | 经典高敏检测 | 内源性生物素相关背景 |
| TSA／酪胺放大 | 酶催化报告分子局部沉积 | 弱信号检出、部分多重染色 | 背景同步放大、沉积饱和与批次差异 |
| 循环多重 IF / DNA 条码抗体 | 多轮染色与荧光读数 | 同一区域记录更多表位 | 多轮配准、表位损失、旧轮信号残留 |

(Hsu et al., 1981, J Histochem Cytochem; Wood & Warnke, 1981, J Histochem Cytochem; Bobrow et al., 1989, J Immunol Methods; Stack et al., 2014, Methods; Lin et al., 2018, eLife)

**来源边界：** Bobrow 等首先在免疫测定中验证了酶催化报告沉积的放大思路，它是后续相关技术的原理来源，而不是脑组织 TSA 多重染色的直接重复试验。(Bobrow et al., 1989, J Immunol Methods)

### 3. 组织处理与抗原可及性

**固定**可保持组织形态，也可能遮蔽表位。石蜡包埋切片（FFPE）、冰冻切片、游离漂浮切片和厚组织整体染色有不同的通透性、形态保留、背景与取样限制，不能使用固定不变的抗原修复条件。1991 年的热修复比较已记录不同抗体出现增强、无变化或下降的结果。(Shi et al., 1991, J Histochem Cytochem; Ramos-Vara, 2005, Vet Pathol)

薄片便于均一标记但可能截断细胞；厚切片与透明化组织更适合三维形态却引入深度相关的抗体穿透、折射率和组织形变问题。完整脑及大器官抗体标记的研究证明部分体系可行，但不能认定每一种抗体或每一个脑区的染色深度均已被充分验证。(Susaki et al., 2020, Nat Commun; Yapp et al., 2025, Nat Methods)

### 4. 神经科学常见分子标记及判读边界

| 标记 | 常用于观察 | 限制与替代解释 |
| --- | --- | --- |
| NeuN／RBFOX3 | 多数成熟神经元的核／胞体定位 | 普肯野细胞、部分嗅球细胞等存在阴性例外，发育状态也影响检出 |
| MAP2、神经丝 | 树突或神经突起结构 | 标记分布不等于完整远程轴突重建 |
| GFAP | 部分星形胶质细胞的中间丝及组织反应 | GFAP 单独不足以定义完整星形胶质细胞群或统一“反应性”状态 |
| Iba1／AIF1 | 许多小胶质及其他髓系细胞的形态 | 受病理和浸润影响；不总能单标识别小胶质起源 |
| TMEM119 等 | 在特定条件下辅助鉴别小胶质细胞 | 表达随物种、发育和疾病状态变化 |
| MBP／髓鞘蛋白 | 髓鞘相关分布和病变 | 染色强度不必与髓鞘完整性或蛋白总量成正比 |
| TH | 儿茶酚胺合成相关酶表型 | 不只存在于多巴胺神经元，单标记不能证明多巴胺释放 |
| c-Fos 等 IEG | 刺激相关转录反应的固定时间窗 | 不能还原实时放电或证明任务中的因果作用 |
| PSD-95、synaptophysin | 候选突触区域及蛋白斑点 | 光学共定位不直接证明单一前后突触搭档 |

(Mullen et al., 1992, Development; Kim et al., 2009, J Biol Chem; Ito et al., 1998, Brain Res Mol Brain Res; Bennett et al., 2016, PNAS; Escartin et al., 2021, Nat Neurosci; Sagar et al., 1988, Science; Prehn et al., 2023, Front Cell Neurosci)

### 5. 研究设计的一般步骤（非通用试剂处方）

1. 确定要观察的是**抗原定位、阳性细胞比例、分子状态、相对强度、脑区总体细胞数**中的哪一种。
2. 在当前物种、脑区、组织制备与实验状态下验证一抗，优先综合遗传阴性、阳／阴性组织、不同表位抗体和独立检测方式。
3. 预先确定相应检测体系及控制：只做省略一抗对照不能验证一抗对目标蛋白的特异性。
4. 控制组织固定、切片、标记及成像条件；荧光定量尤其应留在探测器的可比较线性范围。
5. 定义脑区边界、ROI 取样、阳性阈值及分割与盲法规则；明确独立生物学单位。
6. 针对关键结果使用多指标或跨技术核验，再把结论限制到被验证的观察层级。(Uhlen et al., 2016, Nat Methods; West et al., 1991, Anat Rec; Jost & Waters, 2019, J Cell Biol)

## 能回答什么，不能回答什么？

### 1. 直接观察、代理指标与外推层次

| 研究问题 | 观察到的实际读数 | 能够审慎支持 | 不能直接推断 |
| --- | --- | --- | --- |
| 组织中是否存在可检出目标信号？ | 一抗—检测体系对应的染色及背景差异 | 特定验证条件下的候选抗原定位 | 某蛋白在所有细胞中一定存在／不存在，或完全没有交叉反应 |
| 哪些细胞具有某标记表型？ | 单个或多个抗原阳性胞体、核与位置 | 经限定规则定义的候选细胞群 | 一个标记覆盖某细胞类型的所有成员 |
| 处理组阳性细胞数是否变化？ | 按分割与取样规则得到的阳性对象数 | 在相同预处理和抽样条件下的阳性群体变化 | 某群细胞数量一定死亡／生成；也可能只是表达越过阈值 |
| 某蛋白是否升高？ | 相对荧光强度、积分光密度、染色阳性面积 | 可比较条件下的相对免疫反应变化 | 绝对蛋白分子数、每细胞摩尔浓度或真实功能活性 |
| 两种抗原是否共定位？ | 像素空间重叠、双阳性细胞、共定位系数 | 在当前光学与阈值定义下的空间共现 | 蛋白直接结合、位于相同纳米复合物或形成突触 |
| c-Fos 对任务是否响应？ | 固定时间点 c-Fos 阳性细胞和脑区分布 | 一段诱导／表达窗口内的活动相关分子变化 | 毫秒级脉冲、瞬时神经电流或行为因果必要性 |
| 星形／小胶质是否具有病理状态？ | GFAP、Iba1 等强度及形态 | 某些状态相关免疫表型改变 | 所有细胞进入单一“有害／保护”状态 |

(Sagar et al., 1988, Science; Kovács, 2008, J Neuroendocrinol; Dunn et al., 2011, Am J Physiol Cell Physiol; Escartin et al., 2021, Nat Neurosci)

### 2. 四种经常被混淆的数量

**阳性细胞数、阳性面积、单细胞平均亮度、脑区总荧光**不是同一项测量。亮度受抗原暴露、二抗量、反应放大、镜头、探测器和组织背景影响；阳性面积还可能受突起形态与阈值变化影响。在局灶缺血小鼠中，抗体克隆性和组织预处理曾导致 IF 强度与 Western blot 所见变化不一致，这是“染色越亮就必然蛋白越多”的直接反例。(Prehn et al., 2023, Front Cell Neurosci; Waters, 2009, J Cell Biol)

若目标是脑区**神经元总体数量**，不能把随机拍几张切片所得的二维阳性密度直接当作全脑区总数。光学分样器等体视学方法规定了系统均匀随机抽样及计数框架；但无偏取样也无法纠正抗体未识别某类真实细胞的错误。(West et al., 1991, Anat Rec; Schmitz & Hof, 2005, Neuroscience)

### 3. 共定位与分子互作

两个颜色在光镜图像里叠合，可能是空间尺度、离焦背景或光谱泄漏所致。即使使用 Pearson 或 Manders 等系数，量化的仍是空间信号相关性。**直接分子相互作用或确定的突触前后配对**，应依研究对象选用附加的高分辨、遗传、生物化学或电生理证据。(Dunn et al., 2011, Am J Physiol Cell Physiol; Jost & Waters, 2019, J Cell Biol)

## 空间、时间尺度与适用对象

### 1. 空间分辨与组织覆盖

- **亚细胞和细胞级**：可定位核抗原、膜蛋白、树突标记与突触相关荧光斑点，但实际可分辨尺度取决于标记、样本、物镜与点扩散函数，而非仅由显微镜的标称放大倍数决定。(Waters, 2009, J Cell Biol)
- **局部脑区及组织层**：宽视野扫描、共聚焦和图像分析支持脑区层次细胞分布与阳性细胞统计；图谱配准和脑区边界定义可能改变计数结果。(Bankhead et al., 2017, Sci Rep)
- **厚切片与整器官**：透明化及光片可扩大覆盖，但抗体能否进入深层、固定后是否发生收缩与变形须独立核查。荧光成像覆盖完整脑体积不等于每个目标分子都已被检出。(Renier et al., 2016, Cell; Susaki et al., 2020, Nat Commun)
- **多轮多标记与三维**：循环 IF 可增加在同一样本上可观察的指标，厚切片三维多重研究也指出常规薄片内细胞被截断对空间邻近分析的潜在影响；但相关 2025 年技术验证主要使用人类肿瘤组织，不能自动移用至脑组织。(Lin et al., 2018, eLife; Yapp et al., 2025, Nat Methods)

### 2. 时间尺度

大部分 IHC 使用固定组织，所见是**取样时点保留下来的蛋白和表位状态**，并非实时的生理活动录像。c-Fos 等即时早期基因蛋白的表达有生物学诱导和检出时程，因此染色可表示某时间窗的活动相关历史，但无法恢复所有动作电位、突触输入或细胞连续时间序列。(Sagar et al., 1988, Science; Kovács, 2008, J Neuroendocrinol)

### 3. 样本与外推边界

- **啮齿类脑**：具有大量经典标记与区域图谱实践，但不同发育期、品系和病理条件的抗原表现可能不同。
- **非人灵长类脑**：狨猴脑多重批次免疫荧光有已发表的原始方法验证；其抗体面板和组织处理条件不能机械外推到所有灵长类与脑区。(Chitsaz et al., 2025, Brain Behav)
- **人体离体脑**：能观察细胞／病理空间标记，但死后延迟、固定历程、原发病及保存条件影响表位可及性；不能称为人脑活体实时蛋白成像。
- **非脑组织技术原始研究**：FFPE 肿瘤和小鼠脾脏的多重 IF 结果支持染色平台的可行性，**不是**成人脑、髓鞘丰富脑区或脑病组织标记特异性的独立验证。(Gerdes et al., 2013, PNAS; Goltsev et al., 2018, Cell; Yapp et al., 2025, Nat Methods)

## 质量控制与典型伪迹

### 1. 误差来源、可能误判与验证思路

下列为**科研编辑性质量控制建议**，不是学会发布的单一强制规范。不同阴性对照所控制的偏差也不相同。(Uhlen et al., 2016, Nat Methods; Jost & Waters, 2019, J Cell Biol)

| 误差源 | 可能的误判 | 针对性验证和报告 |
| --- | --- | --- |
| 一抗与非目标蛋白交叉反应 | 错误细胞／脑区出现目标蛋白阳性 | 靶基因缺失、已知正负组织、不同表位抗体、正交检测组合 |
| 批次／克隆／厂家信息不完整 | 同名抗体跨实验出现不同染色图谱 | 报告厂家、货号、克隆、批号、RRID 与当前组织验证 |
| 只做省略一抗控制 | 忽略一抗本身的非特异结合 | 区分二抗背景控制与真正的靶标特异性控制 |
| 二抗串扰或同宿主多重染色交叉 | 假双阳性细胞和不真实共定位 | 二抗吸附验证、单染／串色控制、换用相容的标记策略 |
| 内源性过氧化酶或生物素 | 没有目标抗原也出现显色 | 与所用检测体系相匹配的内源酶、亲和素结合背景对照 |
| 固定时长及抗原修复变化 | 表位遮蔽或非特异性增强 | 记录所有样本的处理，针对目标抗原验证修复必要性 |
| 脂褐素与组织自发荧光 | 多个荧光通道出现背景亮点 | 观察无一抗或未标记组织，检查光谱和背景处理是否同时损失真信号 |
| 光漂白、曝光差异、探测饱和 | 伪组间强度差异或真正差异被压缩 | 在相同线性采集范围内取像，保留完整原始图及元数据 |
| 厚组织抗体穿透梯度 | 深层细胞被错误认定无表达 | 对比组织各深度阳性率、背景及相应薄片控制 |
| 单标记无法完整定义细胞型 | 例如 NeuN 阴性神经元被误作非神经元 | 联用多指标、解剖背景和适当细胞身份验证 |
| 细胞／纤维重叠及自动分割错误 | 将相邻胞体合并、血管背景当胞体 | 在代表性脑区和批次上进行盲法人工标注抽查 |
| 薄片细胞截断、切片损失或组织形变 | 细胞计数及脑区体积失真 | 记录厚度、间距、脑区界限与体视学／三维抽样框架 |
| 多轮染色信号残留或抗原损耗 | 假表型共现、后轮强度系统变低 | 每轮检查失活／去除有效性与跨轮图像注册 |
| 选择“最亮视野”或把细胞当独立动物 | 偏向支持假说且显著性虚高 | 事先确定 ROI、盲法取样，按真实动物／供体汇总统计 |
| 图像阈值、批次归一化和后处理 | 人工制造差异或掩盖失败样本 | 冻结分析版本，原始图、处理流水线和排除条件共同保存 |

(Wood & Warnke, 1981, J Histochem Cytochem; Shi et al., 1991, J Histochem Cytochem; Schnell et al., 1999, J Histochem Cytochem; Bandrowski et al., 2016, Neuroinformatics; Wang et al., 2025, Cell Rep Methods)

### 2. 抗体验证不应只依赖一种阴性控制

- **靶基因敲除／缺失组织**：若标记随目标基因缺失消失，对当前体系内特异性提供强支持，但仍要检查敲除造成的细胞状态变化和间接效应。
- **第二种表位不同的抗体**：两支独立抗体图谱接近可增加信心，但仍可能共享组织背景、固定伪迹或同类脱靶。
- **免疫印迹、质谱、RNA 原位检测等正交证据**：能帮助辨别抗原身份与表达背景，却不一定提供与组织 IF 相同的细胞空间读数。
- **省略一抗、二抗空白、同型对照**：分别检查检测系统或部分非特异背景；**省略一抗绝不等同于证明一抗只识别目标蛋白**。
- **已知阳／阴性组织与独立生物学重复**：共同检验标记位置、样本状态和批次可比较性，而非只确认单张图像可见。(Bordeaux et al., 2010, Biotechniques; Uhlen et al., 2016, Nat Methods)

### 3. 三项重要的负面／限制性证据

**第一，抗原修复并非总有益。** 对 FFPE 组织开展的早期比较已经显示部分抗体修复后不变或信号降低，因而“更强的加热处理”并不等价于“更真实的生物学结果”。(Shi et al., 1991, J Histochem Cytochem)

**第二，脑损伤组织可能改变 IF 与蛋白丰度之间的关系。** 在缺血小鼠模型中，Prehn 等使用不同克隆性抗体并比较 IF 和 Western blot，发现一些强度差异无法简单解释为蛋白总量变化；固定和修复本身还可能不同程度地影响受损与未受损组织。这是局部病理环境的直接反例，不能反过来说所有 IHC 定量都无效。(Prehn et al., 2023, Front Cell Neurosci)

**第三，单一标记不是细胞全集。** NeuN 对部分真实神经元存在阴性例外，GFAP 也不足以独自划分所有反应性星形胶质状态；“标记减弱”可以来自抗原变化、检出变化或细胞数量变化，应保留这些竞争解释。(Mullen et al., 1992, Development; Escartin et al., 2021, Nat Neurosci)

### 4. 计数、算法、批次和统计单位

CellProfiler、Fiji、QuPath、Cellpose 等提供可记录的图像分析流程，**软件并不代替在本实验上检查误检／漏检**；脑内不规则神经元及胶质突起尤其需要仔细检查分割规则。(Carpenter et al., 2006, Genome Biol; Schindelin et al., 2012, Nat Methods; Bankhead et al., 2017, Sci Rep; Stringer et al., 2021, Nat Methods)

若研究完整核团的细胞总数，需考虑**系统均匀随机取样**及正确三维计数框架；若研究的是某标记的相对强度，则需尽可能固定染色和成像条件，且不把曝光后画面的亮度当作实际的绝对浓度。(West et al., 1991, Anat Rec; Schmitz & Hof, 2005, Neuroscience; Waters, 2009, J Cell Biol)

2025 年的 UniFORM 为多重成像的批次归一化提供一种可评估的分析方案，但**归一化无法恢复未被染到的细胞或被固定遮蔽的抗原**。独立生物学样本通常是动物／供体，而不是一幅图内每个像素或细胞。(Wang et al., 2025, Cell Rep Methods)

### 5. 建议报告的可复核信息

至少报告：物种、品系／供体与年龄、实验或病理状态、脑区与采样边界、固定方式和时间、切片厚度与组织处理、全部一抗与二抗的厂家／货号／克隆／批号／RRID、实际应用内验证、正负对照、显色或荧光平台、通道设置与采集参数、阳性阈值和计数对象定义、分割算法与版本、样本排除规则、真实生物学重复单位、批次及统计方法。这是**透明报告的编辑性检查表**，不是已确立的统一认证标准。(Bandrowski et al., 2016, Neuroinformatics; Jost & Waters, 2019, J Cell Biol)

## 代表性实验或应用

### 1. 从荧光抗体到酶促组织显色

Coons 与 Kaplan 在 1950 年展示荧光抗体抗原定位方法；Nakane 与 Pierce 在 1966 年发展了酶标抗体定位；Hsu 等随后比较 ABC 与其他免疫过氧化物酶检测体系，同一时期 Wood 与 Warnke 已经直接描述内源性亲和素结合所产生的非目标背景。(Coons & Kaplan, 1950, J Exp Med; Nakane & Pierce, 1966, J Histochem Cytochem; Hsu et al., 1981, J Histochem Cytochem; Wood & Warnke, 1981, J Histochem Cytochem)

**支持**：抗体识别和多种显影路线可以操作性结合。**不能证明**：更高检测灵敏度就意味着更高的识别特异性或任何组织均无背景。

### 2. 抗原修复和检测放大的历史进展

Bobrow 等发展了酶催化报告沉积的基础技术；Shi 等以 FFPE 切片直接比较加热修复对多支抗体的影响。后续方法研究与综述使抗原可及性、显影反应、非特异背景与多重染色成为独立质控问题。(Bobrow et al., 1989, J Immunol Methods; Shi et al., 1991, J Histochem Cytochem; Stack et al., 2014, Methods)

### 3. NeuN 的细胞分布与 RBFOX3 分子身份

Mullen 等观察到 NeuN 在多数成熟神经元中的定位，同时报告普肯野细胞等的阴性例外；Kim 等随后将 NeuN 分子身份联系到 Fox-3／RBFOX3。这组研究说明**某抗体识别到什么抗原**与**该抗原覆盖哪些神经元**是两个需要分别证明的问题。(Mullen et al., 1992, Development; Kim et al., 2009, J Biol Chem)

### 4. c-Fos：刺激相关细胞定位与全脑空间图谱

Sagar 等展示刺激后 Fos 蛋白可通过免疫染色形成区域性细胞标记；Renier 等结合整体组织免疫染色、透明化和自动图谱统计，将即时早期基因的空间观察扩展到全脑范围。(Sagar et al., 1988, Science; Kovács, 2008, J Neuroendocrinol; Renier et al., 2016, Cell)

**支持**：特定诱导与检测时间窗内的活动相关分子图。**不能支持**：毫秒级放电波形或被标记细胞对行为的因果必要性。

### 5. 小胶质／星形胶质标记的边界验证

Iba1 的发现研究、TMEM119 等辅助小胶质标记的建立，以及星形胶质反应性命名共识，提供了跨细胞类型的证据：**一个抗原标记可以帮助分类，但并不自动构成细胞型或细胞状态的完整定义**。(Ito et al., 1998, Brain Res Mol Brain Res; Bennett et al., 2016, PNAS; Escartin et al., 2021, Nat Neurosci)

### 6. 小胶质与突触相互作用的多技术交叉证据

Tremblay 等结合免疫细胞学、电镜连续切片重建以及活体双光子成像，分析了幼鼠视觉皮层小胶质细胞的突触邻近与视觉经验相关变化。这里的动态接触及超微结构主张来自**跨方法组合**，不能回写成普通 Iba1 染色图像直接测得的全部事实。(Tremblay et al., 2010, PLoS Biol)

### 7. 从单／双标记走向多重和整器官染色

Gerdes 等在 FFPE 肿瘤组织中演示高重数单细胞表型分析，Lin 等提出 t-CyCIF，Goltsev 等使用 CODEX 分析脾脏细胞空间结构；Susaki 等则将优化的整体免疫染色推进到大脑和其他大型器官。(Gerdes et al., 2013, PNAS; Lin et al., 2018, eLife; Goltsev et al., 2018, Cell; Susaki et al., 2020, Nat Commun)

**独立性与外推**：这是不同组织、不同检测机制的方法进展，不是同一抗体在成人脑所有细胞型的多实验室盲法复现。

### 8. 2023 年脑缺血组织的定量反例

Prehn 等直接比较小鼠脑缺血模型中不同抗体克隆性与组织处理对 IF 强度的影响，并与 Western blot 结果对照。其发现支持免疫染色**不应被无条件解释为蛋白丰度直接测量**，同时也说明必须区分模型内结果与跨组织普遍规律。(Prehn et al., 2023, Front Cell Neurosci)

### 9. 2025—2026 年：灵长类脑、3D 多重 IF 和计算方法

Chitsaz 等在狨猴脑切片上发展可批量处理的多重免疫荧光标记；Yapp 等在非脑的厚切片组织演示三维循环 IF 的细胞完整性优势；Wang 等提出免疫荧光批次归一化工具；Huang 等则在 2026 年提出专用于脑组织多重 IHC 图像的 mViSE 视觉检索方法。(Chitsaz et al., 2025, Brain Behav; Yapp et al., 2025, Nat Methods; Wang et al., 2025, Cell Rep Methods; Huang et al., 2026, Sci Rep)

**支持**：更复杂的空间蛋白成像与计算分析工具。**不能证明**：软件检索到的细胞邻域就是细胞通信的因果机制，或所有染色面板已经免于抗体特异性验证。

## 与其他方法的关系

| 相邻方法 | 如何互补 | 证据边界 |
| --- | --- | --- |
| **单细胞RNA测序／单核RNA测序** | 获得大规模细胞转录身份，辅助选取抗体标记 | RNA 与蛋白不同，解离测序通常丢失原位置 |
| **空间转录组与原位杂交** | 在组织中定位 RNA，补充蛋白分子表型 | RNA 阳性不等于蛋白 IF 强度及定位必然一致 |
| **组织透明化与光片成像** | 提高厚组织／全脑抗原标记的三维覆盖 | 透明化不等于抗体验证；深度穿透与组织变形须另测 |
| **神经示踪、AAV病毒载体示踪** | 示踪界定投射方向，IHC 补充被示踪细胞分子身份 | 双阳性不直接证明突触或功能联系 |
| **电子显微镜／关联光镜电镜** | 检验候选细胞接触与亚细胞超微结构 | IF 空间邻近不能直接替代纳米突触确认 |
| **蛋白质组学／Western blot** | 辅助检查蛋白身份、相对丰度与抗体异常结果 | 匀浆没有单细胞空间定位，也可能出现表位和检测偏差 |
| **光遗传／膜片钳／在体钙成像** | 从实时信号及干预角度检验活动标记的功能解释 | IEG 阳性与即时电生理活动并非同一种读数 |
| **细胞型遗传报告与敲除** | 验证抗体识别或细胞身份 | 报告系统本身也有表达与操作偏差 |
| **CyCIF、CODEX 等多重蛋白成像** | 扩大同一组织上可比较标记数量 | 跨轮配准、抗原流失与批次效应须控制 |
| **Fiji、CellProfiler、QuPath、Cellpose、mViSE** | 提供从像素到细胞／区域统计的计算方法 | 任何算法都不能弥补未检出抗原或验证失败的一抗 |

(Dunn et al., 2011, Am J Physiol Cell Physiol; Yao et al., 2023, Nature; Prehn et al., 2023, Front Cell Neurosci; Huang et al., 2026, Sci Rep)

\*\*方法选择原则：\*\*想知道“某个抗原在哪儿能被检测到”，IHC 是有力工具；想知道基因转录谱，需 RNA 方法；想知道谁和谁真正形成突触，需超微结构及其他经过验证的连接方法；想知道细胞活动或行为因果，需实时记录与干预。不能靠染色图跨越全部层次。(Yao et al., 2023, Nature; Tremblay et al., 2010, PLoS Biol)

### 证据等级与人工审核

1. **较稳定基础**：经应用内验证的抗体可在组织空间背景定位目标相关抗原；染色还受固定、表位暴露、酶促放大、光学采集与算法阈值影响。
2. **有条件成立**：特定细胞型标记、真实阳性细胞数量、病理状态比较、多轮染色、全器官染色均依赖物种、抗体、组织与分析方案。
3. **不能直接得出**：荧光强度即绝对蛋白量；颜色叠合即分子相互作用；NeuN 覆盖所有神经元；单一 GFAP／Iba1／c-Fos 标记就确定完整细胞功能状态。
4. **证据独立性**：不同原始抗原／染色方法提供多机制验证，但同平台升级、同数据二次分析及非脑组织技术演示不能计为脑组织结果的全新独立生物学重复。
5. **未完成／原因**：未取得用户完整 Vault 与实验原始图像，因此未验证已有同义节点、双链真实路径、实际抗体性能或批次重复性；文件内文献提供 DOI 核验入口，真正采用前仍需按所需结论审阅原文图表。
