# 空间转录组学

> **一句话介绍：** 空间转录组学（spatial transcriptomics；也称 spatially resolved transcriptomics）是一组在保存组织空间信息的前提下测量 RNA 分布的实验与计算方法，帮助研究者回答\*\*“哪些基因在组织的什么位置、由哪些细胞或细胞群表达”\*\*；它测到的是空间化的 RNA 信号，并不直接证明蛋白功能、突触连接或行为因果关系。(Ståhl et al., 2016, Science; Chen et al., 2015, Science; Yao et al., 2023, Nature)

## 快速理解

常规单细胞 RNA 测序可以把复杂脑组织拆解成许多转录组不同的细胞，却常常丢失这些细胞原先的**解剖地址**。空间转录组学尝试让表达数据留在地图上：既知道“某个位置有什么 RNA”，也能尽可能回答“它位于哪一层皮层、哪一个脑核团，周围还有谁”。早期空间条码测序与后来在原位逐分子识别 RNA 的方法，是实现这一目标的不同技术路线。(Ståhl et al., 2016, Science; Chen et al., 2015, Science; Moffitt et al., 2018, Science)

**必须分清三个层次：**

1. **原始观测：** 组织上的条码捕获位置及其测序读数，或者显微图像里被识别的 RNA 分子及坐标。不同平台的检测单位可能是一个包含多细胞的捕获区域、接近单细胞大小的位置，或被分配到单个细胞的分子。(Rodriques et al., 2019, Science; Eng et al., 2019, Nature)
2. **计算重建：** 用图像分割、去卷积、单细胞参考图谱匹配、空间域聚类等方法，推测哪些位置有哪些细胞类型。这些结果依赖算法、参考数据与参数，并不全是显微镜直接看见的细胞身份。(Biancalani et al., 2021, Nat Methods; Kleshchevnikov et al., 2022, Nat Biotechnol; Li et al., 2023, Nat Commun)
3. **生物学解释：** 细胞邻近、配体—受体 RNA 同时表达、或空间上共同变化，可以提出细胞互作与回路研究的候选假说，但**不能自动认定存在有效信号传递、直接突触或者因果关系**。(Efremova et al., 2020, Nat Protoc; Jin et al., 2021, Nat Commun)

**在脑科学中的直观用途：** 给细胞类型图谱加上脑区、核团和皮层层次坐标；分析神经元与星形胶质细胞、小胶质细胞、血管相关细胞的空间组织；比较发育、疾病模型或处理条件中的局部分子状态；检验单细胞转录组亚群是否有可重复的空间分布。(Codeluppi et al., 2018, Nat Methods; Yao et al., 2023, Nature; Huuki-Myers et al., 2024, Science)

## 原理与操作流程

### 一、按主要读出方式划分的技术路线

| 技术路线 | 基本思路与代表技术 | 常见优势 | 主要限制与误解 |
| --- | --- | --- | --- |
| **空间条码捕获＋测序** | 组织切片放在已知坐标的条码阵列上，RNA 被捕获后通过测序恢复“位置—表达”关系；经典 ST、HDST、Slide-seq / Slide-seqV2、Stereo-seq 是代表。(Ståhl et al., 2016, Science; Vickovic et al., 2019, Nat Methods; Rodriques et al., 2019, Science; Stickels et al., 2021, Nat Biotechnol; Chen et al., 2022, Cell) | 容易同时分析较多基因；部分平台可覆盖较大组织范围或接近细胞尺度 | 条码点大小不等于有效分辨率；有些点包含多个细胞；捕获效率、RNA 扩散和测序深度影响解释 |
| **组织原位荧光杂交成像** | 在组织中多轮识别指定 RNA，或使用纠错编码形成多重 RNA 图像；seqFISH、MERFISH、osmFISH、seqFISH+ 等。(Lubeck et al., 2014, Nat Methods; Chen et al., 2015, Science; Codeluppi et al., 2018, Nat Methods; Eng et al., 2019, Nature) | RNA 分子坐标与组织图像直接关联；有的平台能分析亚细胞定位 | 常需预先设计基因面板；图像拥挤、探针性能、分子识别及细胞分割均可产生偏差 |
| **原位测序与三维读出** | 在保存组织形态的情况下通过原位核酸识别、扩增及读取进行空间表达测定；原位测序（ISS）和 STARmap 是代表。(Ke et al., 2013, Nat Methods; Wang et al., 2018, Science) | 可以与局部三维组织结构对应 | 原位识别效率、覆盖的基因集合和组织处理限制使其与普通全长 RNA-seq 不等价 |
| **空间多组学及流程拓展** | 通过组织内确定性条码等方法联合读取 RNA 与其他分子层信息，例如 DBiT-seq。(Liu et al., 2020, Cell) | 将空间表达与蛋白或其他组学读出共同解释 | 不同分子层的空间分辨率、检出灵敏度与背景不一定相同 |

> **分类提醒：** “测序型”和“成像型”是按主要 RNA 读出机制做的实用划分，不是所有平台都严格互斥；一些技术含有原位扩增、成像解码与后续测序等组合步骤。不能将品牌或平台名称直接等同于固定的单细胞精度。(Ke et al., 2013, Nat Methods; You et al., 2024, Nat Methods)

### 二、从组织到可解释结果的概念性流程

1. **定义问题与取样层级：** 明确物种、脑区、发育时期、组织状态、比较组与生物学重复单位；决定重点是区域表达图谱、细胞定位、亚细胞 RNA，还是转录本异构体。(Moffitt et al., 2018, Science; Liu et al., 2026, Nat Methods)
2. **尽量保存组织空间背景：** 保留对应的组织影像、切片方向和解剖标注；不同保存与检测方式可能改变 RNA 的保留及可检出分布。(Ståhl et al., 2016, Science; You et al., 2024, Nat Methods)
3. **获得空间化 RNA 信号：** 根据平台输出坐标—表达矩阵、RNA 分子点云或成像解码数据；记录检测单位、基因面板与测量的技术限制。(Chen et al., 2015, Science; Rodriques et al., 2019, Science; Eng et al., 2019, Nature)
4. **质量控制与配准：** 检查组织破损、局部信号异常、背景及批次；将分子或捕获坐标与组织图像对应，并保留定位不确定性。(You et al., 2024, Nat Methods; Totty et al., 2025, Nat Methods)
5. **细胞与区域层的计算分析：** 在需要时进行细胞分割、区域注释、低分辨率点的细胞组成去卷积、空间差异表达及邻域分析；区分数据直接支持与模型补全的成分。(Svensson et al., 2018, Nat Methods; Petukhov et al., 2022, Nat Biotechnol; Kleshchevnikov et al., 2022, Nat Biotechnol)
6. **生物学验证：** 结合独立样本、靶向原位检测、蛋白/形态/电生理证据，验证最关键的分区、细胞身份或分子相互作用假说；避免让一个数据集的聚类定义充当其自身的独立验证。(Yao et al., 2023, Nature; Huuki-Myers et al., 2024, Science; Yuan et al., 2024, Nat Methods)

### 三、测量对象与计算产物

- **原始数据：** 条码与组织空间位置关联的 reads / UMI 计数（视平台而定），或特定 RNA 分子在图像中的识别与坐标；一般是一定检测效率下的表达代理量，并非所有 RNA 分子的绝对普查。(Ståhl et al., 2016, Science; Chen et al., 2015, Science)
- **细胞级结果：** 当单细胞分割准确且每个细胞可归属足够信号时，能得到近似细胞级表达矩阵；若采用多细胞 spot 的去卷积，所得“细胞比例/丰度”是**模型估计**，不能与逐细胞实际观测混写。(Cable et al., 2022, Nat Biotechnol; Kleshchevnikov et al., 2022, Nat Biotechnol; Petukhov et al., 2022, Nat Biotechnol)
- **空间统计与配体—受体互作：** 空间变异基因、空间域、邻域富集和候选通讯均依赖检验假设、空间邻接规则或分子数据库；它们是衍生结论而非实验直接记录的交流事件。(Svensson et al., 2018, Nat Methods; Sun et al., 2020, Nat Methods; Palla et al., 2022, Nat Methods; Jin et al., 2021, Nat Commun)

## 能回答什么，不能回答什么？

| 科学问题 | 本方法可以提供什么 | 不能直接推出什么、需补什么证据 |
| --- | --- | --- |
| 哪些 RNA 富集在特定脑区或皮层层次？ | RNA 随解剖空间变化的分布图及条件间比较。(Codeluppi et al., 2018, Nat Methods; Huuki-Myers et al., 2024, Science) | RNA 信号不是蛋白含量、细胞放电或回路活动的直接读数 |
| 某种转录组细胞亚型位于哪里？ | 利用多基因定位及与 sc/snRNA-seq 图谱整合形成的空间细胞注释。(Yao et al., 2023, Nature; Zhang et al., 2023, Nature) | 聚类/标签不天然等同独立的功能性细胞类型；映射有错误率 |
| 两类细胞是否倾向于相邻？ | 邻域、距离或共定位统计及其不确定性。(Palla et al., 2022, Nat Methods) | 相邻不代表直接接触、突触连接、配体释放或功能依赖 |
| 低分辨率 spot 内有哪些细胞类型？ | 依托参考图谱的去卷积组成估计。(Cable et al., 2022, Nat Biotechnol; Li et al., 2023, Nat Commun) | 不等于确定了点内每个真实细胞的身份、边界或准确数目 |
| 哪些基因具有空间表达模式？ | 空间变异基因与空间域候选。(Svensson et al., 2018, Nat Methods; Sun et al., 2020, Nat Methods) | 模式可能来自细胞组成、局部文库大小或组织损伤，不能自动当作细胞内调控变化 |
| 是否出现细胞间通讯？ | 由邻近关系与配体—受体表达产生的候选通讯机制。(Efremova et al., 2020, Nat Protoc; Jin et al., 2021, Nat Commun) | 不能证明蛋白实际结合、跨细胞信号发生，更不能等同神经元突触传递 |
| 处理或疾病导致了哪种机制？ | 可观察特定条件下的空间相关表达差异。(Bhuva et al., 2024, Genome Biol) | 单纯横断面对比不能确证时序、病因或细胞间因果链；需统计设计与扰动验证 |
| 是否能读出剪接异构体或 RNA 编辑？ | **部分特定新平台或分析框架能够**研究其空间特征。(Liu et al., 2026, Nat Methods; Chen et al., 2026, Nat Commun) | 不可推广为所有空间转录组系统自带全长转录本或高可信编辑位点检测能力 |

一个重要的表述原则是：**空间位置是被保留的观测维度；细胞身份、互作和因果机制是不同强度的推断层级。** 当实验只报告 RNA 图谱时，最好使用“定位到”“富集于”“与……邻近”“预测可能”而不是“证明该神经元驱动了……”。(Moffitt et al., 2018, Science; Yao et al., 2023, Nature; You et al., 2024, Nat Methods)

## 空间、时间尺度与适用对象

### 空间尺度不只有一个“分辨率”数字

- **捕获单元尺度：** 平台标称的 spot、bead、bin 或编码位置大小，影响混合细胞 RNA 的可能性。(Ståhl et al., 2016, Science; Vickovic et al., 2019, Nat Methods; Rodriques et al., 2019, Science)
- **有效空间分辨率：** RNA 扩散、捕获效率、分子错位、光学识别及算法聚合共同决定能区分多细的组织结构。2024 年跨平台实测明确显示，不能仅用平台的标称点间距代替实际有效分辨率。(You et al., 2024, Nat Methods)
- **生物学单细胞分辨率：** 一张“亚细胞大小 bin”的图并不自动意味着每个 bin 都能无误归属到一个完整细胞；神经元长突起、细胞密集层以及不规则的细胞边界尤其需要检查分割和未归属 RNA。(Petukhov et al., 2022, Nat Biotechnol; Jones et al., 2025, Nat Methods; Lee et al., 2026, Nat Commun)
- **组织覆盖与三维恢复：** 单张组织切片常提供二维位置；研究整个脑区或三维结构通常要结合连续切片、组织登记或三维原位检测，并处理切片间缺失与形变。(Wang et al., 2018, Science; Zhang et al., 2023, Nature)

### 时间尺度和研究对象

单次采样大多提供组织在取材时点的**空间分子快照**。比较发育阶段、损伤前后或不同疾病状态，可以构建时空图谱，但不同个体/切片间的变化不等于同一细胞被真实连续追踪，更不自动等于细胞谱系迁移。(Chen et al., 2022, Cell; Moffitt et al., 2018, Science)

神经科学常用样本包括小鼠脑组织切片、发育期脑组织、人脑死后样本及部分灵长类材料。物种、样本保存方式与基因面板差异，都会限制跨图谱的直接比较。(Yao et al., 2023, Nature; Huuki-Myers et al., 2024, Science; Liu et al., 2026, Nat Methods)

**平台选型不是单一排名：** 对“全组织表达模式”可优先评估覆盖范围与基因检出；对“少量稀有细胞的可靠定位”要更重视检测灵敏度、单细胞分割及验证；对“神经突起内 RNA”要保留亚细胞位置信息而不能把全部点强制分到胞体。不同方法的分辨率、通量、覆盖与成本存在条件性取舍。(Eng et al., 2019, Nature; You et al., 2024, Nat Methods; Lee et al., 2026, Nat Commun)

## 质量控制与典型伪迹

### 1. 组织学与实验读出层面

- **切片破损、局部折叠、组织外背景、未覆盖区：** 可能生成伪空间域或异常低/高表达区域。2025 年提出的空间感知 QC 方法利用局部邻域发现局部及区域性异常，说明直接搬用 scRNA-seq 的全局阈值并不可靠。(Totty et al., 2025, Nat Methods)
- **捕获效率与扩散伪迹：** 转录本可能偏离真实来源位置；相邻组织类型信号的串扰会使“边界模糊”既可能是生物学连续变化，也可能是检测扩散。(You et al., 2024, Nat Methods)
- **平台选择性：** 探针面板缺乏某亚型标记、识别效率不均或测序覆盖不足，均会使细胞/分子群体被低估。影像式技术的靶向面板与测序式技术的广泛基因覆盖，在“能不能找到未知细胞状态”上不可完全等价。(Eng et al., 2019, Nature; Yao et al., 2023, Nature)
- **测序文库大小混杂：** 文库大小变化在不同位置可能对应生物学组织结构，也可能是技术差异；未经验证的简单归一化可能扭曲空间表达趋势。(Bhuva et al., 2024, Genome Biol)

### 2. 细胞层面的错误

- **分割过大、过小、细胞合并或碎裂：** 会把一个细胞的 RNA 分给其他细胞，甚至生成虚假的细胞。Baysor、Proseg 和新一代跨平台识别方法均从不同角度处理这一问题；某方法在其基准数据上更好，并不保证任何脑组织都最优。(Petukhov et al., 2022, Nat Biotechnol; Jones et al., 2025, Nat Methods; Sun et al., 2026, Nat Genet)
- **未归属 RNA 与神经突起：** RNA 并不只存在于胞体内部，强制按细胞核划分可能遗漏来自神经突起或难分割细胞的信号；2026 年 RESCUE 研究提示这些未归属成分有时含重要生物学模式。(Lee et al., 2026, Nat Commun)
- **参考图谱错配：** 用不同物种、时期、脑区或样本条件下的单细胞图谱去推断空间细胞类型，可能产生“似乎匹配、实际上不存在”的类别。对照已知标记的空间位置，并报告去卷积不确定性。(Cable et al., 2022, Nat Biotechnol; Kleshchevnikov et al., 2022, Nat Biotechnol; Li et al., 2023, Nat Commun)

### 3. 统计与计算推断层面

- **空间自相关不等于生物学机制：** 空间表达显著可能源自解剖分层与细胞组成；空间变异检验需要适当零模型与多重检验控制，不能仅凭颜色渐变宣称新分子机制。(Svensson et al., 2018, Nat Methods; Sun et al., 2020, Nat Methods)
- **空间域聚类存在算法依赖：** 2024 年比较研究发现不同聚类方法各有适用条件，非连续空间域尤其容易成为难题。聚类的“层数/区域数”不是客观无误的脑区真值。(Yuan et al., 2024, Nat Methods)
- **细胞、spot 或 RNA 分子不等于独立生物学重复：** 条件间统计应说明供体/动物、组织切片、脑区与细胞的嵌套结构，避免把单个动物上的大量点当作大量独立动物。(Huuki-Myers et al., 2024, Science; Bhuva et al., 2024, Genome Biol)
- **空间邻近或配体—受体预测的假阳性：** 邻接半径、分割偏差、组织组成、表达阈值及数据库假设都会改变候选互作图；最佳做法是把通讯概率标为“预测”而非真实发生的生理事件。(Efremova et al., 2020, Nat Protoc; Jin et al., 2021, Nat Commun; Palla et al., 2022, Nat Methods)

### 最低限度的报告与核验清单

- **材料：** 物种、脑区、年龄/疾病状态、取材/保存方式、切片方向、动物或供体数量与分组。
- **技术：** 实际平台版本、分析所用基因集合/面板、空间捕获/成像单位、读出限制和组织覆盖范围。
- **QC：** 空间位置质量图、组织损伤与离群区域、局部背景、检出基因及信号强度、排除标准；不要只给一个全局通过率。
- **计算：** 图像配准、细胞分割/去卷积、参考单细胞图谱来源、归一化、空间统计与邻域设定、参数敏感性。
- **重复性：** 以生物学样本作为比较的基本重复单位；报告切片内与样本间的变异，并尝试对关键空间模式用另一技术独立验证。
- **推断：** 将实际测到的 RNA、模型预测的细胞身份与未经验证的通讯/功能假说分开表述。(You et al., 2024, Nat Methods; Totty et al., 2025, Nat Methods; Li et al., 2023, Nat Commun)

## 代表性实验或应用

| 研究主题 | 代表性成果 | 证据性质及不可越过的边界 |
| --- | --- | --- |
| **空间测序奠基** | 在保留组织切片二维位置的条件下，获取小鼠脑组织等样本的空间化 RNA 测序信号。(Ståhl et al., 2016, Science) | 验证组织空间表达能被测量；早期捕获位置不是精确单细胞坐标 |
| **下丘脑分子—空间—功能整合** | 结合 MERFISH 等方法分析小鼠下丘脑视前区细胞的分子与空间分布，并与功能研究结合。(Moffitt et al., 2018, Science) | 空间标记提供细胞群候选；涉及行为的机制解释须查看独立功能实验 |
| **体感皮层分层与细胞组织** | osmFISH 测定细胞类型标志物，解析小鼠体感皮层内的空间组织。(Codeluppi et al., 2018, Nat Methods) | 面板内标记的空间分布，不是所有基因的无偏全转录组普查 |
| **皮层亚细胞 RNA 定位** | seqFISH+ 在小鼠皮层及相关脑组织显示大量基因的原位检测和细胞内 RNA 分布模式。(Eng et al., 2019, Nature) | 子细胞 RNA 位置不自动等于局部翻译活性或突触功能 |
| **大视野/更高密度捕获** | HDST、Slide-seq 与 Slide-seqV2 扩展空间捕获的密度或灵敏度。(Vickovic et al., 2019, Nat Methods; Rodriques et al., 2019, Science; Stickels et al., 2021, Nat Biotechnol) | 更密集点阵仍需检验每点的检出和真实归属 |
| **组织发育时空图谱** | Stereo-seq 构建小鼠器官发生过程的时空转录组图谱。(Chen et al., 2022, Cell) | 跨发育阶段的取样数据不等于同一细胞被连续观测 |
| **全脑细胞类型图谱** | 将单细胞 RNA 测序与 MERFISH 结合，形成成年小鼠全脑高分辨率细胞类型分类及空间地图；配套独立文章详述大范围分子定义的空间细胞组织。(Yao et al., 2023, Nature; Zhang et al., 2023, Nature) | 分类、空间推断与实际的生理功能、突触连接是不同证据层级；配套论文不是完全独立的重复 |
| **人前额叶空间图谱** | 联合单细胞/单核与空间转录组数据描绘人前额叶细胞组成和层次背景。(Huuki-Myers et al., 2024, Science) | 死后组织/供体结构、批次及脑区注释影响人群外推 |
| **跨平台有效分辨率比较** | 对多类测序型空间平台在参考组织上开展比较，揭示 RNA 扩散与检出灵敏度等条件效应。(You et al., 2024, Nat Methods) | 属测量技术基准，而非所有组织的统一平台优劣表 |
| **细胞边界与未归属 RNA** | 通过概率分割、空间感知 QC、未归属表达恢复与跨平台细胞识别改进分析。(Jones et al., 2025, Nat Methods; Totty et al., 2025, Nat Methods; Lee et al., 2026, Nat Commun; Sun et al., 2026, Nat Genet) | 这些工具显示旧分析的偏差可能被改善，但其优越性仍依赖数据集和评估标准 |
| **灵长类转录本异构体** | 新的全长单细胞空间测序研究解析灵长类脑内特定细胞类型和位置的转录本异构体分布。(Liu et al., 2026, Nat Methods) | 新型特定方案的能力；不是常规 3′ 偏向空间测序均可得到全长异构体 |
| **灵长类皮层 RNA 编辑** | 基于空间 RNA 测序及专门分析框架研究猕猴皮层层次与细胞类型相关的 A-to-I RNA 编辑。(Chen et al., 2026, Nat Commun) | RNA 编辑位点推断需排除基因组变异及覆盖度影响；研究中的疾病相关探索不能写成已确立病因 |

**重复性认识：** 空间 RNA 的位置化测量已经由多组技术体系与独立研究实现，是较稳固的方法学能力；但某个细胞亚型的精确数量、某个脑区的空间域边界、某条候选细胞通讯关系是否在不同平台/物种中严格相同，需要逐项核验，不能从平台广泛使用直接推出。(Moffitt et al., 2018, Science; Yao et al., 2023, Nature; You et al., 2024, Nat Methods; Yuan et al., 2024, Nat Methods)

## 与其他方法的关系

| 相关方法 | 互补性 | 特别注意 |
| --- | --- | --- |
| **单细胞 RNA 测序（scRNA-seq）及单核 RNA 测序（snRNA-seq）** | 通常具有更灵活的转录组覆盖与细胞分类；空间技术补回组织地址，并能用参考图谱辅助映射。(Biancalani et al., 2021, Nat Methods; Yao et al., 2023, Nature) | sc/snRNA-seq 参考类别与空间信号的匹配是模型推断；组织解离和细胞核取样带来不同偏差 |
| **传统 FISH、RNAscope 类靶向 RNA 原位检测** | 对关键空间差异基因作更聚焦的独立定位核查；高通量原位方法本身也是 FISH 技术发展的延伸。(Lubeck et al., 2014, Nat Methods; Chen et al., 2015, Science) | 定向基因验证不足以证明全基因组的无偏准确性 |
| **免疫组织化学、空间蛋白组** | 比较 RNA 与蛋白位置、细胞形态及激活标记 | mRNA 与蛋白并非一一对应，也不能把蛋白共定位自动读成功能相互作用 |
| **神经元形态重建、电子显微镜连接组** | 进一步检验空间相邻细胞是否形成结构性接触与突触 | RNA 图谱缺乏细胞级完整轴突/树突连接关系；电镜也不自动提供活动强度 |
| **AAV 病毒载体示踪、单突触狂犬病毒示踪** | 病毒示踪描绘投射或候选突触前输入；空间转录组增加细胞类别及所在组织微环境 | RNA 分型和投射/突触示踪的阳性信号回答不同问题；互相配合也需排除载体/取样偏差 |
| **光遗传辅助电生理、在体钙成像、行为干预** | 检验定位出的细胞群是否具有相应的活动、突触效应或行为因果功能 | 只有空间表达和细胞邻接，不足以证明突触方向、网络动态或因果必要性 |
| **空间多组学与长读长/全长空间转录组** | 补足蛋白、染色质、转录本异构体等不同分子层。(Liu et al., 2020, Cell; Liu et al., 2026, Nat Methods) | 各模态的空间精度、检测量程和统计误差必须分别报告 |

**推荐的证据组合：** 先以空间转录组确定候选脑区/细胞类型及局部表达模式，再用独立原位标记和其他结构、蛋白或生理测量验证。用病毒示踪检验候选投射/输入、用电生理或干预检验功能时，须分别报告每种方法真实观测的对象，不能把多个间接指标自动叠加成“因果机制已证实”。(Moffitt et al., 2018, Science; Zhang et al., 2023, Nature)

## 相关节点

**链接原则：** 本轮只能确认用户提供过相应模板的节点名称，不能检查整个 Obsidian Vault 的实际存在性与发布状态；因此此处全部使用普通文本候选，**不预建任何 Wikilink**。

- **已有主题模板对应的候选节点：** 单细胞RNA测序（参考分型与空间映射）、AAV病毒载体示踪（轴突/投射与空间表达区分）、单突触狂犬病毒示踪（候选突触前输入与空间邻近区分）。
- **建议未来关联的技术节点：** 单核RNA测序、MERFISH、seqFISH、Slide-seq、Stereo-seq、空间蛋白组学、空间多组学、RNAscope、细胞分割、去卷积、组织配准、细胞通讯推断、空间差异表达。
- **建议未来关联的研究对象或证据节点：** 神经元亚型、胶质细胞、神经发育、皮层层化、脑区图谱、RNA编辑、转录本异构体、批次效应、伪重复、可重复性、因果推断。
- **待人工确认：** 检查 Vault 是否已有“空间RNA测序 / spatially resolved transcriptomics / ST”等同义节点；仅对真实存在且拟发布的目标建立按规范路径编写的 Wikilink。

### 证据成熟度、研究争议与人工审核

- **相对稳固：** 多种成像与测序路线可以在保留空间位置的条件下检测 RNA 分布；结合独立实验可以在脑组织中建立可复核的区域/细胞表达地图。(Ståhl et al., 2016, Science; Chen et al., 2015, Science; Yao et al., 2023, Nature)
- **明显受技术与模型影响：** 单细胞定位精度、去卷积细胞比例、空间域边界、未归属 RNA 以及特定亚型的可检测性；平台规格不等于真实有效空间分辨率。(Petukhov et al., 2022, Nat Biotechnol; You et al., 2024, Nat Methods; Lee et al., 2026, Nat Commun)
- **属于候选或推断：** 配体—受体细胞通讯、疾病机制、细胞时序/发育命运、空间 RNA 编辑与蛋白活性之间的因果链，均需按各假说另行设计验证。(Efremova et al., 2020, Nat Protoc; Chen et al., 2026, Nat Commun)
- **新近研究的审慎使用：** 2025—2026 年的分割、RNA 恢复、全长异构体与编辑分析具有方法创新价值，但不能据此推定所有商业化或实验室平台已经实现相同能力。(Jones et al., 2025, Nat Methods; Liu et al., 2026, Nat Methods)
