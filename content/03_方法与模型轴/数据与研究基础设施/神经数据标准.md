# 神经数据标准

> **一句话定义：** 神经数据标准是规定神经科学数据「怎么存、怎么描述、怎么交换」的公共规约——从医学影像的 DICOM 文件格式，到组织目录与元数据的脑成像数据结构（BIDS），到电生理数据语言 NWB 与模型描述语言 NeuroML；它不规定怎么分析，而是让「任何人（包括程序）都能读懂这份数据是什么、怎么采的」成为默认状态。

## 快速理解

一份实验数据如果只以私有格式躺在某台机器上，缺少机器可读的采集参数说明，那么对其他研究者（甚至几个月后的记录者本人）而言就接近不可用：找不到、读不出、对不上。显微成像领域的系统梳理把问题讲得很直接——共享需要公共格式，而各厂商私有格式的碎片化使数据在真实世界里难以流通(Linkert et al., 2010, J Cell Biol)；电生理实验室的实践总结则指出，元数据往往不完整、外人不可读或有歧义，需要专门的工作流来补救(Zehl et al., 2016, Front Neuroinform)。

神经数据标准就是针对这一问题的分层解法。人脑影像方向，脑成像数据结构（BIDS）用「文件名与目录即元数据」的方式组织与描述 MRI 数据集，并且与既有软件兼容(Gorgolewski et al., 2016, Sci Data)；此后社区把它逐步扩展到脑磁图(Niso et al., 2018, Sci Data)、头皮脑电(Pernet et al., 2019, Sci Data)、颅内脑电(Holdgraf et al., 2019, Sci Data)与正电子发射断层(Nørgaard et al., 2022, Sci Data)。细胞与组织电生理方向，Neurodata Without Borders（NWB）为电生理与光学成像建立了公共数据格式(Teeters et al., 2015, Neuron)，并发展成覆盖管理、分析、可视化与存档的数据语言生态(Rübel et al., 2022, eLife)。计算建模方向，NeuroML 用统一的描述语言让模型可以跨模拟器交换(Goddard et al., 2001, Philos Trans R Soc B; Gleeson et al., 2010, PLoS Comput Biol)。这些格式层面的约定之上，还有 FAIR 四原则作为数据管理的公共框架(Wilkinson et al., 2016, Sci Data)。

标准化的效果可以从公开存档的规模读出：OpenNeuro 依据 BIDS 标准管理数据，已公开超过 600 个数据集、覆盖 20,000 余名被试，基于其数据的复用发表超过 150 篇(Markiewicz et al., 2021, eLife)。本节点梳理这套基础设施的分层构成、支持其可靠性的证据，以及采纳不均衡、覆盖不全与「标准化不等于数据质量」三条主要边界。

## 概念界定与边界

**文件格式、数据标准与存档平台是三个不同层面的对象，经常被混用。** 文件格式规定字节怎么排：医学影像的 DICOM 规定了图像数据与通信的标准(Mildenberger et al., 2002, Eur Radiol)，神经影像常用的 NIfTI、MINC 等格式及其与 DICOM 的关系有系统比较(Larobina & Murino, 2014, J Digit Imaging)，电生理与通用科学数据则常用 HDF5 这类通用分层数据容器(Folk et al., 2011, Proc EDBT/ICDT Workshops Array Databases)。数据标准在其上规定组织结构与元数据语义：BIDS 规定目录树、文件命名与 JSON sidecar(Gorgolewski et al., 2016, Sci Data)，odML 规定层级键值的元数据表示(Grewe et al., 2011, Front Neuroinform)，NWB 规定电生理数据语言的组件(Rübel et al., 2022, eLife)。存档与管理平台则是运行这些标准的软件系统：XNAT 提供存档、界面与中间件三层架构，新数据先隔离检疫、验证后入库并保留变更历史(Marcus et al., 2007, Neuroinformatics)；LORIS 以被试为中心整合多中心研究的影像、临床、行为与遗传数据(Das et al., 2011, Front Neuroinform)；COINS 面向大型异构数据集(Scott et al., 2011, Front Neuroinform)；OpenNeuro 与 NeuroVault 是公开存档，前者存放遵循 BIDS 的原始数据(Markiewicz et al., 2021, eLife)，后者存放未阈值统计图并通过公开 API 支持元分析(Gorgolewski et al., 2015, Front Neuroinform)。把三者混为一谈会导致错误的期待——换一个存档平台不会改变数据的组织标准，反之亦然。

**FAIR 是原则而非格式。** FAIR 四原则（可发现、可访问、可互操作、可复用）强调机器自动发现与使用数据的能力，但它是一组管理与治理原则，本身不规定任何文件格式；具体落地仍需 BIDS、NWB 这类标准承担互操作性(Wilkinson et al., 2016, Sci Data)。宣称「数据符合 FAIR」不等于数据已采用任何神经数据标准。

**同一标准的「原始版」与「扩展版」要区分。** BIDS 最初只覆盖 MRI(Gorgolewski et al., 2016, Sci Data)；MEG(Niso et al., 2018, Sci Data)、EEG(Pernet et al., 2019, Sci Data)、iEEG(Holdgraf et al., 2019, Sci Data)、PET(Nørgaard et al., 2022, Sci Data)各自由后续扩展覆盖，元数据字段与验证规则各不相同。使用数据时，「遵循 BIDS」必须具体到模态与版本。

**电生理方向还有一套平行的基础设施。** G-Node 技术栈把电生理数据表示与元数据注释整合为统一存储与 REST API（GNData 平台）(Sobolev et al., 2014, Front Neuroinform)，其元数据框架即 odML(Grewe et al., 2011, Front Neuroinform)；NIX 数据模型也是这一脉络的产物，但它没有独立的方法学论文，本节点不作引注。

## 结构与机制（适用时）

**这套基础设施的分层结构：字节格式 → 组织与元数据 → 数据语言 → 平台与存档。** 最底层是文件格式：影像链路以 DICOM 进入、以 NIfTI 进入分析(Larobina & Murino, 2014, J Digit Imaging)，电生理多以 HDF5 为容器(Folk et al., 2011, Proc EDBT/ICDT Workshops Array Databases)。中间层是组织与元数据约定。BIDS 的核心设计有三点：用文件名与目录结构本身携带元数据；兼容既有软件可直接读取的文件格式；用 JSON sidecar 补充逐数据集与逐采集的参数(Gorgolewski et al., 2016, Sci Data)。odML 则解决另一端的问题——采集时随手产生的元数据——用「格式与内容分离」的层级键值结构，让任意元数据即时入库而不被预定义词表卡住(Grewe et al., 2011, Front Neuroinform)。数据语言层，NWB 把数据与元数据的描述组件化，使同一语言能覆盖从果蝇到人类、从电生理到光学的多种实验(Rübel et al., 2022, eLife)。模型描述层，NeuroML 用声明式「模板」描述从细胞膜到网络的各级结构，使模型可跨工具交换(Goddard et al., 2001, Philos Trans R Soc B)，其后续版本让生物细节模型在 NEURON、GENESIS、MOOSE、NEST、PSICS 等模拟器之间以独立形式定义与复用(Gleeson et al., 2010, PLoS Comput Biol)。

**标准的价值要经由工具链兑现。** BIDS Apps 把分析工具容器化，输入约定就是一个 BIDS 目录，应用在三大操作系统上开箱即用，显著降低了「把新方法套到别人数据上」的门槛(Gorgolewski et al., 2017, PLoS Comput Biol)。fMRIPrep 作为分析无关的预处理流水线，自动适配数据集差异，其可靠运行正以数据的 BIDS 化为前提(Esteban et al., 2019, Nat Methods)。存档层则把标准变成规模：OpenNeuro 按公开、可引用的方式托管 BIDS 数据集(Markiewicz et al., 2021, eLife)，NeuroVault 让组级统计图可公开检索与解码(Gorgolewski et al., 2015, Front Neuroinform)，XNAT 类平台在医院与实验室场景里管理数据全生命周期(Marcus et al., 2007, Neuroinformatics)。

**标准本身是多实验室协商的产物。** NWB 的第一版来自一个明确的试点工程：神经电生理学家与软件开发者共同为细胞电生理与光学成像的记录及元数据制定公共格式，连同 API 与样例数据一起发布(Teeters et al., 2015, Neuron)。这类「先立约定、再长生态」的过程与自发形成的惯例不同，其规约是显式的、可版本化的。

## 关键研究与可重复性

**规模与复用指标是检验标准是否「活了下来」的直接证据。** OpenNeuro 报告的运营数字——600 余个数据集、20,000 余名被试、150 余篇复用发表——是 BIDS 生态持续运转的可查指标(Markiewicz et al., 2021, eLife)；NeuroVault 的公开 API 供其他服务调用，构成元分析与共激活分析的数据底座(Gorgolewski et al., 2015, Front Neuroinform)。这些是资源报告而非受控实验，数字随时间变化，引用时应核对存档现状。

**「标准降低复用成本」有工具链层面的可比较证据。** BIDS Apps 的设计目标与实现——容器化、统一输入目录、跨平台运行——直接针对「方法难以套用到他人数据」这一痛点(Gorgolewski et al., 2017, PLoS Comput Biol)；fMRIPrep 在跨数据集适配与减少人工干预上的表现，使同一流水线可以不变地跑过异质数据集(Esteban et al., 2019, Nat Methods)。这两类证据说明标准化把「分析别人的数据」从定制工程变成常规操作，但不构成对分析结论正确性的证明。

**元数据采集是标准能否落地的瓶颈环节，且有针对性的工程研究。** 电生理实验室的元数据常因实验复杂、流程特异与工具使用门槛而残缺(Zehl et al., 2016, Front Neuroinform)；odML 的设计以「不预设词表、即时入库」换取采集可行性(Grewe et al., 2011, Front Neuroinform)，GNData 平台把数据与元数据统一到一个 API 之后(Sobolev et al., 2014, Front Neuroinform)，采集成本才可被工程化地摊薄。

**标准内部的跨实验室一致性由公开样例与验证器保障，但这属于规约执行而非科学假设检验。** BIDS 与 NWB 都随标准发布样例数据集(Teeters et al., 2015, Neuron; Gorgolewski et al., 2016, Sci Data)；「某数据集是否符合标准」可由验证工具机械判定，而「遵循标准的数据分析结论是否可靠」是另一个问题，见 [[04_证据与推理轴/证据质量/可重复性|可重复性]]。

## 当前较稳定的认识

1. **BIDS 是人脑影像数据组织的事实标准，且已扩展至五大模态。** MRI 原始标准(Gorgolewski et al., 2016, Sci Data)之后，MEG(Niso et al., 2018, Sci Data)、EEG(Pernet et al., 2019, Sci Data)、iEEG(Holdgraf et al., 2019, Sci Data)、PET(Nørgaard et al., 2022, Sci Data)相继并入同一目录与元数据体系；公开存档 OpenNeuro 以其为核心托管 600 余个数据集(Markiewicz et al., 2021, eLife)。

2. **NWB 是细胞与系统电生理的主要公共数据语言。** 从试点格式(Teeters et al., 2015, Neuron)到组件化数据语言与配套生态(Rübel et al., 2022, eLife)，它把「跨物种、跨模态统一描述电生理数据」作为设计目标。

3. **FAIR 四原则是数据管理的公共框架，但需标准承载互操作。** 机器可发现与可访问是 FAIR 相对既有共享实践的主要增量(Wilkinson et al., 2016, Sci Data)；落地仍依赖 BIDS、NWB、DICOM 等具体规约。

4. **医学影像数据以 DICOM 采集、以 NIfTI 分析是主流入口格式。** DICOM 定义采集与通信(Mildenberger et al., 2002, Eur Radiol)，分析格式之间的转换与比较见系统综述(Larobina & Murino, 2014, J Digit Imaging)。

5. **计算模型的可交换性由 NeuroML 系语言承担。** 从需求分析(Goddard et al., 2001, Philos Trans R Soc B)到跨模拟器实现(Gleeson et al., 2010, PLoS Comput Biol)，模型描述与实验数据格式是两条并行但互补的标准线。

## 争议与推断边界

**标准化不解决数据质量问题，更不保证分析结论可靠。** BIDS 只约束「数据如何组织与描述」(Gorgolewski et al., 2016, Sci Data)；一个完全合规的数据集仍可能采集质量低下或分析错误。把「可复用」读成「可信」是常见误读，二者由不同的机制保障，参见 [[04_证据与推理轴/证据质量/可重复性|可重复性]]。

**各模态标准化程度差异巨大，早期数据普遍不合规。** PET 直到 2022 年才有 BIDS 扩展(Nørgaard et al., 2022, Sci Data)，电生理的公共格式在 2015 年才经试点确立(Teeters et al., 2015, Neuron)；此前积累的数据若未回溯转换，就无法进入标准化流水线。跨数据集聚合时，「是否可被标准描述」本身构成样本选择。

**标准覆盖不全，且扩展带来版本负担。** 组织学、行为观察等数据类型缺少同级成熟标准；BIDS 的持续扩展意味着「符合 BIDS」随时间漂移，旧数据集可能不符合新版本规则，工具链与存档对版本的支持也不同步(Gorgolewski et al., 2016, Sci Data; Niso et al., 2018, Sci Data)。

**平台与标准的耦合会形成迁移成本。** XNAT、LORIS、COINS 等平台各有数据模型与访问控制设计(Marcus et al., 2007, Neuroinformatics; Das et al., 2011, Front Neuroinform; Scott et al., 2011, Front Neuroinform)，同一标准数据在不同平台间的迁移并非无损；选择平台实质上也是在选择一套工作流约束。

**人类数据的共享边界由伦理与法律约束，标准无能为力。** FAIR 中的「可访问」在人类数据上常需让位于知情同意与隐私保护(Wilkinson et al., 2016, Sci Data)；受控访问的存档与完全开放存档在可复用性上不可直接比较。
