# 逆转学习任务

> **一句话介绍：** 逆转学习任务（reversal learning task）让受试者先学会一种刺激或行动更有利，随后在实验规则改变但通常不明确告知的情况下，观察受试者能否利用新反馈更新其选择。它用于研究**反馈驱动的行为适应和认知灵活性**，而不是专门测量一个单一的“反应抑制能力”。(Dias et al., 1996, Nature; Izquierdo et al., 2017, Neuroscience; Walton et al., 2010, Neuron)

## 快速理解

假设你要在两幅图案——A 和 B——之间反复选择。最初 A 更容易带来奖励，你渐渐学会选 A。实验进行一段时间后，奖励规则悄悄反转，B 变成更有利的选项。研究者观察你什么时候减少选择 A、什么时候改选 B，以及遇到一次坏反馈时是否立即改变主意。动物实验可以用食物或水奖励，人类实验常用点数、货币收益或其他结果。(Cools et al., 2002, J Neurosci; Bari et al., 2010, Neuropsychopharmacology; Izquierdo et al., 2017, Neuroscience)

这里有三个不能混淆的现象：

1. **学会规则**：初始阶段是否辨别出哪个选择更好。
2. **发现变化**：奖惩关系交换后，是否察觉原先经验已不适用。
3. **稳定重学**：是否能维持新的有利选择，而不是每次遇到失奖就随机切换。

**逆转任务不是“换按键”任务。** 实验应分开刺激身份、按键位置和奖励关联；只有奖惩映射的交换才是这里的核心逆转。研究者还要区分真正的规则改变与概率性反馈中的偶发失奖。(Dias et al., 1996, Nature; Hampton et al., 2006, J Neurosci; Izquierdo et al., 2017, Neuroscience)

**一个重要反直觉结果：** OFC（眶额皮层）损伤后并非总是持续选择旧答案；有的猴子反而**在选项之间切换过多**，可能是无法准确学习“是哪次选择导致了反馈”。因此，错误总量升高不能自动解释为“抑制旧行为失败”。(Walton et al., 2010, Neuron; Izquierdo et al., 2017, Neuroscience)

## 原理与操作流程

### 1. 任务是什么、主要变式是什么

逆转学习通常维持原来的任务维度与候选选项，让先前的优势选项变成劣势选项，同时让另一选项变得更好。与之不同，注意定势转移（attentional set shifting）可能需要从颜色维度转到形状维度；消退任务可能只是不给旧行为奖励，而未出现新的最优选项。(Dias et al., 1996, Nature; Clarke et al., 2005, J Neurosci; Izquierdo et al., 2017, Neuroscience)

| 变式 | 典型实现 | 主要用途 | 混杂风险 |
| --- | --- | --- | --- |
| 确定性逆转 | 规则未变时选 A 总得奖、B 不得奖；逆转后交换 | 规则改变明确时的适应 | 感觉辨别、理解、运动反应、初始学习 |
| 概率性逆转（PRLT） | A 奖励概率高于 B，但 A 也可能偶尔失奖；反转概率映射 | 噪声下的反馈整合与状态推断 | 奖惩敏感、误导反馈、探索倾向 |
| 连续／多次逆转 | 同一配对反复交换或更换多对刺激 | 学会“规则可变”、逆转经验迁移 | 次数规律、过度训练、疲劳 |
| 奖励／惩罚版本 | 将得分、失分、无奖励、惩罚分离 | 正负反馈不对称性 | 价值尺度、负性动机和损失厌恶 |
| 刺激—结果／行动—结果 | 分别更新图案价值或动作的结果 | 价值更新、选择—结果归因 | 位置偏好、执行与信用分配 |
| 固定／随机／表现触发逆转 | 满足试次数、随机变点或达标后才逆转 | 调节环境的可预测性 | 受试者学会倒数或逆转时点与能力混杂 |

以上属于可以**组合的设计因素**，不是一个正式统一的互斥分类。仅说“使用了逆转学习任务”，不足以让另一实验室复制。(Hampton et al., 2006, J Neurosci; Behrens et al., 2007, Nat Neurosci; Costa et al., 2015, J Neurosci; Izquierdo et al., 2017, Neuroscience)

### 2. 一个概率版本的示例流程

**以下是教学设计而不是通用标准。** 设两选项在初始阶段的奖励概率分别为 A = 0.80、B = 0.20；在真正逆转点交换为 A = 0.20、B = 0.80。具体的实验可使用其他概率、不同奖励额和不同触发规则。(Cools et al., 2002, J Neurosci; Bari et al., 2010, Neuropsychopharmacology)

1. **任务说明与练习**：确认受试者能辨别图案、理解反馈、完成按键；保存练习试次数和排除标准。
2. **初始习得**：呈现 A/B，多次选择并接受反馈。记录行为轨迹、奖励与未回应；预先指定固定阶段长度或“学习达标”准则。
3. **逆转触发**：按预先设定的时点或规则悄然交换两选项的奖励关系。记录**真实变点**，而不是把受试者第一次改选时刻称为变点。
4. **逆转后重新学习**：观察旧选项选择比例如何下降、新选项如何取得优势，并分别记录早期探索和后期稳定。
5. **重复逆转或结束**：如有多个逆转，存档每次逆转规则及训练次数；分析时保留未能达标或提前结束者。
6. **行为与模型分析**：比较初始学习、逆转早期及逆转后稳定阶段，拟合备选模型，检查能否模拟真实试次级选择。(Hampton et al., 2006, J Neurosci; Costa et al., 2015, J Neurosci; Wilson & Collins, 2019, eLife)

在上述示例里，哪怕 A 真是最优选项，选择 A 仍有 **20% 的概率在某次失奖**。所以“失奖”不是“规则一定反转”的同义词；错误与否应按**实验潜在奖励规则**定义，实际是否得奖另行记录。(Bari et al., 2010, Neuropsychopharmacology; Izquierdo et al., 2017, Neuroscience)

### 3. 采集哪些原始数据

| 建议字段 | 内容或用途 |
| --- | --- |
| 被试／动物、会话、试次编号 | 标明分层单位，避免把试次当作独立被试 |
| 两个刺激身份、左右屏幕位置、所选动作 | 区分刺激学习、动作偏好、空间侧偏 |
| 隐藏的真实规则和每个选项奖励概率 | 对照生成规则，正确标出真实逆转时点 |
| 实际结果、结果效价、奖励大小 | 区分奖励与惩罚、遗漏和误导性负反馈 |
| 反应时、无回应、无效按键 | 检查动机、执行障碍及延迟 |
| 逆转事件编号、触发方式与规则变更次数 | 比较不同逆转，保证分析可重算 |
| 练习标识、剔除原因与中止原因 | 防止只保留表现好的参与者或动物 |

这是本节点提出的**编辑用可复核字段清单**，不是某篇文献原封不动的标准。对于药理和神经干预，另需存档剂量、时窗、脑区定位、刺激参数与靶区验证；对于动物需记录训练日程及奖励动机状态。(Bari et al., 2010, Neuropsychopharmacology; Izquierdo et al., 2017, Neuroscience; Wilson & Collins, 2019, eLife)

### 4. 行为指标及其真正含义

| 指标 | 如何定义 | 主要解释与限制 |
| --- | --- | --- |
| 初始学习正确率／达标准则 | 尚未逆转时选优势选项的比例／到达预定义准则的试次数 | 识别起始联结学习弱者，避免把它误认成逆转特异缺损 |
| 逆转后旧选项选择（perseverative choices） | 真正逆转后指定窗口继续选择旧优势选项的数量／比例 | 可能来自价值更新慢，也可能来自谨慎等待更多证据 |
| 逆转后达标试次数 | 逆转后达到新的预先设定标准所需试次 | 必须报告固定时长、达标截尾、退出与未达标者 |
| 逆转代价 | 逆转与初始学习阶段的表现差异 | 阶段时长与学习机会需可比 |
| Win–stay / Lose–shift | 中奖后保持选择、失奖后切换的条件概率 | 描述反馈—选择关系，**不是**学习率的直接测量 |
| 逆转对齐的行为曲线 | 以真实变点为中心展示选择比例／反应时 | 分离切换延迟、重新稳定及后期波动 |
| 总奖励量、反应时、遗漏率 | 记录实际回报、行动执行与动机 | 不等于单独的“认知灵活性得分” |
| 模型参数 | 学习率、反馈敏感、选择坚持、隐状态信念 | 都属于给定模型下的潜变量估计，需恢复和信度验证 |

特别注意，概率性任务中，**正确选择**常是指“选择真实生成规则中期望奖励更高的选项”，并非“这一试次碰巧获奖”。两者应分别编码，否则会系统性误记表现。(Cools et al., 2002, J Neurosci; Izquierdo et al., 2017, Neuroscience; Waltmann et al., 2022, Behav Res Methods)

### 5. 如何用模型检验竞争性解释

**简单强化学习：**

\[
\delta\_t=r\_t-Q\_t(a\_t),\qquad Q\_{t+1}(a\_t)=Q\_t(a\_t)+\alpha\delta\_t.
]

这里 (a\_t) 是当前选择，(Q\_t) 是估计价值，(r\_t) 是结果，(\alpha) 是学习率。模型也可区分正负更新率（(\alpha\_+,\alpha\_-)），但这种额外参数是否可恢复、是否必要必须经模型比较，而非默认“所有人有两种独立学习率”。(Bari et al., 2010, Neuropsychopharmacology; Schaaf et al., 2024, Behav Res Methods; Wilson & Collins, 2019, eLife)

**价值引导选择与坚持偏好：**

\[
P\_t(a)=\frac{\exp{\beta Q\_t(a)+\kappa\mathbf{1}(a=a\_{t-1})}}%
{\sum\_b\exp{\beta Q\_t(b)+\kappa\mathbf{1}(b=a\_{t-1})}}.
]

(\beta) 表示选择多大程度依赖价值差异（逆温度），(\kappa) 在这里描述**继续选择同一动作**的倾向，而不必来自当前奖励价值。其他论文可能为“刺激坚持”设置单独参数；两种定义不能混淆。高 (\kappa) 不是对强迫症或其他精神疾病的直接诊断。(Walton et al., 2010, Neuron; Apergis-Schoute et al., 2024, Biol Psychiatry Glob Open Sci; Wilson & Collins, 2019, eLife)

**隐状态／贝叶斯模型：** 假定存在未直接告知的“现在 A 较优还是 B 较优”的环境状态，通过整合反馈推断该状态，并允许环境以一定先验概率反转（hazard rate）。这与逐步更新每个选项的价值相比，在受试者熟悉逆转结构的任务中可能给出不同预测。(Hampton et al., 2006, J Neurosci; Behrens et al., 2007, Nat Neurosci; Costa et al., 2015, J Neurosci; Wilson et al., 2014, Neuron)

**探索与信用分配模型：** 行为切换还可能来自探索信息或不能将结果准确归因给某次选择；OFC 病灶研究有“过度切换”的证据，因此单个“持续错误数”不足以区分这些计算过程。(Daw et al., 2006, Nature; Walton et al., 2010, Neuron; Jocham et al., 2016, Neuron)

**建模最少应做的检查：** 写明似然、参数边界和先验；模拟数据进行参数恢复和模型恢复；对个体时序进行预测检验；比较合理的候选模型，报告拟合不确定性。若两模型对实际任务几乎产生相同可观察行为，便不能依据微小拟合差异宣称某个真实脑机制被识别。(Wilson & Collins, 2019, eLife; Schaaf et al., 2024, Behav Res Methods; Waltmann et al., 2022, Behav Res Methods)

## 能回答什么，不能回答什么？

### 1. 直接观察与较稳妥的推断

逆转学习范式能够直接提供**刺激或行动选择、反应时、奖惩反馈及选择轨迹如何围绕规则交换发生变化**的数据；对照设计可以检验干预后这套任务表现是否改变。与模型结合可进一步估计参与者如何利用反馈，但学习率、状态信念、动机和行动坚持等都是需要独立验证的潜在解释。(Cools et al., 2002, J Neurosci; Hampton et al., 2006, J Neurosci; Izquierdo et al., 2017, Neuroscience)

| 常见过度解释 | 更准确的表述与验证方向 |
| --- | --- |
| “逆转后错误多，就说明反应抑制差” | 可能涉及初始学习差、负反馈敏感性、状态变更识别慢或错误归因；需要控制任务及模型证据。(Walton et al., 2010, Neuron; Izquierdo et al., 2017, Neuroscience) |
| “切换次数越多，灵活性越好” | 受误导性失奖频繁切换也会损失奖励；须分别看逆转前、逆转后的转换。(Walton et al., 2010, Neuron; Costa et al., 2015, J Neurosci) |
| “一次失奖后换选项，就是发现逆转” | 在概率版本中，单次失奖不证明规则变化；应观察跨试次的证据与行为。(Bari et al., 2010, Neuropsychopharmacology; Hampton et al., 2006, J Neurosci) |
| “OFC 在 fMRI 中显著，就证明逆转必需 OFC” | 激活与因果不同；局部损伤和保留经过纤维的损伤研究也有阴性结果。(O'Doherty et al., 2001, Nat Neurosci; Cools et al., 2002, J Neurosci; Kazama & Bachevalier, 2009, J Neurosci; Rudebeck et al., 2013, Nat Neurosci) |
| “血清素负责抑制旧行为，多巴胺负责形成新行为” | 神经递质的效应依药物、脑区、训练史和反馈条件变化，不能套用简单的一一映射。(Clarke et al., 2004, Science; Bari et al., 2010, Neuropsychopharmacology; Costa et al., 2015, J Neurosci) |
| “计算参数更精细，必定比行为指标更可靠” | 参数恢复、重测信度、跨会话独立预测和外部效度必须单独评估。(Waltmann et al., 2022, Behav Res Methods; Schaaf et al., 2024, Behav Res Methods; Kalender et al., 2025, Psychol Assess) |
| “临床患者某项表现差，就能用于疾病诊断” | 需要证明区分效度、药物与症状混杂、独立样本预测价值，且不得从组间差异直接跳到个人诊断。(Apergis-Schoute et al., 2024, Biol Psychiatry Glob Open Sci; Kalender et al., 2025, Psychol Assess) |

**因果层级：** 脑损伤、药理和局部干预比观察性 fMRI 更接近“对指定任务表现的因果影响”，但干预靶区、白质影响、运动执行和情绪动机依然限制解释范围。跨物种行为外表相似，也不足以说明神经计算机制完全相同。(Dias et al., 1996, Nature; Hornak et al., 2004, J Cogn Neurosci; Rudebeck et al., 2013, Nat Neurosci; Izquierdo et al., 2017, Neuroscience)

## 空间、时间尺度与适用对象

### 1. 时间与层级

- **单试次／秒级：** 选择、正负反馈、反应时间和切换；适合试次级行为模型、EEG 或神经记录。事件相关 fMRI 记录的是血流动力学相关信号，不等于毫秒级放电。(Cools et al., 2002, J Neurosci; Hampshire & Owen, 2006, Cereb Cortex; Ghahremani et al., 2010, Cereb Cortex)
- **阶段／分钟级：** 初始联结学习、真正逆转、逆转后的渐进适应和稳定选择，依奖励概率、区块长度和触发机制变化。(Hampton et al., 2006, J Neurosci; Izquierdo et al., 2017, Neuroscience)
- **跨会话／周：** 反复训练会形成“环境可能变化”的先验经验；稳定个体差异研究还要设计间隔重测，不能直接从当日的模型拟合推出长期稳定性。(Costa et al., 2015, J Neurosci; Schaaf et al., 2024, Behav Res Methods; Williams et al., 2025, Behav Res Methods)
- **神经干预与临床状态：** 药理作用、脑损伤、疾病和用药状态可能改变初始学习、动机与反馈反应，不能简单归为统一的“灵活性下降”。(Clarke et al., 2005, J Neurosci; Bari et al., 2010, Neuropsychopharmacology; Apergis-Schoute et al., 2024, Biol Psychiatry Glob Open Sci)

### 2. 实验对象与空间尺度

| 对象 | 常见形式 | 优势 | 特有局限 |
| --- | --- | --- | --- |
| 健康成人与青少年 | 屏幕两选项、分数／货币、眼动和反应时、可结合 fMRI | 适合试次模型及人的任务报告 | 主观奖赏价值、注意和需求特征、年龄差异 |
| 临床人群 | 同一任务加症状、药物与病程资料 | 研究跨诊断反馈处理差异 | 诊断异质性和药物、动机、加工速度混杂 |
| 非人灵长类 | 视觉触屏、反复逆转、食物奖赏、损伤或神经记录 | 接近较复杂前额叶环路的因果干预 | 大量预训练、动机及损伤方式决定结果 |
| 大鼠／小鼠 | 气味、触屏视觉、鼻触或杠杆任务、食物或水奖励 | 可结合细胞类型与回路操作 | 感官类别、食物限制、运动要求与人类不同 |

**跨物种真正应对齐的是任务信息结构，而不仅是正确率**：哪种刺激或动作导致哪类结果，受试者看到什么反馈，多久才可合理推断发生逆转，以及是否经过大量训练。(Dias et al., 1996, Nature; Chudasama & Robbins, 2003, J Neurosci; Walton et al., 2010, Neuron; Izquierdo et al., 2017, Neuroscience)

### 3. 难度与训练史会改变所测机制

较小的奖励概率差通常需要更多证据才能辨别；逆转太频繁可能奖励频繁探索，固定逆转间隔会让受试者学会预测时间，而不是仅从反馈推断规则。充分训练的灵长类也可能由“逐次价值学习”转而使用“任务中存在隐含逆转”的更高阶策略。因此务必记录是否首次接触任务、实际逆转次数、概率安排和逆转间隔。(Hampton et al., 2006, J Neurosci; Behrens et al., 2007, Nat Neurosci; Costa et al., 2015, J Neurosci)

## 质量控制与典型伪迹

### 1. 实验设计和数据层面的检查表

| 风险 | 会制造怎样的假象 | 推荐控制 |
| --- | --- | --- |
| 初始习得失败 | 本来不会辨别，误作逆转困难 | 初始阶段单独分析，预先定义达标与未达标处理 |
| 刺激与按键位置混淆 | 看似更换价值，其实只换位置 | 随机／平衡左右位置，按刺激和动作分别编码 |
| 奖赏序列可预测 | 受试者利用规律而非推断隐状态 | 预生成并存档随机数种子、真实反馈表与变点 |
| 逆转总在固定试次 | 倒数切换，测到计时策略 | 明确固定或随机触发；根据研究目标选择 |
| 单次“坏反馈” | 误把失奖当真实逆转 | 将逆转前误导性失奖和逆转后真正变化分开 |
| 用药或操作改变动机 | 选得少、反应慢被解释为学习差 | 控制奖赏敏感性、反应时、遗漏及初始学习 |
| 不同实验只保留成功者 | 达标快者留下，夸大能力 | 报告全部纳入、截尾、失败与退出规则 |
| 多次训练未报告 | 老练受试者高阶规则知识不同 | 存档训练日、逆转次数和先验任务经验 |
| 在同一数据中探索并验证 ROI | 循环神经影像推断 | 预设对比／ROI，独立样本检验或控制多重比较 |
| 试次当作独立被试 | 假增样本量，置信区间过窄 | 使用合适的被试／动物随机效应或层级模型 |

### 2. 必须同时保留的因果“反例”

早期绒猴 5-HT 去除研究和部分额叶病灶研究观察到逆转后的持续旧选择；而 Walton 等的灵长类 OFC 损伤猴表现出**过度切换**，提示选项—结果信用分配异常可导致同样的总体逆转失败。仅报告错误总数，可能遮盖两种相反的选择策略。(Clarke et al., 2004, Science; Walton et al., 2010, Neuron)

此外，部分 OFC 亚区选择性损伤，以及 2013 年采用保留经过纤维的兴奋毒性损伤的研究，观察到特定物体逆转表现仍然保存；与早期损伤研究并不完全一致。应分别讨论亚区、白质通路损伤、病灶方法、训练史和任务指标，而不是简单宣称“新的阴性结果推翻所有旧研究”，或坚持“OFC 对所有逆转任务必需”。(Fellows & Farah, 2003, Brain; Hornak et al., 2004, J Cogn Neurosci; Kazama & Bachevalier, 2009, J Neurosci; Rudebeck et al., 2013, Nat Neurosci)

### 3. 计算模型的五项不可省略的检查

1. **竞争模型设定：** 至少考虑价值学习、独立的正负反馈效应、上一次刺激或动作坚持、合理的隐状态推断与探索机制。
2. **参数恢复：** 模拟已知参数的被试行为，再估计参数，检查准确度与互相混淆。
3. **模型恢复：** 分别模拟每个候选模型生成的行为，用同样的模型比较程序检查是否能辨认原始模型。
4. **预测而非只拟合：** 比较逆转前后曲线、失奖后的切换以及留出试次／个体／会话的预测能力。
5. **避免信息泄漏：** 使用两次会话联合估计有时提高参数一致性，但若目标是预测未来独立会话，不应把被预测会话的数据纳入预测所用的个人参数。(Wilson & Collins, 2019, eLife; Waltmann et al., 2022, Behav Res Methods; Schaaf et al., 2024, Behav Res Methods; Kalender et al., 2025, Psychol Assess)

### 4. 关于信度，不能只引用某一个好看的数字

Waltmann 等在 N=40 的实验中发现，特定混合效应和层级参数估计方案下可以得到较高的部分信度，但结果受到跨会话联合建模、先验与模型结构影响。Schaaf 等的在线独立会话研究发现，有些强化学习参数的信度很低，另外一些则较高；两项结果不是“互相否定”，需要明确估计方法和时间尺度。(Waltmann et al., 2022, Behav Res Methods; Schaaf et al., 2024, Behav Res Methods)

Williams 等于 2025 年使用 N=150 的逆转学习重测数据及仿真指出，信度本身的**估计精度**也受样本量和方差成分制约，单报 ICC 不能说明个体间与个体内方差来源。另一个 N=179 的精神病谱系临床研究发现，部分行为与模型指标均为差到中等重测信度，计算模型未显示稳定的指标优势。**因此临床预测研究必须做目标人群的独立重测与外部验证。**(Williams et al., 2025, Behav Res Methods; Kalender et al., 2025, Psychol Assess)

建议报告：每个指标的完整定义、试次数和逆转次数、分母与删失处理、ICC 具体模型及置信区间、估计先验、参数与模型恢复结果、与症状或外部行为的收敛和区分证据。研究者可因隐私限制而不公开患者数据，但需要说明受控复核条件；材料无法获取**不等于结论已经被证伪**。(Waltmann et al., 2022, Behav Res Methods; Wilson & Collins, 2019, eLife; Williams et al., 2025, Behav Res Methods)

## 代表性实验或应用

### 1. 经典灵长类研究：逆转和注意定势转换不是一件事

Dias 等通过不同前额叶区域的病灶研究发现，刺激—奖惩关联逆转与注意维度转移具有不同的功能要求。这一经典结果支持将“认知灵活性”拆为可操作的具体过程，而不是把各种切换任务统称为同一个抑制得分。(Dias et al., 1996, Nature)

### 2. 人类成像与病灶：从奖惩反馈到真正改变选择

O'Doherty 等的早期货币反馈任务研究发现眶额皮层的奖赏和惩罚相关信号；Cools 等使用事件相关 fMRI 区分负反馈与真正的行为逆转；Hampshire & Owen 以及 Ghahremani 等也尝试从任务事件中区分前额叶及相关网络参与的具体控制成分。**这些结果是神经相关性，不等于单区脑区必要性。**(O'Doherty et al., 2001, Nat Neurosci; Cools et al., 2002, J Neurosci; Hampshire & Owen, 2006, Cereb Cortex; Ghahremani et al., 2010, Cereb Cortex)

Fellows & Farah 与 Hornak 等的人类额叶病灶研究则进一步提供“特定前额叶损伤会影响某种奖惩逆转表现”的因果层级证据；但神经损伤范围、关注反馈的能力与执行环节需单独控制。(Fellows & Farah, 2003, Brain; Hornak et al., 2004, J Cogn Neurosci)

### 3. 啮齿类研究与 OFC 干预的冲突

Schoenbaum 等使用嗅觉辨别和逆转任务检验眶额—杏仁核相关功能；Chudasama & Robbins 则对比眶额与下边缘皮层在不同学习任务中的作用。两个研究均说明，改变结果映射不是单一局部回路的全部功能。(Schoenbaum et al., 2003, Learn Mem; Chudasama & Robbins, 2003, J Neurosci)

与“损伤 OFC 必然让个体保持旧选择”的解释相对，Kazama & Bachevalier 发现特定眶额亚区损伤对物体逆转表现并非必需；Rudebeck 等采用不同损伤方式进一步提出，经过眶额皮层的纤维损伤可能解释部分既往逆转缺陷。**阴性证据需要与阳性证据并列，而不能将一种损伤方法推广为整个脑区的一切功能。**(Kazama & Bachevalier, 2009, J Neurosci; Rudebeck et al., 2013, Nat Neurosci)

Walton 等在猕猴动态奖励任务中发现，OFC 病灶可能导致**过度转换选择**；依据实验结果的建模，将其解释为正确分配选择—结果关系的困难，比将全部缺陷解释成“行为抑制障碍”更符合当时数据。(Walton et al., 2010, Neuron)

### 4. 神经递质干预：反馈敏感性与隐状态推断

Clarke 等在绒猴研究中发现前额叶 5-HT 去除影响价值逆转，而注意定势转换未表现出同样损害；Bari 等在大鼠概率逆转任务中进一步表明，血清素相关操作会改变对正反馈与负反馈的反应。Costa 等在反复训练的猕猴中利用贝叶斯分析研究多巴胺操作与逆转策略，提示**神经递质效应依药物、训练和任务结构而改变**。(Clarke et al., 2004, Science; Clarke et al., 2005, J Neurosci; Bari et al., 2010, Neuropsychopharmacology; Costa et al., 2015, J Neurosci)

不能将这些结果归纳成“血清素仅负责抑制、多巴胺仅负责奖赏”的一一对应关系，更不能从实验动物药理变化直接推导某种精神疾病的病因。(Izquierdo et al., 2017, Neuroscience; Costa et al., 2015, J Neurosci)

### 5. 从价值更新到“任务状态”的竞争性理论

Hampton 等在概率逆转任务中使用高阶隐状态推断模型研究腹内侧额叶活动；Behrens 等研究环境变动率与反馈权重的调整。Wilson 等后来提出“眶额皮层是任务状态的认知地图”的理论框架，Schuck 等通过人类成像解码提供了对隐含状态表征的支持，但“提出理论、在影像中发现表征、证明因果必要”依然是三类不同证据。(Hampton et al., 2006, J Neurosci; Behrens et al., 2007, Nat Neurosci; Wilson et al., 2014, Neuron; Schuck et al., 2016, Neuron)

Jocham 等的研究进一步突出一个关键机制：需要把奖励或惩罚归因给**哪项选择**，而不是仅简单统计最近是否获得奖励。这有助于解释一些受试者为什么即使记得奖励，也难以稳定选中真正的优势行动。(Jocham et al., 2016, Neuron)

### 6. OCD 与计算精神病学：改变任务，就可能改变结论

Apergis-Schoute 等 2024 年正式见刊的研究纳入确定性与概率性逆转版本，发现强迫症相关表现受到惩罚条件、任务不确定性与 5-HT 药物状态的影响；坚持旧选择与切换过多可在不同设置中同时出现。**这对个体诊断没有直接充分性**，且临床观察比较不能排除用药选择的混杂。(Apergis-Schoute et al., 2024, Biol Psychiatry Glob Open Sci)

2022—2025 年针对概率逆转的重测研究也提醒我们：即使计算模型能对单会话数据拟合得很好，其个体参数未必跨次稳定；临床预测用途必须额外检验构念效度、信度、模型可识别性和目标人群外部预测。(Waltmann et al., 2022, Behav Res Methods; Schaaf et al., 2024, Behav Res Methods; Kalender et al., 2025, Psychol Assess; Williams et al., 2025, Behav Res Methods)

## 与其他方法的关系

| 相邻范式／方法 | 与逆转学习不同的研究重点 | 如何组合以提高解释力 |
| --- | --- | --- |
| 注意定势／维度转换 | 相关刺激维度可能从颜色变成形状，不一定交换奖惩 | 区分奖赏规则更新与维度转移。(Dias et al., 1996, Nature; Clarke et al., 2005, J Neurosci) |
| 消退与再习得 | 奖赏停止，未必存在另一个新的优势选项 | 区分旧关联弱化与在竞争选项间转移。(Izquierdo et al., 2017, Neuroscience) |
| 双臂老虎机／探索—利用任务 | 环境可能固定或缓慢波动，不一定有明确逆转 | 检验切换源于信息搜集还是规则变化。(Daw et al., 2006, Nature; Costa et al., 2015, J Neurosci) |
| 奖赏去价值化 | 改变某种结果的价值，未必改变奖励概率映射 | 检验结果价值更新与刺激—结果关联的区别。(Rudebeck et al., 2013, Nat Neurosci; Walton et al., 2010, Neuron) |
| 停止信号／Go-NoGo | 更直接研究反应制止，不一定包含反馈驱动的长期重学 | 判断逆转错误是否真来自反应抑制。(Izquierdo et al., 2017, Neuroscience) |
| EEG／fMRI／多神经元记录 | 测量神经活动，任务本身只记录行为及反馈 | 分离反馈加工、状态推断和选择转换的神经相关性。(Cools et al., 2002, J Neurosci; Hampton et al., 2006, J Neurosci; Schuck et al., 2016, Neuron) |
| 病灶、药理、特定回路操作 | 操纵神经系统而非仅记录选择 | 对任务条件下某脑区或递质贡献获得更强因果信息，但需要靶向验证。(Clarke et al., 2004, Science; Walton et al., 2010, Neuron; Rudebeck et al., 2013, Nat Neurosci) |
| RL／贝叶斯模型、层级统计 | 基于同一行为检验不同潜在计算过程 | 通过模型模拟、参数恢复、恢复失败与独立预测限定解释。(Hampton et al., 2006, J Neurosci; Wilson & Collins, 2019, eLife; Schaaf et al., 2024, Behav Res Methods) |

**实用选择：** 若研究目标是清晰规则改变后的行为适应，可选择确定性逆转；若要考察在误导反馈下如何推断隐藏状态，概率逆转及变点模型更契合；若要测量稳定个人特质，需特别考虑训练量、独立重测、构念效度及指标稳定性。没有单一版本能自动同时满足所有目标。(Izquierdo et al., 2017, Neuroscience; Waltmann et al., 2022, Behav Res Methods; Williams et al., 2025, Behav Res Methods)

## 相关节点

本轮仅能验证上传的《逆转学习任务》模板；没有完整的 Obsidian Vault 目录与节点发布状态，**不生成未经验证的 Wikilink**。下列内容均为普通文本候选：

- **科学问题：** 大脑如何选择动作、奖励学习如何更新、行为习惯如何形成、探索与利用如何平衡、前额叶如何实现灵活决策。
- **研究对象：** 眶额皮层（OFC）、腹内侧前额叶（vmPFC）、纹状体、基底节、杏仁核、5-羟色胺（血清素）、多巴胺。
- **方法与模型：** 强化学习、Rescorla–Wagner 更新、贝叶斯状态推断、奖赏去价值化、注意定势转换、停止信号范式、fMRI 解码、神经药理干预。
- **证据质量：** 构念效度、信度、可重复性、因果推断、参数恢复、模型恢复、数据泄漏。

**人工核链建议：** 优先核对《大脑如何选择动作》《5-羟色胺》《构念效度》《信度》《可重复性》是否在 Vault 内真实存在、路径是否已确定且拟公开；确认后再添加正确的 Obsidian 相对路径双链。
