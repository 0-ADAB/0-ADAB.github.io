# 抑郁涉及哪些可重复的环路异常

> **核心问题：** 在重性抑郁障碍（major depressive disorder, MDD）中，哪些脑环路层面的结构与功能差异，能够在独立样本、跨中心与跨分析流程的条件下被稳定复现？它们的效应量有多大？这些差异分别对应诊断类别、症状维度、病程阶段与治疗反应中的哪一层？

## 为什么重要？

**临床层面。** 重性抑郁障碍的病因学尚未确立，诊断仍以症状学标准为主，缺少可用于分型或疗效预测的客观生物学指标。现有治疗中，只有部分患者获得充分应答。若存在稳定复现的环路异常，理论上可用于刻画亚型、选择靶点与监测疗效。

**研究层面。** 过去二十余年积累了大量小样本神经影像研究，但结论彼此矛盾，同一网络（例如默认模式网络，default mode network, DMN）内连接改变的方向在不同研究中报告为增高或降低。因此，真正需要回答的不是"抑郁有没有环路异常"，而是"哪些异常在多大样本、何种分析条件下仍然成立"。

**方法层面。** 这一问题同时是脑-行为关联研究（brain-wide association study, BWAS）可重复性讨论的具体案例。脑影像个体差异效应普遍偏小，样本量不足会同时造成效应量膨胀与重复失败 \[来源 25]。

## 问题范围与操作性定义

**属于本问题：**

1. 重性抑郁障碍患者组与健康对照组在静息态功能连接（resting-state functional connectivity, RSFC）、任务态激活、结构磁共振（皮层厚度、表面积、皮层下体积）上的系统性组间差异。
2. 神经调控靶点（经颅磁刺激，transcranial magnetic stimulation, TMS；脑深部电刺激，deep brain stimulation, DBS）与症状环路之间的连接关系。
3. 在啮齿类模型中经光遗传学等方法验证的投射特异性环路机制，及其向人类的外推限度。
4. 这些发现的**可重复程度本身**：计算可复现（同数据同代码）、独立重复（新样本新中心）、跨情境泛化（不同年龄、病程、用药状态、扫描参数）应分别判断，不能互相替代。

**不属于本问题：**

- 单胺类神经递质假说本身（属分子与药理层面，不构成本页的环路证据）。
- 单个基因、单个蛋白或单条信号通路的机制。
- 以影像指标对个体做临床诊断。目前没有任何影像标志物获得临床诊断用途的批准，本页所有结论均为**组间统计差异**，不可直接用于个体判定。
- "抑郁由单一环路导致"的单一病因模型。现有证据更支持多网络关系改变，而非单一病灶。

**"可重复"在本页的操作定义**采用三层区分，与本站 [[04_证据与推理轴/证据质量/可重复性|可重复性]] 节点一致：计算可复现性（reproducibility）、独立重复验证（replicability）、跨情境泛化（generalizability）。下文凡称"较稳健"，均指至少在一项多中心或大样本独立数据中得到方向一致的结果，且报告了效应量。

## 当前较稳妥的回答

按证据强度而非引用次数排列：

1. **结构层面最稳健的发现是海马体积的轻度减小与特定皮层区域变薄，但效应量很小。** ENIGMA 多中心分析显示成人患者海马体积低于对照（Cohen's d = −0.14），该效应由复发病例驱动，首发患者与对照无差异；21 岁前起病者海马更小（d = −0.20）(Schmaal et al., 2016, Mol Psychiatry)。成人患者眶额皮层、前/后扣带回、岛叶与颞叶皮层变薄（d 约 −0.10 至 −0.14），青少年患者则主要表现为表面积降低而非厚度改变 (Schmaal et al., 2017, Mol Psychiatry)。这些是**组间平均差异**，不构成个体诊断依据。

2. **sgACC 与 DLPFC 之间的功能连接（反相关）关系是目前一致性最高的环路层面关系之一，并能预测神经调控疗效，但效应量在更大样本中显著缩小。** Fox 等（2012，Biol Psychiatry）在健康人连接组中显示疗效更高的 DLPFC 位点与 sgACC 反相关更强 ；Weigand 等（2018，Biol Psychiatry）前瞻性验证 r = −0.55 ；Siddiqi 等（2021，Nat Hum Behav）将损伤、TMS 与 DBS 三类数据汇聚到同一环路 。但在 295 例患者样本中，同一指标与疗效的相关仅为 r = −0.16，约解释 3% 变异 (Elbau et al., 2023, Am J Psychiatry)。合理表述是：该关系方向可信，但**单个指标的解释力有限**。

3. **大规模网络间关系改变得到多源支持，但具体方向在不同数据集间不一致。** Meta 分析支持 DMN、CEN/FPN、SN 之间连接异常 (Kaiser et al., 2015, JAMA Psychiatry; Mulders et al., 2015, Neurosci Biobehav Rev)；然而 REST-meta-MDD 在 1,300 例患者中发现 DMN 内连接**降低**且与用药相关 (Yan et al., 2019, PNAS)，PsyMRI 在 606 例患者中未在 DMN 与 FPN 内检出显著差异，而将稳定差异指向感觉运动网络与突显网络 (Javaheripour et al., 2021, Transl Psychiatry)。因此"DMN 内连接增高"不应被当作已确立结论。

4. **损伤-刺激汇聚映射提供了目前最强的因果汇聚证据，但仍不等同于机制证明。** 14 个数据集、三类干预/损伤来源收敛到同一抑郁相关环路（P < 0.001），且该环路连接可样本外预测 TMS 与 DBS 位点的抗抑郁效能（P < 0.0001）(Siddiqi et al., 2021, Nat Hum Behav)。这一结果说明**靶点所在环路**比所用技术更能解释结局差异，但预测效能仍需前瞻随机试验确认。

5. **网络拓扑的个体差异是一条新的候选线索，重复证据尚不充分。** Lynch 等（2024，Nature）报告额纹状体突显网络在多数抑郁个体中扩张近两倍，跨样本可重复、不随情绪状态变化，且在青少年发病前即可检测 。这是一项单一研究组的发现，独立实验室重复尚未完成。

6. **目前没有任何影像指标达到可替代临床判断的阈值。** 所有上述发现的组间效应量均在小到中等范围，且缺乏前瞻性验证其改变治疗决策能改善结局的证据。

## 证据质量与可重复性

**三层分离的判断。** 计算可复现、独立重复与跨情境泛化须分别评估（见 [[04_证据与推理轴/证据质量/可重复性|可重复性]]）。本主题中，ENIGMA 与 REST-meta-MDD 采用本地统一预处理后集中汇总，主要提升的是**跨中心一致性**，不等于同一原始数据被独立重算。

**明确的重复失败案例。** Dinga 等（2019，NeuroImage Clin）严格复现 Drysdale 等（2017，Nat Med）的分析流程，在 187 例抑郁/焦虑样本中得到同样高的典型相关与三聚类解，但加入更严格的统计检验后，典型相关与聚类**均不显著**；作者指出聚类方法在随机数据上也会产生簇 。

**效应量随样本量增大而收缩。** sgACC 连接与 rTMS 疗效的相关从早期小样本的 r = −0.55 (Weigand et al., 2018, Biol Psychiatry) 降至 295 例样本中的 r = −0.16 (Elbau et al., 2023, Am J Psychiatry)，符合 BWAS 在样本量不足时效应量膨胀的普遍模式 (Marek et al., 2022, Nature)。这一模式本身应作为阅读早期文献时的校正项。

**测量可靠性约束。** 单条连接（edge）水平的重测信度平均 ICC = 0.29 (Noble et al., 2019, NeuroImage)，常见任务态 fMRI 指标平均 ICC = 0.397 (Elliott et al., 2020, Psychol Sci)。这限制了任何以单次短时扫描做个体层面预测的方案。提高可靠性的方向包括延长扫描时长与增加个体内重复测量。

**已知混杂因素。** 抗抑郁药使用与连接方式相关（用药者 DMN、FPN、SN 内连接更低）(Yan et al., 2019, PNAS; Javaheripour et al., 2021, Transl Psychiatry)；首发与复发、青年与成人的结构改变模式不同 (Schmaal et al., 2016, Mol Psychiatry; Schmaal et al., 2017, Mol Psychiatry)；头动与呼吸相关的全局信号波动可显著改变连接估计，Elbau 等（2023，Am J Psychiatry）的关联主要由具特定周期性呼吸模式的亚组驱动 。

**负结果与零发现。** Gray 等（2020，Am J Psychiatry）初级分析未检出跨研究空间收敛，仅在合并类别的次级分析与按临床亚型分层的三级分析中识别收敛 ；Javaheripour 等（2021，Transl Psychiatry）在 DMN 与 FPN 内未检出显著差异 ；Dinga 等（2019，NeuroImage Clin）未能重复生物亚型 。

**跨物种外推边界。** Chaudhury 等（2013，Nature）在小鼠中建立了 VTA 投射通路特异的双向因果证据 ，但慢性社交挫败模型与人类重性抑郁障碍的诊断类别之间缺少已验证的对应关系，且人类层面缺少同等特异性的因果干预数据。

## 未解决问题

1. **DMN 内连接方向分歧的来源是什么？** 需在前瞻设计中同时操纵用药状态、病程阶段（首发/复发）、扫描时的自发思维状态与预处理流程，判定哪一因素主导方向差异。
2. **个体层面的稳定估计需要多少数据与多少次重复扫描？** 需要在同一批受试者上做扫描时长与重测次数的剂量-可靠性曲线，并与预测效度直接挂钩。
3. **突显网络拓扑扩张能否被独立实验室重复，是否为抑郁特异？** 需要在其他精神障碍对照组与独立队列中检验 (Lynch et al., 2024, Nature)。
4. **sgACC-DLPFC 反相关之外的连接特征能否实质提高疗效预测？** Elbau 等（2023，Am J Psychiatry）提示单指标解释力约 3%，需要多特征模型的前瞻验证 。
5. **症状维度与环路的映射是否可重复？** 快感缺失、焦虑性痛苦、反刍等症状维度各自对应的环路证据目前样本量不足且流程不一。
6. **发育阶段的差异如何解释？** 青少年以表面积降低为主、成人以皮层变薄为主 (Schmaal et al., 2017, Mol Psychiatry)，这一差异对应的是神经发育轨迹、病程累积还是用药暴露，尚无定论。
7. **影像标志物能否真正改善治疗选择？** 需要以影像分层为随机化因素的前瞻试验，终点应为功能结局而非缓解率的组间差异。
