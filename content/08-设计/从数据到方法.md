# 从数据到方法

> 分析方向不是"想做什么就做什么"，而是被**数据本身的物理限制**筛过一遍的结果。这一页按数据倒推：手上有什么，就只剩哪些路可走。 🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 内容 | 从数据类型倒推分析族、预处理、统计与工具的路径 |
| 输入 | 已有数据（自己的或公开的） |
| 输出 | 可行的分析方案与不可行的排除理由 |
| 相关模态 | 电生理、血流代谢、结构扩散、行为眼动、多人 |
| 主要方法 | 预处理、统计、连接、解码 |
| 证据类型 | 数据的物理量决定上限 |

## 一、倒推的四步

```text
① 数据物理量是什么？采样与覆盖如何？
      ↓ 能提取哪些指标（分析族）
② 指标需要什么前提假设？
      ↓ 需要哪些预处理来满足假设
③ 检验族与设计结构是什么？
      ↓ 统计模型与多重比较校正方式
④ 最后才选工具
```

第 ④ 步对应 [[07-资源/分析平台|分析平台]]。

顺序很重要：**先定分析族，再定预处理**。反过来（先跑一遍标准预处理）经常会删掉后面才需要的成分，而这一步不可逆。

## 二、电生理（EEG / MEG / iEEG）

| 环节 | 内容 |
| --- | --- |
| 物理限制 | 直接反映群体电活动的时间过程，时间精度高；头皮信号空间模糊，参考与容积传导影响大；对肌电、眼动、工频与运动伪迹敏感 |
| 可做的分析族 | 事件相关成分、时频功率与相位、试次间一致性、功能连接、微状态类动态描述、解码 |
| 需要的预处理 | 滤波（含线噪处理）、参考选择、坏导与坏段处理、伪迹成分分解或回归、分段与基线校正、重采样 |
| 统计与校正 | 电极×时间点的高维检验族，常用簇水平置换或对指标先降维再检验；被试内设计需匹配的置换方案 |
| 对应页面 | [[电生理记录]]、[[预处理与伪迹控制]]、[[事件相关分析]]、[[时频分析]]、[[源定位]] |
| 排除项 | 无法回答"哪个核团的哪类细胞在放电"；头皮层面不能直接给出解剖定位 |

## 三、fMRI

| 环节 | 内容 |
| --- | --- |
| 物理限制 | 测的是血氧相关信号，间接反映神经活动；时间分辨率受血流动力学响应限制，单次事件的时间信息被平滑 |
| 可做的分析族 | 任务态激活对比、参数化调制、静息态功能连接、多变量模式分析、表征相似性、有效连接的模型比较 |
| 需要的预处理 | 头动校正与头动影响控制、切片时间校正、配准与标准化、空间平滑（若使用）、去噪与滤波（静息态） |
| 统计与校正 | 一般线性模型与对比；体素、簇或网络水平的校正；组水平需处理被试间与站点间变异 |
| 对应页面 | [[血流与代谢成像]]、[[统计推断与多重比较]]、[[功能连接]]、[[表征相似性分析]]、[[解码与机器学习]] |
| 排除项 | 不能给出毫秒级先后顺序；激活差异不等于某类神经元活动变化；体素级差异不能直接当解剖定位 |

## 四、结构影像与扩散

| 环节 | 内容 |
| --- | --- |
| 物理限制 | 结构像反映形态与组织对比；扩散信号反映水分子扩散的方向性，纤维走向是模型推断的结果而非直接观测 |
| 可做的分析族 | 体积与厚度测量、形态学指标、白质微结构指标、纤维追踪与结构连接矩阵、形变分析 |
| 需要的预处理 | 偏置场校正、颅骨剥离、配准与标准化、扩散数据的运动与涡流校正、张量或更复杂模型的拟合 |
| 统计与校正 | 体素或顶点水平的一般线性模型；追踪结果需注意假阳/假阴纤维与跨被试配准误差 |
| 对应页面 | [[结构与扩散成像]]、[[皮层分区]]、[[大尺度网络]] |
| 排除项 | 结构或扩散指标不直接反映当前活动状态；追踪出的"连接"不等于存在功能耦合或直接突触连接 |

## 五、行为与眼动

| 环节 | 内容 |
| --- | --- |
| 物理限制 | 记录的是外周反应（按键、反应时、注视位置、瞳孔），与中枢过程之间隔着推断步骤 |
| 可做的分析族 | 反应时与正确率的条件比较、漂移扩散类过程模型、眼动指标（注视、扫视、瞳孔）、个体差异与混合模型 |
| 需要的预处理 | 试次筛选与排除标准、异常反应时处理（规则须事先声明）、眼动数据的注视与扫视切分、校准质量核查 |
| 统计与校正 | 混合效应模型（被试与项目为随机效应）、多重比较校正、必要时用贝叶斯方法量化证据强度 |
| 对应页面 | [[行为与眼动]]、[[感知]]、[[注意]]、[[决策与奖赏]] |
| 排除项 | 行为指标不能单独证明某脑区参与；点击位置与注视点不自动等于认知过程本身 |

## 六、多人同步

| 环节 | 内容 |
| --- | --- |
| 物理限制 | 多台设备同时记录，时间对齐与配对结构是关键；个体信号与耦合成分混在一起 |
| 可做的分析族 | 配对或群体水平的同步指标、角色与方向性分析、耦合随任务阶段的变化、行为—神经耦合 |
| 需要的预处理 | 各自模态的常规预处理、跨设备时钟对齐、配对级伪迹检查、共同的被试与试次筛选规则 |
| 统计与校正 | 需要能保留配对结构的置换或分层模型；关键是给出"同步高于随机"的零模型定义 |
| 对应页面 | [[多人同步记录]]、[[实时的神经同步]]、[[社会认知]] |
| 排除项 | 同步指标不能单独解释为"交流"或"共情"；共享刺激即可产生同步，必须设计能排除它的对照 |

## 七、跨越所有数据的通用检查

| 检查项 | 为什么必须在分析前确定 |
| --- | --- |
| 排除标准 | 事后调整排除标准可轻易改变结论，属过度自由度 |
| 参数与随机种子 | 不记录就无法重跑，也无法判断差异来源 |
| 分析的验证性与探索性归属 | 决定结论能被写成"验证"还是"发现" |
| 校正方式与检验族 | 检验族一变，显著性就会变 |
| 质控指标 | 数据质量差异常被误读为效应差异，见 [[质控与可重复性]] |

## 八、三类反向陷阱

| 陷阱 | 表现 | 更好的做法 |
| --- | --- | --- |
| 数据决定问题 | 因为有某数据集，就把问题改成它能回答的 | 明确写清这是局部问题，限制结论范围 |
| 工具决定假设 | 默认预处理就当作正确，不核对前提 | 回到方法页核对假设，记录参数 |
| 结果决定路径 | 试几种分析，报告最好的那个 | 用预注册或分析计划固定路径，探索部分单独报告 |
