# 从问题到证据

> 大多数失败的研究不是"分析做错了"，而是**在问题还没被定义清楚时就选定了手段**。这条链路的作用是把选手段这一步尽量往后推。 🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 内容 | 从研究问题到证据强度预判的完整决策链路 |
| 输入 | 一个想回答的问题 |
| 输出 | 可行的设计、分析方案与预期证据等级 |
| 相关模态 | 全部 |
| 主要方法 | 设计与范式、统计推断、多模态策略 |
| 证据类型 | 由链路各步共同决定 |

## 一、总链路

```text
① 研究问题                          → 能否被观测？
② 可操作定义（构念 → 可测量指标）     → 发生在什么范围？
③ 尺度选择（空间 × 时间）            → 哪种物理量对它敏感？
④ 模态选择（含多模态组合）           → 怎么让效应有机会出现？
⑤ 设计与范式（条件/对照/试次/被试）   → 数据怎么变成指标？
⑥ 分析方案（前提假设/校正/质控）      → 指标能否支持目标推断？
⑦ 证据强度与边界的预判  →  回到 ① 修正问题
```

第 ⑦ 步不是收尾，而是**反馈回第 ① 步**：如果预判出来的证据只能支持关联、而你的问题是因果性的，此时改问题比改分析便宜得多。

## 二、逐步决策表

### ① 研究问题

| 项 | 内容 |
| --- | --- |
| 关键问题 | 要回答的是"是否存在""是否相关""能否预测""何时发生""是否必要/充分""通过什么机制"？ |
| 决策依据 | 问题类型直接决定证据等级上限，见 [[从结果到推断]] 的推断阶梯 |
| 对应页面 | [[06-证据/index\|证据与推断]]、[[解释边界与常见错误]] |
| 常见失败点 | 一句话里塞进"机制"与"定位"两个目标，两者需要不同设计 |

### ② 可操作定义

| 项 | 内容 |
| --- | --- |
| 关键问题 | 构念对应哪个可测量指标？该指标还有哪些别的解释？ |
| 决策依据 | 指标必须能在刺激、反应与时间窗上被明确界定，且能被独立测量 |
| 对应页面 | [[实验设计与范式]]、[[行为与眼动]]、[[03-现象/index\|现象与功能]] 各页的「行为指标」段落 |
| 常见失败点 | 用任务名称代替构念（"注意任务"不等于"注意"），导致结论无法与其它研究比较 |

### ③ 尺度选择

| 项 | 内容 |
| --- | --- |
| 关键问题 | 目标过程的空间与时间范围是多少？需要单被试内还是群体水平？ |
| 决策依据 | 尺度决定可选模态集合；尺度错配无法用分析弥补 |
| 对应页面 | [[01-尺度/空间尺度\|空间尺度]]、[[01-尺度/时间尺度\|时间尺度]]、[[跨尺度整合]] |
| 常见失败点 | 用秒级手段研究毫秒级过程，或用全脑信号推断单细胞机制 |

### ④ 模态选择

| 项 | 内容 |
| --- | --- |
| 关键问题 | 哪个物理量对该过程敏感？该模态的空间/时间分辨率够不够？ |
| 决策依据 | 先看测量的物理量与被测量的距离，再看分辨率与覆盖 |
| 对应页面 | [[模态比较]]、[[02-模态/index\|测量模态]] |
| 常见失败点 | 只比较"能不能做"，不比较"能不能支持我要的推断类型" |

### ⑤ 设计与范式

| 项 | 内容 |
| --- | --- |
| 关键问题 | 条件如何设置？对照是否只差一个变量？试次与被试量是否足够？ |
| 决策依据 | 分析的上限在数据产生之前就被决定；功效不足无法靠统计补救 |
| 对应页面 | [[实验设计与范式]]、[[神经调控技术]]（涉及干预时） |
| 常见失败点 | 混淆变量未控、条件间难度不等、试次太少导致估计不稳 |

### ⑥ 分析方案

| 项 | 内容 |
| --- | --- |
| 关键问题 | 指标如何提取？检验族是什么？校正方式与设计是否匹配？ |
| 决策依据 | 方法的输出量决定它能支持哪类证据；前提假设必须逐条核对 |
| 对应页面 | [[05-方法/index\|方法与分析]]、[[统计推断与多重比较]]、[[质控与可重复性]] |
| 常见失败点 | 循环分析（同一数据既选特征又检验）、校正与检验族不一致、参数不记录 |

### ⑦ 证据强度与边界预判

| 项 | 内容 |
| --- | --- |
| 关键问题 | 最好的结果能支持到推断阶梯的第几级？最坏情况什么样？ |
| 决策依据 | 证据类型必须与结论强度一致，限制条件要事先写出来 |
| 对应页面 | [[从结果到推断]]、[[跨模态一致性]]、[[标准与规范]] |
| 常见失败点 | 事先没想清楚"结果不显著时怎么办"，导致事后改变分析 |

## 三、立项检查清单

- 问题类型已明确（存在 / 关联 / 预测 / 时序 / 因果 / 机制）
- 构念有可操作定义，且列出了竞争解释
- 空间与时间尺度已写明，并与模态分辨率核对过
- 模态的物理量与被测量之间的距离已说清
- 条件之间只差目标变量，混淆变量有控制方案
- 分析方案的每一步都能落到一个已核对其假设的方法页
- 检验族、校正方式与假设结构一致
- 预注册或分析计划已写明验证性与探索性部分
- 预判了证据等级上限，并写了必须随结果一起报告的限制
- 已排除三类整体性错误：手段先行、尺度跳跃、事后定向
