# 从结果到推断

> 分析输出的永远是**某个统计量**，而不是结论。这一页处理它们之间那一步：这个量允许你走到推断阶梯的第几级。 🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 内容 | 结果类型 → 证据类型 → 最强推断 → 限制 → 报告 |
| 输入 | 分析结果与统计量 |
| 输出 | 与证据等级匹配的表述与限制说明 |
| 相关模态 | 全部 |
| 主要方法 | 统计推断、多模态融合 |
| 证据类型 | 结构、功能、动态、因果、计算、一致性、边界 |

## 一、推断强度阶梯

```text
第六级  机制          必要且充分？通过什么过程实现？        ← 需要多条独立证据链与模型
第五级  干预          改变它是否改变结果？（必要/充分）    ← 需要调控或病损类设计
第四级  时间优先      谁先发生？（方向性）                  ← 需要毫秒级或多模态时序证据
第三级  预测          能否预测未见的个体/试次/条件？        ← 需要样本外泛化
第二级  关联          两者是否共同变化？                    ← 相关、连接、共变
第一级  描述          在什么条件下观察到什么量？            ← 一切推断的起点
```

规则：**只能向上跨一级，且必须给出跨级的桥接证据**。从相关性直接跳到机制，等于跳过四级；这是 [[解释边界与常见错误]] 中最常见的问题。

## 二、结果量 → 证据类型

| 结果是什么量 | 属于哪类证据 | 能支持的最强推断 | 必须写出的限制 |
| --- | --- | --- | --- |
| 条件间激活或幅值差异 | [[功能关联证据]] | 该条件与该指标的关联在不同条件下可区分 | 不能断言该区域"负责"该功能；差异可能来自其它同步变化的变量 |
| 时间序列相关或连接强度 | [[功能关联证据]] | 两个单元存在统计依赖 | 统计依赖不包含方向；共同输入可产生相关 |
| 方向性模型参数 | [[时间动态证据]] 或 [[因果干预证据]] 的弱形式 | 数据在模型下更支持某一方向 | 模型方向是模型假设的结果，不等同于生理因果 |
| 潜伏期或时间窗差异 | [[时间动态证据]] | 过程在时间上的先后次序 | 潜伏期差异受信噪比与基线影响，不能直接当传导顺序 |
| 频谱或振荡指标 | [[时间动态证据]] | 某频段活动的动态特征与条件相关 | 振荡功率≠特定回路；头皮分布不等于源位置 |
| 解码或分类准确率 | [[功能关联证据]] 的较强形式（信息存在） | 目标变量在数据中可被区分并可泛化 | 泛化不等于因果；准确率受类别不平衡与样本量影响 |
| 表征距离或相似性结构 | [[功能关联证据]] | 条件间的表征几何存在差异 | 几何差异不能直接映射到具体神经编码 |
| 结构或微结构指标 | [[结构证据]] | 个体间结构差异与某指标共变 | 结构指标是静态的，不反映当下活动；测量误差与配准误差需量化 |
| 调控或病损的效应 | [[因果干预证据]] | 该单元对结果有因果贡献（必要或充分，按设计而定） | 需说明作用的特异性与传播效应；不能外推到未测量的功能 |
| 模型拟合与比较结果 | [[计算模型证据]] | 某计算假设比竞争假设更能解释数据 | 模型族的选择本身影响结论；拟合优不等于机制为真 |
| 多模态同向结果 | [[跨模态一致性]] | 多重独立测量指向同一结论 | 一致可能来自共同的方法学偏差，须说明如何排除 |
| 不显著或效应消失 | [[解释边界与常见错误]] 关注的边界信息 | 在当前功效下未能检出 | 不能写成"不存在"；须给出可检出的效应量范围 |

## 三、从结果到表述的流程

```text
结果 → 是统计量还是原始观测？
     → 属于上表中哪一类？
     → 该类的推断上限是哪一级？
     → 我实际写到的表述在第几级？
     → 若超出上限：降级表述，或补桥接证据
     → 限制段落：写清不能得出的结论
```

## 四、每类结果的报告要求

| 项 | 最低要求 |
| --- | --- |
| 效应量 | 报告效应量而非只有 p 值；单位与含义需说明 |
| 不确定性 | 报告置信区间或后验区间，而不是单点估计 |
| 检验族与校正 | 说明检验族范围与校正方式；簇水平结果须给阈值 |
| 自由度与排除 | 说明被试/试次排除标准与最终纳入量 |
| 多重比较 | 明确哪些比较属验证性、哪些属探索性 |
| 方法细节 | 预处理参数、软件与版本、图谱与坐标空间（以官方文档术语书写） |
| 阴性结果 | 说明可检出效应量或等价性检验结果，避免"无差异"的表述 |
| 复现材料 | 代码、参数与衍生数据可获取性与获取条件 |

规范清单可参照 [[标准与规范]] 中的报告类文档。

## 五、常见越界表述对照

| 越界写法 | 问题 | 可替代写法 |
| --- | --- | --- |
| "A 区负责 X 功能" | 从关联跳到机制 | "A 区活动与 X 相关，且在条件 Y 下可区分" |
| "B 与 C 之间存在信息传递" | 相关当作方向 | "B 与 C 的信号在统计上相关，方向性有待专门设计检验" |
| "解码结果证明脑内存在 X 表征" | 泛化当作机制 | "目标变量可从该数据中读出；其神经实现方式未在本研究检验" |
| "干预后 X 消失，说明 X 定位于 D" | 忽略传播与代偿 | "对 D 的干预改变了 X；作用是否特异于 D 未被检验" |
| "两模态一致，结论可靠" | 一致性当作独立验证 | "两模态结果同向；共同偏差的可能性见限制部分" |
| "结果不显著，说明无效应" | 把未检出当作不存在 | "在本设计的功效下未检出；可检出范围约为…" |

## 六、写限制段落的三条纪律

1. **限制要与结论对应**，不是通用免责。写"样本量有限"不如写"该设计无法区分 A 与 B 两种解释"。
2. **区分测量限制与推断限制**：前者关于信号（分辨率、覆盖率、伪迹），后者关于逻辑（能否从该量推出该结论）。
3. **限制不削弱结论，它界定结论的适用范围**。没有边界的结论在跨研究比较时无法使用。
