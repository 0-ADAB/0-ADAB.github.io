# 路径

> 前面六个目录是"知识"，这里是把知识串成**可执行流程**的地方。三条主线，覆盖研究从想法到结论的全过程。

## 定位

| 坐标 | 取值 |
| --- | --- |
| 内容 | 流程、决策点、检查清单 |
| 输入 | 问题、数据、结果 |
| 输出 | 下一步该做什么 |
| 关联 | 指向全部其它目录 |

## 三条主线

### ① [[从问题到证据]]

```text
研究问题
  → 能否被观测（可操作定义）
  → 需要哪个空间/时间尺度
  → 选择模态
  → 选择设计与范式
  → 选择分析
  → 预判证据强度与边界
```

用于：立项、写方案、判断一个问题是否可做。

### ② [[从数据到方法]]

```text
已有数据
  → 数据类型的物理限制
  → 可做的分析族
  → 需要的预处理
  → 统计与校正
  → 对应工具
```

用于：拿到数据之后、或拿到别人数据之前。

### ③ [[从结果到推断]]

```text
分析结果
  → 结果是什么类型的量
  → 属于哪类证据
  → 能支持的最强推断
  → 必须写出的限制
  → 如何报告
```

用于：写结果与讨论、审稿、自查。

## 一张总览表

| 阶段 | 关键决策 | 常见失败 |
| --- | --- | --- |
| 问题 | 可操作定义是否明确 | 概念模糊，无法测量 |
| 尺度 | 目标过程的时间/空间范围 | 手段分辨率不匹配 |
| 模态 | 测量的物理量与推断目标是否匹配 | 用间接量做直接断言 |
| 设计 | 条件、对照、试次数、被试数 | 功效不足、混淆未控 |
| 分析 | 假设是否成立、自由度是否透明 | 循环分析、未校正 |
| 推断 | 证据类型与结论强度是否一致 | 相关写成因果、定位写成机制 |
| 报告 | 是否可复现 | 缺参数、缺数据、缺代码 |
