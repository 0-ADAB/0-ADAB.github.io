# 决策与奖赏

> 决策与奖赏研究的是价值如何被表征、比较并转化为选择；可观测的是选择与反应时的统计结构，被解释的对象是价值与学习信号，两者之间隔着模型假设。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 神经元 → 回路 → 脑区 → 网络 |
| 时间尺度 | 毫秒（证据累积与放电时序）→ 秒（选择）→ 分钟至天（折扣与状态） |
| 相关模态 | [[02-模态/电生理记录\|电生理记录]]、[[02-模态/血流与代谢成像\|血流与代谢成像]]、生理与神经化学 |
| 相关现象 | 情绪与应激、学习与记忆、注意 |
| 相关结构 | 皮层下结构、神经递质系统、大尺度网络 |
| 主要方法 | 实验设计与范式、表征相似性分析、有效连接与因果建模 |
| 证据类型 | 计算模型证据、因果干预证据、边界类证据 |

## 行为指标

起点是一组可记录、可操作定义的外在量：

- **选择比例**：在两个或多个选项间的选择份额，配合对选项价值或概率的参数化操纵。
- **反应时与潜伏期**：把「决策难度」定义成从刺激到反应的时间，常用于证据累积类解释。
- **风险与模糊偏好**：在概率已知（风险）与概率未知（模糊）的条件下的选择差异。
- **匹配律（matching law）**：并发强化程序（concurrent schedule）下反应分配比例与强化比例之间的关系；强化程序下的反应率（FR/VR/FI/VI）同样是标准指标。
- **主观价值量表与努力折扣**：让被试对选项评分，或在需要付出努力的任务中测量愿意付出的代价。
- **漂移扩散模型（drift-diffusion model, DDM）参数**：漂移率、决策阈限与非决策时间的估计值。

同一现象有多种操作定义，至少可举出以下 2—3 例：

- 「价值」可以是主观评分，可以是选择偏好，也可以是愿意付出的努力量；评分是言语报告量，选择是行为量，努力代价是成本量，三者不等价。
- 「风险态度」可以由彩票的确定性等价物（certainty equivalent）定义，可以由选择比例随概率变化的斜率定义，也可以由反应时分布定义。
- 「奖赏学习」可以由选择随反馈改善的速率定义，可以由强化程序下反应率的变化定义，也可以由后续选择中对已得结果的重访倾向定义。

**不同定义对应不同证据，不能混用**：以主观评分定义的价值与以选择比例定义的价值，在同一被试上可能给出不同排序，把两者的结论放进同一段论证会制造无法归因的矛盾（[[08-设计/从结果到推断|从结果到推断]]）。

三种句式在本页必须分清：

| 句式 | 决策研究中的例子 |
| --- | --- |
| 能力陈述 | 强化程序能稳定产生可预测的反应率；电生理可记录毫秒级放电时刻 |
| 证据陈述 | 多项研究提示，部分中脑神经元的放电与预测误差（prediction error）的估计值相关 |
| 推断边界 | 该相关不能推出「该递质系统就是奖赏本身」，也不能推出某个体的价值函数 |

## 计算层面的描述

行为指标本身不含机制，需要用计算过程解释。以下框架彼此不互斥：

- **价值表征与比较**：把每个选项写成标量或多维价值，选择由比较规则产生；价值可以是学到的，也可以是即时计算的。
- **证据累积到阈限**：把选择写成对证据的连续累积过程，达到阈限即反应；反应时与错误率的联合分布成为对模型的约束。
- **模型式与无模型控制**（model-based / model-free）：把行为分成依赖环境内部模型的前瞻控制与依赖缓存价值的回顾控制；两类模型常可拟合同一批数据，边界判定依赖对任务的先验假设而非单次实验。
- **时间折扣、风险效用与预测误差**：把远期结果按折扣函数折算、把客观概率按效用函数非线性变换，并把学习驱动写成结果与预期之差。

区分这些框架的标准是**能否预测新条件下的行为**，而不是参数拟合优度；参数本身不是心理实体（[[06-证据/计算模型证据|计算模型证据]]）。

## 候选神经机制

以下均为候选与提示，不是定论：

- **眶额与内侧前额的价值表征候选**：多项研究提示，这些区域的活动与多种结果的价值相关；但价值相关性既可能是编码，也可能是输入或输出环节的伴随信号。
- **多巴胺能预测误差信号候选**：多项研究提示，部分中脑多巴胺能神经元的放电模式与预测误差的估计值一致；这提示一种学习信号，不代表多巴胺等同于「快乐」。
- **纹状体—皮层环路与去甲肾上腺素调制**：价值学习、选择与动作执行可能被串成环路候选；同时多项研究提示，觉醒与注意状态会改变证据累积的效率或阈限，从而改变速度—准确性权衡。
- **递质系统的广泛投射**：递质系统以弥散方式调制多个回路，把它当作单一「奖赏通路」会掩盖其在不同任务中的异质角色（[[04-结构/神经递质系统|神经递质系统]]）。

必须避免的写法是「价值由某区域计算」。**功能定位不等于功能解释**：知道某区域与价值相关，不等于知道它执行了什么计算。

## 各尺度证据

| 尺度 | 能提供什么类型的信息 | 在该尺度上看不到什么 |
| --- | --- | --- |
| 分子 | 受体、转运体与递质浓度的分布与变化 | 看不到选择与偏好这一层面的量 |
| 神经元（细胞） | 单个细胞的放电与结果、价值、选择的时序关系 | 看不到群体层面的抽象价值；细胞类型与投射靶区常无法确认 |
| 回路 | 局部兴奋—抑制平衡、投射方向、价值信号如何传递 | 看不到跨区域整合与个体差异 |
| 脑区 | 区域反应与价值、概率、努力程度的关联 | 看不到区域内部的计算，也无法区分编码与伴随 |
| 网络 | 区域间统计依赖、状态重组与图论指标 | 看不到单细胞事件；网络指标受预处理与阈值选择影响 |
| 全脑 | 整体拓扑、跨个体一致性与个体差异分布 | 看不到机制，也不能回答单一个体的价值函数 |

跨层级的推断必须显式声明，见 [[01-尺度/跨尺度整合|跨尺度整合]]。

## 各模态证据

- **电生理**（[[02-模态/电生理记录|电生理记录]]）：毫秒级时序，可检验价值信号与选择、结果出现之间的时间关系。局限：记录位点与细胞类型取样偏差明显，时间先后不等于因果顺序。
- **血流代谢成像**（[[02-模态/血流与代谢成像|血流与代谢成像]]）：空间覆盖与人类适用性最好，可提示价值相关区域与条件差异。局限：秒级间接信号，无法分辨毫秒级顺序；价值相关性不区分编码、比较与反应准备，BOLD 的价值相关信号不是因果价值编码的证据。
- **生理与神经化学**（[[02-模态/生理与神经化学|生理与神经化学]]）：递质、激素与外周生理指标的浓度或代理量，可提示状态性调制。局限：外周量到中枢递质之间存在推断距离，多为关联证据。
- **行为与眼动**（[[02-模态/行为与眼动|行为与眼动]]）：提供独立于神经信号的功能输出与连续时间进程，是校准模型参数的参照。局限：行为指标混合多个成分，且受策略与报告方式影响。
- **神经调控与分子遗传**（[[02-模态/神经调控技术|神经调控技术]]）：调控可检验某区域或某递质系统对选择的必要性；分子与遗传则提供递质相关基因个体差异与行为表型的关联线索。局限：调控影响范围广、个体差异大；遗传关联效应通常小且异质，不能推出个体层面的功能定位。

## 争议与未解问题

- **价值表征的位置之争**：价值是集中在少数区域，还是分布式地表征在多个区域与多种编码形式中，取决于如何定义「价值」。
- **预测误差与奖赏体验的混淆**：把预测误差信号读成主观愉悦，是把学习信号当成了体验，两者在操作定义上不同。
- **参数的心理实在性**：漂移率、折扣率与学习率在个体内的稳定性有限，把它们直接当作稳定特质或临床指标缺少独立效度验证。
- **跨物种与跨尺度外推**：动物的选择模型与神经信号证据较丰富，但人类复杂决策涉及规则与语言；用单细胞的价值相关性解释群体偏好、或用群体激活解释个体选择，都缺少中间环节的独立验证。

## 常见过度解读

1. **把多巴胺一律等同于「快乐分子」**：多项研究提示它与预测误差、动机与运动等多种过程相关，把其中一种读成唯一功能是过度简化。
2. **把 BOLD 价值相关信号当作因果价值编码**：相关只说明该区域活动随价值变化，不说明它产生价值；因果结论需要干预证据。
3. **把强化学习参数当作心理实体**：学习率与折扣率是模型参数，其数值依赖模型假设与拟合方式，换一个模型就可能改变解释。
4. **把动物选择模型直接套到人类复杂决策**：任务结构与可用规则集不同，外推需要独立验证。
5. **由激活区域反推心理过程**：反向推断（reverse inference）只有在区域与过程的对应关系被独立验证时才成立；价值相关活动与选择之间的相关也不能写成因果（[[06-证据/解释边界与常见错误|解释边界与常见错误]]）。
