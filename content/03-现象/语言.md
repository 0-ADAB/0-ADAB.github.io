# 语言

> 语言研究处理的是符号系统（音、形、义与句法结构）如何被表征与加工；可观测的是行为与生理量的差异，被解释的对象却在表征与计算层面。🌿 扩充中

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 回路 → 脑区 → 网络（听觉与语言相关皮层的层级组织） |
| 时间尺度 | 毫秒（声学—音位整合）→ 秒（词与句加工）→ 发育与老化 |
| 相关模态 | [[02-模态/电生理记录\|电生理记录]]、[[02-模态/血流与代谢成像\|血流与代谢成像]]、行为与眼动 |
| 相关现象 | 感知、学习与记忆、社会认知 |
| 相关结构 | 皮层分区、大尺度网络、神经递质系统 |
| 主要方法 | 表征相似性分析、解码与机器学习、有效连接与因果建模 |
| 证据类型 | 功能关联证据、时间动态证据、边界类证据 |

## 行为指标

起点不是「语言」，而是一组可记录、可操作定义的外在量：

- **反应时类**：词汇判断（lexical decision）与图片命名（picture naming）的潜伏期，把「提取一个词」定义成按键或说出名称所需的时间。
- **眼动类**：首次注视时间、注视时长、回视（regression）次数与落点，把「加工困难」定义成阅读中眼睛停留与折返的分布。
- **阅读时间代价**：句法违例、语义违例或歧义区段上的阅读时间增量，常与自定步速阅读或眼动指标配合。
- **知觉范畴类**：语音范畴边界（categorical perception）与辨别函数，把「音位」定义成连续声学参数上的陡峭辨别边界。
- **准确率类**：复述、听写与句子—图片匹配的正确率及错误类型分布；临床上则用失语症成套测验（aphasia battery）的命名、复述、理解与流利度分项分数。

同一现象有多种操作定义，至少可举出以下 2—3 例：

- 「词汇通达」可以是词汇判断潜伏期，可以是命名的发声起始时间，也可以是阅读中的注视时长；前者含决策成分，中者含发声运动成分，后者含阅读过程成分。
- 「句法加工」可以是违例引发的阅读时间代价，可以是语法判断的准确率，也可以是听觉呈现时的脑电成分差异；三者对「句法」的界定并不相同。
- 「语音知觉」可以是范畴边界的陡峭程度，可以是噪声中的识别阈，也可以是音节辨别正确率。

**不同定义对应不同证据，不能混用**：在命名潜伏期上成立的操作定义，不能直接解释词汇判断上的差异；同一现象在不同研究间出现的矛盾，往往来自定义而非来自脑（见 [[08-设计/从结果到推断|从结果到推断]]）。

三种句式在本页必须分清：

| 句式 | 语言研究中的例子 |
| --- | --- |
| 能力陈述 | 眼动可连续记录注视位置与时间；电生理可记录毫秒级电位变化 |
| 证据陈述 | 多项研究提示，句法违例会在阅读时间与特定脑电成分上同时留下可测的代价 |
| 推断边界 | 该代价不能推出「句法模块」的存在，也不能推出某区域在执行句法运算 |

## 计算层面的描述

行为指标本身不含机制，需要用计算过程解释。以下框架彼此不互斥：

- **音—形—义的分层表征与竞争**：把词汇通达写成多层表征间的激活与相互抑制，反应时差异来自竞争解决所需的时间。
- **预测与 surprisal 式加工代价**：把加工难度写成对输入的预测误差或惊奇度（surprisal），预测越强、违例越意外，代价越大。
- **序列编码与层级组合**：把句子加工写成对序列顺序的统计学习加上对层级结构的组合操作，两者可被分别操纵。
- **双通路式的词典—规则分工**：把熟悉形式的直接提取与规则的组合生成分成两条路径，用以解释规则形式与例外形式的差异。

区分这些框架的标准是**能否预测新条件下的行为模式**，而不是能否讲通已有数据（[[06-证据/计算模型证据|计算模型证据]]）。

## 候选神经机制

以下均为候选与提示，不是定论：

- **左侧额颞网络的层级时间整合**：皮层层级上从声学特征到音位、词与句的整合，可能依赖时间常数不同的层级（[[01-尺度/网络|网络]]）。多项研究提示，该网络损伤与特定语言成分缺损相关，但相关不等于它就是「语言中枢」。
- **听觉皮层的语音特征编码**：多项研究提示，听觉皮层对频谱与时序调制等声学特征有选择性，语音特异性可能部分来自对这类特征的敏感性，而非独立的语音模块。
- **白质束与振荡耦合**：背侧与腹侧通路可能分别承担声音—发音映射与声音—意义映射，白质结构提示可能的通路但不证明信息流方向；此外多项研究提示，皮层振荡相位可能对齐语音节律，为切分提供时间框架，而该关系同样可能由刺激节律本身驱动。
- **发育时间窗**：多项研究提示，语音范畴的形成与早期听觉经验的统计结构有关，但成年后的可塑性边界尚无公认判据。

必须避免的写法是「语言功能定位于左额下回」。**功能定位不等于功能解释**：知道某区域参与某任务，不等于知道它执行了什么计算。

## 各尺度证据

| 尺度 | 能提供什么类型的信息 | 在该尺度上看不到什么 |
| --- | --- | --- |
| 分子 | 递质、受体与基因表达的空间分布，与语言相关表型的关联线索 | 看不到句法结构、语义关系这一层面的对象 |
| 神经元（细胞） | 单个细胞对声学、语音或词形的选择性，以及放电时序 | 看不到跨区域整合与句法层级 |
| 回路 | 局部兴奋—抑制平衡、跨区投射的时序关系 | 看不到词汇量与句法规则这类系统层面属性 |
| 脑区 | 区域反应与任务条件的关联，区域损伤后的缺损模式 | 看不到区域内部的计算，也难以区分因果与其伴随 |
| 网络 | 区域间统计依赖、层级拓扑、状态间的重组 | 看不到单细胞或单突触事件；网络指标依赖预处理选择 |
| 全脑 | 整体拓扑、跨个体一致性与个体差异分布 | 看不到机制；群体统计不能回答单一个体的加工过程 |

跨层级的推断必须显式声明，见 [[01-尺度/跨尺度整合|跨尺度整合]]。

## 各模态证据

- **电生理**（[[02-模态/电生理记录|电生理记录]]）：毫秒级时间进程、振荡相位与刺激—反应锁时性，可提示加工阶段的先后。局限：头皮记录的空间定位是逆问题的模型解，不能直接给出解剖位置，单个成分往往对应多个源。
- **血流代谢成像**（[[02-模态/血流与代谢成像|血流与代谢成像]]）：空间定位较好，可提示哪些区域在何种条件下参与。局限：信号是数秒尺度的间接量，无法分辨毫秒级顺序，且激活差异不区分兴奋性与抑制性贡献。
- **结构扩散成像**：白质束走行与结构连接的个体差异，为通路假设提供解剖约束。局限：纤维交叉与方向难以完全解析；结构连接不等于功能连接，更不等于有效连接。
- **行为与眼动**（[[02-模态/行为与眼动|行为与眼动]]）：提供可独立操作定义的功能输出与连续时间进程，是校准其它模态的参照。局限：行为指标混合多个加工成分，单靠行为难以分解。
- **神经调控**（神经调控技术）：可在因果层面检验「该区域或该时段是否必要」。局限：刺激同时影响多个网络，语言任务对状态变化敏感。
- **生理化学与分子遗传**：提供递质系统、受体分布与个体遗传差异的关联线索。局限：多为关联性证据，不能推出单个个体的功能定位。

## 争议与未解问题

- **操作定义混用**：同一现象在一批数据里由命名分数定义，在另一批里由句法判断定义，两类结论并列讨论时矛盾无法归因。
- **左侧优势的地位**：不对称性是统计倾向还是功能组织的必要条件，尚无公认的操作性判据。
- **层级性与统计学习之争**：序列统计学习能否解释全部层级现象，取决于如何定义「层级」，而定义本身就在争议中。
- **区域与网络、跨尺度推断的边界**：语言缺损更适合用局部区域还是用网络节点与连接来描述，两种描述常在同一数据上同时成立；而用细胞层面的选择性直接解释句子理解、或用解码结果断言脑在使用该信息，都缺少中间环节的独立验证。

## 常见过度解读

1. **把左侧优势直接说成「语言中枢」**：不对称性是加工偏向的统计表现，把它读成一个专门脑区，是把功能定位当成了功能解释。
2. **把解码出的词义当作「读心」**：解码能力依赖训练集、刺激集与特征选择，脱离这些条件无法外推为对任意心理内容的读取。
3. **把失语症病灶—症状对应当成模块证据**：病灶很少局限于单一区域，症状也混合多种成分；这属于[[06-证据/功能关联证据|功能关联证据]]，不是模块化的证明。
4. **把动物发声与人类语言等同**：发声序列的统计学习与人类语言的层级组合、开放词汇不是同一个对象。
5. **由激活区域反推心理过程，并把相关性写成因果性**：反向推断（reverse inference）只有在区域与过程的对应关系被独立验证时才成立；区域活动与语言成绩相关，也不能推出该区域产生语言能力，因果结论需要干预或损伤证据（[[06-证据/解释边界与常见错误|解释边界与常见错误]]）。
