# 意识与睡眠

> 意识与睡眠至少要拆成两个变量：觉醒水平（arousal / wakefulness）与体验内容（conscious content）；两者可以同向变化，也可以彼此脱钩。🌿 扩充中

## 行为指标

本页所有推断都必须从外在可观测量出发。同一现象至少有下面几类互不等价的操作定义，它们对应不同证据，**不能混用**：

- **睡眠分期判读**：按规则化的多导睡眠图（polysomnography, PSG）标准，把连续记录切分为清醒、非快速眼动各期与快速眼动期。它是对生理信号的规则化标签，不是对主观体验的分类。
- **觉醒阈值与唤醒反应**：施加定量刺激后是否出现唤醒、所需刺激强度、唤醒后行为恢复的快慢。测的是反应性，不是体验内容。
- **报告范式与无报告范式（no-report paradigm）**：前者要求被试口头或按键报告所见所感；后者改用瞳孔、眼动或自发行为。前者的测量链含报告与决策环节，后者试图把报告环节移出测量链——两者测的不是同一个量。
- **掩蔽与双眼竞争中的可见性评定**：可见性评分（visibility rating）、知觉交替率、主导时长。
- **麻醉深度量表与镇静评分**：临床量表评分，以及由脑电派生的指数。量表评分含评定者与情境成分。
- **觉醒后回忆率**：报告有梦或能回忆内容的比例，同时受回忆与遗忘两个环节影响。

操作定义混用的典型后果：以"是否有报告"定义的清醒，与以"皮层响应是否分化"定义的清醒，可以在同一名被试身上给出相反判定。

## 计算层面的描述

- **全局可用性（global availability）与全局工作空间（global workspace）**：把意识通达刻画为信息被广播到多个专用子系统、从而可被多类下游过程取用的过程。工作空间是功能架构假设，不是解剖实体。
- **整合信息式的复杂度度量**：以系统对扰动的响应多样性与不可分解性刻画"整合程度"，如扰动复杂度指数（perturbational complexity index, PCI）一类指标。它定义在代理量上，与主观体验的关系需要独立论证。
- **预测加工（predictive processing）中的精度**：把状态差异刻画为先验、似然与精度（precision）权重的重新分配，而非某个区域的开关。
- **觉醒—意识二维分离**：觉醒水平与体验内容并非单调绑定，这一框架本身是可检验的计算假设。

## 候选神经机制

以下均为候选机制，不是已确立的结论：

- **丘脑—皮层环路的门控**：丘脑与皮层之间的往返环路被提示参与状态切换与信息选通；丘脑网状核的抑制作用被提示参与慢波与睡眠纺锤的产生条件。
- **长距离皮层—皮层连接的整合**：多项研究提示，远距离连接的有效整合程度与是否出现报告相关；但连接指标对预处理与阈值高度敏感，见 [[05-方法/功能连接|功能连接]]。
- **神经调质对觉醒态的调制**：胆碱能、去甲肾上腺素能等上行调制系统被提示改变皮层兴奋性与状态切换概率。调制不等于"某种递质对应某种意识水平"。
- **振荡现象的候选功能**：慢波、纺锤与高频活动被提示参与状态维持与离线巩固；这是候选角色，不是已定的功能指派。

**功能定位不等于功能解释**：知道某环路参与状态维持，不等于知道它执行了什么计算。

## 各尺度证据

| 尺度 | 能提供的信息 | 在该尺度上看不到什么 |
| --- | --- | --- |
| 分子 | 受体、转运体与递质相关分子的分布与状态 | 看不到网络动力学，也看不到主观状态 |
| 神经元（细胞） | 放电时刻与刺激、行为事件的关系 | 覆盖极小，不能说明全脑状态 |
| 回路 | 局部门控、同步与振荡的产生条件 | 不能说明全脑整合或报告能力 |
| 脑区 | 区域活动的状态依赖与任务依赖 | 不能单独支撑"某区是意识中枢" |
| 网络 | 跨区域耦合的统计结构 | 耦合指标不等于通信，方向需另行论证 |
| 全脑 | 全局状态与复杂度类指标 | 看不到细胞级机制，指标含义依赖其定义 |

## 各模态证据

- **电生理**：能力上给出毫秒级时序，适合分期判读、诱发响应与扰动响应；局限是颅外记录的容积传导与参考依赖，颅内记录受临床取样限制。见 [[02-模态/电生理记录|电生理记录]]。
- **血流与代谢成像**：给出区域级与网络级的空间定位；局限是时间常数以秒计，无法分辨毫秒过程，且状态相关的生理变化本身会改变信号。见 [[02-模态/血流与代谢成像|血流与代谢成像]]。
- **结构与扩散成像**：提供解剖与白质通路参照，为连接指标提供解剖基础；局限是结构连接不决定功能耦合。见 [[02-模态/结构与扩散成像|结构与扩散成像]]。
- **行为与眼动**：提供无报告范式中的瞳孔、注视与自发行为指标；局限是这些指标同样受觉醒与动机影响，不与体验内容一一对应。见 [[02-模态/行为与眼动|行为与眼动]]。
- **神经调控**：经颅磁刺激等扰动可检验系统对扰动的响应，是因果类证据的来源；局限是刺激部位与强度选择影响结论，且效应依赖当前状态。见 [[06-证据/因果干预证据|因果干预证据]]。
- **生理与神经化学**：可用于状态操纵与外周生理同步记录；局限是操纵的弥散性与选择性不足，不能支持"某分子对应某体验"。

## 争议与未解问题

- **复杂度类指标的地位**：这类指标在麻醉、睡眠与脑损伤群体中的变化被广泛报告，但它度量的是响应的多样性与不可压缩性，还是意识本身，仍无共识；指标对刺激参数与记录条件敏感。
- **无报告范式是否真的排除报告**：无报告范式移除了显式报告，但被试仍可能进行内隐评估；把替代指标等同于"无报告的体验"是一条未被独立验证的桥接假设。
- **分期标签与连续状态**：分期把连续状态离散化，边界判定依赖规则与判读者；再用分期标签去解释机制，存在循环解释的风险。
- **跨物种与跨状态外推**：动物在麻醉或睡眠操纵下的结果向人类主观体验外推，需要独立验证，不能默认成立。
- **残余状态的检出**：行为无反应与无体验之间的区分依赖指标的灵敏度与特异度，弱证据下的阳性判定风险需要专门讨论，见 [[06-证据/解释边界与常见错误|解释边界与常见错误]]。

## 常见过度解读

- 把某类复杂度或熵指标直接当作意识的度量，并用于个体判定。
- 把无反应等同于无意识，或把有反应等同于体验内容存在。
- 把睡眠分期标签当作脑状态的全部描述。
- 把麻醉下动物或离体制备的结果直接推及人类主观体验。
- 由区域激活反推心理过程（反向推断, reverse inference）：只有当区域与过程的对应关系被独立验证时，这类推断才成立。
- 把与报告相关的网络活动写成产生意识的因果机制；相关设计不支持因果结论。
- 把清醒与睡眠处理成单一维度的两端，忽略觉醒与体验内容的分离。
