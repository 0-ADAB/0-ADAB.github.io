# 情绪与应激

> 情绪与应激指机体对内外挑战做出的内部状态改变，它同时改变主观体验、外周生理与选择倾向；但情绪本身没有单一观测量，只能由多类指标共同约束。🌿 扩充中

## 行为指标

情绪与应激没有任何一个指标等同于"情绪"，所有研究都依赖操作定义（operational definition）。常见路径至少有四类：

- **主观报告**：效价（valence）与唤醒（arousal）自评量表、情绪调节任务中报告的变化量。
- **外周生理**：皮肤电导反应（skin conductance response, SCR）、心率变异性（heart rate variability, HRV）、瞳孔直径、皮质醇（cortisol）反应曲线。
- **反射与行为倾向**：惊跳反射增强（fear-potentiated startle）与惊愕习惯化、趋近—回避反应、情绪 Stroop（emotional Stroop）的干扰量。
- **任务表现**：急性社会应激任务后的皮质醇变化曲线、风险选择中的回避比例、注意偏向指标。

同一概念的操作定义并不等价。例如"应激"至少可以是：应激任务后的皮质醇曲线变化、自评紧张程度、HRV 下降幅度；"情绪调节"至少可以是：报告效价改变、情绪性材料诱发的皮层下信号变化、皱眉肌肌电（electromyography, EMG）变化。这些定义对应不同证据，**不能混用**：皮质醇上升不蕴含主观紧张，自评改变不蕴含外周生理改变，各层指标之间常只有弱相关。任何"情绪更强""应激更高"的结论都必须指明使用哪一类定义。

## 计算层面的描述

行为指标的规律需要计算层面的描述来组织，主要有四类候选框架：

- **维度模型**：用效价（正—负）与唤醒（高—低）两个连续维度描述状态，解释报告与生理指标的共变结构。
- **基本情绪类别模型**：假设存在若干离散类别，各有特征性表达模式，解释跨情境的归类一致性。
- **评价过程**：把情绪生成看作对刺激与目标相关性的持续评估（appraisal），情绪调节常被写成重新评估（reappraisal）改变评估结果。
- **内感受推断与稳态负荷**：把内部状态作为被推断对象，情绪是对躯体状态与情境先验的推断产物；稳态负荷（allostatic load）框架把应激描述为资源从长期目标向即时应对的再分配。

这些框架不是互斥层级，而是对同一批行为的不同描述；它们在多数范式下预测高度重叠，因此难以用单一指标判定哪一个正确（模型不可辨识问题）。见 [[06-证据/计算模型证据|计算模型证据]]。

## 候选神经机制

以下均为候选解释或提示性关联，不是已确立的机制：

- **皮层下—皮层环路**：多项研究提示杏仁核（amygdala）参与威胁与显著性相关刺激的检测，前额叶对皮层下活动的自上而下调控是常见候选解释；但调控方向、强度与条件依赖，且该环路各节点同时承担其他功能。
- **下丘脑—垂体—肾上腺轴（hypothalamic–pituitary–adrenal axis, HPA axis）**：应激激素反应的候选通路，末端为糖皮质激素；其时间常数为分钟级，不能用来解释秒级情绪波动。
- **蓝斑—去甲肾上腺素系统（locus coeruleus–norepinephrine system, LC-NE）**：多项研究提示它与警觉、觉醒状态以及不确定性下的探索—利用权衡有关；从放电模式到行为策略之间仍隔着多层推断。
- **单胺与神经肽调制**：多巴胺、5-羟色胺（5-hydroxytryptamine, 5-HT）以及促肾上腺皮质激素释放激素（corticotropin-releasing hormone, CRH）、内源性阿片肽等被提示以增益控制方式调节回路反应，而不承载具体信息内容。
- **振荡与网络状态**：某些频段的功率变化与状态相关，但频段—功能的映射不唯一，不能由某一频段反推某一情绪。

## 各尺度证据

| 尺度 | 能提供的信息 | 在该尺度上看不到什么 |
| --- | --- | --- |
| 分子 | 递质、激素、受体与表达产物的丰度与分布 | 回路组织与行为因果方向；丰度不等于功能权重 |
| 神经元（细胞） | 单个细胞放电与调制随状态的关联 | 网络层面的因果方向；取样偏差、细胞类型常不确定 |
| 回路 | 局部微环路与投射的候选机制 | 全脑状态与主观报告；自然条件下该环路是否被调用 |
| 脑区 | 区域参与、损伤与调控证据 | 区域内部的计算与事件时间顺序 |
| 网络 | 跨区域协同与连接模式 | 方向性（相关连接不给方向）、个体特异的含义 |
| 全脑 | 全局状态与多指标联合模式 | 承载机制；个体差异常被平均掩盖 |

尺度之间的桥接需要独立证据。**功能定位不等于功能解释**：知道某区域在一类任务中被卷入，不等于知道它执行了什么计算，也不等于它是该现象的必要条件。跨尺度推断的常见越界见 [[01-尺度/跨尺度整合|跨尺度整合]]。

## 各模态证据

- **电生理**：能提供毫秒级时间进程（如对情绪性刺激的早期与晚期成分）。局限：容积传导与参考选择影响结论，头皮源定位不唯一，对肌电与眼动高度敏感。
- **血流代谢成像**：能提供全脑空间定位与区域参与模式。局限：血流动力学响应延迟为秒级，无法分辨快速序列；激活强度不是必要性证据，见 [[02-模态/血流与代谢成像|血流与代谢成像]]。
- **结构扩散成像**：能为候选环路提供白质通路与解剖连接支持。局限：连接存在不等于功能权重，方向性推断有限。
- **行为与眼动**：能提供注视、瞳孔、反应时与选择等独立输出。局限：单指标与心理过程并非一一对应，见 [[02-模态/行为与眼动|行为与眼动]]。
- **神经调控**：能通过刺激或抑制做因果检验。局限：刺激非特异、状态依赖，结果受参数与靶点定义影响，见 [[02-模态/神经调控技术|神经调控技术]]。
- **生理与神经化学、分子与遗传**：能提供皮质醇、皮电、HRV、受体分布与遗传变异等层次的信息。局限：外周指标与中枢状态之间距离较大，取样时间常数与所关心的心理过程常不匹配。

## 争议与未解问题

- **操作定义混用导致结论互相矛盾**：同一批被试上皮质醇、自评与 HRV 常常并不收敛，"应激升高"是否成立取决于选取了哪一类指标。
- **跨尺度推断越界**：动物恐惧条件化范式得到的回路机制被直接映射到人类主观情绪体验，中间缺少必要的桥接证据。
- **类别与维度之争**：两种描述框架对成像与行为数据的拟合常难分高下，命名化标签（"恐惧中枢"）掩盖了这种不可辨识。
- **反向推断（reverse inference）**：由激活区域反推心理过程，只有在区域与过程的对应关系被独立验证时才成立；本现象中这类独立验证通常缺失，见 [[06-证据/解释边界与常见错误|解释边界与常见错误]]。
- **边界不清**：长期应激状态与情绪状态在时间尺度与测量上高度重叠，"慢性应激"与"情绪特质"是否属于同一层级尚无共识。

## 常见过度解读

1. 把杏仁核活动一律读作"恐惧"：该区域参与显著性、不确定性与觉醒等多种条件，激活本身不指认心理内容。
2. 把皮质醇水平当作"应激程度"的刻度：它受昼夜节律、采样时点、饮食与运动影响，且时间常数与多数实验范式不匹配。
3. 把情绪诱发任务当作情绪本身：任务诱发的是受控条件下的加工差异，不等于自然情境中的状态。
4. 把动物恐惧条件化范式直接推广到人类主观情绪。
5. 把外周生理指标当作中枢机制的读数：SCR 与 HRV 反映自主神经输出，不等于脑内某个具体过程。
6. 把相关性写成因果性：共变既不能说明状态引起行为，也不能说明干预有效。
