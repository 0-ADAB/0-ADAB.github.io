# 现象与功能

> 认知功能不是脑区里的"格子"。每一个现象都需要被拆成：**行为指标 → 计算过程 → 神经表征 → 脑区/网络 → 生理机制**，然后分别在不同尺度上寻找证据。

## 定位

| 坐标 | 取值 |
| --- | --- |
| 空间尺度 | 回路 → 网络 → 全脑 |
| 时间尺度 | 毫秒 → 发育与老化 |
| 相关模态 | 全部 |
| 主要结构 | [[04-结构/index\|结构与系统]] |
| 主要方法 | 实验设计与范式、表征分析、连接分析 |
| 证据类型 | 功能关联、时间动态、因果干预 |

## 每个现象页的固定结构

```text
行为指标          可被观察、可被记录的外在量
    ↓
计算层面的描述     用什么计算过程解释这些行为
    ↓
候选神经机制       回路、振荡、连接、递质
    ↓
各尺度证据         分子 / 细胞 / 回路 / 脑区 / 网络 / 全脑
    ↓
各模态证据         电生理 / 成像 / 行为 / 干预
    ↓
争议与未解问题
    ↓
常见过度解读       把相关当因果、把指标当机制
```

## 使用方式

1. 从现象进入，先看「行为指标」，确认研究中的可操作定义；
2. 再看「各尺度证据」，判断你的问题落在哪个尺度；
3. 横向跳到对应的 [[02-模态/index|测量模态]] 与 [[05-方法/index|方法与分析]]；
4. 最后用 [[06-证据/index|证据与推断]] 检查结论强度。

## 需要注意的三点

- **同一现象有多种操作定义**：例如"注意"在实验中可能是线索效应、搜索效率或持续表现，不同定义对应不同神经证据，不能混用。
- **功能定位不等于功能解释**：知道某区域参与某任务，不等于知道它做了什么计算。
- **反向推断（reverse inference）风险**：由激活区域反推心理过程，只有在区域与过程的对应关系被独立验证时才成立。详见 [[06-证据/解释边界与常见错误|解释边界与常见错误]]。
